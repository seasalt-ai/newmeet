Platformforskelle

Kapitel 29: Platformforskelle

Introduktion

SeaMeet fungerer på flere platforme — Windows, macOS og Linux — men hvert operativsystem har sine egne særheder, kapaciteter og begrænsninger. Hvad der fungerer perfekt på Windows, kan opføre sig anderledes på Mac. Nogle funktioner er tilgængelige på én platform, men ikke en anden. At forstå disse forskelle hjælper dig med at få mest muligt ud af SeaMeet, uanset hvilken computer du bruger.

Dette kapitel forklarer, hvordan SeaMeet tilpasser sig hver platform, hvilke funktioner der er platform-specifikke, og hvilke begrænsninger du bør kende til.

Kapitelmål

Efter at have læst dette kapitel vil du være i stand til at:

  • Forstå forskelle mellem Windows, macOS og Linux-versioner
  • Vide, hvilke funktioner der er platform-specifikke
  • Konfigurere SeaMeet korrekt til dit operativsystem
  • Arbejde omkring platform-specifikke begrænsninger
  • Vælge den rigtige platform til dine optagelsesbehov

Del 1: Oversigt efter platform

SeaMeet på Windows

Bedst til:

  • Maksimal kompatibilitet
  • Spiloptagelse
  • Forretningsmiljøer
  • Mest funktionskomplet version

Nøglekarakteristika:

  • Flest funktioner tilgængelige
  • Bedste hardwareacceleration-understøttelse (NVIDIA/AMD/Intel)
  • Let systemlydoptagelse
  • Bredeste app-kompatibilitet
  • Mest testet og stabil

Understøttede Windows-versioner:

  • Windows 10 (version 1809 og senere)
  • Windows 11
  • Windows Server 2019/2022 (begrænset understøttelse)

Understøttede Windows-arkitekturer:

  • x64 (Intel/AMD 64-bit): Fuld understøttelse, alle funktioner tilgængelige
  • ARM64 (Windows på ARM): Understøttet, nogle lydfunktioner ikke tilgængelige
    • Surface Pro X og lignende enheder
    • Skærmoptagelse, videooptagelse, mikrofonoptagelse fuldt understøttet
    • Systemlydoptagelse og lydenhedsoptælling ikke tilgængelig (graceful nedbrydning)
    • Se Windows ARM64-afsnittet nedenfor for detaljer

Ikke understøttet:

  • Windows 7, 8, 8.1 (slut på levetid)
  • Windows XP/Vista (ældgammel)
  • 32-bit Windows (x86)

SeaMeet på macOS

Bedst til:

  • Kreative fagfolk
  • Apple-økosystem-brugere
  • Ren, konsekvent grænseflade
  • Integration med Mac-arbejdsgange

Nøglekarakteristika:

  • Poleret, native Mac-grænseflade
  • Fremragende ydeevne på Apple Silicon (M1/M2/M3)
  • Fremragende ydeevne på Intel Macs
  • Tæt systemintegration
  • Anderledes tilladelsesmodel
  • Pr.-app mikrofonovervågning
  • Browser-mødedetektering og auto-start-forebyggelse

Understøttede macOS-versioner:

  • macOS 14.2 Sonoma (minimum - kræves til native-audio-node-funktioner)
  • macOS 15 Sequoia
  • Fremtidige versioner

Understøttede macOS-arkitekturer:

  • Apple Silicon (arm64): Fuld understøttelse, alle funktioner inklusive pr.-app lydregistrering
  • Intel (x64): Fuld understøttelse med separat installer

Apple Silicon- og Intel-understøttelse:

  • To separate DMG-installers: en til Intel, en til Apple Silicon
  • Download den version, der matcher din Macs processor
  • M1/M2/M3 Macs → Download arm64-version
  • Intel Macs → Download x64-version
  • Begge versioner har identiske funktioner
  • Hardwareacceleration via VideoToolbox (Apple Silicon) eller Quick Sync (Intel)
  • Pr.-app mikrofonregistrering (native-audio-node)
  • Smart vinduesforhåndsvalg til mødeapplikationer

SeaMeet på Linux

Bedst til:

  • Tekniske brugere, der kører SeaMeet fra kilde
  • Udviklere, der bidrager til projektet
  • Privatlivsbevidste brugere
  • Open source-fortalere

Nøglekarakteristika:

  • Community-understøttet, kun fra kilde (ingen officiel forudbygget installer)
  • Variabelt funktionssæt efter distribution
  • Mere manuel konfiguration nødvendig
  • Kommandolinjevenlig
  • Færre "det virker bare"-funktioner

Understøttede distributioner:

  • Ubuntu 20.04+ (bedste understøttelse)
  • Fedora 34+
  • Debian 11+
  • Andre Debian/Ubuntu-baserede distros

Linux-installationsnoter (v2.1.4+):

✅ npm install lykkes nu rent på Linux

Indtil v2.1.4 fejlede `npm install` på Linux med EBADPLATFORM,
fordi native-audio-node — et macOS/Windows-kun native modul —
var listet i `dependencies`. Fra v2.1.4 bor det i
`optionalDependencies` sammen med de andre platform-specifikke lyd-
pakker (macos-audio-devices, native-sound-mixer, win-audio), så
npm springer dem over på Linux i stedet for at afbryde.

Hvis du tidligere ramte `npm ERR! EBADPLATFORM`:
1. Træk v2.1.4 eller senere
2. Slet node_modules og package-lock.json
3. Kør npm install igen — det skal afsluttes uden fejl

Begrænsninger:

  • Ingen officiel forudbygget installer — kør fra kilde via npm start
  • Pr.-app mikrofonovervågning og mødeauto-detektering er ikke tilgængelig (kræver native-audio-node, som ikke har Linux-binær)
  • Systembakkens tilgængelighed afhænger af desktop-miljø (se Bakke-afsnittet nedenfor)
  • Hardwareacceleration varierer efter GPU/driver-kombination
  • Mere opsætning nødvendig til systemlydoptagelse (PulseAudio / PipeWire loopback)

Systembakke og Lite-tilstand efter platform

SeaMeet fortsætter med at køre i baggrunden, efter du lukker hovedvinduet — systembakken (kaldet menubjælken på macOS) er, hvordan du kommer tilbage til den, ændrer optagelsestilstand og afslutter rent. Electrons Tray-API er platform-specifik, så adfærd varierer:

Linux-bakkenoter:

Electron-bakken fungerer pålideligt på GNOME (med AppIndicator-udvidelsen), KDE Plasma, XFCE, Cinnamon og de fleste Ubuntu/Fedora-standardskriveborde. På Wayland-kun-sessioner og nogle minimale vinduesmanagers vises bakkeikonet muligvis slet ikke — appen kører stadig, men du bliver nødt til at genstarte den fra terminalen eller bruge en global genvej til at bringe vinduet tilbage. Der er ingen Linux-specifik bakkeikon-aktiv; den samme .ico indlæses som for Windows.

Lite-tilstand:

Lite-tilstand (introduceret i v2.x) er et renderer-side kompakt layout — en 560×80 floater-bjælke med optagelseskontroller, bølgeform og hurtige handlinger i stedet for det fulde app-vindue. Den styres af ui.appMode-indstillingen ('full' eller 'lite') og skifter ved runtime via Indstillinger. Lite-tilstand fungerer identisk på alle tre platforme, fordi den ikke har nogen platform-specifik kodesti.

Del 3: Windows-specifikke funktioner og opsætning

Windows-fordele

1. Systemlyd er let

På Windows er det ligetil at fange systemlyd:

Metode: Stereo Mix (mest pålidelig)

Opsætning:
1. Højreklik på højtaler-ikon → Åbn lydindstillinger
2. Lydkontrolpanel → Optagelse
3. Højreklik i tomt område → Vis deaktiverede enheder
4. Højreklik "Stereo Mix" → Aktivér
5. Indstil som standard

SeaMeet kan nu fange systemlyd direkte

Alternative metoder:

  • WASAPI loopback (moderne metode)
  • DirectSound-optagelse
  • Virtuelle lydkabler

2. Masser af hardwareacceleration

Windows har den bedste GPU-encoder-understøttelse:

NVIDIA-GPU'er:

GTX 600-serien og nyere:
• NVENC encoder dedikeret chip
• Fremragende kvalitet
• Meget effektiv
• SeaMeet understøtter automatisk

AMD-GPU'er:

Radeon HD 7000-serien og nyere:
• VCE (Video Coding Engine)
• God kvalitet
• Effektiv kodning
• Automatisk understøttelse

Intel integreret:

4. generation Core og nyere:
• Quick Sync Video
• Overraskende god kvalitet
• Meget strømeffektiv
• Fantastisk til laptops

3. Spilfunktioner

Windows-specifik spilintegration:

Spiltilstand-understøttelse:
• Windows Game Mode API
• Auto-detect, når i spil
• Optimér ressourcer
• Kun tilgængelig på Windows

Game Bar-integration:
• Kan arbejde sammen med Xbox Game Bar
• Ingen konflikter
• Separate genveje

Windows-opsætningsguide

Optimal konfiguration:

1. Aktivér Stereo Mix til systemlyd
2. Opdater GPU-drivere:
   - NVIDIA: GeForce Experience
   - AMD: Radeon Software
   - Intel: Intel Driver Assistant

3. Aktivér hardwareacceleration i SeaMeet:
   Indstillinger → Video → Brug hardwareacceleration

4. Indstil strømplan til "Høj ydelse" til optagelse

5. Deaktivér Windows Game Mode, hvis det forårsager problemer:
   Indstillinger → Spil → Spiltilstand → Fra

Windows-specifikke genveje

Globale genveje (virker overalt):
• Ctrl + Alt + R — Start/stop optagelse
• Ctrl + Alt + F — Gem Flashback
• Ctrl + Alt + S — Skærmbillede

Vinduesstyring:
• Win + G — Game bar (hvis aktiveret)
• Win + Alt + R — Xbox Game Bar-optagelse
   (virker sammen med SeaMeet)

Windows ARM64-specifik information

Hvad er Windows ARM64?

ARM64 er en anden processorarkitektur:
• Bruges i Windows på ARM-enheder (Surface Pro X osv.)
• Native understøttelse til ARM-baserede processorer
• Kan emulere x64-apps (langsommere)
• Voksende understøttelse til native ARM64-apps

SeaMeet på ARM64

SeaMeet har native ARM64-understøttelse fra v1.0.2+:

✅ Fuldt understøttet på ARM64:
• Skærmoptagelse (høj ydelse)
• Videooptagelse (høj ydelse)
• Mikrofonoptagelse (direkte Windows API)
• Vinduesdetektion og -styring
• Floater-widget og tastaturgenveje
• Indstillinger og optagelsesbibliotek
• Alle UI-funktioner

❌ Ikke tilgængelig på ARM64:
• Systemlydoptagelse (lyd fra apps/højtalere)
• Lydenhedsoptælling (mikrofon-/højtalerdetektion)
• Lydmikser-kontrol
• Disse kræver native moduler ikke kompileret til ARM64

Hvornår skal du bruge ARM64

Bedst til:

  • Surface Pro X-brugere, der ønsker native ydelse
  • Optagelse af video/skærm uden systemlyd
  • Mikrofonoptagelse (direkte optagelse virker)
  • Fuld ydelse uden emulerings-sløvhed

Ikke ideel til:

  • Systemlydoptagelse (vil ikke være tilgængelig)
  • Komplekse lydarbejdsgange
  • Lydenhedsvalg (ikke tilgængeligt)

Sådan finder du ud af, hvilken version du har

Windows-indstillinger:
1. Indstillinger → System → Om
2. Kig efter "Systemtype"
3. Viser enten:
   • "x64-baseret processor" (64-bit Intel/AMD)
   • "ARM-baseret processor" (Windows på ARM)

Kommandolinje:

PowerShell: wmic os get osarchitecture
Output: 64-bit eller ARM 64-bit

Installation

SeaMeet auto-detekterer din arkitektur:

• Download den generiske installer
• Den vil automatisk installere den korrekte version
• x64-brugere får: SeaMeet-...-x64-Setup.exe
• ARM64-brugere får: SeaMeet-...-arm64-Setup.exe

Eller download manuelt den rigtige fra releases:
• Tjek din systemtype (ovenfor)
• Download matchende arkitektur

Auto-Updater på ARM64

Sømløse opdateringer:
• Appen tjekker for opdateringer automatisk
• ARM64 opdaterer til ARM64 (ikke x64)
• Bagudkompatibel med tidligere versioner
• Ingen manuel indgriben nødvendig

Fejlfinding af ARM64-problemer

Problem: "Systemlyd"-mulighed er nedtonet

Forventet adfærd på ARM64:
✓ Dette er normalt
✓ Native modul ikke tilgængeligt
✓ Kan stadig optage mikrofon
✓ Ingen fejl - graceful nedbrydning

Problem: Kan ikke vælge mikrofon/højtaler

Løsninger:
1. Brug standard systemenheder
2. Gå til Windows-lydindstillinger for at vælge enhed
3. SeaMeet vil bruge, hvad Windows har valgt
4. Manuelt enhedsvalg ikke tilgængeligt på ARM64

Problem: Optagelse af mikrofon virker ikke

Løsninger:
1. Tjek Windows-lydindstillinger
2. Mikrofon skal være standard inputenhed
3. Giv mikrofontilladelser til SeaMeet
4. Windows bør vise optagelsesniveau
5. Test først i Windows-optagelsesapp

Del 4: macOS-specifikke funktioner og opsætning

macOS-fordele

1. Poleret grænseflade

SeaMeet på Mac føles native:

• Følger macOS-designretningslinjer
• Bruger native kontroller
• Respekterer systemtema
• Touch Bar-understøttelse (på kompatible Macs)
• Korrekt menubjælke-integration

2. Fremragende Apple Silicon-understøttelse

M1/M2/M3-chips virker fremragende:

Apple Silicon-funktioner:
• Hardwareacceleration via VideoToolbox
• Fremragende ydeevne pr. watt
• Hurtig kodning
• Kølig drift
• Lang batterilevetid under optagelse

3. Systemintegration

macOS-integration:
• iCloud Drive-understøttelse
• Time Machine-kompatibel
• Handoff/Continuity-klar
• Korrekt sandboxing
• Sikkerheds-scopede bogmærker

macOS-begrænsninger

1. Systemlyd kræver tilladelse

I modsætning til Windows har macOS brug for eksplicit tilladelse:

Opsætningstrin:

1. Første gang du optager systemlyd:
   Systemindstillinger → Sikkerhed og privatliv → Privatliv
   
2. Klik "Skærmoptagelse" til venstre

3. Marker "SeaMeet" på listen
   (Du skal muligvis låse op med din adgangskode)

4. Genstart SeaMeet helt

5. Systemlyd vil nu virke

Hvorfor dette kræves:

  • macOS-sikkerhedsmodel
  • Skærmoptagelse fanger alt
  • Bruger skal eksplicit tillade
  • Beskytter mod spyware

2. Ingen NVIDIA/AMD-hardwareacceleration

Mac-hardwareacceleration:
• Intel Macs: Intel Quick Sync (hvis tilgængelig)
• Apple Silicon: VideoToolbox (fremragende)
• Eksterne GPU'er: Ikke understøttet til kodning
• Ingen NVENC eller AMD VCE (chips ikke til stede)

Ydeevne:

  • Apple Silicon er så effektiv, at det er ligegyldigt
  • Intel Macs med Quick Sync er fine
  • Ældre Intel Macs uden Quick Sync bruger CPU-kodning

3. Sandboxing-begrænsninger

macOS-sikkerhed:
• Apps er sandboxede
• Skal anmode om tilladelse til:
  - Mikrofon
  - Kamera (hvis brugt)
  - Skærmoptagelse
  - Filsystem-placeringer
  - Downloads-mappe
  - Skrivebord

SeaMeet vil bede om disse efter behov

macOS-arkitekturspecifikke installers

SeaMeet på macOS leverer separate installers til Intel og Apple Silicon Macs:

Hvilken version skal jeg downloade?

Tjek din Mac-type:
Apple-menu (🍎) → Om denne Mac → Chip

Hvis du ser:
• "Apple M1", "Apple M2" eller "Apple M3"
  → Download: SeaMeet-macOS-arm64-[version].dmg

• "Intel Core i5", "Intel Core i7" osv.
  → Download: SeaMeet-macOS-x64-[version].dmg

Hvorfor separate installers?

✅ Mindre downloadstørrelse (~100 MB hver vs ~180 MB universel)
✅ Optimeret til din specifikke processor
✅ Ingen kompatibilitetsproblemer med native moduler
✅ Simpel build- og opdateringsproces

Ydeevne:

Apple Silicon (arm64):
• M1-, M2-, M3-chips
• Fremragende ydeevne
• Bedre batterilevetid
• Native arm64-eksekvering

Intel (x64):
• 2013-2021 Macs
• Fuld funktionsparitet
• Quick Sync-acceleration
• Native x64-eksekvering

Installation:

1. Download den korrekte DMG til din Mac
2. Åbn DMG-filen
3. Træk SeaMeet til Applications
4. Start og giv tilladelser

macOS-mødedetektionsfunktioner

SeaMeet på macOS inkluderer avanceret mødedetektion med pr.-app lydovervågning:

Pr.-app mikrofonovervågning:

Hvordan det virker:
• Overvåger hvilken app der bruger din mikrofon
• Detekterer, når møder starter/stopper
• Bruger native-audio-node til pr.-app detektion
• Tilgængelig på macOS 14.2+ (Sonoma)

Understøttede platforme:
• Zoom
• Google Meet
• Microsoft Teams
• Apple FaceTime
• Webex
• Og andre mødeplatforme

Browser-mødedetektion:

Auto-detekterer aktive møder i:
• Google Meet (Chrome/Firefox/Safari)
• Zoom webklient
• Webex webklient
• Teams web
• Andre web-baserede mødeplatforme

Vinduesforhåndsvalg:
• Vælger automatisk mødevindue
• Forhindrer utilsigtet optagelse af andre apps
• Ingen auto-start medmindre eksplicit aktiveret
• Brugerkontrol opretholdt

Krav:

macOS 14.2 Sonoma eller senere
• Påkrævet til native-audio-node API'er
• Dækker alle moderne Mac-brugere
• Aktiverer pr.-app lydregistrering

macOS-opsætningsguide

Førstegangsopsætning:

1. Installér SeaMeet
   - Download den korrekte DMG (arm64 til Apple Silicon, x64 til Intel)
   - Åbn DMG-fil
   - Træk SeaMeet til Applications
   - Dobbeltklik for at starte

2. Giv tilladelser (kritisk!):
   Systemindstillinger → Sikkerhed og privatliv → Privatliv

   Aktivér for:
   ☑ Skærmoptagelse
   ☑ Mikrofon
   ☑ Tilgængelighed (til nogle genveje)
   ☑ Systembegivenheder (til menubjælke-interaktion)

3. Genstart SeaMeet helt
   - Tving afslut (Cmd+Q)
   - Genstart

4. Test optagelse
   - Simpel test først
   - Prøv derefter mødedetektion

5. Til systemlyd:
   - SeaMeet detekterer systemlyd automatisk
   - Eller brug BlackHole (virtuel lyddriver) til avancerede opsætninger
   - Eller brug indbygget loopback på nyere macOS
   - Følg in-app-instruktioner om nødvendigt

macOS-specifikke genveje

Globale genveje:
• Cmd + Shift + R — Start/stop optagelse
• Cmd + Shift + F — Gem Flashback
• Cmd + Shift + S — Skærmbillede

macOS-integration:
• Touch Bar: Optag-knap (hvis tilgængelig)
• Menubjælke: Hurtige kontroller
• Notifikationscenter: Optagelsesstatus

Del 5: Linux-specifik information

Linux-karakteristika

1. Variabel oplevelse

Linux-versioner varierer efter distribution:

Ubuntu (anbefalet):
• Bedst understøttet
• Lettest at opsætte
• De fleste funktioner virker
• Regelmæssig testning

Fedora:
• God understøttelse
• Nyere pakker
• Kan have brug for ekstra repos

Andre distros:
• Din kilometertal kan variere
• Community-understøttelse
• Kan have brug for manuelle rettelser

2. Kompleksitet i lydoptagelse

Linux-lyd er mere kompleks:

Lydsystemer:
• PulseAudio (mest almindelig)
• PipeWire (nyere, moderne)
• ALSA (lavt niveau)
• JACK (professionel lyd)

Opsætning nødvendig:
Kan have brug for at oprette virtuelle lydenheder
Eller bruge loopback-moduler
Ikke "plug and play" som Windows

PulseAudio-opsætning:

# Opret virtuel sink til systemlyd
pactl load-module module-null-sink sink_name=SeaMeet sink_properties=device.description=SeaMeetRecording

# Overvåg det
pactl load-module module-loopback source=SeaMeet.monitor

3. Hardwareacceleration varierer

NVIDIA på Linux:
• NVENC tilgængelig via proprietære drivere
• Skal installeres separat
• Kvalitet god, når det virker

AMD på Linux:
• VCE-understøttelse varierer efter driver
• Open-source vs proprietære drivere
• Kan have brug for konfiguration

Intel på Linux:
• VA-API til kodning
• Virker normalt godt
• En del af Mesa-drivere

Linux-opsætningsguide

Ubuntu-installation:

# Download .deb-pakke
# Eller installer via repository, hvis tilgængeligt

sudo dpkg -i seameet-linux.deb
sudo apt-get install -f  # Fix afhængigheder

# Giv tilladelser
# Tilføj bruger til videogruppe
sudo usermod -a -G video $USER

# Log ud og ind igen

Fedora-installation:

# Download .rpm-pakke
sudo rpm -i seameet-linux.rpm

# Eller via dnf, hvis i repos
sudo dnf install seameet

Opsætning efter installation:

# 1. Lydopsætning (kompleks)
# Følg SeaMeet in-app lydopsætningsguide

# 2. Hardwareacceleration
# Installer passende drivere:
# NVIDIA: nvidia-utils eller proprietær
# AMD: mesa-va-drivers
# Intel: intel-media-driver

# 3. Tilladelser
# Kan have brug for at konfigurere udev-regler
# Til enhedsadgang

Linux-specifikke genveje

Globale genveje:

Del 6: Platform-specifik fejlfinding

Windows-specifikke problemer

Problem: Kan ikke fange systemlyd

Løsninger:

1. Aktivér Stereo Mix:
   - Lydkontrolpanel → Optagelse
   - Vis deaktiverede enheder
   - Aktivér Stereo Mix

2. Brug WASAPI-metode:
   - SeaMeet-indstillinger → Lyd → Metode
   - Vælg WASAPI loopback

3. Ingen Stereo Mix på Realtek:
   - Opdater Realtek-drivere
   - Eller brug WASAPI-metoden i stedet

4. Windows 11-specifikt:
   - Tjek privatlivsindstillinger
   - Indstillinger → Privatliv → Mikrofon
   - Sørg for, at apps kan tilgå lyd

Problem: Spiloptagelse sort skærm

Løsninger:

1. Deaktivér fuldskærmsoptimering:
   - Højreklik på spilexe → Egenskaber
   - Kompatibilitet → Deaktivér fuldskærmsoptimeringer

2. Brug vindues- eller borderless-tilstand

3. Deaktivér Windows Game Bar:
   - Kan konflikte med SeaMeet

4. Kør SeaMeet som administrator

5. Brug Game Capture-tilstand, hvis tilgængelig

macOS-specifikke problemer

Problem: Ingen systemlyd

Løsninger:

1. Giv skærmoptagelsestilladelse:
   Systemindstillinger → Sikkerhed og privatliv → Privatliv → Skærmoptagelse
   Marker SeaMeet
   Genstart SeaMeet

2. Installer BlackHole (virtuel lyd):
   brew install blackhole-2ch
   Eller download fra GitHub

3. Opsæt multi-output-enhed:
   Audio MIDI Setup → Opret Multi-Output
   Tilføj højtalere + BlackHole
   Indstil som systemoutput

4. Nyere macOS (12+):
   Kan have indbygget loopback
   Tjek SeaMeet-indstillinger

Problem: SeaMeet vil ikke starte

Løsninger:

1. Tjek tilladelser:
   - Skærmoptagelse
   - Mikrofon
   - Tilgængelighed
   - Systembegivenheder

2. Højreklik → Åbn:
   - Første gang kan have brug for dette
   - Omgå Gatekeeper

3. Tjek for karantæneattribut:
   xattr -d com.apple.quarantine /Applications/SeaMeet.app

4. Bekræft macOS-version:
   • Kræver macOS 14.2 Sonoma eller senere
   • Tjek med Apple-ikon → Om denne Mac
   • Opdater om nødvendigt

5. Genstart helt:
   - Tving afslut: Cmd+Q
   - Dræb appen helt
   - Genstart

6. Geninstallér SeaMeet
   - Fjern fra Applications
   - Download frisk DMG
   - Geninstallér

Problem: Mødedetektion virker ikke

Løsninger:

1. Bekræft macOS-version:
   • Mødedetektion kræver macOS 14.2+
   • Tjek Om denne Mac
   • Opdater hvis på ældre version

2. Giv nødvendige tilladelser:
   Systemindstillinger → Sikkerhed og privatliv → Privatliv
   ✓ Skærmoptagelse
   ✓ Mikrofon
   Genstart SeaMeet

3. Tjek mødeplatform:
   • Sørg for, at mødeapp har mikrofonadgang
   • Systemindstillinger → Sikkerhed og privatliv → Mikrofon
   • Tilføj mødeapp om nødvendigt (Zoom, Teams osv.)

4. Test vinduesdetektion:
   • Start et møde i understøttet app
   • Tjek, om vinduet vises i SeaMeet
   • Prøv at vælge vinduet manuelt først

5. Browser-møder:
   • Sørg for, at mødebrowserfane er aktiv
   • Browser skal have skærmoptagelsestilladelse
   • Nogle browsere kan have brug for yderligere opsætning

Linux-specifikke problemer

Problem: Ingen lydenheder vises

Løsninger:

1. Tjek lydsystem:
   - Kører PulseAudio?
   - Eller PipeWire?
   pactl info

2. Tilladelser:
   - Tilføj bruger til lydgruppe
   sudo usermod -a -G audio $USER

3. Installer pavucontrol:
   - PulseAudio Volume Control
   - Tjek input-/outputenheder

4. SeaMeet kan have brug for specifik opsætning:
   - Følg in-app lydkonfiguration
   - Kan have brug for virtuelle enheder

Problem: Høj CPU-brug

Løsninger:

1. Aktivér hardwareacceleration:
   - Installer VA-API-drivere
   - NVIDIA: Tjek NVENC-understøttelse
   - AMD: Kan være begrænset

2. Brug lavere kvalitetsindstillinger:
   - 720p i stedet for 1080p
   - Lavere billedhastighed

3. Tjek, om der optages til langsom disk:
   - Brug SSD hvis muligt
   - Tjek diskydeevne

4. Desktop-miljø:
   - Nogle DE'er bruger flere ressourcer
   - Prøv lettere WM om nødvendigt

Del 7: Cross-platform-arbejdsgangstips

Bevægelse mellem platforme

Indstillingsoverførsel:

SeaMeet-indstillinger gemmes lokalt
Ikke cloud-synkroniseret automatisk

Manuel overførsel:
1. Eksporter indstillinger (hvis funktion tilgængelig)
2. Eller noter ned nøgleindstillinger
3. Genkonfigurer på anden platform
4. Forvent nogle forskelle

Filkompatibilitet:

Optagelsesfiler er universelle:
• MP4 virker på alle platforme
• WebM virker på alle platforme
• MOV virker på alle platforme (med codecs)

Ingen konvertering nødvendig ved skift af computere

Tastaturgenveje:

Windows/Linux: Ctrl + Alt + [tast]
Mac: Cmd + Shift + [tast]

Muskelhukommelse skal justeres
Tjek genveje i indstillinger på hver platform

Bedste platform til specifikke anvendelser

Til spil:

  • Windows (bedst hardwareunderstøttelse, flest spil)

Til kreativt arbejde:

  • macOS (integration med kreative apps)

Til programmering/udvikling:

  • Enhver (personlig præference)
  • Linux, hvis du foretrækker open source

Til forretning/enterprise:

  • Windows (mest almindelig, lettest IT-support)
  • macOS (voksende i erhvervslivet)

Til privatliv:

  • Linux (mest kontrol)

Sammendrag

SeaMeet virker på alle større platforme, men hver har styrker:

✅ Windows: Flest funktioner, lettest opsætning, bedst spil, omfattende lydkontrol

✅ macOS: Poleret, smart mødedetektion, virker på både Intel og Apple Silicon via separate optimerede DMG'er (ikke en universel binær — vælg den, der matcher din chip), fremragende ydeevne

✅ Linux: Fleksibel, privatlivsfokuseret, community-understøttet, kun-kilde-installation (ingen forudbygget installer — ren npm install fra v2.1.4 og fremefter)

Platformanbefalinger:

Vælg Windows hvis:

  • Du vil have maksimal kompatibilitet
  • Du optager spil
  • Du har brug for let systemlydoptagelse
  • Du bruger NVIDIA/AMD GPU'er
  • Du har brug for maksimal funktionskontrol

Vælg macOS hvis:

  • Du er i Apple-økosystemet
  • Du har Intel eller Apple Silicon Mac (begge understøttet)
  • Du vil have poleret native oplevelse
  • Du laver kreativt arbejde
  • Du vil have automatisk mødedetektion og smart vinduesvalg
  • Du værdsætter integreret pr.-app lydovervågning

Vælg Linux hvis:

  • Du er teknisk tilbøjelig
  • Du værdsætter open source
  • Du vil have maksimal kontrol
  • Du har intet imod konfiguration
  • Du foretrækker community-understøttede muligheder

macOS-fordele i v1.0.5+:

✨ Nye funktioner (macOS 14.2+):
• Pr.-app mikrofonovervågning (native-audio-node)
• Automatisk mødedetektion
• Smart vinduesforhåndsvalg
• Browser-mødedetektion
• Auto-start-forebyggelse
• Separate optimerede installers (Intel + Apple Silicon)
• Mindre downloadstørrelser (~100 MB pr. arkitektur)
