Diferencias entre plataformas

Capítulo 29: Diferencias entre plataformas

Introducción

SeaMeet funciona en múltiples plataformas — Windows, macOS y Linux — pero cada sistema operativo tiene sus propias peculiaridades, capacidades y limitaciones. Lo que funciona perfectamente en Windows podría comportarse de manera diferente en Mac. Algunas funciones están disponibles en una plataforma pero no en otra. Comprender estas diferencias te ayuda a sacar el máximo partido a SeaMeet sin importar qué ordenador uses.

Este capítulo explica cómo se adapta SeaMeet a cada plataforma, qué funciones son específicas por plataforma y qué limitaciones debes conocer.

Objetivos del capítulo

Después de leer este capítulo, podrás:

  • Comprender las diferencias entre las versiones de Windows, macOS y Linux
  • Saber qué funciones son específicas de plataforma
  • Configurar SeaMeet correctamente para tu sistema operativo
  • Sortear las limitaciones específicas de plataforma
  • Elegir la plataforma adecuada para tus necesidades de grabación

Parte 1: Visión general por plataforma

SeaMeet en Windows

Lo mejor para:

  • Máxima compatibilidad
  • Grabación de juegos
  • Entornos empresariales
  • La versión más completa en funciones

Características clave:

  • La mayoría de las funciones disponibles
  • Mejor soporte de aceleración por hardware (NVIDIA/AMD/Intel)
  • Captura fácil del audio del sistema
  • Compatibilidad de apps más amplia
  • La más probada y estable

Versiones de Windows soportadas:

  • Windows 10 (versión 1809 y posteriores)
  • Windows 11
  • Windows Server 2019/2022 (soporte limitado)

Arquitecturas de Windows soportadas:

  • x64 (Intel/AMD 64-bit): Soporte completo, todas las funciones disponibles
  • ARM64 (Windows on ARM): Soportado, algunas funciones de audio no disponibles
    • Surface Pro X y dispositivos similares
    • Grabación de pantalla, grabación de vídeo y grabación de micrófono completamente soportadas
    • Captura de audio del sistema y enumeración de dispositivos de audio no disponibles (degradación elegante)
    • Consulta la sección Windows ARM64 más abajo para detalles

No soportado:

  • Windows 7, 8, 8.1 (fin de soporte)
  • Windows XP/Vista (antiguos)
  • Windows de 32 bits (x86)

SeaMeet en macOS

Lo mejor para:

  • Profesionales creativos
  • Usuarios del ecosistema Apple
  • Interfaz limpia y consistente
  • Integración con flujos de trabajo de Mac

Características clave:

  • Interfaz Mac nativa pulida
  • Excelente rendimiento en Apple Silicon (M1/M2/M3)
  • Excelente rendimiento en Intel Macs
  • Integración estrecha con el sistema
  • Modelo de permisos diferente
  • Monitoreo de micrófono por app
  • Detección de reuniones del navegador y prevención de inicio automático

Versiones de macOS soportadas:

  • macOS 14.2 Sonoma (mínimo - requerido para funciones de native-audio-node)
  • macOS 15 Sequoia
  • Versiones futuras

Arquitecturas de macOS soportadas:

  • Apple Silicon (arm64): Soporte completo, todas las funciones incluyendo detección de audio por app
  • Intel (x64): Soporte completo con instalador separado

Soporte para Apple Silicon e Intel:

  • Dos instaladores DMG separados: uno para Intel, uno para Apple Silicon
  • Descarga la versión que coincide con el procesador de tu Mac
  • Macs M1/M2/M3 → Descarga la versión arm64
  • Macs Intel → Descarga la versión x64
  • Ambas versiones tienen funciones idénticas
  • Aceleración por hardware vía VideoToolbox (Apple Silicon) o Quick Sync (Intel)
  • Detección de micrófono por app (native-audio-node)
  • Preselección inteligente de ventana para aplicaciones de reuniones

SeaMeet en Linux

Lo mejor para:

  • Usuarios técnicos que ejecutan SeaMeet desde el código fuente
  • Desarrolladores que contribuyen al proyecto
  • Usuarios preocupados por la privacidad
  • Defensores del código abierto

Características clave:

  • Soportado por la comunidad, solo desde código fuente (sin instalador prebuilt oficial)
  • Conjunto de funciones variable por distribución
  • Más configuración manual requerida
  • Amigable con la línea de comandos
  • Menos funciones "simplemente funcionan"

Distribuciones soportadas:

  • Ubuntu 20.04+ (mejor soporte)
  • Fedora 34+
  • Debian 11+
  • Otras distros basadas en Debian/Ubuntu

Notas de instalación en Linux (v2.1.4+):

✅ npm install ahora tiene éxito limpiamente en Linux

Hasta v2.1.4, `npm install` fallaba en Linux con EBADPLATFORM
porque native-audio-node — un módulo nativo solo de macOS/Windows —
estaba listado en `dependencies`. A partir de v2.1.4 vive en
`optionalDependencies` junto con los otros paquetes de audio
específicos por plataforma (macos-audio-devices, native-sound-mixer,
win-audio), así que npm los salta en Linux en lugar de abortar.

Si antes encontrabas `npm ERR! EBADPLATFORM`:
1. Obtén v2.1.4 o posterior
2. Elimina node_modules y package-lock.json
3. Ejecuta npm install de nuevo — debería completarse sin errores

Limitaciones:

  • Sin instalador prebuilt oficial — ejecuta desde el código fuente vía npm start
  • El monitoreo de micrófono por app y la auto-detección de reuniones no están disponibles (requieren native-audio-node, que no tiene binario para Linux)
  • La disponibilidad de la bandeja del sistema depende del entorno de escritorio (consulta la sección Bandeja más abajo)
  • La aceleración por hardware varía según la combinación GPU/driver
  • Se requiere más configuración para captura de audio del sistema (loopback de PulseAudio / PipeWire)

Bandeja del sistema y modo Lite por plataforma

SeaMeet sigue ejecutándose en segundo plano después de que cierras la ventana principal — la bandeja del sistema (llamada barra de menú en macOS) es cómo vuelves a ella, cambias el estado de grabación y sales limpiamente. La API Tray de Electron es específica por plataforma, así que el comportamiento varía:

CapacidadWindowsmacOSLinux
Icono de bandeja✅ tray.ico en área de notificaciones✅ Plantilla icon.png en barra de menú (adapta a oscuro/claro)⚠️ Depende del entorno de escritorio

"Iniciar oculto en bandeja"✅ Soportado✅ Soportado⚠️ Mejor esfuerzo
Modo Lite (IU floater compacta)✅ Completo✅ Completo✅ Completo

Notas de bandeja en Linux:

La bandeja de Electron funciona de manera fiable en GNOME (con la extensión AppIndicator), KDE Plasma, XFCE, Cinnamon y la mayoría de los escritorios predeterminados de Ubuntu/Fedora. En sesiones solo de Wayland y algunos gestores de ventanas mínimos, el icono de la bandeja podría no aparecer en absoluto — la app aún se ejecuta, pero necesitarás relanzarla desde el terminal o usar un atajo global para traer la ventana de vuelta. No hay activo de icono de bandeja específico para Linux; se carga el mismo .ico que para Windows.

Modo Lite:

El modo Lite (introducido en v2.x) es una disposición compacta del lado del renderer — una barra floater de 560×80 con los controles de grabación, forma de onda y acciones rápidas en lugar de la ventana completa de la app. Está controlado por el ajuste ui.appMode ('full' o 'lite') y cambia en tiempo de ejecución vía Configuración. El modo Lite funciona de manera idéntica en las tres plataformas porque no tiene una ruta de código específica por plataforma.

Parte 3: Funciones y configuración específicas de Windows

Ventajas de Windows

1. El audio del sistema es fácil

En Windows, capturar el audio del sistema es directo:

Método: Mezcla estéreo (más fiable)

Configuración:
1. Clic derecho en icono de altavoz → Abrir Configuración de sonido
2. Panel de control de sonido → Grabación
3. Clic derecho en área vacía → Mostrar dispositivos deshabilitados
4. Clic derecho en "Mezcla estéreo" → Habilitar
5. Establecer como predeterminado

SeaMeet ahora puede capturar audio del sistema directamente

Métodos alternativos:

  • Loopback WASAPI (método moderno)
  • Captura DirectSound
  • Cables de audio virtuales

2. Aceleración por hardware en abundancia

Windows tiene el mejor soporte de codificadores GPU:

GPUs NVIDIA:

Serie GTX 600 y posteriores:
• Chip dedicado del codificador NVENC
• Excelente calidad
• Muy eficiente
• SeaMeet soporta automáticamente

GPUs AMD:

Radeon HD serie 7000 y posteriores:
• VCE (Video Coding Engine)
• Buena calidad
• Codificación eficiente
• Soporte automático

Intel integrado:

4ª generación Core y posteriores:
• Quick Sync Video
• Calidad sorprendentemente buena
• Muy eficiente energéticamente
• Genial para portátiles

3. Funciones de juegos

Integración de juegos específica de Windows:

Soporte de Game Mode:
• API Game Mode de Windows
• Auto-detecta cuando estás en juegos
• Optimiza recursos
• Disponible solo en Windows

Integración con Game Bar:
• Puede funcionar junto con Xbox Game Bar
• Sin conflictos
• Atajos separados

Guía de configuración de Windows

Configuración óptima:

1. Habilita Mezcla estéreo para audio del sistema
2. Actualiza los controladores de GPU:
   - NVIDIA: GeForce Experience
   - AMD: Radeon Software
   - Intel: Intel Driver Assistant

3. Habilita aceleración por hardware en SeaMeet:
   Configuración → Vídeo → Usar aceleración por hardware

4. Establece el plan de energía a "Alto rendimiento" para grabar

5. Deshabilita Windows Game Mode si causa problemas:
   Configuración → Juegos → Game Mode → Off

Atajos específicos de Windows

Atajos globales (funcionan en todas partes):
• Ctrl + Alt + R — Iniciar/detener grabación
• Ctrl + Alt + F — Guardar Flashback
• Ctrl + Alt + S — Captura de pantalla

Gestión de ventanas:
• Win + G — Game bar (si está habilitada)
• Win + Alt + R — Grabación de Xbox Game Bar
   (funciona junto con SeaMeet)

Información específica de Windows ARM64

¿Qué es Windows ARM64?

ARM64 es una arquitectura de procesador diferente:
• Usada en dispositivos Windows on ARM (Surface Pro X, etc.)
• Soporte nativo para procesadores basados en ARM
• Puede emular apps x64 (más lento)
• Soporte creciente para apps ARM64 nativas

SeaMeet en ARM64

SeaMeet tiene soporte nativo de ARM64 a partir de v1.0.2+:

✅ Totalmente soportado en ARM64:
• Grabación de pantalla (alto rendimiento)
• Grabación de vídeo (alto rendimiento)
• Grabación de micrófono (API directa de Windows)
• Detección y gestión de ventanas
• Widget Floater y atajos de teclado
• Configuración y biblioteca de grabaciones
• Todas las funciones de IU

❌ No disponible en ARM64:
• Captura de audio del sistema (audio de apps/altavoces)
• Enumeración de dispositivos de audio (detección de mic/altavoz)
• Control del mezclador de audio
• Estos requieren módulos nativos no compilados para ARM64

Cuándo deberías usar ARM64

Mejor para:

  • Usuarios de Surface Pro X que quieren rendimiento nativo
  • Grabación de vídeo/pantalla sin audio del sistema
  • Grabación de micrófono (la grabación directa funciona)
  • Rendimiento completo sin ralentización por emulación

No ideal para:

  • Captura de audio del sistema (no estará disponible)
  • Flujos de trabajo de audio complejos
  • Selección de dispositivo de audio (no disponible)

Cómo saber qué versión tienes

Configuración de Windows:
1. Configuración → Sistema → Acerca de
2. Busca "Tipo de sistema"
3. Muestra cualquiera de:
   • "Procesador basado en x64" (Intel/AMD 64-bit)
   • "Procesador basado en ARM" (Windows on ARM)

Línea de comandos:

PowerShell: wmic os get osarchitecture
Salida: 64-bit o ARM 64-bit

Instalación

SeaMeet detecta automáticamente tu arquitectura:

• Descarga el instalador genérico
• Instalará automáticamente la versión correcta
• Los usuarios x64 obtienen: SeaMeet-...-x64-Setup.exe
• Los usuarios ARM64 obtienen: SeaMeet-...-arm64-Setup.exe

O descarga manualmente el adecuado desde las versiones:
• Comprueba tu Tipo de sistema (arriba)
• Descarga la arquitectura coincidente

Auto-actualizador en ARM64

Actualizaciones sin interrupciones:
• La app comprueba actualizaciones automáticamente
• ARM64 se actualiza a ARM64 (no x64)
• Compatible hacia atrás con versiones anteriores
• Sin intervención manual necesaria

Resolución de problemas de ARM64

Problema: Opción "Audio del sistema" atenuada

Comportamiento esperado en ARM64:
✓ Esto es normal
✓ Módulo nativo no disponible
✓ Aún puedes grabar micrófono
✓ Sin error - degradación elegante

Problema: No puedo seleccionar micrófono/altavoz

Soluciones:
1. Usa los dispositivos predeterminados del sistema
2. Ve a la configuración de Sonido de Windows para elegir dispositivo
3. SeaMeet usará lo que sea que Windows tenga seleccionado
4. La selección manual de dispositivo no está disponible en ARM64

Problema: La grabación del micrófono no funciona

Soluciones:
1. Comprueba la configuración de Sonido de Windows
2. El micrófono debe ser el dispositivo de entrada predeterminado
3. Concede permisos de micrófono a SeaMeet
4. Windows debe mostrar el nivel de grabación
5. Prueba primero en la app de grabación de Windows

Parte 4: Funciones y configuración específicas de macOS

Ventajas de macOS

1. Interfaz pulida

SeaMeet en Mac se siente nativo:

• Sigue las directrices de diseño de macOS
• Usa controles nativos
• Respeta el tema del sistema
• Soporte de Touch Bar (en Macs compatibles)
• Integración adecuada con la barra de menú

2. Excelente soporte de Apple Silicon

Los chips M1/M2/M3 funcionan genial:

Características de Apple Silicon:
• Aceleración por hardware vía VideoToolbox
• Excelente rendimiento por vatio
• Codificación rápida
• Funcionamiento fresco
• Larga duración de batería mientras grabas

3. Integración con el sistema

Integración con macOS:
• Soporte de iCloud Drive
• Compatible con Time Machine
• Listo para Handoff/Continuity
• Sandboxing adecuado
• Marcadores con ámbito de seguridad

Limitaciones de macOS

1. El audio del sistema requiere permiso

A diferencia de Windows, macOS necesita permiso explícito:

Pasos de configuración:

1. Primera vez grabando audio del sistema:
   Preferencias del Sistema → Seguridad y privacidad → Privacidad
   
2. Haz clic en "Grabación de pantalla" a la izquierda

3. Marca "SeaMeet" en la lista
   (Es posible que necesites desbloquear con tu contraseña)

4. Reinicia SeaMeet completamente

5. El audio del sistema ahora funcionará

Por qué se requiere:

  • Modelo de seguridad de macOS
  • La grabación de pantalla captura todo
  • El usuario debe permitir explícitamente
  • Protege contra spyware

2. Sin aceleración por hardware NVIDIA/AMD

Aceleración por hardware en Mac:
• Macs Intel: Intel Quick Sync (si está disponible)
• Apple Silicon: VideoToolbox (excelente)
• GPUs externas: No soportadas para codificación
• Sin NVENC ni AMD VCE (chips no presentes)

Rendimiento:

  • Apple Silicon es tan eficiente que no importa
  • Los Macs Intel con Quick Sync están bien
  • Los Macs Intel más antiguos sin Quick Sync usan codificación por CPU

3. Restricciones de sandboxing

Seguridad de macOS:
• Las apps están en sandbox
• Deben solicitar permiso para:
  - Micrófono
  - Cámara (si se usa)
  - Grabación de pantalla
  - Ubicaciones del sistema de archivos
  - Carpeta Descargas
  - Escritorio

SeaMeet pedirá estos según sea necesario

Instaladores específicos de arquitectura de macOS

SeaMeet en macOS proporciona instaladores separados para Macs Intel y Apple Silicon:

¿Qué versión debería descargar?

Comprueba el tipo de tu Mac:
Menú Apple (🍎) → Acerca de este Mac → Chip

Si ves:
• "Apple M1", "Apple M2" o "Apple M3"
  → Descarga: SeaMeet-macOS-arm64-[versión].dmg

• "Intel Core i5", "Intel Core i7", etc.
  → Descarga: SeaMeet-macOS-x64-[versión].dmg

¿Por qué instaladores separados?

✅ Tamaño de descarga más pequeño (~100 MB cada uno vs ~180 MB universal)
✅ Optimizado para tu procesador específico
✅ Sin problemas de compatibilidad con módulos nativos
✅ Proceso de compilación y actualización más sencillo

Rendimiento:

Apple Silicon (arm64):
• Chips M1, M2, M3
• Excelente rendimiento
• Mejor duración de batería
• Ejecución nativa arm64

Intel (x64):
• Macs 2013-2021
• Paridad completa de funciones
• Aceleración Quick Sync
• Ejecución nativa x64

Instalación:

1. Descarga el DMG correcto para tu Mac
2. Abre el archivo DMG
3. Arrastra SeaMeet a Aplicaciones
4. Inicia y concede permisos

Funciones de detección de reuniones en macOS

SeaMeet en macOS incluye detección avanzada de reuniones con monitoreo de audio por app:

Monitoreo de micrófono por app:

Cómo funciona:
• Monitorea qué app está usando tu micrófono
• Detecta cuándo comienzan/terminan las reuniones
• Usa native-audio-node para detección por app
• Disponible en macOS 14.2+ (Sonoma)

Plataformas soportadas:
• Zoom
• Google Meet
• Microsoft Teams
• Apple FaceTime
• Webex
• Y otras plataformas de reuniones

Detección de reuniones del navegador:

Detecta automáticamente reuniones activas en:
• Google Meet (Chrome/Firefox/Safari)
• Zoom web client
• Webex web client
• Teams web
• Otras plataformas de reuniones basadas en web

Preselección de ventana:
• Selecciona automáticamente la ventana de la reunión
• Previene grabación accidental de otras apps
• Sin inicio automático a menos que se habilite explícitamente
• Control del usuario mantenido

Requisitos:

macOS 14.2 Sonoma o posterior
• Requerido para las APIs de native-audio-node
• Cubre a todos los usuarios modernos de Mac
• Habilita la detección de audio por app

Guía de configuración de macOS

Configuración por primera vez:

1. Instala SeaMeet
   - Descarga el DMG correcto (arm64 para Apple Silicon, x64 para Intel)
   - Abre el archivo DMG
   - Arrastra SeaMeet a Aplicaciones
   - Doble clic para iniciar

2. Concede permisos (¡Crítico!):
   Preferencias del Sistema → Seguridad y privacidad → Privacidad

   Habilita para:
   ☑ Grabación de pantalla
   ☑ Micrófono
   ☑ Accesibilidad (para algunos atajos)
   ☑ Eventos del sistema (para interacción con barra de menú)

3. Reinicia SeaMeet completamente
   - Forzar salida (Cmd+Q)
   - Relanzar

4. Prueba grabación
   - Prueba simple primero
   - Luego prueba detección de reuniones

5. Para audio del sistema:
   - SeaMeet detecta el audio del sistema automáticamente
   - O usa BlackHole (controlador de audio virtual) para configuraciones avanzadas
   - O usa loopback integrado en macOS más reciente
   - Sigue las instrucciones de la app si es necesario

Atajos específicos de macOS

Atajos globales:
• Cmd + Shift + R — Iniciar/detener grabación
• Cmd + Shift + F — Guardar Flashback
• Cmd + Shift + S — Captura de pantalla

Integración con macOS:
• Touch Bar: Botón de grabar (si está disponible)
• Barra de menú: Controles rápidos
• Centro de Notificaciones: Estado de grabación

Parte 5: Información específica de Linux

Características de Linux

1. Experiencia variable

Las versiones de Linux varían según la distribución:

Ubuntu (Recomendado):
• Mejor soportado
• Configuración más fácil
• La mayoría de las funciones funcionan
• Pruebas regulares

Fedora:
• Buen soporte
• Paquetes más nuevos
• Puede necesitar repos extra

Otras distros:
• Tu experiencia puede variar
• Soporte de la comunidad
• Puede necesitar arreglos manuales

2. Complejidad de captura de audio

El audio en Linux es más complejo:

Sistemas de audio:
• PulseAudio (más común)
• PipeWire (más nuevo, moderno)
• ALSA (bajo nivel)
• JACK (audio profesional)

Configuración requerida:
Puede necesitar crear dispositivos de audio virtuales
O usar módulos de loopback
No es "plug and play" como Windows

Configuración de PulseAudio:

# Crear sumidero virtual para audio del sistema
pactl load-module module-null-sink sink_name=SeaMeet sink_properties=device.description=SeaMeetRecording

# Monitorearlo
pactl load-module module-loopback source=SeaMeet.monitor

3. La aceleración por hardware varía

NVIDIA en Linux:
• NVENC disponible vía controladores propietarios
• Debe instalarse por separado
• Buena calidad cuando funciona

AMD en Linux:
• Soporte de VCE varía según el controlador
• Controladores de código abierto vs propietarios
• Puede necesitar configuración

Intel en Linux:
• VA-API para codificación
• Normalmente funciona bien
• Parte de los controladores Mesa

Guía de configuración de Linux

Instalación en Ubuntu:

# Descargar paquete .deb
# O instalar vía repositorio si está disponible

sudo dpkg -i seameet-linux.deb
sudo apt-get install -f  # Arreglar dependencias

# Conceder permisos
# Añadir usuario al grupo de vídeo
sudo usermod -a -G video $USER

# Cerrar sesión y volver a entrar

Instalación en Fedora:

# Descargar paquete .rpm
sudo rpm -i seameet-linux.rpm

# O vía dnf si está en repos
sudo dnf install seameet

Configuración posterior a la instalación:

# 1. Configuración de audio (compleja)
# Sigue la guía de configuración de audio dentro de la app de SeaMeet

# 2. Aceleración por hardware
# Instala los controladores apropiados:
# NVIDIA: nvidia-utils o propietario
# AMD: mesa-va-drivers
# Intel: intel-media-driver

# 3. Permisos
# Puede necesitar configurar reglas udev
# Para acceso a dispositivos

Atajos específicos de Linux

Atajos globales:
• Ctrl + Alt + R — Iniciar/detener grabación
• Ctrl + Alt + F — Guardar Flashback
• Ctrl + Alt + S — Captura de pantalla

Nota: Pueden entrar en conflicto con atajos del escritorio
Configura en los ajustes de SeaMeet si es necesario

Parte 6: Resolución de problemas específicos por plataforma

Problemas específicos de Windows

Problema: No puedo capturar audio del sistema

Soluciones:

1. Habilita Mezcla estéreo:
   - Panel de control de sonido → Grabación
   - Mostrar dispositivos deshabilitados
   - Habilita Mezcla estéreo

2. Usa el método WASAPI:
   - Configuración de SeaMeet → Audio → Método
   - Selecciona WASAPI loopback

3. Sin Mezcla estéreo en Realtek:
   - Actualiza los controladores de Realtek
   - O usa el método WASAPI en su lugar

4. Específico de Windows 11:
   - Comprueba los ajustes de privacidad
   - Configuración → Privacidad → Micrófono
   - Asegúrate de que las apps pueden acceder al audio

Problema: Pantalla negra al grabar juego

Soluciones:

1. Deshabilita optimización a pantalla completa:
   - Clic derecho en exe del juego → Propiedades
   - Compatibilidad → Deshabilitar optimizaciones a pantalla completa

2. Usa modo ventana o sin bordes

3. Deshabilita Windows Game Bar:
   - Puede entrar en conflicto con SeaMeet

4. Ejecuta SeaMeet como administrador

5. Usa modo Game Capture si está disponible

Problemas específicos de macOS

Problema: Sin audio del sistema

Soluciones:

1. Concede permiso de Grabación de pantalla:
   Preferencias del Sistema → Seguridad y privacidad → Privacidad → Grabación de pantalla
   Marca SeaMeet
   Reinicia SeaMeet

2. Instala BlackHole (audio virtual):
   brew install blackhole-2ch
   O descarga desde GitHub

3. Configura un dispositivo de salida múltiple:
   Configuración Audio MIDI → Crear salida múltiple
   Añade altavoces + BlackHole
   Establece como salida del sistema

4. macOS más nuevo (12+):
   Puede tener loopback integrado
   Comprueba la configuración de SeaMeet

Problema: SeaMeet no inicia

Soluciones:

1. Comprueba permisos:
   - Grabación de pantalla
   - Micrófono
   - Accesibilidad
   - Eventos del sistema

2. Clic derecho → Abrir:
   - La primera vez puede necesitar esto
   - Evita Gatekeeper

3. Comprueba atributo de cuarentena:
   xattr -d com.apple.quarantine /Applications/SeaMeet.app

4. Verifica la versión de macOS:
   • Requiere macOS 14.2 Sonoma o posterior
   • Comprueba con icono Apple → Acerca de este Mac
   • Actualiza si es necesario

5. Reinicia completamente:
   - Forzar salida: Cmd+Q
   - Mata la app completamente
   - Relanza

6. Reinstala SeaMeet
   - Quita de Aplicaciones
   - Descarga DMG nuevo
   - Reinstala

Problema: La detección de reuniones no funciona

Soluciones:

1. Verifica la versión de macOS:
   • La detección de reuniones requiere macOS 14.2+
   • Comprueba Acerca de este Mac
   • Actualiza si está en versión anterior

2. Concede los permisos necesarios:
   Preferencias del Sistema → Seguridad y privacidad → Privacidad
   ✓ Grabación de pantalla
   ✓ Micrófono
   Reinicia SeaMeet

3. Comprueba la plataforma de reuniones:
   • Asegúrate de que la app de reuniones tiene acceso al micrófono
   • Preferencias del Sistema → Seguridad y privacidad → Micrófono
   • Añade la app de reuniones si es necesario (Zoom, Teams, etc.)

4. Prueba la detección de ventanas:
   • Inicia una reunión en una app soportada
   • Comprueba si la ventana aparece en SeaMeet
   • Intenta seleccionar la ventana manualmente primero

5. Reuniones en navegador:
   • Asegúrate de que la pestaña de la reunión está activa
   • El navegador debe tener permiso de grabación de pantalla
   • Algunos navegadores pueden necesitar configuración adicional

Problemas específicos de Linux

Problema: No aparecen dispositivos de audio

Soluciones:

1. Comprueba el sistema de audio:
   - ¿Está PulseAudio ejecutándose?
   - ¿O PipeWire?
   pactl info

2. Permisos:
   - Añade el usuario al grupo de audio
   sudo usermod -a -G audio $USER

3. Instala pavucontrol:
   - PulseAudio Volume Control
   - Comprueba dispositivos de entrada/salida

4. SeaMeet puede necesitar configuración específica:
   - Sigue la configuración de audio dentro de la app
   - Puede necesitar dispositivos virtuales

Problema: Alto uso de CPU

Soluciones:

1. Habilita aceleración por hardware:
   - Instala controladores VA-API
   - NVIDIA: Comprueba soporte de NVENC
   - AMD: Puede ser limitado

2. Usa ajustes de menor calidad:
   - 720p en lugar de 1080p
   - Velocidad de fotogramas más baja

3. Comprueba si grabas en un disco lento:
   - Usa SSD si es posible
   - Comprueba el rendimiento del disco

4. Entorno de escritorio:
   - Algunos DEs usan más recursos
   - Prueba un WM más ligero si es necesario

Parte 7: Consejos de flujo de trabajo entre plataformas

Moverse entre plataformas

Transferencia de configuración:

La configuración de SeaMeet se almacena localmente
No se sincroniza automáticamente con la nube

Transferencia manual:
1. Exporta configuración (si la función está disponible)
2. O anota la configuración clave
3. Reconfigura en la otra plataforma
4. Espera algunas diferencias

Compatibilidad de archivos:

Los archivos de grabación son universales:
• MP4 funciona en todas las plataformas
• WebM funciona en todas las plataformas
• MOV funciona en todas las plataformas (con códecs)

No se necesita conversión al cambiar de ordenador

Atajos de teclado:

Windows/Linux: Ctrl + Alt + [tecla]
Mac: Cmd + Shift + [tecla]

La memoria muscular necesitará ajuste
Comprueba los atajos en la configuración de cada plataforma

Mejor plataforma para usos específicos

Para juegos:

  • Windows (mejor soporte de hardware, más juegos)

Para trabajo creativo:

  • macOS (integración con apps creativas)

Para programación/desarrollo:

  • Cualquiera (preferencia personal)
  • Linux si prefieres código abierto

Para empresa/negocio:

  • Windows (más común, soporte IT más fácil)
  • macOS (creciendo en negocios)

Para privacidad:

  • Linux (más control)

Resumen

SeaMeet funciona en todas las plataformas principales pero cada una tiene sus puntos fuertes:

✅ Windows: La mayoría de funciones, configuración más fácil, mejor juegos, control completo de audio

✅ macOS: Pulida, detección inteligente de reuniones, funciona tanto en Intel como en Apple Silicon vía DMGs optimizados separados (no es un binario universal — elige el que coincide con tu chip), excelente rendimiento

✅ Linux: Flexible, enfocado en privacidad, soportado por la comunidad, instalación solo desde código fuente (sin instalador prebuilt — npm install limpio desde v2.1.4 en adelante)

Recomendaciones de plataforma:

Elige Windows si:

  • Quieres máxima compatibilidad
  • Grabas juegos
  • Necesitas captura fácil de audio del sistema
  • Usas GPUs NVIDIA/AMD
  • Necesitas control completo de funciones

Elige macOS si:

  • Estás en el ecosistema Apple
  • Tienes Mac Intel o Apple Silicon (ambos soportados)
  • Quieres experiencia nativa pulida
  • Haces trabajo creativo
  • Quieres detección automática de reuniones y selección inteligente de ventana
  • Valoras el monitoreo de audio integrado por app

Elige Linux si:

  • Eres técnicamente inclinado
  • Valoras el código abierto
  • Quieres control máximo
  • No te importa la configuración
  • Prefieres opciones soportadas por la comunidad

Ventajas de macOS en v1.0.5+:

✨ Nuevas funciones (macOS 14.2+):
• Monitoreo de micrófono por app (native-audio-node)
• Detección automática de reuniones
• Preselección inteligente de ventana
• Detección de reuniones en navegador
• Prevención de inicio automático
• Instaladores optimizados separados (Intel + Apple Silicon)
• Tamaños de descarga más pequeños (~100 MB por arquitectura)
