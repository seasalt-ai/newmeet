Ang Pangunahing Interface - Kumpletong Tour ng UI ng SeaMeet

Kabanata 13: Ang Pangunahing Interface - Kumpletong Tour ng UI ng SeaMeet

Sa puntong ito, nagamit mo na ang SeaMeet upang mag-rekord ng audio at video, nag-ayos ng iyong library, at nag-playback ng mga pagre-rekord. Nakipag-ugnayan ka sa iba't ibang bahagi ng interface, ngunit maaaring wala kang kumpletong larawan kung paano nagtutugma ang lahat ng mga piraso. Ang kabanatang ito ay nagbibigay ng komprehensibong tour ng pangunahing interface ng SeaMeet—bawat button, panel, indicator, at kontrol—upang ma-navigate mo ang app nang may kumpiyansa at mahanap ang mga tampok na maaaring hindi mo natuklasan.

Isipin ang kabanatang ito bilang isang ginabayang tour ng isang bagong bahay. Maglalakad tayo sa bawat silid, susuriin ang mga tampok, at ipapaliwanag kung ano ang ginagawa ng lahat. Sa pagtatapos, malalaman mo nang eksakto kung saan mahahanap ang bawat function at maunawaan kung paano umaakma ang interface sa iba't ibang sitwasyon.

Ang Window Layout: Malaking Larawan

Kapag binuksan mo ang SeaMeet, makikita mo ang isang window na may pare-parehong layout. Nananatiling matatag ang layout na ito kung nag-rerekord ka, nag-pa-playback, o nagba-browse lang ng iyong library. Ang pag-unawa sa layout na ito ang pundasyon para sa epektibong paggamit ng SeaMeet.

Navigation Toggle (☰)

Ano ang ginagawa nito: Nag-collapse o nagpapalawak ng kaliwang sidebar (listahan ng pagre-rekord).

Kailan gamitin:

  • I-collapse upang bigyan ang Capture Hub ng mas maraming horizontal na espasyo
  • Palawakin upang mag-browse ng iyong recording library habang hindi nagre-rekord

Account / User Menu (👤)

Ano ang ginagawa nito: Binubuksan ang user account menu kung saan maaari kang:

  • Mag-sign in o mag-sign out
  • Buksan ang Mga Setting (audio, video, Flashback, storage, wika, mga shortcut)
  • Buksan ang keyboard shortcut reference
  • Mag-access ng Help & Support

Paano gamitin:

  1. I-click ang iyong profile picture o user icon
  2. Piliin ang nais na opsyon mula sa dropdown

Record Button (🔴)

Icon: Pulang bilog (🔴) kapag handa, Parisukat (⏹️) kapag nagre-rekord Label: "RECORD" o ang icon lamang Kulay: Maliwanag na pula (nagpapahiwatig ng aksyon ng pagre-rekord)

Ano ang ginagawa nito: Sinisimulan o tinatapos ang pagre-rekord

Mga Estado:

Handa Magrekord:

[🔴 RECORD]
Pulang bilog na icon
I-click upang simulan ang pagre-rekord

Aktibong Pagre-rekord:

[⏹️ STOP]
Parisukat na icon
Timer na nagpapakita ng oras na lumipas
I-click upang itigil ang pagre-rekord

Paano gamitin:

Para simulan ang pagre-rekord:

  1. I-configure muna ang iyong mga setting ng pagre-rekord
  2. I-click ang pulang Record button
  3. Agad na magsisimula ang pagre-rekord
  4. Magbabago ang button sa Stop
  5. Magsisimulang magbilang ang timer

Para itigil ang pagre-rekord:

  1. I-click ang Stop button (parisukat)
  2. Tatapusin ang pagre-rekord
  3. Nai-save ang file
  4. Lumalabas ang pagre-rekord sa sidebar
  5. Bumalik ang button sa Record state

Ano ang mangyayari kapag nag-click ka ng Record:

  1. Nagsisimula ang audio/video capture
  2. Lumalabas ang timer na nagpapakita ng oras na lumipas
  3. Nagbabago ang button mula 🔴 sa ⏹️
  4. Ang visual indicator ay nagpapakita ng status ng pagre-rekord
  5. Isinusulat ang file sa storage

Ano ang mangyayari kapag nag-click ka ng Stop:

  1. Tumitigil ang pagre-rekord
  2. Tinatapos at nai-save ang file
  3. Lumalabas ang pagre-rekord sa sidebar list
  4. Bumalik ang button sa 🔴 state
  5. Nawawala o nire-reset ang timer

Mahalagang mga tala:

  • Agad na nagsisimula ang pagre-rekord—maging handa!
  • Walang countdown o babala
  • Tiyaking tama ang iyong mga setting bago mag-click
  • Ang Flashback (kung pinagana) ay isasama ang naka-buffer na nakaraan

System Tray

Ini-install ng SeaMeet ang isang system tray icon (Windows notification area, macOS menu bar) sa unang pag-launch nito at pinapanatiling buhay ito para sa buong session ng app. Ang tray ay ang palaging available na control surface — kahit na isinara mo na ang pangunahing window, tumatakbo pa rin ang SeaMeet, handa na kumuha, at maabot sa isang pag-click sa icon nito.

Bakit Nananatiling Buhay ang Tray

Ang pagsasara ng pangunahing window ay hindi umaalis sa SeaMeet. Sa halip, nagtatago ang window at nananatili ang tray icon. Sinasadya ito:

  • Maaari pa ring magising ng Auto-Detect ang app kapag binuksan ang isang meeting app
  • Mapapanatili ng Flashback ang rolling buffer nito (kung naka-armed)
  • Gumagana pa rin ang mga global hotkey (Start Recording, Show Launcher, Show Floater)
  • Isang tray-click ang layo ng mabilisang pagre-rekord

Sa unang pagkakataon na isinara mo ang window, nagpapadala ang SeaMeet ng isang one-shot na "naka-minimize sa tray" na pahiwatig upang maunawaan mong hindi talaga lumabas ang app. Para tuluyang umalis, gamitin ang Exit SeaMeet mula sa tray menu (tingnan sa ibaba) o ang utos ng pag-quit ng app ng iyong OS.

Ang Tray Icon

Default na icon (idle):

  • Windows: isang maliit na SeaMeet logo .ico sa notification area
  • macOS: isang 22×22 template image sa menu bar na umaakma sa light/dark mode

Recording icon (kasalukuyang nagaganap):

  • Lumilipat sa isang red-tinted variant upang makita mo sa isang sulyap na kumukuha ang SeaMeet
  • Sa macOS ay nakakakuha din ang menu bar ng ● suffix; kung naka-pause ay ipinapakita ito ng ⏸
  • Nagbabago ang tooltip mula sa "SeaMeet" papunta sa "SeaMeet — Recording in progress" (o "Paused")

Click behavior:

  • Left-click ang icon — tina-toggle ang pangunahing window (ipakita kung nakatago, itago kung nakikita)
  • Right-click ang icon (Windows) / single-click (macOS) — binubuksan ang context menu

Kapag hindi ka nagre-rekord, ganito ang hitsura ng menu:

Ano ang ginagawa ng bawat item:

  • Workspace: <pangalan> — Header na nagpapakita kung saang cloud workspace mapupunta ang isang tray-initiated na pagre-rekord. Lumalabas lamang sa mga Lite o cloud-enabled na build kung saan ka naka-sign in at pumili ng workspace. Sa mga non-cloud na build, ang row ay ganap na nakatago kaya ang hugis ng menu ay hindi nagbabago.
  • Mag-rekord ng audio — Sinisimulan kaagad ang audio-only na pagre-rekord. Walang hinihiling na video source.
  • Mag-rekord ng fullscreen — Sinisimulan ang pagre-rekord ng iyong pangunahing display plus audio.
  • Mag-rekord ng rehiyon — Binubuksan ang fullscreen region overlay upang maka-drag-select ka ng lugar, pagkatapos ay magsimula sa pagre-rekord ng lugar na iyon.
  • Kumuha ng screenshot — Binubuksan ang region selector para sa one-shot na screenshot. Ipinapakita ang shortcut kung nag-bind ka ng isa sa Mga Setting → Keyboard.
  • Buksan ang recordings folder — Binubuksan ang OS file browser sa iyong kasalukuyang save directory.
  • Ipakita ang launcher — Tina-toggle ang SeaMeet Launcher panel (tingnan ang Kabanata 14). Ang shortcut ay ipinapakita kapag naka-bind.
  • Ipakita ang floating window — Ipinapakita/itinatago ang Floater widget. Ang shortcut ay ipinapakita kapag naka-bind.
  • Ipakita ang pangunahing window — Iniuuna ang pangunahing window (pareho sa left-click sa icon kapag nakatago).
  • Exit SeaMeet — Ang tanging menu item na aktwal na lumalabas. Itinatakda nito ang internal na "is quitting" flag at humihiling sa Electron na magtapos; lahat ng iba pa ay nagpapakita/nagtatago lamang ng mga surface.

Tray Menu (Habang Nagre-rekord)

Kapag may pagre-rekord na isinasagawa, ang menu ay nag-aakma upang bigyan ka ng direktang mga kontrol sa transportasyon:

┌─────────────────────────────────────────┐
│ ● Recording in progress    (disabled)   │
├─────────────────────────────────────────┤
│ ⏹  Itigil ang pagre-rekord (Ctrl+Shift+R)│
│ ⏸  I-pause ang pagre-rekord             │
│ ⚑  Markahan ang kaganapan               │
├─────────────────────────────────────────┤
│ 🗔 Ipakita ang pangunahing window      │
├─────────────────────────────────────────┤
│ ⏻  Exit SeaMeet                         │
└─────────────────────────────────────────┘

Mga tala sa recording menu:

  • Ang header line ay isang status label lamang (sinasadyang naka-disable).
  • Itigil ang pagre-rekord ay nagtatapos sa pagkuha at nag-iimbak ng file tulad ng pag-click sa Stop button sa pangunahing window.
  • Pause/Resume ay ipinapakita lamang kapag sinusuportahan ito ng codec/source. Ang mga video-only na pagre-rekord ay nagtatago sa Pause item.
  • Markahan ang kaganapan ay nagla-drop ng timestamp marker sa pagre-rekord, na kapaki-pakinabang para sa pagtalon pabalik sa isang pangunahing sandali sa panahon ng playback.
  • Kapag naka-pause, pinapalitan ng menu ang Ipagpatuloy ang pagre-rekord sa lugar ng Pause at ang macOS title ay lumipat sa ⏸.

Mga Lokal na Label

Iginagalang ng tray menu ang 15 na sinusuportahang locale (English, Spanish, French, German, Japanese, Korean, Hindi, Polish, Portuguese, Russian, Thai, Vietnamese, Danish, Simplified Chinese, Traditional Chinese). Ang mga wika sa labas ng set na iyon ay babalik sa English upang palaging mai-render nang tama ang menu.

Search Box

Lokasyon: Itaas ng sidebar Hitsura: Text field na may magnifying glass icon (🔍) Placeholder text: "Maghanap ng mga pagre-rekord..." o katulad

Ano ang ginagawa nito: Nag-fi-filter ng listahan ng pagre-rekord sa real-time habang nagta-type ka

Paano gamitin:

  1. I-click sa search box
  2. Simulan ang pag-type
  3. Awtomatikong nag-fi-filter ang listahan
  4. Ipinapakita lamang ang mga pagre-rekord na tumutugma sa iyong paghahanap
  5. I-clear ang paghahanap upang makita muli ang lahat ng pagre-rekord

Ano ang maaari mong hanapin:

  • Mga pangalan ng pagre-rekord
  • Mga source label ("Zoom", "Teams")
  • Mga petsa (kung nai-type sa nahahanap na format)
  • Gumagana ang mga bahagyang tugma

Mga halimbawa ng paghahanap:

  • Hanapin ang "Zoom" → Ipinapakita ang lahat ng Zoom recording
  • Hanapin ang "budget" → Ipinapakita ang mga pagre-rekord na may "budget" sa pangalan
  • Hanapin ang "March" → Ipinapakita ang mga pagre-rekord ng Marso
  • Hanapin ang "client" → Ipinapakita ang mga pagre-rekord na may kaugnayan sa kliyente

Pag-clear ng paghahanap:

  • I-click ang X button (kung mayroon)
  • Burahin ang lahat ng text
  • Pindutin ang Escape key

Zone 3: Ang Pangunahing Lugar ng Nilalaman

Ang pangunahing lugar ng nilalaman ay ang chameleon ng interface ng SeaMeet—nagbabago ang hitsura nito batay sa iyong ginagawa. Galugarin natin ang iba't ibang estado nito.

Estado 1: Capture Hub (Idle / Handa Mag-rekord)

Kapag ipinapakita:

  • Kapag unang binuksan ang SeaMeet
  • Kapag walang napiling pagre-rekord at hindi ka aktibong nagre-rekord

Lite vs Full Mode

Ang SeaMeet ay sumusumpa sa dalawang interface mode. Pareho silang nagbabahagi ng parehong recording engine, parehong mga file sa disk, at parehong tray icon — ngunit naglalantad sila ng ibang dami ng UI.

Pagpili ng Mode

Sa isang malinis na unang paglulunsad, nagpapakita ang SeaMeet ng isang mode picker na nagtatanong kung anong karanasan ang gusto mo. Ang mga umiiral na v2.x na user na nag-upgrade ay tahimik na inilipat sa Full mode (kaya walang biswal na nagbabago), ngunit ang lahat ay maaaring lumipat sa ibang pagkakataon mula sa Mga Setting.

Ang napiling mode ay pinananatili bilang appMode: 'full' | 'lite' sa iyong mga setting ng UI. Ang paglipat ng mga mode habang may pagre-rekord na isinasagawa ay pinipigilan hanggang sa matapos ang pagre-rekord upang hindi ka mawalan ng capture; ang Settings modal ay agad na isinasara upang makita ang "Saving…" spinner sa panahon ng paghihintay.

Full Mode (Default)

Ito ang kabanata na binabasa mo hanggang ngayon — sidebar + Capture Hub + pangunahing lugar ng nilalaman, lahat ng mga estado (Pagre-rekord, Pag-play, Mga Setting) na saklaw sa mga seksyon sa itaas. Kasama sa Full mode ang:

  • Ang Capture Hub na may Flashback at mga kontrol ng screenshot
  • Ang kumpletong sidebar na may mga recording card, paghahanap, sort at filter
  • Notes at Wiki (tingnan ang Kab 16–17)
  • Media Library (Kab 10)
  • Lahat ng mga kategorya ng setting (Kab 18+)
  • Mga lokal-muna na workspace (tingnan ang "Mga Workspace" sa ibaba)

Gamitin ang Full mode kapag ang SeaMeet ay iyong pangunahing recording surface at gusto mo ng mga note, wiki, agent, at pamamahala ng library sa isang window.

Lite Mode

Ang Lite mode ay isang mas maliit na surface area na nakasentro sa system tray at sa isang cloud-backed na listahan ng meeting. Walang sidebar, walang notes view, walang wiki, walang Capture Hub — ang mga pagre-rekord ay sinisimulan mula sa tray (o auto-detect, o hotkey), at ang mga natapos na pagre-rekord ay isinasama bilang mga meeting card kapag na-upload na ng post-meeting summary pipeline ang mga ito sa iyong SeaMeet workspace.

Workspace header sa Lite:

Ang itaas ng Lite window ay isang workspace switcher (isang button na nagpapakita ng aktibong pangalan ng workspace na may avatar at chevron). Ang pag-click dito ay nagbubukas ng dropdown ng bawat workspace na maa-access mo sa SeaMeet cloud. Ang pagpili ng ibang workspace:

  1. Ay nagpapanatili ng bagong workspace ID nang lokal
  2. Nagre-refresh ng listahan ng meeting
  3. Itinutulak ang bagong pangalan ng workspace sa tray menu upang ang isang tray-started na pagre-rekord ay napupunta rin sa tamang lugar
  4. Nire-reset ang pagination sa pahina 1

Ang pag-sign out ay nag-cclear ng workspace header ng tray (traySetWorkspaceDisplay(null, null)) upang hindi magsinungaling ang menu tungkol sa isang workspace na wala ka nang access.

Pag-rekord sa Lite:

  • I-click ang tray icon at piliin ang Mag-rekord ng audio / fullscreen / region — o gumamit ng global hotkey
  • Ang Lite Recording View ay kinukuha ang pangunahing window na may live waveform, timer, at iisang Stop control
  • Kapag huminto ka, ang file ay nai-save nang lokal at na-upload sa iyong SeaMeet workspace para sa transkripsiyon at summarization
  • Kapag natapos ang cloud pipeline, lumalabas ang meeting card sa listahan

Gamitin ang Lite mode kapag ang SeaMeet ay isang background recorder na nagpapakain sa SeaMeet cloud — gusto mo ang tray na gawin ang trabaho at isang malinis na listahan ng mga meeting na susuriin.

Paglipat sa Pagitan ng mga Mode

Buksan ang Mga Setting (sa alinmang mode), hanapin ang aksyon na "Switch to Full / Lite mode", at kumpirmahin. Ini-drain ng SeaMeet ang anumang isinasagawang pagre-rekord, pagkatapos ay muling ilo-launch ang renderer sa ibang mode. Nakakaligtas ng switch ang iyong mga file, workspace, setting, at tray icon.

Mga Workspace

Ang SeaMeet ay may dalawang magkaibang konsepto ng workspace na may parehong pangalan ngunit naninirahan sa iba't ibang lugar. Ang pag-unawa kung alin ay alin ay umiiwas sa kalituhan.

Mga Lokal na Workspace (Full Mode)

Sa Full mode, ang workspace ay isang Obsidian-style vault — isang folder sa disk na nagtataglay ng iyong mga note, ng iyong nabuong wiki, at (bilang default) ng iyong mga pagre-rekord. Pag-aari ng WorkspaceManager sa pangunahing proseso:

  • Isang registry ng mga workspace ({ id, name, path, isDefault? }[]) na pinananatili sa iyong settings file
  • Ang aktibong workspace ID (isa lang ang aktibo sa isang pagkakataon)
  • Isang chokidar file watcher sa path ng aktibong workspace, na may polling na awtomatikong pinagana para sa mga external volume at network mount (hal. macOS /Volumes/, Google Drive's ~/Library/CloudStorage/GoogleDrive-<email>/…) kung saan ang FSEvents ay hindi maaasahang gumana
  • Per-workspace state (huling binuksan na note, mga kamakailang file, atbp.) sa ilalim ng userData/workspace-state/<id>.json

Sa unang paglulunsad, kung walang nakarehistrong workspace, awtomatikong gumagawa ang SeaMeet ng isang Default na workspace na nakaturo sa iyong save directory. Ang pangalang "Default" ay nai-lokalize sa lahat ng 23 wika.

Ang Workspace Switcher (Sidebar Header):

Ang parehong Notes view (Kab 16) at ang Wiki view (Kab 17) ay nagre-render ng <WorkspaceSwitcher> sa itaas ng file tree:

┌──────────────────────────────────┐
│ [🅰] Acme Vault            ⌄    │   ← aktibong workspace
├──────────────────────────────────┤
│ Mga Workspace                    │
│  ✓ Acme Vault     ~/Notes/Acme  │
│    Personal      ~/Notes/Personal│
│    Side Project  ~/Code/Side    │
├──────────────────────────────────┤
│ + Magdagdag ng workspace…        │
└──────────────────────────────────┘
  • I-click ang aktibong row upang buksan ang dropdown
  • I-click ang anumang iba pang workspace upang lumipat dito — ang file watcher ay tinatanggal, ang path ng bagong workspace ay nakakabit, ang Notes at Wiki ay nagre-refresh, at ang per-workspace state ay naibabalik
  • Magdagdag ng workspace… ay nagbubukas ng katutubong folder picker upang makarehistro ka ng anumang direktoryo bilang isang vault (sinusuri ang pagiging natatangi — tinatanggihan ang pagrerehistro ng parehong path nang dalawang beses)
  • Alisin (×) sa isang row ay nag-aalis lang ng entry ng SeaMeet; hindi hinahawakan ang mga file sa disk. Hindi mo maaaring alisin ang huling workspace.
  • Maaaring magpakita ang bawat row ng cloud badge (Dropbox, iCloud, OneDrive, Google Drive) at isang git remote badge kapag nakikita ng sync detection ang mga ito

Ang paglipat ng mga workspace ay serialized: kung may switch na isinasagawa, hinihintay ng susunod na isa na matapos ito upang hindi mawalan ng updated na path ang NotesManager / WikiManager.

Mga Cloud Workspace (Lite Mode)

Sa Lite mode (at sa cloud-enabled na Full builds), ibig sabihin ng workspace ay isang ibang bagay: isang team workspace sa SeaMeet cloud. Ang <WorkspacePicker> component ay kumukuha ng iyong maa-access na mga workspace sa pamamagitan ng SeaMeet API at pinapanatili ang napili para sa pag-route ng upload.

Pinagagana ng mga cloud workspace ang:

  • Kung aling workspace ang ino-upload ng bagong pagre-rekord
  • Kung aling mga meeting ng workspace ang lumalabas sa Lite meetings list
  • Ang workspace header row sa tray menu (upang makita mo sa isang sulyap kung saan mapupunta ang susunod na tray-started na pagre-rekord)

Ang cloud picker ay nag-fi-filter ng mga workspace kung saan ang iyong my_status ay INACTIVE. Sa unang pag-sign in, kung ang iyong dating napiling workspace ay wala sa ibinalik na listahan (nawala mo ang membership, schema drift, atbp.), ang picker ay awtomatikong pumipili ng unang magagamit na workspace at pinapanatili iyon — upang ang menu ay hindi kailanman maipit sa isang hindi maa-access na ID.

Pareho nang Sabay-Sabay

Sa isang cloud-enabled na Full build, maaari kang magkaroon ng dalawa uri ng workspace na napili nang sabay-sabay: isang lokal na vault na naghahawak ng iyong mga note at isang SeaMeet cloud workspace na tumatanggap ng iyong mga upload. Sila ay nakapag-iisa — ang paglipat ng isa ay hindi nililipat ang isa pa.
