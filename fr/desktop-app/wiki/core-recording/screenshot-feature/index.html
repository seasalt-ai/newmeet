Fonctionnalité de capture d'écran

Chapitre 6 : Fonctionnalité de capture d'écran

En plus de l'enregistrement audio et vidéo, SeaMeet inclut une puissante fonctionnalité de capture d'écran qui vous permet de capturer des images fixes de votre écran. Que vous ayez besoin de sauvegarder un moment spécifique d'une vidéo, capturer un message d'erreur ou documenter quelque chose visuellement, les captures d'écran sont incroyablement utiles. Ce chapitre vous apprendra tout sur la prise, la visualisation et la gestion des captures d'écran dans SeaMeet.

Qu'est-ce qu'une capture d'écran ? (Les bases)

Avant de plonger dans les détails, comprenons ce qu'est réellement une capture d'écran.

Explication simple : Une capture d'écran, c'est comme prendre une photographie de l'écran de votre ordinateur. Au lieu d'utiliser un appareil photo pour capturer le monde réel, vous utilisez un logiciel pour capturer exactement ce que vous voyez sur votre moniteur à un moment précis.

Pensez-y de cette façon :

  • Votre écran affiche des images, du texte et des graphiques
  • Une capture d'écran capture ces pixels exactement comme ils apparaissent
  • L'image est sauvegardée comme un fichier que vous pouvez voir, éditer ou partager
  • Contrairement à la vidéo, c'est un seul moment figé dans le temps

Ce qui rend les captures d'écran de SeaMeet spéciales ? Contrairement aux outils basiques qui sauvegardent simplement une image, SeaMeet :

  1. Capture des régions sélectionnées (pas seulement l'écran entier)
  2. Extrait les métadonnées (dimensions, taille de fichier automatiquement)
  3. Extrait automatiquement le texte (OCR) et le copie dans votre presse-papiers via l'IA
  4. Gère les captures aux côtés de vos enregistrements
  5. Fournit un visualiseur dédié avec options de partage et de copie

Pourquoi utiliser les captures d'écran ?

Les captures d'écran servent des objectifs différents des enregistrements audio ou vidéo. Comprendre quand utiliser chacun vous aide à choisir le bon outil.

Capture d'écran vs. enregistrement audio/vidéo

Ce dont vous avez besoinCapture d'écranEnregistrement audioEnregistrement vidéo

Documenter un paramètre✅ Parfait❌ Pas d'info visuelle⚠️ Excessif
Capturer une image d'une vidéo✅ Parfait❌ Pas de visuel✅ Mais fichier volumineux

Quand les captures d'écran excellent

1. Documentation

  • Sauvegarder des messages d'erreur pour le support technique
  • Capturer des paramètres avant de les modifier
  • Documenter des designs ou mises en page de sites web
  • Sauvegarder des reçus et confirmations

2. Communication

  • Montrer exactement ce que vous voyez à vos collègues
  • Inclure des visuels dans les présentations
  • Créer des guides étape par étape avec des images
  • Partager des moments spécifiques de vidéos

3. Archivage

  • Sauvegarder des informations dont vous pourriez avoir besoin plus tard
  • Capturer du contenu sensible au temps (billets, codes)
  • Préserver des pages web qui pourraient changer
  • Créer des documents de référence visuels

4. Qualité

  • Format PNG sans perte préserve chaque pixel
  • Qualité supérieure aux images extraites de vidéos
  • Parfait pour le texte et les éléments d'interface
  • Pas d'artefacts de compression

Comment fonctionnent les captures d'écran dans SeaMeet

SeaMeet rend la prise de captures d'écran simple et puissante. Voici le flux de base :

clavier ou        zone sur votre     les pixels         le dossier de      le visualiseur
clic de bouton    écran              exactement tels    stockage avec      de captures
                                     qu'ils sont        métadonnées

Le processus :

  1. Vous déclenchez la capture (raccourci clavier ou bouton du Capture Hub)
  2. Pour la capture de zone : dessinez la région souhaitée ; pour le plein écran : la capture se fait immédiatement
  3. SeaMeet capture ce contenu exact (SeaMeet lui-même est masqué de la capture par défaut)
  4. L'image est sauvegardée comme un fichier PNG de haute qualité
  5. Vous pouvez la voir dans le visualiseur de captures dédié de SeaMeet

Prendre votre première capture d'écran

Voyons ensemble comment capturer votre première capture d'écran.

Méthode 1 : Utiliser les raccourcis clavier

Le moyen le plus rapide de prendre une capture d'écran :

Sur Windows :

  1. Appuyez sur Ctrl + Alt + S ensemble
  2. Votre écran s'assombrit légèrement
  3. Dessinez un rectangle en cliquant et en faisant glisser
  4. Relâchez pour capturer

Sur macOS :

  1. Appuyez sur Cmd + Shift + S ensemble
  2. Votre écran s'assombrit légèrement
  3. Dessinez un rectangle en cliquant et en faisant glisser
  4. Relâchez pour capturer

Ce qui se passe :

  • SeaMeet capture la zone sélectionnée instantanément
  • La capture est sauvegardée automatiquement
  • Vous entendez un léger son d'obturateur (si activé)
  • Le fichier apparaît dans votre barre latérale « Recent Snapshots »

Méthode 2 : Utiliser le Capture Hub

Quand vous êtes dans la fenêtre principale de SeaMeet :

  1. Dans le panneau droit du Capture Hub, choisissez votre mode :
    • Full Screen — capture l'affichage entier immédiatement
    • Area Capture — ouvre le sélecteur de région pour dessiner une zone
  2. Cochez éventuellement "Keep SeaMeet window visible when taking screenshot" (voir ci-dessous)
  3. Cliquez sur le bouton Take Screenshot ou la grande icône de caméra
  4. Pour la capture de zone : dessinez le rectangle de capture, puis relâchez

Option de visibilité de la fenêtre : Par défaut, SeaMeet se minimise avant de prendre une capture d'écran pour que l'application n'apparaisse pas dans la capture. Si vous voulez que la fenêtre SeaMeet reste visible (par ex. pour la capturer intentionnellement), cochez la case "Keep SeaMeet window visible when taking screenshot".

Option de copie automatique OCR : Cochez "Extract text (OCR) and copy to clipboard" pour que SeaMeet lise automatiquement tout le texte visible de votre capture d'écran via l'IA et le copie dans votre presse-papiers. Après la capture, le pipeline IA s'exécute en arrière-plan (~15-30 secondes). Une fois terminé, le texte extrait remplace l'image de la capture dans votre presse-papiers et une notification confirme la copie. Cela est utile pour récupérer rapidement du texte à partir d'images, de boîtes de dialogue d'erreur ou de pages web sans avoir à le retaper.

  • La même case à cocher apparaît également dans l'overlay du sélecteur de région (près du bouton "Capture Screen or Press Enter") pour que vous puissiez l'activer ou la désactiver par capture.
  • La valeur par défaut peut être modifiée dans Paramètres → AI Extraction & Summary → Auto-extract text (OCR) on screenshot.
  • Nécessite une Clé API. Si aucune Clé API Gemini n'est configurée, la case est grisée avec un lien "subscribe here" vers le portail d'abonnement.

Méthode 3 : Utiliser le lanceur flottant

Quand SeaMeet est ouvert :

  1. Cherchez le widget lanceur flottant (généralement dans un coin de votre écran)
  2. Trouvez l'icône de caméra 📷 (bouton de capture d'écran)
  3. Cliquez dessus
  4. Dessinez un rectangle sur votre écran
  5. Relâchez pour capturer

Où trouver le lanceur :

  • Apparaît généralement quand SeaMeet est en cours d'exécution
  • Peut être déplacé en le faisant glisser
  • Se minimise quand il n'est pas utilisé
  • Affiche un accès rapide aux fonctionnalités d'enregistrement et de capture d'écran

Comment sélectionner la région parfaite

Étape par étape :

  1. Positionnez votre curseur à un coin de ce que vous voulez capturer
  2. Cliquez et maintenez le bouton gauche de la souris
  3. Faites glisser jusqu'au coin opposé
  4. Relâchez quand la zone couvre exactement ce dont vous avez besoin
  5. Appuyez sur Entrée pour confirmer, ou relâchez simplement pour la capture automatique

Conseils pour une sélection précise :

  • Commencez légèrement en dehors du contenu souhaité
  • Vous pouvez ajuster la sélection avant de relâcher
  • Maintenez Shift pour contraindre à un carré (dans certains modes)
  • Appuyez sur Échap à tout moment pour annuler et réessayer

Ce qui est capturé :

  • Exactement ce qui se trouve dans le rectangle que vous dessinez
  • À pleine résolution (sans perte de qualité)
  • Y compris tout le texte, images et graphiques
  • Mais PAS l'overlay assombri ni la zone de sélection

Où les captures d'écran sont sauvegardées

Comprendre où vont vos captures vous aide à les trouver et les gérer.

Emplacement de stockage par défaut

Les captures d'écran sont sauvegardées dans :

Documents/SeaMeet/Screenshots/

Exemple de chemin :

  • Windows : C:\Users\VotreNom\Documents\SeaMeet\Screenshots\
  • macOS : /Users/VotreNom/Documents/SeaMeet/Screenshots/

Convention de nommage des fichiers

SeaMeet nomme automatiquement vos captures avec des horodatages :

Screenshot_AAAAMMJJ_HHMMSS.png

Exemple : Screenshot_20260209_143052.png

  • Prise le : 9 février 2026
  • À : 14:30:52
  • Format : PNG (haute qualité)

Pourquoi ce nommage est utile :

  • ✅ Vous savez exactement quand chaque capture a été prise
  • ✅ Se trie chronologiquement dans les explorateurs de fichiers
  • ✅ Pas de conflits de noms de fichiers en double
  • ✅ Facile de trouver des captures spécifiques

Métadonnées des captures

Chaque capture inclut des informations automatiquement extraites :

{
  "filename": "Screenshot_20260209_143052.png",
  "type": "screenshot",
  "isScreenshot": true,
  "imageMetadata": {
    "width": 1920,
    "height": 1080,
    "format": "png",
    "fileSize": 2540000
  },
  "timestamp": "2026-02-09T14:30:52.000Z"
}

Ce que cela signifie :

  • Dimensions : 1920×1080 pixels (Full HD)
  • Format : PNG (sans perte, haute qualité)
  • Taille du fichier : ~2,5 Mo
  • Heure de capture : Enregistrée automatiquement

Comprendre l'affichage des métadonnées

Dimensions :

  • Affichées comme Largeur × Hauteur en pixels
  • Exemple : 1920 × 1080
  • Cela vous indique la résolution de l'image capturée

Taille du fichier :

  • Formatée en unités lisibles
  • Exemple : 2,5 Mo ou 850 Ko
  • Les fichiers PNG sont plus grands mais de meilleure qualité que les JPG

Format :

  • Toujours « PNG » pour les captures SeaMeet
  • Les images importées peuvent afficher « JPG », « WebP », etc.

Travailler avec les captures : Actions

Le visualiseur fournit plusieurs actions que vous pouvez effectuer avec vos captures.

Copier dans le presse-papiers

Ce que ça fait : Copie l'image de capture dans le presse-papiers système pour la coller ailleurs.

Comment utiliser :

  1. Ouvrez le visualiseur de captures
  2. Cliquez sur le bouton 📋 Copier
  3. Ou appuyez sur Ctrl+C (Windows) / Cmd+C (macOS)
  4. Collez dans n'importe quelle application acceptant les images (e-mail, chat, document, etc.)

Quand utiliser :

  • ✅ Coller dans Slack, Teams ou Discord
  • ✅ Ajouter à un document Word ou un e-mail
  • ✅ Téléverser sur un site web ou formulaire
  • ✅ Partager dans un message de chat
  • ✅ Créer une référence visuelle rapide

Astuce : C'est le moyen le plus rapide de partager une capture sans la sauvegarder ailleurs d'abord !

Ouvrir dans le visualiseur système

Ce que ça fait : Ouvre le dossier contenant votre capture dans l'explorateur de fichiers système, avec le fichier sélectionné.

Comment utiliser :

  1. Ouvrez le visualiseur de captures
  2. Cliquez sur le bouton 📂 Ouvrir
  3. Votre explorateur de fichiers s'ouvre montrant le dossier Screenshots
  4. Le fichier est surligné/sélectionné

Quand utiliser :

  • ✅ Vous voulez renommer le fichier
  • ✅ Vous devez le déplacer vers un autre emplacement
  • ✅ Vous voulez le joindre à un e-mail depuis le fichier
  • ✅ Vous devez l'éditer dans un autre programme

Partager (macOS uniquement)

Ce que ça fait : Ouvre le menu Partager de macOS pour envoyer la capture via diverses méthodes.

Comment utiliser :

  1. Ouvrez le visualiseur de captures (sur macOS)
  2. Cliquez sur le bouton 🔗 Partager
  3. Choisissez parmi les options de partage :
    • AirDrop (vers les appareils à proximité)
    • Messages
    • Mail
    • Notes
    • Réseaux sociaux
    • Et plus encore...

Quand utiliser :

  • ✅ Partage rapide vers les appareils Apple
  • ✅ Envoi via Messages
  • ✅ Ajout à Notes ou Rappels
  • ✅ Publication sur les réseaux sociaux

Pourquoi Windows n'a pas cette option : Windows n'a pas d'API de partage standardisée comme macOS. Sur Windows, utilisez Copier puis collez dans votre application de destination.

Gérer les captures dans la barre latérale

Les captures apparaissent dans votre section « Recent Snapshots » aux côtés des enregistrements.

Comment les captures apparaissent

Indicateurs visuels :

  • 📷 Icône de caméra (au lieu de 🎥 vidéo ou 🎵 audio)
  • Couleur violette pour le fond de l'icône
  • Affiche les dimensions dans la ligne de métadonnées (ex. « 1920×1080 »)
  • Affiche l'étiquette "Screenshot"

Exemple d'entrée dans la barre latérale :

┌─────────────────────────────────────────┐
│ 📷  Capture d'écran                     │
│     Screenshot_20260209_143052.png      │
│     1920×1080 • Aujourd'hui à 14:30    │
└─────────────────────────────────────────┘

Rechercher des captures

La barre de recherche fonctionne aussi pour les captures :

  1. Tapez dans la zone de recherche en haut de la barre latérale
  2. Les captures apparaîtront si elles correspondent à votre recherche
  3. Recherche par nom de fichier et métadonnées

Ce que vous pouvez rechercher :

  • Nom de fichier partiel (ex. « Screenshot_20260209 »)
  • Mots-clés temporels (ex. « Today », « Yesterday »)
  • Extension de fichier (ex. « .png »)

Tri et organisation

Comment les captures sont triées :

  • Par horodatage (les plus récentes en premier)
  • Mélangées avec les enregistrements en ordre chronologique
  • Les captures les plus récentes apparaissent en haut

Rafraîchissement automatique :

  • Les nouvelles captures apparaissent immédiatement quand elles sont prises
  • Pas besoin de rafraîchir manuellement (mais vous pouvez si nécessaire)
  • La barre latérale se met à jour en temps réel

Comment importer des images

  3. Sélectionnez votre/vos fichier(s) image

  2. Faites-le glisser dans la fenêtre SeaMeet
  3. Déposez-le dans la zone de la barre latérale

  • Vous pouvez la voir dans le visualiseur de captures

Note : Les images importées restent à leur emplacement d'origine. SeaMeet crée une référence vers elles.

Scénarios pratiques de captures d'écran

Regardons des situations réelles où les captures d'écran sont l'outil parfait.

Scénario 1 : Sauvegarder un message d'erreur

La situation : Une application affiche une erreur que vous ne comprenez pas. Vous voulez demander au support technique.

Pourquoi la capture est parfaite :

  • Capture le texte exact de l'erreur
  • Inclut tous les codes d'erreur
  • Montre le contexte (ce que vous faisiez)
  • Facile à joindre à un ticket de support

Comment faire :

  1. Quand l'erreur apparaît, appuyez sur Ctrl+Alt+S (Windows) ou Cmd+Shift+S (macOS)
  2. Dessinez une zone autour du dialogue d'erreur
  3. La capture est sauvegardée automatiquement
  4. Ouvrez-la et utilisez Copier pour la coller dans votre chat/e-mail de support

Scénario 2 : Documenter des paramètres

La situation : Vous allez changer des paramètres importants et voulez vous souvenir de ce qu'ils étaient avant.

Pourquoi la capture est parfaite :

  • Enregistrement visuel de la configuration exacte
  • Plus rapide que tout noter
  • Aucune chance d'erreur de transcription
  • Facile de comparer « avant » et « après »

Comment faire :

  1. Naviguez vers la page de paramètres
  2. Prenez une capture des paramètres actuels
  3. Faites vos modifications
  4. Prenez une autre capture
  5. Vous avez maintenant un enregistrement visuel des deux états

Scénario 3 : Créer des instructions étape par étape

La situation : Vous expliquez comment utiliser un logiciel à un collègue et avez besoin d'aides visuelles.

Pourquoi la capture est parfaite :

  • Montre exactement quels boutons cliquer
  • Capture les emplacements des menus
  • Pas d'ambiguïté sur ce que vous voulez dire
  • Documentation professionnelle

Comment faire :

  1. Suivez le processus vous-même
  2. À chaque étape importante, prenez une capture
  3. Ensuite, arrangez-les dans l'ordre avec des explications
  4. Partagez le guide complet

Scénario 4 : Capturer une image spécifique d'une vidéo

La situation : Vous regardez une vidéo et voulez sauvegarder un moment particulier comme image.

Pourquoi la capture est mieux qu'une image extraite de vidéo :

  • Qualité supérieure à l'extraction d'image vidéo
  • Capture instantanée (pas de traitement vidéo)
  • Moment exact souhaité
  • Fichier plus petit qu'un clip vidéo

Comment faire :

  1. Mettez la vidéo en pause à l'image exacte
  2. Prenez une capture de la zone du lecteur vidéo
  3. L'image est sauvegardée en pleine qualité
  4. Vous pouvez partager juste ce moment

Scénario 5 : Sauvegarder du contenu web

La situation : Vous trouvez des informations importantes sur un site web qui pourrait changer ou disparaître.

Pourquoi la capture est parfaite :

  • Préserve la page exactement comme vous la voyez
  • Fonctionne même si le site tombe en panne
  • Capture le design et la mise en page visuelle
  • Plus rapide que sauvegarder la page entière

Comment faire :

  1. Naviguez vers la page
  2. Prenez une capture de la section pertinente
  3. L'image est sauvegardée de manière permanente
  4. Vous avez un enregistrement visuel pour toujours

Comparer les captures aux autres fonctionnalités

Comprendre quand utiliser les captures vs. les autres fonctionnalités de SeaMeet vous aide à travailler plus efficacement.

Capture d'écran vs. enregistrement vidéo

AspectCapture d'écranEnregistrement vidéo
Ce qu'elle captureUn momentAction continue
Taille de fichierPetite (~2-5 Mo)Grande (~60 Mo/min)
Idéale pourContenu statique, texte, interfaceMouvement, processus, démos
Temps de captureInstantanéNécessite une durée
QualitéPrécision parfaite au pixelCompressé, peut être flou
SonAucunPeut inclure l'audio

Guide de décision :

  • Utilisez la capture quand : Vous avez besoin d'un moment spécifique, le texte est important, ou la taille de fichier compte
  • Utilisez la vidéo quand : Vous devez montrer un processus, le mouvement est important, ou vous avez besoin d'audio

Capture d'écran vs. enregistrement Flashback

AspectCapture d'écranEnregistrement Flashback
TimingMoment présentPassé (déjà arrivé)
DuréeInstantanéVariable (dernières X minutes)
Taille de fichierTrès petite (~2-5 Mo)Moyenne (~variable)
Idéale pourCapturer l'état actuelRécupérer des moments manqués
QualitéPleine résolutionQualité vidéo (compressée)

Guide de décision :

  • Utilisez la capture quand : Vous voyez quelque chose maintenant que vous voulez sauvegarder
  • Utilisez Flashback quand : Vous venez de manquer quelque chose et voulez récupérer les dernières minutes

Bonnes pratiques pour les captures d'écran

Suivez ces directives pour tirer le meilleur parti des captures d'écran.

Avant de prendre des captures

✅ Préparez votre écran

  • Fermez les fenêtres sans rapport
  • Cachez les informations sensibles
  • Maximisez le contenu que vous voulez capturer
  • Assurez un bon contraste et une bonne visibilité

✅ Pensez à l'objectif

  • Qui verra cette capture ?
  • Quelles informations doivent être visibles ?
  • Le texte sera-t-il lisible à la taille de capture ?
  • Des données sensibles sont-elles visibles ?

✅ Nettoyez votre bureau

  • Retirez les fichiers personnels de la vue
  • Fermez les applications de chat
  • Cachez les zones de notification si nécessaire
  • Présentez une apparence professionnelle

En prenant des captures

✅ Soyez précis dans la sélection

  • Capturez exactement ce dont vous avez besoin (ni plus, ni moins)
  • Incluez le contexte si cela aide à la compréhension
  • Évitez de couper des éléments d'interface importants
  • Laissez une petite marge autour du contenu

✅ Pensez à la résolution

  • Plus haute résolution = plus de détails
  • Mais fichier plus volumineux
  • Pensez à l'usage prévu de la capture
  • Le 1080p est généralement suffisant pour la plupart des usages

✅ Vérifiez avant de terminer

  • Avez-vous capturé la bonne zone ?
  • Le contenu est-il clairement visible ?
  • Des informations sensibles incluses accidentellement ?
  • Le texte est-il lisible ?

Après avoir pris des captures

✅ Renommez de manière descriptive Au lieu de : Screenshot_20260209_143052.png Essayez : Photoshop_Erreur_Calques.png ou Site_Web_Design_Accueil.png

✅ Organisez régulièrement

  • Créez des dossiers par projet ou sujet
  • Supprimez les captures temporaires/de test
  • Sauvegardez les captures importantes
  • Archivez les anciennes captures dont vous n'avez plus besoin

✅ Vérifiez avant de partager

  • Ouvrez la capture et vérifiez la qualité
  • Vérifiez les informations sensibles
  • Assurez-vous qu'elle montre clairement ce que vous vouliez
  • Recadrez ou annotez si nécessaire

Dépannage des problèmes de captures

« Les captures n'apparaissent pas dans la barre latérale »

Causes possibles et solutions :

  1. Vérifiez que le scan est terminé

    • Cliquez sur le bouton de rafraîchissement dans la barre latérale
    • Attendez quelques secondes que le scan se termine
    • Les nouvelles captures devraient apparaître

  2. Vérifiez l'emplacement du fichier

    • Les captures devraient être dans Documents/SeaMeet/Screenshots/
    • Vérifiez que le dossier existe
    • Assurez-vous que les fichiers PNG sont à cet emplacement

  3. Vérifiez les permissions de fichiers

    • SeaMeet a besoin de la permission de lire le dossier
    • Sur macOS : Vérifiez Préférences Système → Sécurité et confidentialité → Fichiers et dossiers
    • Sur Windows : Assurez-vous qu'aucun antivirus ne bloque l'accès

  4. Redémarrez SeaMeet

    • Parfois un nouveau scan est nécessaire
    • Fermez et rouvrez l'application
    • Vérifiez si les captures apparaissent

« La qualité de la capture semble mauvaise »

Solutions :

  1. Les captures sont toujours en pleine qualité

    • SeaMeet sauvegarde les PNG à 100 % de qualité
    • Le visualiseur montre le fichier original
    • Si ça semble mauvais, le contenu source pourrait être en basse résolution

  2. Vérifiez la mise à l'échelle de votre écran

    • Certains portables utilisent 125 % ou 150 % de mise à l'échelle
    • Cela peut affecter la netteté apparente
    • La capture capture ce que vous voyez (mis à l'échelle)

  3. Vérifiez le contenu original

    • Si vous capturez une vidéo, la vidéo pourrait être en basse résolution
    • Les captures ne peuvent pas ajouter de détails qui n'existent pas
    • Elles capturent exactement ce qui est à l'écran

« Je ne trouve pas mes captures sur le disque »

Solutions :

  1. Vérifiez l'emplacement par défaut

    • Windows : C:\Users\[VotreNom]\Documents\SeaMeet\Screenshots\
    • macOS : /Users/[VotreNom]/Documents/SeaMeet/Screenshots/

  2. Recherchez le nom de fichier

    • Cherchez les fichiers commençant par « Screenshot_ »
    • Utilisez la recherche de fichiers de votre système
    • Filtrez par fichiers PNG

  3. Vérifiez les paramètres SeaMeet

    • Vous pouvez changer l'emplacement de stockage dans Paramètres → Storage
    • Vérifiez le chemin du dossier de captures affiché

« La copie dans le presse-papiers ne fonctionne pas »

Solutions :

  1. Essayez le bouton au lieu du clavier

    • Cliquez sur le bouton « Copy » dans le visualiseur
    • Parfois le raccourci clavier ne fonctionne pas

  2. Vérifiez les permissions du presse-papiers

    • Certains logiciels de sécurité bloquent l'accès au presse-papiers
    • Essayez de redémarrer SeaMeet
    • Testez avec une autre application

  3. Vérifiez que le fichier existe

    • Si la capture a été déplacée ou supprimée, la copie ne fonctionnera pas
    • Ouvrez l'emplacement du fichier pour confirmer qu'il existe
    • Réimportez si nécessaire

« Le bouton Partager n'apparaît pas »

C'est normal sur Windows et Linux :

  • Le bouton Partager n'apparaît que sur macOS
  • macOS a une API SharingService intégrée
  • Windows et Linux n'ont pas de système de partage standardisé
  • Utilisez Copier et collez à la place sur ces plateformes
