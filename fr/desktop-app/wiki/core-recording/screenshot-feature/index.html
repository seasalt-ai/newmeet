Fonctionnalité de capture d'écran

Chapitre 6 : Fonctionnalité de capture d'écran

En plus de l'enregistrement audio et vidéo, SeaMeet propose une puissante fonctionnalité de capture d'écran qui vous permet de capturer des images fixes de votre écran. Que vous ayez besoin d'enregistrer un moment précis d'une vidéo, de capturer un message d'erreur ou de documenter visuellement quelque chose, les captures d'écran sont incroyablement utiles. Ce chapitre vous apprendra tout sur la prise, la visualisation et la gestion des captures d'écran dans SeaMeet.

Qu'est-ce qu'une capture d'écran ? (Les bases)

Avant de plonger dans les détails, comprenons ce qu'est réellement une capture d'écran.

Explication simple : Une capture d'écran, c'est comme prendre une photographie de l'écran de votre ordinateur. Au lieu d'utiliser un appareil photo pour capturer le monde réel, vous utilisez un logiciel pour capturer exactement ce que vous voyez sur votre moniteur à un moment précis.

Pensez-y comme ceci :

  • Votre écran affiche des images, du texte et des graphiques
  • Une capture d'écran capture ces pixels exactement comme ils apparaissent
  • L'image est enregistrée sous forme de fichier que vous pouvez consulter, modifier ou partager
  • Contrairement à la vidéo, c'est un instant figé dans le temps

Qu'est-ce qui rend les captures d'écran de SeaMeet spéciales ? Contrairement aux outils basiques de capture d'écran qui se contentent d'enregistrer une image, SeaMeet :

  1. Capture des régions sélectionnées (pas seulement l'écran entier)
  2. Extrait les métadonnées (dimensions, taille du fichier automatiquement)
  3. Extrait automatiquement le texte (OCR) et le copie dans votre presse-papiers grâce à l'IA
  4. Gère les captures d'écran parallèlement à vos enregistrements
  5. Fournit une visionneuse dédiée avec des options de partage et de copie

Pourquoi utiliser les captures d'écran ?

Les captures d'écran servent à des fins différentes de celles des enregistrements audio ou vidéo. Comprendre quand utiliser chacun vous aide à choisir le bon outil.

Capture d'écran vs enregistrement audio/vidéo

Ce dont vous avez besoinUtiliser une capture d'écranUtiliser un enregistrement audioUtiliser un enregistrement vidéo
Enregistrer un message d'erreur✅ Parfait❌ Ne peut pas capturer le texte⚠️ Excessif
Documenter un paramètre✅ Parfait❌ Aucune information visuelle⚠️ Excessif
Capturer une image d'une vidéo✅ Parfait❌ Aucune image✅ Mais fichier volumineux
Enregistrer une conversation❌ Pas d'audio✅ Parfait✅ Parfait
Montrer un processus étape par étape⚠️ Plusieurs nécessaires❌ Aucune image✅ Parfait
Enregistrer un reçu ou une confirmation✅ Parfait❌ Ne peut pas lire le texte⚠️ Excessif

Quand les captures d'écran brillent

1. Documentation

  • Enregistrer les messages d'erreur pour l'assistance technique
  • Capturer les paramètres avant de les modifier
  • Documenter les conceptions ou mises en page de sites web
  • Enregistrer les reçus et confirmations

2. Communication

  • Montrer exactement ce que vous voyez à vos collègues
  • Inclure des visuels dans les présentations
  • Créer des guides étape par étape avec des images
  • Partager des moments précis de vidéos

3. Archivage

  • Enregistrer des informations dont vous pourriez avoir besoin plus tard
  • Capturer du contenu sensible au temps (billets, codes)
  • Préserver des pages web susceptibles de changer
  • Créer des supports de référence visuels

4. Qualité

  • Le format PNG sans perte préserve chaque pixel
  • Qualité supérieure aux images vidéo
  • Parfait pour le texte et les éléments d'interface
  • Pas d'artefacts de compression

Comment fonctionnent les captures d'écran dans SeaMeet

SeaMeet rend la prise de captures d'écran simple et puissante. Voici le flux de base :

1. DÉCLENCHEUR   →  2. SÉLECTIONNER →  3. CAPTURER    →  4. ENREGISTRER →  5. VISUALISER
Raccourci        Dessinez un cadre   SeaMeet capture    PNG enregistré    Ouvrir dans
clavier ou       sur votre écran     les pixels         dans le dossier   la visionneuse
clic sur bouton                      exactement comme   de stockage avec  de captures
                                     ils apparaissent   métadonnées       d'écran
                                                        extraites

Le processus :

  1. Vous déclenchez la capture d'écran (raccourci clavier ou bouton du Capture Hub)
  2. Pour la capture de zone : dessinez la région souhaitée ; pour le plein écran : la capture se fait immédiatement
  3. SeaMeet capture ce contenu exact (SeaMeet lui-même est masqué de la capture par défaut)
  4. L'image est enregistrée sous forme de fichier PNG de haute qualité
  5. Vous pouvez la visualiser dans la visionneuse de captures d'écran dédiée de SeaMeet

Réaliser votre première capture d'écran

Voyons comment réaliser votre première capture d'écran.

Méthode 1 : Utiliser les raccourcis clavier

Le moyen le plus rapide de prendre une capture d'écran :

Sur Windows :

  1. Appuyez sur Ctrl + Alt + S ensemble
  2. Votre écran s'assombrit légèrement
  3. Dessinez un rectangle en cliquant et en glissant
  4. Relâchez pour capturer

Sur macOS :

  1. Appuyez sur Cmd + Shift + S ensemble
  2. Votre écran s'assombrit légèrement
  3. Dessinez un rectangle en cliquant et en glissant
  4. Relâchez pour capturer

Ce qui se passe :

  • SeaMeet capture instantanément la zone sélectionnée
  • La capture d'écran est enregistrée automatiquement
  • Vous entendez un léger son d'obturateur d'appareil photo (si activé)
  • Le fichier apparaît dans votre barre latérale Instantanés récents

Méthode 2 : Utiliser le Capture Hub

Lorsque vous êtes dans la fenêtre principale de SeaMeet :

  1. Dans le panneau de droite du Capture Hub, choisissez votre mode :
    • Full Screen — capture immédiatement tout l'écran
    • Area Capture — ouvre le sélecteur de région pour vous permettre de dessiner un cadre
  2. Cochez éventuellement "Keep SeaMeet window visible when taking screenshot" (voir ci-dessous)
  3. Cliquez sur le bouton Take Screenshot ou sur la grande icône d'appareil photo
  4. Pour la capture de zone : dessinez le rectangle de capture, puis relâchez

Option de visibilité de la fenêtre : Par défaut, SeaMeet se réduit avant de prendre une capture d'écran pour que l'application n'apparaisse pas dans la capture. Si vous souhaitez que la fenêtre SeaMeet reste visible (par exemple, pour la capturer intentionnellement), cochez la case "Keep SeaMeet window visible when taking screenshot".

Option de copie automatique OCR : Cochez "Extract text (OCR) and copy to clipboard" pour que SeaMeet lise automatiquement tout le texte visible de votre capture d'écran à l'aide de l'IA et le copie dans votre presse-papiers. Une fois la capture d'écran réalisée, le pipeline IA s'exécute en arrière-plan (~15–30 secondes). Lorsqu'il se termine, le texte extrait remplace l'image de la capture d'écran dans votre presse-papiers et une notification confirme la copie. C'est utile pour récupérer rapidement du texte à partir d'images, de boîtes de dialogue d'erreur ou de pages web sans avoir à le retaper.

  • La même case à cocher apparaît également dans la superposition Region Selector (près du bouton "Capture Screen or Press Enter") afin que vous puissiez l'activer par capture.
  • La valeur par défaut peut être modifiée dans Paramètres → AI Extraction & Summary → Auto-extract text (OCR) on screenshot.
  • Nécessite une clé API. Si aucune clé API Gemini n'est configurée, la case à cocher est grisée avec un lien "subscribe here" vers le portail de facturation.

Méthode 3 : Utiliser le lanceur flottant

Lorsque SeaMeet est ouvert :

  1. Recherchez le widget du lanceur flottant (généralement dans un coin de votre écran)
  2. Trouvez l'icône d'appareil photo 📷 (bouton de capture d'écran)
  3. Cliquez dessus
  4. Dessinez un rectangle sur votre écran
  5. Relâchez pour capturer

Où trouver le lanceur :

  • Apparaît généralement lorsque SeaMeet est en cours d'exécution
  • Peut être déplacé par glisser-déposer
  • Se réduit lorsqu'il n'est pas utilisé
  • Offre un accès rapide aux fonctionnalités d'enregistrement et de capture d'écran

Comment sélectionner la région parfaite

Étape par étape :

  1. Positionnez votre curseur à un coin de ce que vous souhaitez capturer
  2. Cliquez et maintenez le bouton gauche de la souris
  3. Glissez vers le coin opposé
  4. Relâchez lorsque le cadre couvre exactement ce dont vous avez besoin
  5. Appuyez sur Entrée pour confirmer, ou relâchez simplement pour une capture automatique

Conseils pour une sélection précise :

  • Commencez légèrement en dehors du contenu que vous souhaitez
  • Vous pouvez ajuster la sélection avant de relâcher
  • Maintenez Shift pour contraindre à un carré (dans certains modes)
  • Appuyez sur Échap à tout moment pour annuler et recommencer

Ce qui est capturé :

  • Exactement ce qui se trouve dans le rectangle que vous dessinez
  • En pleine résolution (aucune perte de qualité)
  • Y compris tout le texte, les images et les graphiques
  • Mais PAS la superposition assombrie ni le cadre de sélection

Où sont enregistrées les captures d'écran

Comprendre où vont vos captures d'écran vous aide à les trouver et à les gérer.

Emplacement de stockage par défaut

Les captures d'écran sont enregistrées dans :

Documents/SeaMeet/Screenshots/

Exemple de chemin :

  • Windows : C:\Users\YourName\Documents\SeaMeet\Screenshots\
  • macOS : /Users/YourName/Documents/SeaMeet/Screenshots/

Convention de nommage des fichiers

SeaMeet nomme automatiquement vos captures d'écran avec des horodatages :

Screenshot_YYYYMMDD_HHMMSS.png

Exemple : Screenshot_20260209_143052.png

  • Prise le : 9 février 2026
  • À : 14h30:52
  • Format : PNG (haute qualité)

Pourquoi cette dénomination est utile :

  • ✅ Vous savez exactement quand chaque capture a été prise
  • ✅ Triées chronologiquement dans les explorateurs de fichiers
  • ✅ Aucun conflit de noms de fichiers en double
  • ✅ Facile de trouver des captures spécifiques

Métadonnées des captures d'écran

Chaque capture d'écran inclut des informations automatiquement extraites :

{
  "filename": "Screenshot_20260209_143052.png",
  "type": "screenshot",
  "isScreenshot": true,
  "imageMetadata": {
    "width": 1920,
    "height": 1080,
    "format": "png",
    "fileSize": 2540000
  },
  "timestamp": "2026-02-09T14:30:52.000Z"
}

Ce que cela signifie :

  • Dimensions : 1920×1080 pixels (Full HD)
  • Format : PNG (sans perte, haute qualité)
  • Taille du fichier : ~2,5 Mo
  • Heure de capture : Enregistrée automatiquement

Visualiser les captures d'écran dans SeaMeet

SeaMeet propose une visionneuse de captures d'écran dédiée pour visualiser vos captures.

Ouvrir la visionneuse de captures d'écran

Méthode 1 : Depuis la barre latérale

  1. Regardez votre barre latérale "Instantanés récents"
  2. Trouvez votre capture d'écran (avec une icône d'appareil photo 📷)
  3. Cliquez dessus
  4. La visionneuse de captures d'écran s'ouvre automatiquement

Méthode 2 : Depuis l'importation de fichiers

  1. Cliquez sur "Import" ou glissez-déposez des fichiers dans SeaMeet
  2. Sélectionnez les fichiers image (PNG, JPG, etc.)
  3. Ils apparaissent dans votre barre latérale
  4. Cliquez pour visualiser

Comprendre l'affichage des métadonnées

Dimensions :

  • Affichées sous la forme Largeur × Hauteur en pixels

Taille du fichier :

  • Formatée en unités lisibles par l'humain
  • Exemple : 2,5 Mo ou 850 Ko
  • Les fichiers PNG sont plus volumineux mais de meilleure qualité que JPG

Format :

  • Toujours "PNG" pour les captures d'écran SeaMeet
  • D'autres images importées peuvent afficher "JPG", "WebP", etc.

Travailler avec les captures d'écran : Actions

La visionneuse de captures d'écran propose plusieurs actions que vous pouvez effectuer avec vos captures.

Copier dans le presse-papiers

Ce qu'elle fait : Copie l'image de la capture d'écran dans le presse-papiers de votre système afin que vous puissiez la coller ailleurs.

Comment l'utiliser :

  1. Ouvrez la visionneuse de captures d'écran
  2. Cliquez sur le bouton 📋 Copier
  3. Ou appuyez sur Ctrl+C (Windows) / Cmd+C (macOS)
  4. Collez dans n'importe quelle application qui accepte les images (e-mail, chat, document, etc.)

Quand l'utiliser :

  • ✅ Coller dans Slack, Teams ou Discord
  • ✅ Ajouter à un document Word ou un e-mail
  • ✅ Télécharger sur un site web ou un formulaire
  • ✅ Partager dans un message de chat
  • ✅ Créer une référence visuelle rapide

Astuce de pro : C'est le moyen le plus rapide de partager une capture d'écran sans l'enregistrer ailleurs au préalable !

Ouvrir dans la visionneuse système

Ce qu'elle fait : Ouvre le dossier contenant votre capture d'écran dans l'explorateur de fichiers de votre système, avec le fichier sélectionné.

Comment l'utiliser :

  1. Ouvrez la visionneuse de captures d'écran
  2. Cliquez sur le bouton 📂 Ouvrir
  3. Votre explorateur de fichiers s'ouvre en affichant le dossier Screenshots
  4. Le fichier est mis en surbrillance/sélectionné

Quand l'utiliser :

  • ✅ Vous voulez renommer le fichier
  • ✅ Vous devez le déplacer vers un autre emplacement
  • ✅ Vous souhaitez le joindre à un e-mail à partir du fichier
  • ✅ Vous devez le modifier dans un autre programme

Partager (macOS uniquement)

Ce qu'elle fait : Ouvre le menu Partager de macOS pour envoyer la capture d'écran par divers moyens.

Comment l'utiliser :

  1. Ouvrez la visionneuse de captures d'écran (sur macOS)
  2. Cliquez sur le bouton 🔗 Partager
  3. Choisissez parmi les options de partage :
    • AirDrop (vers les appareils à proximité)
    • Messages
    • Mail
    • Notes
    • Réseaux sociaux
    • Et plus encore...

Quand l'utiliser :

  • ✅ Partage rapide vers les appareils Apple
  • ✅ Envoi via Messages
  • ✅ Ajout aux Notes ou Rappels
  • ✅ Publication sur les réseaux sociaux

Pourquoi Windows ne dispose pas de cette fonction : Windows n'a pas d'API de partage standardisée comme macOS. Sur Windows, utilisez Copier puis collez dans votre application de destination à la place.

Gérer les captures d'écran dans la barre latérale

Les captures d'écran apparaissent dans votre section "Instantanés récents" parallèlement aux enregistrements.

Comment les captures d'écran apparaissent

Indicateurs visuels :

  • 📷 Icône d'appareil photo (au lieu de l'icône vidéo 🎥 ou audio 🎵)
  • Couleur violette pour l'arrière-plan de l'icône
  • Affiche les dimensions dans la ligne de métadonnées (par exemple, "1920×1080")
  • Affiche l'étiquette "Screenshot"

Exemple d'entrée dans la barre latérale :

┌─────────────────────────────────────────┐
│ 📷  Capture d'écran                     │
│     Screenshot_20260209_143052.png      │
│     1920×1080 • Aujourd'hui à 14h30     │
└─────────────────────────────────────────┘

Rechercher des captures d'écran

La barre de recherche fonctionne également pour les captures d'écran :

  1. Tapez dans la zone de recherche en haut de la barre latérale
  2. Les captures d'écran apparaîtront si elles correspondent à votre recherche
  3. Recherche par nom de fichier et métadonnées

Ce que vous pouvez rechercher :

  • Nom de fichier partiel (par exemple, "Screenshot_20260209")
  • Mots-clés temporels (par exemple, "Aujourd'hui", "Hier")
  • Extension de fichier (par exemple, ".png")

Tri et organisation

Comment les captures d'écran sont triées :

  • Par horodatage (le plus récent en premier)
  • Mélangées avec les enregistrements par ordre chronologique
  • Les captures les plus récentes apparaissent en haut

Actualisation automatique :

  • Les nouvelles captures d'écran apparaissent immédiatement après leur capture
  • Pas besoin d'actualiser manuellement (mais vous pouvez le faire si nécessaire)
  • La barre latérale se met à jour en temps réel

  3. Sélectionnez votre/vos fichier(s) image
  4. Cliquez sur "Open"
  5. Les images apparaissent dans votre barre latérale

  • Vous pouvez la visualiser dans la visionneuse de captures d'écran

Remarque : Les images importées restent à leur emplacement d'origine. SeaMeet crée une référence vers elles.

Scénarios pratiques de capture d'écran

Examinons des situations réelles où les captures d'écran sont l'outil parfait.

Scénario 1 : Sauvegarder un message d'erreur

La situation : Une application affiche une erreur que vous ne comprenez pas. Vous souhaitez interroger le support technique à ce sujet.

Pourquoi la capture d'écran est parfaite :

  • Capture le texte exact de l'erreur
  • Inclut les codes d'erreur
  • Montre le contexte (ce que vous étiez en train de faire)
  • Facile à joindre à un ticket de support

Comment procéder :

  1. Lorsque l'erreur apparaît, appuyez sur Ctrl+Alt+S (Windows) ou Cmd+Shift+S (macOS)
  2. Dessinez un cadre autour de la boîte de dialogue d'erreur
  3. La capture d'écran est enregistrée automatiquement
  4. Ouvrez-la et utilisez Copier pour la coller dans votre chat/e-mail de support

Scénario 2 : Documenter les paramètres

La situation : Vous modifiez des paramètres importants et souhaitez vous souvenir de leur état précédent.

Pourquoi la capture d'écran est parfaite :

  • Enregistrement visuel de la configuration exacte
  • Plus rapide que d'écrire tout
  • Aucun risque d'erreurs de transcription
  • Facile de comparer "avant" et "après"

Comment procéder :

  1. Accédez à la page des paramètres
  2. Prenez une capture d'écran des paramètres actuels
  3. Effectuez vos modifications
  4. Prenez une autre capture d'écran
  5. Vous avez maintenant un enregistrement visuel des deux états

Scénario 3 : Créer des instructions étape par étape

La situation : Vous expliquez comment utiliser un logiciel à un collègue et avez besoin de supports visuels.

Pourquoi la capture d'écran est parfaite :

  • Montre exactement sur quels boutons cliquer
  • Capture les emplacements des menus
  • Aucune ambiguïté sur ce que vous voulez dire
  • Documentation professionnelle

Comment procéder :

  1. Parcourez vous-même le processus
  2. À chaque étape importante, prenez une capture d'écran
  3. Plus tard, organisez-les dans l'ordre avec des explications
  4. Partagez le guide complet

Scénario 4 : Capturer une image spécifique d'une vidéo

La situation : Vous regardez une vidéo et souhaitez enregistrer un moment particulier sous forme d'image.

Pourquoi la capture d'écran est meilleure que l'extraction d'image vidéo :

  • Qualité supérieure à l'extraction d'image vidéo
  • Capture instantanée (pas de traitement vidéo)
  • Moment exact souhaité
  • Fichier plus petit qu'un extrait vidéo

Comment procéder :

  1. Mettez la vidéo en pause à l'image exacte
  2. Prenez une capture d'écran de la zone du lecteur vidéo
  3. L'image est enregistrée en pleine qualité
  4. Vous pouvez partager juste ce moment

Scénario 5 : Sauvegarder du contenu Web

La situation : Vous trouvez des informations importantes sur un site Web susceptible de changer ou de disparaître.

Pourquoi la capture d'écran est parfaite :

  • Préserve la page exactement comme vous la voyez
  • Fonctionne même si le site tombe en panne
  • Capture la conception visuelle et la mise en page
  • Plus rapide que d'enregistrer toute la page

Comment procéder :

  1. Accédez à la page
  2. Prenez une capture d'écran de la section pertinente
  3. L'image est enregistrée de façon permanente
  4. Vous avez un enregistrement visuel pour toujours

Comparer les captures d'écran à d'autres fonctionnalités

Comprendre quand utiliser les captures d'écran par rapport aux autres fonctionnalités SeaMeet vous aide à travailler plus efficacement.

Capture d'écran vs enregistrement vidéo

AspectCapture d'écranEnregistrement vidéo
Ce qu'elle captureUn instantAction continue
Taille du fichierPetite (~2-5 Mo)Grande (~60 Mo/min)
Idéal pourContenu statique, texte, interfaceMouvement, processus, démos
Temps de captureInstantanéNécessite une durée
QualitéPrécision parfaite des pixelsCompressée, peut être floue
SonAucunPeut inclure de l'audio

Guide de décision :

  • Utilisez une capture d'écran quand : Vous avez besoin d'un moment précis, le texte est important, ou la taille du fichier compte
  • Utilisez la vidéo quand : Vous devez montrer un processus, le mouvement est important, ou vous avez besoin d'audio

Capture d'écran vs enregistrement Flashback

AspectCapture d'écranEnregistrement Flashback
TimingMoment présentPassé (déjà passé)
DuréeInstantanéeVariable (X dernières minutes)
Taille du fichierTrès petite (~2-5 Mo)Moyenne (~variable)
Idéal pourCapturer l'état actuelRécupérer des moments manqués
QualitéPleine résolutionQualité vidéo (compressée)

Guide de décision :

  • Utilisez une capture d'écran quand : Vous voyez quelque chose maintenant que vous voulez sauvegarder
  • Utilisez Flashback quand : Vous venez de manquer quelque chose et voulez récupérer les dernières minutes

Bonnes pratiques pour les captures d'écran

Suivez ces directives pour tirer le meilleur parti des captures d'écran.

Avant de prendre des captures d'écran

✅ Préparez votre écran

  • Fermez les fenêtres non pertinentes
  • Masquez les informations sensibles
  • Maximisez le contenu que vous voulez capturer
  • Assurez-vous d'un bon contraste et d'une bonne visibilité

✅ Tenez compte de l'objectif

  • Qui verra cette capture d'écran ?
  • Quelles informations doivent être visibles ?
  • Le texte sera-t-il lisible à la taille de la capture ?
  • Y a-t-il des données sensibles affichées ?

✅ Nettoyez votre bureau

  • Supprimez les fichiers personnels de la vue
  • Fermez les applications de chat
  • Masquez les zones de notification si nécessaire
  • Présentez une apparence professionnelle

Lors de la prise de captures d'écran

✅ Soyez précis dans la sélection

  • Capturez exactement ce dont vous avez besoin (ni plus, ni moins)
  • Incluez le contexte si cela aide à la compréhension
  • Évitez de couper les éléments d'interface importants
  • Laissez une petite marge autour du contenu

✅ Faites attention à la résolution

  • Résolution plus élevée = plus de détails
  • Mais taille de fichier plus grande
  • Tenez compte de l'utilisation de la capture d'écran
  • 1080p est généralement suffisant pour la plupart des usages

✅ Vérifiez avant de terminer

  • Avez-vous capturé la bonne zone ?
  • Le contenu est-il clairement visible ?
  • Des informations sensibles ont-elles été incluses accidentellement ?
  • Le texte est-il lisible ?

Après avoir pris des captures d'écran

✅ Renommez de manière descriptive Au lieu de : Screenshot_20260209_143052.png Essayez : Photoshop_Erreur_Calques.png ou Site_Web_Page_Accueil.png

✅ Organisez régulièrement

  • Créez des dossiers par projet ou sujet
  • Supprimez les captures temporaires/de test
  • Sauvegardez les captures importantes
  • Archivez les anciennes captures dont vous n'avez plus besoin

✅ Vérifiez avant de partager

  • Ouvrez la capture d'écran et vérifiez la qualité
  • Vérifiez s'il y a des informations sensibles
  • Assurez-vous qu'elle montre clairement ce que vous vouliez
  • Recadrez ou annotez si nécessaire

Dépannage des problèmes de capture d'écran

"Les captures d'écran n'apparaissent pas dans la barre latérale"

Causes possibles et solutions :

  1. Vérifiez que l'analyse est terminée

    • Cliquez sur le bouton d'actualisation dans la barre latérale
    • Attendez quelques secondes que l'analyse se termine
    • Les nouvelles captures d'écran devraient apparaître

  2. Vérifiez l'emplacement du fichier

    • Les captures d'écran doivent se trouver dans Documents/SeaMeet/Screenshots/
    • Vérifiez que le dossier existe
    • Assurez-vous que les fichiers PNG s'y trouvent

  3. Vérifiez les autorisations de fichiers

    • SeaMeet a besoin de l'autorisation de lire le dossier
    • Sur macOS : Vérifiez Préférences système → Sécurité et confidentialité → Fichiers et dossiers
    • Sur Windows : Assurez-vous qu'aucun antivirus ne bloque l'accès

  4. Redémarrez SeaMeet

    • Parfois, une nouvelle analyse est nécessaire
    • Fermez et rouvrez l'application
    • Vérifiez si les captures d'écran apparaissent

"La qualité de la capture d'écran semble mauvaise"

Solutions :

  1. Les captures d'écran sont toujours en pleine qualité

    • SeaMeet enregistre le PNG à 100 % de qualité
    • La visionneuse affiche le fichier d'origine
    • Si la qualité semble mauvaise, le contenu source peut être de faible résolution

  2. Vérifiez la mise à l'échelle de votre écran

    • Certains ordinateurs portables utilisent une mise à l'échelle de 125 % ou 150 %
    • Cela peut affecter la netteté apparente
    • La capture d'écran capture ce que vous voyez (mis à l'échelle)

  3. Vérifiez le contenu d'origine

    • Si vous capturez une vidéo, la vidéo peut être de faible résolution
    • Les captures d'écran ne peuvent pas ajouter de détails qui ne sont pas là
    • Elles capturent exactement ce qui est à l'écran

"Je ne trouve pas mes captures d'écran sur le disque"

Solutions :

  1. Vérifiez l'emplacement par défaut

    • Windows : C:\Users\[VotreNom]\Documents\SeaMeet\Screenshots\
    • macOS : /Users/[VotreNom]/Documents/SeaMeet/Screenshots/

  2. Recherchez le nom du fichier

    • Recherchez les fichiers commençant par "Screenshot_"
    • Utilisez la recherche de fichiers de votre système
    • Filtrez par fichiers PNG

  3. Vérifiez les paramètres SeaMeet

    • Vous pouvez modifier l'emplacement de stockage dans Paramètres → Storage
    • Vérifiez le chemin du dossier de captures d'écran qui y est affiché

"Copier dans le presse-papiers ne fonctionne pas"

Solutions :

  1. Essayez le bouton plutôt que le clavier

    • Cliquez sur le bouton "Copier" dans la visionneuse
    • Parfois, le raccourci clavier ne fonctionne pas

  2. Vérifiez les autorisations du presse-papiers

    • Certains logiciels de sécurité bloquent l'accès au presse-papiers
    • Essayez de redémarrer SeaMeet
    • Testez avec une autre application

  3. Vérifiez que le fichier existe

    • Si la capture d'écran a été déplacée ou supprimée, la copie ne fonctionnera pas
    • Ouvrez l'emplacement du fichier pour confirmer son existence
    • Réimportez si nécessaire

"Le bouton Partager n'apparaît pas"

C'est normal sur Windows et Linux :

  • Le bouton Partager n'apparaît que sur macOS
  • macOS dispose d'une API SharingService intégrée
  • Windows et Linux n'ont pas de système de partage standardisé
  • Utilisez Copier puis collez à la place sur ces plateformes
