Guide de configuration BYOK - Configuration de vos fournisseurs IA

Chapitre 36 : Guide de configuration BYOK — Configuration de vos fournisseurs IA

Pensez à BYOK (Bring Your Own Key) comme apporter vos propres grains de café dans un café qui a la machine à espresso — SeaMeet fournit le moteur d'extraction et d'analyse, vous fournissez les identifiants d'accès IA. Cela garde vos données circulant directement entre vous et votre fournisseur d'IA choisi, sans relais tiers.

Ce chapitre vous guide à travers la configuration des deux composants requis : une clé Résumé IA (Gemini) et un fournisseur Agent IA (GitHub Copilot ou Claude Code). Il couvre également un avantage qui surprend souvent les nouveaux abonnés — votre plan BYOK Pro inclut également la synchronisation gratuite entre appareils via GitHub, pas seulement l'accès IA.

Inclut la synchronisation GitHub

À partir de v2.1.x, chaque abonnement BYOK Pro est livré avec la synchronisation entre appareils de notes et wikis via votre propre dépôt GitHub privé — sans coût supplémentaire, un dépôt par espace de travail, sans limite de stockage. La synchronisation était auparavant invisible sur les écrans de mise à niveau ; elle est maintenant exposée sur le hero de valeur Pre-Subscribe, la carte du plan, la FAQ BYOK Explainer et l'écran des paramètres Sync.

En quoi cela diffère du plan dédié Sync Pro : BYOK synchronise uniquement le texte léger (notes + wiki) via votre propre GitHub. Sync Pro est un service géré séparément qui synchronise tout — notes, audio, vidéo et captures d'écran — via l'infrastructure de SeaMeet. La plupart des utilisateurs BYOK n'ont besoin que de la synchronisation de texte déjà incluse.

Voir Chapitre 38 : Synchronisation GitHub pour la procédure complète.

Objectifs du chapitre

Après avoir lu ce chapitre, vous serez capable de :

  • Comprendre quelles clés sont nécessaires et pourquoi
  • Obtenir une clé API Gemini gratuite depuis Google AI Studio
  • Installer et configurer GitHub Copilot CLI (niveau gratuit)
  • Alternativement installer et configurer Claude Code CLI
  • Configurer la synchronisation GitHub qui est groupée avec votre abonnement (Ch 38)
  • Vérifier que les deux composants fonctionnent
  • Mettre à jour ou supprimer une clé au besoin

Récapitulatif de la proposition de valeur

Ce que couvre l'abonnement BYOK Pro à 4,99 $/mois :

  • Confidentialité — les données vont directement de votre appareil à Google / Anthropic / OpenAI ; les serveurs SeaMeet ne les voient jamais.
  • Qualité — choisissez le meilleur modèle par travail.
  • Contrôle des coûts — payez les fournisseurs directement ; la plupart des utilisateurs restent sur le niveau gratuit de Gemini.
  • Souveraineté — les clés vivent dans votre trousseau OS ; révoquez à tout moment.
  • Synchronisation gratuite et privée — sauvegardez les notes et wiki dans votre propre dépôt GitHub privé.

Où vous le verrez dans l'application

Ces cinq avantages sont renforcés à chaque point de contact de mise à niveau BYOK via le BYOK Value Hero partagé — sur l'explicateur Pre-Subscribe, le reçu post-abonnement, Paramètres → IA, les Locked Feature Cards qui apparaissent quand un utilisateur gratuit clique sur une fonctionnalité bloquée par l'IA (transcription, résumé, éléments d'action, synthèse de notes, liste wiki, IA de capture d'écran), et la bannière incitative des paramètres Sync.

Partie A : Résumé IA — Clé API Gemini

Pourquoi Gemini ?

SeaMeet utilise le modèle Gemini de Google pour la transcription audio, les résumés de réunion, l'extraction des éléments d'action et les sorties IA associées. L'API Gemini a un niveau gratuit généreux qui couvre les charges de travail typiques de réunion.

Obtenir votre clé API Gemini

  1. Ouvrez votre navigateur et allez sur Google AI Studio (aistudio.google.com/apikey)
    • Connectez-vous avec votre compte Google si demandé
  2. Cliquez sur Create API Key
  3. Sélectionnez ou créez un projet Google Cloud lorsque demandé
  4. Copiez la clé générée (elle commence par AIza…)

Niveau gratuit : Le niveau gratuit de Gemini permet un nombre substantiel d'appels API par jour. Pour une utilisation typique d'enregistrement de réunion (quelques heures d'audio par semaine), le niveau gratuit est suffisant pour la plupart des utilisateurs.

Confidentialité : Votre audio est envoyé directement à l'API de Google pour transcription. Examinez la politique d'utilisation des données IA de Google si cela est une préoccupation pour votre cas d'utilisation.

Saisir votre clé dans SeaMeet

Pendant l'assistant de configuration (première fois après l'abonnement) :

  1. L'assistant s'ouvre automatiquement après votre abonnement
  2. L'étape 1 affiche la section Résumé IA
  3. Collez votre clé Gemini dans le champ de saisie
  4. La clé est validée automatiquement — vous verrez :
    • ✅ Coche verte : la clé est valide
    • ❌ X rouge : la clé est invalide ou mal copiée — vérifiez et recollez
  5. Cliquez sur Suivant pour passer à la configuration de l'Agent IA

Plus tard, via les Paramètres :

  1. Ouvrez Paramètres (⚙️)
  2. Naviguez jusqu'à IA → Clés API
  3. Trouvez la section Résumé IA
  4. Cliquez sur Modifier ou collez dans le champ de clé Gemini
  5. Cliquez sur Enregistrer — la clé se valide automatiquement

Tester et supprimer une clé

Dans les paramètres Clés API :

  • Bouton Tester — valide la clé contre l'API de Google
  • Bouton Supprimer — supprime la clé stockée ; les fonctionnalités Résumé IA seront indisponibles jusqu'à ce que vous ajoutiez une nouvelle clé

Si une clé échoue la validation, elle est automatiquement effacée pour empêcher le stockage d'une clé cassée. Il suffit d'en coller une nouvelle.

Partie B : Fournisseur Agent IA

Vous avez besoin d'au moins un fournisseur Agent IA. SeaMeet en prend actuellement en charge deux :

FournisseurCoûtLimiteIdéal pour
GitHub Copilot CLIGratuit (plan Copilot Free)50 chats/moisPour commencer, utilisation légère
Claude Code CLIPayant (Claude Pro ou Max)Limites supérieuresUtilisation régulière, utilisateurs avancés

Vous pouvez installer les deux et basculer entre eux depuis Paramètres → IA.

Option 1 : GitHub Copilot CLI (Gratuit)

GitHub Copilot CLI est un outil en ligne de commande que SeaMeet utilise comme son Agent IA. Le niveau gratuit GitHub Copilot inclut 50 requêtes d'agent par mois — suffisant pour une analyse occasionnelle de captures d'écran et des requêtes IA.

Étape 1 : Installer GitHub Copilot CLI

Choisissez la méthode qui correspond à votre système :

Windows (winget) :

winget install GitHub.cli

macOS (Homebrew) :

brew install gh

Linux (apt) :

sudo apt install gh

Remarque : SeaMeet affiche des boutons de copie à côté de chaque commande dans l'interface utilisateur de configuration — vous pouvez copier la commande exacte sans la taper. Pour d'autres distributions Linux, voir la documentation d'installation de GitHub CLI.

Étape 2 : S'authentifier avec GitHub

Après l'installation, ouvrez un terminal et exécutez :

gh auth login

Suivez les invites pour vous connecter à votre compte GitHub. Cela lie le CLI à votre compte GitHub et active les fonctionnalités Copilot.

Étape 3 : Détecter dans SeaMeet

  1. Dans la configuration des clés API de SeaMeet (ou Paramètres → IA → Clés API) :
  2. Trouvez la section Agent IA → tuile GitHub Copilot
  3. Cliquez sur Actualiser (🔄)
  4. SeaMeet recherche le CLI installé
  5. Si trouvé : le statut ✅ "Détecté" apparaît
  6. Si non trouvé : vérifiez votre installation et répétez

Limite de 50 chats/mois : Le plan gratuit Copilot est assez généreux pour commencer, mais si vous utilisez fréquemment l'Agent IA, vous pourriez atteindre la limite. Vous pouvez passer à GitHub Copilot Pro ou basculer vers Claude Code CLI pour des limites plus élevées.

Option 2 : Claude Code CLI (Payant)

Claude Code est l'outil CLI d'Anthropic. Il nécessite un abonnement Claude Pro ou Max mais a des limites d'utilisation plus élevées que le niveau gratuit Copilot.

Étape 1 : Installer Claude Code CLI

Windows (PowerShell) :

irm https://claude.ai/install.ps1 | iex

macOS / Linux :

curl -fsSL https://claude.ai/install.sh | sh

L'interface utilisateur de configuration de SeaMeet affiche des boutons de copie pour chaque commande d'installation.

Étape 2 : S'authentifier

Après l'installation, ouvrez un terminal et exécutez :

claude auth

Connectez-vous avec votre compte Anthropic (nécessite un plan Claude Pro ou Max).

Étape 3 : Détecter dans SeaMeet

  1. Dans Paramètres → IA → Clés API → Agent IA → tuile Claude Code
  2. Cliquez sur Actualiser (🔄) pour détecter le CLI installé
  3. ✅ "Détecté" apparaît lorsque trouvé

Choisir votre fournisseur par défaut

Si vous avez à la fois Copilot et Claude installés, SeaMeet vous permet de choisir lequel utiliser par défaut :

  1. Allez dans Paramètres → IA → Clés API
  2. Dans la section Agent IA, les deux tuiles s'afficheront comme détectées
  3. Utilisez le bouton radio ou le sélecteur pour choisir le fournisseur actif
  4. Le fournisseur sélectionné est utilisé pour toutes les requêtes Agent IA

Vous pouvez basculer les fournisseurs à tout moment depuis les Paramètres.

Vérifier que tout fonctionne

Après la configuration, effectuez une vérification rapide de bout en bout :

Test Résumé IA :

  1. Ouvrez n'importe quel enregistrement dans votre bibliothèque
  2. Cliquez sur AI Insights → Generate Summary
  3. S'il se termine sans erreur : ✅ La clé Gemini fonctionne

Test Agent IA :

  1. Prenez une capture d'écran avec SeaMeet
  2. Ouvrez-la dans la visionneuse de captures d'écran
  3. Cliquez sur l'onglet d'analyse IA et posez une question
  4. Si vous obtenez une réponse : ✅ Le fournisseur Agent IA fonctionne

Mettre à jour une clé

Pour mettre à jour votre clé Gemini :

  1. Paramètres → IA → Clés API → Résumé IA → Modifier
  2. Effacez l'ancienne clé et collez la nouvelle
  3. Cliquez sur Enregistrer

Pour mettre à jour votre fournisseur Agent :

  • Réexécutez les étapes d'installation/authentification du CLI si une clé a expiré
  • Cliquez sur Actualiser dans SeaMeet pour re-détecter
