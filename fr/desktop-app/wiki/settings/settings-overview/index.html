Vue d'ensemble des paramètres

Chapitre 18 : Vue d'ensemble des paramètres

Introduction

Bienvenue au centre de contrôle de SeaMeet ! Si l'interface principale est comme le cockpit où vous pilotez l'avion, le menu Paramètres est comme la baie de maintenance où vous affinez le moteur, ajustez les sièges et personnalisez votre expérience de vol. Ce chapitre vous montrera comment accéder au menu Paramètres et vous donnera une feuille de route de toutes les différentes catégories que vous y trouverez.

À la fin de ce chapitre, vous saurez exactement où trouver chaque paramètre dans SeaMeet et comprendrez ce que chaque catégorie contrôle. Considérez ceci comme votre visite d'orientation avant de plonger profondément dans chaque section spécifique.

Objectifs du chapitre

Après avoir lu ce chapitre, vous serez capable de :

  • Ouvrir le menu Paramètres depuis plusieurs emplacements dans SeaMeet
  • Comprendre les 10 catégories principales de paramètres et ce qu'elles contrôlent (y compris les nouveaux groupes Fonctionnalités IA et Synchronisation introduits dans la v2.1.0)
  • Naviguer rapidement entre les différentes sections de paramètres
  • Reconnaître les indicateurs visuels et icônes utilisés dans l'interface des paramètres
  • Savoir quand changer quels paramètres selon vos besoins

Que sont les paramètres et pourquoi sont-ils importants ?

Pensez aux paramètres SeaMeet comme aux préférences de votre smartphone. Vous n'avez pas besoin de les modifier pour utiliser les fonctionnalités de base, mais leur personnalisation fait fonctionner l'application exactement comme VOUS le souhaitez. C'est la différence entre porter une chemise taille unique et une chemise adaptée à vos mesures.

Les paramètres sont importants car ils vous permettent de :

Personnaliser votre expérience

  • Choisir votre langue préférée (16 options disponibles !)
  • Définir le mode clair ou sombre selon le confort de vos yeux
  • Choisir où vos enregistrements sont enregistrés
  • Configurer des raccourcis qui correspondent à votre mémoire musculaire

Optimiser les performances

  • Ajuster la qualité audio en fonction des capacités de votre microphone
  • Définir la résolution vidéo pour correspondre à votre écran et aux besoins de stockage
  • Activer ou désactiver les fonctionnalités en fonction de la puissance de votre ordinateur
  • Gérer l'utilisation de la mémoire pour l'enregistrement flashback

Assurer la fiabilité

  • Configurer la détection automatique afin de ne jamais manquer une réunion
  • Configurer les avertissements de stockage avant de manquer d'espace
  • Choisir les bons périphériques audio pour votre configuration
  • Configurer correctement les autorisations dès le départ

Résoudre les problèmes avant qu'ils ne surviennent

  • Ajuster le gain du microphone si les gens disent que vous êtes trop calme ou trop fort
  • Définir les modes d'enregistrement par défaut pour éviter d'oublier de changer
  • Configurer les options de démarrage automatique pour que l'enregistrement commence quand vous le souhaitez
  • Activer le mode faible mémoire si votre ordinateur est plus ancien ou plus lent

Comment ouvrir le menu Paramètres

SeaMeet vous offre plusieurs façons d'accéder aux Paramètres, tout comme vous pouvez déverrouiller votre téléphone avec un mot de passe, une empreinte digitale ou la reconnaissance faciale. Voici toutes les façons d'accéder à vos paramètres :

Méthode 1 : Depuis la barre latérale gauche

C'est la façon la plus courante d'accéder aux Paramètres. Regardez la barre latérale verticale sur le côté gauche de la fenêtre principale SeaMeet.

Étape par étape :

  1. Trouvez la barre latérale gauche avec les icônes pour Enregistrements, Vidéo, Flashback, etc.

  2. Recherchez l'icône Paramètres — elle ressemble à un engrenage ou une roue dentée (⚙️)

  3. Cliquez sur l'icône Paramètres

  4. La zone principale passera de l'affichage de vos enregistrements à l'affichage du panneau Paramètres

Référence visuelle :

┌─────────────────────────────────────────────────────────────┐
│  [🎤] [🎥] [📼] [🔍] [⚙️ Paramètres]                       │
│   Enr   Vid   Flash  Auto    ← Icône Paramètres ici !       │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │                                                      │  │
│  │        LE PANNEAU PARAMÈTRES S'OUVRE ICI             │  │
│  │                                                      │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘

Méthode 2 : Depuis la barre de menus (Windows)

Si vous êtes sur Windows, vous pouvez également accéder aux Paramètres via la barre de menus traditionnelle en haut de la fenêtre.

Étape par étape :

  1. Cliquez sur "File" dans la barre de menus supérieure

  2. Recherchez "Settings" ou "Preferences" dans le menu déroulant

  3. Cliquez dessus pour ouvrir le panneau Paramètres

Remarque : Cette méthode peut varier légèrement selon votre version de Windows et de SeaMeet.

Méthode 3 : Raccourci clavier (Windows)

Pour les amateurs de clavier, il y a un raccourci rapide :

Sur Windows : Appuyez sur Ctrl + Virgule (,)

C'est un raccourci courant dans de nombreuses applications Windows (y compris Microsoft Office et beaucoup d'autres), il peut donc déjà être dans votre mémoire musculaire.

Comment l'utiliser :

  1. Assurez-vous que SeaMeet est la fenêtre active (cliquez dessus si vous n'êtes pas sûr)
  2. Maintenez Ctrl enfoncé
  3. Tout en maintenant Ctrl, appuyez sur la touche virgule
  4. Les Paramètres s'ouvriront immédiatement

Méthode 4 : Depuis le menu de la barre des tâches (Windows)

SeaMeet s'exécute dans votre barre des tâches système (c'est la zone près de votre horloge avec toutes ces petites icônes). Vous pouvez également y accéder aux Paramètres.

Étape par étape :

  1. Recherchez l'icône SeaMeet dans votre barre des tâches système (coin inférieur droit de l'écran)

    • Vous devrez peut-être cliquer sur la petite flèche vers le haut pour voir les icônes cachées

  2. Cliquez avec le bouton droit sur l'icône SeaMeet

  3. Un menu contextuel apparaîtra avec diverses options

  4. Cliquez sur "Settings" dans le menu

Pourquoi utiliser cette méthode ?

  • Idéal lorsque SeaMeet est réduit
  • Accès rapide sans ouvrir la fenêtre principale
  • Parfait quand vous êtes pressé

Méthode 5 : Depuis le menu Floater

Souvenez-vous du widget de contrôle flottant (le Floater) du chapitre 14 ? Vous pouvez également y accéder aux Paramètres.

Étape par étape :

  1. Cliquez sur le Floater pour le développer (s'il est en mode compact)

  2. Recherchez une icône d'engrenage de paramètres ou une option de menu

  3. Cliquez dessus pour ouvrir les Paramètres

Remarque : L'emplacement exact peut varier en fonction de votre configuration Floater, mais l'option de paramètres est toujours accessible depuis la vue Floater développée.

L'interface Paramètres : Une visite

Une fois que vous avez ouvert les Paramètres, vous verrez un panneau bien organisé divisé en sections. Faisons un tour de ce que vous verrez :

Disposition globale

Le panneau Paramètres suit généralement cette structure :

┌─────────────────────────────────────────────────────────────┐
│  PARAMÈTRES                              [X] Fermer         │
├─────────────────────────────────────────────────────────────┤
│  Liste de catégories │  Paramètres de la catégorie sélec.   │
│                     │                                      │
│  ☐ General          │  ┌────────────────────────────────┐   │
│  ☐ Storage          │  │  Paramètre 1                   │   │
│  ☐ Audio            │  │  [Contrôle]                    │   │
│  ☐ Video            │  └────────────────────────────────┘   │
│  ☐ Flashback        │  ┌────────────────────────────────┐   │
│  ☐ AI Features ✨   │  │  Paramètre 2                   │   │
│  ☐ Auto-Recording   │  │  [Contrôle]                    │   │
│  ☐ Sync 🔄          │  └────────────────────────────────┘   │
│  ☐ Language         │                                      │
│  ☐ About            │                                      │
│                     │                                      │
│  [Rechercher...]    │  [Appliquer] [Annuler] [Réinitialiser]│
└─────────────────────────────────────────────────────────────┘

Nouveau dans v2.1.0 : Le groupe AI Features héberge vos contrôles de transcription/extraction/résumé, le panneau AI Summary Templates (avec la bascule Auto-detect summary template), et — lorsqu'activé — les paramètres AI Agent & Cowork. Le groupe Sync héberge GitHub Sync & Backup.

Côté gauche : Liste de catégories

  • Affiche toutes les catégories de paramètres disponibles
  • Cliquez sur n'importe quelle catégorie pour voir ses paramètres
  • La catégorie actuellement sélectionnée est mise en surbrillance
  • Certaines catégories ont des icônes à côté de leurs noms

Côté droit : Contenu des paramètres

  • Affiche tous les paramètres de la catégorie sélectionnée
  • Chaque paramètre a une étiquette expliquant ce qu'il fait
  • Les paramètres utilisent différents types de contrôles :
    • Bascules (interrupteurs marche/arrêt) — pour les choix oui/non
    • Menus déroulants — pour choisir parmi plusieurs options
    • Champs de texte — pour saisir des chemins ou des noms de fichiers
    • Curseurs — pour ajuster des valeurs comme le volume
    • Boutons — pour des actions comme "Parcourir" ou "Réinitialiser"

Bas : Boutons d'action

  • Appliquer — enregistre vos modifications (parfois automatique)
  • Annuler — annule les modifications et ferme les paramètres
  • Réinitialiser — restaure tous les paramètres aux valeurs par défaut
  • Rechercher — trouvez rapidement des paramètres spécifiques (dans certaines versions)

Les 10 catégories de paramètres expliquées

SeaMeet organise les paramètres en 10 catégories logiques. Pensez-y comme des tiroirs dans un classeur — chacun contient des éléments connexes. Deux d'entre eux — AI Features et Sync — ont été ajoutés dans la v2.1.0 pour regrouper les nouveaux contrôles de modèles de résumé IA et la synchronisation entre appareils basée sur GitHub :

Catégorie 1 : Paramètres généraux

Icône : Généralement une icône d'engrenage ou de maison Ce qu'elle contrôle : Le comportement et l'apparence de base de l'application

Paramètres typiques inclus :

  • Comportement de démarrage — SeaMeet devrait-il s'ouvrir automatiquement au démarrage de votre ordinateur ?
  • Réduire dans la barre des tâches — SeaMeet doit-il continuer à fonctionner lorsque vous fermez la fenêtre ?
  • Sélection du thème — Mode clair, mode sombre ou automatique (suit le système)
  • Préférences de notification — Quels événements doivent déclencher des notifications ?
  • Paramètres de mise à jour — SeaMeet doit-il vérifier automatiquement les mises à jour ?

Quand utiliser cette catégorie :

  • Lorsque vous installez SeaMeet pour la première fois et souhaitez définir les préférences de base
  • Lorsque vous voulez changer l'apparence et la convivialité de l'application
  • Lorsque vous voulez contrôler le comportement de SeaMeet en arrière-plan
  • Lors de la configuration du démarrage automatique

Analogie : C'est comme ajuster les paramètres de base de votre voiture — les phares doivent-ils s'allumer automatiquement ? Doit-elle se souvenir de la position de votre siège ? Doit-elle sonner quand vous laissez les clés à l'intérieur ?

Catégorie 2 : Paramètres de stockage

Icône : Généralement une icône de disque dur ou de dossier Ce qu'elle contrôle : Où et comment vos enregistrements sont enregistrés

Paramètres typiques inclus :

  • Emplacement de sauvegarde — Dans quel dossier les enregistrements doivent-ils aller ?
  • Gestion du stockage — Nettoyage automatique des anciens enregistrements
  • Organisation des fichiers — Comment les fichiers doivent-ils être nommés et triés ?
  • Avertissements d'espace disque — Alerte quand vous manquez d'espace
  • Paramètres de sauvegarde — Les enregistrements doivent-ils être sauvegardés dans le stockage cloud ?

Quand utiliser cette catégorie :

  • Lorsque vous voulez changer l'emplacement de sauvegarde des enregistrements (comme les déplacer vers un disque externe)
  • Lorsque vous manquez d'espace disque et devez gérer le stockage
  • Lorsque vous voulez organiser les enregistrements d'une manière spécifique
  • Lors de la configuration du nettoyage automatique pour éviter l'accumulation

Analogie : C'est comme organiser votre placard — décider quel tiroir reçoit quels vêtements, comment étiqueter les boîtes et quand donner les vieux articles pour faire de la place pour les nouveaux.

Remarque importante : Ceci est couvert en détail au chapitre 19 (Paramètres de stockage), où nous parcourrons chaque option étape par étape.

Catégorie 3 : Paramètres audio

Icône : Généralement une icône de microphone ou de haut-parleur Ce qu'elle contrôle : Tout ce qui concerne l'enregistrement et la lecture du son

Paramètres typiques inclus :

  • Microphone par défaut — Quel microphone utiliser pour l'enregistrement
  • Gain du microphone — À quel point votre voix doit être forte enregistrée
  • Source audio système — Quelle sortie audio capturer
  • Avertissements Bluetooth — Alertes lors de l'utilisation de microphones Bluetooth
  • Format audio — Format préféré pour les enregistrements audio (MP3, WAV, etc.)
  • Fréquence d'échantillonnage — Niveau de qualité audio (44.1kHz, 48kHz, etc.)

Quand utiliser cette catégorie :

  • Lorsque les gens disent que vous êtes trop calme ou trop fort dans les enregistrements
  • Lorsque vous avez plusieurs microphones et voulez en choisir un par défaut
  • Lorsque vous utilisez des écouteurs Bluetooth et avez besoin d'avertissements de latence
  • Lorsque vous voulez changer la qualité audio ou les formats de fichiers
  • Lors du dépannage des problèmes d'enregistrement audio

Analogie : C'est comme ajuster le système sonore dans une salle de concert — choisir quels microphones utiliser, définir les bons niveaux de volume et s'assurer que l'acoustique fonctionne parfaitement pour la performance.

Remarque importante : Ceci est couvert en détail au chapitre 20 (Paramètres audio), où nous plongerons profondément dans la sélection du microphone, le contrôle du gain et plus encore.

Catégorie 4 : Paramètres vidéo

Icône : Généralement une icône de caméra vidéo ou de moniteur Ce qu'elle contrôle : Tout ce qui concerne l'enregistrement d'écran

Paramètres typiques inclus :

  • Mode d'enregistrement par défaut — Plein écran, fenêtre ou région
  • Qualité vidéo — Résolution (1080p, 720p, 480p)
  • Fréquence d'images — À quel point la vidéo doit être fluide (30fps, 60fps)
  • Sélection du moniteur — Quel écran enregistrer (si vous en avez plusieurs)
  • Format vidéo — Format préféré pour les fichiers vidéo (MP4, WebM, etc.)
  • Accélération matérielle — Utiliser le GPU pour de meilleures performances
  • Enregistrement du curseur — Le pointeur de souris doit-il être visible ?
  • Effets de curseur — Surligner les clics, modifier la taille du curseur, etc.

Quand utiliser cette catégorie :

  • Lorsque vous voulez définir un mode d'enregistrement par défaut pour économiser des clics
  • Lorsque vous devez équilibrer qualité et taille de fichier
  • Lorsque vous avez plusieurs moniteurs et devez spécifier lequel enregistrer
  • Lors de l'enregistrement de gameplay et avez besoin de fréquences d'images élevées (60fps)
  • Lors de la création de tutoriels et que vous voulez des effets de curseur

Analogie : C'est comme installer une caméra de cinéma — choisir la qualité du film, décider quel objectif utiliser, définir la fréquence d'images pour une action fluide et décider de montrer ou non la main du caméraman dans le plan.

Remarque importante : Ceci est couvert en détail au chapitre 21 (Paramètres vidéo), où nous expliquerons tous les termes techniques et vous aiderons à choisir les bons paramètres.

Catégorie 5 : Paramètres Flashback

Icône : Généralement une flèche circulaire ou icône d'horloge (représentant le "rembobinage") Ce qu'elle contrôle : La fonctionnalité d'enregistrement machine à remonter le temps

Paramètres typiques inclus :

  • Démarrage automatique de Flashback — Flashback doit-il démarrer automatiquement au lancement de SeaMeet ?
  • Durée du tampon — Jusqu'où dans le temps conserver (10-120 secondes)
  • Longueur du tampon audio — Combien d'audio garder (fixé à 30 secondes)
  • Qualité vidéo — Résolution pour la vidéo Flashback (souvent inférieure à l'enregistrement régulier)
  • Mode faible mémoire — Réduire l'utilisation de la mémoire pour les ordinateurs plus anciens
  • Persistance du tampon — Garder le tampon lors du changement d'application ?

Quand utiliser cette catégorie :

  • Lorsque vous voulez que Flashback soit toujours prêt (démarrage auto)
  • Lorsque vous devez équilibrer jusqu'où vous pouvez sauvegarder vs l'utilisation de la mémoire
  • Lorsque votre ordinateur est plus ancien et vous devez économiser la RAM
  • Lorsque vous voulez personnaliser le comportement de Flashback

Analogie : C'est comme configurer le DVR d'une caméra de sécurité — décider combien de jours de séquences conserver, définir la qualité d'enregistrement et gérer l'espace de stockage pour l'enregistrement constant.

Remarque importante : Ceci est couvert en détail au chapitre 22 (Paramètres Flashback), où nous vous aiderons à trouver l'équilibre parfait entre longueur du tampon et performances.

Catégorie 6 : Fonctionnalités IA (nouveau dans v2.1.0)

Icône : Une icône violette d'étincelle/baguette magique Ce qu'elle contrôle : Tout ce qui alimente le côté IA de SeaMeet — transcription en direct, extraction post-réunion, modèles de résumé et (optionnellement) l'Agent IA intégré à l'application

Le groupe AI Features contient trois éléments de menu :

  • AI Transcription, Extraction, Summary, Wiki — votre fournisseur de modèle, la saisie de clé API BYOK, la langue du résumé et quels pipelines IA s'exécutent automatiquement après un enregistrement. Couvert en détail au chapitre 36 (Bring Your Own Key — BYOK).
  • AI Summary Templates — la nouvelle bibliothèque de modèles livrée dans la v2.1.0 (48 modèles intégrés sur 8 catégories : Équipe et Management, Projet et Agile, Ventes et Client, RH et Recrutement, Éducation et Formation, Médical et Santé, Légal et Conformité, et Événements et Médias). Inclut la bascule Auto-detect summary template (par défaut ON) — lorsque activée, SeaMeet classifie la transcription de chaque réunion et choisit le modèle le mieux adapté ; lorsque désactivée, chaque enregistrement utilise Meeting Minutes et aucun appel de classificateur n'est effectué. Couvert en détail au chapitre 33 (AI Summary Templates).
  • AI Agent & Cowork — visible uniquement lorsque l'indicateur de fonctionnalité de l'agent est activé. Héberge la configuration de l'agent de chat (Fournisseur, valeurs par défaut Ask/Code/Plan). Couvert en détail au chapitre 37 (Copilot & AI Agent).

Quand utiliser cette catégorie :

  • Lorsque vous voulez configurer BYOK avec votre propre clé API Gemini
  • Lorsque vous voulez basculer globalement le comportement Auto-detect template
  • Lorsque vous voulez parcourir la bibliothèque de modèles installés sans ouvrir un enregistrement
  • Lors de la configuration des valeurs par défaut de l'AI Agent

Analogie : C'est la salle de contrôle IA — le panneau où vous choisissez quel "cerveau" SeaMeet est connecté et avec quelle agressivité il doit penser pour vous.

Catégorie 7 : Paramètres d'enregistrement automatique

Icône : Généralement une loupe ou icône de robot/automatisation Ce qu'elle contrôle : Détection et enregistrement automatiques des réunions

Paramètres typiques inclus :

  • Détection automatique activée — Interrupteur marche/arrêt principal pour la fonctionnalité
  • Sensibilité de détection — À quel point la détection doit être agressive
  • Action par défaut — Démarrer l'enregistrement immédiatement ou simplement notifier ?
  • Autorisations par application — Quelles applications peuvent déclencher l'enregistrement automatique
  • Méthodes de détection — Quels signaux surveiller (titre de fenêtre, audio, etc.)
  • Délai avant démarrage — Attendre quelques secondes après la détection pour commencer
  • Actions post-réunion — Quoi faire à la fin d'une réunion

Quand utiliser cette catégorie :

  • Lors de la configuration de SeaMeet pour la première fois et de l'activation de la détection automatique
  • Lorsque vous voulez affiner quelles applications déclenchent l'enregistrement
  • Lorsque vous trouvez la détection automatique trop sensible (ou pas assez sensible)
  • Lorsque vous voulez que SeaMeet attende un moment avant de commencer
  • Lors de la personnalisation de ce qui se passe après la fin des réunions

Analogie : C'est comme former un assistant intelligent — lui apprendre à reconnaître quand vous êtes en réunion, décider quelles réunions comptent et lui dire comment répondre lorsqu'il en détecte une.

Remarque importante : Ceci est couvert en détail au chapitre 23 (Paramètres d'enregistrement automatique), où nous parcourrons la configuration des autorisations pour toutes les 47+ applications prises en charge.

Catégorie 8 : Synchronisation (nouveau dans v2.1.0)

Icône : Logo GitHub / icône cloud Ce qu'elle contrôle : Sauvegarde cloud privée optionnelle de vos notes et wiki via votre propre dépôt GitHub

Paramètres typiques inclus :

  • Set Up GitHub Sync / Authorize GitHub — flux OAuth en un clic qui crée un dépôt privé par espace de travail
  • Synchronisation automatique lors des modifications — valider et pousser pendant que vous éditez (par défaut ON)
  • Synchroniser au démarrage — récupérer les dernières modifications au lancement de SeaMeet (par défaut ON)
  • Intervalle de synchronisation — à quelle fréquence les modifications locales sont regroupées en un commit (1, 5, 10 ou 30 minutes)
  • Sync Now — déclencheur manuel de commit + push
  • Résolution de conflit — édition manuelle ou fusion assistée par Agent lorsque deux appareils éditent le même fichier
  • Ré-autoriser / Déconnecter — actualiser OAuth GitHub ou délier l'espace de travail

Portée importante : La synchronisation couvre les notes et le wiki uniquement (fichiers .md). Les enregistrements audio, les enregistrements vidéo et les captures d'écran restent sur votre appareil — ils ne sont jamais poussés vers GitHub. C'est ce qui permet à un seul dépôt GitHub de 1 Go du plan gratuit de contenir environ 200 000 à 500 000 notes.

Quand utiliser cette catégorie :

  • Lors de la configuration de l'accès multi-appareils à vos notes et wiki pour la première fois
  • Lorsque vous voulez que vos notes soient sauvegardées dans un dépôt GitHub privé sans frais
  • Lors de la résolution d'un conflit de synchronisation entre deux appareils

Comprendre les contrôles de paramètres

Différents paramètres utilisent différents types de contrôles. Voici un guide pour reconnaître et utiliser chaque type :

Interrupteurs à bascule (marche/arrêt)

À quoi ils ressemblent : Un interrupteur horizontal qui glisse à gauche (off) ou à droite (on). Souvent coloré quand activé (généralement bleu ou vert).

Nom du paramètre     [━━●──]   ← Position off
                      [──●━━]   ← Position on (coloré)

Comment l'utiliser :

  • Cliquez sur l'interrupteur pour le basculer
  • L'interrupteur glissera et changera de couleur
  • Le changement prend généralement effet immédiatement

Exemples dans SeaMeet :

  • Démarrage auto de Flashback
  • Réduire dans la barre des tâches système
  • Activer la détection automatique
  • Afficher le curseur dans les enregistrements

Analogie : Comme un interrupteur d'éclairage sur votre mur — basculez-le d'un côté pour allumer, de l'autre pour éteindre.

Menus déroulants

À quoi ils ressemblent : Un champ rectangulaire affichant la sélection actuelle avec une flèche vers le bas à droite.

Qualité d'enregistrement [1080p HD     ▼]
                          ↑ Valeur     ↑ Cliquer pour voir
                            actuelle     toutes les options

Comment l'utiliser :

  1. Cliquez sur le menu déroulant (ou la flèche)
  2. Une liste d'options apparaît en dessous
  3. Cliquez sur l'option souhaitée
  4. Le menu déroulant se ferme avec votre nouvelle sélection affichée

Exemples dans SeaMeet :

  • Qualité vidéo (1080p, 720p, 480p)
  • Fréquence d'images (30fps, 60fps)
  • Format audio (MP3, WAV, WebM)
  • Mode d'enregistrement par défaut (Plein écran, Fenêtre, Région)
  • Langue d'affichage (16 options)

Analogie : Comme un menu de restaurant — vous voyez la sélection actuelle dans votre assiette, mais vous pouvez ouvrir le menu pour choisir autre chose.

Champs de saisie de texte

À quoi ils ressemblent : Une boîte rectangulaire vide ou pré-remplie où vous pouvez taper.

Emplacement de sauvegarde [C:\Users\Vous\Enregistrements] [Parcourir...]
                            ↑ Cliquer pour taper       ↑ Ou cliquer pour
                                                         parcourir

Comment l'utiliser :

  1. Cliquez à l'intérieur du champ de texte
  2. Tapez votre texte (ou effacez d'abord le texte existant)
  3. Appuyez sur Tab ou cliquez ailleurs lorsque vous avez terminé

Fonctionnalités spéciales :

  • Bouton Parcourir — Souvent à côté des champs de chemin, ouvre un navigateur de fichiers
  • Texte de placeholder — Texte gris affichant un exemple d'entrée
  • Validation — Peut devenir rouge si vous entrez quelque chose d'invalide

Exemples dans SeaMeet :

  • Chemin du répertoire de sauvegarde
  • Modèle de nommage de fichier
  • Raccourcis clavier personnalisés
  • Nom du périphérique microphone (parfois)

Analogie : Comme remplir un formulaire chez le médecin — vous écrivez des informations dans des champs vides.

Curseurs

À quoi ils ressemblent : Une barre horizontale avec une poignée que vous pouvez glisser à gauche ou à droite.

Gain du microphone   [━●━━━━━━━━━━━] 45%
                       ↑ Glisser cette poignée
                         à gauche (plus calme)
                         ou à droite (plus fort)

Comment l'utiliser :

  1. Cliquez et maintenez la poignée du curseur
  2. Glissez-la à gauche pour diminuer la valeur
  3. Glissez-la à droite pour augmenter la valeur
  4. Relâchez quand vous êtes satisfait

Alternative : Cliquez n'importe où sur la barre du curseur pour sauter à cette position

Exemples dans SeaMeet :

  • Gain/volume du microphone
  • Sensibilité de détection (pour l'enregistrement automatique)
  • Durée du tampon (pour Flashback)
  • Équilibre qualité/compression

Analogie : Comme un bouton de volume sur une chaîne stéréo — tournez à gauche pour plus calme, à droite pour plus fort.

Boutons

À quoi ils ressemblent : Boutons rectangulaires ou arrondis avec des étiquettes de texte.

[Vérifier les mises à jour] [Réinitialiser] [Parcourir...]

Comment l'utiliser :

  • Cliquez simplement sur le bouton une fois
  • Quelque chose se passe immédiatement (boîte de dialogue ouverte, action effectuée, etc.)

Types de boutons :

  • Boutons d'action — Effectuent une action (Vérifier les mises à jour, Parcourir)
  • Boutons de réinitialisation — Restaurent les valeurs par défaut (Réinitialiser)
  • Boutons de navigation — Vont vers d'autres écrans (Paramètres avancés)
  • Boutons de confirmation — Enregistrent ou annulent les modifications (Appliquer, OK, Annuler)

Exemples dans SeaMeet :

  • Parcourir (pour choisir des dossiers)
  • Réinitialiser (pour n'importe quelle catégorie)
  • Vérifier les mises à jour (dans la section À propos)
  • Appliquer/Enregistrer les modifications
  • Tester le microphone (dans les paramètres audio)

Analogie : Comme les boutons d'ascenseur — appuyez une fois et l'ascenseur fait quelque chose (monte, descend, ouvre les portes).

Cases à cocher

À quoi elles ressemblent : Un petit carré qui peut être coché (✓) ou vide.

☐ Démarrer SeaMeet au démarrage de l'ordinateur
☑ Réduire dans la barre des tâches à la fermeture
☐ Afficher les notifications d'enregistrement

Comment les utiliser :

  • Cliquez sur la case à cocher pour la basculer
  • Une coche apparaît quand activée
  • Cliquez à nouveau pour décocher

Différence avec les bascules :

  • Les cases à cocher sont généralement utilisées lorsque vous pouvez sélectionner plusieurs options
  • Les bascules sont utilisées pour les choix uniques marche/arrêt
  • SeaMeet utilise principalement des bascules, mais vous pouvez voir des cases à cocher dans les paramètres avancés

Analogie : Comme une liste de tâches — vous cochez les éléments que vous avez terminés.

Comportement des paramètres : Immédiat vs Appliqué

Tous les paramètres ne fonctionnent pas de la même manière lorsque vous les modifiez. Il y a deux comportements principaux :

Paramètres immédiats

Ceux-ci prennent effet dès que vous les modifiez — pas besoin de cliquer sur "Appliquer" ou "Enregistrer".

Exemples :

  • Changements de thème (mode clair/sombre)
  • Sélection de langue
  • Interrupteurs à bascule (la plupart d'entre eux)
  • Curseurs de volume/gain (vous entendez le changement en temps réel)

Comment les reconnaître :

  • Les changements se produisent instantanément
  • Aucun bouton "Appliquer" nécessaire
  • Habituellement des changements visuels ou des bascules simples

Paramètres appliqués

Ceux-ci nécessitent que vous cliquiez sur "Appliquer", "OK" ou "Enregistrer" avant qu'ils ne prennent effet.

Exemples :

  • Chemin d'emplacement de sauvegarde
  • Mode d'enregistrement par défaut
  • Configurations audio/vidéo complexes
  • Certains paramètres d'autorisation

Comment les reconnaître :

  • Un bouton "Appliquer" ou "Enregistrer" est présent
  • Vous pouvez voir des indicateurs de "modifications non enregistrées"
  • Les changements ne se produisent pas jusqu'à ce que vous confirmiez

Important : Si vous modifiez les paramètres et cliquez sur "Annuler", vos modifications seront supprimées ! Cliquez toujours sur "Appliquer" ou "OK" si vous voulez conserver vos modifications.

La fonctionnalité de recherche (si disponible)

Certaines versions de SeaMeet incluent une zone de recherche en haut du panneau Paramètres. C'est incroyablement utile !

Comment utiliser la recherche :

  1. Recherchez une zone de recherche (indique généralement "Rechercher des paramètres..." ou a une icône de loupe)

  2. Cliquez dans la zone de recherche et tapez des mots-clés :

    • "microphone" → Affiche tous les paramètres liés au microphone
    • "sauvegarde" → Affiche les paramètres de stockage et d'emplacement de sauvegarde
    • "qualité" → Affiche les paramètres de qualité vidéo et audio

  3. Au fur et à mesure que vous tapez, la liste des paramètres se filtre pour n'afficher que les éléments correspondants

  4. Cliquez sur un résultat pour sauter directement à ce paramètre

Pourquoi la recherche est utile :

  • Découvrez des paramètres connexes que vous ne saviez pas exister
  • Idéal lorsque vous n'êtes pas sûr de la catégorie d'un paramètre
  • Fait gagner du temps lorsque vous savez exactement ce que vous voulez changer

Flux de travail courants des paramètres

Voici quelques scénarios typiques et les étapes exactes pour les gérer :

Scénario 1 : Configuration initiale

Vous êtes nouveau sur SeaMeet et voulez configurer les bases :

  1. Ouvrez les Paramètres (cliquez sur l'icône d'engrenage dans la barre latérale gauche)

  2. Allez dans Général

    • Définissez le thème selon vos préférences
    • Activez "Réduire dans la barre des tâches" si souhaité
    • Activez "Démarrer avec l'ordinateur" si souhaité

  3. Allez dans Stockage

    • Vérifiez ou changez l'emplacement de sauvegarde
    • Configurez les avertissements d'espace disque

  4. Allez dans Audio

    • Sélectionnez votre microphone par défaut
    • Testez le microphone et ajustez le gain
    • Vérifiez les avertissements Bluetooth si vous utilisez des écouteurs sans fil

  5. Allez dans Langue

    • Sélectionnez votre langue d'affichage préférée

  6. Cliquez sur Appliquer pour enregistrer toutes les modifications

  7. Allez dans À propos pour noter votre numéro de version (utile pour le support)

Scénario 2 : Changer l'emplacement de sauvegarde des enregistrements

Votre lecteur C: se remplit et vous voulez déplacer les enregistrements vers un lecteur externe :

  1. Ouvrez les Paramètres

  2. Cliquez sur Stockage dans la barre latérale gauche

  3. Trouvez "Emplacement de sauvegarde" ou "Répertoire d'enregistrement"

  4. Cliquez sur le bouton "Parcourir"

  5. Naviguez jusqu'à votre lecteur externe dans le navigateur de fichiers

    • Exemple : D:\SeaMeet Recordings

  6. Sélectionnez ou créez un dossier

  7. Cliquez sur OK dans le navigateur de fichiers

  8. Cliquez sur Appliquer dans les Paramètres

  9. Optionnel : Déplacez vos enregistrements existants vers le nouvel emplacement à l'aide de l'Explorateur de fichiers

Scénario 3 : Configurer la détection automatique

Vous voulez que SeaMeet détecte automatiquement les réunions Zoom :

  1. Ouvrez les Paramètres

  2. Cliquez sur Enregistrement automatique

  3. Activez "Détection automatique" (interrupteur à bascule)

  4. Trouvez Zoom dans la liste des applications

  5. Activez l'autorisation pour Zoom (bascule ou case à cocher)

  6. Choisissez l'action par défaut : Démarrer l'enregistrement immédiatement ou simplement notifier ?

  7. Ajustez la sensibilité si nécessaire (curseur)

  8. Cliquez sur Appliquer

  9. Testez-le : Ouvrez Zoom et démarrez une réunion pour voir si SeaMeet la détecte

Scénario 4 : Optimiser pour un ordinateur plus ancien

Votre ordinateur a quelques années et fonctionne lentement pendant les enregistrements :

  1. Ouvrez les Paramètres

  2. Allez dans Vidéo

    • Abaissez la qualité vidéo à 720p ou 480p
    • Définissez la fréquence d'images à 30fps (au lieu de 60fps)
    • Désactivez l'accélération matérielle si elle pose des problèmes

  3. Allez dans Flashback

    • Activez "Mode faible mémoire"
    • Réduisez la durée du tampon à 30-60 secondes (au lieu de 120)

  4. Allez dans Audio

    • Choisissez une fréquence d'échantillonnage inférieure si disponible (44.1kHz au lieu de 48kHz)

  5. Allez dans Stockage

    • Activez le nettoyage automatique pour éviter les problèmes d'espace disque

  6. Cliquez sur Appliquer

  7. Testez un enregistrement pour voir si les performances s'améliorent

Scénario 5 : Préparer une présentation professionnelle

Vous devez enregistrer une présentation de haute qualité pour le travail :

  1. Ouvrez les Paramètres

  2. Allez dans Vidéo

    • Définissez la qualité à 1080p (ou la plus élevée disponible)
    • Définissez la fréquence d'images à 60fps pour un mouvement fluide
    • Activez "Enregistrer le curseur"
    • Activez "Surligner les clics du curseur" si disponible

  3. Allez dans Audio

    • Sélectionnez votre meilleur microphone
    • Définissez le gain au niveau optimal (testez d'abord !)
    • Choisissez un format de haute qualité (WAV pour le meilleur, ou MP3 haut débit)

  4. Allez dans Général

    • Désactivez les notifications pour éviter les interruptions
    • Assurez-vous que "Réduire dans la barre des tâches" est activé

  5. Allez dans Stockage

    • Vérifiez que vous avez suffisamment d'espace disque (la vidéo HD utilise beaucoup d'espace !)

  6. Cliquez sur Appliquer

  7. Faites un enregistrement de test de 30 secondes pour vérifier que tout est parfait visuellement et sonorement

Conseils et astuces sur les paramètres

Conseil 1 : Le filet de sécurité "Réinitialiser"

Si vous modifiez les paramètres et que quelque chose cesse de fonctionner, ne paniquez pas ! Chaque catégorie a un bouton "Réinitialiser" qui ramène cette section aux paramètres d'usine.

  2. Cliquez sur "Réinitialiser" (généralement en bas)
  3. Confirmez la réinitialisation
  4. Réessayez avec des paramètres propres

Attention : Cela réinitialise TOUS les paramètres de cette catégorie, pas seulement celui que vous avez modifié en dernier.

Conseil 2 : Exporter/Importer les paramètres (si disponible)

Certaines versions de SeaMeet vous permettent d'exporter vos paramètres dans un fichier. C'est idéal pour :

  • Sauvegarder vos préférences

  • Partager des paramètres optimisés avec des collègues

Recherchez : Les boutons "Exporter les paramètres" ou "Importer les paramètres", généralement dans Général ou en bas du panneau Paramètres.

Conseil 3 : Navigation au clavier

Vous pouvez naviguer dans les paramètres sans souris :

  • Tab — Passer au contrôle suivant

  • Touches fléchées — Naviguer dans les options de menu déroulant ou ajuster les curseurs

Conseil 5 : Les paramètres sont enregistrés automatiquement (habituellement)

Dans la plupart des cas, SeaMeet enregistre vos paramètres automatiquement lorsque vous les modifiez. Cependant, certaines modifications complexes nécessitent de cliquer sur "Appliquer".

Signes que vous devez cliquer sur Appliquer :

  • Un bouton "Appliquer" est visible et cliquable
  • Vous voyez du texte comme "Modifications non enregistrées"
  • Le paramètre implique des chemins de fichiers ou des ressources externes

En cas de doute : Cliquez sur Appliquer ! Cela ne fait jamais de mal de confirmer vos modifications.

Comprendre la persistance des paramètres

Voici quelque chose d'important à comprendre : Les paramètres sont enregistrés dans votre profil utilisateur et persistent entre les sessions.

Ce que cela signifie :

  • Les paramètres survivent lorsque vous fermez et rouvrez SeaMeet
  • Les paramètres restent les mêmes même si vous redémarrez votre ordinateur
  • Les paramètres sont liés à votre compte utilisateur Windows/Mac
  • Si vous avez plusieurs comptes utilisateurs, chacun a ses propres paramètres

Où sont stockés les paramètres (technique) :

  • Windows : Habituellement dans votre dossier de profil utilisateur, souvent dans AppData
  • macOS : Dans votre dossier Library utilisateur
  • Vous n'avez pas besoin d'accéder directement à ces fichiers — utilisez l'interface des Paramètres

Exceptions :

  • Certaines versions portables peuvent stocker les paramètres dans le dossier de l'application
  • Les déploiements d'entreprise peuvent utiliser des paramètres centralisés
  • La réinstallation de SeaMeet préserve généralement les paramètres utilisateur

Sécurité et confidentialité des paramètres

Les paramètres SeaMeet sont locaux à votre ordinateur et ne contiennent généralement pas d'informations sensibles. Cependant :

Ce qui se trouve dans les paramètres :

  • Chemins de fichiers (peuvent révéler la structure des dossiers)
  • Préférences d'application (quelles fonctionnalités vous utilisez)
  • Choix matériels (quel microphone vous préférez)
  • Aucun mot de passe ou identifiants de compte

Considérations de confidentialité :

  • Les paramètres n'incluent pas vos enregistrements réels (juste où ils sont enregistrés)
  • Les paramètres de détection automatique montrent quelles applications vous utilisez (mais pas les données d'utilisation)
  • Pas de synchronisation cloud des paramètres (tout reste local)

Environnements d'entreprise :

  • Les administrateurs IT peuvent être en mesure de visualiser ou de gérer les paramètres
  • La stratégie de groupe peut remplacer certains paramètres
  • Vérifiez auprès de votre service IT si vous avez des préoccupations

Dépannage des problèmes de paramètres

Problème 1 : Les paramètres ne s'enregistrent pas

Symptômes : Vous modifiez un paramètre, mais il revient à son état précédent lorsque vous rouvrez les Paramètres.

Solutions :

  1. Assurez-vous de cliquer sur "Appliquer" — Certains paramètres nécessitent une sauvegarde explicite
  2. Vérifiez l'espace disque — Si votre lecteur est plein, les paramètres ne peuvent pas être enregistrés
  3. Exécutez en tant qu'administrateur — Essayez de cliquer avec le bouton droit sur SeaMeet et "Exécuter en tant qu'administrateur"
  4. Vérifiez les autorisations — Assurez-vous d'avoir un accès en écriture à votre dossier de profil utilisateur
  5. Réinstallez SeaMeet — Sauvegardez d'abord vos enregistrements, puis réinstallez

Problème 2 : Les paramètres sont grisés

Symptômes : Certains paramètres sont visibles mais ne peuvent pas être modifiés (grisés ou désactivés).

Causes courantes :

  • Un autre paramètre les désactive — Par exemple, vous ne pouvez pas définir la qualité vidéo si l'enregistrement vidéo est désactivé
  • Restrictions admin/entreprise — Votre organisation peut verrouiller certains paramètres
  • Fonctionnalité non disponible — Cette fonctionnalité peut ne pas être incluse dans votre version
  • Limitations matérielles — Certains paramètres nécessitent un matériel spécifique

Solutions :

  1. Vérifiez si vous devez d'abord activer un paramètre parent
  2. Contactez votre service IT s'il s'agit d'une restriction d'entreprise
  3. Vérifiez la version de SeaMeet (certaines fonctionnalités sont spécifiques à la version)
  4. Vérifiez que votre matériel prend en charge la fonctionnalité

Problème 3 : L'interface utilisateur des Paramètres est défectueuse

Symptômes : Les Paramètres semblent incorrects, se chevauchent ou ne s'affichent pas correctement.

Solutions :

  1. Redimensionnez la fenêtre — Essayez d'agrandir la fenêtre SeaMeet
  2. Redémarrez SeaMeet — Fermez et rouvrez l'application
  3. Mettez à jour les pilotes graphiques — Les pilotes obsolètes peuvent causer des problèmes d'interface utilisateur
  4. Changez la mise à l'échelle d'affichage — Si vous utilisez DPI élevé (4K), essayez temporairement la mise à l'échelle à 100 %
  5. Réinstallez SeaMeet — Si tout le reste échoue, une nouvelle installation corrige généralement les problèmes d'interface utilisateur

Problème 4 : Impossible de trouver un paramètre

Symptômes : Vous savez qu'un paramètre existe, mais vous ne pouvez pas le localiser.

Solutions :

  1. Utilisez la recherche — Tapez des mots-clés dans la zone de recherche des paramètres
  2. Vérifiez toutes les catégories — Il peut être dans une catégorie inattendue
  3. Vérifiez les paramètres avancés — Certains paramètres sont cachés derrière un bouton "Avancé"
  4. Mettez à jour SeaMeet — Le paramètre peut être dans une version plus récente
  5. Lisez le manuel — Chaque chapitre des paramètres répertorie toutes les options disponibles

Avancé : Emplacement du fichier de paramètres (pour les utilisateurs avancés)

Si vous êtes un utilisateur technique et avez besoin d'accéder directement aux paramètres, voici où les trouver :

Windows

Installation standard :

C:\Users\[VotreNomUtilisateur]\AppData\Roaming\SeaMeet\

Les noms de fichiers peuvent inclure :

  • settings.json
  • config.json
  • preferences.json
  • SeaMeet.config

Comment y accéder :

  1. Appuyez sur Windows + R
  2. Tapez %AppData%\SeaMeet et appuyez sur Entrée
  3. Recherchez les fichiers de paramètres

Avertissement : Modifier ces fichiers manuellement peut corrompre SeaMeet. Sauvegardez toujours d'abord !

macOS

Emplacement standard :

~/Library/Application Support/SeaMeet/

Ou dans les préférences :

~/Library/Preferences/com.seameet.app.plist

Comment y accéder :

  1. Ouvrez le Finder
  2. Appuyez sur Cmd + Shift + G
  3. Tapez ~/Library/Application Support/SeaMeet
  4. Cliquez sur Aller

Quand modifier directement les fichiers de paramètres

En général, vous ne devriez jamais avoir besoin de faire cela, mais cela peut être utile pour :

  • Migrer les paramètres entre ordinateurs sans le cloud
  • Modifier en masse plusieurs paramètres à la fois
  • Récupérer les paramètres à partir d'une sauvegarde
  • Dépannage lorsque l'interface utilisateur ne s'ouvre pas

Toujours :

  • Fermez complètement SeaMeet avant d'éditer
  • Faites d'abord une copie de sauvegarde
  • Utilisez un éditeur JSON/texte approprié (Notepad++, VS Code, etc.)
  • Vérifiez que le format du fichier est correct avant d'enregistrer

Liste de vérification des paramètres : Que configurer en premier

Si vous vous sentez submergé par toutes les options, voici une liste de vérification priorisée des paramètres les plus importants à configurer :

Essentiel (à faire en premier)

  • Emplacement de stockage — Assurez-vous que les enregistrements vont là où vous le souhaitez
  • Microphone par défaut — Assurez-vous que le bon appareil est sélectionné
  • Langue — Définissez sur votre langue préférée
  • Préférence de démarrage auto — Décidez si SeaMeet doit démarrer avec votre ordinateur

Important (à faire bientôt)

  • Qualité vidéo — Définissez en fonction de vos besoins et de la puissance de votre ordinateur
  • Format audio — Choisissez en fonction de la qualité vs la préférence de taille de fichier
  • Thème — Mode clair ou sombre pour le confort
  • Raccourcis clavier — Personnalisez pour correspondre à votre flux de travail

Utile (à configurer si nécessaire)

  • Applications de détection automatique — Activez pour les applications que vous utilisez fréquemment
  • Paramètres Flashback — Ajustez la durée du tampon à votre préférence
  • Préférences de notification — Choisissez quels événements vous notifient
  • Options d'enregistrement du curseur — Pour les enregistrements de tutoriels/présentations

Optionnel (à affiner plus tard)

  • Paramètres audio avancés — Fréquences d'échantillonnage, profondeurs de bits
  • Préférences de codec vidéo — Paramètres de compression
  • Modèles de nommage de fichiers — Formats personnalisés pour l'organisation
  • Personnalisation des raccourcis — Mappage avancé des raccourcis clavier

Glossaire des paramètres : Référence rapide

Voici un glossaire rapide des termes que vous verrez dans les Paramètres :

Activer/Désactiver — Activer ou désactiver une fonctionnalité Par défaut — Le paramètre utilisé sauf si vous spécifiez autrement Chemin/Répertoire — Un emplacement sur votre ordinateur (comme C:\Users\Vous\Documents) Parcourir — Ouvrir un navigateur de fichiers pour sélectionner un emplacement Débit binaire — Quantité de données utilisée par seconde (plus élevé = meilleure qualité, fichiers plus volumineux) Fréquence d'échantillonnage — À quelle fréquence l'audio est capturé par seconde (44.1kHz = 44 100 fois/seconde) Résolution — Taille de l'image vidéo (1080p = 1920×1080 pixels) Fréquence d'images — Combien d'images vidéo par seconde (fps) Tampon — Stockage de mémoire temporaire pour les données en cours Gain — Niveau de volume d'entrée (sensibilité du microphone) Codec — Logiciel qui compresse/décompresse l'audio/vidéo Format — Type de fichier (MP3, MP4, WebM, etc.) Bascule — Un interrupteur qui active ou désactive quelque chose Appliquer — Enregistrer les modifications que vous avez apportées Réinitialiser — Revenir aux valeurs originales/par défaut
