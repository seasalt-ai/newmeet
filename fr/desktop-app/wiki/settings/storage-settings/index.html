Paramètres de stockage

Chapitre 19 : Paramètres de stockage

Introduction

Chaque enregistrement que vous réalisez avec SeaMeet a besoin d'un emplacement — un endroit où il réside sur votre ordinateur jusqu'à ce que vous décidiez de le déplacer, de le supprimer ou de le conserver indéfiniment. Les paramètres de stockage sont votre tableau de bord pour gérer cet espace numérique. Imaginez que vous êtes le gestionnaire de vos enregistrements : vous décidez dans quel quartier (dossier) ils vivent, quelle peut être la taille de leurs maisons (limites de taille de fichier) et quand vient le moment du grand ménage (suppression automatique).

À la fin de ce chapitre, vous saurez exactement comment contrôler l'emplacement de sauvegarde de vos enregistrements, comment éviter que votre disque dur ne se remplisse, et comment organiser votre bibliothèque grandissante de réunions, présentations et contenus créatifs.

Objectifs du chapitre

Après avoir lu ce chapitre, vous serez capable de :

  • Modifier l'emplacement de sauvegarde par défaut pour tous les enregistrements
  • Configurer des avertissements de stockage avant de manquer d'espace disque
  • Configurer le nettoyage automatique des anciens enregistrements
  • Comprendre les conventions de nommage des fichiers et l'organisation
  • Déplacer des enregistrements existants vers un nouvel emplacement
  • Résoudre les problèmes liés au stockage
  • Calculer l'espace de stockage dont vous avez besoin

Pourquoi les paramètres de stockage sont importants

Laissez-moi vous raconter une histoire. Rencontrez Sarah, une cheffe de projet qui utilise SeaMeet pour enregistrer toutes les réunions quotidiennes de son équipe. Pendant trois mois, tout a fonctionné parfaitement — les enregistrements se sauvegardaient automatiquement, la lecture était fluide et elle pouvait facilement faire référence aux discussions passées. Puis un jour, son ordinateur a commencé à ralentir. Des programmes se sont plantés. Elle ne pouvait plus sauvegarder de nouveaux fichiers. Après investigation, elle a découvert que son lecteur C: était complètement plein — 47 Go d'enregistrements SeaMeet s'étaient accumulés sans qu'elle s'en rende compte !

Cette histoire illustre pourquoi la gestion du stockage n'est pas seulement un « plus » — c'est essentiel pour :

Prévenir les problèmes système

  • Lorsque votre disque dur est plein, tout votre ordinateur ralentit
  • Windows et macOS ont besoin d'espace libre pour fonctionner correctement
  • Un disque plein peut empêcher les mises à jour logicielles et provoquer des plantages

Maintenir les performances

  • SeaMeet a besoin d'espace pour créer des fichiers temporaires lors de l'enregistrement
  • Les enregistrements vidéo notamment nécessitent beaucoup d'espace libre pour fonctionner correctement
  • L'enregistrement Flashback utilise la RAM et l'espace disque pour son tampon

Rester organisé

  • Sans gestion, les enregistrements s'accumulent en un seul tas
  • Trouver des enregistrements spécifiques devient un cauchemar
  • Les sauvegardes deviennent difficiles quand tout est désorganisé

Contrôler les coûts

  • Les sauvegardes cloud coûtent en fonction du stockage utilisé
  • Les disques durs externes doivent être dimensionnés de manière appropriée
  • Connaître votre utilisation vous aide à planifier vos achats de stockage

Comprendre les bases du stockage

Avant de plonger dans les paramètres, abordons quelques notions fondamentales sur le stockage :

Combien d'espace utilisent les enregistrements ?

Enregistrements audio uniquement :

  • Format MP3 (qualité standard) : ~1 Mo par minute
  • Format WAV (haute qualité) : ~10 Mo par minute
  • Réunion d'1 heure en MP3 : ~60 Mo
  • Réunion d'1 heure en WAV : ~600 Mo

Enregistrements vidéo :

  • 1080p à 30 fps (bonne qualité) : ~150-300 Mo par minute
  • 720p à 30 fps (qualité standard) : ~75-150 Mo par minute
  • 480p à 30 fps (qualité basique) : ~25-50 Mo par minute
  • Enregistrement 1080p d'1 heure : ~9-18 Go
  • Enregistrement 720p d'1 heure : ~4,5-9 Go

Enregistrement Flashback (tampon continu) :

  • Tampon audio (30 secondes) : utilise la RAM, pas le disque
  • Tampon vidéo (variable) : utilise ~30-600 Mo de RAM selon la durée et la qualité

Exemple concret : Si vous enregistrez une réunion vidéo d'une heure par jour en 1080p :

  • Quotidien : ~15 Go
  • Hebdomadaire (5 réunions) : ~75 Go
  • Mensuel (20 réunions) : ~300 Go
  • Annuel : ~3,6 To

C'est beaucoup d'espace ! C'est pourquoi la gestion du stockage est cruciale.

Emplacements de stockage : où pouvez-vous sauvegarder ?

Disque dur interne (lecteur C: sous Windows, Macintosh HD sur Mac)

  • Avantages : Rapide, toujours disponible, pas de matériel supplémentaire nécessaire
  • Inconvénients : Espace limité, se remplit rapidement, affecte les performances système quand il est plein

Disque dur externe (connecté par USB)

  • Avantages : Grande capacité (1 To-5 To+), n'affecte pas le lecteur système, portable
  • Inconvénients : Doit être connecté pour enregistrer, plus lent que les disques internes, peut se déconnecter accidentellement

Lecteur réseau (NAS, dossiers partagés)

  • Avantages : Stockage centralisé, accessible depuis plusieurs ordinateurs, sauvegardes automatiques
  • Inconvénients : Nécessite une connexion réseau, performances d'enregistrement plus lentes, complexité de configuration

Stockage cloud (dossier OneDrive, Google Drive, Dropbox)

  • Avantages : Sauvegarde automatique, accessible de partout, synchronisation entre appareils
  • Inconvénients : Nécessite internet, délais de téléchargement, coûts d'abonnement continus

Bonne pratique : De nombreux utilisateurs sauvegardent les enregistrements sur leur disque interne temporairement, puis déplacent les anciens enregistrements vers un stockage externe ou une sauvegarde cloud.

Section 1 : Emplacement de sauvegarde

C'est le paramètre de stockage le plus important — il détermine où vivent tous vos enregistrements.

Comment modifier l'emplacement de sauvegarde

Instructions étape par étape :

  1. Ouvrez les paramètres de stockage

    • Cliquez sur l'icône d'engrenage des paramètres dans la barre latérale gauche de SeaMeet
    • Cliquez sur "Storage" dans la liste des catégories

  2. Trouvez "Save Location"

    • Cherchez le champ texte affichant votre chemin actuel
    • Il peut ressembler à : C:\Users\VotreNom\SeaMeet Recordings

  3. Cliquez sur "Browse..."

    • Une fenêtre de navigation s'ouvre

  4. Naviguez vers l'emplacement souhaité

    • Pour les lecteurs internes : cliquez sur "This PC" puis votre lecteur C: ou D:
    • Pour les lecteurs externes : cherchez sous "This PC" votre lecteur USB
    • Pour les emplacements réseau : utilisez la barre d'adresse pour taper le chemin

  5. Sélectionnez ou créez un dossier

    • Vous pouvez sélectionner un dossier existant
    • Ou en créer un nouveau : clic droit → Nouveau dossier → Nommez-le (ex. "SeaMeet Recordings")

  6. Cliquez sur "Select Folder" ou "OK"

    • La fenêtre de navigation se ferme
    • Le nouveau chemin apparaît dans le champ texte

  7. Cliquez sur "Apply"

    • Vos modifications sont sauvegardées
    • Les futurs enregistrements iront au nouvel emplacement

Exemples de chemins :

Windows:
- Interne : C:\Users\Sarah\Documents\SeaMeet Recordings
- Externe : D:\SeaMeet Recordings
- Réseau : \\server\shared\recordings

macOS:
- Interne : /Users/sarah/Documents/SeaMeet Recordings
- Externe : /Volumes/ExternalDrive/SeaMeet Recordings
- Réseau : /Volumes/Server/recordings

Choisir le bon emplacement

Scénario 1 : Vous avez beaucoup d'espace interne

  • Situation actuelle : 500 Go+ libres sur votre lecteur C:
  • Recommandation : Gardez l'emplacement par défaut
  • Pourquoi : Meilleures performances, configuration la plus simple

Scénario 2 : Votre lecteur C: se remplit

  • Situation actuelle : Moins de 100 Go libres
  • Recommandation : Passez au lecteur D: ou au stockage externe
  • Étapes :
    1. Copiez les enregistrements existants vers le nouvel emplacement
    2. Modifiez l'emplacement de sauvegarde dans les paramètres
    3. Vérifiez que les nouveaux enregistrements fonctionnent
    4. Supprimez les anciennes copies (après sauvegarde !)

Scénario 3 : Vous avez un grand disque externe

  • Situation actuelle : Disque USB externe de 2 To
  • Recommandation : Sauvegardez directement sur le disque externe
  • Étapes :
    1. Assurez-vous que le disque est toujours connecté lors de l'enregistrement
    2. Définissez l'emplacement de sauvegarde sur le disque externe
    3. Envisagez de n'utiliser le disque que pour les enregistrements

Scénario 4 : Vous utilisez le stockage cloud

  • Situation actuelle : Dossier OneDrive ou Google Drive synchronisé
  • Recommandation : Sauvegardez dans un sous-dossier de votre lecteur cloud
  • Étapes :
    1. Créez un dossier "SeaMeet Recordings" dans le lecteur cloud
    2. Définissez-le comme emplacement de sauvegarde
    3. Les enregistrements se synchronisent automatiquement vers le cloud
    4. Note : Les gros fichiers vidéo peuvent mettre du temps à se télécharger

Déplacer les enregistrements existants vers un nouvel emplacement

Lorsque vous modifiez l'emplacement de sauvegarde, SeaMeet ne déplace pas automatiquement vos enregistrements existants. Voici comment procéder correctement :

Important : Faites toujours une sauvegarde avant de déplacer des fichiers !

Étape par étape :

  1. Ouvrez les deux dossiers

    • Ouvrez votre dossier d'enregistrements actuel (ancien emplacement)
    • Ouvrez votre nouveau dossier d'enregistrements (nouvel emplacement)
    • Arrangez les fenêtres côte à côte

  2. Sélectionnez tous les enregistrements existants

    • Dans l'ancien dossier, appuyez sur Ctrl+A (Windows) ou Cmd+A (Mac) pour tout sélectionner
    • Ou sélectionnez manuellement des enregistrements spécifiques à déplacer

  3. Copiez (ne déplacez pas encore !)

    • Appuyez sur Ctrl+C (Windows) ou Cmd+C (Mac) pour copier
    • Cliquez dans le nouvel emplacement du dossier
    • Appuyez sur Ctrl+V (Windows) ou Cmd+V (Mac) pour coller
    • Attendez la fin de la copie (peut prendre du temps pour de gros fichiers)

  4. Vérifiez la copie

    • Vérifiez que tous les fichiers apparaissent au nouvel emplacement
    • Lisez un ou deux enregistrements pour confirmer qu'ils fonctionnent
    • Vérifiez que les tailles de fichiers correspondent

  5. Mettez à jour les paramètres SeaMeet

    • Ouvrez SeaMeet Paramètres → Storage
    • Modifiez l'emplacement de sauvegarde vers le nouveau dossier
    • Cliquez sur Apply

  6. Testez un nouvel enregistrement

    • Faites un court enregistrement test
    • Vérifiez qu'il apparaît au nouvel emplacement
    • Lisez-le pour confirmer qu'il fonctionne

  7. Supprimez les anciennes copies (optionnel)

    • Uniquement après avoir confirmé que tout fonctionne !
    • Sélectionnez les fichiers dans l'ancien emplacement
    • Appuyez sur la touche Suppr
    • Confirmez la suppression
    • Ou déplacez vers la Corbeille pour plus de sécurité

Alternative : Déplacer au lieu de copier Si vous êtes sûr et à court d'espace :

  • Ignorez les étapes 3-4
  • À l'étape 3, utilisez Ctrl+X (couper) au lieu de Ctrl+C (copier)
  • Puis Ctrl+V pour coller au nouvel emplacement
  • Les fichiers se déplacent au lieu d'être copiés (plus rapide, mais sans sauvegarde)

Problèmes courants d'emplacement de sauvegarde

Problème 1 : "Access Denied" lors du changement d'emplacement

Cause : Vous n'avez pas la permission d'écrire dans le dossier sélectionné.

Solutions :

  1. Choisissez un autre emplacement (comme votre dossier Documents)
  2. Exécutez SeaMeet en tant qu'administrateur (clic droit → Exécuter en tant qu'administrateur)
  3. Vérifiez les permissions du dossier (clic droit → Propriétés → Sécurité)

Problème 2 : Le disque externe n'apparaît pas dans la navigation

Cause : Le disque n'est pas connecté, pas formaté correctement ou problèmes de pilotes.

Solutions :

  1. Assurez-vous que le disque est branché et allumé
  2. Vérifiez l'Explorateur Windows (Windows) ou le Finder (Mac) pour voir si le disque apparaît
  3. Essayez un autre port USB
  4. Redémarrez votre ordinateur
  5. Vérifiez la Gestion des disques (Windows) ou l'Utilitaire de disque (Mac) pour l'état du disque

Problème 3 : Lecteur réseau non disponible

Cause : Problèmes de connexion réseau, lecteur hors ligne ou permissions.

Solutions :

  1. Assurez-vous d'être connecté au réseau
  2. Essayez d'abord d'accéder au lecteur via l'Explorateur de fichiers/Finder
  3. Vérifiez si vous devez entrer des identifiants
  4. Contactez votre service informatique s'il s'agit d'un lecteur réseau professionnel

Problème 4 : Les enregistrements n'apparaissent pas au nouvel emplacement

Cause : Les paramètres n'ont pas été sauvegardés, ou SeaMeet utilise un emplacement en cache.

Solutions :

  1. Redémarrez SeaMeet complètement
  2. Vérifiez que le paramètre a été appliqué
  3. Vérifiez si plusieurs instances de SeaMeet sont en cours d'exécution
  4. Essayez de définir à nouveau l'emplacement et cliquez immédiatement sur Apply

Section 2 : Moniteur d'utilisation du stockage

La section d'utilisation du stockage vous donne un tableau de bord visuel de votre situation de stockage. Pensez-y comme à votre jauge de carburant pour le stockage numérique.

Comprendre l'affichage du stockage

Vous verrez généralement :

Current Storage Usage
┌──────────────────────────────────────────────────────┐
│ Recordings folder: 47.3 GB used                      │
│ Available space: 12.7 GB remaining                   │
│ Total capacity: 500 GB                               │
│                                                      │
│ █████████████████████████████████░░░░░░░░░░░░░░░░░   │
│ 79% full — Warning threshold: 85%                    │
└──────────────────────────────────────────────────────┘

Détail des chiffres :

  • Recordings folder : Espace occupé par vos enregistrements
  • Available space : Espace restant sur ce lecteur
  • Total capacity : Taille totale du lecteur/partition
  • Barre visuelle : Représentation graphique de l'utilisation
  • Pourcentage : Taux de remplissage de votre stockage
  • Warning threshold : Seuil à partir duquel vous commencez à recevoir des avertissements

Codage couleur (dans la plupart des versions) :

  • 🟢 Vert : Moins de 50% — Vous êtes en bonne forme !
  • 🟡 Jaune : 50-80% — Surveillez la situation
  • 🟠 Orange : 80-90% — Zone d'avertissement, envisagez un nettoyage
  • 🔴 Rouge : 90%+ — Critique ! Nettoyez immédiatement !

Pourquoi les chiffres sont importants

Espace disponible pour de nouveaux enregistrements :

  • Besoin d'enregistrer une réunion vidéo de 2 heures ?
  • En 1080p, c'est environ 20-30 Go
  • Si vous n'avez que 15 Go libres, vous ne pourrez pas enregistrer !

Performances système :

  • Windows a besoin d'au moins 10-15% d'espace libre pour fonctionner correctement
  • macOS nécessite également beaucoup d'espace libre pour la mémoire virtuelle
  • Un disque plein provoque des ralentissements, plantages et problèmes

Exigences d'enregistrement Flashback :

  • Flashback a besoin de RAM et d'un peu d'espace disque pour les tampons
  • Si le stockage est à un niveau critique, Flashback peut ne pas fonctionner correctement

Que faire à différents niveaux de stockage

Zone verte (0-50% plein) :

  • Vous êtes en bonne forme !
  • Continuez à enregistrer normalement
  • Envisagez peut-être de configurer un nettoyage automatique par précaution
  • Aucune action immédiate nécessaire

Zone jaune (50-80% plein) :

  • Surveillez la situation
  • Envisagez de configurer des avertissements de stockage
  • Planifiez une stratégie de nettoyage pour l'avenir
  • Encore sûr pour enregistrer normalement

Zone orange (80-90% plein) :

  • ⚠️ Zone d'avertissement !
  • Configurez des avertissements de stockage si ce n'est pas déjà fait
  • Envisagez de déplacer les anciens enregistrements vers un stockage externe
  • Activez le nettoyage automatique
  • Vérifiez si des enregistrements peuvent être supprimés
  • Encore fonctionnel, mais soyez proactif

Zone rouge (90%+ plein) :

  • 🚨 Critique ! Action immédiate nécessaire !
  • Arrêtez d'enregistrer jusqu'à ce que vous libériez de l'espace
  • Déplacez immédiatement les enregistrements vers un disque externe
  • Supprimez les fichiers inutiles
  • Videz la Corbeille
  • Exécutez des utilitaires de nettoyage de disque
  • Vérifiez les enregistrements en double

Section 3 : Avertissements de stockage

Les avertissements de stockage sont comme le témoin de carburant dans votre voiture — ils vous alertent avant d'être à court d'espace. Cela vous donne le temps d'agir au lieu d'être surpris par une erreur "disque plein" en cours d'enregistrement.

Comment fonctionnent les avertissements de stockage

Paramètre de seuil d'avertissement : Vous pouvez définir quand SeaMeet doit vous avertir d'un stockage insuffisant :

Show warning when storage is low: [80% ▼]

Options typiques :

  • 70% plein
  • 75% plein
  • 80% plein (recommandé)
  • 85% plein
  • 90% plein
  • Pourcentage personnalisé

Ce qui se passe quand le seuil est atteint :

  1. Avertissement visuel :

    • Une notification popup apparaît
    • La barre de stockage devient orange/rouge
    • Une icône d'avertissement apparaît dans l'interface

  2. Avertissement avant l'enregistrement :

    • Si activé, vous avertit avant de démarrer un enregistrement
    • Affiche l'espace estimé nécessaire vs disponible
    • Vous donne la possibilité d'annuler ou de continuer

  3. Indicateur d'icône de la barre des tâches :

    • L'icône de SeaMeet dans la barre des tâches peut changer
    • Affiche un badge d'avertissement ou un changement de couleur

Exemple de message d'avertissement :

⚠️ STORAGE WARNING

Your recordings folder is 87% full (43.5 GB used of 50 GB).
Only 6.5 GB remaining.

A 1-hour video recording needs approximately 15 GB.
You may not have enough space to complete your recording.

[Manage Storage] [Continue Anyway] [Cancel]

Configurer les avertissements de stockage

Étape par étape :

  1. Ouvrez les paramètres de stockage

  2. Trouvez la section "Storage Warnings"

  3. Activez "Show warning when storage is low"

    • Cochez la case ou activez le bouton

  4. Définissez votre seuil

    • Cliquez sur le menu déroulant (affiche actuellement un pourcentage)
    • Choisissez votre seuil préféré
    • Recommandations :
      • Utilisateurs intensifs : 70-75%
      • Utilisateurs moyens : 80%
      • Utilisateurs occasionnels : 85-90%

  5. Activez "Show warning before recording if low space"

    • Cela évite de démarrer des enregistrements que vous ne pourrez pas terminer
    • Fortement recommandé !

  6. Cliquez sur "Apply"

Tester vos avertissements : Pour vous assurer que les avertissements fonctionnent :

  1. Définissez temporairement un seuil très bas (comme 10%)
  2. Vérifiez si l'avertissement apparaît
  3. Réinitialisez le seuil à votre valeur préférée
  4. Cliquez sur Apply

Vérification d'espace avant l'enregistrement

C'est l'une des fonctionnalités les plus utiles — elle calcule si vous avez suffisamment d'espace avant de commencer l'enregistrement.

Comment ça fonctionne :

  1. Vous cliquez sur "Start Recording"
  2. SeaMeet estime l'espace nécessaire en fonction de :
    • Type d'enregistrement (audio seulement vs vidéo)
    • Paramètres de qualité sélectionnés
    • Durée (si connue, ou suppose 1 heure)
  3. Compare l'espace nécessaire vs disponible
  4. Vous avertit s'il n'y a pas suffisamment d'espace

Exemples d'estimations :

Estimated space needed for this recording:
• Audio only (MP3): 60 MB per hour
• Audio only (WAV): 600 MB per hour
• Video (1080p): 18 GB per hour
• Video (720p): 9 GB per hour
• Video (480p): 3 GB per hour

You have 12 GB available.
Recommended maximum duration: 40 minutes at 1080p

Pourquoi c'est important : Rien n'est plus frustrant que d'enregistrer une réunion importante de 2 heures, pour la voir s'interrompre après 45 minutes parce que votre disque est plein. Cet avertissement l'évite.

Section 4 : Nettoyage automatique

Le nettoyage automatique est comme avoir un assistant robot qui organise périodiquement vos enregistrements et supprime les anciens que vous n'avez probablement plus besoin. C'est une gestion du stockage en mode « configurer et oublier ».

Comment fonctionne le nettoyage automatique

Concept de base : SeaMeet supprime automatiquement les enregistrements qui répondent à certains critères d'âge, tout en protégeant les enregistrements récents dont vous pourriez encore avoir besoin.

Deux contrôles principaux :

  1. Seuil d'âge : Supprimer les enregistrements plus anciens que X jours
  2. Conserver un minimum : Toujours garder au moins Y enregistrements les plus récents

Exemple de configuration :

☑ Automatically delete old recordings
Delete recordings older than: [90 days ▼]
Keep at least: [10 most recent ▼]
☑ Move to Recycle Bin instead of permanent delete

Comment ça fonctionne en pratique :

  • Vous avez 50 enregistrements des 6 derniers mois
  • 30 enregistrements ont plus de 90 jours
  • SeaMeet supprimera 20 des plus anciens
  • Mais garde les 10 plus récents (même si certains ont plus de 90 jours)
  • Résultat : Vous gardez 30 enregistrements (10 plus récents + 20 assez récents)

Configurer le nettoyage automatique

Étape par étape :

  1. Ouvrez les paramètres de stockage

  2. Trouvez la section "Automatic Cleanup"

  3. Activez "Automatically delete old recordings"

    • Activez le bouton

  4. Définissez le seuil d'âge

    • Cliquez sur le menu déroulant
    • Choisissez combien de temps conserver les enregistrements
    • Options typiques : 7, 14, 30, 60, 90, 180, 365 jours
    • Recommandation pour la plupart des utilisateurs : 90 jours (3 mois)

  5. Définissez le nombre minimum à conserver

    • Choisissez combien d'enregistrements récents conserver toujours
    • Options typiques : 5, 10, 20, 50 ou Tous
    • Recommandation : 10-20 enregistrements

  6. Choisissez la méthode de suppression

    • ☑ Déplacer vers la Corbeille (plus sûr, récupération possible si nécessaire)
    • ☐ Suppression permanente (libère l'espace immédiatement, irrécupérable)
    • Recommandation : Utilisez la Corbeille !

  7. Cliquez sur "Apply"

Quand le nettoyage se produit-il ?

  • Quotidiennement : Vérifie généralement une fois par jour
  • Au démarrage : Peut vérifier quand SeaMeet se lance
  • Déclenchement manuel : Certaines versions ont un bouton "Cleanup Now"
  • Après l'enregistrement : Peut vérifier après avoir terminé un enregistrement

Choisir les bons paramètres de nettoyage

Utilisateur occasionnel (1-2 enregistrements par semaine) :

Seuil d'âge : 180 jours (6 mois)
Minimum à conserver : 20 enregistrements
Pourquoi : Vous n'en créez pas beaucoup, donc gardez-les plus longtemps

Utilisateur moyen (3-5 enregistrements par semaine) :

Seuil d'âge : 90 jours (3 mois)
Minimum à conserver : 10 enregistrements
Pourquoi : Approche équilibrée pour une utilisation modérée

Utilisateur intensif (enregistrements quotidiens) :

Seuil d'âge : 30 jours (1 mois)
Minimum à conserver : 10 enregistrements
Pourquoi : Les enregistrements fréquents remplissent l'espace rapidement, nettoyage agressif

Utilisateur professionnel/conformité :

Seuil d'âge : 365 jours (1 an) ou plus
Minimum à conserver : 50+ enregistrements
☐ Désactivez le nettoyage automatique
Pourquoi : Les exigences légales ou de conformité peuvent imposer une rétention
Note : Gérez manuellement le stockage ou utilisez des archives externes

Fonctionnalités de sécurité importantes

Protection de la Corbeille :

  • Activez toujours "Move to Recycle Bin"
  • Les enregistrements supprimés restent dans la Corbeille pendant 30 jours (Windows) ou jusqu'à ce que la Corbeille soit vidée (Mac)
  • Vous pouvez récupérer des enregistrements accidentellement supprimés
  • Pour libérer définitivement de l'espace, videz la Corbeille séparément

Protection des éléments favoris :

  • Certaines versions ne suppriment pas les enregistrements marqués comme favoris
  • Marquez les enregistrements importants pour les protéger du nettoyage
  • Vérifiez si votre version a cette fonctionnalité dans les paramètres de nettoyage

Remplacement manuel :

  • Vous pouvez toujours supprimer des enregistrements manuellement à tout moment
  • La suppression manuelle est immédiate
  • Le nettoyage automatique ne supprime que les anciens enregistrements non protégés

Surveiller le nettoyage automatique

Affichage de l'historique de nettoyage : Certaines versions affichent un journal de ce qui a été nettoyé :

Cleanup History (Last 30 Days)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Jan 15 — Deleted 3 recordings (oldest: 95 days)
Jan 14 — Deleted 2 recordings (oldest: 92 days)
Jan 12 — Deleted 5 recordings (oldest: 98 days)
Jan 08 — No cleanup needed

Recevoir des notifications de nettoyage : Vous pouvez choisir d'être notifié lors du nettoyage :

☑ Notify me when old recordings are deleted
☑ Show summary of what was cleaned up
☑ Warn before deleting if more than 10 files

Désactivation temporaire : Si vous devez suspendre le nettoyage :

  1. Allez dans les paramètres de stockage
  2. Décochez "Automatically delete old recordings"
  3. Cliquez sur Apply
  4. Réactivez quand vous êtes prêt (le nettoyage reprendra)

Section 5 : Organisation des fichiers

La façon dont vos enregistrements sont nommés et organisés fait une grande différence pour les retrouver plus tard. Une bonne organisation transforme un tas chaotique en une bibliothèque consultable.

Modèles de nommage des fichiers

Ce que c'est : Le modèle de nommage détermine le nom de fichier par défaut lorsque vous sauvegardez un enregistrement.

Modèles disponibles (options typiques) :

  1. Date_Time (Simple)

    2024-01-15_14-30-22.mp4
    • Avantages : Simple, tri chronologique
    • Inconvénients : Pas de contexte sur ce qui a été enregistré

  2. Date_Time_App (Recommandé)

    2024-01-15_14-30-22_Zoom.mp4
2024-01-15_14-30-22_Teams.mp4
    • Avantages : Indique l'application, tri chronologique
    • Inconvénients : Ne précise toujours pas le sujet de la réunion

  3. App_Date_Time

    Zoom_2024-01-15_14-30-22.mp4
Teams_2024-01-15_14-30-22.mp4
    • Avantages : Regroupement par application, facile de trouver une plateforme spécifique
    • Inconvénients : Dans chaque application, tri par date

  4. Modèle personnalisé

    {YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}_{App}_{Custom}
    • Certaines versions permettent de créer des modèles personnalisés
    • Utilisez des variables comme la date, l'heure, le nom de l'application

Comment modifier :

  1. Ouvrez les paramètres de stockage
  2. Trouvez la section "File Organization"
  3. Cliquez sur le menu déroulant "Naming pattern"
  4. Sélectionnez votre modèle préféré
  5. Cliquez sur Apply

Créer des sous-dossiers

Ce que c'est : Organisez automatiquement les enregistrements dans des dossiers selon des périodes de temps ou d'autres critères.

Options d'organisation :

  1. Pas de sous-dossiers (Plat)

    /SeaMeet Recordings/
  ├── 2024-01-15_14-30-22_Zoom.mp4
  ├── 2024-01-15_16-00-00_Teams.mp4
  └── 2024-01-16_09-00-00_Zoom.mp4
    • Tous les enregistrements dans un seul dossier
    • Simple mais peut devenir encombré

  2. Par année

    /SeaMeet Recordings/
  ├── 2023/
  │   └── [enregistrements 2023...]
  └── 2024/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      └── [enregistrements 2024...]
    • Sépare par année
    • Bon pour les archives à long terme

  3. Par mois (Recommandé)

    /SeaMeet Recordings/
  └── 2024-01/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      ├── 2024-01-15_16-00-00_Teams.mp4
      └── 2024-01-16_09-00-00_Zoom.mp4
    • Sépare par mois
    • Organisation équilibrée
    • Facile de trouver les enregistrements récents
    • Bon pour le nettoyage/révision mensuel

  4. Par semaine

    /SeaMeet Recordings/
  └── 2024-W03/
      ├── [enregistrements semaine 3...]
    • Sépare par numéro de semaine
    • Bon pour le travail basé sur les projets
    • Peut s'aligner sur les cycles de sprint

  5. Par jour

    /SeaMeet Recordings/
  └── 2024-01-15/
      ├── 14-30-22_Zoom.mp4
      └── 16-00-00_Teams.mp4
    • Sépare par jour
    • Plus granulaire
    • Beaucoup de dossiers si vous enregistrez fréquemment

Configuration :

  1. Ouvrez les paramètres de stockage
  2. Trouvez "Create subfolders by"
  3. Sélectionnez votre organisation préférée
  4. Cliquez sur Apply
  5. Les nouveaux enregistrements suivront cette structure

Note : Les enregistrements existants restent à leur emplacement actuel ; cela n'affecte que les nouveaux enregistrements.

Bonnes pratiques d'organisation

La stratégie "Mensuel + Application" (Fortement recommandée) :

Nommage : Date_Time_App
Sous-dossiers : Par mois

Résultat :

/SeaMeet Recordings/
  ├── 2024-01/
  │   ├── 2024-01-15_14-30-22_Zoom.mp4
  │   ├── 2024-01-15_16-00-00_Teams.mp4
  │   └── 2024-01-16_09-00-00_Zoom.mp4
  └── 2024-02/
      ├── 2024-02-01_10-00-00_Meet.mp4
      └── 2024-02-05_14-00-00_Zoom.mp4

Pourquoi ça fonctionne :

  1. Chronologique : Facile de trouver les enregistrements par date
  2. Pas écrasant : Chaque mois a un nombre gérable de fichiers
  3. Identification de l'application : Savoir quelle plateforme a été utilisée
  4. Nettoyage facile : Supprimez des dossiers mensuels entiers quand ils sont anciens
  5. Sauvegarde simple : Copiez des dossiers mensuels vers le stockage externe

Section 6 : Bonnes pratiques de stockage

La règle de sauvegarde 3-2-1

Pour les enregistrements importants, suivez la stratégie de sauvegarde standard 3-2-1 :

3 : Gardez 3 copies des données importantes

  • Enregistrement original
  • Sauvegarde locale (disque externe)
  • Sauvegarde cloud (OneDrive, Google Drive, etc.)

2 : Utilisez 2 types de stockage différents

  • Disque interne (original)
  • Disque externe ou cloud (sauvegarde)

1 : Gardez 1 sauvegarde hors site

  • Le stockage cloud compte comme hors site
  • Ou gardez le disque externe dans un autre lieu physique

Comment appliquer à SeaMeet :

  1. Enregistrez sur le disque interne (rapide, accès immédiat)
  2. Configurez une synchronisation automatique vers un dossier cloud (OneDrive, Dropbox)
  3. Mensuellement : Copiez les enregistrements importants sur un disque externe
  4. Trimestriellement : Déplacez les anciens enregistrements vers une archive externe

Calculer vos besoins de stockage

Utilisez cette formule pour estimer vos besoins :

Stockage nécessaire = (Utilisation quotidienne × Jours) + Tampon de sécurité + Croissance

Exemple de calcul :

Scénario : Vous enregistrez 2 heures de vidéo 1080p par jour, 5 jours par semaine

Quotidien : 2 heures × 15 Go/heure = 30 Go par jour
Hebdomadaire : 30 Go × 5 jours = 150 Go par semaine
Mensuel : 150 Go × 4 semaines = 600 Go par mois
Annuel : 600 Go × 12 mois = 7,2 To par an

Tampon de sécurité : 20% = 1,44 To
Facteur de croissance : 1,5× (50% de croissance) = 3,6 To

Total recommandé : 7,2 + 1,44 + 3,6 = 12,24 To

Recommandations pratiques :

  • Utilisateur occasionnel (1 heure/semaine audio) : 100 Go par an
  • Utilisateur moyen (5 heures/semaine mixte) : 1-2 To par an
  • Utilisateur intensif (2 heures/jour vidéo) : 5-10 To par an

Gérer les coûts de stockage

Si vous utilisez le stockage cloud :

  • Audio seulement : Très abordable (~2-5€/mois pour 100 Go)
  • Enregistrements vidéo : Peut devenir rapidement coûteux
  • 1 To de vidéo dans le cloud : ~10-20€/mois
  • 10 To de vidéo dans le cloud : ~100-200€/mois

Stratégies d'économie :

  1. Utilisez une qualité vidéo inférieure pour les réunions routinières (720p au lieu de 1080p)
  2. Gardez seulement l'audio pour la plupart des réunions, la vidéo uniquement si nécessaire
  3. Archivez les anciens enregistrements vers un stockage moins cher
  4. Supprimez les enregistrements après transcription/résumé
  5. Utilisez des formats compressés (MP3, MP4 compressé)

Si vous utilisez des disques externes :

  • Disque externe 1 To : ~50-70€ (coût unique)
  • Disque externe 4 To : ~100-120€ (coût unique)
  • Disque externe 8 To : ~150-200€ (coût unique)
  • Plus rentable pour les grandes bibliothèques vidéo

Routine de maintenance mensuelle du stockage

Consacrez 15 minutes chaque mois à la maintenance du stockage :

1ère semaine de chaque mois :

  1. Vérifiez le tableau de bord du stockage

    • Ouvrez SeaMeet → Paramètres → Storage
    • Notez le pourcentage d'utilisation actuel
    • Vérifiez l'espace disponible

  2. Révisez le nettoyage automatique

    • Vérifiez le journal de nettoyage si disponible
    • Assurez-vous que les paramètres fonctionnent
    • Ajustez si nécessaire

  3. Déplacez les anciens enregistrements

    • Créez un dossier pour le mois précédent sur le disque externe
    • Copiez les enregistrements de plus de 30 jours
    • Vérifiez que les copies fonctionnent
    • Supprimez du disque interne

  4. Videz la Corbeille

    • Clic droit sur la Corbeille → Vider
    • Libérez définitivement de l'espace

  5. Mettez à jour la sauvegarde

    • Synchronisez le dossier cloud
    • Vérifiez la sauvegarde sur disque externe

Temps requis : 10-15 minutes Avantage : Prévient les crises de stockage et maintient le système en bon état

Résolution des problèmes de stockage

Problème 1 : Erreur "Not Enough Space" lors de l'enregistrement

Symptômes :

  • Message d'erreur : "Insufficient disk space to start recording"
  • L'enregistrement ne démarre pas
  • Un avertissement est apparu mais vous avez continué quand même

Solutions immédiates :

  1. Libérez rapidement de l'espace :

    • Videz la Corbeille (peut libérer 1-10 Go instantanément)
    • Exécutez le Nettoyage de disque (Windows) ou Optimiser le stockage (Mac)
    • Supprimez les anciens téléchargements, fichiers temporaires
    • Désinstallez les programmes inutilisés

  2. Changez l'emplacement de sauvegarde :

    • Passez à un lecteur avec plus d'espace
    • Un disque externe est la solution la plus rapide

  3. Réduisez la qualité d'enregistrement :

    • Paramètres → Video → Réduisez la qualité à 720p ou 480p
    • Utilise 50-75% moins d'espace

  4. Passez en audio seulement :

    • Si la vidéo n'est pas essentielle, enregistrez uniquement l'audio
    • Utilise 99% moins d'espace que la vidéo

Solutions à long terme :

  • Configurez le nettoyage automatique
  • Augmentez le seuil d'avertissement de stockage
  • Passez à un disque plus grand
  • Mettez en place une routine de maintenance régulière

Problème 2 : Les enregistrements ont disparu

Symptômes :

  • Les enregistrements étaient là hier, partis aujourd'hui
  • Impossible de trouver les fichiers dans le dossier prévu
  • SeaMeet affiche les enregistrements dans la bibliothèque mais les fichiers sont manquants

Causes possibles et solutions :

Cause 1 : Le nettoyage automatique a été exécuté

  • Vérifiez si le nettoyage a supprimé d'anciens enregistrements
  • Cherchez dans la Corbeille pour récupérer
  • Solution : Ajustez les paramètres de nettoyage ou désactivez-le

Cause 2 : Déplacé vers un autre emplacement

  • Vérifiez si vous avez récemment changé l'emplacement de sauvegarde
  • Anciens enregistrements dans le dossier précédent
  • Solution : Mettez à jour la bibliothèque ou déplacez les fichiers vers le nouvel emplacement

Cause 3 : Suppression accidentelle

  • Vérifiez la Corbeille
  • Vérifiez si vous (ou quelqu'un d'autre) avez supprimé les fichiers
  • Solution : Restaurez depuis la Corbeille ou la sauvegarde

Cause 4 : La lettre du lecteur a changé (Windows)

  • Le disque externe a obtenu une lettre différente (D: est devenu E:)
  • SeaMeet cherche au mauvais endroit
  • Solution : Réaffectez la lettre du lecteur ou mettez à jour l'emplacement de sauvegarde

Étapes de récupération :

  1. Vérifiez d'abord la Corbeille
  2. Recherchez les noms de fichiers d'enregistrement sur tout l'ordinateur
  3. Vérifiez les emplacements de sauvegarde (cloud, disque externe)
  4. Utilisez un logiciel de récupération de fichiers si récemment supprimés
  5. Vérifiez la base de données interne de SeaMeet (peut afficher les chemins)

Problème 3 : SeaMeet ne peut pas accéder à l'emplacement de sauvegarde

Symptômes :

  • Erreur : "Cannot write to save location"
  • Les enregistrements échouent à se sauvegarder
  • Les paramètres affichent un avertissement rouge sur l'emplacement de sauvegarde

Solutions :

  1. Vérifiez les permissions du dossier :

    • Clic droit sur le dossier → Propriétés → Sécurité (Windows)
    • Assurez-vous que votre utilisateur a la permission "Écriture"
    • Ajoutez la permission si elle manque

  2. Vérifiez l'état du lecteur :

    • Exécutez une vérification des erreurs du lecteur
    • Windows : Clic droit sur le lecteur → Propriétés → Outils → Vérifier
    • Mac : Utilitaire de disque → Premiers Secours

  3. Vérifiez la connexion du lecteur :

    • Si lecteur externe/réseau, assurez-vous qu'il est connecté
    • Vérifiez que le lecteur apparaît dans l'Explorateur/Finder
    • Reconnectez si nécessaire

  4. Choisissez un autre emplacement :

    • Passez au dossier Documents (généralement toujours accessible)
    • Utilisez le disque interne au lieu de l'externe

  5. Exécutez en tant qu'administrateur :

    • Clic droit sur SeaMeet → Exécuter en tant qu'administrateur
    • Peut contourner certains problèmes de permission

Problème 4 : L'utilisation du stockage affiche des chiffres incorrects

Symptômes :

  • SeaMeet affiche 50 Go utilisés, mais le dossier affiche 20 Go
  • L'espace disponible ne correspond pas à l'Explorateur de fichiers
  • Les chiffres semblent complètement faux

Raisons possibles :

  1. Fichiers cachés :

    • SeaMeet peut compter les fichiers temporaires cachés
    • Activez "Afficher les fichiers cachés" dans l'Explorateur de fichiers pour vérifier

  2. Données en cache :

    • Ancien calcul de stockage en cache
    • Redémarrez SeaMeet pour actualiser

  3. Emplacements multiples :

    • SeaMeet peut surveiller plusieurs dossiers
    • Vérifiez si l'emplacement de sauvegarde a récemment changé

  4. Base de données vs Système de fichiers :

    • La base de données de SeaMeet peut avoir des informations obsolètes
    • Rescannez ou actualisez la bibliothèque

Correction :

  1. Fermez SeaMeet complètement
  2. Vérifiez manuellement la taille du dossier dans l'Explorateur de fichiers
  3. Redémarrez SeaMeet
  4. Allez dans les paramètres de stockage et cherchez "Refresh" ou "Rescan"
  5. Attendez le recalcul

Sujets avancés de stockage

Configuration du stockage réseau (NAS)

Qu'est-ce qu'un NAS ? Network Attached Storage — un disque dur connecté à votre réseau, accessible depuis n'importe quel ordinateur.

Configuration de SeaMeet avec NAS :

  1. Mapper le lecteur réseau (Windows) :

    • Ouvrez l'Explorateur de fichiers
    • Cliquez sur "Ce PC" → "Connecter un lecteur réseau"
    • Entrez le chemin NAS : \\NAS-Name\shared-folder
    • Cochez "Se reconnecter lors de la connexion"
    • Assignez une lettre de lecteur (ex. Z:)

  2. Définir l'emplacement de sauvegarde SeaMeet :

    • Paramètres → Storage
    • Naviguez vers Z:\SeaMeet Recordings (ou votre lecteur mappé)
    • Cliquez sur Apply

  3. Considérations :

    • La vitesse réseau affecte les performances d'enregistrement
    • L'enregistrement 1080p nécessite ~25 Mo/s de vitesse d'écriture soutenue
    • Le Wi-Fi peut être trop lent ; utilisez Ethernet si possible
    • Si le réseau tombe, l'enregistrement peut échouer

Bonne pratique : Enregistrez sur le disque local, puis synchronisez automatiquement vers NAS ensuite.

Intégration du stockage cloud

Comment ça fonctionne : SeaMeet sauvegarde vers un dossier qui se synchronise avec le stockage cloud (OneDrive, Google Drive, Dropbox, etc.)

Étapes de configuration :

  1. Créez un dossier cloud :

    • Ouvrez le dossier OneDrive/Google Drive
    • Créez un sous-dossier "SeaMeet Recordings"

  2. Définissez comme emplacement de sauvegarde :

    • Paramètres → Storage → Browse
    • Sélectionnez le dossier cloud
    • Apply

  3. Configurez la synchronisation :

    • OneDrive : Clic droit sur le dossier → Toujours garder sur cet appareil (si vous voulez une copie locale)
    • Ou "Libérer de l'espace" pour stocker uniquement dans le cloud

  4. Surveillez l'upload :

    • Les grandes vidéos prennent du temps à se télécharger
    • Vérifiez l'application cloud pour la progression de l'upload
    • N'éteignez pas avant la fin de l'upload

Avantages :

  • Sauvegarde automatique
  • Accès de n'importe où
  • Synchronisation entre appareils

Inconvénients :

  • Utilisation de la bande passante upload
  • Coûts de stockage pour les grandes bibliothèques
  • Délais d'upload avant que les fichiers soient disponibles ailleurs

Conseils :

  • Utilisez "Files On-Demand" (OneDrive) ou "Smart Sync" (Dropbox) pour économiser l'espace local
  • Planifiez les uploads pendant les heures creuses
  • Compressez les vidéos avant le stockage cloud pour économiser de l'argent
