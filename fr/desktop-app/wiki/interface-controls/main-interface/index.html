L'interface principale - Visite complète de l'interface de SeaMeet

Chapitre 11 : L'interface principale - Visite complète de l'interface de SeaMeet

À ce stade, vous avez utilisé SeaMeet pour enregistrer de l'audio et de la vidéo, organisé votre bibliothèque et écouté vos enregistrements. Vous avez interagi avec différentes parties de l'interface, mais vous n'avez peut-être pas une vision complète de la façon dont toutes les pièces s'assemblent. Ce chapitre propose une visite exhaustive de l'interface principale de SeaMeet — chaque bouton, panneau, indicateur et contrôle — afin que vous puissiez naviguer dans l'application en toute confiance et découvrir des fonctionnalités que vous n'avez peut-être pas encore trouvées.

Considérez ce chapitre comme une visite guidée d'une nouvelle maison. Nous allons parcourir chaque pièce, examiner les caractéristiques et expliquer le rôle de chaque élément. À la fin, vous saurez exactement où trouver chaque fonction et comprendrez comment l'interface s'adapte aux différentes situations.

La disposition de la fenêtre : vue d'ensemble

Lorsque vous ouvrez SeaMeet, vous voyez une fenêtre unique avec une disposition cohérente. Cette disposition reste stable que vous soyez en train d'enregistrer, de lire un enregistrement ou simplement de parcourir votre bibliothèque. Comprendre cette disposition est la base pour utiliser SeaMeet efficacement.

Zone 1 : Barre de navigation supérieure

  • Toujours visible
  • Contient les contrôles globaux
  • Accès rapide aux fonctionnalités principales

Zone 2 : Barre latérale (Liste des enregistrements)

  • Toujours visible (dans la plupart des vues)
  • Affiche vos enregistrements
  • Liste déroulante de fiches d'enregistrement

Zone 3 : Zone de contenu principal

  • Change selon le contexte
  • Affiche le lecteur lors de la lecture d'enregistrements
  • Affiche les contrôles d'enregistrement lors de la préparation
  • Affiche les paramètres lors de la configuration des options

Zone 1 : La barre de navigation supérieure

La barre de navigation supérieure fournit la navigation et les contrôles de compte. Elle reste fine et ciblée — les contrôles d'enregistrement et Flashback ont été déplacés vers le Capture Hub dans la zone de contenu principal (voir État 1 ci-dessous).

Disposition de la barre supérieure

┌─────────────────────────────────────────────────────────────────────┐
│ [☰ Nav]  SeaMeet Screen & Audio Recorder              [👤 Compte]  │
│   │                                                        │        │
│  Bascule de navigation                            Menu profil util. │
└─────────────────────────────────────────────────────────────────────┘

Bascule de navigation (☰)

Ce que ça fait : Réduit ou développe la barre latérale gauche (liste des enregistrements).

Quand l'utiliser :

  • Réduire pour donner plus d'espace horizontal au Capture Hub
  • Développer pour parcourir votre bibliothèque d'enregistrements lorsque vous n'enregistrez pas

Compte / Menu utilisateur (👤)

Ce que ça fait : Ouvre le menu du compte utilisateur où vous pouvez :

  • Vous connecter ou vous déconnecter
  • Ouvrir les Paramètres (audio, vidéo, Flashback, stockage, langue, raccourcis)
  • Ouvrir la référence des raccourcis clavier
  • Accéder à l'aide et au support

Comment l'utiliser :

  1. Cliquez sur votre photo de profil ou l'icône utilisateur
  2. Sélectionnez l'option souhaitée dans le menu déroulant

Bouton d'enregistrement (🔴)

Icône : Cercle rouge (🔴) lorsque prêt, Carré (⏹️) pendant l'enregistrement Libellé : "RECORD" ou simplement l'icône Couleur : Rouge vif (indique l'action d'enregistrement)

Ce que ça fait : Démarre ou arrête l'enregistrement

États :

Prêt à enregistrer :

[🔴 RECORD]
Icône cercle rouge
Cliquer pour démarrer l'enregistrement

Enregistrement actif :

[⏹️ STOP]
Icône carrée
Chronomètre affichant le temps écoulé
Cliquer pour arrêter l'enregistrement

Comment l'utiliser :

Pour démarrer l'enregistrement :

  1. Configurez d'abord vos paramètres d'enregistrement
  2. Cliquez sur le bouton rouge d'enregistrement
  3. L'enregistrement commence immédiatement
  4. Le bouton change en « Stop »
  5. Le chronomètre démarre

Pour arrêter l'enregistrement :

  1. Cliquez sur le bouton « Stop » (carré)
  2. L'enregistrement s'arrête
  3. Le fichier est sauvegardé
  4. L'enregistrement apparaît dans la barre latérale
  5. Le bouton revient à l'état « Record »

Ce qui se passe quand vous cliquez sur « Record » :

  1. La capture audio/vidéo commence
  2. Un chronomètre affiche le temps écoulé
  3. Le bouton change de 🔴 à ⏹️
  4. Un indicateur visuel montre l'état de l'enregistrement
  5. Le fichier est en cours d'écriture sur le stockage

Ce qui se passe quand vous cliquez sur « Stop » :

  1. L'enregistrement s'arrête
  2. Le fichier est finalisé et sauvegardé
  3. L'enregistrement apparaît dans la liste de la barre latérale
  4. Le bouton revient à l'état 🔴
  5. Le chronomètre disparaît ou se réinitialise

Notes importantes :

  • L'enregistrement démarre immédiatement — soyez prêt !
  • Pas de compte à rebours ni d'avertissement
  • Assurez-vous que vos paramètres sont corrects avant de cliquer
  • Flashback (s'il est activé) inclut le passé mis en mémoire tampon

Barre de recherche

Emplacement : En haut de la barre latérale Apparence : Champ de texte avec icône de loupe (🔍) Texte indicatif : "Search recordings..." ou similaire

Ce que ça fait : Filtre la liste des enregistrements en temps réel pendant que vous tapez

Comment l'utiliser :

  1. Cliquez dans la barre de recherche
  2. Commencez à taper
  3. La liste se filtre automatiquement
  4. Affiche uniquement les enregistrements correspondant à votre recherche
  5. Effacez la recherche pour revoir tous les enregistrements

Ce que vous pouvez rechercher :

  • Noms des enregistrements
  • Libellés de source ("Zoom", "Teams")
  • Dates (si tapées dans un format recherchable)
  • Les correspondances partielles fonctionnent

Exemples de recherche :

  • Rechercher "Zoom" → Affiche tous les enregistrements Zoom
  • Rechercher "budget" → Affiche les enregistrements avec "budget" dans le nom
  • Rechercher "Mars" → Affiche les enregistrements de mars
  • Rechercher "client" → Affiche les enregistrements liés aux clients

Effacer la recherche :

  • Cliquez sur le bouton X (si présent)
  • Supprimez tout le texte
  • Appuyez sur la touche Échap

Fiches d'enregistrement

Chaque enregistrement de votre bibliothèque est affiché sous forme de fiche d'enregistrement — un résumé compact des informations clés de l'enregistrement.

Deux modes d'affichage :

  1. Vue compacte (par défaut) - Informations minimales, navigation efficace
  2. Vue détaillée - Informations complètes, aperçu de la forme d'onde

Vue compacte

┌──────────────────────────────────────────────────────────┐
│ 🎤 Revue budget T3 - Réunion d'équipe                    │
│ 47:32 • Aujourd'hui, 14:30 • Zoom • Audio                │
└──────────────────────────────────────────────────────────┘

Éléments :

  • Icône (🎤) - Indique le type (audio/vidéo)
  • Nom - Titre de l'enregistrement
  • Durée - Longueur (47:32)
  • Horodatage - Date d'enregistrement (Aujourd'hui, 14:30)
  • Source - Provenance (Zoom)
  • Type - Audio/Vidéo/Flashback

Quand utiliser la vue compacte :

  • Parcourir de nombreux enregistrements
  • Balayage rapide
  • Espace d'écran limité
  • Vue d'ensemble de la bibliothèque

  • Taille du fichier - Espace de stockage utilisé

Quand utiliser la vue détaillée :

  • Travailler avec un enregistrement spécifique
  • Besoin de tous les détails
  • Avant la lecture
  • Lors de l'organisation

Explication des icônes des fiches d'enregistrement

Icônes audio :

  • 🎤 - Microphone (enregistrement audio)
  • 🔴 - Audio (générique)
  • 🔊 - Audio système uniquement
  • 🎤+🔊 - Audio combiné (micro + système)

Icônes vidéo :

  • 🎥 - Enregistrement vidéo
  • 📹 - Enregistrement d'écran
  • 🖥️ - Enregistrement plein écran
  • 🪟 - Enregistrement de fenêtre

Icônes spéciales :

  • ⏪ - Enregistrement Flashback
  • 📥 - Fichier importé
  • 🌐 - Enregistrement web/navigateur

Contrôles de tri et de filtrage

Emplacement : Généralement en haut de la barre latérale, près de la recherche

Options de tri :

  • Date (plus récent en premier) - Par défaut
  • Date (plus ancien en premier)
  • Nom (A-Z)
  • Nom (Z-A)
  • Durée (plus court en premier)
  • Durée (plus long en premier)
  • Taille (plus petit en premier)
  • Taille (plus grand en premier)

Comment changer le tri :

  1. Cliquez sur le menu déroulant « Sort »
  2. Sélectionnez la méthode de tri
  3. Cliquez à nouveau pour inverser l'ordre

Options de filtrage :

  • All - Tout afficher
  • Audio only - Enregistrements audio
  • Video only - Enregistrements vidéo
  • Today - Enregistrements d'aujourd'hui
  • This week - Enregistrements récents
  • Flashback - Captures Flashback
  • By Source - Zoom, Teams, etc.

Comment filtrer :

  1. Cliquez sur le bouton ou le menu déroulant « Filter »
  2. Sélectionnez les critères de filtrage
  3. La liste se met à jour pour afficher uniquement les correspondances
  4. Cliquez sur « Clear » ou « All » pour réinitialiser

Zone 3 : La zone de contenu principal

La zone de contenu principal est le caméléon de l'interface de SeaMeet — elle change d'apparence selon ce que vous faites. Explorons ses différents états.

État 1 : Capture Hub (Inactif / Prêt à enregistrer)

Quand il s'affiche :

  • Lorsque vous ouvrez SeaMeet pour la première fois
  • Lorsqu'aucun enregistrement n'est sélectionné et que vous n'êtes pas en train d'enregistrer

Ce que vous voyez — le Capture Hub :

Panneau gauche — Démarrer l'enregistrement

Le panneau gauche contient tous les contrôles pour démarrer un nouvel enregistrement :

Contrôles latéraux (haut de la fiche) :

  • Bascule Flashback (gauche) — Cliquez pour alterner le mode Flashback : OFF → Audio → Écran → OFF. Affiche une icône d'éclair ⚡ lorsqu'il est armé (la mémoire tampon se charge ou est prête). Voir le chapitre 6 pour tous les détails.
  • Gros cercle rouge micro (centre) — Cliquez pour ouvrir la fenêtre Paramètres vidéo et choisir votre mode d'enregistrement (audio uniquement, plein écran, fenêtre, zone).
  • Bascule Auto-Detect (droite) — Active l'enregistrement automatique lorsqu'une application de réunion est détectée.

Zone de contexte (milieu de la fiche) :

  • Quand Flashback est OFF : affiche une brève description pour démarrer.
  • Quand Flashback est en cours d'armement (chargement) : affiche un indicateur de progression pendant le remplissage de la mémoire tampon.
  • Quand Flashback est prêt : affiche l'icône ⚡ et la confirmation "Flashback armed".

Bouton CTA (bas de la fiche) :

  • Le libellé et l'action s'adaptent à l'état de Flashback :
    • Flashback OFF → "Start Recording" (ouvre les Paramètres vidéo)
    • Flashback en chargement → "Buffering…" (désactivé pendant le remplissage)
    • Flashback prêt → "Record with Flashback" (capture la mémoire tampon et démarre l'enregistrement)

Raccourcis de lancement rapide (bande inférieure) :

  • Open Launcher — Ouvre le panneau Launcher de SeaMeet avec le raccourci clavier affiché
  • Open Floater — Affiche/masque le widget Floater avec le raccourci clavier affiché

Panneau droit — Prendre une capture d'écran

Le panneau droit gère les captures d'écran indépendamment des enregistrements :

  • Bouton icône caméra — Grand bouton principal ; cliquez pour prendre une capture d'écran avec le mode actuellement sélectionné.
  • Full Screen / Area Capture — Boutons radio pour choisir entre une capture plein écran ou le tracé d'une zone.
  • Case « Keep SeaMeet window visible » — Lorsqu'elle est décochée (par défaut), SeaMeet se minimise avant la capture pour ne pas apparaître dans la capture d'écran. Lorsqu'elle est cochée, la fenêtre reste visible et apparaîtra dans la capture.
  • Bouton « Take Screenshot » — Déclenche la capture (identique au clic sur l'icône caméra).

Objectif :

  • Un hub centralisé pour tout ce dont vous avez besoin avant de commencer à capturer
  • L'état de Flashback est visible et contrôlable sans ouvrir les Paramètres
  • La capture d'écran et l'enregistrement sont clairement séparés en deux fiches

Éléments :

Indicateur d'enregistrement :

  • Texte ou indicateur rouge "RECORDING"
  • Point rouge clignotant (dans certaines versions)
  • Montre que l'enregistrement est actif

Chronomètre :

  • Affiche la durée de l'enregistrement en cours
  • Format : HH:MM:SS ou MM:SS
  • Se met à jour chaque seconde

Affichage de la forme d'onde :

  • Visualisation en temps réel de l'audio
  • Montre les niveaux sonores pendant l'enregistrement
  • Permet de vérifier que l'audio est bien capturé

Indicateur de niveau audio :

  • Affiche le volume d'entrée actuel
  • Vert = Bon niveau
  • Jaune = Volume élevé
  • Rouge = Trop fort (écrêtage/distorsion)

Boutons de contrôle :

  • Pause (⏸️) - Interrompt temporairement l'enregistrement (si pris en charge)
  • Arrêter (⏹️) - Termine l'enregistrement et sauvegarde
  • Marquer (⏺️) - Ajoute un marqueur d'horodatage (si disponible)

Indicateurs visuels et icônes d'état

À travers SeaMeet, diverses icônes et couleurs fournissent un retour visuel sur l'état de l'application.

Indicateurs d'état de l'enregistrement

Pas d'enregistrement :

  • Le bouton d'enregistrement affiche 🔴 (cercle rouge)
  • Pas de chronomètre visible
  • Titre de fenêtre normal

Enregistrement actif :

  • Le bouton d'enregistrement affiche ⏹️ (carré)
  • Chronomètre affichant le temps écoulé
  • Peut avoir une bordure rouge ou un indicateur "RECORDING"
  • Le titre de la fenêtre peut changer pour afficher "[Recording]"

En pause (si pris en charge) :

  • Bouton pause mis en surbrillance
  • Chronomètre figé
  • Indicateur "PAUSED" visible

Indicateurs d'état de Flashback

OFF :

  • Couleur grise
  • "OFF" ou pas d'indicateur
  • N'utilise pas de mémoire

REMPLISSAGE :

  • Couleur ambre/jaune
  • Animation ou pulsation
  • Un pourcentage peut s'afficher (ex : "FILLING 60%")
  • Attendez le vert avant de vous y fier

PRÊT :

  • Couleur verte
  • Indicateur stable
  • Affiche la durée (ex : "30S")
  • Prêt à capturer les moments passés

Indicateurs de niveau audio

Pendant l'enregistrement :

Bon niveau (Vert) :

Audio : ████████████░░ 70%
  • Barres vertes constantes
  • Environ 60-80% est idéal

Trop faible (Bas) :

Audio : ███░░░░░░░░░░ 20%
  • Presque pas de barres
  • Augmentez le gain du microphone
  • Rapprochez-vous du microphone

Trop fort (Rouge) :

Audio : ██████████████ 100% ⚠️
  • Barres au maximum
  • Risque de distorsion
  • Diminuez le gain ou éloignez-vous

Redimensionnement et ajustements de la disposition

L'interface de SeaMeet s'adapte aux différentes tailles de fenêtre.

Taille de fenêtre standard

Taille optimale :

  • Largeur : 1000-1400 pixels
  • Hauteur : 700-900 pixels
  • Tous les éléments visibles et accessibles

Fenêtre étroite (Barre latérale réduite)

Quand la fenêtre est étroite :

  • La barre latérale peut se réduire ou devenir un menu déroulant
  • Le contenu principal occupe plus d'espace
  • Certains contrôles peuvent se déplacer dans les menus

Fenêtre large (Vue étendue)

Quand la fenêtre est large :

  • La barre latérale peut s'élargir
  • Plus de fiches d'enregistrement visibles
  • Zone du lecteur plus grande pour la vidéo

Mode plein écran

Disponible pour :

  • Lecture vidéo (touche F ou bouton)
  • Certains panneaux de paramètres
  • Mode présentation

Comment basculer :

  • Entrer : Touche F ou double-clic sur la vidéo
  • Sortir : Touche Échap ou touche F à nouveau

Personnalisation de l'interface (si disponible)

Certaines versions de SeaMeet permettent la personnalisation de l'interface.

Paramètres de thème

Mode clair :

  • Fond blanc/gris clair
  • Texte sombre
  • Standard pour une utilisation en journée

Mode sombre :

  • Fond gris foncé/noir
  • Texte clair
  • Plus confortable pour les yeux en faible luminosité
  • Peut économiser la batterie sur les écrans OLED

Comment changer :

  1. Paramètres → Langue et apparence
  2. Sélectionnez "Light" ou "Dark"
  3. Ou "Auto" pour suivre le paramètre système

Largeur de la barre latérale (si ajustable)

Comment redimensionner :

  1. Trouvez le bord entre la barre latérale et la zone principale
  2. Le curseur se transforme en curseur de redimensionnement (↔️)
  3. Faites glisser vers la gauche ou la droite
  4. Relâchez pour définir la nouvelle largeur

Astuces de navigation dans l'interface

Se déplacer rapidement

1. Utilisez les raccourcis clavier

  • Plus rapide que la souris pour les actions courantes
  • Espace pour lecture/pause
  • Flèches pour la navigation
  • Voir le chapitre 13 pour la liste complète

2. Clic droit pour les menus contextuels

  • Les enregistrements ont des menus au clic droit
  • Accès rapide aux actions courantes
  • Options différentes selon les zones

3. Cherchez les info-bulles au survol

  • Survolez les boutons pour voir leur fonction
  • Particulièrement utile pour les boutons avec icône seule
  • Affiche les raccourcis clavier si disponibles

4. Utilisez la barre de recherche

  • Moyen le plus rapide de trouver des enregistrements
  • Fonctionne en temps réel
  • Recherche dans les noms et les sources

Comprendre le retour visuel

Les couleurs ont une signification :

  • Rouge : Enregistrement, erreur, arrêt
  • Vert : Prêt, succès, actif
  • Jaune/Ambre : Avertissement, remplissage, prudence
  • Gris : Désactivé, inactif, éteint
  • Bleu : Information, liens, sélection

Les animations ont une signification :

  • Pulsation : Chargement, remplissage, en cours
  • Statique : Prêt, terminé, stable
  • Clignotement : Urgent, attention requise
