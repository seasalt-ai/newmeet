Raccourcis clavier - Maîtriser les raccourcis de SeaMeet

Chapitre 15 : Raccourcis clavier - Maîtriser les raccourcis de SeaMeet

Vous avez appris l'interface, les fonctionnalités et les flux de travail de SeaMeet. Il est maintenant temps de porter votre efficacité au niveau supérieur grâce aux raccourcis clavier. Bien que cliquer sur les boutons fonctionne, les raccourcis clavier vous permettent de contrôler SeaMeet sans retirer vos mains du clavier ou vos yeux de votre travail. Pour les utilisateurs avancés, les raccourcis font la différence entre une bonne et une excellente productivité.

Ce chapitre couvre tous les raccourcis clavier disponibles dans SeaMeet, explique comment les utiliser efficacement, vous montre comment les personnaliser selon vos préférences et vous aide à résoudre les conflits éventuels avec d'autres applications.

Pourquoi utiliser les raccourcis clavier ?

Avant de plonger dans les raccourcis spécifiques, comprenons pourquoi cela vaut la peine de les apprendre.

Vitesse et efficacité

Souris vs clavier :

  • Action souris : Déplacer la main vers la souris → déplacer le curseur vers le bouton → cliquer → revenir au clavier
  • Raccourci clavier : Appuyer sur une combinaison de touches (mains déjà sur le clavier)
  • Temps gagné : 2 à 5 secondes par action
  • Sur une journée : Minutes de temps économisé
  • Sur une année : Heures de temps économisé

Exemple de flux de travail :

Sans raccourcis :
1. Atteindre la souris (1 sec)
2. Cliquer sur Floater (1 sec)
3. Cliquer sur Record Audio (1 sec)
4. Revenir au clavier (1 sec)
Total : 4 secondes

Avec raccourcis :
1. Appuyer sur Ctrl+Alt+A (instantané)
Total : <1 seconde

Concentration et flux

Le problème avec la souris :

  • Brise votre concentration
  • Les yeux quittent le contenu de l'écran
  • Les mains quittent le clavier
  • La charge cognitive augmente

L'avantage des raccourcis :

  • Les yeux restent sur votre travail
  • Les mains restent sur le clavier
  • La concentration reste ininterrompue
  • Vous restez "dans la zone"

Scénario réel : Vous prenez des notes pendant une réunion. Vous réalisez que c'est important et que cela devrait être enregistré.

  • Avec la souris : Détourner le regard de la réunion → trouver le Floater → cliquer → revenir à la réunion (distrait, manqué ce qui a été dit)
  • Avec le raccourci : Appuyer sur les touches tout en continuant à regarder (n'a jamais raté un battement)

Professionnalisme

Pendant les réunions et appels :

  • Cliquer partout semble peu professionnel
  • Les commandes clavier sont invisibles pour les autres
  • Le partage d'écran montre un flux de travail fluide
  • Pas de tâtonnement avec l'interface

Lors des démonstrations :

  • Les raccourcis clavier semblent fluides et soignés
  • Impressionne les collègues par votre efficacité
  • Montre la maîtrise de l'outil

Comprendre les motifs de raccourcis

Remarquez les motifs logiques dans ces raccourcis :

Motif Windows/Linux

Ctrl + Alt + [Lettre]
  • Ctrl + Alt = Combinaison de touches modificatrices de SeaMeet
  • Lettre = Première lettre de l'action (généralement)
    • A = Audio
    • F = Fullscreen
    • W = Window
    • R = Region
    • K = Floater (widget)
    • L = Launcher

Motif macOS

Cmd + Shift + [Lettre]
  • Cmd + Shift = Combinaison de touches modificatrices de SeaMeet
  • Lettre = Mêmes premières lettres que Windows

Pourquoi des modificateurs différents ?

  • Windows/Linux : Ctrl+Alt est courant pour les raccourcis d'application
  • macOS : Cmd+Shift suit les conventions Apple
  • Évite les conflits avec les raccourcis système sur chaque plateforme

Descriptions détaillées des raccourcis

Record Audio : Ctrl+Alt+A (Windows) / Cmd+Shift+A (Mac)

Ce qu'il fait : Démarre immédiatement l'enregistrement audio à partir de votre source de microphone sélectionnée.

Quand l'utiliser :

  • Mémos vocaux rapides
  • Enregistrement d'appels téléphoniques
  • Capture audio de réunions
  • Lorsque vous n'avez besoin que de son, pas de vidéo

Ce qui se passe :

  1. L'enregistrement démarre instantanément
  2. Le Floater affiche l'indicateur d'enregistrement (si visible)
  3. La fenêtre principale peut s'ouvrir ou se mettre à jour
  4. Vous enregistrez maintenant l'audio

Pour arrêter :

  • Cliquez sur Stop dans le Floater ou la fenêtre principale
  • Ou utilisez le raccourci Stop (s'il est configuré)

Record Fullscreen : Ctrl+Alt+F (Windows) / Cmd+Shift+F (Mac)

Ce qu'il fait : Démarre l'enregistrement de tout votre écran.

Quand l'utiliser :

  • Enregistrement de présentations
  • Capture de tutoriels
  • Documentation de flux de travail
  • Lorsque vous avez besoin que tout soit visible

Ce qui se passe :

  1. L'enregistrement démarre immédiatement
  2. Capture tous les moniteurs (ou le principal, selon les paramètres)
  3. Inclut l'audio si configuré
  4. Enregistrement en plein écran en cours

Remarque : Assurez-vous d'avoir configuré les paramètres vidéo au préalable (qualité, fréquence d'images).

Record Window : Ctrl+Alt+W (Windows) / Cmd+Shift+W (Mac)

Ce qu'il fait : Démarre l'enregistrement d'une fenêtre d'application spécifique.

Quand l'utiliser :

  • Enregistrement de réunions Zoom/Teams
  • Capture de démonstrations d'applications spécifiques
  • Lorsque vous ne voulez pas afficher tout votre bureau
  • Enregistrement de contenu ciblé

Ce qui se passe :

  1. Si la fenêtre n'est pas pré-sélectionnée, peut vous demander d'en choisir une
  2. L'enregistrement de cette fenêtre spécifique commence
  3. La fenêtre peut être déplacée pendant l'enregistrement
  4. Seul le contenu de cette fenêtre est capturé

Configuration :

  • Certaines versions mémorisent la dernière fenêtre
  • Ou sélectionnez la fenêtre dans Video Settings d'abord

Record Region : Ctrl+Alt+R (Windows) / Cmd+Shift+R (Mac)

Ce qu'il fait : Démarre l'enregistrement d'une zone rectangulaire personnalisée de votre écran.

Quand l'utiliser :

  • Enregistrement d'une partie d'une page web
  • Capture d'éléments d'interface spécifiques
  • Création de tutoriels ciblés
  • Lorsque vous n'avez besoin que d'une section

Ce qui se passe :

  1. L'écran s'assombrit légèrement
  2. L'outil de sélection apparaît
  3. Vous dessinez un rectangle autour de la zone souhaitée
  4. L'enregistrement de cette région commence

Astuce : Certaines versions vous permettent de prédéfinir des régions dans les paramètres.

Toggle Floater : Ctrl+Alt+K (Windows) / Cmd+Alt+K (Mac)

Ce qu'il fait : Affiche le Floater s'il est masqué, ou le masque s'il est visible.

Quand l'utiliser :

  • Accès rapide aux contrôles du Floater
  • Le masquer lorsqu'il n'est pas nécessaire
  • Le ramener lorsque vous en avez besoin
  • Basculer tout au long de la journée

Ce qui se passe :

  • Si masqué : Le Floater apparaît à sa dernière position
  • Si visible : Le Floater disparaît de la vue
  • Comportement de bascule : Le même raccourci affiche et masque

Pourquoi 'K' ?

  • Près des autres raccourcis sur le clavier
  • Facile à atteindre (main gauche pour Ctrl+Alt, droite pour K)
  • Mémorisable (pensez "K"ontrol widget)

Open Launcher : Ctrl+Alt+L (Windows) / Cmd+Shift+L (Mac)

Ce qu'il fait : Ouvre le lanceur rapide de SeaMeet (si cette fonctionnalité est disponible dans votre version).

Quand l'utiliser :

  • Manière alternative de démarrer SeaMeet
  • Palette de commandes rapide
  • Accéder aux fonctionnalités sans la fenêtre principale

Remarque : Cela peut être un espace réservé ou disponible dans des versions spécifiques.

L'éditeur de notes (Ch 16 – Vue d'ensemble des notes, Ch 17 – Éditeur de notes) superpose quelques liaisons locales à l'éditeur en plus de celles globales ci-dessus. Elles ne se déclenchent que lorsque l'éditeur a le focus.

Caractères déclencheurs (tapés en ligne plutôt que comme raccourcis) :

  • [[ — ouvre le popover de suggestion wikilink listant les notes + pages wiki correspondantes. Touches fléchées pour naviguer, Entrée pour valider, Échap pour annuler. Insère [[basename]] (ou [[basename\|alias]]).
  • Bouton + de la gouttière — apparaît au début de tout paragraphe vide ; cliquer dessus ouvre le menu slash (sélecteur de blocs de style Notion). Touches fléchées pour naviguer, Entrée pour valider, Échap pour annuler. Taper / reste comme un / littéral.

Le bouton fractionné Regenerate de l'onglet AI Summary (v2.1.0) et le menu fractionné de synthèse des notes correspondant se ferment avec Échap ; la bascule de modèle Auto-suggest à l'intérieur est une case à cocher cliquable uniquement (également accessible depuis Paramètres → Fonctionnalités IA → AI Summary Templates, Ch 31–37).

Comment utiliser efficacement les raccourcis

La technique "rangée d'accueil"

Meilleure position des mains pour Windows/Linux :

Main gauche : Petit doigt sur Ctrl, annulaire sur Alt
Main droite : Libre pour appuyer sur les touches lettres

Exemple : Ctrl+Alt+A
- Petit doigt gauche : Ctrl
- Annulaire gauche : Alt  
- Main droite : Appuyer sur A

Meilleure position des mains pour Mac :

Main gauche : Petit doigt sur Cmd (⌘), annulaire sur Shift
Main droite : Libre pour appuyer sur les touches lettres

Exemple : Cmd+Shift+A
- Petit doigt gauche : Cmd
- Annulaire gauche : Shift
- Main droite : Appuyer sur A

Pourquoi cela fonctionne :

  • Les deux touches modificatrices sur la main gauche
  • La main droite libre pour les touches d'action
  • Ergonomique et rapide
  • Pas besoin de changer de main

Stratégie d'apprentissage : un à la fois

N'essayez pas de mémoriser tous les raccourcis en même temps. Utilisez cette progression :

Semaine 1 : Juste un raccourci

  • Apprenez : Record Audio (Ctrl+Alt+A ou Cmd+Shift+A)
  • Utilisez-le exclusivement pour tous les enregistrements
  • Jusqu'à ce que ce soit une mémoire musculaire

Semaine 2 : Ajouter un autre

  • Apprenez : Toggle Floater (Ctrl+Alt+K ou Cmd+Alt+K)
  • Maintenant, vous avez deux raccourcis
  • Pratiquez les deux quotidiennement

Semaine 3 : Ajouter la variété d'enregistrement

  • Apprenez : Record Fullscreen (F) et Window (W)
  • Choisissez le raccourci approprié à la situation
  • Vous choisirez naturellement le bon

Semaine 4 : Maîtriser le reste

  • Apprenez : Record Region (R)
  • Ajoutez Launcher (L) si disponible
  • Maintenant, vous avez un contrôle complet

Exercices d'entraînement

Exercice 1 : Le tir rapide

  1. Appuyez sur Ctrl+Alt+A pour démarrer l'audio
  2. Comptez jusqu'à 5
  3. Arrêtez l'enregistrement
  4. Répétez 10 fois
  5. Objectif : Mouvement fluide et sans effort

Exercice 2 : Le changement de mode

  1. Démarrez l'enregistrement audio (A)
  2. Arrêtez
  3. Démarrez en plein écran (F)
  4. Arrêtez
  5. Démarrez la fenêtre (W)
  6. Arrêtez
  7. Répétez le cycle
  8. Objectif : Changement de mode rapide

Exercice 3 : La danse du Floater

  1. Appuyez sur K pour afficher le Floater
  2. Appuyez sur K pour masquer le Floater
  3. Répétez 20 fois
  4. Objectif : Le basculement devient automatique

Personnaliser vos raccourcis

SeaMeet vous permet de personnaliser les raccourcis pour correspondre à vos préférences ou éviter les conflits avec d'autres applications.

Accéder aux paramètres de raccourcis

Méthode 1 : Via Paramètres

  1. Ouvrez SeaMeet
  2. Cliquez sur ⚙️ Paramètres
  3. Naviguez jusqu'à "Raccourcis clavier" ou "Hotkeys"
  4. Voir la liste des raccourcis personnalisables

Méthode 2 : Accès direct

  • Certaines versions ont une section dédiée aux raccourcis
  • Regardez dans la barre latérale gauche des Paramètres

Comment modifier un raccourci

Étape par étape :

  1. Trouvez l'action

    • Localisez "Record Audio" ou autre action dans la liste
    • Voir le raccourci actuel

  2. Cliquez pour modifier

    • Cliquez sur le champ de raccourci
    • Peut indiquer "Cliquer pour modifier" ou similaire

  3. Appuyez sur la nouvelle combinaison de touches

    • Appuyez sur les touches souhaitées
    • Exemple : Appuyez sur Ctrl+Shift+1
    • La combinaison apparaît dans le champ

  4. Vérifiez les conflits

    • SeaMeet peut avertir si le raccourci est déjà pris
    • Voir la section "Détection des conflits" ci-dessous

  5. Enregistrez la modification

    • Cliquez sur "Enregistrer" ou "Appliquer"
    • Le nouveau raccourci est maintenant actif

Exemple de personnalisation :

Changer : Ctrl+Alt+A (Record Audio)
Pour :    Ctrl+Shift+1

Pourquoi : Plus facile à atteindre, évite la touche Alt

Bonnes pratiques de personnalisation

À faire :

  • ✅ Choisir des combinaisons facilement accessibles
  • ✅ Utiliser des motifs qui ont du sens pour vous
  • ✅ Tenir compte des conflits avec d'autres applications
  • ✅ Documenter vos personnalisations
  • ✅ Tester immédiatement après modification

À ne pas faire :

  • ❌ Utiliser des touches uniques (peuvent entrer en conflit avec la saisie)
  • ❌ Copier les raccourcis système (Cmd+S pour enregistrer, etc.)
  • ❌ Utiliser des raccourcis nécessitant les deux mains
  • ❌ Les rendre trop complexes (4+ touches)
  • ❌ Oublier ce que vous avez modifié

Alternatives personnalisées suggérées

Si les raccourcis par défaut ne fonctionnent pas pour vous :

Pour Windows/Linux :

Record Audio :       Ctrl+Shift+1
Record Fullscreen :  Ctrl+Shift+2
Record Window :      Ctrl+Shift+3
Record Region :      Ctrl+Shift+4
Toggle Floater :     Ctrl+Shift+0

Pour Mac :

Record Audio :       Cmd+Option+1
Record Fullscreen :  Cmd+Option+2
Record Window :      Cmd+Option+3
Record Region :      Cmd+Option+4
Toggle Floater :     Cmd+Option+0

Avantages des motifs numériques :

  • Faciles à retenir (1=Audio, 2=Fullscreen, etc.)
  • Séquentiels et logiques
  • Une main peut appuyer sur toutes les touches
  • Moins de risques de conflit

Détection et résolution des conflits

L'un des défis des raccourcis globaux est qu'ils peuvent entrer en conflit avec d'autres applications ou fonctions système. SeaMeet inclut une détection de conflits pour vous aider à identifier et résoudre ces problèmes.

Qu'est-ce qu'un conflit ?

Un conflit se produit lorsque :

  • Deux applications utilisent le même raccourci
  • Le système réserve un raccourci
  • Le raccourci est invalide
  • SeaMeet ne peut pas enregistrer le raccourci

Symptômes :

  • Le raccourci ne fonctionne pas
  • SeaMeet affiche un avertissement
  • L'autre application a la priorité
  • Fonctionnalité intermittente

Comment SeaMeet détecte les conflits

Détection automatique :

  • SeaMeet essaie d'enregistrer chaque raccourci
  • Si l'enregistrement échoue, il est marqué comme en conflit
  • Un avertissement apparaît dans l'interface
  • Les raccourcis en conflit sont affichés dans la liste

Indicateurs visuels :

Record Audio : Ctrl+Alt+A  ⚠️ Conflit détecté

Où vous verrez les conflits :

  • Page Paramètres → Raccourcis clavier
  • Peut afficher une surbrillance rouge ou une icône d'avertissement
  • L'info-bulle explique le conflit

Sources courantes de conflits

1. Autres applications d'enregistrement

  • OBS Studio
  • Outils d'enregistrement d'écran
  • Applications de mémo vocal
  • Logiciels d'enregistrement de jeux

2. Applications de communication

  • Slack (a de nombreux raccourcis)
  • Discord
  • Microsoft Teams
  • Zoom

3. Raccourcis système

  • Alt+Tab (changement de fenêtre Windows)
  • Cmd+Espace (Spotlight Mac)
  • Raccourcis d'accessibilité
  • Changement de langue

4. Outils de développement

  • Raccourcis IDE
  • Raccourcis terminal
  • Outils Git
  • Éditeurs de code

5. Raccourcis du navigateur

  • Extensions Chrome
  • Modules complémentaires Firefox
  • Raccourcis d'applications web
  • Raccourcis de favoris

Résoudre les conflits

Option 1 : Changer le raccourci SeaMeet

  1. Allez dans Paramètres → Raccourcis clavier
  2. Trouvez le raccourci en conflit
  3. Cliquez pour le modifier
  4. Choisissez une combinaison de touches différente
  5. Enregistrez

Exemple :

Conflit : Ctrl+Alt+A utilisé par Zoom
Changer SeaMeet en : Ctrl+Shift+1
Résultat : Plus de conflit

Option 2 : Changer le raccourci de l'autre application

  1. Ouvrez l'application en conflit
  2. Trouvez ses paramètres de raccourcis clavier
  3. Modifiez ou désactivez le raccourci en conflit
  4. Revenez à SeaMeet
  5. Le conflit est résolu

Exemple :

Conflit : Discord utilise Ctrl+Alt+R
Changer Discord en : Ctrl+Alt+Shift+R
SeaMeet conserve : Ctrl+Alt+R
Résultat : Les deux applications fonctionnent

Option 3 : Utiliser des touches modificatrices différentes

Au lieu de Ctrl+Alt, essayez :

  • Ctrl+Shift
  • Alt+Shift
  • Ctrl+Alt+Shift
  • Touches de fonction (F1-F12)

Pour Mac : Au lieu de Cmd+Shift, essayez :

  • Cmd+Option
  • Cmd+Control
  • Cmd+Shift+Option
  • Touches de fonction

Bonnes pratiques de conflit

Prévention :

  • Choisissez des raccourcis uniques non utilisés par les applications courantes
  • Évitez les combinaisons réservées au système
  • Utilisez les touches de fonction (F9-F12) pour moins de conflits
  • Documentez vos raccourcis

Détection :

  • Vérifiez immédiatement les avertissements de conflit
  • Testez les raccourcis après les avoir définis
  • Surveillez si les raccourcis cessent de fonctionner
  • Soyez conscient des applications nouvellement installées

Priorité de résolution :

  1. Essayez d'abord de changer SeaMeet (le plus facile)
  2. Si l'autre application est rarement utilisée, modifiez-la
  3. Si l'autre application est critique, contournez-la
  4. Envisagez d'utiliser des touches modificatrices différentes

Considérations spécifiques à la plateforme

Windows

Conflits Windows courants :

  • Alt+Tab (changement de fenêtre) - Réservé système
  • Win+L (verrouillage écran) - Réservé système
  • Ctrl+Alt+Suppr (sécurité) - Réservé système
  • De nombreuses applications utilisent des combinaisons Ctrl+Alt

Avantages Windows :

  • De nombreuses combinaisons de touches disponibles
  • Raccourcis globaux bien pris en charge
  • Facile à personnaliser

Conseils Windows :

  • Utilisez Ctrl+Shift pour éviter les conflits
  • Touches de fonction souvent disponibles
  • Combos touche Windows + souvent réservés système (à éviter)

macOS

Conflits Mac courants :

  • Cmd+Espace (Spotlight) - Réservé système
  • Cmd+Tab (changement d'app) - Réservé système
  • Cmd+Shift+3/4 (captures d'écran) - Réservé système
  • De nombreuses applications Apple utilisent Cmd+Shift

Avantages Mac :

  • Système de raccourcis globaux propre
  • La touche Option offre de nombreuses options
  • Moins d'interférences d'applications que Windows

Conseils Mac :

  • Les combinaisons Cmd+Option sont souvent disponibles
  • Les touches de fonction nécessitent la touche Fn (ou pref système)
  • Les combos Control+ moins couramment utilisés

Linux

Considérations Linux :

  • L'environnement de bureau compte (GNOME, KDE, etc.)
  • Chaque DE a ses propres raccourcis
  • Plus de variabilité que Windows/Mac

Conseils Linux :

  • Vérifiez les paramètres clavier de votre DE
  • La touche Super (Windows) souvent utilisée par le DE
  • Ctrl+Alt populaire mais peut entrer en conflit

Conseils avancés sur les raccourcis

Créer des flux de travail de raccourcis

Exemple : Flux de travail d'enregistrement de réunion

Configuration avant la réunion :

1. Appuyez sur Ctrl+Alt+K (afficher le Floater)
2. Activez Flashback dans le Floater
3. Attendez l'indicateur vert

Pendant la réunion :

1. Appuyez sur Ctrl+Alt+A (démarrer l'enregistrement audio)
2. Prenez des notes pendant la réunion
3. Appuyez sur Ctrl+Alt+K puis cliquez sur Stop dans le Floater (ou utilisez le raccourci Stop)

Résultat : Réunion complète enregistrée sans souris !

Combinaisons de raccourcis

Enchaîner les raccourcis :

Ctrl+Alt+F (démarrer plein écran)
... enregistrement ...
Ctrl+Alt+K (afficher le Floater)
Cliquez sur Stop dans le Floater
Ctrl+Alt+K (masquer le Floater)

Flux de travail uniquement au clavier :

Cmd+Shift+A (enregistrer l'audio)
Espace (pause - si pris en charge)
Espace (reprendre)
Échap ou raccourci Stop (terminer)

Considérations d'accessibilité

Pour les utilisateurs à mobilité limitée :

  • Raccourcis à une main possibles
  • Prise en charge des touches rémanentes (appuyer sur les modificateurs un par un)
  • Alternatives de contrôle vocal
  • Claviers à grandes touches

Pour les utilisateurs malvoyants :

  • Les raccourcis réduisent le besoin de localiser les boutons
  • Retour audio important
  • Les raccourcis cohérents aident la mémoire musculaire
  • Compatibilité lecteur d'écran

Dépannage des raccourcis

"Le raccourci ne fonctionne pas"

Vérifiez ceci :

  1. SeaMeet est-il en cours d'exécution ?

    • Les raccourcis globaux ne fonctionnent que lorsque l'application est active
    • Vérifiez l'icône SeaMeet dans la barre des tâches

  2. Y a-t-il un conflit ?

    • Vérifiez les avertissements de conflit dans les Paramètres
    • Essayez un raccourci différent
    • Vérifiez d'autres applications

  3. Appuyez-vous sur les bonnes touches ?

    • Windows : Ctrl+Alt (pas Ctrl+Shift)
    • Mac : Cmd+Shift (pas juste Cmd)
    • Vérifiez si Num Lock affecte les touches numériques

  4. Problèmes de disposition du clavier ?

    • Les différentes langues ont des dispositions différentes
    • Certaines touches peuvent être à des positions différentes
    • Essayez d'utiliser le clavier à l'écran pour vérifier

"Le raccourci fonctionne par intermittence"

Causes possibles :

  1. Problèmes de focus

    • Certains raccourcis ne fonctionnent que lorsque SeaMeet est focalisé
    • D'autres fonctionnent globalement (dépend de l'implémentation)

  2. Conflit avec une autre application

    • Une autre application peut voler le raccourci
    • Fermez d'autres applications pour tester

  3. Système sous charge

    • Une utilisation élevée du CPU peut retarder la réponse aux raccourcis
    • Fermez les programmes inutiles

"Impossible de personnaliser les raccourcis"

Raisons possibles :

  1. Les paramètres ne sont pas enregistrés

    • Vérifiez que SeaMeet a l'autorisation d'enregistrer les paramètres
    • Essayez d'exécuter en tant qu'administrateur (Windows)
    • Vérifiez l'espace disque

  2. Raccourci invalide

    • Certaines combinaisons ne sont pas autorisées
    • Raccourcis réservés au système bloqués
    • Essayez une combinaison différente

  3. Limitation de version

    • Certaines versions peuvent ne pas prendre en charge la personnalisation
    • Vérifiez les mises à jour

Navigation dans la liste de la barre latérale

En plus des raccourcis globaux, SeaMeet prend en charge la navigation au clavier dans la liste d'enregistrements de la barre latérale.

Naviguer dans la liste d'enregistrements

Une fois que vous cliquez n'importe où dans la liste d'enregistrements de la barre latérale pour lui donner le focus, vous pouvez naviguer sans la souris :

ToucheAction
↑ Flèche hautDéplacer la sélection vers l'enregistrement précédent
↓ Flèche basDéplacer la sélection vers l'enregistrement suivant

L'enregistrement sélectionné défile automatiquement dans la vue à mesure que vous vous déplacez dans la liste.

Pour activer la navigation au clavier :

  1. Cliquez sur n'importe quel enregistrement dans la liste de la barre latérale
  2. Utilisez ↑ / ↓ pour naviguer

La navigation se désactive lorsque :

  • Vous cliquez en dehors de la barre latérale (par exemple, sur la zone de contenu principal ou un champ de texte)
  • Vous interagissez avec une visionneuse de captures d'écran ou un lecteur

Astuce : Ceci est utile pour parcourir rapidement les enregistrements sans atteindre la souris — appuyez sur ↓ à plusieurs reprises pour parcourir les enregistrements récents tout en regardant la mise à jour du lecteur.
