术语表

第 26 章：术语表

简介

录制软件和任何技术领域一样，有着自己的词汇。"编解码器"、"比特率"、"帧率"和"编码"等词不断出现。本章是您的全面词典——解释您在使用 SeaMeet 或阅读有关音频/视频录制内容时可能遇到的每个技术术语。

如果您不是技术人员也不用担心。每个术语都用通俗的语言解释，并附有类比来帮助您理解。当您遇到不熟悉的词时，可以将本章作为参考。

本章目标

阅读本章后，您将能够：

  • 理解 SeaMeet 中使用的技术术语
  • 了解常见混淆术语之间的区别
  • 在故障排除时使用正确的术语
  • 基于技术概念做出明智的决策

A

Audio Buffer

在处理或保存之前临时存储音频数据的空间。就像一个等候室，音频采样在被编码前在此排队。

Audio Interface

将麦克风和乐器连接到计算机的硬件。通常比内置声卡提供更好的音频质量。

Action Items (AI)

由 AI 摘要从录制中识别的任务。每个行动项包括任务描述、指定的负责人和截止日期（如果在对话中提到）。参见第 28 章。

AI Extraction

SeaMeet 的录制后分析功能。录制结束后，点击 ✨ "Generate Summary" 将音频发送到 AI 引擎，返回五种结构化输出：转录文本、摘要、行动项、关键决策和章节。参见第 28 章。

AI Insights

SeaMeet 中显示录制的所有 AI 生成结果的面板。可从录制详情视图访问。包含转录文本、摘要、行动、决策和章节的标签。

Audio Track

视频文件中的单独音频流。一个视频可能有多个轨道：您的麦克风、系统音频、背景音乐。

Auto-Detection

SeaMeet 的功能，可自动识别您何时加入会议并在无需手动干预的情况下开始录制。

AVI (Audio Video Interleave)

由 Microsoft 开发的较旧视频文件格式。在 Windows 上运行良好，但与现代设备的兼容性较差。

B

Bit

数字信息的最小单位。要么是 0，要么是 1。计算机上的一切都由比特组成。

Bit Depth (Audio)

用多少比特来表示每个音频采样。更高的位深度 = 更多细节 = 更大的文件。CD 品质为 16 位。

Bitrate

每秒处理的数据量。通常以千比特每秒 (kbps) 或兆比特每秒 (Mbps) 为单位。越高 = 更好的质量 = 更大的文件。

Bluetooth Latency

声音产生和您通过蓝牙连接听到之间的延迟。通常为 100-300ms，这会导致同步问题。

Buffer

在传输或处理数据时临时存储的区域。就像一个蓄水池，在水流过管道之前储存水。

Buffer Duration (Flashback)

SeaMeet 在循环缓冲区中保留多少秒的画面。当您保存 Flashback 时，您会获得这段时间的过去画面。

Byte

一组 8 个比特。衡量文件大小的标准单位。一兆字节 (MB) 约为一百万个字节。

C

Circular Buffer

一种到达末端时循环回到开头的缓冲区。SeaMeet 将此用于 Flashback——持续录制并覆盖旧数据。

Codec (Coder-Decoder)

压缩和解压缩音频或视频的软件。H.264 是视频编解码器。MP3 是音频编解码器。

Codec vs. Container

编解码器是压缩方法（数据如何被压缩）。容器是文件格式（存放数据的盒子）。MP4 是通常包含 H.264 视频的容器。

Compression

通过移除冗余或不太重要的数据来减小文件大小。可以是无损的（无质量损失）或有损的（有一定质量损失但文件更小）。

Chapters (AI)

AI 摘要的五种输出之一。带时间索引的主题分段，类似于书中的章节。在 AI Insights 面板中点击章节会跳转到录制中的该时刻。参见第 28 章。

CPU (Central Processing Unit)

计算机的"大脑"。进行计算和运行程序。录制软件使用 CPU 来编码视频。

Cursor Highlighting

在录制中引起对鼠标光标注意的视觉效果。对教程很有用，这样观众可以跟随您的操作。

D

Decibel (dB)

衡量声音音量的单位。用于 SeaMeet 的音频电平表。-12 dB 是良好的录制电平。0 dB 是最大值（失真）。

Default Device

Windows/macOS 自动使用的音频或视频设备。SeaMeet 可以使用默认设备或让您选择特定设备。

Detection Method (Auto-Detection)

SeaMeet 如何识别您正在会议中。方法包括窗口标题分析、进程监控和音频检测。

Digital Audio

用数字表示的声音。您的计算机将声波转换为可以存储和处理的数字采样（数字）。

Disk Space

硬盘或 SSD 上的可用存储空间。录制视频需要大量磁盘空间。

DRM (Digital Rights Management)

防止复制受保护内容的技术。Netflix、DVD 和一些流媒体服务使用 DRM，它会阻止屏幕录制。

Decisions (AI)

AI 摘要的五种输出之一。会议中做出的关键选择和协议列表，从对话中提取。与行动项不同——决策是达成的共识，行动是因此需要做的事。参见第 28 章。

Drop Frame

当视频录制丢帧时，导致卡顿。通常在计算机无法跟上编码需求时发生。

E

Echo Cancellation

从录制中消除回声的技术。在使用扬声器而不是耳机时很有用——防止麦克风拾取扬声器声音。

Encode

将原始视频/音频转换为压缩格式的过程。CPU 或 GPU 在您录制时实时执行此操作。

Encoder

执行编码的软件或硬件。SeaMeet 使用软件编码器（CPU）或硬件编码器（GPU）。

External Drive

通过 USB 连接的硬盘或 SSD。可用于存储录制，但可能比内部驱动器慢。

F

Flashback

SeaMeet 的时光机功能，在循环缓冲区中持续录制，让您可以保存过去的时刻。

Flashback Buffer

Flashback 使用的临时内存存储。保存最近 X 秒的视频/音频。

Floater (SeaMeet Floater)

出现在屏幕上用于快速录制控制的浮动组件。可以最小化为小图标或展开为完整控件。

FPS (Frames Per Second)

每秒捕获多少静态图像（帧）来创建视频。30fps 是标准的。60fps 更流畅。

Fullscreen Recording

捕获整个屏幕的录制模式。适用于会议和需要捕获所有内容的场景。

Frame

视频中的单个静态图像。视频本质上是一系列快速播放的帧（每秒 30-60 帧）来创造运动。

G

Gain

音频信号的放大级别。增加增益使录制中的音频更响。与音量不同（音量影响播放）。

Game Mode

Windows 功能，优先处理游戏应用程序。可以帮助录制性能，但有时与录制软件冲突。

GPU (Graphics Processing Unit)

计算机中的显卡。可用于硬件加速视频编码（比 CPU 快得多）。

GPU Encoding

使用显卡而不是 CPU 来编码视频。也称为硬件加速。更快更高效。

H

H.264 (AVC)

最常见的视频编解码器。以合理的文件大小提供良好的质量。在几乎所有设备上都能工作。

H.265 (HEVC)

更新、更高效的视频编解码器。在相同质量下产生比 H.264 小约 50% 的文件。通用支持较少。

Hardware Acceleration

使用专用硬件（如 GPU）来执行任务而不是通用 CPU。使视频编码更快。

Hardware Encoder

GPU 上的专用芯片，用于编码视频。NVIDIA 称之为 NVENC。Intel 称之为 Quick Sync。

HD (High Definition)

1280x720 (720p) 或更高的视频分辨率。提供清晰、详细的视频。

Headphones vs. Speakers

录制时使用耳机可防止回声（扬声器声音被麦克风拾取）。推荐以获得最佳音频质量。

I

I-Frame (Intra-frame)

不依赖其他帧的完整视频帧。作为参考点。文件大小较大但对于定位搜索是必要的。

Import

将外部音频或视频文件导入 SeaMeet。SeaMeet 可以导入各种格式进行播放和管理。

Input Device

向计算机发送音频/视频的硬件。麦克风、摄像头和采集卡都是输入设备。

J

Jitter

音频/视频数据时序的变化。导致播放卡顿或不均匀。通常由系统性能问题引起。

Join a Meeting

通过 Zoom、Teams、Meet 等进入在线会议。SeaMeet 可以自动检测您何时加入并开始录制。

K

Kbps (Kilobits per second)

数据速率的度量。用于音频比特率。128 kbps 是 MP3 的标准。192 kbps 是更高质量。

Keyframe

参见 I-Frame。用作参考点的完整视频帧。

Keyboard Shortcuts

快速触发操作的按键组合。Ctrl+Alt+R 开始录制。快捷键比点击界面更节省时间。

L

Latency

动作和处理或听到之间的延迟。蓝牙耳机有高延迟。有线耳机几乎没有。

Live Transcription

SeaMeet 的功能，在录制期间将语音实时转换为文本。单词在说出时出现在转录文本面板中，带有时间戳和说话人标签。需要启用 AI 功能和互联网连接。参见第 27 章。

Library (Recording Library)

SeaMeet 中所有录制的集合。显示缩略图、元数据，并允许播放/管理。

Lossless Compression

在不丢失任何数据的情况下减小文件大小的压缩。可以完美重建。FLAC 音频使用无损压缩。

Lossy Compression

永久移除一些数据以实现更小文件的压缩。MP3 和 H.264 是有损的。质量损失通常不可感知。

Low-Memory Mode

SeaMeet 的功能，降低质量以使用更少的 RAM。适用于较旧的计算机或运行内存密集型应用时。

M

Macroblock

视频压缩中使用的 16x16 像素方块。H.264 将帧分成宏块以高效压缩。

Mbps (Megabits per second)

用于视频的数据速率度量。8 Mbps 对 1080p 视频来说很好。越高 = 更好的质量 = 更大的文件。

Metadata

关于文件的信息（不是实际内容）。包括创建日期、时长、分辨率等。

Microphone Array

多个麦克风协同工作。一些笔记本电脑有麦克风阵列以获得更好的声音拾取和降噪。

Minimize to Tray

SeaMeet 可以在后台运行，通过系统托盘图标（在时钟附近）访问。节省任务栏空间。

MKV (Matroska)

灵活的视频容器格式。支持多个音频轨道和字幕。适合存档。

Monitor

您的计算机屏幕。SeaMeet 可以录制一个显示器或所有显示器（如果您有多个）。

Mono vs. Stereo

单声道 = 1 个音频声道。立体声 = 2 个声道（左和右）。立体声听起来更沉浸但创建更大的文件。

MOV

Apple 的视频容器格式。在 Mac 上常见。质量好但在 Windows 上没有额外软件兼容性较差。

MP3

最流行的音频格式。使用有损压缩。文件小，通用兼容。典型 128-320 kbps。

MP4

最流行的视频容器格式。在几乎所有设备上工作。通常包含 H.264 视频和 AAC 音频。

Multi-Monitor

使用多个屏幕。SeaMeet 可以录制所有显示器或仅一个。录制多个显示器使用更多资源。

Mute

临时关闭音频输入或输出。SeaMeet 可以静音录制而不影响系统音量。

N

Native Resolution

屏幕实际显示的像素数。以原生分辨率录制提供最清晰的结果。

Noise Suppression

从音频录制中去除背景噪音（风扇、空调）的技术。使语音更清晰。

Notification

提醒您事件的弹出消息。SeaMeet 在录制开始、停止或检测到会议时显示通知。

NVENC

NVIDIA 的硬件视频编码器。在 GTX 600 系列及更新版本上可用。以最少的 CPU 使用进行快速编码。

O

Ogg

开源音频格式。良好的压缩但有限的设备支持。通常使用 Vorbis 编解码器。

Output Device

从计算机播放音频的硬件。扬声器和耳机是输出设备。

Overhead (CPU/Memory)

录制软件本身使用的资源，与实际录制分开。SeaMeet 的开销很低。

P

P-Frame (Predicted Frame)

仅存储与前一帧差异的视频帧。比 I 帧小得多。创建高效压缩。

PCM (Pulse Code Modulation)

未压缩的数字音频格式。在编码为 MP3 或其他格式之前内部使用。高质量，大文件。

Permissions

访问系统资源的授权。macOS 和 Windows 要求您授予 SeaMeet 录制屏幕和音频的权限。

Pixel

屏幕上的单个颜色点。图像由数千或数百万个像素组成。1920x1080 = 约 200 万像素。

Playback

观看或收听录制。SeaMeet 有内置播放器用于查看录制。

Pop Filter

麦克风的泡沫或网格罩，可减少 "p" 和 "b" 的爆破声。改善音频质量。

Process Monitoring

监视正在运行的程序的自动检测方法。检测 zoom.exe 或 Teams.exe 何时启动。

Q

Quantization

降低数据精度以节省空间。是压缩的一部分。简化几乎相同的颜色/声音。

Quick Sync

Intel 的硬件视频编码器。内置在现代 Intel 处理器中。高效且质量好，适合录制。

R

RAM (Random Access Memory)

计算机的短期记忆。SeaMeet 使用 RAM 进行 Flashback 缓冲和处理。更多 RAM = 更好的性能。

RAW Audio/Video

未压缩的数据。大文件但最高质量。SeaMeet 通常编码为压缩格式以节省空间。

Real-time

实时发生，无延迟。SeaMeet 在您录制时实时编码视频。无需等待后期处理。

Recording Mode

SeaMeet 如何捕获视频：全屏（整个屏幕）、窗口（特定应用）或区域（选定区域）。

Region Recording

仅录制屏幕的选定部分。最高效的模式——只捕获您需要的内容。

Resolution

图像中的像素数。1920x1080 表示 1920 像素宽 x 1080 像素高。越高 = 越清晰 = 越大的文件。

Ring Menu (Floater)

展开 Floater 组件时出现的圆形控制界面。提供对录制控件的快速访问。

S

Sample Rate (Audio)

每秒测量音频多少次。CD 品质为 44.1 kHz（每秒 44,100 个采样）。越高 = 更好的质量。

Sampling

通过定期测量将连续声波转换为数字数字。

Save Location

SeaMeet 存储录制的文件夹。可在设置中更改。应有足够的可用空间。

Screen Recording

捕获计算机屏幕的视频。SeaMeet 专门用于带音频的屏幕录制。

Screenshot

屏幕的静态图像捕获。SeaMeet 可以通过键盘快捷键或 Floater 进行截图。

Sensitivity (Auto-Detection)

SeaMeet 查找会议的积极程度。高灵敏度捕获更多会议但可能有误报。

Shortcut

参见键盘快捷键。不使用鼠标控制 SeaMeet 的快速方式。

Sidebar

SeaMeet 中显示不同部分的左侧面板：录制、视频、Flashback 等。

Source (Audio/Video)

信号的来源。音频源包括麦克风和系统音频。视频源包括屏幕和窗口。

Speaker Detection

在实时转录或 AI 摘要期间自动识别谁在说话的过程。每个不同的声音被分配一个标签（"Speaker 1"、"Speaker 2"）。清晰的音频和最少的交叉对话可提高准确性。参见第 27 章。

Speaker Label

转录文本中分配给说话人的名称。默认为 "Speaker 1"、"Speaker 2" 等。可以重命名（例如 "Alice"），或者如果两个标签属于同一人则可以合并。参见第 29 章。

SRT (SubRip Subtitle)

字幕的文本文件格式。包含带时间戳的文本行。SeaMeet 可以将转录文本导出为 SRT 文件，可导入视频编辑器（Premiere、iMovie）或上传到 YouTube 作为字幕。

SSD (Solid State Drive)

没有移动部件的快速存储设备。录制时比传统硬盘 (HDD) 更好。写入速度更快。

Stereo Mix

Windows 音频功能，允许您录制系统音频。SeaMeet 可以使用 Stereo Mix 或 WASAPI 进行系统音频捕获。

Storage

硬盘或 SSD 上保存录制的空间。视频录制需要大量存储空间。

Stream

持续的数据流。录制时捕获和编码音频和视频流。

Sync (Audio-Video)

音频和视频正确对齐。不同步意味着您看到嘴唇在听到声音之前/之后移动。

System Audio

来自计算机的声音——通知、视频、会议声音。SeaMeet 可以将系统音频与麦克风分开录制。

System Tray

时钟附近后台应用显示图标的区域。SeaMeet 可以最小化到系统托盘。

T

Theme (Light/Dark)

SeaMeet 的视觉外观。浅色主题有白色背景。深色主题有深色背景。夜间更护眼。

Thumbnail

代表视频的小预览图像。SeaMeet 在库中显示录制的缩略图。

Time Machine (Flashback)

Flashback 功能的比喻。让您"回到过去"捕获已经发生的时刻。

Timeline

录制时长的可视化表示。SeaMeet 的播放器显示带有播放位置的时间线。

Toggle

打开或关闭功能的开关。SeaMeet 在设置中使用切换——点击在两种状态之间切换。

Transcript

口述音频的文本记录。SeaMeet 产生两种：实时转录文本（录制过程中实时捕获的文字）和提取转录文本（录制后从音频文件产生的）。两者都出现在 AI Insights 面板的转录文本标签下。参见第 27 章和第 28 章。

Track (Audio)

文件中的单独音频流。SeaMeet 可以录制多个轨道：麦克风、系统音频等。

Trim

移除录制中不需要的开头或结尾部分。SeaMeet 允许修剪已保存的录制。

Troubleshooting

U

通过 USB 端口连接的麦克风。易于使用，通常比内置笔记本电脑麦克风质量更好。

V

VBR (Variable Bit Rate)

根据内容复杂度调整质量的编码方法。简单场景使用较低比特率。复杂场景使用较高比特率。

当至少运行过一次重新生成时，出现在 AI Insights 标签栏中的小标签（例如 "v3 ▾"）。点击它打开版本选择器。参见第 29 章。

录制的所有先前 AI 摘要运行的记录。每次重新生成 (⟳) 时，SeaMeet 在覆盖之前将先前结果保存为编号快照。您可以随时查看任何过去的版本。参见第 29 章。

Video Track

视频文件的视觉组件。与音频轨道分开。视频文件包含至少一个视频轨道。

Volume

音频的响度。与增益不同——音量影响您听到的。增益影响录制的内容。

VP8/VP9

在 WebM 文件中使用的开源视频编解码器。质量好，免费使用。VP9 比 VP8 更新、更高效。

WASAPI (Windows Audio Session API)

捕获系统音频的现代 Windows 方法。在某些系统上比 Stereo Mix 更可靠。

未压缩的音频格式。大文件但完美质量。适合存档或编辑。

WebM

由 Google 开发的开源视频格式。适合网页使用。使用 VP8 或 VP9 编解码器。

读取应用程序窗口标题的自动检测方法。查找 "Zoom Meeting" 或 "Teams" 等关键词。

X

高端麦克风上使用的专业音频连接器。需要音频接口才能连接到计算机。

Y

流行的视频分享平台。SeaMeet 录制可以上传到 YouTube。YouTube 建议特定设置以获得最佳效果。

Z

Zero Latency

动作和录制之间无延迟。在实践中不可能，但有线连接和良好的硬件可以将延迟降至最低。

容易混淆的术语解释

Codec vs. Container

  • 编解码器：数据如何被压缩（H.264、MP3）
  • 容器：数据存储在哪里（MP4、WebM、AVI）

类比：编解码器是书写的语言。容器是书本身。

Bitrate vs. Resolution

  • 比特率：每秒多少数据（影响质量和文件大小）
  • 分辨率：多少像素（影响清晰度）

您可以有高分辨率低比特率（有马赛克）或低分辨率高比特率（流畅但小）。

Gain vs. Volume

  • 增益：输入电平（录制的响度）
  • 音量：输出电平（播放的响度）

改变音量不影响录制。改变增益影响录制。

Latency vs. Delay

  • 延迟（Latency）：数字系统中延迟的技术术语
  • 延迟（Delay）：任何等待时间的通用术语

它们本质上是同一回事，但 "latency" 用于技术上下文。

Frame Rate vs. Resolution

  • 帧率：每秒多少张图片（流畅度）
  • 分辨率：每张图片多详细（清晰度）

60fps 720p 比 30fps 1080p 更流畅，但 1080p 更清晰。
