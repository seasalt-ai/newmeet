术语表

第 30 章：术语表

介绍

录音软件，像任何技术领域一样，有自己的词汇。"编解码器"、"码率"、"帧率"和"编码"等词不断被提及。本章是你的综合字典——解释你在使用 SeaMeet 或阅读音视频录制相关内容时可能遇到的每个技术术语。

如果你不是技术人员也别担心。每个术语都用通俗英语解释，并配有类比帮你理解。每当你遇到不熟悉的词时，把本章作为参考。

本章目标

读完本章后，你将能够：

  • 理解 SeaMeet 中使用的技术术语
  • 知道常被混淆术语之间的差异
  • 排查时使用正确的术语
  • 基于技术概念做出明智决策

A

Audio Buffer（音频缓冲）

音频数据在被处理或保存之前的临时存储。就像音频样本在被编码前排队的等候室。

Audio Interface（音频接口）

把麦克风和乐器连接到计算机的硬件。常提供比内置声卡更好的音频质量。

Action Items（AI 行动项）

通过 AI 提取从录音中识别出的任务。每个行动项包含任务描述、被分配的人和到期日（如果对话中提到）。见第 32 章。

AI Extraction（AI 提取）

SeaMeet 的录音后分析功能。录音结束后，点击 ✨ 生成摘要会把音频发送到 AI 引擎，返回五个结构化输出：转录、摘要、行动项、关键决议和章节。见第 32 章。

AI Insights（AI 洞察）

SeaMeet 中显示录音所有 AI 生成结果的面板。可从录音详情视图访问。包含转录、摘要、行动、决议和章节的标签。

Audio Track（音频轨道）

视频文件中独立的音频流。一个视频可能有多个轨道：你的麦克风、系统音频、背景音乐。

Auto-Detection（自动检测）

SeaMeet 自动识别你加入会议并可在无人工干预下开始录制的功能。

Auto-pick（自动选择）

根据录音内容自动选择最合适 AI 摘要模板的分类器。当你重新生成摘要时，Auto-pick 分析转录并挑选最合适的模板（例如站会、销售电话、面试），所以你无需手动选择。见第 33 章。

AVI (Audio Video Interleave)

Microsoft 开发的较旧视频文件格式。在 Windows 上工作良好，但与现代设备兼容性较差。

B

Bit（比特）

数字信息的最小单位。要么是 0 要么是 1。计算机上的一切都由比特组成。

BYOK (Bring Your Own Key)

SeaMeet 的订阅模式，用户提供自己的 LLM API 密钥（例如 OpenAI、Anthropic、Google），而不是通过 SeaMeet 付费推理。费用直接由提供方计费；SeaMeet 只对应用收费。

Bit Depth (Audio)（音频位深）

用多少比特表示每个音频样本。位深越高 = 细节越多 = 文件越大。CD 质量是 16 位。

Bitrate（码率）

每秒处理的数据量。通常以千比特每秒 (kbps) 或兆比特每秒 (Mbps) 衡量。更高 = 更好质量 = 更大文件。

Bluetooth Latency（蓝牙延迟）

声音产生与通过蓝牙连接听到之间的延迟。通常 100-300ms，导致同步问题。

Buffer（缓冲）

在数据传输或处理时保存数据的临时存储区域。就像在水流过管道前蓄水的水库。

Buffer Duration (Flashback)（Flashback 缓冲时长）

SeaMeet 在循环缓冲中保留多少秒的画面。保存 Flashback 时，你得到这么多过去画面。

Byte（字节）

8 个比特的组。衡量文件大小的标准单位。一兆字节 (MB) 约一百万字节。

C

Circular Buffer（循环缓冲）

到达末尾时回环到开头的缓冲类型。SeaMeet 用它做 Flashback——不断录制并覆盖旧数据。

Codec (Coder-Decoder)（编解码器）

压缩和解压缩音频或视频的软件。H.264 是视频编解码器。MP3 是音频编解码器。

Codec vs. Container（编解码器 vs 容器）

Codec 是压缩方法（如何挤压数据）。Container 是文件格式（盛放数据的盒子）。MP4 是常含 H.264 视频的容器。

Compression（压缩）

通过移除冗余或不重要数据来减小文件大小。可以是无损（无质量损失）或有损（一些质量损失但文件较小）。

Chapters (AI)（AI 章节）

AI 提取的五个输出之一。时间索引的话题段，类似书中的章节。点击 AI 洞察面板中的章节会把播放器跳到录音中的那一刻。见第 32 章。

Chunked Pipeline（分块管线）

AI 提取策略，把长视频处理为 10 分钟片以保持在 Gemini 上下文窗口内。每个块单独被转录和摘要，然后合并为单一连贯输出。自动用于超出模型单次容量的录音。

Conflict Resolution Modal（冲突解决模态）

当 GitHub 同步检测到同一笔记在两个设备上被不同地编辑时出现的对话框。让你选择保留哪个版本，或手动合并更改。见第 38 章。

CPU (Central Processing Unit)（中央处理单元）

计算机的"大脑"。做计算和运行程序。录音软件用 CPU 编码视频。

Cursor Highlighting（光标高亮）

在录音中吸引你鼠标光标注意的视觉效果。对教程有用，让观众跟随你的操作。

D

Decibel (dB)（分贝）

衡量声音音量的单位。用于 SeaMeet 的音频电平表。-12 dB 是良好录音电平。0 dB 是最大（失真）。

Default Device（默认设备）

Windows/macOS 自动使用的音频或视频设备。SeaMeet 可使用默认或让你选择特定设备。

Detection Method (Auto-Detection)（自动检测方法）

SeaMeet 如何识别你在会议中。方法包括窗口标题分析、进程监控和音频检测。

Digital Audio（数字音频）

以数字表示的声音。你的计算机把声波转换为数字样本（数字），可存储和处理。

Disk Space（磁盘空间）

你的硬盘或 SSD 上的存储量。录制视频需要可观的磁盘空间。

DRM (Digital Rights Management)（数字版权管理）

防止复制受保护内容的技术。Netflix、DVD 和一些流媒体服务使用 DRM，它会阻止屏幕录制。

Decisions (AI)（AI 决议）

AI 提取的五个输出之一。会议期间做出的关键选择和协议列表，从对话中提取。与 Action Items 不同——决议是已达成的协议，行动是作为结果必须做什么。见第 32 章。

Drop Frame（丢帧）

视频录制错过帧时，导致卡顿。通常发生在计算机跟不上编码需求时。

E

Echo Cancellation（回声消除）

从录音中移除回声的技术。在使用喇叭而不是耳机时有用——防止麦克风拾取喇叭声。

Encode（编码）

把原始视频/音频转换为压缩格式的过程。CPU 或 GPU 在你录音时实时做这件事。

Encoder（编码器）

执行编码的软件或硬件。SeaMeet 使用软件编码器 (CPU) 或硬件编码器 (GPU)。

External Drive（外部驱动器）

通过 USB 连接的硬盘或 SSD。可用于存储录音但可能比内部驱动器慢。

F

Flashback

SeaMeet 的时光机功能，在循环缓冲中持续录制，让你保存过去的瞬间。

Flashback Buffer（Flashback 缓冲）

Flashback 使用的临时内存存储。保留最后 X 秒的视频/音频。

Floater (SeaMeet Floater)

屏幕上出现的悬浮组件，用于快速录音控制。可最小化为小图标或展开为完整控件。

FPS (Frames Per Second)（帧率）

每秒捕获多少静止图像（帧）以创建视频。30fps 是标准。60fps 更流畅。

Fullscreen Recording（全屏录制）

捕获整个屏幕的录制模式。对会议有用，并在你想要捕获一切时使用。

Frame（帧）

视频中的单张静止图像。视频本质上是一系列帧（每秒 30-60 张）快速播放以创建运动。

Fuzzy Search（模糊搜索）

侧边栏和媒体库中的相关性排名搜索，即使查询拼写错误或仅与标题部分重叠也能找到匹配。替代旧的精确子串匹配，所以 "qrtly review" 仍能找到 "Quarterly Review"。见第 10 章。

G

Gain（增益）

音频信号的放大水平。增加增益会使录音中的音频更响。与音量不同（影响播放）。

Game Mode（游戏模式）

优先化游戏应用的 Windows 功能。可帮助录音性能但有时与录音软件冲突。

GitHub Sync（GitHub 同步）

SeaMeet 由私有 GitHub 仓库支持的跨设备同步功能。笔记和元数据被提交到你的仓库，所以同一工作区在你安装 SeaMeet 的每台机器上可用。见第 38 章。

GPU (Graphics Processing Unit)（图形处理单元）

你计算机中的显卡。可用于硬件加速视频编码（比 CPU 快得多）。

GPU Encoding（GPU 编码）

使用显卡而不是 CPU 编码视频。也称硬件加速。更快更高效。

H

H.264 (AVC)

最常见的视频编解码器。以合理文件大小提供良好质量。在几乎所有设备上工作。

H.265 (HEVC)

较新、更高效的视频编解码器。生成的文件在相同质量下比 H.264 小约 50%。通用支持较少。

Hardware Acceleration（硬件加速）

使用专用硬件（如 GPU）执行任务而不是通用 CPU。使视频编码快得多。

Hardware Encoder（硬件编码器）

GPU 上专用编码视频的芯片。NVIDIA 称之为 NVENC。Intel 称之为 Quick Sync。

HD (High Definition)（高清）

1280×720 (720p) 或更高的视频分辨率。提供清晰、详细的视频。

Headphones vs. Speakers（耳机 vs 喇叭）

录音时使用耳机可防止回声（喇叭的声音被麦克风拾取）。推荐以获得最佳音频质量。

I

I-Frame (Intra-frame)（I 帧）

不依赖其他帧的完整视频帧。作为参考点。文件大小较大但定位所需。

Import（导入）

把外部音频或视频文件带入 SeaMeet。SeaMeet 可导入多种格式用于播放和管理。

Input Device（输入设备）

把音频/视频送入计算机的硬件。麦克风、相机和捕获卡是输入设备。

J

Jitter（抖动）

音频/视频数据计时的变化。导致播放断断续续或不均。通常由系统性能问题引起。

Join a Meeting（加入会议）

通过 Zoom、Teams、Meet 等加入在线会议。SeaMeet 可自动检测你何时加入并开始录制。

K

Kbps (Kilobits per second)（千比特每秒）

数据速率的衡量。用于音频码率。128 kbps 是 MP3 的标准。192 kbps 是更高质量。

Keyframe（关键帧）

见 I-Frame。用作参考点的完整视频帧。

Keyboard Shortcuts（键盘快捷键）

快速触发操作的键组合。Ctrl+Alt+R 开始录制。快捷键节省点击界面的时间。

L

Latency（延迟）

操作与处理或听到之间的延迟。Bluetooth 耳机有高延迟。有线耳机几乎没有。

Live Transcription（实时转录）

SeaMeet 在录音期间实时把语音转换为文字的功能。词语在被说出时出现在转录面板中，带时间戳并按发言人标注。需要启用 AI 功能和互联网连接。见第 31 章。

Library (Recording Library)（录音库）

SeaMeet 中所有录音的集合。显示缩略图、元数据，并允许播放/管理。

Lite Mode（Lite 模式）

较小的、以托盘为中心的 SeaMeet 界面。把主窗口剥离到必需品——开始/停止录制、最近项目、快速设置——专为驻留在系统托盘中以最小屏幕占用而设计。

Lossless Compression（无损压缩）

减小文件大小而不丢失任何数据的压缩。可被完美重建。FLAC 音频使用无损压缩。

Lossy Compression（有损压缩）

永久移除一些数据以实现较小文件的压缩。MP3 和 H.264 是有损的。质量损失通常不可察觉。

Low-Memory Mode（低内存模式）

SeaMeet 降低质量以使用较少 RAM 的功能。对老旧计算机或运行内存密集型应用时有用。

M

Macroblock（宏块）

视频压缩中使用的 16×16 像素方块。H.264 把帧分为宏块以高效压缩。

Mbps (Megabits per second)（兆比特每秒）

用于视频的数据速率衡量。8 Mbps 对 1080p 视频较好。更高 = 更好质量 = 更大文件。

MCP Server

SeaMeet 暴露的 Model Context Protocol 服务器，让 AI 助手可以列出模板、重新生成摘要、获取转录，以及从连接的 LLM 客户端驱动 SeaMeet。作为子进程从 dist-main/mcp-server.cjs 运行。

Media Library（媒体库）

录音和截图的专属全窗口浏览器。支持网格和列表视图、筛选（日期、时长、标签）和批量操作（删除、导出、标签）。与侧边栏的录音库不同。见第 10 章。

Metadata（元数据）

关于文件的信息（不是实际内容）。包括创建日期、时长、分辨率等。

Microphone Array（麦克风阵列）

多个麦克风协作。一些笔记本电脑有麦克风阵列以获得更好声音拾取和噪音消除。

Minimize to Tray（最小化到托盘）

SeaMeet 可在后台运行，通过系统托盘图标访问（时钟附近）。节省任务栏空间。

MKV (Matroska)

灵活的视频容器格式。支持多个音频轨道和字幕。适合归档。

Monitor（显示器）

你的计算机屏幕。SeaMeet 可录制一个显示器或所有显示器（如有多个）。

Mono vs. Stereo（单声道 vs 立体声）

Mono = 1 个音频通道。Stereo = 2 个通道（左和右）。Stereo 更沉浸但创建较大文件。

MOV

Apple 的视频容器格式。Mac 上常见。质量好但没有额外软件时与 Windows 兼容性较差。

MP3

最流行的音频格式。使用有损压缩。小文件，通用兼容性。典型 128-320 kbps。

MP4

最流行的视频容器格式。在几乎所有设备上工作。通常包含 H.264 视频和 AAC 音频。

Multi-Monitor（多显示器）

使用多于一个屏幕。SeaMeet 可录制所有显示器或仅一个。录制多个显示器使用更多资源。

Mute（静音）

临时关闭音频输入或输出。SeaMeet 可在不影响系统音量的情况下静音录音。

N

Native Resolution（原生分辨率）

你屏幕显示的实际像素数。以原生分辨率录制提供最锐利结果。

Noise Suppression（噪声抑制）

从音频录音中移除背景噪声（风扇、空调）的技术。让人声更清晰。

Notification（通知）

提醒你事件的弹出消息。SeaMeet 在录音开始、停止或检测到会议时显示通知。

NVENC

NVIDIA 的硬件视频编码器。在 GTX 600 系列及更新上可用。非常快的编码且 CPU 使用最少。

O

OAuth Auto-Refresh（OAuth 自动刷新）

在令牌到期前 5 分钟运行的 GitHub 同步令牌刷新机制。在不强制用户重新认证的情况下保持同步会话活跃，把 Sync State Machine 无可见中断地切回到 synced。见第 38 章。

Ogg

开源音频格式。压缩好但设备支持有限。常使用 Vorbis 编解码器。

Output Device（输出设备）

播放计算机音频的硬件。喇叭和耳机是输出设备。

Overhead (CPU/Memory)（开销）

录音软件本身使用的资源，与实际录音分开。SeaMeet 有低开销。

P

P-Frame (Predicted Frame)（P 帧）

仅存储与前一帧差异的视频帧。比 I 帧小得多。创建高效压缩。

PCM (Pulse Code Modulation)（脉冲编码调制）

未压缩的数字音频格式。编码为 MP3 或其他格式前内部使用。高质量、大文件。

Permissions（权限）

访问系统资源的授权。macOS 和 Windows 要求你授予 SeaMeet 录制屏幕和音频的权限。

Pixel（像素）

屏幕上单个颜色点。图像由数千或数百万像素组成。1920×1080 = 约 200 万像素。

Playback（播放）

观看或收听录音。SeaMeet 有内置播放器用于回顾录音。

Pop Filter（噗噗过滤器）

麦克风的泡沫或网罩，减少 "p" 和 "b" 的噗噗声。提升音频质量。

Process Monitoring（进程监控）

监视哪些程序在运行的自动检测方法。检测 zoom.exe 或 Teams.exe 何时启动。

Q

Quantization（量化）

降低数据精度以节省空间。压缩的一部分。简化几乎相同的颜色/声音。

Quick Sync

Intel 的硬件视频编码器。内置于现代 Intel 处理器。对录音高效且质量好。

R

RAM (Random Access Memory)（随机存取存储器）

你计算机的短期记忆。SeaMeet 用 RAM 做 Flashback 缓冲和处理。更多 RAM = 更好性能。

RAW Audio/Video（原始音频/视频）

未压缩数据。大文件但最大质量。SeaMeet 通常编码为压缩格式以节省空间。

Real-time（实时）

现场发生、无延迟。SeaMeet 在你录音时实时编码视频。无需等后处理。

Recording Mode（录制模式）

SeaMeet 如何捕获视频：全屏（整个屏幕）、窗口（特定应用）或区域（选定区域）。

Region Recording（区域录制）

仅录制屏幕选定部分。最高效的模式——只捕获你需要的。

Resolution（分辨率）

图像中的像素数。1920×1080 表示 1920 像素宽 1080 像素高。更高 = 更锐利 = 更大文件。

Ring Menu (Floater)（环形菜单）

展开 Floater 组件时出现的圆形控制界面。为录音控件提供快速访问。

S

Sample Rate (Audio)（音频采样率）

每秒衡量音频的次数。CD 质量是 44.1 kHz（每秒 44,100 样本）。更高 = 更好质量。

Sampling（采样）

通过定期间隔测量把连续声波转换为数字。

Save Location（保存位置）

SeaMeet 存储录音的文件夹。可在设置中更改。应有充足空闲空间。

Screen Recording（屏幕录制）

捕获你计算机屏幕的视频。SeaMeet 专长于带音频的屏幕录制。

Screenshot（截图）

你屏幕的静止图像捕获。SeaMeet 可通过键盘快捷键或 Floater 截图。

Sensitivity (Auto-Detection)（自动检测灵敏度）

SeaMeet 多积极寻找会议。高灵敏度捕获更多会议但可能有误报。

Shortcut（快捷键）

见键盘快捷键。无需鼠标控制 SeaMeet 的快速方式。

Sidebar（侧边栏）

SeaMeet 中显示不同部分的左面板：录音、视频、Flashback 等。

Slash Menu（斜杠菜单）

笔记编辑器中的块插入菜单，通过在新行上输入 / 调用。让你无需离开键盘即可插入标题、列表、呼出、代码块、嵌入和其他块类型。见第 16-17 章。

Source (Audio/Video)（音频/视频源）

信号的来源。音频源包括麦克风和系统音频。视频源包括屏幕和窗口。

Speaker Detection（发言人检测）

在实时转录或 AI 提取期间识别哪个人在发言的自动过程。每个独特声音被分配标签（"Speaker 1"、"Speaker 2"）。准确性随清晰音频和最少交叉对话而提升。见第 31 章。

Speaker Label（发言人标签）

转录中分配给发言人的名字。默认为 "Speaker 1"、"Speaker 2" 等。可重命名（例如 "Alice"）或与另一标签合并（如果两个标签属于同一人）。见第 34 章。

SplitButtonMenu（分体按钮菜单）

AI 摘要标签上的 UI 控件，把主操作与相关操作的下拉组合——例如，单个按钮默认运行 "用 Auto-pick 重新生成"，但从下拉雪佛龙提供 "Manual template" 选择。见第 33-34 章。

SRT (SubRip Subtitle)

字幕的文本文件格式。包含带时间戳的文本行。SeaMeet 可把转录导出为 SRT 文件，可导入到视频编辑器（Premiere、iMovie）或作为字幕上传到 YouTube。

SSD (Solid State Drive)（固态驱动器）

无活动部件的快速存储设备。比传统硬盘 (HDD) 更适合录音。更快的写入速度。

Stereo Mix

让你录制系统音频的 Windows 音频功能。SeaMeet 可使用 Stereo Mix 或 WASAPI 进行系统音频捕获。

Storage（存储）

你硬盘或 SSD 上保存录音的空间。视频录音需要大量存储空间。

Stream（流）

数据的持续流动。音频和视频流在录制时被捕获和编码。

Sync (Audio-Video)（音视频同步）

音频和视频正确对齐。不同步意味着你在听到词之前/之后看到嘴唇移动。

Sync State Machine（同步状态机）

GitHub 同步的生命周期：idle → pending → syncing → synced，带 error、offline、token-expired、installing-app 和 creating-repo 的分支。状态显示在同步状态指示器中，所以你确切知道同步在任何时刻处于何处。见第 38 章。

System Audio（系统音频）

来自你计算机的声音——通知、视频、会议声音。SeaMeet 可与麦克风分开录制系统音频。

System Tray（系统托盘）

时钟附近显示后台应用图标的区域。SeaMeet 可最小化到系统托盘。

T

Template (AI Summary Template)（AI 摘要模板）

为特定会议类型塑造 AI 提取输出的结构化提示——例如，站会模板强调阻塞和明天的计划，而销售电话模板强调反对意见和下一步。可通过 Auto-pick 或手动选择模板。见第 33 章。

Theme (Light/Dark)（主题）

SeaMeet 的视觉外观。Light 主题有白色背景。Dark 主题有深色背景。夜间对眼睛较舒适。

Thumbnail（缩略图）

代表视频的小预览图像。SeaMeet 在库中显示录音的缩略图。

Time Machine (Flashback)（时光机）

Flashback 功能的隐喻。让你"回到过去"捕获已经发生的瞬间。

Timeline（时间轴）

录音时长的视觉表示。SeaMeet 的播放器显示带播放位置的时间轴。

Toggle（切换）

打开或关闭功能的开关。SeaMeet 在设置中使用切换——点击在状态之间切换。

Transcript（转录）

口语音频的文本记录。SeaMeet 生成两种：实时转录（录音期间实时捕获的词）和提取转录（录音后从音频文件生成）。两者都出现在 AI 洞察面板的转录标签下。见第 27 和 28 章。

Track (Audio)（音频轨道）

文件中独立的音频流。SeaMeet 可录制多个轨道：麦克风、系统音频等。

Tray（托盘）

系统托盘图标菜单——Windows 通知区、macOS 菜单栏、Linux 指示器——当 SeaMeet 最小化时它驻留的地方。即使没有主窗口可见，也提供开始/停止录制、打开 Lite 模式和退出。

Trim（修剪）

移除录音不需要的开头或结尾部分。SeaMeet 允许修剪保存的录音。

Troubleshooting（故障排查）

诊断和修复问题的过程。第 25 章涵盖常见 SeaMeet 问题的故障排查。

U

USB Microphone（USB 麦克风）

通过 USB 端口连接的麦克风。使用方便且常比内置笔记本电脑麦克风质量更好。

V

VBR (Variable Bit Rate)（可变码率）

根据内容复杂度调整质量的编码方法。简单场景使用较低码率。复杂场景使用较高。

Video Buffer（视频缓冲）

Flashback 录制期间视频帧的临时存储。保留最近画面的滚动窗口。

Version Badge（版本徽章）

至少运行一次重新生成时出现在 AI 洞察标签栏的小标签（例如 "v3 ▾"）。点击打开版本选择器。见第 34 章。

Version History（版本历史）

录音所有先前 AI 提取运行的记录。每次重新生成 (⟳)，SeaMeet 在覆盖前把先前结果保存为编号快照。你可随时查看任意过去版本。见第 34 章。

Video Track（视频轨道）

视频文件的视觉组成。与音频轨道分开。一个视频文件至少包含一个视频轨道。

Volume（音量）

音频的响度。与增益不同——音量影响你听到的。增益影响录制的。

VP8/VP9

WebM 文件中使用的开源视频编解码器。质量好，免费使用。VP9 比 VP8 更新且更高效。

W

WASAPI (Windows Audio Session API)

捕获系统音频的现代 Windows 方法。在某些系统上比 Stereo Mix 更可靠。

WAV (Waveform Audio File Format)

未压缩音频格式。大文件但完美质量。适合归档或编辑。

WebM

Google 开发的开源视频格式。适合网络使用。使用 VP8 或 VP9 编解码器。

Wikilink

笔记中的 [[title]] 语法，创建可导航到另一条笔记的链接。输入 [[ 打开现有笔记选择器；选择一条插入链接，点击渲染笔记中的链接跳到那一页。见第 16-17 章。

Window Recording（窗口录制）

仅捕获特定应用窗口的录制模式。比全屏更高效。

Window Title Detection（窗口标题检测）

读取应用窗口标题的自动检测方法。寻找像 "Zoom Meeting" 或 "Teams" 这样的关键词。

Workspace（工作区）

你可在之间切换的独立笔记树加录音集——例如，"Work" 工作区和 "Personal" 工作区，各有自己的 GitHub Sync 仓库。切换工作区会一次性切换侧边栏、库和同步目标。见第 38 章。

X

XLR

高端麦克风上使用的专业音频连接器。需要音频接口连接到计算机。

Y

YouTube

流行的视频分享平台。SeaMeet 录音可上传到 YouTube。YouTube 推荐特定设置以获得最佳结果。

Z

Zero Latency（零延迟）

操作与录制之间无延迟。实践中不可能，但有线连接和良好硬件最小化延迟。

Zoom (App)

流行的视频会议平台。SeaMeet 可自动检测并录制的 47+ 应用之一。

Zoom (Digital)（数字缩放）

放大或扩大视图。SeaMeet 的播放器允许放大视频以查看细节。

易混淆术语解释

Codec vs. Container

  • Codec: 数据如何被压缩 (H.264, MP3)
  • Container: 数据在哪里存储 (MP4, WebM, AVI)

类比：Codec 是书的语言。Container 是书本身。

Bitrate vs. Resolution

  • Bitrate: 每秒多少数据（影响质量和文件大小）
  • Resolution: 多少像素（影响锐度）

你可以有高分辨率低码率（块状）或低分辨率高码率（平滑但小）。

Gain vs. Volume

  • Gain: 输入电平（录音多响）
  • Volume: 输出电平（播放多响）

更改音量不影响录音。更改增益影响录音。

Latency vs. Delay

  • Latency: 数字系统中延迟的技术术语
  • Delay: 任何等待时间的通用术语

本质上是同一件事，但 "latency" 用于技术上下文。

Frame Rate vs. Resolution

  • Frame Rate: 每秒多少图片（流畅度）
  • Resolution: 每张图片多详细（清晰度）

60fps 720p 比 30fps 1080p 流畅，但 1080p 更锐利。
