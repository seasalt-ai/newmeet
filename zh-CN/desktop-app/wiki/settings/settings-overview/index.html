设置概览

第 18 章：设置概览

介绍

欢迎来到 SeaMeet 的控制中心！如果主界面像驾驶飞机的驾驶舱，那么设置菜单就像维护舱：在这里你可以微调引擎、调整座椅、定制你的飞行体验。本章会展示如何打开设置菜单，并提供你将在那里看到的所有不同类别的路线图。

读完本章，你将完全了解 SeaMeet 中每一项设置的位置，并理解每个类别控制什么。把它当作我们深入每一具体部分之前的入门导览。

本章目标

读完本章后，你将能够：

  • 从 SeaMeet 中多个位置打开设置菜单
  • 理解 10 大设置类别及其控制的内容（包括 v2.1.0 新增的 AI Features 和 Sync 组）
  • 快速在不同设置区间切换
  • 识别设置界面使用的视觉指示器和图标
  • 根据需求知道何时该改哪些设置

什么是设置，为何它们很重要？

把 SeaMeet 设置想成手机上的偏好设置。要使用基本功能你不需要改它们，但定制后，应用会完全按照你的方式工作。这就像穿一件均码 T 恤 vs. 按你尺寸量身定做的差别。

设置之所以重要，是因为它们让你能够：

个性化你的体验

  • 选择你偏好的语言（可选 16 种！）
  • 根据眼睛舒适度设置浅色或深色模式
  • 选择录音保存位置
  • 配置与你肌肉记忆匹配的快捷键

优化性能

  • 根据麦克风能力调整音频质量
  • 设置匹配屏幕和存储的视频分辨率
  • 根据计算机性能启用或禁用功能
  • 管理 Flashback 录音的内存使用

确保可靠性

  • 设置自动检测以免错过会议
  • 配置磁盘空间警告以防容量耗尽
  • 为你的配置选择正确的音频设备
  • 从一开始就正确设置权限

预防问题

  • 如果有人说你太轻或太响，请调整麦克风增益
  • 设置默认录音模式，避免忘记切换
  • 配置自动开始选项，让录音在你想要时开始
  • 如果你的电脑较老或较慢，请启用低内存模式

如何打开设置菜单

SeaMeet 提供多种打开设置的方式，就像你能用密码、指纹或面部识别解锁手机一样。下面是所有可以进入设置的方式：

方式 1：从左侧栏

这是访问设置最常见的方式。看 SeaMeet 主窗口左侧的垂直侧边栏。

分步操作：

  1. 找到带录音、视频、Flashback 等图标的左侧栏。

  2. 寻找 Settings 图标 — 它看起来像齿轮 (⚙️)

  3. 点击 Settings 图标

  4. 主区域会从显示录音切换到显示设置面板

视觉参考：

│  [🎤] [🎥] [📼] [🔍] [⚙️ 设置]                              │

│                                                             │

方式 2：从菜单栏（Windows）

如果你使用 Windows，也可以通过窗口顶部的传统菜单栏访问设置。

分步操作：

  1. 点击顶部菜单栏的 "File"

  2. 在下拉菜单中寻找 "Settings" 或 "Preferences"

  3. 点击打开设置面板

注意： 此方式可能因 Windows 版本和 SeaMeet 版本而略有不同。

方式 3：键盘快捷键（Windows）

对于键盘爱好者，有快捷方式：

在 Windows 上： 按 Ctrl + 逗号 (,)

这是许多 Windows 应用（包括 Microsoft Office 等）通用的快捷键，所以它可能已经在你的肌肉记忆中。

如何使用：

  1. 确保 SeaMeet 是活动窗口（不确定时点一下）
  2. 按住 Ctrl
  3. 按住 Ctrl 的同时按逗号
  4. 设置立即打开

方式 4：从托盘菜单（Windows）

SeaMeet 运行在系统托盘中（时钟附近那些小图标区域）。你也可以从那里打开设置。

分步操作：

  1. 在系统托盘中找到 SeaMeet 图标（屏幕右下角）

    • 可能需要点击向上箭头来查看隐藏图标

  2. 在 SeaMeet 图标上右键

  3. 出现包含各种选项的上下文菜单

  4. 从菜单中点击 "Settings"

为何使用此方式？

  • 当 SeaMeet 最小化时很棒
  • 无需打开主窗口的快速访问
  • 着急时完美

方式 5：从 Floater 菜单

还记得第 14 章的悬浮控制组件（Floater）吗？你也可以从那里访问设置。

分步操作：

  1. 点击 Floater 展开它（如果处于紧凑模式）

  2. 寻找设置齿轮图标或菜单选项

  3. 点击打开设置

注意： 准确位置可能因 Floater 配置而异，但设置选项始终可从展开的 Floater 视图访问。

左侧：类别列表

  • 显示所有可用的设置类别
  • 点击任意类别查看其设置
  • 当前所选类别被高亮
  • 部分类别在名称旁有图标

右侧：设置内容

  • 显示所选类别的所有设置
  • 每个设置都有标签解释其作用
  • 设置使用不同控件类型：
    • 切换（开/关）— 用于是/否选择
    • 下拉菜单 — 从多个选项中选择
    • 文本字段 — 输入文件路径或名称
    • 滑块 — 调整音量等值
    • 按钮 — 执行 "Browse" 或 "Reset" 等操作

底部：操作按钮

  • Apply — 保存你的更改（有时自动）
  • Cancel — 放弃更改并关闭设置
  • Reset to Defaults — 把所有设置恢复到出厂默认
  • Search — 快速找到特定设置（部分版本）

10 大设置类别详解

SeaMeet 把设置组织到 10 个逻辑类别中。把这些想成文件柜里的抽屉——每个都包含相关的项目。其中两个——AI Features 和 Sync ——是在 v2.1.0 添加的，用于把新的 AI 摘要模板控制和基于 GitHub 的跨设备同步聚集在一起：

类别 1：常规设置

图标： 通常是齿轮或房子图标 控制内容： 基本应用行为和外观

典型设置包括：

  • 启动行为 — SeaMeet 应该在电脑启动时自动打开吗？
  • 最小化到托盘 — 关闭窗口时 SeaMeet 应该继续运行吗？
  • 主题选择 — 浅色模式、深色模式或自动（跟随系统）
  • 通知偏好 — 哪些事件应触发通知？
  • 更新设置 — SeaMeet 应该自动检查更新吗？

何时使用此类别：

  • 首次安装 SeaMeet 并想设置基本偏好时
  • 想更改应用外观与感觉时
  • 想控制 SeaMeet 在后台行为时
  • 设置自动启动时

类比： 这就像调整汽车的基本设置——灯应该自动打开吗？应该记住座椅位置吗？把钥匙留在车里时应该叮一声吗？

类别 2：存储设置

图标： 通常是硬盘或文件夹图标 控制内容： 录音保存的位置和方式

典型设置包括：

  • 保存位置 — 录音应该进入哪个文件夹？
  • 存储管理 — 自动清理旧录音
  • 文件组织 — 文件应如何命名和排序？
  • 磁盘空间警告 — 在空间不足时提醒
  • 备份设置 — 录音应该备份到云存储吗？

何时使用此类别：

  • 想更改录音保存位置（例如移到外部驱动器）
  • 磁盘空间不足，需要管理存储时
  • 想以特定方式整理录音时
  • 设置自动清理以防累积时

类比： 这就像整理衣柜——决定哪件衣服放哪个抽屉、如何标记盒子、何时捐赠旧物腾出空间。

重要说明： 这在第 19 章（存储设置）中详细介绍，我们会逐项讲解每个选项。

类别 3：音频设置

图标： 通常是麦克风或喇叭图标 控制内容： 与声音录制和播放相关的一切

典型设置包括：

  • 默认麦克风 — 录音使用哪个麦克风
  • 麦克风增益 — 你的声音应该录得多响
  • 系统音频源 — 捕获哪个音频输出
  • Bluetooth 警告 — 使用 Bluetooth 麦克风时的提醒
  • 音频格式 — 音频录音的首选格式（MP3、WAV 等）
  • 采样率 — 音频质量等级（44.1kHz、48kHz 等）

何时使用此类别：

  • 别人说你在录音中太轻或太响时
  • 有多个麦克风需要选择默认时
  • 使用 Bluetooth 耳机需要延迟警告时
  • 想更改音频质量或文件格式时
  • 排查音频录音问题时

类比： 这就像调整音乐厅的音响系统——选择使用哪些麦克风、设置正确音量、确保音响完美适合演出。

重要说明： 这在第 20 章（音频设置）中详细介绍，我们会深入研究麦克风选择、增益控制等。

类别 4：视频设置

图标： 通常是摄像机或显示器图标 控制内容： 与屏幕录制相关的一切

典型设置包括：

  • 默认录制模式 — 全屏、窗口或区域
  • 视频质量 — 分辨率（1080p、720p、480p）
  • 帧率 — 视频应该多流畅（30fps、60fps）
  • 显示器选择 — 录制哪个屏幕（如果有多个）
  • 视频格式 — 视频文件的首选格式（MP4、WebM 等）
  • 硬件加速 — 使用 GPU 提升性能
  • 光标录制 — 鼠标指针应该可见吗？
  • 光标效果 — 高亮点击、更改光标大小等

何时使用此类别：

  • 想设置默认录制模式以节省点击时
  • 需要平衡质量与文件大小时
  • 有多个显示器需要指定录制时
  • 录制游戏需要高帧率（60fps）时
  • 制作教程时想要光标效果

类比： 这就像设置电影摄影机——选择胶片质量、决定用哪个镜头、设置流畅动作的帧率，并决定是否在画面中显示摄影师的手。

重要说明： 这在第 21 章（视频设置）中详细介绍，我们会解释所有技术术语并帮你选择正确设置。

类别 5：Flashback 设置

图标： 通常是圆形箭头或时钟图标（表示"倒带"） 控制内容： 时光机录音功能

典型设置包括：

  • 自动启动 Flashback — SeaMeet 启动时 Flashback 应该自动开始吗？
  • 缓冲时长 — 保留多久（10-120 秒）
  • 音频缓冲长度 — 保留多少音频（固定 30 秒）
  • 视频质量 — Flashback 视频的分辨率（通常低于常规录制）
  • 低内存模式 — 减少老旧电脑的内存使用
  • 缓冲持续 — 切换应用时保留缓冲吗？

何时使用此类别：

  • 想让 Flashback 始终就绪（自动启动）时
  • 需要平衡可保存多远的时间与内存使用时
  • 电脑较老需要节省 RAM 时
  • 想自定义 Flashback 行为时

类比： 这就像配置安全摄像机的 DVR——决定保留多少天的录像、设置录制质量、为持续录制管理存储空间。

重要说明： 这在第 22 章（Flashback 设置）中详细介绍，我们会帮你找到缓冲长度和性能之间的完美平衡。

类别 6：AI Features（v2.1.0 新增）

图标： 紫色闪光/魔杖图标 控制内容： 支撑 SeaMeet AI 部分的一切——实时转录、会后提取、摘要模板，以及（可选的）应用内 AI 助手

AI Features 组包含三个菜单项：

  • AI Transcription, Extraction, Summary, Wiki — 你的模型提供方、BYOK API 密钥输入、摘要语言，以及录音后哪些 AI 管线会自动运行。在第 36 章（Bring Your Own Key — BYOK）中详细介绍。
  • AI Summary Templates — v2.1.0 推出的新模板库（48 个内置模板，分布于 8 个类别：Team & Management、Project & Agile、Sales & Client、HR & Recruitment、Education & Training、Medical & Healthcare、Legal & Compliance、Events & Media）。包括 Auto-detect summary template 切换（默认开启）——开启时 SeaMeet 会对每次会议的转录进行分类，并挑选最合适的模板；关闭时每段录音都使用 Meeting Minutes，且不发起分类器调用。在第 33 章（AI 摘要模板）中详细介绍。
  • AI Agent & Cowork — 仅在 agent 功能标志启用时可见。承载聊天助手配置（Provider、Ask/Code/Plan 默认）。在第 37 章（Copilot & AI Agent）中详细介绍。

何时使用此类别：

  • 想用自己的 Gemini API 密钥设置 BYOK 时
  • 想全局翻转 Auto-detect 模板行为时
  • 想在不打开录音的情况下浏览已安装模板库时
  • 配置 AI 助手默认值时

类比： 这是 AI 控制室——你选择 SeaMeet 接入哪个"大脑"以及它应该多积极地为你思考的面板。

类别 7：自动录音设置

图标： 通常是放大镜或机器人/自动化图标 控制内容： 自动会议检测和录制

典型设置包括：

  • 自动检测启用 — 功能的主开关
  • 检测灵敏度 — 检测应该多激进
  • 默认操作 — 立即开始录制或只通知？
  • 每应用权限 — 哪些应用可以触发自动录制
  • 检测方法 — 监视哪些信号（窗口标题、音频等）
  • 开始前延迟 — 检测后等几秒再开始
  • 会议后操作 — 会议结束后做什么

何时使用此类别：

  • 首次设置 SeaMeet 并启用自动检测时
  • 想精调哪些应用触发录制时
  • 发现自动检测太敏感（或不够敏感）时
  • 想让 SeaMeet 等一会再开始时
  • 自定义会议结束后发生的事时

类比： 这就像训练智能助手——教它识别你在开会时、决定哪些会议重要，并告诉它检测到时如何响应。

重要说明： 这在第 23 章（自动录音设置）中详细介绍，我们会逐步讲解为所有 47+ 个支持的应用设置权限。

类别 8：Sync（v2.1.0 新增）

图标： GitHub 标志 / 云图标 控制内容： 通过你自己的 GitHub 仓库为笔记和 wiki 提供可选的私有云备份

典型设置包括：

  • Set Up GitHub Sync / Authorize GitHub — 一键 OAuth 流程，为每个工作区创建一个私有仓库
  • Auto-sync on changes — 你编辑时提交并推送（默认开启）
  • Sync on startup — SeaMeet 启动时拉取最新更改（默认开启）
  • Sync interval — 本地编辑被批为一次提交的频率（1、5、10 或 30 分钟）
  • Sync Now — 手动提交 + 推送触发
  • Conflict resolution — 两个设备编辑同一文件时手动编辑或 Agent 辅助合并
  • Re-authorize / Disconnect — 刷新 GitHub OAuth 或解除工作区链接

重要范围： 同步只覆盖笔记和 wiki（.md 文件）。音频录音、视频录音和截图保留在你的设备上——它们绝不会推送到 GitHub。这就是为什么单个 1 GB 的 GitHub 免费仓库可以容纳大约 200,000–500,000 条笔记。

何时使用此类别：

  • 首次设置跨设备访问笔记和 wiki 时
  • 想免费把笔记备份到私有 GitHub 仓库时
  • 解决两个设备之间的同步冲突时
  • OAuth 令牌过期后需要重新授权时

订阅门控： Sync 在 BYOK Pro 下提供。免费用户会看到带 "BYOK Pro" 徽章的 Sync 菜单项，以及点击时打开付费墙的横幅。

理解设置控件

不同设置使用不同类型的控件。下面是识别和使用每种类型的指南：

切换开关（开/关）

外观： 一个水平开关，向左滑动（关）或向右滑动（开）。开启时通常有颜色（通常是蓝色或绿色）。

设置名称              [━━●──]   ← 关闭位置
                      [──●━━]   ← 开启位置（有色）

如何使用：

  • 点击开关切换
  • 开关会滑动并改变颜色
  • 更改通常立即生效

SeaMeet 中的示例：

  • 自动启动 Flashback
  • 最小化到系统托盘
  • 启用自动检测
  • 在录制中显示光标

类比： 就像墙上的电灯开关——按一方向开，按另一方向关。

下拉菜单

外观： 一个矩形字段，显示当前选择，右侧有向下箭头。

录制质量              [1080p HD        ▼]
                       ↑ 当前        ↑ 点击查看
                         值            所有选项

如何使用：

  1. 点击下拉（或箭头）
  2. 下方出现选项列表
  3. 点击你想要的选项
  4. 下拉关闭，显示新选择

SeaMeet 中的示例：

  • 视频质量（1080p、720p、480p）
  • 帧率（30fps、60fps）
  • 音频格式（MP3、WAV、WebM）
  • 默认录制模式（全屏、窗口、区域）
  • 显示语言（16 种选项）

类比： 就像餐馆菜单——你看到当前选择在你的盘子里，但你可以打开菜单选择不同的。

文本输入字段

外观： 一个空的或预填充的矩形框，你可以输入。

保存位置              [C:\Users\You\Recordings    ] [浏览…]
                       ↑ 点击这里输入             ↑ 或点击
                                                   浏览文件夹

如何使用：

  1. 点击文本字段内
  2. 输入文本（或先清除现有文本）
  3. 完成时按 Tab 或点击其他位置

特殊功能：

  • 浏览按钮 — 通常在路径字段旁，打开文件浏览器
  • 占位文字 — 显示示例输入的灰色文字
  • 验证 — 如果输入无效可能变红

SeaMeet 中的示例：

  • 保存目录路径
  • 文件命名模式
  • 自定义键盘快捷键
  • 麦克风设备名称（有时）

类比： 就像在医生办公室填表——在空白字段中填写信息。

滑块

外观： 一个水平条，带可以左右拖动的把手。

麦克风增益            [━●━━━━━━━━━━━] 45%
                       ↑ 拖动此旋钮
                         向左（更轻）
                         或向右（更响）

如何使用：

  1. 点击并按住滑块把手（或旋钮）
  2. 向左拖减小值
  3. 向右拖增大值
  4. 满意时松开

替代： 点击滑块条上任意位置直接跳到该位置

SeaMeet 中的示例：

  • 麦克风增益/音量
  • 检测灵敏度（自动录制）
  • 缓冲时长（Flashback）
  • 质量/压缩平衡

类比： 就像立体声上的音量旋钮——向左转更轻、向右转更响。

按钮

外观： 带文字标签的矩形或圆角按钮。

[检查更新] [恢复默认] [浏览…]

如何使用：

  • 简单点击按钮一次
  • 立即发生某事（对话框打开、操作执行等）

按钮类型：

  • 操作按钮 — 执行操作（检查更新、浏览）
  • 重置按钮 — 恢复默认（恢复默认）
  • 导航按钮 — 跳到其他屏幕（高级设置）
  • 确认按钮 — 保存或取消更改（应用、确定、取消）

SeaMeet 中的示例：

  • 浏览（选择文件夹）
  • 恢复默认（任何类别）
  • 检查更新（关于部分）
  • 应用/保存更改
  • 测试麦克风（音频设置）

类比： 就像电梯按钮——按一下电梯就做点什么（上升、下降、开门）。

复选框

外观： 一个可勾选 (✓) 或为空的小方块。

☐ 计算机启动时启动 SeaMeet
☑ 关闭时最小化到系统托盘
☐ 显示录音通知

如何使用：

  • 点击复选框切换
  • 启用时出现勾号
  • 再次点击取消勾选

与切换的区别：

  • 复选框通常用于可选择多个选项时
  • 切换用于单一开/关选择
  • SeaMeet 主要使用切换，但你可能在高级设置中看到复选框

类比： 就像待办清单——勾掉已完成的项目。

设置行为：立即 vs. 应用

不是所有设置都以相同方式工作。有两种主要行为：

立即设置

这些在你更改时立即生效——无需点击 "Apply" 或 "Save"。

示例：

  • 主题更改（浅色/深色模式）
  • 语言选择
  • 切换开关（大多数）
  • 音量/增益滑块（你实时听到变化）

如何识别：

  • 更改立即发生
  • 不需要 "Apply" 按钮
  • 通常是视觉更改或简单切换

应用设置

这些需要你点击 "Apply"、"OK" 或 "Save" 才能生效。

示例：

  • 保存位置路径
  • 默认录制模式
  • 复杂的音频/视频配置
  • 部分权限设置

如何识别：

  • 存在 "Apply" 或 "Save" 按钮
  • 你可能看到 "未保存的更改" 指示器
  • 更改在确认之前不发生

重要： 如果你更改设置并点击 "Cancel"，你的更改会被放弃！如果想保留更改，请始终点击 "Apply" 或 "OK"。

搜索功能（如可用）

某些 SeaMeet 版本在设置面板顶部包含一个搜索框。这非常有用！

如何使用搜索：

  1. 寻找搜索框（通常显示 "搜索设置…" 或带放大镜图标）

  2. 在搜索框中点击并输入关键词：

    • "microphone" → 显示所有麦克风相关设置
    • "save" → 显示存储和保存位置设置
    • "quality" → 显示视频和音频质量设置
    • "shortcut" → 显示键盘快捷键设置

  3. 输入时设置列表会过滤只显示匹配项

  4. 点击结果直接跳到该设置

为何搜索有用：

  • 无需浏览类别即可快速找到设置
  • 发现你不知道存在的相关设置
  • 当你不确定设置在哪个类别时很棒
  • 当你确切知道想改什么时节省时间

常见设置工作流

下面是一些典型场景及处理它们的确切步骤：

场景 1：首次设置

你是 SeaMeet 新用户，想要配置基础：

  1. 打开设置（点击左侧栏齿轮图标）

  2. 进入 General

    • 把主题设为你偏好
    • 如愿意启用 "最小化到托盘"
    • 如愿意启用 "随计算机启动"

  3. 进入 Storage

    • 验证或更改保存位置
    • 设置磁盘空间警告

  4. 进入 Audio

    • 选择默认麦克风
    • 测试麦克风并调整增益
    • 如使用无线耳机检查 Bluetooth 警告

  5. 进入 Language

    • 选择你偏好的显示语言

  6. 点击 Apply 保存所有更改

  7. 进入 About 记下你的版本号（便于支持）

场景 2：更改录音保存位置

你的 C: 盘塞满了，想把录音移到外部驱动器：

  1. 打开设置

  2. 点击左侧栏的 Storage

  3. 找到 "Save Location" 或 "Recording Directory"

  4. 点击 "浏览" 按钮

  5. 在文件浏览器中导航到外部驱动器

    • 示例：D:\SeaMeet Recordings

  6. 选择或创建文件夹

  7. 在文件浏览器中点击确定

  8. 在设置中点击 Apply

  9. 可选： 使用文件资源管理器把现有录音手动移到新位置

场景 3：设置自动检测

你想让 SeaMeet 自动检测 Zoom 会议：

  1. 打开设置

  2. 点击 Auto-Recording

  3. 启用 "自动检测"（切换开关）

  4. 在应用列表中找到 Zoom

  5. 为 Zoom 启用权限（切换或复选框）

  6. 选择默认操作： 立即开始录制或只通知？

  7. 必要时调整灵敏度（滑块）

  8. 点击 Apply

  9. 测试： 打开 Zoom 并开始会议，看 SeaMeet 是否检测到

场景 4：为老旧电脑优化

你的电脑用了几年，录制时变慢：

  1. 打开设置

  2. 进入 Video

    • 把视频质量降到 720p 或 480p
    • 把帧率设为 30fps（而不是 60fps）
    • 如果硬件加速引起问题就禁用它

  3. 进入 Flashback

    • 启用 "低内存模式"
    • 把缓冲时长降到 30-60 秒（而不是 120）

  4. 进入 Audio

    • 如可用选择较低采样率（44.1kHz 代替 48kHz）

  5. 进入 Storage

    • 启用自动清理以防磁盘空间问题

  6. 点击 Apply

  7. 测试录制看性能是否改善

场景 5：为专业演示做准备

你需要为工作录制一次高质量演示：

  1. 打开设置

  2. 进入 Video

    • 把质量设为 1080p（或最高可用）
    • 把帧率设为 60fps 以获得流畅动作
    • 启用 "录制光标"
    • 启用 "高亮光标点击"（如可用）

  3. 进入 Audio

    • 选择你最好的麦克风
    • 把增益设为最佳水平（先测试！）
    • 选择高质量格式（WAV 最好，或高码率 MP3）

  4. 进入 General

    • 禁用通知以防中断
    • 确保启用 "最小化到托盘"

  5. 进入 Storage

    • 验证有足够磁盘空间（HD 视频用很多空间！）

  6. 点击 Apply

  7. 做 30 秒测试录制 以确认一切看起来和听起来都完美

设置技巧与诀窍

技巧 1："恢复默认" 安全网

如果你更改设置后某事停止工作，别慌！每个类别都有 "Reset to Defaults" 按钮，把该部分恢复到出厂设置。

如何使用：

  1. 进入有问题的类别
  2. 点击 "Reset to Defaults"（通常在底部）
  3. 确认重置
  4. 用干净设置重试

注意： 这会重置该类别中所有设置，不只是你最后更改的那个。

技巧 2：导出/导入设置（如可用）

某些 SeaMeet 版本允许把设置导出到文件。这对以下情况很棒：

  • 备份你的偏好
  • 把设置传到另一台电脑
  • 与同事分享优化的设置

寻找： "Export Settings" 或 "Import Settings" 按钮，通常在 General 中或设置面板底部。

技巧 3：键盘导航

你可以不用鼠标在设置中导航：

  • Tab — 移到下一个控件
  • Shift + Tab — 移到上一个控件
  • 空格键 — 切换复选框或激活按钮
  • 箭头键 — 在下拉选项中导航或调整滑块
  • Enter — 确认选择或激活按钮

对于辅助功能或鼠标无法使用时特别有用。

技巧 4：悬停查看帮助

许多设置都有有用的工具提示。用鼠标悬停在设置名称或控件上查看更多信息。

示例： 悬停在 "麦克风增益" 上可能显示："Adjust this if your recordings are too quiet or too loud. 50% is the default."

技巧 5：设置自动保存（通常）

在大多数情况下，SeaMeet 在你更改时自动保存设置。然而，一些复杂更改需要点击 "Apply"。

需要点击 Apply 的迹象：

  • 可见且可点击的 "Apply" 按钮
  • 你看到 "未保存的更改" 等文字
  • 设置涉及文件路径或外部资源

疑惑时： 点击 Apply！确认更改从来不会有害。

理解设置持久性

下面是要理解的重要一点：设置保存到你的用户配置，并在会话之间持久化。

这意味着：

  • 关闭并重新打开 SeaMeet 后设置保留
  • 即使重启计算机设置也保持
  • 设置与你的 Windows/Mac 用户账户绑定
  • 如果有多个用户账户，每个都有自己的设置

设置存储位置（技术）：

  • Windows： 通常在你的用户配置文件夹中，常在 AppData
  • macOS： 在你的用户 Library 文件夹
  • 你不需要直接访问这些文件 — 使用设置 UI

例外：

  • 部分便携版本可能把设置存在应用文件夹
  • 企业部署可能使用集中设置
  • 重新安装 SeaMeet 通常保留用户设置

设置安全性与隐私

SeaMeet 设置在你的电脑本地，通常不包含敏感信息。然而：

设置中的内容：

  • 文件路径（可能透露文件夹结构）
  • 应用偏好（你使用哪些功能）
  • 硬件选择（你偏好哪个麦克风）
  • 没有密码或账户凭据

隐私考虑：

  • 设置不包含你实际的录音（只是保存位置）
  • 自动检测设置显示你使用哪些应用（但不是使用数据）
  • 没有设置的云同步（一切都在本地）

企业环境：

  • IT 管理员可能能查看或管理设置
  • 组策略可能覆盖部分设置
  • 如有顾虑请咨询 IT 部门

排查设置问题

问题 1：设置无法保存

症状： 你更改设置，但重新打开设置时它会还原。

解决方案：

  1. 确保点击 "Apply" — 部分设置需要显式保存
  2. 检查磁盘空间 — 驱动器满则无法保存设置
  3. 以管理员运行 — 尝试在 SeaMeet 上右键并 "以管理员身份运行"
  4. 检查权限 — 确保你对用户配置文件夹有写入访问
  5. 重新安装 SeaMeet — 先备份录音，然后重新安装

问题 2：设置变灰

症状： 一些设置可见但无法更改（变灰或禁用）。

常见原因：

  • 另一个设置禁用它们 — 例如，如果视频录制被禁用，你无法设置视频质量
  • 管理员/企业限制 — 你的组织可能锁定某些设置
  • 功能不可用 — 该功能可能不在你的版本中
  • 硬件限制 — 部分设置需要特定硬件

解决方案：

  1. 检查是否需要先启用父设置
  2. 如果是企业限制请联系 IT 部门
  3. 检查 SeaMeet 版本（部分功能为版本特定）
  4. 验证硬件支持该功能

问题 3：设置 UI 故障

症状： 设置看起来不对、重叠或显示不正确。

解决方案：

  1. 调整窗口大小 — 试试让 SeaMeet 窗口更大
  2. 重启 SeaMeet — 关闭并重新打开应用
  3. 更新显卡驱动 — 过时的驱动会导致 UI 问题
  4. 更改显示缩放 — 如果使用高 DPI (4K)，临时尝试 100% 缩放
  5. 重新安装 SeaMeet — 如果其他都不行，全新安装通常解决 UI 问题

问题 4：找不到设置

症状： 你知道存在某个设置，但找不到它。

解决方案：

  1. 使用搜索 — 在设置搜索框中输入关键词
  2. 检查所有类别 — 它可能在意外类别中
  3. 检查高级设置 — 部分设置藏在 "高级" 按钮后面
  4. 更新 SeaMeet — 该设置可能在更新版本中
  5. 阅读手册 — 每个设置章节列出所有可用选项

进阶：设置文件位置（适用进阶用户）

标准位置：

~/Library/Application Support/SeaMeet/

或在偏好中：

~/Library/Preferences/com.seameet.app.plist

如何访问：

  1. 打开访达
  2. 按 Command + Shift + G
  3. 输入 ~/Library/Application Support/SeaMeet
  4. 点击 Go

何时直接编辑设置文件

通常你不应该需要这样做，但对以下情况可能有帮助：

  • 在没有云的情况下在计算机之间迁移设置
  • 一次性批量编辑多个设置
  • 从备份恢复设置
  • UI 无法打开时排查

始终：

  • 编辑前完全关闭 SeaMeet
  • 先制作备份副本
  • 使用合适的 JSON/文本编辑器（Notepad++、VS Code 等）
  • 保存前验证文件格式正确

设置检查清单：先配置什么

如果你被所有选项压倒，下面是按优先级排序的最重要设置检查清单：

必备（首先做这些）

  • 存储位置 — 确保录音去你想要的地方
  • 默认麦克风 — 确保选中正确设备
  • 语言 — 设为你偏好的语言
  • 自动启动偏好 — 决定 SeaMeet 是否应随计算机启动

重要（尽快做这些）

  • 视频质量 — 根据需求和计算机性能设置
  • 音频格式 — 根据质量与文件大小偏好选择
  • 主题 — 浅色或深色模式以获得舒适
  • 键盘快捷键 — 自定义以匹配你的工作流

有用（需要时配置）

  • 自动检测应用 — 为你常用的应用启用
  • Flashback 设置 — 把缓冲时长调到你偏好
  • 通知偏好 — 选择哪些事件通知你
  • 光标录制选项 — 用于教程/演示录制

可选（以后细调）

  • 高级音频设置 — 采样率、位深
  • 视频编解码器偏好 — 压缩设置
  • 文件命名模式 — 自定义组织格式
  • 热键自定义 — 进阶键盘快捷键映射

设置术语表：快速参考

下面是你在设置中会看到的术语的快速术语表：

Enable/Disable — 打开或关闭功能 Default — 除非你另外指定使用的设置 Path/Directory — 你计算机上的位置（如 C:\Users\You\Documents） Browse — 打开文件浏览器选择位置 Bitrate — 每秒使用多少数据（更高 = 更好质量、更大文件） Sample Rate — 每秒捕获音频多少次（44.1kHz = 44,100 次/秒） Resolution — 视频图像大小（1080p = 1920×1080 像素） Frame Rate — 每秒多少视频帧 (fps) Buffer — 进行中数据的临时内存存储 Gain — 输入的音量水平（麦克风灵敏度） Codec — 压缩/解压缩音频/视频的软件 Format — 文件类型（MP3、MP4、WebM 等） Toggle — 打开或关闭某物的开关 Apply — 保存你做的更改 Reset — 返回原始/默认值
