音频设置

第 20 章：音频设置

简介

声音是录音的灵魂。无论您是在录制一场关键的商务会议、录制播客，还是保存家庭视频通话，音频质量都可能决定最终结果是专业水准还是令人沮丧、无法使用的废品。音频设置是您确保每个声音清晰传达的工具箱——没有含糊不清、没有回声、没有"你能听到我吗？"的尴尬时刻。

读完本章后，您将成为音频专家。您将了解如何选择合适的麦克风、完美调整音量水平、避免蓝牙延迟等常见音频问题，以及为您的需求选择最佳音频格式。

本章目标

阅读本章后，您将能够：

  • 选择和配置默认麦克风
  • 调整麦克风增益以获得最佳音量水平
  • 了解并防止蓝牙音频延迟问题
  • 为您的需求选择合适的音频格式（MP3、WAV、WebM）
  • 配置系统音频捕获设置
  • 排除常见音频录制问题
  • 为不同的录制场景设置音频

为什么音频设置很重要

想象一下这个场景：您刚刚结束了一场 2 小时的战略规划会议。您录制了整个会议，以便团队稍后回顾决策。但当您回放时，却发现：

  • 您的声音几乎听不到（麦克风太远）
  • 视频通话中的客户听起来像在水下说话（压缩过度）
  • 有令人分心的回声（房间声学 + 增益过高）
  • 每次打字时都像雷声一样响（敏感的麦克风拾取了键盘声）

视频看起来很好，但音频太差，录音几乎没有用处。这就是为什么花时间在音频设置上是值得的——好的音频比好的视频更难在后期修复。

掌握音频设置的关键原因：

1. 专业品质

  • 清晰的音频让您听起来专业且准备充分
  • 差的音频会削弱即使是最好的内容
  • 客户和同事会通过声音来判断质量

2. 理解力和可访问性

  • 清晰的音频更容易理解
  • 对转录准确性很重要
  • 对无障碍访问至关重要（听力障碍）

3. 文件大小管理

  • 音频格式的文件大小差异巨大
  • 选择质量与大小之间的正确平衡
  • 在不牺牲清晰度的情况下节省存储空间

4. 避免重录

  • 最好一次就做对
  • 重新录制会议通常是不可能的
  • 正确的设置可以防止灾难

理解音频基础知识

在深入设置之前，让我们先了解数字音频录制的基本原理。

数字音频的工作原理（简单解释）

将音频录制想象成给声音拍照：

采样率 = 每秒拍多少"照片"

  • 类似于相机快门速度
  • 44.1kHz = 每秒 44,100 个采样
  • 48kHz = 每秒 48,000 个采样
  • 越高 = 更多细节，更大的文件

位深度 = 每个采样的细节程度

  • 类似于相机色彩深度
  • 16 位 = 65,536 个可能的值
  • 24 位 = 1670 万个可能的值
  • 越高 = 更大的动态范围，更大的文件

比特率 = 每秒总数据量

  • 采样率 x 位深度 x 声道数
  • 越高 = 更好的质量，更大的文件
  • MP3 使用"有损"压缩来降低比特率

类比： 录制音频就像用点（像素）画画。每英寸更多的点（采样率）和更多可用的颜色（位深度）= 更好的画面。但需要更多的颜料（存储空间）。

音频声道

单声道（1 个声道）：

  • 单一音频流
  • 所有声音混合在一起
  • 更小的文件
  • 适用于：语音录制、听写

立体声（2 个声道）：

  • 左右两个音频流
  • 创造空间感
  • 更大的文件（单声道的 2 倍）
  • 适用于：音乐、沉浸式录制

SeaMeet 通常录制：

  • 麦克风音频为单声道
  • 系统音频为立体声（如果源是立体声）

第 1 节：麦克风选择

麦克风是您的音频输入设备——它捕获您的声音并将其转换为数字数据。选择合适的麦克风会产生巨大的差异。

麦克风类型

1. 内置麦克风（笔记本电脑/网络摄像头）

  • 优点： 随时可用，无需设置
  • 缺点： 质量差，拾取计算机噪音，对位置敏感
  • 最适用于： 仅在紧急情况下使用

2. USB 麦克风（独立式）

  • 示例： Blue Yeti、Audio-Technica AT2020USB+、Rode NT-USB
  • 优点： 出色的质量，易于设置，价格实惠（$50-200）
  • 缺点： 占用桌面空间，在摄像头中可见
  • 最适用于： 家庭办公、播客、日常录制

3. 耳机麦克风

  • 示例： Jabra、Plantronics、游戏耳机
  • 优点： 与嘴巴距离一致，免提
  • 缺点： 质量不一，长时间佩戴可能不舒适
  • 最适用于： 长时间通话、游戏、免提工作

4. 无线/蓝牙麦克风

  • 示例： AirPods、蓝牙耳机
  • 优点： 行动自由，无线缆
  • 缺点： 延迟问题，依赖电池，压缩伪影
  • 最适用于： 短时通话、移动录制（有注意事项）

5. 专业 XLR 麦克风

  • 示例： Shure SM7B、Electro-Voice RE20
  • 优点： 录音棚品质，极其耐用
  • 缺点： 需要音频接口（$$），设置复杂
  • 最适用于： 专业录音棚、广播品质

在 SeaMeet 中选择默认麦克风

分步操作：

  1. 打开音频设置

    • 点击设置齿轮图标
    • 点击左侧边栏中的 "Audio"

  2. 找到 "Default microphone" 下拉菜单

    • 显示当前选择的设备

  3. 点击下拉菜单

    • 列出所有可用的麦克风

  4. 选择您首选的麦克风

    • 选择您最常使用的那个
    • 通常最好选择有线 USB 麦克风

  5. 点击 "Apply"

您将在列表中看到：

Microphone (Blue Yeti)
Microphone (Realtek Audio) ← 内置
Headset Microphone (Jabra)
Microphone (USB Audio Device)
Stereo Mix ← 系统音频（通常不要选择这个）

提示：

  • 选择名称中带有 "Microphone" 的麦克风，而不是 "Stereo Mix"
  • "Default" 通常表示 Windows 默认值（可能会意外改变）
  • 选择特定设备可确保一致性

测试您的麦克风

在录制任何重要内容之前，请务必测试您的麦克风！

使用 SeaMeet 的测试功能：

  1. 在音频设置中，找到输入电平测试部分

  2. 正常对着麦克风说话

  3. 观察电平表：

    • 应在 "Good" 区域（中间）跳动
    • 偶尔达到 "Loud" 是可以的
    • 不应持续达到最大值（红色）
    • 不应一直停留在 "Quiet"（太低）

  4. 查看当前电平显示：

    • 显示分贝 (dB)
    • -12 dB 到 -6 dB 是理想的
    • 0 dB 是最大值（会失真）
    • 低于 -30 dB 太安静了

颜色含义：

  • 🟢 绿色（-30 到 -12 dB）：良好电平
  • 🟡 黄色（-12 到 -6 dB）：变响了，偶尔可以
  • 🔴 红色（-6 到 0 dB）：太响了！会失真！

测试用语：

"Testing one, two, three. This is a microphone test."
"The quick brown fox jumps over the lazy dog."
"Peter Piper picked a peck of pickled peppers."

需要注意的事项：

  • ☐ 清晰，不闷
  • ☐ 没有回声或混响
  • ☐ 没有背景噪音（风扇、空调）
  • ☐ 发 "P" 和 "B" 音时没有爆破声
  • ☐ 音量一致
  • ☐ 没有噼啪声或静电声

第 2 节：麦克风增益（音量控制）

增益是描述麦克风信号被放大程度的技术术语。可以将它想象成音响上的音量旋钮——但用于输入而不是输出。

理解增益与音量的区别

增益（输入）：

  • 控制麦克风信号的响度
  • 在录制之前调整
  • 影响信噪比
  • 过高 = 失真（削波）
  • 过低 = 安静、有噪音的录音

音量（输出）：

  • 控制您听到的播放响度
  • 在录制之后调整
  • 不影响录音质量
  • 之后可以随时调高

类比：

  • 增益就像设置相机传感器的灵敏度
  • 音量就像调整屏幕亮度来查看照片
  • 如果照片模糊（低增益），把屏幕调亮也无法修复

调整麦克风增益

分步操作：

  1. 打开音频设置

  2. 找到 "Microphone Gain" 部分

  3. 调整增益滑块：

    • 正常对着麦克风说话
    • 观察电平表
    • 调整滑块直到稳定在 -12 到 -6 dB

  4. 针对特定场景微调：

    • 轻声说话（耳语）：应该仍然有反应
    • 大声说话（兴奋时）：应在 -6 dB 达到峰值，而不是 0 dB
    • 正常对话：应保持在 -18 到 -12 dB 左右

"增强"设置

某些麦克风（特别是内置笔记本电脑麦克风）需要额外的放大阶段，称为"增强"。

何时使用增强：

  • 麦克风本身声音很小
  • 即使增益为 100%，电平仍然太低
  • 使用距离嘴巴很远的麦克风
  • 内置麦克风通常需要 +10-20dB 增强

何时不使用增强：

  • 麦克风已经足够响了
  • 启用后听到嘶嘶声或噪音
  • 使用高质量 USB 麦克风（通常不需要）

如何设置：

  1. 首先尝试调整主增益滑块
  2. 如果仍然太安静，启用增强
  3. 从 10-20% 增强开始
  4. 测试并调整
  5. 增强越多 = 噪音越多，所以使用所需的最小值

自动增益：是好是坏？

什么是自动增益？ 自动实时调整麦克风音量以保持电平一致。

优点：

  • ☐ 适合不一致的讲话者（有的声音大，有的声音小）
  • ☐ 在整个录制过程中保持一致的音量
  • ☐ 无需手动操作，无需手动调整

缺点：

  • ☐ 可能导致"抽吸"效果（音量明显波动）
  • ☐ 当您停止说话时可能放大背景噪音
  • ☐ 可能产生不自然的音频
  • ☐ 不适合专业录制

建议：

  • ✅ 在以下情况下启用自动增益：

    • 非正式团队会议
    • 质量不太重要的快速通话
    • 当您经常走动时

  • ❌ 在以下情况下禁用自动增益：

    • 专业演示
    • 播客录制
    • 客户会议
    • 任何质量重要的录制

如何切换：

☑ Automatically adjust microphone gain  ← 勾选启用
☐ Automatically adjust microphone gain  ← 取消勾选禁用

第 3 节：系统音频捕获

系统音频是从您的计算机发出的声音——视频通话中的声音、通知声音、您播放的视频等。捕获这些对于完整的会议录制至关重要。

什么会被捕获？

包含在系统音频中：

  • 来自 Zoom、Teams、Meet 通话的声音
  • 来自 YouTube 和培训视频的音频
  • 游戏声音
  • 计算机上播放的音乐
  • 通知声音

不包含：

  • 来自其他物理设备的声音
  • 您的麦克风（那是单独的）
  • 来自手机的音频
  • 播放物理媒体的外部扬声器

系统音频源选择

通常可用的选项：

  1. 默认输出设备

    • 捕获计算机正在播放的任何内容
    • 自动跟随您的声音设置
    • 推荐大多数用户使用

  2. 特定输出设备

    • Speakers (Realtek Audio)
    • Headphones (USB Audio)
    • Monitor Audio (HDMI)
    • 如果您有多个输出设备则使用

  3. Stereo Mix / What U Hear

    • 捕获计算机上播放的所有内容
    • 可能并非所有系统都可用
    • 可能需要在 Windows 声音设置中启用

如何设置：

Default system audio source: [Default Output Device ▼]

建议： 除非您有特定原因需要从特定输出捕获，否则使用 "Default Output Device"。

系统音频与麦克风：混合

当您录制 "Both"（麦克风 + 系统音频）时，SeaMeet 会创建混合音频：

您的声音 ───────┐
                ├──→ 混合在一起 ──→ 录音
对方的声音 ─────┘

为什么这很重要：

  • 录制后无法将它们分开
  • 如果一个太响/太安静，之后无法修复
  • 在录制前将两个电平都调好

测试混合：

  1. 选择 "Both" 开始测试录制
  2. 加入测试通话或播放视频
  3. 同时说话并播放视频/通话
  4. 停止并回放
  5. 检查：
    • 您的声音清晰可辨
    • 对方的声音可以听到
    • 两者都不会压过对方

第 4 节：蓝牙音频设置

蓝牙麦克风和耳机很方便，但在录制时有严重的注意事项。如果您使用无线音频设备，务必阅读本节。

理解蓝牙延迟

什么是延迟？ 声音产生到被捕获或回放之间的延迟。

蓝牙延迟问题：

您说: "Hello"
                ↓
蓝牙传输 (50-200ms 延迟)
                ↓
SeaMeet 接收: "Hello" (迟了半秒)
                ↓
录音出现同步问题

为什么蓝牙有延迟：

  1. 音频压缩（蓝牙使用有损编解码器）
  2. 无线传输时间
  3. 设备处理时间
  4. 不同的蓝牙版本有不同的延迟

典型蓝牙延迟：

  • 蓝牙 4.2：200-300ms（非常明显）
  • 蓝牙 5.0：100-200ms（明显）
  • 蓝牙 5.2 LE Audio：40-80ms（较好）
  • 有线连接：<10ms（不可感知）

蓝牙录制的最佳实践

什么时候可以使用蓝牙：

  • ✅ 非正式的内部会议
  • ✅ 音频质量不太重要时
  • ✅ 短时录制（<15 分钟）
  • ✅ 没有有线选项时

什么时候应避免蓝牙：

  • ❌ 客户演示
  • ❌ 将公开分享的录音
  • ❌ 播客或专业内容
  • ❌ 长时间录制（电池会耗尽）
  • ❌ 需要精确唇形同步时

如果必须使用蓝牙：

  1. 让设备保持近距离：

    • 距计算机 3 英尺（1 米）以内
    • 减少断连并改善延迟

  2. 确保电量充足：

    • 低电量 = 更差的性能
    • 长时间录制前检查电量

  3. 关闭其他蓝牙设备：

    • 减少干扰
    • 断开未使用的蓝牙外设

  4. 使用最好的可用编解码器：

    • aptX Low Latency（如果支持）：~40ms
    • AAC（Apple 设备）：~120-150ms
    • SBC（标准）：~200-300ms

  5. 先测试：

    • 始终进行 30 秒的测试录制
    • 检查同步问题
    • 验证音频质量

  6. 考虑替代方案：

    • 有线 USB 耳机：更好的质量，无延迟
    • USB 麦克风 + 有线耳机：专业配置
    • 在手机上单独录制音频，后期编辑中同步

第 5 节：音频格式设置

音频格式决定了录音的压缩和保存方式。这会影响文件大小、兼容性和质量。

SeaMeet 中可用的音频格式

1. MP3 (MPEG-1 Audio Layer III)

  • 最适用于： 分享、网络播放、存储效率
  • 优点： 文件小、通用兼容性、处理快
  • 缺点： 有损压缩（有一定质量损失）
  • 典型大小： 每分钟 1MB（128 kbps）

2. WAV (Waveform Audio File Format)

  • 最适用于： 专业编辑、存档、最高质量
  • 优点： 未压缩、无质量损失、行业标准
  • 缺点： 文件大、上传较慢
  • 典型大小： 每分钟 10MB（CD 品质）

3. WebM（纯音频子集）

  • 最适用于： 网络应用、HTML5 播放
  • 优点： 开放格式、良好压缩、现代
  • 缺点： 不如 MP3 通用
  • 典型大小： 每分钟 0.5-1MB（使用 Opus 编解码器）

4. OGG (Ogg Vorbis)

  • 最适用于： 开源项目、技术应用
  • 优点： 免费格式、良好压缩
  • 缺点： 有限的设备支持
  • 典型大小： 每分钟 1-2MB

5. M4A (MPEG-4 Audio)

  • 最适用于： Apple 生态系统、播客
  • 优点： 低比特率下质量好、与 iTunes 兼容
  • 缺点： 在 Apple 之外兼容性不一
  • 典型大小： 每分钟 1MB

质量设置

MP3/M4A（比特率选项）：

Quality: [Medium (128 kbps) ▼]

选项：
• Low (96 kbps)     — 文件小，可接受的质量
• Medium (128 kbps) — 良好平衡，推荐
• High (192 kbps)   — 更好的质量，更大的文件
• Very High (256 kbps) — 出色的质量
• Extreme (320 kbps) — 近乎透明，大文件

建议：

  • 语音录制：128-192 kbps
  • 音乐/内容：192-320 kbps
  • 存档：WAV 或 320 kbps MP3

WAV（位深度选项）：

Bit depth: [16-bit ▼]

选项：
• 16-bit — CD 品质，标准
• 24-bit — 专业级，更大的动态范围
• 32-bit float — 最高质量，非常大的文件

建议：

  • 大多数录制：16 位就够了
  • 专业工作：24 位
  • 32 位浮点仅在进行大量音频处理时使用

采样率设置

Sample rate: [48 kHz ▼]

选项：
• 44.1 kHz — CD 品质，音乐标准
• 48 kHz — 专业视频标准，推荐
• 96 kHz — 高分辨率，对大多数用途来说过于冗余

建议：

  • 视频录制使用 48 kHz（匹配视频标准）
  • 纯音频使用 44.1 kHz 也可以
  • 更高的采样率 = 更大的文件，可听到的差异微乎其微

格式选择指南

场景 1：快速团队会议记录

Format: MP3
Quality: Medium (128 kbps)
Sample rate: 48 kHz
原因：文件小，易于分享，语音质量足够

场景 2：客户演示录制

Format: WAV
Bit depth: 16-bit
Sample rate: 48 kHz
原因：最高质量，专业存档

场景 3：播客录制

Format: MP3
Quality: High (192 kbps)
Sample rate: 44.1 kHz
原因：良好质量，可管理的大小，播客标准

场景 4：网页上传/流媒体

Format: WebM (Opus codec)
Quality: Medium
Sample rate: 48 kHz
原因：为网页优化，文件小，质量好

第 6 节：高级音频设置

噪音抑制

功能说明： 使用软件算法去除背景噪音（风扇、空调、键盘敲击声）。

通常包含的设置：

☑ Enable noise suppression
Level: [Medium ▼]

级别：
• Light — 仅去除明显的噪音
• Medium — 平衡的噪音去除（推荐）
• Aggressive — 去除更多噪音但可能影响语音

何时使用：

  • ✅ 嘈杂的环境
  • ✅ 笔记本电脑风扇运转时
  • ✅ 机械键盘敲击时
  • ✅ 空调嗡嗡声

注意：

  • 激进的抑制可能使声音听起来像机器人
  • 可能会去除想要的环境声音
  • 在重要录制前测试

回声消除

功能说明： 当您的麦克风拾取扬声器发出的声音时，防止产生回声。

工作原理：

  1. 计算机播放通话中的声音
  2. 麦克风可能从扬声器拾取这个声音
  3. 没有消除功能：对方会听到自己的回声
  4. 有消除功能：软件去除回声声音

设置：

☑ Enable echo cancellation
Strength: [Normal ▼]

何时使用：

  • ✅ 使用扬声器而不是耳机时
  • ✅ 在有扬声器的会议室中
  • ❌ 使用耳机/耳麦时不需要

注意： 回声消除可能会稍微降低音频质量。尽可能使用耳机替代。

自动增益控制 (AGC)

已在第 2 节中介绍，但值得注意高级选项：

☑ Enable AGC
Attack time: [Fast ▼]  — 对响亮声音的响应速度
Release time: [Slow ▼] — 恢复正常的速度
Max gain: [+20 dB ▼]   — 允许的最大放大量

微调：

  • Attack time： 快速 = 快速响应突然的响声
  • Release time： 慢速 = 平滑过渡，避免抽吸效果
  • Max gain： 限制安静声音的提升幅度（防止噪音放大）

第 7 节：音频故障排除

问题 1：未检测到麦克风

症状：

  • 麦克风未出现在下拉列表中
  • "No microphone found" 错误
  • 测试没有输入

解决方案：

  1. 检查物理连接：

    • 确保 USB 线缆牢固插入
    • 尝试不同的 USB 端口
    • 检查麦克风是否有电源指示灯

  2. Windows 声音设置：

    • 右键单击任务栏中的扬声器图标 -> 打开声音设置
    • 点击 "Sound Control Panel"（在右侧）
    • 转到 "Recording" 标签
    • 查看麦克风是否出现
    • 如果出现但被禁用：右键单击 -> 启用
    • 如果出现但不是默认设备：右键单击 -> 设为默认设备

  3. 更新驱动程序：

    • 设备管理器 -> 音频输入和输出
    • 找到您的麦克风
    • 右键单击 -> 更新驱动程序
    • 或卸载并重启（Windows 会重新安装）

  4. macOS 权限：

    • 系统偏好设置 -> 安全性与隐私 -> 隐私
    • 点击左侧的麦克风
    • 确保 SeaMeet 已勾选

  5. 重启 SeaMeet：

    • 完全关闭并重新打开
    • 有时需要完全重启计算机

问题 2：录音太安静

症状：

  • 电平表几乎不动
  • 回放需要最大音量才能听到
  • 转录失败或不准确

解决方案：

  1. 增加增益： 音频设置 -> 麦克风增益滑块，增加到 70-80%
  2. 启用增强： 打开 "Boost" 选项，设置为 10-20%
  3. 靠近麦克风： 理想距离：6-12 英寸（15-30 厘米）
  4. 检查 Windows 电平： 声音控制面板 -> 录制 -> 双击您的麦克风 -> 级别标签 -> 增加到 80-100%
  5. 检查静音按钮： 许多麦克风有物理静音按钮

问题 3：录音太响/失真

症状：

  • 电平表持续在红色区域
  • 音频听起来噼啪或爆裂
  • 峰值达到最大电平

解决方案：

  1. 降低增益： 音频设置 -> 将增益降至 40-60%
  2. 禁用增强： 如果已启用，关闭增强
  3. 远离麦克风： 增加距离至 12-18 英寸
  4. 说话声音小一些： 正常对话水平最佳
  5. 检查 Windows 中的削波： 声音控制面板 -> 录制 -> 属性 -> 级别标签

问题 4：背景噪音/嘶嘶声

解决方案：

机械噪音： 启用噪音抑制，设为 Medium 或 Aggressive，将麦克风远离计算机风扇。

键盘敲击声： 使用按键通话功能，将键盘远离麦克风，使用机械键盘阻尼器。

房间回声： 添加软质家具，在较小的房间录制，使用隔音板，靠近麦克风。

电子嘶嘶声： 降低麦克风增益，靠近麦克风，使用更高质量的麦克风，检查线缆连接。

问题 5：系统音频未录制

解决方案：

  1. 检查录制模式： 确保录制 "System Audio" 或 "Both"
  2. 检查系统音频源： 音频设置 -> 默认系统音频来源
  3. Windows Stereo Mix： 声音控制面板 -> 录制 -> 显示禁用的设备 -> 启用 Stereo Mix
  4. macOS 屏幕录制权限： 系统偏好设置 -> 安全性与隐私 -> 隐私 -> 屏幕录制 -> 勾选 SeaMeet
  5. 检查通话音频： 确保通话音频通过计算机播放

问题 6：音频/视频不同步

解决方案：

  1. 使用有线麦克风： 从蓝牙切换到 USB 或有线耳麦
  2. 重启计算机： 清除音频缓冲区问题
  3. 检查蓝牙延迟： 遵循第 4 节的蓝牙最佳实践
  4. 调整缓冲区大小（高级）： 更大的缓冲区 = 更多延迟但更少故障
  5. 后期制作修复： 导入视频编辑器，手动调整音频轨道时间

第 8 节：录制场景配置

场景 1：专业播客录制

目标： 最高质量，存档标准

设置：

Microphone: USB condenser mic (Blue Yeti, AT2020)
Gain: 65% (peaks at -6 dB)
Boost: Off
Auto-gain: Off
Format: WAV (24-bit, 48 kHz)
Noise suppression: Light or Off
Echo cancellation: Off
System audio: Off (unless doing interviews)
Bluetooth: Never

场景 2：每日团队站会

目标： 良好质量，高效存储，快速分享

设置：

Microphone: Headset or built-in (convenience over quality)
Gain: 70%
Boost: 10% (if using laptop mic)
Auto-gain: On (inconsistent speakers)
Format: MP3 (192 kbps)
Sample rate: 48 kHz
Noise suppression: Medium
Echo cancellation: On (using speakers)
System audio: On (capture team voices)
Bluetooth: Only if necessary, test first

场景 3：客户演示录制

目标： 专业质量，可靠捕获，备份安全

设置：

Microphone: Quality USB mic or headset
Gain: Test and set to -12 dB peaks
Boost: Off
Auto-gain: Off
Format: WAV (16-bit) for primary, MP3 backup
Sample rate: 48 kHz
Noise suppression: Light
Echo cancellation: Off (use headphones)
System audio: On (capture client audio)
Bluetooth: Never (too risky)

场景 4：游戏/教程录制

目标： 平衡语音清晰度和游戏音频

设置：

Microphone: Headset mic or dedicated USB
Gain: 60-70%
Boost: Off
Auto-gain: Off (prevents volume pumping during quiet game moments)
Format: MP3 (192 kbps) or M4A
Sample rate: 48 kHz
Noise suppression: Medium (keyboard clicks)
Echo cancellation: Off (wearing headphones)
System audio: On (game audio)
Bluetooth: Never (latency ruins gameplay)
