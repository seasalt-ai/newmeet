主界面——SeaMeet 用户界面完整导览

第 11 章：主界面——SeaMeet 用户界面完整导览

到目前为止，你已经用 SeaMeet 录制过音视频、整理过库，也播放过录音。你和界面的许多部分都打过交道，但未必清楚这些部分如何拼成整体。本章对 SeaMeet 的主界面做一次完整导览——涵盖每个按钮、面板、指示器和控件——让你能自信地导航应用，并发现可能尚未注意到的功能。

把本章想象成参观一栋新房：我们会逐个空间走过，查看功能，并说明每样东西的用途。读完后，你将清楚每项功能在哪里，以及界面在不同情境下如何变化。

窗口布局：全局视角

打开 SeaMeet 时，你会看到一个布局一致的单窗口。无论你正在录音、播放，还是仅仅浏览库，这种布局都保持稳定。理解这一布局，是高效使用 SeaMeet 的基础。

区域 1：顶部导航栏

  • 始终可见
  • 包含全局控件
  • 快速访问关键功能

区域 2：侧边栏（录音列表）

  • 在大多数视图中始终可见
  • 展示你的录音
  • 可滚动的录音卡片列表

  • 随上下文变化

  • 配置选项时显示设置

区域 1：顶部导航栏

顶部导航栏提供导航与账户相关控件。它保持精简——录音控件与 Flashback 已移至主内容区的 Capture Hub（见下文状态 1）。

导航开关（☰）

作用： 收起或展开左侧边栏（录音列表）。

何时使用：

  • 收起以为 Capture Hub 腾出更多横向空间
  • 在未录音时展开，浏览录音库

账户 / 用户菜单（👤）

作用： 打开用户账户菜单，你可以在其中：

  • 登录或退出
  • 打开设置（音频、视频、Flashback、存储、语言、快捷键）
  • 打开键盘快捷键参考
  • 访问帮助与支持

如何使用：

  1. 点击头像或用户图标
  2. 在下拉菜单中选择所需选项

录音按钮（🔴）

图标： 就绪时为红色圆点（🔴），录音中为方块（⏹️）
标签： “RECORD”或仅图标
颜色： 亮红色（表示录音操作）

作用：
开始或停止录音

状态：

就绪录音：

[🔴 RECORD]
红色圆点图标
点击开始录音

录音进行中：

[⏹️ STOP]
方块图标
显示已用时间的计时器
点击停止录音

如何使用：

开始录音：

  1. 先配置好录音设置
  2. 点击红色录音按钮
  3. 录音立即开始
  4. 按钮变为停止
  5. 计时器开始计数

停止录音：

  1. 点击停止按钮（方块）
  2. 录音结束
  3. 文件已保存
  4. 录音出现在侧边栏
  5. 按钮恢复为录音状态

点击录音时会发生什么：

  1. 开始采集音频/视频
  2. 出现显示已用时间的计时器
  3. 按钮从 🔴 变为 ⏹️
  4. 视觉指示反映录音状态
  5. 文件正在写入存储

点击停止时会发生什么：

  1. 录音停止
  2. 文件完成写入并保存
  3. 录音出现在侧边栏列表
  4. 按钮回到 🔴 状态
  5. 计时器消失或重置

重要说明：

  • 录音会立即开始——请做好准备！
  • 没有倒计时或警告
  • 点击前请确认设置正确
  • 若已启用 Flashback，会包含缓冲的过去片段

搜索框

位置： 侧边栏顶部
外观： 带放大镜图标（🔍）的文本框
占位符： “Search recordings…”或类似文案

作用：
在你输入时实时筛选录音列表

如何使用：

  1. 点击搜索框
  2. 开始输入
  3. 列表自动筛选
  4. 仅显示与搜索匹配的录音
  5. 清空搜索即可再次看到全部录音

可以搜索什么：

  • 录音名称
  • 来源标签（“Zoom”、“Teams”）
  • 日期（若以可搜索格式输入）
  • 支持部分匹配

搜索示例：

  • 搜索 “Zoom” → 显示所有 Zoom 录音
  • 搜索 “budget” → 显示名称中含 “budget” 的录音
  • 搜索 “March” → 显示三月相关录音
  • 搜索 “client” → 显示与客户相关的录音

清除搜索：

  • 点击 X 按钮（若有）
  • 删除全部文字
  • 按 Esc 键

左侧面板 — 开始录音

左侧面板包含开始新录音所需的全部控件：

卡片顶部两侧控件：

  • Flashback 开关（左侧）—— 点击可在 Flashback 模式间循环：关 → 音频 → 屏幕 → 关。就绪（缓冲充电或已就绪）时显示 ⚡ 闪电图标。完整说明见第 6 章。
  • 大红麦克风圆钮（中间）—— 点击可打开 “Video Settings” 对话框并选择录音模式（仅音频、全屏、窗口、区域）。
  • Auto-Detect 开关（右侧）—— 检测到会议应用时自动开始录音。

卡片中部上下文区：

  • Flashback 关闭时：显示简要入门说明。
  • Flashback 正在武装（充电）时：缓冲填充过程中显示进度指示。
  • Flashback 就绪时：显示 ⚡ 图标和 “Flashback armed” 确认文案。

卡片底部主按钮（CTA）：

  • 标签与行为随 Flashback 状态变化：
    • Flashback 关 → “Start Recording”（打开 “Video Settings”）
    • Flashback 武装中 → “Buffering…”（填充期间禁用）
    • Flashback 就绪 → “Record with Flashback”（捕获缓冲并开始录音）

底部快捷入口：

  • Open Launcher — 打开 SeaMeet Launcher 面板，并显示对应快捷键
  • Open Floater — 显示/隐藏 Floater 小部件，并显示对应快捷键

右侧面板 — 截图

右侧面板独立于录音处理截图：

  • 相机图标按钮 — 大号主按钮；点击即可按当前所选模式截图。
  • Full Screen / Area Capture — 单选：全屏截图或框选区域。
  • Keep SeaMeet window visible 复选框 — 未勾选（默认）时，SeaMeet 会在截图前最小化，以免出现在截图中。勾选后窗口保持可见并会出现在画面中。
  • Take Screenshot 按钮 — 触发截图（与点击相机图标相同）。

用途：

  • 开始捕获前所需功能的一站式入口
  • 无需打开设置即可查看并控制 Flashback 状态
  • 截图与录音清晰分为两张卡片

  • 格式：时:分:秒 或 分:秒
  • 每秒更新

  • 音频的实时可视化
  • 录音时显示音量变化
  • 便于确认音频已被采集

音量电平表：

  • 显示当前输入音量
  • 绿色 = 电平合适
  • 黄色 = 偏响
  • 红色 = 过响（削波/失真）

控制按钮：

  • Pause（⏸️）— 暂停录音（若支持）
  • Stop（⏹️）— 结束录音并保存
  • Mark（⏺️）— 添加时间戳标记（若可用）

视觉指示与状态图标

在 SeaMeet 各处，不同图标与颜色会反馈应用状态。

录音状态指示

未在录音：

  • 录音按钮显示 🔴（红圆）
  • 无计时器
  • 窗口标题正常

正在录音：

  • 录音按钮显示 ⏹️（方块）
  • 计时器显示已用时间
  • 可能有红色描边或 “RECORDING” 指示
  • 窗口标题可能变为显示 “[Recording]”

已暂停（若支持）：

  • 暂停按钮高亮
  • 计时器冻结
  • 可见 “PAUSED” 指示

Flashback 状态指示

关：

  • 灰色
  • “OFF” 或无指示
  • 未占用内存

填充中：

  • 琥珀/黄色
  • 动画或脉冲效果
  • 可能显示百分比（例如 “FILLING 60%”）
  • 依赖其就绪前请等待变为绿色

就绪：

  • 绿色
  • 稳定指示
  • 显示时长（例如 “30S”）
  • 可捕获过去片段

音量电平指示

录音过程中：

电平合适（绿色）：

音频：████████████░░ 70%
  • 稳定的绿色条
  • 约 60–80% 较理想

过轻（偏低）：

音频：███░░░░░░░░░░ 20%
  • 条形几乎不动
  • 提高麦克风增益
  • 靠近麦克风一些

过响（红色）：

音频：██████████████ 100% ⚠️
  • 条形顶满
  • 可能失真
  • 降低增益或离麦克风远一些

调整大小与布局

SeaMeet 的界面会随窗口尺寸变化。

常规窗口尺寸

较佳尺寸：

  • 宽度：1000–1400 像素
  • 高度：700–900 像素
  • 各元素可见且可操作

窄窗口（侧边栏收起）

窗口较窄时：

  • 侧边栏可能收起或变为下拉
  • 主内容区占用更多空间
  • 部分控件可能移入菜单

宽窗口（展开视图）

窗口较宽时：

  • 侧边栏可能变宽
  • 可见更多录音卡片
  • 播放器区域更大，利于视频

全屏模式

可用于：

  • 视频播放（F 键或按钮）
  • 部分设置面板
  • 演示模式

如何切换：

  • 进入： F 键或双击视频
  • 退出： Esc 键或再次按 F

界面自定义（若版本支持）

部分 SeaMeet 版本允许自定义界面。

主题设置

浅色模式：

  • 白/浅灰背景
  • 深色文字
  • 适合白天使用

深色模式：

  • 深灰/黑背景
  • 浅色文字
  • 弱光环境下更护眼
  • 在 OLED 屏上可能更省电

如何更改：

  1. 设置 → “Language & Appearance”
  2. 选择 “Light” 或 “Dark”
  3. 或选 “Auto” 跟随系统

侧边栏宽度（若可调）

如何调整：

  1. 找到侧边栏与主区域之间的边缘
  2. 光标变为调整大小光标（↔️）
  3. 左右拖动
  4. 松开以设定新宽度

界面导航技巧

快速移动

1. 使用键盘快捷键

  • 常见操作比鼠标更快
  • 空格播放/暂停
  • 方向键导航
  • 完整列表见第 13 章

2. 右键打开上下文菜单

  • 录音支持右键菜单
  • 快速访问常用操作
  • 不同区域选项不同

3. 留意悬停提示

  • 悬停在按钮上可查看说明
  • 对纯图标按钮尤其有用
  • 若可用会显示快捷键

4. 使用搜索框

  • 查找录音最快的方式
  • 实时搜索
  • 可搜名称与来源

理解视觉反馈

颜色含义：

  • 红色： 录音、错误、停止
  • 绿色： 就绪、成功、活动
  • 黄/琥珀： 警告、填充中、注意
  • 灰色： 禁用、未激活、关闭
  • 蓝色： 信息、链接、选中

动画含义：

  • 脉冲： 加载、填充、进行中
  • 静止： 就绪、完成、稳定
  • 闪烁： 紧急、需要关注
