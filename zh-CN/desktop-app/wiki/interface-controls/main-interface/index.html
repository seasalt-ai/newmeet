主界面 - SeaMeet UI 完整导览

第 13 章：主界面 - SeaMeet UI 完整导览

到目前为止，你已经用 SeaMeet 录制了音频和视频、整理过录音库，也回放过录音。你与界面的各部分都有过交互，但可能还没有一个完整的全貌，了解所有部分是如何拼装起来的。本章对 SeaMeet 主界面提供一次全面导览——每一个按钮、面板、指示器与控件——以便你可以自信地浏览应用，并发现那些你尚未察觉的功能。

把本章当作参观新房子的导游。我们会走进每个房间、查看其特色、解释每件设备的功能。读完本章，你将清楚知道在哪里能找到每一项功能，并理解界面如何根据不同情境进行自适应。

窗口布局：宏观图

打开 SeaMeet 时，你会看到一个具有一致布局的单一窗口。无论是在录制、播放，还是只是浏览库，这个布局都保持稳定。理解这个布局是高效使用 SeaMeet 的基础。

作用： 折叠或展开左侧侧边栏（录音列表）。

何时使用：

  • 折叠以给 Capture Hub 更多水平空间
  • 展开以在不录制时浏览录音库

作用： 打开用户账户菜单，你可以：

  • 登录或注销

  • 访问帮助与支持

如何使用：

  1. 点击你的头像或用户图标
  2. 从下拉中选择所需选项

录音按钮（🔴）

图标： 就绪时为红色圆圈（🔴），录音时为方块（⏹️） 标签： "RECORD" 或仅图标 颜色： 亮红色（表示录音动作）

作用： 开始或停止录音

状态：

就绪录音：

录音中：

[⏹️ STOP]
方块图标

如何使用：

开始录音：

  1. 先配置你的录音设置
  2. 点击红色 Record 按钮
  3. 录音立即开始
  4. 按钮变成 Stop
  5. 计时器开始计时

停止录音：

  1. 点击 Stop 按钮（方块）
  2. 录音停止
  3. 文件被保存
  4. 录音出现在侧边栏中
  5. 按钮回到 Record 状态

点击 Record 时发生的：

  1. 音频/视频捕获开始
  2. 计时器显示已用时间
  3. 按钮从 🔴 变为 ⏹️
  4. 视觉指示器显示录音状态
  5. 文件正在写入存储

点击 Stop 时发生的：

  1. 录音停止
  2. 文件被完结并保存
  3. 录音出现在侧边栏列表中
  4. 按钮回到 🔴 状态
  5. 计时器消失或重置

重要提示：

  • 录音立即开始——做好准备！
  • 没有倒计时或警告
  • 点击之前确保设置正确
  • Flashback（如启用）会包含已缓冲的过去

系统托盘

SeaMeet 在首次启动时安装一个系统托盘图标（Windows 通知区、macOS 菜单栏），并在整个应用会话期间保持运行。托盘是始终可用的控制平面——即使你关闭了主窗口，SeaMeet 仍在运行，准备捕获，并且只需点击它的图标即可访问。

为什么托盘保持存活

关闭主窗口并不会退出 SeaMeet。相反，窗口隐藏而托盘图标保留。这是有意的：

  • Auto-Detect 仍可以在会议应用启动时唤醒应用
  • Flashback 可以让其滚动缓冲保持充能（如已激活）
  • 全局热键（开始录音、显示启动器、显示 Floater）仍然有效
  • 一次快速录音只需点击托盘一次

第一次关闭窗口时，SeaMeet 会发送一次"已最小化到托盘"的提示，让你了解应用没有真的退出。要完全退出，请使用托盘菜单中的 Exit SeaMeet（见下文）或操作系统的退出应用命令。

托盘图标

默认图标（空闲）：

  • Windows：通知区的一个小 SeaMeet 标志 .ico
  • macOS：菜单栏中 22×22 的模板图像，适配明暗模式

录音图标（进行中）：

  • 切换为红色调变体，让你一眼看出 SeaMeet 正在捕获
  • 在 macOS 上菜单栏还会获得 ● 后缀；如果暂停则显示 ⏸
  • 提示文字从 "SeaMeet" 变为 "SeaMeet — Recording in progress"（或 "Paused"）

点击行为：

  • 左键点击图标 — 切换主窗口（隐藏则显示，可见则隐藏）
  • 右键点击图标（Windows）/ 单击（macOS）— 打开上下文菜单

托盘菜单（空闲状态）

不录音时，菜单大致如下：

┌─────────────────────────────────────────┐
│ 工作区: Acme Sales        (已禁用)      │   ← 仅 Lite / 云构建
├─────────────────────────────────────────┤

│   🖥️  录制全屏                          │
│   ◰  录制区域                           │
│   📷  截图                  (Ctrl+Shift+S)│
│   📁  打开录音文件夹                    │
├─────────────────────────────────────────┤
│ 🚀 显示启动器             (Ctrl+Shift+L)│
│ 🪟 显示悬浮窗口           (Ctrl+Shift+F)│
├─────────────────────────────────────────┤

│ ⏻  退出 SeaMeet                         │

各项含义：

  • Workspace: <name> — 显示从托盘启动的录音将落入哪个云工作区的标题。仅在已登录并选择了工作区的 Lite 或云启用构建中出现。在非云构建中该行完全隐藏，菜单形状保持不变。
  • Record audio — 立即开始仅音频录音。不请求视频源。
  • Record fullscreen — 开始主显示器加音频的录音。
  • Record region — 打开全屏区域叠加层让你拖选区域，然后开始该区域的录音。
  • Take screenshot — 打开区域选择器进行单次截图。如已在 Settings → Keyboard 中绑定，则显示快捷键。
  • Open recordings folder — 在当前保存目录打开操作系统的文件浏览器。
  • Show launcher — 切换 SeaMeet 启动器面板（见第 14 章）。绑定时显示快捷键。
  • Show floating window — 显示/隐藏 Floater 组件。绑定时显示快捷键。
  • Show main window — 把主窗口拉到前台（与图标隐藏时左键点击相同）。
  • Exit SeaMeet — 唯一真正退出的菜单项。它会设置内部"正在退出"标志，并请求 Electron 终止；其他都只是显示/隐藏界面。

托盘菜单（录音中）

当录音正在进行时，菜单会重新组合以提供直接的控制：

┌─────────────────────────────────────────┐
│ ● 录音进行中            (已禁用)        │
├─────────────────────────────────────────┤
│ ⏹  停止录音               (Ctrl+Shift+R)│
│ ⏸  暂停录音                             │
│ ⚑  标记事件                             │
├─────────────────────────────────────────┤
│ 🗔 显示主窗口                           │
├─────────────────────────────────────────┤
│ ⏻  退出 SeaMeet                         │
└─────────────────────────────────────────┘

关于录音菜单的说明：

  • 标题行纯粹是状态标签（被有意禁用）。
  • Stop recording 结束捕获并保存文件，与点击主窗口中的 Stop 按钮相同。
  • Pause/Resume 仅在编解码器/源支持时显示。仅视频录音会隐藏 Pause 项。
  • Mark event 在录音中放置一个时间戳标记，便于在播放时跳回关键时刻。
  • 暂停时，菜单会用 Resume recording 替换 Pause，macOS 标题翻转为 ⏸。

本地化标签

托盘菜单遵循 15 种支持的语言区域（英语、西班牙语、法语、德语、日语、韩语、印地语、波兰语、葡萄牙语、俄语、泰语、越南语、丹麦语、简体中文、繁体中文）。这些语言之外的退回到英语，菜单始终能正确渲染。

搜索框

位置： 侧边栏顶部 外观： 带放大镜图标 (🔍) 的文本字段 占位文字： "搜索录音…" 或类似

  • 没有选中录音且未在录音时

左面板 — 开始录音

左面板包含开始新录音的所有控件：

两侧控件（卡片顶部）：

  • Flashback toggle（左）— 点击循环 Flashback 模式：OFF → Audio → Screen → OFF。激活时（缓冲充能中或就绪）显示 ⚡ 闪电图标。完整细节见第 7 章。
  • 大红色麦克风圈（中）— 点击打开 Video Settings 模态，选择录音模式（仅音频、全屏、窗口、区域）。

上下文区（卡片中部）：

  • 当 Flashback 关闭时：显示如何开始的简短描述。
  • 当 Flashback 正在准备（充能中）时：显示缓冲填充的进度指示器。
  • 当 Flashback 就绪时：显示 ⚡ 图标和 "Flashback armed" 确认。

CTA 按钮（卡片底部）：

  • 标签和操作根据 Flashback 状态自适应：
    • Flashback OFF → "Start Recording"（打开 Video Settings）

    • Flashback 就绪 → "Record with Flashback"（捕获缓冲并开始录音）

  • Open Launcher — 打开 SeaMeet 启动器面板，显示对应快捷键

Lite 模式 vs Full 模式

SeaMeet 提供两种界面模式。它们共享同一个录音引擎、磁盘上的同一份文件、以及同一个托盘图标——但呈现的 UI 数量截然不同。

选择模式

在干净的首次启动时，SeaMeet 会显示一个模式选择器询问你想要哪种体验。已经升级的 v2.x 用户会被静默迁移到 Full 模式（所以没有可见变化），但所有人都可以在 Settings 中再切换。

所选模式以 appMode: 'full' | 'lite' 形式持久化在你的 UI 设置中。录音进行中切换模式会被等到录音排空之后再执行，所以你不会丢失捕获；设置模态会立即关闭，"保存中…" 的旋转图标在等待期间可见。

Full 模式（默认）

这是你到此读到的章节内容——侧边栏 + Capture Hub + 主内容区，包括上面各节涵盖的所有状态（录音、回放、设置）。Full 模式包括：

  • 带 Flashback 和截图控制的 Capture Hub
  • 带录音卡片、搜索、排序和筛选的完整侧边栏
  • 笔记和 Wiki（见第 16–17 章）
  • 媒体库（第 10 章）
  • 所有设置类别（第 18 章及之后）
  • 本地优先工作区（见下面的"工作区"）

当 SeaMeet 是你主要的录音界面，且你想在一个窗口里管理笔记、wiki、agent 和库时，请使用 Full 模式。

Lite 模式

Lite 模式是一个小得多的界面，以系统托盘和单一的云端会议列表为中心。没有侧边栏、没有笔记视图、没有 wiki、没有 Capture Hub——录音从托盘启动（或自动检测，或热键），完成的录音作为会议卡片在会后摘要管线把它们上传到你的 SeaMeet 工作区后浮现。

Lite 中的工作区标题：

Lite 窗口的最顶部是一个工作区切换器（显示活动工作区名称、头像和雪佛龙的按钮）。点击它会打开一个下拉，列出你在 SeaMeet 云上有权限的每个工作区。选择不同的工作区：

  1. 在本地持久化新工作区 ID
  2. 刷新会议列表
  3. 把新工作区名称推送到托盘菜单，让从托盘启动的录音也落到正确的地方
  4. 把分页重置到第 1 页

注销会清除托盘的工作区标题（traySetWorkspaceDisplay(null, null)），让菜单永远不会就你不再有权限的工作区撒谎。

在 Lite 中录音：

  • 点击托盘图标并选择 Record audio / fullscreen / region — 或使用全局热键
  • Lite 的 Recording View 接管主窗口，显示实时波形、计时器和单一的停止控件
  • 当你停止时，文件会被保存到本地并上传到你的 SeaMeet 工作区进行转录和摘要
  • 云端管线完成后，会议卡片会出现在列表中

当 SeaMeet 是为 SeaMeet 云提供素材的后台录音器时——你希望托盘做事，并有一个干净的会议列表供回顾——请使用 Lite 模式。

在模式之间切换

打开 Settings（任一模式下），找到 "Switch to Full / Lite mode" 操作并确认。SeaMeet 会排空任何进行中的录音，然后把渲染器重新启动到另一种模式。你的文件、工作区、设置和托盘图标都会在切换后保留。

工作区

SeaMeet 有两种不同的工作区概念，它们共享一个名字但生活在不同的地方。理解哪个是哪个能避免混淆。

本地工作区（Full 模式）

在 Full 模式中，工作区是类似 Obsidian 的 vault——磁盘上一个文件夹，存放你的笔记、生成的 wiki，以及（默认情况下）你的录音。主进程中的 WorkspaceManager 拥有：

  • 持久化在你的设置文件中的工作区注册表（{ id, name, path, isDefault? }[]）
  • 活动工作区 ID（同一时间只能激活一个）
  • 在活动工作区路径上的 chokidar 文件监视器，对外部卷和网络挂载（例如 macOS /Volumes/、Google Drive 的 ~/Library/CloudStorage/GoogleDrive-<email>/…）自动启用轮询，因为 FSEvents 在这些位置无法可靠触发
  • userData/workspace-state/<id>.json 下的每工作区状态（上次打开的笔记、最近文件等）

首次启动时，如果没有注册任何工作区，SeaMeet 会自动创建一个指向你保存目录的单一默认工作区。"默认"这个名字在所有 23 种语言中都有本地化。

工作区切换器（侧边栏标题）：

笔记视图（第 16 章）和 Wiki 视图（第 17 章）都会在文件树顶部渲染一个 <WorkspaceSwitcher>：

┌──────────────────────────────────┐
│ [🅰] Acme Vault            ⌄    │   ← 活动工作区
├──────────────────────────────────┤
│ 工作区                          │
│  ✓ Acme Vault     ~/Notes/Acme  │
│    Personal      ~/Notes/Personal│
│    Side Project  ~/Code/Side    │
├──────────────────────────────────┤
│ + 添加工作区…                    │
└──────────────────────────────────┘
  • 点击活动行打开下拉
  • 点击其他工作区进行切换 — 文件监视器拆除、新工作区的路径被挂载、笔记和 Wiki 刷新，并恢复每工作区状态
  • 添加工作区… 打开原生文件夹选择器，让你可以把任意目录注册为 vault（会检查唯一性——重复注册同一路径会被拒绝）
  • 行上的 删除（×）只移除 SeaMeet 条目；磁盘上的文件不会被动到。你无法删除最后一个工作区。
  • 当同步检测发现时，每行可能显示 云徽章（Dropbox、iCloud、OneDrive、Google Drive）和 git 远程徽章

工作区切换是串行化的：如果一次切换还在进行中，下一次会等待它完成，这样 NotesManager / WikiManager 永远不会指向陈旧路径。

云工作区（Lite 模式）

在 Lite 模式（以及云启用的 Full 构建）中，工作区的含义不同：SeaMeet 云上的团队工作区。<WorkspacePicker> 组件通过 SeaMeet API 获取你可访问的工作区，并持久化所选工作区供上传路由使用。

云工作区驱动：

  • 新录音上传到哪个工作区
  • 哪个工作区的会议出现在 Lite 会议列表中
  • 托盘菜单中的工作区标题行（这样你一眼就能看到下一个从托盘启动的录音将落到哪里）

云选择器会过滤掉 my_status 为 INACTIVE 的工作区。首次登录时，如果你之前选择的工作区不在返回列表中（你失去了成员资格、模式漂移等），选择器会自动选择第一个可用工作区并持久化——这样菜单永远不会被卡在不可访问的 ID 上。

同时存在

在云启用的 Full 构建中，你可以同时选中两种工作区：一个保存笔记的本地 vault 和一个接收上传的 SeaMeet 云工作区。它们是独立的——切换一个不会切换另一个。
