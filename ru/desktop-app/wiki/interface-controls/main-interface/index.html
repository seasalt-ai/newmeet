Главный интерфейс — полный обзор UI SeaMeet

Глава 13: Главный интерфейс — полный обзор UI SeaMeet

К этому моменту вы использовали SeaMeet для записи аудио и видео, организовали свою библиотеку и воспроизводили записи. Вы взаимодействовали с различными частями интерфейса, но у вас может не быть полной картины того, как все части сочетаются вместе. Эта глава предоставляет всесторонний обзор главного интерфейса SeaMeet — каждой кнопки, панели, индикатора и элемента управления — чтобы вы могли уверенно навигировать по приложению и находить функции, которые могли не обнаружить.

Думайте об этой главе как о гид-туре по новому дому. Мы пройдёмся по каждой комнате, осмотрим возможности и объясним, что делает каждый элемент. К концу вы будете точно знать, где найти каждую функцию, и понимать, как интерфейс адаптируется к различным ситуациям.

Макет окна: общая картина

Когда вы открываете SeaMeet, вы видите одно окно с последовательным макетом. Этот макет остаётся стабильным, независимо от того, записываете ли вы, воспроизводите или просто просматриваете свою библиотеку. Понимание этого макета — основа эффективного использования SeaMeet.

Три основные зоны

Окно SeaMeet делится на три основные зоны:

┌─────────────────────────────────────────────────────────────────────┐
│  1. ВЕРХНЯЯ ПАНЕЛЬ НАВИГАЦИИ                                        │
│  [Лого] SeaMeet Screen & Audio Recorder       [⚙️] [⏪] [🔴]        │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  2. БОКОВАЯ ПАНЕЛЬ (Список записей)  3. ОБЛАСТЬ ОСНОВНОГО КОНТЕНТА │
│  ┌─────────────────────┐            ┌───────────────────────────┐  │
│  │ 🔍 Поиск...         │            │                           │  │
│  ├─────────────────────┤            │   Плеер / Управление      │  │
│  │ 🎤 Запись 1         │            │   записью / Настройки     │  │
│  │ 🎥 Запись 2         │            │                           │  │
│  │ 🎤 Запись 3         │            │   (Эта область меняется   │  │
│  │                     │            │    в зависимости от того, │  │
│  │ [Карточки записей   │            │    что вы делаете)        │  │
│  │  прокручиваются]    │            │                           │  │
│  └─────────────────────┘            └───────────────────────────┘  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘

Зона 1: Верхняя панель навигации

  • Всегда видима
  • Содержит глобальные элементы управления
  • Быстрый доступ к ключевым функциям

Зона 2: Боковая панель (Список записей)

  • Всегда видима (в большинстве представлений)
  • Показывает ваши записи
  • Прокручиваемый список карточек записей

Зона 3: Область основного контента

  • Меняется в зависимости от контекста
  • Показывает плеер при воспроизведении записей
  • Показывает элементы управления записью при подготовке к записи
  • Показывает настройки при настройке опций

Зона 1: Верхняя панель навигации

Верхняя панель навигации предоставляет навигацию и элементы управления учётной записью. Она остаётся тонкой и сфокусированной — элементы управления записью и Flashback переместились в Capture Hub в области основного контента (см. Состояние 1 ниже).

Макет верхней панели

┌─────────────────────────────────────────────────────────────────────┐
│ [☰ Нав]  SeaMeet Screen & Audio Recorder              [👤 Учётка] │
│   │                                                        │        │
│  Переключатель навигации                  Меню профиля пользователя │
└─────────────────────────────────────────────────────────────────────┘

Переключатель навигации (☰)

Что делает: Сворачивает или разворачивает левую боковую панель (список записей).

Когда использовать:

  • Сверните, чтобы дать Capture Hub больше горизонтального пространства
  • Разверните для просмотра библиотеки записей, когда не записываете

Меню учётной записи / пользователя (👤)

Что делает: Открывает меню учётной записи пользователя, где вы можете:

  • Войти или выйти
  • Открыть Настройки (аудио, видео, Flashback, хранилище, язык, сочетания)
  • Открыть справочник сочетаний клавиш
  • Получить доступ к Справке и Поддержке

Как использовать:

  1. Нажмите на свою фотографию профиля или значок пользователя
  2. Выберите нужный вариант из выпадающего списка

Кнопка записи (🔴)

Значок: Красный круг (🔴) когда готов, Квадрат (⏹️) когда идёт запись Метка: "RECORD" или просто значок Цвет: Ярко-красный (указывает на действие записи)

Что делает: Запускает или останавливает запись

Состояния:

Готов к записи:

[🔴 RECORD]
Значок красного круга
Нажмите, чтобы начать запись

Запись активна:

[⏹️ STOP]
Значок квадрата
Таймер, показывающий прошедшее время
Нажмите, чтобы остановить запись

Как использовать:

Чтобы начать запись:

  1. Сначала настройте параметры записи
  2. Нажмите красную кнопку записи
  3. Запись начинается немедленно
  4. Кнопка меняется на Стоп
  5. Таймер начинает считать

Чтобы остановить запись:

  1. Нажмите кнопку Стоп (квадрат)
  2. Запись останавливается
  3. Файл сохраняется
  4. Запись появляется в боковой панели
  5. Кнопка возвращается в состояние записи

Что происходит при нажатии записи:

  1. Начинается захват аудио/видео
  2. Появляется таймер, показывающий прошедшее время
  3. Кнопка меняется с 🔴 на ⏹️
  4. Визуальный индикатор показывает статус записи
  5. Файл записывается в хранилище

Что происходит при нажатии Стоп:

  1. Запись останавливается
  2. Файл финализируется и сохраняется
  3. Запись появляется в списке боковой панели
  4. Кнопка возвращается в состояние 🔴
  5. Таймер исчезает или сбрасывается

Важные замечания:

  • Запись начинается немедленно — будьте готовы!
  • Никакого обратного отсчёта или предупреждения
  • Убедитесь, что ваши настройки правильные перед нажатием
  • Flashback (если включён) включает буферизованное прошлое

Системный трей

SeaMeet устанавливает значок системного трея (область уведомлений Windows, строка меню macOS) при первом запуске и поддерживает его живым на протяжении всей сессии приложения. Трей — это всегда доступная поверхность управления — даже когда вы закрыли главное окно, SeaMeet всё ещё работает, готов к захвату и доступен в один клик по значку.

Почему трей остаётся живым

Закрытие главного окна не завершает работу SeaMeet. Вместо этого окно скрывается, а значок трея остаётся на месте. Это сделано намеренно:

  • Auto-Detect всё ещё может разбудить приложение, когда запускается приложение совещания
  • Flashback может продолжать заряжать свой прокручиваемый буфер (если активирован)
  • Глобальные сочетания клавиш (Начать запись, Показать лаунчер, Показать Floater) всё ещё работают
  • Быстрая запись — на расстоянии одного клика по трею

В первый раз, когда вы закрываете окно, SeaMeet отправляет однократную подсказку «свёрнут в трей», чтобы вы понимали, что приложение на самом деле не вышло. Чтобы полностью выйти, используйте Exit SeaMeet из меню трея (см. ниже) или команду выхода из приложения вашей ОС.

Значок трея

Значок по умолчанию (бездействие):

  • Windows: маленький логотип SeaMeet .ico в области уведомлений
  • macOS: шаблонное изображение 22×22 в строке меню, которое адаптируется к светлому/тёмному режиму

Значок записи (в процессе):

  • Переключается на вариант с красным оттенком, чтобы вы могли с первого взгляда увидеть, что SeaMeet захватывает
  • На macOS строка меню также получает суффикс ●; если приостановлено, показывает ⏸
  • Подсказка меняется с "SeaMeet" на "SeaMeet — Recording in progress" (или "Paused")

Поведение клика:

  • Левый клик по значку — переключает главное окно (показать если скрыто, скрыть если видимо)
  • Правый клик по значку (Windows) / одиночный клик (macOS) — открывает контекстное меню

Меню трея (состояние бездействия)

Когда вы не записываете, меню выглядит примерно так:

┌─────────────────────────────────────────┐
│ Workspace: Acme Sales      (отключено)  │   ← только в Lite / облачных сборках
├─────────────────────────────────────────┤
│ Быстрая запись           (отключено)    │
│   🎤  Запись аудио                      │
│   🖥️  Запись на весь экран              │
│   ◰  Запись области                     │
│   📷  Сделать снимок экрана  (Ctrl+Shift+S)│
│   📁  Открыть папку записей             │
├─────────────────────────────────────────┤
│ 🚀 Показать лаунчер     (Ctrl+Shift+L)  │
│ 🪟 Показать плав. окно  (Ctrl+Shift+F)  │
├─────────────────────────────────────────┤
│ 🗔 Показать главное окно                │
├─────────────────────────────────────────┤
│ ⏻  Выйти из SeaMeet                     │
└─────────────────────────────────────────┘

Что делает каждый пункт:

  • Workspace: <name> — Заголовок, показывающий, в какое облачное рабочее пространство попадёт запись, начатая из трея. Появляется только в сборках Lite или с поддержкой облака, где вы вошли и выбрали рабочее пространство. В некоблачных сборках строка полностью скрыта, чтобы форма меню оставалась неизменной.
  • Запись аудио — Запускает запись только аудио немедленно. Видеоисточники не запрашиваются.
  • Запись на весь экран — Запускает запись вашего основного дисплея плюс аудио.
  • Запись области — Открывает полноэкранное наложение области, чтобы вы могли перетащить-выбрать область, затем запускает запись этой области.
  • Сделать снимок экрана — Открывает селектор области для однократного снимка экрана. Сочетание показывается, если вы привязали его в Настройки → Клавиатура.
  • Открыть папку записей — Открывает файловый браузер ОС в вашем текущем каталоге сохранения.
  • Показать лаунчер — Переключает панель SeaMeet Launcher (см. главу 14). Сочетание показывается, когда привязано.
  • Показать плав. окно — Показывает/скрывает виджет Floater. Сочетание показывается, когда привязано.
  • Показать главное окно — Выводит главное окно вперёд (то же, что левый клик по значку, когда скрыт).
  • Выйти из SeaMeet — Единственный пункт меню, который действительно выходит. Он устанавливает внутренний флаг «выхожу» и просит Electron завершиться; всё остальное просто показывает/скрывает поверхности.

Меню трея (во время записи)

Когда идёт запись, меню перестраивается, чтобы дать вам прямые элементы управления транспортом:

┌─────────────────────────────────────────┐
│ ● Идёт запись              (отключено)  │
├─────────────────────────────────────────┤
│ ⏹  Остановить запись     (Ctrl+Shift+R) │
│ ⏸  Приостановить запись                 │
│ ⚑  Отметить событие                     │
├─────────────────────────────────────────┤
│ 🗔 Показать главное окно                │
├─────────────────────────────────────────┤
│ ⏻  Выйти из SeaMeet                     │
└─────────────────────────────────────────┘

Примечания к меню записи:

  • Строка заголовка — это чисто метка статуса (она намеренно отключена).
  • Остановить запись завершает захват и сохраняет файл точно так же, как нажатие кнопки Стоп в главном окне.
  • Пауза/Возобновить показывается только когда кодек/источник поддерживает это. Записи только видео скрывают пункт Пауза.
  • Отметить событие добавляет метку времени в запись, полезно для перехода к ключевому моменту во время воспроизведения.
  • Когда приостановлено, меню заменяет Возобновить запись на месте Паузы, а заголовок macOS переключается на ⏸.

Локализованные метки

Меню трея учитывает 15 поддерживаемых локалей (английский, испанский, французский, немецкий, японский, корейский, хинди, польский, португальский, русский, тайский, вьетнамский, датский, упрощённый китайский, традиционный китайский). Языки вне этого набора возвращаются к английскому, чтобы меню всегда отображалось правильно.

Поле поиска

Расположение: Верх боковой панели Внешний вид: Текстовое поле со значком лупы (🔍) Текст-заполнитель: "Поиск записей..." или подобный

Что делает: Фильтрует список записей в реальном времени по мере ввода

Как использовать:

  1. Нажмите в поле поиска
  2. Начните вводить
  3. Список фильтруется автоматически
  4. Показывает только записи, соответствующие вашему поиску
  5. Очистите поиск, чтобы снова увидеть все записи

Что вы можете искать:

  • Имена записей
  • Метки источников ("Zoom", "Teams")
  • Даты (если введены в формате, доступном для поиска)
  • Частичные совпадения работают

Примеры поиска:

  • Поиск "Zoom" → Показывает все записи Zoom
  • Поиск "budget" → Показывает записи со словом "budget" в имени
  • Поиск "March" → Показывает мартовские записи
  • Поиск "client" → Показывает записи, связанные с клиентами

Очистка поиска:

  • Нажмите кнопку X (если присутствует)
  • Удалите весь текст
  • Нажмите клавишу Escape

Карточки записей

Каждая запись в вашей библиотеке отображается как карточка записи — компактная сводка ключевой информации о записи.

Два режима просмотра:

  1. Компактное представление (по умолчанию) - Минимум информации, эффективный просмотр
  2. Расширенное представление - Подробная информация, предпросмотр формы волны

Компактное представление

┌──────────────────────────────────────────────────────────┐
│ 🎤 Обзор бюджета Q3 - Совещание команды                  │
│ 47:32 • Сегодня, 14:30 • Zoom • Аудио                    │
└──────────────────────────────────────────────────────────┘

Элементы:

  • Значок (🎤) - Указывает тип (аудио/видео)
  • Имя - Заголовок записи
  • Длительность - Сколько (47:32)
  • Временная метка - Когда записано (Сегодня, 14:30)
  • Источник - Откуда (Zoom)
  • Тип - Аудио/Видео/Flashback

Левая панель — Начать запись

Левая панель содержит все элементы управления для начала новой записи:

Боковые элементы управления (верх карточки):

  • Переключатель Flashback (слева) — Нажмите, чтобы переключить режим Flashback: OFF → Аудио → Экран → OFF. Показывает значок молнии ⚡, когда активирован (буфер заряжается или готов). См. главу 7 для полных деталей.
  • Большой красный круг микрофона (центр) — Нажмите, чтобы открыть модальное окно настроек видео и выбрать режим записи (только аудио, полный экран, окно, область).
  • Переключатель Auto-Detect (справа) — Включает автоматическую запись при обнаружении приложения совещания.

Область контекста (середина карточки):

  • Когда Flashback OFF: показывает краткое описание того, как начать.
  • Когда Flashback активируется (заряжается): показывает индикатор прогресса, пока буфер заполняется.
  • Когда Flashback готов: показывает значок ⚡ и подтверждение "Flashback armed".

Кнопка CTA (низ карточки):

  • Метка и действие адаптируются к состоянию Flashback:
    • Flashback OFF → "Start Recording" (открывает настройки видео)
    • Flashback активируется → "Buffering…" (отключено во время заполнения)
    • Flashback готов → "Record with Flashback" (захватывает буфер и начинает запись)

Быстрые сочетания запуска (нижняя полоса):

  • Open Launcher — Открывает панель SeaMeet Launcher с показанным сочетанием
  • Open Floater — Показывает/скрывает виджет Floater с показанным сочетанием

Правая панель — Сделать снимок экрана

Правая панель обрабатывает снимки экрана независимо от записей:

  • Кнопка значка камеры — Большая героическая кнопка; нажмите, чтобы сделать снимок экрана с использованием текущего выбранного режима.
  • Full Screen / Area Capture — Радиокнопки для выбора между захватом всего экрана или рисованием области.
  • Флажок Keep SeaMeet window visible — Когда не отмечен (по умолчанию), SeaMeet сворачивается перед захватом, чтобы не появляться на снимке экрана. Когда отмечен, окно остаётся видимым и будет появляться в захвате.
  • Кнопка Take Screenshot — Запускает захват (то же, что нажатие значка камеры).

Назначение:

  • Универсальный центр для всего, что вам нужно перед началом захвата
  • Состояние Flashback видимо и управляемо без открытия Настроек
  • Снимок экрана и запись чисто разделены на две карточки

Визуальные индикаторы и значки состояния

По всему SeaMeet различные значки и цвета обеспечивают визуальную обратную связь о состоянии приложения.

Индикаторы статуса записи

Не записывает:

  • Кнопка записи показывает 🔴 (красный круг)
  • Таймер не виден
  • Обычный заголовок окна

Запись активна:

  • Кнопка записи показывает ⏹️ (квадрат)
  • Таймер, показывающий прошедшее время
  • Может иметь красную границу или индикатор "ЗАПИСЬ"
  • Заголовок окна может измениться, чтобы показать "[Запись]"

Пауза (если поддерживается):

  • Кнопка паузы выделена
  • Таймер заморожен
  • Виден индикатор "ПАУЗА"

Индикаторы статуса Flashback

OFF:

  • Серый цвет
  • "OFF" или нет индикатора
  • Не использует память

ЗАПОЛНЕНИЕ:

  • Янтарный/жёлтый цвет
  • Анимация или пульсация
  • Может показывать процент (например, "ЗАПОЛНЕНИЕ 60%")
  • Подождите зелёного, прежде чем полагаться на него

ГОТОВ:

  • Зелёный цвет
  • Стабильный индикатор
  • Показывает длительность (например, "30С")
  • Готов к захвату прошлых моментов

Индикаторы уровня аудио

Во время записи:

  • Около 60-80% идеально

Аудио: ███░░░░░░░░░░ 20%
  • Едва есть полосы
  • Увеличьте усиление микрофона
  • Подойдите ближе к микрофону

Изменение размера и регулировка макета

Интерфейс SeaMeet адаптируется к разным размерам окна.

Стандартный размер окна

Оптимальный размер:

  • Ширина: 1000-1400 пикселей
  • Высота: 700-900 пикселей
  • Все элементы видимы и доступны

Узкое окно (Боковая панель свёрнута)

Когда окно узкое:

  • Боковая панель может свернуться или стать выпадающим списком
  • Основной контент занимает больше места
  • Некоторые элементы управления могут перейти в меню

Широкое окно (Расширенное представление)

Когда окно широкое:

  • Боковая панель может расшириться
  • Видно больше карточек записей
  • Область плеера больше для видео

Полноэкранный режим

Доступно для:

  • Воспроизведение видео (клавиша F или кнопка)
  • Некоторые панели настроек
  • Режим презентации

Как переключить:

  • Войти: Клавиша F или двойной щелчок по видео
  • Выйти: Клавиша ESC или F снова

Настройки темы

  • Тёмный текст
  • Стандарт для дневного использования

Тёмный режим:

  • Тёмно-серый/чёрный фон
  • Светлый текст
  • Легче для глаз при слабом освещении
  • Может экономить заряд батареи на OLED-экранах

Как изменить:

  1. Настройки → Язык и оформление
  2. Выберите "Светлый" или "Тёмный"
  3. Или "Авто", чтобы следовать системной настройке

  2. Курсор меняется на курсор изменения размера (↔️)
  3. Перетащите влево или вправо
  4. Отпустите, чтобы установить новую ширину

Советы по навигации по интерфейсу

Быстрое перемещение

1. Используйте сочетания клавиш

  • Быстрее, чем мышь для распространённых действий
  • Пробел для воспроизведения/паузы
  • Стрелки для навигации
  • Полный список см. в главе 15

2. Щёлкните правой кнопкой мыши для контекстных меню

  • У записей есть меню правой кнопки мыши
  • Быстрый доступ к распространённым действиям
  • Разные опции в разных областях

3. Ищите подсказки при наведении

  • Наведите курсор на кнопки, чтобы увидеть, что они делают
  • Особенно полезно для кнопок только со значками
  • Показывает сочетания клавиш, если доступны

4. Используйте поле поиска

  • Самый быстрый способ найти записи
  • Работает в реальном времени
  • Ищет имена и источники

Понимание визуальной обратной связи

Цвета что-то означают:

  • Красный: Запись, ошибка, стоп
  • Зелёный: Готов, успех, активен
  • Жёлтый/Янтарный: Предупреждение, заполнение, осторожность
  • Серый: Отключено, неактивен, выключен
  • Синий: Информация, ссылки, выбор

Анимация что-то означает:

  • Пульсация: Загрузка, заполнение, в процессе
  • Статика: Готов, завершён, стабилен
  • Мигание: Срочно, требуется внимание

Lite vs Full режим

SeaMeet поставляется с двумя режимами интерфейса. Они используют один и тот же движок записи, одни и те же файлы на диске и один и тот же значок трея — но они показывают совершенно разные объёмы UI.

Выбор режима

При чистом первом запуске SeaMeet показывает селектор режима, спрашивая, какой опыт вы хотите. Существующие пользователи v2.x, которые обновляются, молча мигрируют в режим Full (так что ничего видимо не меняется), но каждый может переключиться позже из Настроек.

Выбранный режим сохраняется как appMode: 'full' | 'lite' в ваших настройках UI. Переключение режимов во время идущей записи откладывается до завершения записи, чтобы вы никогда не теряли захват; модальное окно Настроек закрывается немедленно, чтобы спиннер «Сохранение…» был виден во время ожидания.

Full режим (по умолчанию)

Это глава, которую вы читали до сих пор — боковая панель + Capture Hub + область основного контента, все состояния (Запись, Воспроизведение, Настройки), рассмотренные в разделах выше. Full режим включает:

  • Capture Hub с элементами управления Flashback и снимками экрана
  • Полную боковую панель с карточками записей, поиском, сортировкой и фильтром
  • Заметки и Wiki (см. главы 16–17)
  • Медиатеку (глава 10)
  • Все категории настроек (глава 18+)
  • Локальные рабочие пространства (см. «Рабочие пространства» ниже)

Используйте Full режим, когда SeaMeet — ваша основная поверхность записи и вы хотите заметки, wiki, агента и управление библиотекой в одном окне.

Lite режим

Lite режим — это гораздо меньшая поверхность, сосредоточенная на системном трее и едином облачном списке совещаний. Здесь нет боковой панели, нет представления заметок, нет wiki, нет Capture Hub — записи запускаются из трея (или автоопределения, или горячей клавиши), а завершённые записи появляются как карточки совещаний после того, как конвейер сводок после совещания загрузит их в ваше рабочее пространство SeaMeet.

Заголовок рабочего пространства в Lite:

Самая верхняя часть окна Lite — это переключатель рабочих пространств (кнопка, показывающая активное имя рабочего пространства с аватаром и шевроном). Нажатие на неё открывает выпадающий список всех рабочих пространств, к которым у вас есть доступ в облаке SeaMeet. Выбор другого рабочего пространства:

  1. Сохраняет новый ID рабочего пространства локально
  2. Обновляет список совещаний
  3. Передаёт новое имя рабочего пространства в меню трея, чтобы запись, начатая из трея, тоже попадала в правильное место
  4. Сбрасывает пагинацию на страницу 1

Выход из учётной записи очищает заголовок рабочего пространства трея (traySetWorkspaceDisplay(null, null)), чтобы меню никогда не врало о рабочем пространстве, к которому у вас больше нет доступа.

Запись в Lite:

  • Нажмите значок трея и выберите Запись аудио / на весь экран / области — или используйте глобальную горячую клавишу
  • Представление записи Lite заменяет главное окно живой формой волны, таймером и единственным элементом управления Стоп
  • Когда вы останавливаете, файл сохраняется локально и загружается в ваше рабочее пространство SeaMeet для транскрипции и сводки
  • Когда облачный конвейер завершится, карточка совещания появится в списке

Используйте Lite режим, когда SeaMeet — это фоновый записывающий, который питает облако SeaMeet — вы хотите, чтобы трей делал работу, а чистый список совещаний — для обзора.

Переключение между режимами

Откройте Настройки (в любом режиме), найдите действие «Switch to Full / Lite mode» и подтвердите. SeaMeet завершает любую идущую запись, затем перезапускает рендерер в другой режим. Ваши файлы, рабочие пространства, настройки и значок трея переживают переключение.

Рабочие пространства

У SeaMeet есть две различные концепции рабочих пространств, которые делят имя, но живут в разных местах. Понимание того, что есть что, избегает путаницы.

Локальные рабочие пространства (Full режим)

В режиме Full рабочее пространство — это хранилище в стиле Obsidian — папка на диске, которая содержит ваши заметки, ваш сгенерированный wiki и (по умолчанию) ваши записи. WorkspaceManager в главном процессе владеет:

  • Реестром рабочих пространств ({ id, name, path, isDefault? }[]), сохранённым в вашем файле настроек
  • Активным ID рабочего пространства (только одно активно одновременно)
  • Файловым наблюдателем chokidar на пути активного рабочего пространства, с автоматически включённым опросом для внешних томов и сетевых монтирований (например, macOS /Volumes/, ~/Library/CloudStorage/GoogleDrive-<email>/… для Google Drive), где FSEvents не сработают надёжно
  • Состоянием по рабочему пространству (последняя открытая заметка, недавние файлы и т. д.) под userData/workspace-state/<id>.json

При первом запуске, если рабочих пространств не зарегистрировано, SeaMeet автоматически создаёт одно Default рабочее пространство, указывающее на ваш каталог сохранения. Имя «Default» локализовано на все 23 языка.

Переключатель рабочих пространств (заголовок боковой панели):

И представление Заметок (глава 16), и представление Wiki (глава 17) отображают <WorkspaceSwitcher> в верхней части дерева файлов:

┌──────────────────────────────────┐
│ [🅰] Acme Vault            ⌄    │   ← активное рабочее пространство
├──────────────────────────────────┤
│ Рабочие пространства             │
│  ✓ Acme Vault     ~/Notes/Acme  │
│    Personal      ~/Notes/Personal│
│    Side Project  ~/Code/Side    │
├──────────────────────────────────┤
│ + Добавить рабочее пространство… │
└──────────────────────────────────┘
  • Нажмите активную строку, чтобы открыть выпадающий список
  • Нажмите любое другое рабочее пространство, чтобы переключиться на него — файловый наблюдатель сворачивается, монтируется путь нового рабочего пространства, обновляются Заметки и Wiki, и восстанавливается состояние по рабочему пространству
  • Добавить рабочее пространство… открывает нативный селектор папок, чтобы вы могли зарегистрировать любой каталог как хранилище (проверяется уникальность — регистрация одного и того же пути дважды отклоняется)
  • Удалить (×) на строке удаляет только запись SeaMeet; файлы на диске не трогаются. Вы не можете удалить последнее рабочее пространство.
  • Каждая строка может показывать значок облака (Dropbox, iCloud, OneDrive, Google Drive) и значок git-удалёнки, когда обнаружение синхронизации находит их

Переключение рабочих пространств сериализовано: если переключение уже идёт, следующее ждёт его завершения, поэтому NotesManager / WikiManager никогда не указывают на устаревший путь.

Облачные рабочие пространства (Lite режим)

В режиме Lite (и в облачных сборках Full) рабочее пространство означает другое: командное рабочее пространство в облаке SeaMeet. Компонент <WorkspacePicker> получает ваши доступные рабочие пространства через API SeaMeet и сохраняет выбранное для маршрутизации загрузок.

Облачные рабочие пространства управляют:

  • В какое рабочее пространство загружается новая запись
  • Какие совещания рабочего пространства появляются в списке совещаний Lite
  • Строкой заголовка рабочего пространства в меню трея (чтобы вы могли с первого взгляда увидеть, куда попадёт следующая запись, начатая из трея)

Облачный селектор отфильтровывает рабочие пространства, где ваш my_status равен INACTIVE. При первом входе, если ваше ранее выбранное рабочее пространство нет в возвращённом списке (вы потеряли членство, дрейф схемы и т. д.), селектор автоматически выбирает первое доступное рабочее пространство и сохраняет его — поэтому меню никогда не может застрять на недоступном ID.

Оба одновременно

В облачной сборке Full вы можете иметь оба вида рабочих пространств, выбранных одновременно: локальное хранилище, содержащее ваши заметки, и облачное рабочее пространство SeaMeet, которое получает ваши загрузки. Они независимы — переключение одного не переключает другое.
