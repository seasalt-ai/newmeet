パフォーマンス最適化

第27章：パフォーマンス最適化

はじめに

音声と映像の録画は、コンピューターにとって負荷の高い作業です。処理能力、メモリ、ストレージ速度、システムリソースが必要です。すべてがうまく機能すると、スムーズで高品質な録画ができます。リソースが足りないと、カクつき、フレームドロップ、フラストレーションが生じます。この章は、SeaMeet とシステムを最高の録画パフォーマンスに最適化するためのガイドです。

ハイエンドなワークステーションでも普通のノートパソコンでも、これらの最適化技術はハードウェアをアップグレードせずに最良の結果を得るのに役立ちます。

章の目標

この章を読むと、以下のことができるようになります：

  • ハードウェアに合わせて SeaMeet の設定を最適化する
  • 品質とパフォーマンスのバランスを効果的に取る
  • パフォーマンスのボトルネックを特定して解消する
  • 録画のためにオペレーティングシステムを最適化する
  • ハードウェアアクセラレーションを効果的に使用する
  • 録画中にシステムリソースを管理する
  • パフォーマンス関連の問題をトラブルシューティングする

録画パフォーマンスを理解する

録画が負荷の高い理由は？

録画にはコンピューターが以下を行う必要があります：

  1. 映像フレームのキャプチャ（毎秒30〜60回）
  2. 音声サンプルのキャプチャ（毎秒44,100〜48,000回）
  3. リアルタイムでの映像圧縮（H.264/H.265にエンコード）
  4. 継続的なディスクへの書き込み（持続的な書き込み速度）
  5. バッファと処理のためのメモリ管理

録画種類別のリソース使用量：

録画種類CPURAMディスクGPU
音声のみ低低低なし
720p 30fps中中中低
1080p 60fps高高高中
4K 60fps非常に高非常に高非常に高高

ボトルネックの原則： 録画パフォーマンスは最も弱いコンポーネントによって制限されます。ボトルネックを特定して対処しましょう。

パート1：SeaMeet 設定の最適化

パフォーマンス三角形

3つの要素のバランスを取る：

        品質
         /\
        /  \
       /    \
      /      \
     /        \
    /__________\
パフォーマンス  ファイルサイズ

どれか2つは最適化できますが、3つすべてはできません：

  • 高品質 + 良いパフォーマンス = 大きなファイル
  • 高品質 + 小さなファイル = 低いパフォーマンス
  • 良いパフォーマンス + 小さなファイル = 低い品質

最適化レベル1：音声のみ（最高パフォーマンス）

使用するとき：

  • 非常に古いコンピューター
  • 他の重いアプリを実行しているとき
  • バッテリー駆動デバイス（省電力）
  • 映像が不要なとき

設定：

録画モード：音声のみ
音声フォーマット：MP3（128〜192 kbps）
サンプルレート：44.1 kHz
マイク：デフォルトデバイス
自動ゲイン：オン

リソース使用量：

  • CPU：2〜5%
  • RAM：50〜100 MB
  • ディスク：1 MB/分
  • バッテリー：最小の影響

結果： 過去10年間に製造されたほぼすべてのコンピューターで録画できます。

最適化レベル2：軽量映像（バランス）

使用するとき：

  • 標準的なビジネス録画
  • ノートパソコンと中級コンピューター
  • ストレージ容量が重要なとき
  • 管理しやすいリソースで良い品質が必要なとき

設定：

録画モード：ウィンドウまたはリージョン
解像度：720p（1280×720）
フレームレート：30 fps
ハードウェアアクセラレーション：オン（利用可能な場合）
品質プリセット：バランス
映像フォーマット：MP4 (H.264)
音声：MP3 128 kbps

リソース使用量：

  • CPU：10〜20%（ハードウェアアクセラレーション：5〜10%）
  • RAM：200〜300 MB
  • ディスク：75〜150 MB/分
  • バッテリー：中程度の影響

結果： 2015年以降のほとんどのコンピューターで正常に動作します。

最適化レベル3：高品質（高負荷）

使用するとき：

  • プロフェッショナルな制作
  • 現代のゲーミングコンピューター
  • 品質が最重要のとき
  • デスクトップワークステーション

設定：

録画モード：フルスクリーン
解像度：1080p（1920×1080）
フレームレート：60 fps
ハードウェアアクセラレーション：オン（必須）
品質プリセット：高品質
映像フォーマット：MP4（H.264 高ビットレート）
音声：WAV または高ビットレートMP3

リソース使用量：

  • CPU：20〜40%（ハードウェアアクセラレーション：10〜20%）
  • RAM：400〜600 MB
  • ディスク：300〜500 MB/分
  • バッテリー：高い影響

結果： スムーズな動作のために現代のハードウェア（2018年以降）が必要です。

最適化レベル4：最高品質（非常に高負荷）

使用するとき：

  • プロフェッショナルスタジオ
  • コンテンツ制作
  • 最高のものだけが必要なとき
  • ハイエンドワークステーション

設定：

録画モード：フルスクリーン
解像度：1440p または4K
フレームレート：60 fps
ハードウェアアクセラレーション：オン（必要）
品質プリセット：最高品質
映像フォーマット：MP4（H.265、効率のため）
音声：WAV（非圧縮）

リソース使用量：

  • CPU：40〜70%（ハードウェアアクセラレーション：20〜40%）
  • RAM：800 MB〜2 GB
  • ディスク：600 MB〜1 GB/分
  • バッテリー：非常に高い影響（デスクトップ推奨）

結果： ハイエンドハードウェアが必要です。専用GPUを搭載したデスクトップ推奨。

パート2：ハードウェアアクセラレーションの詳細

ハードウェアアクセラレーションとは？

CPU（プロセッサー）を使用して映像をエンコードする代わりに、ハードウェアアクセラレーションはGPU（グラフィックカード）または専用エンコードハードウェアを使用します。

ハードウェアアクセラレーションなし：

CPU：映像エンコード + アプリケーション実行 + オペレーティングシステム
     ↓
CPUの使用率が高く、速度低下の可能性

ハードウェアアクセラレーションあり：

CPU：アプリケーション実行 + オペレーティングシステム
GPU：映像エンコード
     ↓
バランスの取れた負荷、より良いパフォーマンス

ハードウェアアクセラレーションの種類

NVIDIA NVENC：

  • 利用可能なもの：GTX 600シリーズ以降
  • 品質：優秀
  • パフォーマンス：非常に効率的
  • 推奨：利用可能であれば有効にする

AMD VCE（ビデオコーディングエンジン）：

  • 利用可能なもの：Radeon HD 7000シリーズ以降
  • 品質：良好
  • パフォーマンス：効率的
  • 推奨：利用可能であれば有効にする

Intel Quick Sync：

  • 利用可能なもの：第2世代Coreプロセッサー（2011年以降）以降
  • 品質：良好
  • パフォーマンス：効率的
  • 推奨：Intelグラフィックスを搭載したノートパソコンとデスクトップで有効にする

Apple VideoToolbox（macOS）：

  • 利用可能なもの：すべての現代のMac
  • 品質：優秀
  • パフォーマンス：macOS向けに最適化
  • 推奨：Macでは常に有効にする

有効化と確認の方法

有効化：

設定 → 映像 → 「ハードウェアアクセラレーションを使用」にチェック

動作確認：

  1. ハードウェアアクセラレーションを有効にする
  2. 録画を開始
  3. タスクマネージャー（Windows）またはアクティビティモニター（macOS）を開く
  4. 録画中のCPU使用率を確認
  5. ハードウェアアクセラレーションあり：CPUは10〜20%であるべき
  6. ハードウェアアクセラレーションなし：CPUは30〜50%になる可能性

利用できない場合の対処：

  • グラフィックドライバーを更新
  • GPUがエンコードをサポートしているか確認
  • 重い録画をする場合はアップグレードを検討

ハードウェアアクセラレーションを使用すべきでない場合

ソフトウェア（CPU）エンコードの方が良い稀なケース：

  1. 品質上の懸念：

    • 一部のハードウェアエンコーダーはわずかに低い品質を生成する
    • 両方の方法でテストして比較する
    • アーカイブ目的では、CPUエンコードの方が良いかもしれない

  2. 互換性の問題：

    • 非常に古いハードウェアアクセラレーションにはバグがある可能性
    • アーティファクトが見える場合は無効にしてみる

  3. マルチパスエンコード：

    • 一部の高度なエンコードはCPUでのみ動作する
    • SeaMeet は通常、リアルタイムのシングルパスを使用

推奨： デフォルトでハードウェアアクセラレーションを有効にする。特定の品質の問題が発生した場合のみ無効にする。

パート3：システムの最適化

Windows の最適化

1. 電源設定：

コントロールパネル → 電源オプション
→ 「高パフォーマンス」または「バランス」を選択
→ 録画中は「省電力」を使用しない

2. ゲームモード（Windows 10/11）：

設定 → ゲーム → ゲームモード
→ オンにする
→ 録画/ゲームアプリケーションを優先

3. 視覚効果を無効にする：

システム → 詳細システム設定 → パフォーマンス設定
→ 「パフォーマンスを優先する」を選択
→ またはアニメーションを手動で無効にする

4. バックグラウンドアプリ：

設定 → プライバシー → バックグラウンドアプリ
→ 不要なアプリをオフにする
→ リソースの競合を減らす

5. スタートアッププログラム：

タスクマネージャー → スタートアップタブ
→ 不要なスタートアッププログラムを無効にする
→ RAMとCPUを解放する

macOS の最適化

1. エネルギー設定：

システム環境設定 → 省エネルギー
→ 録画中はコンピュータースリープを「しない」に設定
→ 「可能な場合はハードディスクをスリープさせる」を無効にする

2. Spotlight インデックスを無効にする：

録画中、Spotlight はカクつきの原因になる可能性
システム環境設定 → Spotlight → プライバシー
→ インデックス作成を防ぐために録画フォルダーを追加

3. 不要なアプリを閉じる：

アクティビティモニターがリソース使用量を表示
→ 高いCPUまたはRAMを使用しているアプリを閉じる
→ 特に多くのタブを開いているブラウザ

4. macOSを更新する：

システム環境設定 → ソフトウェアアップデート
→ 最高のパフォーマンスのためにmacOSを最新の状態に保つ

ストレージの最適化

ストレージ速度の階層：

  1. NVMe SSD（最速）

    • 速度：2000〜7000 MB/s
    • 最適：4K録画、プロフェッショナルな作業

  2. SATA SSD（高速）

    • 速度：400〜600 MB/s
    • 最適：1080p録画、一般的な使用

  3. 外付けSSD（良好）

    • 速度：300〜500 MB/s（USB 3.0）
    • 最適：720p録画、バックアップ

  4. 内蔵HDD（低速）

    • 速度：100〜200 MB/s
    • 最適：音声のみ、アーカイブ

  5. 外付けHDD（最低速）

    • 速度：50〜150 MB/s
    • 最適：バックアップのみ、録画には不向き

必要な書き込み速度：

録画種類最低速度推奨
音声のみ1 MB/s任意のドライブ
720p 30fps10 MB/sSSD
1080p 30fps20 MB/sSSD
1080p 60fps40 MB/s高速SSD
4K 60fps100 MB/sNVMe SSD

最適化のヒント：

  1. SSDに録画する：

    • 内蔵SSDが最適
    • USB 3.0経由の外付けSSDも良い
    • 外付けHDDへの録画は避ける

  2. 可能であればシステムドライブへの録画を避ける：

    • 録画ドライブをOSドライブから分離する
    • ディスクアクセスの競合を防ぐ
    • 例：C: = Windows、D: = 録画

  3. 20%以上の空き容量を維持する：

    • SSDは満杯に近いと速度が低下する
    • HDDは最高のパフォーマンスに容量が必要
    • 録画失敗を防ぐ

パート4：メモリ管理

RAMの使用量を理解する

SeaMeet のメモリコンポーネント：

  1. アプリケーション： 〜100〜150 MB
  2. 映像録画バッファ： 〜100〜300 MB
  3. Flashback バッファ： 〜100〜600 MB（有効な場合）
  4. 音声処理： 〜20〜50 MB
  5. システムオーバーヘッド： 〜50〜100 MB

典型的な合計使用量： 300〜800 MB

RAM の推奨：

システムRAM録画能力推奨
4 GB音声のみ、軽量映像Flashback を無効、低品質
8 GB標準720p/1080pバランス設定
16 GB高品質1080p/1440pすべての機能を有効
32 GB+最高品質、複数機能無制限の能力

メモリ最適化技術

1. メモリを多く使用するアプリを閉じる：

録画前に閉じる：
- Chrome/Firefox（特に多くのタブを開いているとき）
- Photoshop、Premiere、After Effects
- Slack、Discord、Teams（不要な場合）
- Spotify、音楽アプリ
- 不要なバックグラウンドアプリ

2. 不要なときはFlashbackを無効にする：

設定 → Flashback → 無効にする
→ 100〜600 MB のRAMを節約
→ 必要なときに再有効化

3. Flashbackバッファを縮小する：

設定 → Flashback → バッファ時間
→ 120秒から60秒または30秒に縮小
→ 100〜400 MB のRAMを節約

4. 低メモリモードを使用する：

設定 → Flashback → 低メモリモードを有効にする
→ 品質は低下するが機能は維持
→ 大幅なRAM節約

5. 長いセッション前に再起動する：

重要な録画前にコンピューターを再起動
→ メモリリークをクリア
→ 断片化されたRAMを解放
→ フレッシュスタート = より良いパフォーマンス

パート5：CPU最適化

CPU負荷を理解する

録画タスク別のCPU使用量：

タスクCPU使用量（ソフトウェア）CPU使用量（ハードウェアアクセラレーション）
音声エンコード2〜5%2〜5%
720p H.26415〜25%5〜10%
1080p H.26430〜50%10〜20%
4K H.26460〜80%25〜40%
4K H.26570〜90%30〜50%

CPU 閾値： 総CPU使用量が90〜100%に達すると、以下が発生します：

  • フレームドロップ
  • カクつき
  • エンコードエラー
  • システムの無応答

目標： 録画中はCPUを70%以下に保つ。

CPU 負荷を減らす

1. ハードウェアアクセラレーションを有効にする：

CPU 負荷を減らす最善の方法
設定 → 映像 → ハードウェアアクセラレーションを有効にする
→ エンコードをGPUにオフロード
→ CPU使用量を50〜70%削減

2. 解像度を下げる：

720p は1080p より50%少ないCPUを使用
480p は1080p より75%少ないCPUを使用

3. フレームレートを下げる：

30fps は60fps より50%少ないCPUを使用
スムーズな動きが必要な場合のみ60fpsを使用

4. 品質プリセットを変更する：

設定 → 映像 → 品質プリセット
→ 「ファスト」は「高品質」よりCPUを使用しない
→ トレードオフ：ファイルがわずかに大きくなる

5. 映像フォーマットを変更する：

H.264はH.265よりエンコードが簡単
CPUに負担がかかっている場合はH.264を使用

パート6：バッテリー最適化（ノートパソコン）

バッテリー駆動での録画

課題： 録画は電力を多く消費します。バッテリー寿命は大幅に短縮されます。

典型的なバッテリーへの影響：

録画種類バッテリー寿命の短縮
音声のみ10〜15%速く消耗
720p 30fps30〜40%速く消耗
1080p 60fps50〜70%速く消耗
4K 60fps70〜90%速く消耗

実際の例：

  • 通常のノートパソコンのバッテリー：8時間
  • 1080p 60fps録画：3〜4時間
  • 4K 60fps録画：1〜2時間

バッテリー節約戦略

1. 最適な設定を使用する：

解像度：720p（1080pでなく）
フレームレート：30fps（60fpsでなく）
ハードウェアアクセラレーション：オン（CPUより効率的）
Flashback を無効（電力節約）
音声フォーマット：MP3（WAVでなく）

2. 画面の明るさを下げる：

画面は主要な電力消費源
録画中は50〜70%に下げる

3. キーボードバックライトを無効にする：

わずかな節約だが、少しずつが積み重なる

4. 不要なアプリを閉じる：

各アプリが電力を消費する
必要のないものはすべて閉じる

5. 省電力モードを慎重に使用する：

Windows：省電力モード
→ パフォーマンスは低下するがバッテリーを延長
→ 音声または720p録画のみに
→ 高品質映像には使用しない（問題が発生する）

6. 可能であれば電源に接続する：

最善の解決策：AC電源を使用
妥協は不要
最大パフォーマンスが利用可能

パート7：パフォーマンス問題のトラブルシューティング

問題：録画がカクつくかフレームドロップが発生する

症状：

  • 映像再生がぎこちない
  • スキップされたフレームが見える
  • 動きがスムーズでない

診断手順：

  1. CPU 使用率を確認：

    • タスクマネージャー → パフォーマンス → CPU
    • 録画中に90〜100%になる場合 → CPU ボトルネック

  2. ディスク使用率を確認：

    • タスクマネージャー → パフォーマンス → ディスク
    • 100%になる場合 → ストレージボトルネック

  3. 温度を確認：

    • 過熱はサーマルスロットリングを引き起こす
    • HWiNFO または類似ツールで温度を確認
    • CPU が85°Cを超える場合 = サーマルスロットリング

原因別の解決策：

CPU ボトルネック：

  • ハードウェアアクセラレーションを有効にする
  • 解像度を下げる
  • フレームレートを下げる
  • 品質プリセットを「ファスト」に変更
  • 他のアプリケーションを閉じる

ストレージボトルネック：

  • HDDの代わりにSSDに録画
  • 外付けドライブの代わりに内蔵ドライブに録画
  • 映像品質を下げる（小さいファイル = 書き込みが少ない）
  • ドライブに空き容量があることを確認

サーマルスロットリング：

  • ノートパソコン/デスクトップのファンを清掃
  • 冷却パッドを使用（ノートパソコン）
  • 室温を下げる
  • 発熱を減らすために録画品質を下げる

問題：音声のグリッチまたは途切れ

症状：

  • 音声が一時的に途切れる
  • ポッピングまたはクリッキング音
  • 音声と映像の同期ズレ

原因と解決策：

バッファアンダーラン：

原因：CPUが音声を処理できない速度が不十分
解決策：
- CPU負荷の高いアプリを閉じる
- 音声バッファサイズを増やす（利用可能な場合）
- 音声エフェクト/ノイズリダクションを無効にする
- ハードウェアアクセラレーションを使用する

USB の問題：

原因：USBマイクの帯域幅/干渉
解決策：
- 異なるUSBポートを試す
- 音声デバイスにUSB 2.0ポートを使用（3.0でなく）
- USBドライバーを更新
- 他のUSBデバイスを取り外す

ドライバーの問題：

原因：古いまたは破損した音声ドライバー
解決策：
- 音声ドライバーを更新
- 音声サービスを再起動：
  Windows：services.msc → Windows Audio → 再起動

問題：録画中の高レイテンシ

症状：

  • 操作と録画の間に遅延
  • マウスがカーソルに遅れる
  • インターフェースが遅い

解決策：

  1. ハードウェアアクセラレーションを有効にする：

    • エンコードレイテンシを低減

  2. 品質設定を下げる：

    • 処理が少ない = レイテンシが低い

  3. ゲームモードを使用する（Windows）：

    • SeaMeet を優先

  4. Windows Defender リアルタイムスキャンを一時的に無効にする：

    録画中に一時的に：
設定 → 更新とセキュリティ → Windows セキュリティ
→ ウイルスと脅威の防止 → 設定の管理
→ リアルタイム保護をオフにする
→ 録画後にオンに戻す

  5. バックグラウンドアプリを閉じる：

    • 特にクラウド同期（OneDrive、Dropbox）
    • ウイルス対策スキャンを一時停止
    • ブラウザを閉じる

パート8：高度な最適化

マルチモニターの考慮事項

パフォーマンスへの影響： 複数のモニターを録画 = 2倍または3倍のリソース使用量

最適化：

  1. 必要なモニターのみを録画する
  2. 複数のディスプレイを録画する場合は解像度を下げる
  3. 録画中に未使用のモニターを無効にする
  4. すべてのモニターのフルスクリーンではなくウィンドウ/リージョンモードを使用する

ネットワーク録画（高度）

ネットワークドライブへの録画：

メリット：

  • 集中ストレージ
  • 自動バックアップ
  • 複数のコンピューターからアクセス可能

デメリット：

  • ネットワークレイテンシが録画に影響する
  • 安定した高速接続が必要
  • 録画失敗のリスクが高い

要件：

  • ギガビットイーサネット（WiFiでなく）
  • 安定したネットワーク（切断なし）
  • 書き込みパフォーマンスの良いサーバー
  • 720p以下の解像度を推奨

最適化：

  1. まずローカルに録画する
  2. 録画後に自動的にネットワークに同期
  3. Syncthing または Resilio Sync などのソフトウェアを使用

ストリーミングプラットフォーム向けのエンコード

YouTube、Vimeo などにアップロードする場合：

YouTube推奨設定：

解像度：1080p または4K
フレームレート：30 または60 fps
コーデック：H.264
ビットレート：
  - 1080p：8 Mbps
  - 4K：35〜45 Mbps
音声：AAC 128〜384 kbps

プラットフォームに最適化する理由：

  • YouTubeはとにかくすべてを再エンコードする
  • 仕様に合わせることで再エンコードのアーティファクトが減る
  • アップロードと処理が速くなる

YouTube向けの SeaMeet 設定：

1080p、30fps、H.264、〜10 Mbps ビットレート
