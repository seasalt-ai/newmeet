ストレージ設定

第19章：ストレージ設定

はじめに

SeaMeetで作成するすべての録音には保存場所が必要です。移動、削除、または永久保存を決定するまで、その録音がコンピューター上に存在する場所です。ストレージ設定は、このデジタル不動産を管理するためのコントロールパネルです。録音の「物件管理者」として考えてください。録音がどの「地区」（フォルダー）に住み、「家」の大きさ（ファイルサイズの制限）はどれくらいで、大掃除（自動削除）のタイミングはいつかを決めます。

この章の最後には、録音の保存場所を正確に制御する方法、ハードドライブが満杯になるのを防ぐ方法、そして会議、プレゼンテーション、クリエイティブコンテンツの増え続けるライブラリを整理する方法を正確に理解できるようになります。

章の目標

この章を読み終えると、以下のことができるようになります：

  • すべての録音のデフォルト保存場所を変更する
  • ディスクスペースが不足する前にストレージ警告を設定する
  • 古い録音の自動クリーンアップを設定する
  • ファイル命名規則と整理方法を理解する
  • 既存の録音を新しい場所に移動する
  • ストレージ関連の問題をトラブルシューティングする
  • 必要なストレージ容量を計算する

ストレージ設定が重要な理由

話をしましょう。Sarahはプロジェクトマネージャーで、チームの毎日のスタンドアップミーティングをすべて録音するためにSeaMeetを使用しています。3ヶ月間、すべてが完璧に機能していました。録音は自動的に保存され、再生はスムーズで、過去の議論を簡単に参照できました。そしてある日、彼女のコンピューターが遅くなり始めました。プログラムがクラッシュしました。新しいファイルを保存できなくなりました。調査の結果、Cドライブが完全にいっぱいになっていることがわかりました。47GBものSeaMeetの録音が彼女の知らないうちに蓄積されていたのです！

この話は、ストレージ管理が単なる「あれば便利なもの」ではなく、以下の理由から必須であることを示しています：

システムの問題を防ぐ

  • ハードドライブが満杯になると、コンピューター全体が遅くなります
  • WindowsとmacOSが正常に機能するにはフリースペースが必要です
  • ドライブが満杯になるとソフトウェアのアップデートが防がれ、クラッシュが発生する可能性があります

パフォーマンスを維持する

  • SeaMeetは録音中に一時ファイルを作成するためのスペースが必要です
  • ビデオ録音は特に円滑な操作のために大きなフリースペースを必要とします
  • Flashback録音はバッファーのためにRAMとディスクスペースを使用します

整理整頓を保つ

  • 管理しないと、録音が一つの大きな山に積み上がります
  • 特定の録音を見つけることが悪夢になります
  • すべてが散らかっているとバックアップが困難になります

コストを管理する

  • クラウドバックアップは使用されたストレージに基づいてコストがかかります
  • 外付けハードドライブは適切なサイズにする必要があります
  • 使用量を把握することでストレージの購入計画を立てられます

ストレージの基本を理解する

設定に進む前に、ストレージの基本を確認しましょう：

録音はどれだけのスペースを使うか？

音声録音のみ：

  • MP3形式（標準品質）：約1MB/分
  • WAV形式（高品質）：約10MB/分
  • MP3での1時間の会議：約60MB
  • WAVでの1時間の会議：約600MB

ビデオ録音：

  • 1080p 30fps（良品質）：約150〜300MB/分
  • 720p 30fps（標準品質）：約75〜150MB/分
  • 480p 30fps（基本品質）：約25〜50MB/分
  • 1080pの1時間の録音：約9〜18GB
  • 720pの1時間の録音：約4.5〜9GB

Flashback録音（連続バッファー）：

  • 音声バッファー（30秒）：RAMを使用（ディスクは使用しない）
  • ビデオバッファー（可変）：時間と品質に応じて約30〜600MBのRAMを使用

実際の例： 1日1回1080pで1時間のビデオ会議を録音する場合：

  • 日次：約15GB
  • 週次（5回の会議）：約75GB
  • 月次（20回の会議）：約300GB
  • 年次：約3.6TB

これは大きなスペースです！だからこそストレージ管理が重要なのです。

ストレージの場所：どこに保存できるか？

内蔵ハードドライブ（WindowsのCドライブ、MacのMacintosh HD）

  • 長所：速い、常に利用可能、追加のハードウェア不要
  • 短所：スペースが限られている、すぐに満杯になる、満杯になるとシステムパフォーマンスに影響する

外付けハードドライブ（USB接続）

  • 長所：大容量（1〜5TB以上）、システムドライブに影響しない、携帯可能
  • 短所：録音するには接続する必要がある、内蔵ドライブより遅い、誤って切断される可能性がある

ネットワークドライブ（NAS、共有フォルダー）

  • 長所：集中型ストレージ、複数のコンピューターからアクセス可能、自動バックアップ
  • 短所：ネットワーク接続が必要、録音パフォーマンスが遅い、設定が複雑

クラウドストレージ（OneDrive、Google Drive、Dropboxフォルダー）

  • 長所：自動バックアップ、どこからでもアクセス可能、デバイス間で同期
  • 短所：インターネットが必要、アップロード時間の遅延、継続的なサブスクリプションコスト

ベストプラクティス： 多くのユーザーは一時的に内蔵ドライブに録音を保存し、古い録音を外付けストレージまたはクラウドバックアップに移動します。

セクション1：保存場所

これはすべての録音の保存場所を決定する最も重要なストレージ設定です。

保存場所を変更する方法

ステップバイステップの手順：

  1. ストレージ設定を開く

    • SeaMeetの左サイドバーの設定ギアアイコンをクリックします
    • カテゴリリストの"Storage"をクリックします

  2. "Save Location"を見つける

    • 現在のパスを表示するテキストフィールドを探します
    • 例：C:\Users\YourName\SeaMeet Recordings

  3. "Browse..."をクリックする

    • ファイルブラウザウィンドウが開きます

  4. 希望する場所に移動する

    • 内蔵ドライブの場合：「この PC」をクリックして C: または D: ドライブを選択
    • 外付けドライブの場合：「この PC」以下で USB ドライブを探す
    • ネットワークの場所の場合：アドレスバーにパスを入力

  5. フォルダーを選択または作成する

    • 既存のフォルダーを選択できます
    • または新しいフォルダーを作成：右クリック → 新しいフォルダー → 名前を付ける（例："SeaMeet Recordings"）

  6. "Select Folder"または"OK"をクリックする

    • ファイルブラウザが閉じます
    • 新しいパスがテキストフィールドに表示されます

  7. "Apply"をクリックする

    • 変更が保存されます
    • 今後の録音は新しい場所に保存されます

パスの例：

Windows:
- 内蔵：C:\Users\Sarah\Documents\SeaMeet Recordings
- 外付け：D:\SeaMeet Recordings
- ネットワーク：\\server\shared\recordings

macOS:
- 内蔵：/Users/sarah/Documents/SeaMeet Recordings
- 外付け：/Volumes/ExternalDrive/SeaMeet Recordings
- ネットワーク：/Volumes/Server/recordings

適切な場所を選ぶ

シナリオ1：内蔵スペースが十分にある場合

  • 現状：C: ドライブに500GB以上の空き
  • 推奨：デフォルトの場所をそのままにする
  • 理由：最速のパフォーマンス、最も簡単なセットアップ

シナリオ2：C: ドライブが満杯になりつつある場合

  • 現状：100GB未満の空き
  • 推奨：D: ドライブまたは外部ストレージに移動
  • 手順：
    1. 既存の録音を新しい場所にコピーする
    2. 設定の保存場所を変更する
    3. 新しい録音が動作することを確認する
    4. 古いコピーを削除する（バックアップ後！）

シナリオ3：大きな外付けドライブがある場合

  • 現状：2TBの外付けUSBドライブ
  • 推奨：外付けドライブに直接保存する
  • 手順：
    1. 録音時はドライブを常に接続していることを確認する
    2. 保存場所を外付けドライブに設定する
    3. そのドライブを録音専用に使うことを検討する

シナリオ4：クラウドストレージを使用している場合

  • 現状：OneDriveまたはGoogle Driveフォルダーが同期されている
  • 推奨：クラウドドライブのサブフォルダーに保存する
  • 手順：
    1. クラウドドライブに「SeaMeet Recordings」フォルダーを作成する
    2. それを保存場所として設定する
    3. 録音は自動的にクラウドに同期される
    4. 注意：大きなビデオファイルはアップロードに時間がかかる場合があります

既存の録音を新しい場所に移動する

保存場所を変更しても、SeaMeetは既存の録音を自動的に移動しません。適切に移動する方法は次のとおりです：

重要： ファイルを移動する前に必ずバックアップを取ってください！

ステップバイステップ：

  1. 両方のフォルダーを開く

    • 現在の録音フォルダー（古い場所）を開く
    • 新しい録音フォルダー（新しい場所）を開く
    • ウィンドウを並べて配置する

  2. すべての既存録音を選択する

    • 古いフォルダーで、Ctrl+A（Windows）またはCmd+A（Mac）を押してすべてを選択する
    • または移動したい特定の録音を手動で選択する

  3. コピーする（まだ移動しない！）

    • Ctrl+C（Windows）またはCmd+C（Mac）を押してコピーする
    • 新しいフォルダーの場所をクリックする
    • Ctrl+V（Windows）またはCmd+V（Mac）を押して貼り付ける
    • コピーが完了するまで待つ（大きなファイルは時間がかかる場合があります）

  4. コピーを確認する

    • すべてのファイルが新しい場所に表示されることを確認する
    • 1〜2つの録音を再生して動作することを確認する
    • ファイルサイズが一致することを確認する

  5. SeaMeet設定を更新する

    • SeaMeet設定 → Storageを開く
    • 保存場所を新しいフォルダーに変更する
    • Applyをクリックする

  6. 新しい録音をテストする

    • 短いテスト録音を行う
    • 新しい場所に表示されることを確認する
    • 再生して動作することを確認する

  7. 古いコピーを削除する（任意）

    • すべてが動作することを確認した後のみ！
    • 古い場所のファイルを選択する
    • Deleteキーを押す
    • 削除を確認する
    • または安全のためにゴミ箱/ゴミ箱に移動する

代替方法：コピーではなく移動する 確信がある場合やスペースが不足している場合：

  • 手順3〜4をスキップする
  • 手順3では、Ctrl+C（コピー）の代わりにCtrl+X（切り取り）を使用する
  • 次にCtrl+Vで新しい場所に貼り付ける
  • ファイルはコピーではなく移動される（より速いが、バックアップなし）

保存場所の一般的な問題

問題1：場所を変更する際に"Access Denied"エラーが表示される

原因： 選択したフォルダーへの書き込み権限がありません。

解決策：

  1. 別の場所を選ぶ（Documentsフォルダーなど）
  2. SeaMeetを管理者として実行する（右クリック → 管理者として実行）
  3. フォルダーの権限を確認する（右クリック → プロパティ → セキュリティ）

問題2：外付けドライブが参照に表示されない

原因： ドライブが接続されていない、正しくフォーマットされていない、またはドライバーの問題。

解決策：

  1. ドライブが接続されて電源が入っていることを確認する
  2. Windowsエクスプローラー（Windows）またはFinder（Mac）でドライブが表示されるか確認する
  3. 別のUSBポートを試す
  4. コンピューターを再起動する
  5. Windowsのディスク管理またはMacのディスクユーティリティでドライブの状態を確認する

問題3：ネットワークドライブが利用できない

原因： ネットワーク接続の問題、ドライブがオフライン、または権限の問題。

解決策：

  1. ネットワークに接続していることを確認する
  2. まずファイルエクスプローラー/Finderでドライブにアクセスを試みる
  3. 資格情報の入力が必要かどうかを確認する
  4. 職場のネットワークドライブの場合はITサポートに連絡する

問題4：録音が新しい場所に表示されない

原因： 設定が保存されなかった、またはSeaMeetがキャッシュされた場所を使用している。

解決策：

  1. SeaMeetを完全に再起動する
  2. 設定が適用されたことを確認する
  3. SeaMeetの複数のインスタンスが実行されているかどうかを確認する
  4. 場所を再設定してすぐにApplyをクリックする

セクション2：ストレージ使用状況モニター

ストレージ使用状況セクションでは、録音ストレージの状況を視覚的なダッシュボードで確認できます。デジタルストレージの燃料計と考えてください。

ストレージ表示を理解する

通常、次のように表示されます：

Current Storage Usage
┌──────────────────────────────────────────────────────┐
│ Recordings folder: 47.3 GB used                      │
│ Available space: 12.7 GB remaining                   │
│ Total capacity: 500 GB                               │
│                                                      │
│ █████████████████████████████████░░░░░░░░░░░░░░░░░   │
│ 79% full — Warning threshold: 85%                    │
└──────────────────────────────────────────────────────┘

数値の内訳：

  • Recordings folder： 実際の録音が使用しているスペース
  • Available space： そのドライブに残っている空き容量
  • Total capacity： ドライブ/パーティションの合計サイズ
  • 視覚バー： 使用状況のグラフィカルな表現
  • パーセンテージ： ストレージの使用率
  • Warning threshold： 警告が表示され始めるタイミング

カラーコーディング（ほとんどのバージョン）：

  • 🟢 緑：50%未満 — 問題なし！
  • 🟡 黄：50〜80% — 注意して監視する
  • 🟠 オレンジ：80〜90% — 警告ゾーン、クリーンアップを検討
  • 🔴 赤：90%以上 — 緊急！すぐにクリーンアップ！

数値が重要な理由

新しい録音のための利用可能スペース：

  • 2時間のビデオ会議を録音する必要がある場合
  • 1080pでは約20〜30GB必要
  • 15GBしか空き容量がない場合は録音できない！

システムパフォーマンス：

  • Windowsは正常に動作するために少なくとも10〜15%の空きスペースが必要
  • macOSも仮想メモリのために大きな空きスペースが必要
  • 満杯のドライブはスローダウン、クラッシュ、問題を引き起こす

Flashback録音の要件：

  • FlashbackはRAMとバッファー用のディスクスペースが必要
  • ストレージが危機的に低い場合、Flashbackが正常に動作しない場合がある

各ストレージレベルでの対処法

緑ゾーン（0〜50%満杯）：

  • 問題ありません！
  • 通常どおり録音を続ける
  • 予防措置として自動クリーンアップの設定を検討する
  • 即座のアクションは不要

黄ゾーン（50〜80%満杯）：

  • 状況を監視する
  • ストレージ警告の設定を検討する
  • 将来のクリーンアップ戦略を計画する
  • まだ通常の録音は安全

オレンジゾーン（80〜90%満杯）：

  • ⚠️ 警告ゾーン！
  • まだ設定していない場合はストレージ警告を設定する
  • 古い録音を外部ストレージに移動することを検討する
  • 自動クリーンアップを有効にする
  • 削除できる録音を確認する
  • まだ機能しているが、積極的に対処する

赤ゾーン（90%以上満杯）：

  • 🚨 緊急！即時対処が必要！
  • スペースが空くまで録音を停止する
  • 直ちに録音を外付けドライブに移動する
  • 不要なファイルを削除する
  • ゴミ箱を空にする
  • ディスククリーンアップユーティリティを実行する
  • 重複する録音を確認する

セクション3：ストレージ警告

ストレージ警告は車の燃料計のようなものです。スペースが不足する前にアラートを表示します。これにより、録音中に「ディスクフル」エラーに驚かされる代わりに、対処する時間が与えられます。

ストレージ警告の仕組み

警告しきい値の設定： SeaMeetが低ストレージについて警告するタイミングを設定できます：

Show warning when storage is low: [80% ▼]

通常利用可能なオプション：

  • 70%満杯
  • 75%満杯
  • 80%満杯（推奨）
  • 85%満杯
  • 90%満杯
  • カスタムパーセンテージ

しきい値に達した時の動作：

  1. 視覚的な警告：

    • 通知ポップアップが表示される
    • ストレージバーがオレンジ/赤に変わる
    • インターフェースに警告アイコンが表示される

  2. 録音前の警告：

    • 有効にすると、録音を開始する前に警告
    • 必要なスペースと利用可能なスペースを表示
    • キャンセルまたは続行のオプションを提供

  3. トレイアイコンインジケーター：

    • SeaMeetのシステムトレイアイコンが変わる場合がある
    • 警告バッジまたは色の変更が表示される

警告メッセージの例：

⚠️ STORAGE WARNING

Your recordings folder is 87% full (43.5 GB used of 50 GB).
Only 6.5 GB remaining.

A 1-hour video recording needs approximately 15 GB.
You may not have enough space to complete your recording.

[Manage Storage] [Continue Anyway] [Cancel]

ストレージ警告の設定

ステップバイステップ：

  1. ストレージ設定を開く

  2. "Storage Warnings"セクションを見つける

  3. "Show warning when storage is low"を有効にする

    • チェックボックスをオンにするかトグルスイッチをオンにする

  4. しきい値を設定する

    • ドロップダウンをクリックする（現在はパーセンテージが表示されている）
    • 希望するしきい値を選択する
    • 推奨：
      • ヘビーユーザー：70〜75%
      • 一般ユーザー：80%
      • ライトユーザー：85〜90%

  5. "Show warning before recording if low space"を有効にする

    • これにより、完了できない録音を開始することを防げます
    • 強くお勧めします！

  6. "Apply"をクリックする

警告をテストする： 警告が機能することを確認するには：

  1. しきい値を一時的に非常に低く設定する（10%など）
  2. 警告が表示されることを確認する
  3. しきい値を希望の値にリセットする
  4. Applyをクリックする

録音前のスペース確認

これは最も便利な機能の一つです。録音を開始する前に十分なスペースがあるかどうかを計算します。

仕組み：

  1. "Start Recording"をクリックします
  2. SeaMeetは次の内容に基づいて必要なスペースを推定します：
    • 録音タイプ（音声のみとビデオ）
    • 選択した品質設定
    • 時間（わかっている場合、または1時間を想定）
  3. 必要なスペースと利用可能なスペースを比較する
  4. スペースが不足している場合は警告する

見積もりの例：

Estimated space needed for this recording:
• Audio only (MP3): 60 MB per hour
• Audio only (WAV): 600 MB per hour
• Video (1080p): 18 GB per hour
• Video (720p): 9 GB per hour
• Video (480p): 3 GB per hour

You have 12 GB available.
Recommended maximum duration: 40 minutes at 1080p

なぜこれが重要か： 2時間の重要な会議を録音して、ドライブが満杯になったために45分後に中断されることほど悔しいことはありません。この警告はそれを防ぎます。

セクション4：自動クリーンアップ

自動クリーンアップは、定期的に録音を整理して不要になった古い録音を削除するロボットアシスタントのようなものです。設定してあとはおまかせのストレージ管理です。

自動クリーンアップの仕組み

基本概念： SeaMeetは特定の古さの基準を満たす録音を自動的に削除しますが、まだ必要な可能性がある最近の録音は保護します。

2つの主なコントロール：

  1. 古さのしきい値： X日より古い録音を削除
  2. 最小保持数： 常に最新のY件の録音を保持

設定例：

☑ Automatically delete old recordings
Delete recordings older than: [90 days ▼]
Keep at least: [10 most recent ▼]
☑ Move to Recycle Bin instead of permanent delete

実際の動作例：

  • 過去6ヶ月の録音が50件ある
  • 30件が90日以上経過している
  • SeaMeetは最も古い20件を削除する
  • ただし最新の10件は保持する（一部が90日以上経過していても）
  • 結果：30件の録音を保持する（最新10件 + 十分に最近の20件）

自動クリーンアップの設定

ステップバイステップ：

  1. ストレージ設定を開く

  2. "Automatic Cleanup"セクションを見つける

  3. "Automatically delete old recordings"を有効にする

    • スイッチをオンにする

  4. 古さのしきい値を設定する

    • ドロップダウンをクリックする
    • 録音を保持する期間を選択する
    • 通常のオプション：7、14、30、60、90、180、365日
    • ほとんどのユーザーへの推奨：90日（3ヶ月）

  5. 最小保持数を設定する

    • 常に保持する最新録音の数を選択する
    • 通常のオプション：5、10、20、50件、またはすべて
    • 推奨：10〜20件の録音

  6. 削除方法を選択する

    • ☑ ゴミ箱に移動する（より安全、必要に応じて回復できる）
    • ☐ 完全削除（すぐにスペースを解放、回復不可）
    • 推奨：ゴミ箱を使用！

  7. "Apply"をクリックする

クリーンアップはいつ実行されるか？

  • 毎日：通常1日1回確認する
  • 起動時：SeaMeet起動時に確認する場合がある
  • 手動トリガー：一部のバージョンには"Cleanup Now"ボタンがある
  • 録音後：録音終了後に確認する場合がある

適切なクリーンアップ設定を選ぶ

ライトユーザー（週1〜2件の録音）：

古さのしきい値：180日（6ヶ月）
最小保持数：20件
理由：録音数が少ないので、より長く保持する

一般ユーザー（週3〜5件の録音）：

古さのしきい値：90日（3ヶ月）
最小保持数：10件
理由：中程度の使用状況でのバランスの取れたアプローチ

ヘビーユーザー（毎日の録音）：

古さのしきい値：30日（1ヶ月）
最小保持数：10件
理由：頻繁な録音はスペースをすぐに使い果たす、積極的にクリーンアップ

ビジネス/コンプライアンスユーザー：

古さのしきい値：365日（1年）以上
最小保持数：50件以上
☐ 自動クリーンアップを無効にする
理由：法律またはコンプライアンス要件によりデータ保持が義務付けられている場合
注：ストレージを手動管理するか、外部アーカイブを使用する

重要な安全機能

ゴミ箱の保護：

  • "Move to Recycle Bin"を常に有効にする
  • 削除された録音はWindowsでは30日間（またはMacでゴミ箱を空にするまで）ゴミ箱に留まる
  • 誤って削除された録音を回復できる
  • スペースを完全に解放するには、別途ゴミ箱を空にする

スター/お気に入りの保護：

  • 一部のバージョンでは、スター付きまたはお気に入りの録音は削除されない
  • 重要な録音にスターを付けてクリーンアップから保護する
  • クリーンアップ設定でバージョンにこの機能があるか確認する

手動オーバーライド：

  • いつでも手動で録音を削除できる
  • 手動削除は即時に行われる
  • 自動クリーンアップは古い保護されていない録音のみを削除する

自動クリーンアップの監視

クリーンアップ履歴の表示： 一部のバージョンでは、クリーンアップ内容のログが表示されます：

Cleanup History (Last 30 Days)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Jan 15 — Deleted 3 recordings (oldest: 95 days)
Jan 14 — Deleted 2 recordings (oldest: 92 days)
Jan 12 — Deleted 5 recordings (oldest: 98 days)
Jan 08 — No cleanup needed

クリーンアップ通知の受け取り： クリーンアップが発生したときに通知を受け取ることができます：

☑ Notify me when old recordings are deleted
☑ Show summary of what was cleaned up
☑ Warn before deleting if more than 10 files

一時的な無効化： クリーンアップを一時停止する必要がある場合：

  1. ストレージ設定に移動する
  2. "Automatically delete old recordings"のチェックを外す
  3. Applyをクリックする
  4. 準備ができたら再度有効にする（クリーンアップが再開される）

セクション5：ファイル整理

録音の命名と整理の方法は、後で見つけるときに大きな違いをもたらします。良い整理は混沌とした山を検索可能なライブラリに変えます。

ファイル命名パターン

これとは： 命名パターンは録音を保存するときのデフォルトのファイル名を決定します。

利用可能なパターン（典型的なオプション）：

  1. Date_Time（シンプル）

    2024-01-15_14-30-22.mp4
    • 長所：シンプル、時系列で並び替え
    • 短所：録音内容のコンテキストなし

  2. Date_Time_App（推奨）

    2024-01-15_14-30-22_Zoom.mp4
2024-01-15_14-30-22_Teams.mp4
    • 長所：使用したアプリがわかる、時系列で並び替え
    • 短所：会議の内容はまだわからない

  3. App_Date_Time

    Zoom_2024-01-15_14-30-22.mp4
Teams_2024-01-15_14-30-22.mp4
    • 長所：アプリ別にグループ化、特定のプラットフォームを見つけやすい
    • 短所：各アプリ内では日付順になる

  4. カスタムパターン

    {YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}_{App}_{Custom}
    • 一部のバージョンではカスタムパターンを作成できる
    • 日付、時刻、アプリ名などの変数を使用する

変更方法：

  1. ストレージ設定を開く
  2. "File Organization"セクションを見つける
  3. "Naming pattern"ドロップダウンをクリックする
  4. 希望するパターンを選択する
  5. Applyをクリックする

サブフォルダーの作成

これとは： 時間帯などの基準に基づいて録音をフォルダーに自動的に整理します。

整理オプション：

  1. サブフォルダーなし（フラット）

    /SeaMeet Recordings/
  ├── 2024-01-15_14-30-22_Zoom.mp4
  ├── 2024-01-15_16-00-00_Teams.mp4
  └── 2024-01-16_09-00-00_Zoom.mp4
    • すべての録音が1つのフォルダーに
    • シンプルだが混雑する可能性がある

  2. 年別

    /SeaMeet Recordings/
  ├── 2023/
  │   └── [2023年の録音...]
  └── 2024/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      └── [2024年の録音...]
    • 年別に分ける
    • 長期アーカイブに適している

  3. 月別（推奨）

    /SeaMeet Recordings/
  └── 2024-01/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      ├── 2024-01-15_16-00-00_Teams.mp4
      └── 2024-01-16_09-00-00_Zoom.mp4
    • 月別に分ける
    • バランスの取れた整理
    • 最近の録音を見つけやすい
    • 月次のクリーンアップ/レビューに適している

  4. 週別

    /SeaMeet Recordings/
  └── 2024-W03/
      ├── [第3週の録音...]
    • 週番号別に分ける
    • プロジェクトベースの作業に適している
    • スプリントサイクルと合わせられる

  5. 日別

    /SeaMeet Recordings/
  └── 2024-01-15/
      ├── 14-30-22_Zoom.mp4
      └── 16-00-00_Teams.mp4
    • 日別に分ける
    • 最も細かい
    • 頻繁に録音する場合はフォルダーが多くなる

設定方法：

  1. ストレージ設定を開く
  2. "Create subfolders by"を見つける
  3. 希望する整理方法を選択する
  4. Applyをクリックする
  5. 新しい録音はこの構造に従う

注意： 既存の録音は現在の場所に留まります。これは新しい録音にのみ影響します。

整理のベストプラクティス

"月別 + アプリ"戦略（強く推奨）：

命名：Date_Time_App
サブフォルダー：月別

結果：

/SeaMeet Recordings/
  ├── 2024-01/
  │   ├── 2024-01-15_14-30-22_Zoom.mp4
  │   ├── 2024-01-15_16-00-00_Teams.mp4
  │   └── 2024-01-16_09-00-00_Zoom.mp4
  └── 2024-02/
      ├── 2024-02-01_10-00-00_Meet.mp4
      └── 2024-02-05_14-00-00_Zoom.mp4

なぜこれが機能するか：

  1. 時系列： 日付で録音を見つけやすい
  2. 圧倒的でない： 各月には管理可能な数のファイル
  3. アプリの識別： どのプラットフォームが使用されたかわかる
  4. 簡単なクリーンアップ： 古い月のフォルダー全体を削除できる
  5. シンプルなバックアップ： 月フォルダーを外部ストレージにコピーできる

セクション6：ストレージのベストプラクティス

3-2-1バックアップルール

重要な録音については、業界標準の3-2-1バックアップ戦略に従ってください：

3： 重要なデータの3つのコピーを保持する

  • オリジナルの録音
  • ローカルバックアップ（外付けドライブ）
  • クラウドバックアップ（OneDrive、Google Driveなど）

2： 2種類の異なるストレージタイプを使用する

  • 内蔵ドライブ（オリジナル）
  • 外付けドライブまたはクラウド（バックアップ）

1： 1つのバックアップをオフサイトに保持する

  • クラウドストレージはオフサイトとして数えられる
  • または外付けドライブを別の物理的な場所に保管する

SeaMeetへの適用方法：

  1. 内蔵ドライブに録音する（高速、即時アクセス）
  2. クラウドフォルダーへの自動同期を設定する（OneDrive、Dropbox）
  3. 月次：重要な録音を外付けドライブにコピーする
  4. 四半期ごと：古い録音を外部アーカイブに移動する

ストレージニーズの計算

次の式を使用してニーズを見積もります：

必要なストレージ = (日次使用量 × 日数) + 安全バッファー + 成長

計算例：

シナリオ：1日2時間の1080pビデオを週5日録音する

日次：2時間 × 15GB/時間 = 30GB/日
週次：30GB × 5日 = 150GB/週
月次：150GB × 4週 = 600GB/月
年次：600GB × 12ヶ月 = 7.2TB/年

安全バッファー：20% = 1.44TB
成長係数：1.5×（50%成長）= 3.6TB

推奨合計：7.2 + 1.44 + 3.6 = 12.24TB

実用的な推奨：

  • ライトユーザー（週1時間の音声）：年間100GB
  • 一般ユーザー（週5時間の混合）：年間1〜2TB
  • ヘビーユーザー（毎日2時間のビデオ）：年間5〜10TB

ストレージコストの管理

クラウドストレージを使用する場合：

  • 音声のみ：非常に手頃（100GBで月約300〜600円）
  • ビデオ録音：急速にコストが増加する
  • クラウドの1TBのビデオ：月約1,000〜2,000円
  • クラウドの10TBのビデオ：月約10,000〜20,000円

コスト節約戦略：

  1. 定例会議には低品質のビデオを使用する（1080pの代わりに720p）
  2. ほとんどの会議では音声のみを保持し、必要な時だけビデオを使用する
  3. 古い録音をより安価な低速ストレージにアーカイブする
  4. 文字起こし/要約後に録音を削除する
  5. 圧縮形式を使用する（MP3、圧縮MP4）

外付けドライブを使用する場合：

  • 1TB外付けドライブ：約5,000〜7,000円（一回限りのコスト）
  • 4TB外付けドライブ：約10,000〜12,000円（一回限りのコスト）
  • 8TB外付けドライブ：約15,000〜20,000円（一回限りのコスト）
  • 大きなビデオライブラリには費用対効果が高い

月次ストレージメンテナンスルーティン

毎月15分をストレージメンテナンスに充てましょう：

各月の第1週：

  1. ストレージダッシュボードを確認する

    • SeaMeet → 設定 → Storageを開く
    • 現在の使用率を記録する
    • 利用可能なスペースを確認する

  2. 自動クリーンアップをレビューする

    • 利用可能な場合はクリーンアップログを確認する
    • 設定が機能していることを確認する
    • 必要に応じて調整する

  3. 古い録音を移動する

    • 外付けドライブに前月のフォルダーを作成する
    • 30日以上前の録音をコピーする
    • コピーが動作することを確認する
    • 内蔵ドライブから削除する

  4. ゴミ箱を空にする

    • ゴミ箱を右クリック → 空にする
    • スペースを完全に解放する

  5. バックアップを更新する

    • クラウドフォルダーを同期する
    • 外付けドライブのバックアップを確認する

必要な時間： 10〜15分 メリット： ストレージの危機を防ぎ、システムをスムーズに動作させる

ストレージ問題のトラブルシューティング

問題1：録音時の"Not Enough Space"エラー

症状：

  • エラーメッセージ："Insufficient disk space to start recording"
  • 録音が開始できない
  • 警告が表示されたが続行した

即時の解決策：

  1. スペースを素早く解放する：

    • ゴミ箱を空にする（すぐに1〜10GBを解放できる）
    • ディスククリーンアップ（Windows）またはストレージを最適化（Mac）を実行する
    • 古いダウンロード、一時ファイルを削除する
    • 未使用のプログラムをアンインストールする

  2. 保存場所を変更する：

    • より多くのスペースがあるドライブに切り替える
    • 外付けドライブが最も速い解決策

  3. 録音品質を下げる：

    • 設定 → Video → 品質を720pまたは480pに下げる
    • 50〜75%少ないスペースを使用する

  4. 音声のみに切り替える：

    • ビデオが必須でない場合は音声のみを録音する
    • ビデオより99%少ないスペースを使用する

長期的な解決策：

  • 自動クリーンアップを設定する
  • ストレージ警告のしきい値を上げる
  • より大きなドライブに移行する
  • 定期的なメンテナンスルーティンを実施する

問題2：録音が消えた

症状：

  • 録音が昨日はあったのに今日はない
  • 予想されるフォルダーにファイルが見つからない
  • SeaMeetはライブラリに録音を表示しているがファイルが見つからない

考えられる原因と解決策：

原因1：自動クリーンアップが実行された

  • クリーンアップが古い録音を削除したかどうかを確認する
  • 回復のためにゴミ箱を確認する
  • 解決策：クリーンアップ設定を調整するか無効にする

原因2：別の場所に移動された

  • 最近保存場所を変更したかどうかを確認する
  • 古い録音は以前のフォルダーにある
  • 解決策：ライブラリを更新するか、ファイルを新しい場所に移動する

原因3：誤って削除された

  • ゴミ箱を確認する
  • 自分（または他の誰か）がファイルを削除したかどうかを確認する
  • 解決策：ゴミ箱またはバックアップから復元する

原因4：ドライブレターが変更された（Windows）

  • 外付けドライブが異なるレター（D: → E:）を取得した
  • SeaMeetが誤った場所を探している
  • 解決策：ドライブレターを再割り当てするか、保存場所を更新する

回復手順：

  1. まずゴミ箱を確認する
  2. コンピューター全体で録音ファイル名を検索する
  3. バックアップの場所を確認する（クラウド、外付けドライブ）
  4. 最近削除された場合はファイル回復ソフトウェアを使用する
  5. SeaMeetの内部データベースを確認する（パスが表示される場合がある）

問題3：SeaMeetが保存場所にアクセスできない

症状：

  • エラー："Cannot write to save location"
  • 録音の保存に失敗する
  • 設定が保存場所に赤い警告を表示する

解決策：

  1. フォルダーの権限を確認する：

    • フォルダーを右クリック → プロパティ → セキュリティ（Windows）
    • ユーザーが「書き込み」権限を持っていることを確認する
    • 不足している場合は権限を追加する

  2. ドライブの状態を確認する：

    • ドライブエラーチェックを実行する
    • Windows：ドライブを右クリック → プロパティ → ツール → チェック
    • Mac：ディスクユーティリティ → 救急処置

  3. ドライブの接続を確認する：

    • 外付け/ネットワークドライブの場合は接続されていることを確認する
    • ファイルエクスプローラー/Finderにドライブが表示されることを確認する
    • 必要に応じて再接続する

  4. 別の場所を選ぶ：

    • Documentsフォルダーに切り替える（通常は常にアクセス可能）
    • 外付けの代わりに内蔵ドライブを使用する

  5. 管理者として実行する：

    • SeaMeetを右クリック → 管理者として実行
    • 一部の権限の問題をバイパスできる場合がある

問題4：ストレージ使用状況が誤った数値を表示する

症状：

  • SeaMeetが50GB使用と表示しているが、フォルダーは20GBと表示
  • 利用可能なスペースがファイルエクスプローラーと一致しない
  • 数値が大幅に間違っているように見える

考えられる原因：

  1. 隠しファイル：

    • SeaMeetは隠しの一時ファイルをカウントする場合がある
    • ファイルエクスプローラーで「隠しファイルを表示」を有効にして確認する

  2. キャッシュされたデータ：

    • 古いストレージ計算がキャッシュされている
    • SeaMeetを再起動して更新する

  3. 複数の場所：

    • SeaMeetが複数のフォルダーを追跡している場合がある
    • 最近保存場所が変更されたかどうかを確認する

  4. データベースとファイルシステム：

    • SeaMeetのデータベースに古い情報がある場合がある
    • ライブラリを再スキャンまたは更新する

修正：

  1. SeaMeetを完全に閉じる
  2. ファイルエクスプローラーでフォルダーサイズを手動で確認する
  3. SeaMeetを再起動する
  4. ストレージ設定に移動して"Refresh"または"Rescan"を探す
  5. 再計算を待つ

高度なストレージトピック

ネットワークストレージ（NAS）のセットアップ

NASとは？ Network Attached Storage — ネットワークに接続されたハードドライブで、任意のコンピューターからアクセスできます。

SeaMeetをNASで設定する：

  1. ネットワークドライブをマップする（Windows）：

    • ファイルエクスプローラーを開く
    • 「この PC」→「ネットワーク ドライブの割り当て」をクリックする
    • NASパスを入力：\\NAS-Name\shared-folder
    • 「サインイン時に再接続する」をチェックする
    • ドライブレターを割り当てる（例：Z:）

  2. SeaMeetの保存場所を設定する：

    • 設定 → Storage
    • Z:\SeaMeet Recordings（またはマップされたドライブ）に移動する
    • Applyをクリックする

  3. 考慮事項：

    • ネットワーク速度が録音パフォーマンスに影響する
    • 1080p録音には約25MB/sの持続的な書き込み速度が必要
    • Wi-Fiは速度が不十分な場合がある；可能な場合はイーサネットを使用する
    • ネットワークが切断された場合、録音が失敗する可能性がある

ベストプラクティス： ローカルドライブに録音してから、後でNASに自動同期する。

クラウドストレージの統合

仕組み： SeaMeetはクラウドストレージ（OneDrive、Google Drive、Dropboxなど）と同期するフォルダーに保存します。

セットアップ手順：

  1. クラウドフォルダーを作成する：

    • OneDrive/Google Driveフォルダーを開く
    • "SeaMeet Recordings"サブフォルダーを作成する

  2. 保存場所として設定する：

    • 設定 → Storage → Browse
    • クラウドフォルダーを選択する
    • Apply

  3. 同期を設定する：

    • OneDrive：フォルダーを右クリック → 常にこのデバイスに保持する（ローカルコピーが必要な場合）
    • または「容量を節約」でクラウドのみに保存する

  4. アップロードを監視する：

    • 大きなビデオはアップロードに時間がかかる
    • クラウドアプリでアップロードの進行状況を確認する
    • アップロードが完了するまでシャットダウンしない

長所：

  • 自動バックアップ
  • どこからでもアクセス可能
  • デバイス間で同期

短所：

  • アップロード帯域幅の使用
  • 大きなライブラリのストレージコスト
  • ファイルが他の場所で利用可能になるまでのアップロード遅延

ヒント：

  • "Files On-Demand"（OneDrive）または"Smart Sync"（Dropbox）でローカルスペースを節約する
  • オフピーク時間帯にアップロードをスケジュールする
  • お金を節約するためにクラウドストレージ前にビデオを圧縮する

クイックリファレンス：推奨設定

ほとんどのユーザー向け：

保存場所：C:\Users\[あなた]\SeaMeet Recordings（スペースが不足している場合は外付け）
ストレージ警告：80%のしきい値
自動クリーンアップ：有効、90日、10件の録音を保持
命名パターン：Date_Time_App
サブフォルダー：月別
ゴミ箱：有効（常に！）

ヘビーユーザー向け：

保存場所：外付けドライブまたはDドライブ
ストレージ警告：70%のしきい値
自動クリーンアップ：有効、30日、10件の録音を保持
命名パターン：Date_Time_App
サブフォルダー：月別
バックアップ：クラウド同期 + 月次外部アーカイブ
