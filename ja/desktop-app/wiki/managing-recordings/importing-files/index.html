ファイルのインポート - 外部の録音をSeaMeetに取り込む

第12章：ファイルのインポート — 外部の録音をSeaMeetに取り込む

このマニュアルでは、SeaMeetで直接行う録音に焦点を当ててきました。しかし、すでに持っている録音はどうでしょうか？別のアプリの古い会議録音、スマートフォンのボイスメモ、音声を抽出したい動画ファイルがあるかもしれません。同僚からSeaMeetの録音と一緒に整理したい録音を受け取ったかもしれません。

この章では、外部の音声・動画ファイルをSeaMeetのライブラリに取り込む方法を説明します。サポートされているフォーマット、インポートの方法、インポート中に何が起こるか、そしてインポートしたファイルをSeaMeetネイティブの録音と一緒に管理する方法を学びます。

なぜファイルをインポートするのか？

技術的な詳細に入る前に、元の場所でファイルを再生するのではなく、なぜSeaMeetにファイルをインポートしたいのかを理解しましょう。

一元管理

問題： 録音がさまざまな場所に散在しています：

  • ダウンロードフォルダに Zoom 録音がある
  • ボイスメモアプリにスマートフォンの録音がある
  • デスクトップにランダムな音声ファイルがある
  • メールの添付ファイルに会議録音がある
  • 外付けハードドライブにアーカイブファイルがある

解決策： すべてをSeaMeetにインポート：

  • すべての録音のための1つの中央ライブラリ
  • 一貫した再生インターフェース
  • 統一された整理と命名
  • すべてのファイルを横断する簡単な検索

たとえるなら： さまざまなカメラ、スマートフォン、コンピューターに散在している写真をすべて1つのフォトライブラリに統合するようなものです。

一貫した再生体験

問題： 異なるファイルには異なるアプリが必要：

  • MP3は音楽プレーヤーで開く
  • MP4は動画プレーヤーで開く
  • WebM ファイルはデフォルトプレーヤーで再生できない場合がある
  • 各アプリのコントロールやインターフェースが異なる

解決策： SeaMeetでほぼすべてを再生可能：

  • すべての録音を1つのインターフェースで
  • すべてのファイルに同じ再生コントロール
  • 一貫したタイムラインと波形表示
  • 統一されたキーボードショートカット

より優れた整理機能

SeaMeetが追加する機能：

  • リネーム： 暗号的なファイル名にわかりやすい名前を付ける
  • メタデータ： タイムスタンプ、ソースラベル、長さ情報
  • 検索： どの録音でも瞬時に検索
  • 波形： 音声の視覚的表現（元々なかったファイルにも）
  • 並べ替えとフィルタ： 日付、サイズ、ソースで整理

例： recording_1634578921.mp3 というファイル名が Client Call - Budget Discussion - Oct 15 になります

動画からの音声抽出

特別な機能： SeaMeetは動画ファイルから音声トラックを抽出できます。

使用例：

  • Zoom の動画録音をインポートし、音声だけを保持
  • YouTube動画からポッドキャスト音声を抽出
  • 大きな動画ファイルから音声だけを保存してスペースを節約
  • 動画なしでコンテンツに集中

動画ファイルはどうなるか？

動画ファイルをインポートすると、SeaMeetは：

  1. ファイルをSeaMeetのストレージ場所にコピー
  2. 音声トラックを抽出または保持
  3. SeaMeetのインターフェースで再生可能に
  4. プレーヤーで動画を表示（動画ファイルの場合）

音声抽出：

  • SeaMeetは動画ファイルから自動的に音声を抽出可能
  • インポート中または別のアクションとして実行
  • 元の動画は保持され、音声は別のトラックまたはオプションとして追加

フォーマット互換性の注意事項

インポートに最適なフォーマット：

  1. MP3 - どこでも使用可能、良好な圧縮
  2. MP4 - 汎用動画フォーマット
  3. WebM - SeaMeetネイティブ、高効率
  4. M4A - 良好な品質、Apple エコシステム

問題が発生する可能性があるフォーマット：

  • プロプライエタリフォーマット（Windows Media の WMA、WMV）
  • 非常に古いフォーマット（古いコーデックの AVI）
  • DRM保護ファイル（購入した音楽、暗号化された動画）
  • 破損ファイル（データ損傷）

ファイルがインポートできない場合：

  1. 上記のサポートリストに含まれているか確認
  2. まずMP3/MP4に変換してみる（第5章を参照）
  3. ファイルが他のアプリ（VLC）で再生できるか確認
  4. ファイルが破損している可能性

ファイルのインポート方法

SeaMeetには、インポートボタンとドラッグ＆ドロップの2つの主な方法があります。

方法1：インポートボタン

ステップバイステップ：

  1. SeaMeetを開き、インポートボタンを探す

    • 通常はトップツールバーにある
    • 「Import」というラベルまたは📥アイコン
    • またはFileメニュー：File → Import

  2. インポートボタンをクリック

    • ファイル選択ダイアログが開く

  3. ファイルに移動

    • ファイルが保存されている場所を参照
    • インポートしたいファイルを選択
    • 複数のファイルを選択可能（Ctrl+クリックまたはCmd+クリック）

  4. 「Open」または「Import」をクリック

    • インポート処理が開始
    • 進捗インジケーターが表示される場合がある

  5. インポートの完了を待つ

    • 小さなファイル：即座に完了
    • 大きな動画ファイル：時間がかかる場合がある（変換/抽出）

  6. ファイルがライブラリに表示される

    • 録音リストに表示される
    • 他の録音と同様に再生、リネーム、整理が可能

ワークフローの例：

1. Import ボタンをクリック
2. Downloads/Old_Meetings/ に移動
3. "team_meeting_march15.mp3" を選択
4. Open をクリック
5. ファイルがインポートされる
6. ライブラリに "team_meeting_march15" として表示
7. "Team Meeting - March 15 - Q1 Review" にリネーム

方法2：ドラッグ＆ドロップ

最も簡単な方法： ファイルエクスプローラーからファイルを直接SeaMeetにドラッグするだけです。

ステップバイステップ：

  1. ファイルエクスプローラーを開く（Macの場合Finder、Windowsの場合ファイルエクスプローラー）
  2. インポートしたいファイルに移動
  3. 両方が見えるようにウィンドウを配置：
    • ファイルがあるファイルエクスプローラー
    • SeaMeetウィンドウ
  4. ファイルをクリックしたまま保持
  5. SeaMeetウィンドウにドラッグ
  6. 録音リストエリアにドロップ
  7. ファイルが自動的にインポートされる

ドラッグ＆ドロップのコツ：

複数ファイル：

  • ファイルエクスプローラーで複数のファイルを選択（Ctrl+クリックまたはCmd+クリック）
  • すべてを一度にドラッグ
  • すべてのファイルがまとめてインポートされる

ドロップする場所：

  • 録音リストエリア（サイドバー）にドロップ
  • 一部のバージョンではウィンドウの任意の場所でも受け付ける
  • 視覚的なフィードバック（ハイライト、境界線の変化）に注意

キーボード修飾キー：

  • Ctrl+ドラッグ（Windows）/ Cmd+ドラッグ（Mac）： コピーを作成（元のファイルを移動しない）
  • Alt+ドラッグ： ショートカットを作成（インポートでは機能しない場合がある）

方法3：右クリックインポート（コンテキストメニュー）

お使いのバージョンで利用可能な場合：

  1. ファイルエクスプローラーでファイルを見つける
  2. ファイルを右クリック（またはControl+クリック）
  3. **「Open with SeaMeet」**または「Import to SeaMeet」を探す
  4. そのオプションをクリック
  5. SeaMeetが開き（まだ開いていない場合）、ファイルをインポート

注意： これにはSeaMeetがオペレーティングシステムにこれらのファイルタイプのハンドラーとして登録されている必要があります。すべてのバージョンでサポートされているわけではありません。

方法4：フォルダ/ディレクトリのインポート（利用可能な場合）

一括インポート用：

  1. File → Import Folder に移動（利用可能な場合）
  2. フォルダ全体を選択
  3. SeaMeetがそのフォルダ内のサポートされているすべてのファイルをインポート
  4. 進捗インジケーターが一括インポートの状態を表示

便利な用途：

  • 別の録音アプリからの移行
  • 何年分ものアーカイブ録音のインポート
  • 散在するファイルの統合

インポート中に何が起こるか

インポートプロセスを理解することで、何を期待し、どのくらい時間がかかるかがわかります。

インポートプロセスのステップ

ステップ1：ファイル検証

  • SeaMeetがファイルフォーマットがサポートされているか確認
  • ファイルが破損していないか検証
  • 十分なストレージ容量があるか確認

ステップ2：ファイルのコピー

  • 元のファイルは現在の場所に残る
  • SeaMeetがSeaMeetストレージフォルダにコピーを作成
  • これにより元のファイルの誤った変更や削除を防止

ステップ3：メタデータの抽出

  • ファイルの作成日を読み取る（録音タイムスタンプとして使用）
  • ファイルの長さを判定
  • コーデックとフォーマットを特定
  • 既存のメタデータを抽出

ステップ4：波形生成（音声）

  • 音声コンテンツを分析
  • 視覚的な波形を生成
  • 大きなファイルでは時間がかかる場合がある
  • 将来のすばやい表示のために保存

ステップ5：動画処理（該当する場合）

  • 動画ファイルの場合：再生用に動画を準備
  • 音声トラックの抽出を行う場合がある
  • サムネイルまたはプレビューを作成

ステップ6：ライブラリエントリの作成

  • SeaMeetのライブラリデータベースにエントリを追加
  • デフォルト名を割り当て（ファイル名に基づく）
  • 再生と整理の準備完了

インポート時間の見積もり

インポートにはどのくらいかかるか？

ファイルタイプサイズおおよそのインポート時間
小さな音声（MP3、10 MB未満）10 MB1〜5秒
中程度の音声（MP3、50 MB未満）50 MB5〜15秒
大きな音声（WAV、100 MB以上）100 MB以上15〜60秒
短い動画（5分未満）50〜100 MB10〜30秒
長い動画（30分以上）500 MB以上1〜5分
一括インポート（10ファイル以上）さまざま2〜10分

インポート時間に影響する要因：

  • ファイルサイズ： 大きいほど時間がかかる
  • フォーマット： 一部のフォーマットはより多くの処理が必要
  • コンピューターの速度： 高速なCPU＝高速なインポート
  • 波形生成： 初回の音声分析には時間がかかる
  • 動画の抽出： 動画からの音声抽出により時間が追加

ストレージへの影響

重要： インポートするとファイルのコピーが作成されます。

インポート前：

元のファイルの場所: 50 MB
SeaMeetストレージ使用: 0 MB
合計スペース使用: 50 MB

インポート後：

元のファイルの場所: 50 MB (変更なし)
SeaMeetストレージ使用: 50 MB (新しいコピー)
合計スペース使用: 100 MB

重要な理由：

  • インポートによりストレージ使用量が一時的に倍増
  • スペースを節約するためにインポート後に元のファイルを削除可能
  • または両方をバックアップ目的で保持

ストレージ計画：

  • ファイルサイズの少なくとも2倍の空き容量を確保
  • 1 GBのファイルをインポートするには2 GBの空き容量が必要
  • インポート後、確信があれば元のファイルを削除可能

インポートしたファイルの整理

ファイルがインポートされると、SeaMeetネイティブの録音と一緒にライブラリに表示されます。効果的に管理する方法を紹介します。

インポート直後に行うこと

1. ファイルをリネーム

前: "zoom_1615489321x2.mp4"
後: "Client Presentation - March 15 - Website Redesign"

2. ソースラベルを確認

  • 「Imported」または元のアプリ名が表示される場合がある
  • ネイティブ録音と区別するのに役立つ

3. 正しく再生されるか確認

  • 最初の30秒を再生して確認
  • 音声/動画の品質を確認
  • インポート中に破損がないか確認

4. 自分のシステムに整理

  • 命名規則を適用
  • 適切なカテゴリに追加
  • インポートが成功した場合は元のファイルの削除を検討

インポートとネイティブ録音の区別

見分け方：

ソースラベル：

  • ネイティブ：「Zoom」、「Teams」、「Microphone」
  • インポート：「Imported」、「File」、元のアプリ名、またはファイル名

タイムスタンプ：

  • ネイティブ：正確な録音時間
  • インポート：ファイルの作成日（実際の録音時間と異なる場合がある）

波形品質：

  • ネイティブ：高品質の波形
  • インポート：元の品質によって異なる場合がある

インポートしたファイルのメタデータ更新

課題： インポートしたファイルのメタデータが不正確または欠落している場合があります。

よくある問題：

  • 日付が間違っている： ファイルの作成日≠録音日
  • ソース情報がない： 元々どのアプリで録音されたかが表示されない
  • 一般的な名前： ファイル名が内容を説明していない

解決策：

1. 日付付きでリネーム：

"Budget Meeting - [Original Date] - Q3 Planning"
"Budget Meeting - March 15, 2024 - Q3 Planning"

2. 名前にソースを追加：

"[Zoom] Team Standup - March 15"
"[Phone] Voice Memo - App Idea"
"[Downloaded] Podcast Episode 47"

3. 説明フィールドを使用（利用可能な場合）： 一部のバージョンでは録音にメモや説明を追加できます。

動画ファイルからの音声抽出

SeaMeetの最も便利なインポート機能の1つは、動画ファイルから音声を抽出し、必要なコンテンツを保持しながらスペースを節約する機能です。

音声抽出とは？

概念： 動画ファイルには両方が含まれています：

  • 動画トラック： 画像/視覚コンテンツ
  • 音声トラック： 音/声/音楽

音声抽出は音声トラックのみを含む新しいファイルを作成し、動画を破棄します。

なぜ音声を抽出するのか？

  • スペースの節約： 音声は動画の5〜10分の1のサイズ
  • コンテンツに集中： 視覚的な気を散らすことなく聴く
  • 再生が簡単： 音声ファイルは読み込みが速い
  • 文字起こし： 音声のみからの方が文字起こしが簡単

音声を抽出するタイミング

抽出に適した候補：

✅ 画面共有のある会議録音

  • 会話だけが必要
  • 共有画面はメモに記録済み
  • 音声を抽出し、動画を削除

✅ 講義とプレゼンテーション

  • スライドは別に入手可能
  • 講師の声だけが必要
  • レビューには音声のみで十分

✅ 音声のみが重要な長い動画

  • ポッドキャスト、インタビュー
  • BGMコンテンツ
  • 音楽や音声の録音

✅ 動画として録音されたボイスメモ

  • スマートフォンが誤って動画として録音
  • 重要な視覚コンテンツがない
  • 効率的な音声フォーマットに変換

動画を保持するタイミング

以下の場合は音声を抽出しないでください：

❌ 視覚コンテンツが重要な場合

  • デモンストレーション、チュートリアル
  • 手話の動画
  • ボディランゲージが重要

❌ スライド/画面を見る必要がある場合

  • プレゼンテーション録画
  • ソフトウェアチュートリアル
  • 視覚的な参照

❌ 品質の比較が必要な場合

  • ビフォー/アフターの比較
  • 視覚的な証拠
  • 重要なビジュアルを含む画面録画

音声の抽出方法

方法1：インポート時

一部のバージョンでは、インポートオプションとして抽出を提供します：

  1. 動画ファイルのインポートを開始
  2. 「Extract audio」チェックボックスを探す
  3. インポート完了前にチェック
  4. SeaMeetが両方を作成：
    • 動画ファイル（オリジナル）
    • 音声ファイル（抽出済み）

方法2：インポート後

  1. 動画ファイルを通常通りインポート
  2. ライブラリで見つける
  3. 右クリックまたはアクションメニューを探す
  4. 「Extract Audio」または「Create Audio Version」を選択
  5. SeaMeetが処理して音声ファイルをライブラリに追加

方法3：音声のエクスポート/ダウンロード

  1. SeaMeetで動画を再生
  2. ダウンロードまたはエクスポートオプションを探す
  3. 「Audio only」フォーマットを選択
  4. 抽出した音声を保存

インポートのベストプラクティス

インポート前

1. ファイルの整合性を確認

  • ファイルが別のアプリ（VLC）で再生できるか確認
  • 破損していないか確認
  • 正しいファイルか確認

2. 利用可能なストレージを確認

  • インポートはコピーを作成することを忘れずに
  • ファイルサイズの2倍の空き容量を確保
  • 例：10 GBのインポートには20 GBの空き容量が必要

3. インポート前に整理

  • ファイルをプロジェクトや日付ごとにグループ化
  • インポート前に暗号的なファイル名をリネーム
  • 明らかに不要なファイルを削除

4. 事前の変換を検討

  • 非常に古いまたは特殊なフォーマットはうまくインポートできない場合がある
  • 必要に応じてまずMP3/MP4に変換（第5章を参照）
  • 互換性の向上を確保

インポート中

1. バッチでインポート

  • 一度に数百のファイルをインポートしない
  • 10〜20ファイルずつ行う
  • 管理とトラブルシューティングが容易

2. 進捗を監視

  • エラーメッセージに注意
  • 大きな動画ファイルは時間がかかる — 辛抱強く
  • インポート中にSeaMeetを閉じない

3. 各インポートを確認

  • ファイルがインポートされたら、すばやく確認
  • 再生されることを確認
  • 名前が正しく見えるか確認

インポート後

1. すぐにリネーム

  • デフォルトのファイル名のままにしない
  • 内容を覚えているうちにわかりやすい名前を付ける
  • 命名規則に従う

2. カテゴリに整理

  • フィルタやラベルを適用
  • 外部の整理を使用している場合はフォルダに移動
  • 利用可能な場合はプレイリストやコレクションに追加

3. 元のファイルについて判断

  • バックアップとして元のファイルを保持する？（最も安全）
  • それともスペースを節約するために削除する？（確信がある場合）
  • 元のファイルをアーカイブストレージに移動

4. システムを更新

  • 多数のファイルをインポートした場合、整理システムを更新
  • 必要に応じて新しいカテゴリを作成
  • 現在の構造がまだ機能するか検討

よくあるインポートの問題と解決策

「ファイルフォーマットがサポートされていません」

問題： ファイルをインポートしようとすると、フォーマットがサポートされていないというエラーが表示される。

考えられる原因：

  1. フォーマットが実際にサポートされていない（第5章のリストを確認）
  2. ファイル拡張子が実際のフォーマットと一致していない
  3. ファイルがSeaMeetで扱えないコーデックを使用している
  4. DRM保護ファイル（購入した音楽/映画）

解決策：

1. フォーマットを確認：

  • ファイルを右クリック → プロパティ（Windows）または情報を見る（Mac）
  • フォーマットがサポートリストにあるか確認

2. ファイルを変換：

  • VLCまたはオンラインコンバーターを使用
  • MP3（音声）またはMP4（動画）に変換
  • 変換したバージョンのインポートを試す

3. DRMを確認：

  • iTunes、Apple Music、Netflixなどのファイルは保護されている場合がある
  • DRMファイルはインポートできないことが多い
  • VLCで再生できるか確認（VLCで再生できない場合はおそらくDRM）

「インポートに失敗した、またはファイルが破損している」

問題： インポートが途中で失敗する、またはインポートしたファイルが再生されない。

解決策：

1. 別のプレーヤーでファイルを確認：

  • VLC Media Playerで再生を試す
  • VLCで再生できない場合、ファイルは破損している可能性が高い

2. ファイルサイズを確認：

  • ファイルサイズが0 KBまたは極端に小さい場合、空/破損
  • 元のファイルが完全か確認

3. 再ダウンロード/再コピーを試す：

  • ダウンロードしたファイルの場合は再度ダウンロード
  • 他の場所からコピーした場合は再コピー
  • 元のファイルが不完全だった可能性

4. ストレージ容量を確認：

  • ディスクが満杯の場合、インポートが失敗する可能性
  • 利用可能なスペースを確認
  • 必要に応じてスペースを解放

「インポートに時間がかかりすぎる」

問題： インポートプロセスが停止しているか、非常に遅い。

正常 vs. 問題：

大きなファイルでは正常：

  • 1 GBの動画が2〜3分かかるのは正常
  • 2時間の音声の波形生成には時間がかかる
  • プログレスバーは動き続けているはず

問題の兆候：

  • プログレスバーが10分以上固まっている
  • ディスクアクティビティがない（タスクマネージャー/アクティビティモニターで確認）
  • SeaMeetがフリーズしている

解決策：

1. もう少し待つ：

  • 非常に大きなファイル（5 GB以上）は10分以上かかる場合がある
  • 辛抱強く、プログレスバーを観察

2. システムリソースを確認：

  • タスクマネージャー（Windows）またはアクティビティモニター（Mac）を開く
  • CPUとディスクの使用状況を確認
  • SeaMeetがリソースを使用していれば、処理中

3. 小さなチャンクで試す：

  • 停止している場合はインポートをキャンセル
  • ファイルを1つずつインポート
  • または小さなバッチで

4. SeaMeetを再起動：

  • 本当にフリーズしている場合は強制終了して再起動
  • 部分的なインポートをクリアする必要がある場合も
  • 再度インポートを試す

「インポートしたファイルが再生されるが音声/動画がない」

問題： ファイルは正常にインポートされるが、再生時に音声または動画が欠落している。

解決策：

音声がない：

  1. SeaMeetの音量がミュートになっていないか確認
  2. システム音量を確認
  3. VLCで再生してファイルに音声があるか確認
  4. 一部の動画ファイルはサポートされていないコーデックの音声を持つ場合がある

動画がない（黒い画面）：

  1. 動画コーデックがサポートされていない可能性
  2. VLCで再生して確認
  3. H.264コーデックのMP4に変換
  4. 変換したバージョンを再インポート

「重複した録音が表示された」

問題： 同じ録音がライブラリに複数回表示される。

考えられる原因：

  1. 同じファイルを2回インポートした
  2. ファイルが複数の場所に存在する
  3. SeaMeetが再スキャンして重複を検出した

解決策：

1. 重複を削除：

  • どれが重複か特定
  • 余分なコピーを削除
  • 最もよく名前が付けられたものを保持

2. 将来の重複を防止：

  • インポート前にライブラリを確認
  • 再インポートの代わりに「Refresh」を使用
  • ファイルを1つの場所に保持

「インポートしたファイルのタイムスタンプが間違っている」

問題： インポートしたファイルに間違った日時が表示される。

なぜこれが起こるか：

  • SeaMeetはファイルの作成日をタイムスタンプとして使用
  • ファイルがコピーまたはダウンロードされた場合、作成日が最近になっている場合がある
  • 実際の録音日ではない

解決策：

  • 正しい日付で手動リネーム
  • 例：「Team Meeting - [March 15, 2024] - Budget Review」
  • 明確にするために名前に日付を含める

他の録音アプリからの移行

別の録音アプリからSeaMeetに切り替える場合、既存のライブラリを移行する方法を紹介します。

ステップ1：古い録音の場所を特定

よくある保存場所：

  • Zoom： Documents/Zoom/
  • Teams： ダウンロードした会議ファイル
  • ボイスメモ（iPhone）： iTunesの同期またはiCloud
  • Audacity： 選択した保存場所
  • その他のアプリ： 通常はDocumentsまたはDownloads

見つけ方：

  1. 古いアプリを開く
  2. 設定で「Save location」または「Storage」を確認
  3. そのフォルダに移動
  4. 録音を探す

ステップ2：インポート用にファイルを準備

インポート前に整理：

  1. すべてのファイルを集める：

    • 1つの一時フォルダにコピー
    • インポートが容易になる

  2. 暗号的なファイル名をリネーム：

    • 多くのアプリはタイムスタンプをファイル名に使用
    • わかりやすい名前にリネーム
    • パターンを使用：「トピック - 日付 - コンテキスト」

  3. フォーマットを確認：

    • ファイルがサポートされているフォーマットか確認
    • 特殊なフォーマットはインポート前に変換

  4. 不要なファイルを削除：

    • テスト録音
    • 誤って録音したもの
    • 明らかに不要なファイル

ステップ3：バッチでインポート

すべてを一度にインポートしないでください：

  1. 最新のファイルから開始：

    • まず直近3か月をインポート
    • 最も必要になる可能性が高い
    • 管理しやすいバッチサイズ

  2. 各バッチを確認：

    • ファイルが正しく再生されるか確認
    • 名前とメタデータを確認
    • 次のバッチの前に整理

  3. 逆順に作業：

    • 次に3〜6か月前をインポート
    • 次に6〜12か月前をインポート
    • 完了まで続ける

  4. 非常に古いファイルをアーカイブ：

    • 1〜2年以上前のファイル
    • アクティブなライブラリに必要ない場合がある
    • 外部ストレージに保持

ステップ4：整理システムの更新

システムの更新が必要な場合：

  1. カテゴリのレビュー：

    • フォルダ/ラベルはまだ意味があるか？
    • 必要に応じて新しいカテゴリを追加
    • 既存のものを結合または分割

  2. 命名規則の更新：

    • 新しいファイルに対して機能しているか確認
    • 将来の参照のために文書化
    • チームメンバーがいる場合は教育

  3. 古い構造のアーカイブ：

    • インポートが完了したら、古いフォルダ構造をアーカイブ可能
    • しばらくバックアップとして保持
    • 確信が持てたら削除

クリップボードからの画像インポート

SeaMeetは、クリップボードから直接画像をインポートできます — ファイルは不要です。別のアプリからスクリーンショットや画像をコピーすると、SeaMeetが自動的に検出します。

仕組み

  1. 任意のアプリで画像をコピー — スクリーンショット、トリミングした画像、写真など、Ctrl+C / Cmd+C でコピーしたもの。
  2. SeaMeetが画像を検出し、プロンプトを表示：
┌─────────────────────────────────┐
│        画像を検出しました        │
│                                 │
│    [サムネイルプレビュー]        │
│    1920 × 1080                  │
│                                 │
│  [  Download  ]  [ Dismiss ]    │
└─────────────────────────────────┘
  1. 画像をSeaMeetにインポートするには**「Download」をクリック**、無視するには**「Dismiss」をクリック**。
    • キーボード： Enter でインポート、Escape で却下。
  2. 画像は他のスクリーンショットと同様にライブラリに追加されます。

使用するタイミング

  • ブラウザやデザインツールからスクリーンショットをコピーして、AI分析用にインポート
  • ディスクに保存せずに図やホワイトボードの写真を直接貼り付け
  • 余分な手順なしで、すでにコピーした視覚コンテンツをインポート

注意： プロンプトは画像をコピーした場合のみ表示されます。テキストやファイルのコピーではトリガーされません。
