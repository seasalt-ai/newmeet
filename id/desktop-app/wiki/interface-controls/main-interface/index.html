Antarmuka Utama - Tur Lengkap UI SeaMeet

Bab 13: Antarmuka Utama - Tur Lengkap UI SeaMeet

Sekarang, Anda telah menggunakan SeaMeet untuk merekam audio dan video, mengatur pustaka Anda, dan memutar ulang perekaman. Anda telah berinteraksi dengan berbagai bagian antarmuka, tetapi mungkin belum memiliki gambaran lengkap tentang bagaimana semua bagian cocok bersama. Bab ini memberikan tur komprehensif antarmuka utama SeaMeet—setiap tombol, panel, indikator, dan kontrol—sehingga Anda dapat menavigasi aplikasi dengan percaya diri dan menemukan fitur yang mungkin belum Anda temukan.

Pikirkan bab ini sebagai tur berpemandu rumah baru. Kita akan berjalan melalui setiap ruangan, memeriksa fitur, dan menjelaskan apa yang dilakukan semuanya. Pada akhirnya, Anda akan tahu persis di mana menemukan setiap fungsi dan memahami bagaimana antarmuka beradaptasi dengan situasi yang berbeda.

Tata Letak Jendela: Gambaran Besar

Saat Anda membuka SeaMeet, Anda melihat satu jendela dengan tata letak yang konsisten. Tata letak ini tetap stabil baik Anda sedang merekam, memutar ulang, atau hanya menjelajahi pustaka Anda. Memahami tata letak ini adalah fondasi untuk menggunakan SeaMeet secara efektif.

Zona 1: Bilah Navigasi Atas

  • Selalu terlihat
  • Berisi kontrol global
  • Akses cepat ke fitur kunci

Zona 2: Sidebar (Daftar Perekaman)

  • Selalu terlihat (di sebagian besar tampilan)
  • Menampilkan perekaman Anda
  • Daftar kartu perekaman yang dapat digulir

Zona 3: Area Konten Utama

  • Berubah berdasarkan konteks
  • Menampilkan pemutar saat memutar perekaman
  • Menampilkan kontrol perekaman saat bersiap untuk merekam
  • Menampilkan pengaturan saat mengonfigurasi opsi

Zona 1: Bilah Navigasi Atas

Bilah navigasi atas menyediakan navigasi dan kontrol akun. Tetap ramping dan fokus — kontrol perekaman dan Flashback telah pindah ke Capture Hub di area konten utama (lihat Status 1 di bawah).

Toggle Navigasi (☰)

Apa yang dilakukan: Meruntuhkan atau memperluas sidebar kiri (daftar perekaman).

Kapan menggunakan:

  • Runtuhkan untuk memberi Capture Hub lebih banyak ruang horizontal
  • Perluas untuk menelusuri pustaka perekaman Anda saat tidak merekam

Menu Akun / Pengguna (👤)

Apa yang dilakukan: Membuka menu akun pengguna di mana Anda dapat:

  • Masuk atau keluar
  • Buka Pengaturan (audio, video, Flashback, penyimpanan, bahasa, pintasan)
  • Buka referensi pintasan keyboard
  • Akses Help & Support

Cara menggunakan:

  1. Klik gambar profil atau ikon pengguna Anda
  2. Pilih opsi yang diinginkan dari dropdown

Tombol Rekam (🔴)

Ikon: Lingkaran merah (🔴) saat siap, Persegi (⏹️) saat merekam Label: "RECORD" atau hanya ikon Warna: Merah cerah (menunjukkan tindakan perekaman)

Apa yang dilakukan: Mulai atau hentikan perekaman

Status:

Siap Merekam:

[🔴 RECORD]
Ikon lingkaran merah
Klik untuk mulai merekam

Perekaman Aktif:

[⏹️ STOP]
Ikon persegi
Timer menunjukkan waktu yang telah berlalu
Klik untuk menghentikan perekaman

Cara menggunakan:

Untuk mulai merekam:

  1. Konfigurasikan pengaturan perekaman Anda terlebih dahulu
  2. Klik tombol Rekam merah
  3. Perekaman dimulai segera
  4. Tombol berubah menjadi Stop
  5. Timer mulai menghitung

Untuk menghentikan perekaman:

  1. Klik tombol Stop (persegi)
  2. Perekaman berhenti
  3. File disimpan
  4. Perekaman muncul di sidebar
  5. Tombol kembali ke status Rekam

Apa yang terjadi saat Anda klik Rekam:

  1. Penangkapan audio/video dimulai
  2. Timer muncul menunjukkan waktu yang telah berlalu
  3. Tombol berubah dari 🔴 ke ⏹️
  4. Indikator visual menunjukkan status perekaman
  5. File sedang ditulis ke penyimpanan

Apa yang terjadi saat Anda klik Stop:

  1. Perekaman berhenti
  2. File diselesaikan dan disimpan
  3. Perekaman muncul di daftar sidebar
  4. Tombol kembali ke status 🔴
  5. Timer menghilang atau direset

Catatan penting:

  • Perekaman dimulai segera—siaplah!
  • Tidak ada hitungan mundur atau peringatan
  • Pastikan pengaturan Anda benar sebelum mengklik
  • Flashback (jika diaktifkan) termasuk masa lalu yang di-buffer

System Tray

SeaMeet memasang ikon system tray (area notifikasi Windows, bilah menu macOS) saat pertama kali diluncurkan dan menjaganya tetap hidup untuk seluruh sesi aplikasi. Tray adalah permukaan kontrol yang selalu tersedia — bahkan saat Anda telah menutup jendela utama, SeaMeet masih berjalan, siap untuk menangkap, dan dapat dijangkau dari satu klik pada ikonnya.

Mengapa Tray Tetap Hidup

Menutup jendela utama tidak menutup SeaMeet. Sebaliknya, jendela disembunyikan dan ikon tray tetap di tempatnya. Ini disengaja:

  • Auto-Detect masih dapat membangunkan aplikasi saat aplikasi rapat diluncurkan
  • Flashback dapat menjaga buffer bergulirnya tetap terisi (jika dipersenjatai)
  • Hotkey global (Mulai Perekaman, Tampilkan Peluncur, Tampilkan Floater) masih berfungsi
  • Perekaman cepat hanya satu klik tray jauhnya

Saat pertama kali Anda menutup jendela, SeaMeet mengirim petunjuk "diminimalkan ke tray" sekali sehingga Anda mengerti bahwa aplikasi tidak benar-benar keluar. Untuk benar-benar keluar, gunakan Exit SeaMeet dari menu tray (lihat di bawah) atau perintah keluar aplikasi OS Anda.

Ikon Tray

Ikon default (idle):

  • Windows: logo SeaMeet kecil .ico di area notifikasi
  • macOS: gambar template 22×22 di bilah menu yang menyesuaikan dengan mode terang/gelap

Ikon perekaman (sedang berlangsung):

  • Beralih ke varian yang diwarnai merah sehingga Anda dapat melihat sekilas bahwa SeaMeet sedang menangkap
  • Di macOS bilah menu juga mendapat akhiran ●; jika dijeda menunjukkan ⏸
  • Tooltip berubah dari "SeaMeet" menjadi "SeaMeet — Recording in progress" (atau "Paused")

Perilaku klik:

  • Klik kiri ikon — mengaktifkan jendela utama (tampilkan jika tersembunyi, sembunyikan jika terlihat)
  • Klik kanan ikon (Windows) / klik tunggal (macOS) — membuka menu konteks

Menu Tray (Status Idle)

Saat Anda tidak merekam, menu terlihat seperti ini:

├─────────────────────────────────────────┤
│ Perekaman cepat        (dinonaktifkan)  │

│   🖥️  Rekam fullscreen                  │
│   ◰  Rekam area                         │
│   📷  Ambil tangkapan layar (Ctrl+Shift+S)│
│   📁  Buka folder perekaman             │
├─────────────────────────────────────────┤
│ 🚀 Tampilkan peluncur     (Ctrl+Shift+L)│
│ 🪟 Tampilkan jendela mengambang (Ctrl+Shift+F)│

Apa yang dilakukan setiap item:

  • Workspace: <nama> — Header yang menunjukkan workspace cloud mana yang akan ditempati perekaman yang dimulai dari tray. Hanya muncul di build Lite atau yang berkemampuan cloud di mana Anda telah masuk dan memilih workspace. Di build non-cloud baris tersebut disembunyikan seluruhnya sehingga bentuk menu tetap tidak berubah.
  • Rekam audio — Memulai perekaman audio saja segera. Tidak ada sumber video yang diminta.
  • Rekam fullscreen — Memulai perekaman tampilan utama Anda ditambah audio.
  • Rekam area — Membuka hamparan area fullscreen sehingga Anda dapat menyeret-memilih area, lalu memulai perekaman area itu.
  • Ambil tangkapan layar — Membuka pemilih area untuk tangkapan layar sekali. Pintasan ditampilkan jika Anda telah mengikatnya di Pengaturan → Keyboard.
  • Buka folder perekaman — Membuka penjelajah file OS di direktori penyimpanan Anda saat ini.
  • Tampilkan peluncur — Mengaktifkan panel SeaMeet Launcher (lihat Bab 14). Pintasan ditampilkan saat terikat.
  • Tampilkan jendela mengambang — Menampilkan/menyembunyikan widget Floater. Pintasan ditampilkan saat terikat.
  • Tampilkan jendela utama — Membawa jendela utama ke depan (sama dengan klik kiri ikon saat tersembunyi).
  • Keluar SeaMeet — Satu-satunya item menu yang benar-benar keluar. Itu menetapkan tanda internal "sedang keluar" dan meminta Electron untuk mengakhiri; yang lainnya hanya menampilkan/menyembunyikan permukaan.

Menu Tray (Saat Merekam)

Saat perekaman sedang berlangsung, menu diubah bentuknya untuk memberi Anda kontrol transportasi langsung:

┌─────────────────────────────────────────┐
│ ● Perekaman berlangsung (dinonaktifkan) │
├─────────────────────────────────────────┤
│ ⏹  Hentikan perekaman (Ctrl+Shift+R)   │
│ ⏸  Jeda perekaman                      │
│ ⚑  Tandai peristiwa                     │
├─────────────────────────────────────────┤
│ 🗔 Tampilkan jendela utama              │
├─────────────────────────────────────────┤
│ ⏻  Keluar SeaMeet                       │
└─────────────────────────────────────────┘

Catatan pada menu perekaman:

  • Baris header adalah label status murni (sengaja dinonaktifkan).
  • Hentikan perekaman mengakhiri penangkapan dan menyimpan file persis seperti mengklik tombol Stop di jendela utama.
  • Jeda/Lanjutkan hanya ditampilkan saat codec/sumber mendukungnya. Perekaman hanya video menyembunyikan item Jeda.
  • Tandai peristiwa menjatuhkan penanda stempel waktu ke dalam perekaman, berguna untuk melompat kembali ke momen kunci selama pemutaran.
  • Saat dijeda, menu menukar Lanjutkan perekaman di tempat Jeda dan judul macOS berbalik menjadi ⏸.

Label yang Dilokalkan

Menu tray menghormati 15 lokal yang didukung (Inggris, Spanyol, Prancis, Jerman, Jepang, Korea, Hindi, Polandia, Portugis, Rusia, Thailand, Vietnam, Denmark, Cina Sederhana, Cina Tradisional). Bahasa di luar set itu jatuh kembali ke bahasa Inggris sehingga menu selalu dirender dengan benar.

Kotak Pencarian

Lokasi: Bagian atas sidebar Tampilan: Bidang teks dengan ikon kaca pembesar (🔍) Teks placeholder: "Cari perekaman..." atau serupa

Apa yang dilakukan: Memfilter daftar perekaman secara real-time saat Anda mengetik

Cara menggunakan:

  1. Klik di kotak pencarian
  2. Mulai mengetik
  3. Daftar memfilter secara otomatis
  4. Menampilkan hanya perekaman yang cocok dengan pencarian Anda
  5. Bersihkan pencarian untuk melihat semua perekaman lagi

Apa yang dapat Anda cari:

  • Nama perekaman
  • Label sumber ("Zoom", "Teams")
  • Tanggal (jika diketik dalam format yang dapat dicari)
  • Pencocokan parsial berfungsi

Contoh pencarian:

  • Cari "Zoom" → Menampilkan semua perekaman Zoom
  • Cari "budget" → Menampilkan perekaman dengan "budget" dalam nama
  • Cari "Maret" → Menampilkan perekaman Maret
  • Cari "client" → Menampilkan perekaman terkait klien

Membersihkan pencarian:

  • Klik tombol X (jika ada)
  • Hapus semua teks
  • Tekan tombol Escape

Kartu Perekaman

Setiap perekaman di pustaka Anda ditampilkan sebagai kartu perekaman—ringkasan kompak informasi kunci perekaman.

Dua mode tampilan:

  1. Tampilan Kompak (default) - Info minimal, penelusuran efisien
  2. Tampilan Diperluas - Info terperinci, pratinjau gelombang suara

Tampilan Kompak

┌──────────────────────────────────────────────────────────┐
│ 🎤 Tinjauan Anggaran Q3 - Rapat Tim                      │
│ 47:32 • Hari ini, 2:30 PM • Zoom • Audio                 │
└──────────────────────────────────────────────────────────┘

Elemen:

  • Ikon (🎤) - Menunjukkan jenis (audio/video)
  • Nama - Judul perekaman
  • Durasi - Berapa lama (47:32)
  • Stempel Waktu - Kapan direkam (Hari ini, 2:30 PM)
  • Sumber - Dari mana (Zoom)
  • Jenis - Audio/Video/Flashback

Kapan menggunakan tampilan kompak:

  • Menelusuri banyak perekaman
  • Pemindaian cepat
  • Ruang layar terbatas
  • Gambaran umum pustaka

Ikon Kartu Perekaman Dijelaskan

Ikon Audio:

  • 🎤 - Mikrofon (perekaman audio)
  • 🔴 - Audio (umum)
  • 🔊 - Audio sistem saja
  • 🎤+🔊 - Audio gabungan (mik + sistem)

Ikon Video:

  • 🎥 - Perekaman video
  • 📹 - Perekaman layar
  • 🖥️ - Perekaman fullscreen
  • 🪟 - Perekaman jendela

Ikon Khusus:

  • ⏪ - Perekaman Flashback
  • 📥 - File yang diimpor
  • 🌐 - Perekaman web/browser

Kontrol Pengurutan dan Pemfilteran

Lokasi: Biasanya di bagian atas sidebar, dekat pencarian

Opsi Pengurutan:

  • Tanggal (terbaru pertama) - Default
  • Tanggal (tertua pertama)
  • Nama (A-Z)
  • Nama (Z-A)
  • Durasi (terpendek pertama)
  • Durasi (terpanjang pertama)
  • Ukuran (terkecil pertama)
  • Ukuran (terbesar pertama)

Cara mengubah pengurutan:

  1. Klik dropdown "Sort"
  2. Pilih metode pengurutan
  3. Klik lagi untuk membalik urutan

Opsi Filter:

  • Semua - Tampilkan semuanya
  • Hanya audio - Perekaman audio
  • Hanya video - Perekaman video
  • Hari ini - Perekaman hari ini
  • Minggu ini - Perekaman terbaru
  • Flashback - Tangkapan Flashback
  • Berdasarkan Sumber - Zoom, Teams, dll.

Cara memfilter:

  1. Klik tombol atau dropdown "Filter"
  2. Pilih kriteria filter
  3. Daftar diperbarui untuk hanya menampilkan kecocokan
  4. Klik "Clear" atau "All" untuk mengatur ulang

Zona 3: Area Konten Utama

Area konten utama adalah bunglon antarmuka SeaMeet—mengubah tampilannya berdasarkan apa yang Anda lakukan. Mari jelajahi statusnya yang berbeda.

Status 1: Capture Hub (Idle / Siap Merekam)

Saat ditampilkan:

  • Saat Anda pertama kali membuka SeaMeet
  • Saat tidak ada perekaman yang dipilih dan Anda tidak sedang merekam

Apa yang Anda lihat — Capture Hub:

Area konten utama menampilkan Capture Hub, tata letak dua panel yang menempatkan kontrol perekaman dan tangkapan layar di depan dan tengah:

Panel Kiri — Mulai Perekaman

Panel kiri berisi semua kontrol untuk memulai perekaman baru:

Kontrol pengapit (atas kartu):

  • Toggle Flashback (kiri) — Klik untuk siklus mode Flashback: OFF → Audio → Layar → OFF. Menunjukkan ikon ⚡ petir saat dipersenjatai (buffer mengisi atau siap). Lihat Bab 7 untuk detail lengkap.
  • Lingkaran mik merah besar (tengah) — Klik untuk membuka modal Pengaturan Video dan pilih mode perekaman Anda (audio saja, fullscreen, jendela, area).
  • Toggle Auto-Detect (kanan) — Mengaktifkan perekaman otomatis saat aplikasi rapat terdeteksi.

Area konteks (tengah kartu):

  • Saat Flashback OFF: menampilkan deskripsi singkat tentang cara memulai.
  • Saat Flashback sedang dipersenjatai (mengisi): menunjukkan indikator kemajuan saat buffer mengisi.
  • Saat Flashback siap: menampilkan ikon ⚡ dan konfirmasi "Flashback armed".

Tombol CTA (bawah kartu):

  • Label dan tindakan beradaptasi dengan status Flashback:
    • Flashback OFF → "Start Recording" (membuka Pengaturan Video)
    • Flashback sedang dipersenjatai → "Buffering…" (dinonaktifkan saat mengisi)
    • Flashback siap → "Record with Flashback" (menangkap buffer dan memulai perekaman)

Pintasan peluncuran cepat (strip bawah):

  • Buka Peluncur — Membuka panel SeaMeet Launcher dengan hotkey yang ditampilkan
  • Buka Floater — Menampilkan/menyembunyikan widget Floater dengan hotkey yang ditampilkan

Panel Kanan — Ambil Tangkapan Layar

Panel kanan menangani tangkapan layar secara independen dari perekaman:

  • Tombol ikon kamera — Tombol hero besar; klik untuk mengambil tangkapan layar menggunakan mode yang saat ini dipilih.
  • Full Screen / Area Capture — Tombol radio untuk memilih antara penangkapan layar penuh atau menggambar area.
  • Pertahankan kotak centang jendela SeaMeet terlihat — Saat tidak dicentang (default), SeaMeet meminimalkan dirinya sendiri sebelum menangkap sehingga tidak muncul dalam tangkapan layar. Saat dicentang, jendela tetap terlihat dan akan muncul dalam tangkapan.
  • Tombol Take Screenshot — Memicu penangkapan (sama dengan mengklik ikon kamera).

Tujuan:

  • Hub satu atap untuk semua yang Anda butuhkan sebelum mulai menangkap
  • Status Flashback terlihat dan dapat dikontrol tanpa membuka Pengaturan
  • Tangkapan layar dan perekaman dipisahkan dengan rapi menjadi dua kartu

Mode Lite vs Full

SeaMeet dikirim dengan dua mode antarmuka. Mereka berbagi mesin perekaman yang sama, file yang sama di disk, dan ikon tray yang sama — tetapi mengekspos jumlah UI yang sangat berbeda.

Memilih Mode

Pada peluncuran pertama bersih, SeaMeet menampilkan pemilih mode yang menanyakan pengalaman mana yang Anda inginkan. Pengguna v2.x yang ada yang melakukan upgrade dimigrasi secara diam-diam ke mode Full (sehingga tidak ada yang berubah secara visual), tetapi semua orang dapat beralih nanti dari Pengaturan.

Mode yang dipilih dipertahankan sebagai appMode: 'full' | 'lite' di pengaturan UI Anda. Beralih mode saat perekaman sedang berlangsung ditunda sampai perekaman selesai sehingga Anda tidak pernah kehilangan penangkapan; modal Pengaturan tertutup segera sehingga spinner "Menyimpan…" terlihat selama menunggu.

Mode Full (Default)

Ini adalah bab yang telah Anda baca sejauh ini — sidebar + Capture Hub + area konten utama, semua status (Perekaman, Putar Ulang, Pengaturan) tercakup dalam bagian di atas. Mode Full mencakup:

  • Capture Hub dengan kontrol Flashback dan tangkapan layar
  • Sidebar penuh dengan kartu perekaman, pencarian, urutkan dan filter
  • Catatan dan Wiki (lihat Bab 16–17)
  • Pustaka Media (Bab 10)
  • Semua kategori pengaturan (Bab 18+)
  • Ruang kerja lokal-pertama (lihat "Ruang Kerja" di bawah)

Gunakan mode Full saat SeaMeet adalah permukaan perekaman utama Anda dan Anda ingin catatan, wiki, agen, dan manajemen pustaka dalam satu jendela.

Mode Lite

Mode Lite adalah area permukaan yang jauh lebih kecil yang berpusat di system tray dan satu daftar rapat yang didukung cloud. Tidak ada sidebar, tidak ada tampilan catatan, tidak ada wiki, tidak ada Capture Hub — perekaman dimulai dari tray (atau deteksi otomatis, atau hotkey), dan perekaman yang sudah selesai muncul sebagai kartu rapat setelah pipeline ringkasan pasca-rapat mengunggahnya ke ruang kerja SeaMeet Anda.

Jendela Lite tipikal terlihat seperti ini:

│                                                             │
│  3 rapat, 2j 14m minggu ini                                 │
│                                                             │
│  ┌─────────────────────────────────────────────────────────┐│
│  │ Tinjauan Pipeline Q3 — Hari ini, 10:00        [Buka]   ││
│  │ Discovery: Northwind — Kemarin, 14:30         [Buka]   ││
│  │ Sinkronisasi Internal — Sen, 09:00            [Buka]   ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘

Header ruang kerja di Lite:

Bagian paling atas jendela Lite adalah pemilih ruang kerja (tombol yang menunjukkan nama ruang kerja aktif dengan avatar dan chevron). Mengklik membuka dropdown dari setiap ruang kerja yang Anda miliki akses di cloud SeaMeet. Memilih ruang kerja yang berbeda:

  1. Mempertahankan ID ruang kerja baru secara lokal
  2. Menyegarkan daftar rapat
  3. Mendorong nama ruang kerja baru ke menu tray sehingga perekaman yang dimulai tray juga mendarat di tempat yang tepat
  4. Mengatur ulang paginasi ke halaman 1

Keluar membersihkan header ruang kerja tray (traySetWorkspaceDisplay(null, null)) sehingga menu tidak pernah berbohong tentang ruang kerja yang Anda tidak lagi memiliki akses.

Perekaman di Lite:

  • Klik ikon tray dan pilih Rekam audio / fullscreen / area — atau gunakan hotkey global
  • Tampilan Perekaman Lite mengambil alih jendela utama dengan gelombang suara langsung, timer, dan kontrol Stop tunggal
  • Saat Anda berhenti, file disimpan secara lokal dan diunggah ke ruang kerja SeaMeet Anda untuk transkripsi dan ringkasan
  • Setelah pipeline cloud selesai, kartu rapat muncul dalam daftar

Gunakan mode Lite saat SeaMeet adalah perekam latar belakang yang memberi makan cloud SeaMeet — Anda ingin tray melakukan pekerjaan dan daftar rapat yang bersih untuk ditinjau.

Beralih Antar Mode

Buka Pengaturan (di salah satu mode), temukan tindakan "Beralih ke mode Full / Lite", dan konfirmasi. SeaMeet mengeringkan perekaman yang sedang berlangsung, lalu meluncurkan kembali renderer ke mode lain. File, ruang kerja, pengaturan, dan ikon tray Anda bertahan dari sakelar.

Ruang Kerja

SeaMeet memiliki dua konsep ruang kerja yang berbeda yang berbagi nama tetapi tinggal di tempat yang berbeda. Memahami mana adalah mana menghindari kebingungan.

Ruang Kerja Lokal (Mode Full)

Dalam mode Full, ruang kerja adalah vault gaya Obsidian — folder di disk yang menampung catatan Anda, wiki yang dihasilkan, dan (secara default) perekaman Anda. WorkspaceManager di proses utama memiliki:

  • Registri ruang kerja ({ id, name, path, isDefault? }[]) yang dipertahankan dalam file pengaturan Anda
  • ID ruang kerja aktif (hanya satu yang aktif pada satu waktu)
  • Pengamat file chokidar di jalur ruang kerja aktif, dengan polling otomatis-diaktifkan untuk volume eksternal dan mount jaringan (mis. macOS /Volumes/, Google Drive ~/Library/CloudStorage/GoogleDrive-<email>/…) di mana FSEvents tidak akan menembak dengan andal
  • Status per-ruang kerja (catatan terakhir dibuka, file terbaru, dll.) di bawah userData/workspace-state/<id>.json

Pada peluncuran pertama, jika tidak ada ruang kerja yang terdaftar, SeaMeet secara otomatis membuat satu ruang kerja Default yang menunjuk ke direktori penyimpanan Anda. Nama "Default" dilokalkan di semua 23 bahasa.

Pemilih Ruang Kerja (Header Sidebar):

Baik tampilan Catatan (Bab 16) dan tampilan Wiki (Bab 17) merender <WorkspaceSwitcher> di bagian atas pohon file:

┌──────────────────────────────────┐
│ [🅰] Acme Vault            ⌄    │  ← ruang kerja aktif
├──────────────────────────────────┤
│ Ruang Kerja                      │
│  ✓ Acme Vault     ~/Notes/Acme  │
│    Personal      ~/Notes/Personal│
│    Side Project  ~/Code/Side    │
├──────────────────────────────────┤
│ + Tambahkan ruang kerja…         │
└──────────────────────────────────┘
  • Klik baris aktif untuk membuka dropdown
  • Klik ruang kerja lain untuk beralih ke sana — pengamat file dirobohkan, jalur ruang kerja baru dipasang, Catatan dan Wiki disegarkan, dan status per-ruang kerja dipulihkan
  • Tambahkan ruang kerja… membuka pemilih folder asli sehingga Anda dapat mendaftarkan direktori apa pun sebagai vault (keunikan diperiksa — mendaftarkan jalur yang sama dua kali ditolak)
  • Hapus (×) pada baris menghapus entri SeaMeet saja; file di disk tidak tersentuh. Anda tidak dapat menghapus ruang kerja terakhir.
  • Setiap baris dapat menampilkan lencana cloud (Dropbox, iCloud, OneDrive, Google Drive) dan lencana git remote saat deteksi sinkronisasi menemukannya

Mengalihkan ruang kerja diserialisasi: jika sakelar sudah dalam penerbangan, yang berikutnya menunggu untuk selesai sehingga NotesManager / WikiManager tidak pernah berakhir menunjuk ke jalur basi.

Ruang Kerja Cloud (Mode Lite)

Dalam mode Lite (dan dalam build Full yang berkemampuan cloud), ruang kerja berarti sesuatu yang berbeda: ruang kerja tim di cloud SeaMeet. Komponen <WorkspacePicker> mengambil ruang kerja yang dapat Anda akses melalui SeaMeet API dan mempertahankan yang dipilih untuk routing unggahan.

Ruang kerja cloud menggerakkan:

  • Ruang kerja mana yang diunggah perekaman baru
  • Rapat ruang kerja mana yang muncul dalam daftar rapat Lite
  • Baris header ruang kerja di menu tray (sehingga Anda dapat melihat sekilas di mana perekaman yang dimulai tray berikutnya akan mendarat)

Pemilih cloud memfilter ruang kerja di mana my_status Anda adalah INACTIVE. Pada masuk pertama, jika ruang kerja yang sebelumnya Anda pilih tidak ada dalam daftar yang dikembalikan (Anda kehilangan keanggotaan, schema drift, dll.), pemilih secara otomatis memilih ruang kerja pertama yang tersedia dan mempertahankannya — sehingga menu tidak pernah dapat terjebak pada ID yang tidak dapat diakses.

Keduanya Sekaligus

Dalam build Full yang berkemampuan cloud, Anda dapat memiliki keduanya jenis ruang kerja yang dipilih secara bersamaan: vault lokal yang menampung catatan Anda dan ruang kerja cloud SeaMeet yang menerima unggahan Anda. Mereka independen — beralih satu tidak mengalihkan yang lain.
