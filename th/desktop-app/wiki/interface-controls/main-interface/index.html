อินเทอร์เฟซหลัก - ทัวร์ครบถ้วนของ UI ของ SeaMeet

บทที่ 13: อินเทอร์เฟซหลัก - ทัวร์ครบถ้วนของ UI ของ SeaMeet

ในตอนนี้ คุณได้ใช้ SeaMeet เพื่อบันทึกเสียงและวิดีโอ จัดระเบียบคลังของคุณ และเล่นการบันทึก คุณได้โต้ตอบกับส่วนต่าง ๆ ของอินเทอร์เฟซ แต่คุณอาจไม่มีภาพรวมที่สมบูรณ์ของวิธีที่ทุกชิ้นส่วนเข้าด้วยกัน บทนี้ให้ทัวร์ที่ครอบคลุมของอินเทอร์เฟซหลักของ SeaMeet — ทุกปุ่ม แผง ตัวบ่งชี้ และตัวควบคุม — เพื่อให้คุณสามารถนำทางแอปด้วยความมั่นใจและค้นหาฟีเจอร์ที่คุณอาจยังไม่ได้ค้นพบ

คิดถึงบทนี้เป็นทัวร์นำทางของบ้านใหม่ เราจะเดินผ่านแต่ละห้อง ตรวจสอบฟีเจอร์ และอธิบายว่าทุกอย่างทำอะไร เมื่อจบ คุณจะรู้แน่นอนว่าจะหาฟังก์ชันทุกอย่างได้ที่ไหนและเข้าใจว่าอินเทอร์เฟซปรับให้เข้ากับสถานการณ์ต่าง ๆ อย่างไร

เลย์เอาต์หน้าต่าง: ภาพรวม

เมื่อคุณเปิด SeaMeet คุณจะเห็นหน้าต่างเดียวที่มีเลย์เอาต์สม่ำเสมอ เลย์เอาต์นี้ยังคงเสถียรไม่ว่าคุณจะกำลังบันทึก กำลังเล่น หรือเพียงแค่เรียกดูคลังของคุณ การเข้าใจเลย์เอาต์นี้เป็นรากฐานสำหรับการใช้ SeaMeet อย่างมีประสิทธิภาพ

ถาดระบบ

SeaMeet ติดตั้ง ไอคอนถาดระบบ (พื้นที่การแจ้งเตือนของ Windows, แถบเมนูของ macOS) ครั้งแรกที่เปิดและรักษามันไว้ตลอดเซสชันของแอป ถาดคือพื้นผิวควบคุมที่ใช้ได้ตลอดเวลา — แม้คุณจะปิดหน้าต่างหลัก SeaMeet ยังคงทำงานอยู่ พร้อมที่จะจับภาพ และเข้าถึงได้จากคลิกเดียวบนไอคอน

ทำไมถาดยังคงทำงาน

การปิดหน้าต่างหลักไม่ได้ ไม่ได้ หยุด SeaMeet แทนหน้าต่างจะซ่อนและไอคอนถาดยังคงอยู่ นี่เป็นไปโดยตั้งใจ:

  • Auto-Detect ยังคงสามารถปลุกแอปได้เมื่อแอปประชุมเปิด
  • Flashback สามารถรักษาบัฟเฟอร์ที่ทำงานต่อเนื่องได้ (หากเปิดใช้งาน)
  • ฮอตคีย์ระดับโลก (Start Recording, Show Launcher, Show Floater) ยังคงทำงาน
  • การบันทึกอย่างรวดเร็วอยู่ห่างเพียงคลิกถาดเดียว

ครั้งแรกที่คุณปิดหน้าต่าง SeaMeet ส่งคำใบ้ "ย่อขนาดไปยังถาด" ครั้งเดียวเพื่อให้คุณเข้าใจว่าแอปไม่ได้ออกจริง ๆ ในการออกอย่างสมบูรณ์ ใช้ Exit SeaMeet จากเมนูถาด (ดูด้านล่าง) หรือคำสั่งออกจากแอปของ OS ของคุณ

ไอคอนถาด

ไอคอนเริ่มต้น (ว่าง):

  • Windows: โลโก้ SeaMeet .ico ขนาดเล็กในพื้นที่การแจ้งเตือน
  • macOS: ภาพเทมเพลต 22×22 ในแถบเมนูที่ปรับให้เข้ากับโหมดสว่าง/มืด

ไอคอนการบันทึก (กำลังดำเนินการ):

  • เปลี่ยนเป็นรูปแบบสีแดงเพื่อให้คุณเห็นในพริบตาว่า SeaMeet กำลังจับภาพ
  • บน macOS แถบเมนูยังได้รับคำต่อท้าย ●; หากหยุดชั่วคราวจะแสดง ⏸
  • ทูลทิปเปลี่ยนจาก "SeaMeet" เป็น "SeaMeet — Recording in progress" (หรือ "Paused")

พฤติกรรมการคลิก:

  • คลิกซ้ายที่ไอคอน — สลับหน้าต่างหลัก (แสดงถ้าซ่อน ซ่อนถ้ามองเห็น)
  • คลิกขวาที่ไอคอน (Windows) / คลิกเดียว (macOS) — เปิดเมนูบริบท

  • Record fullscreen — เริ่มการบันทึกการแสดงผลหลักของคุณพร้อมเสียง
  • Record region — เปิดการซ้อนทับพื้นที่เต็มหน้าจอเพื่อให้คุณสามารถเลือกพื้นที่ด้วยการลาก จากนั้นเริ่มการบันทึกพื้นที่นั้น
  • Take screenshot — เปิดตัวเลือกพื้นที่สำหรับภาพหน้าจอแบบครั้งเดียว แสดงทางลัดหากคุณได้ผูกไว้ใน ตั้งค่า → Keyboard
  • Open recordings folder — เปิดเบราว์เซอร์ไฟล์ของ OS ที่ไดเรกทอรีบันทึกปัจจุบันของคุณ
  • Show launcher — สลับแผง SeaMeet Launcher (ดูบทที่ 14) แสดงทางลัดเมื่อผูก
  • Show floating window — แสดง/ซ่อนวิดเจ็ต Floater แสดงทางลัดเมื่อผูก
  • Show main window — นำหน้าต่างหลักไปข้างหน้า (เหมือนกับคลิกซ้ายที่ไอคอนเมื่อซ่อน)
  • Exit SeaMeet — รายการเมนูเดียวที่ออกจริง มันตั้งค่าธง "is quitting" ภายในและขอให้ Electron ยุติ; ทุกอย่างอื่นเพียงแสดง/ซ่อนพื้นผิว

  • ตัวบ่งชี้ "PAUSED" มองเห็นได้

  • สีเขียว
  • ตัวบ่งชี้คงที่
  • แสดงระยะเวลา (เช่น "30S")
  • พร้อมที่จะจับช่วงเวลาในอดีต

  • มองเห็นการ์ดการบันทึกมากขึ้น

  • ออก: แป้น ESC หรือ F อีกครั้ง

บางเวอร์ชันของ SeaMeet ยอมให้ปรับแต่งอินเทอร์เฟซได้

การตั้งค่าธีม

Light Mode:

  • พื้นหลังสีขาว/เทาอ่อน
  • ข้อความสีเข้ม
  • มาตรฐานสำหรับการใช้กลางวัน

Dark Mode:

  • พื้นหลังสีเทาเข้ม/ดำ
  • ข้อความสีอ่อน
  • สบายตามากขึ้นในแสงน้อย
  • อาจประหยัดแบตเตอรี่บนหน้าจอ OLED

วิธีเปลี่ยน:

  1. ตั้งค่า → Language & Appearance
  2. เลือก "Light" หรือ "Dark"
  3. หรือ "Auto" เพื่อทำตามการตั้งค่าระบบ

ความกว้างของแถบด้านข้าง (หากปรับได้)

วิธีปรับขนาด:

  1. หาขอบระหว่างแถบด้านข้างและพื้นที่หลัก
  2. เคอร์เซอร์เปลี่ยนเป็นเคอร์เซอร์ปรับขนาด (↔️)
  3. ลากซ้ายหรือขวา
  4. ปล่อยเพื่อตั้งความกว้างใหม่

เคล็ดลับการนำทางอินเทอร์เฟซ

การเคลื่อนไหวอย่างรวดเร็ว

1. ใช้แป้นพิมพ์ลัด

  • เร็วกว่าเมาส์สำหรับการกระทำทั่วไป
  • Space สำหรับเล่น/หยุด
  • ลูกศรสำหรับการนำทาง
  • ดูบทที่ 15 สำหรับรายการเต็ม

2. คลิกขวาเพื่อเมนูบริบท

  • การบันทึกมีเมนูคลิกขวา
  • เข้าถึงการกระทำทั่วไปอย่างรวดเร็ว
  • ตัวเลือกที่แตกต่างในพื้นที่ที่แตกต่าง

3. มองหาทูลทิปเมื่อโฮเวอร์

  • โฮเวอร์เหนือปุ่มเพื่อดูว่าทำอะไร
  • มีประโยชน์โดยเฉพาะอย่างยิ่งสำหรับปุ่มที่มีเฉพาะไอคอน
  • แสดงแป้นพิมพ์ลัดถ้ามี

4. ใช้กล่องค้นหา

  • วิธีที่เร็วที่สุดในการหาการบันทึก
  • ทำงานแบบเรียลไทม์
  • ค้นหาชื่อและแหล่ง

ทำความเข้าใจข้อเสนอแนะภาพ

สีหมายถึงสิ่งต่าง ๆ:

  • สีแดง: การบันทึก ข้อผิดพลาด หยุด
  • สีเขียว: พร้อม สำเร็จ ทำงาน
  • สีเหลือง/อำพัน: คำเตือน กำลังเติม ระวัง
  • สีเทา: ปิดใช้งาน ไม่ทำงาน ปิด
  • สีน้ำเงิน: ข้อมูล ลิงก์ การเลือก

แอนิเมชันหมายถึงสิ่งต่าง ๆ:

  • เต้น: กำลังโหลด กำลังเติม กำลังดำเนินการ
  • คงที่: พร้อม เสร็จสมบูรณ์ มั่นคง
  • กระพริบ: เร่งด่วน ต้องการความสนใจ

โหมด Lite กับ Full

SeaMeet มาพร้อมกับสองโหมดอินเทอร์เฟซ พวกเขาแชร์เครื่องยนต์การบันทึกเดียวกัน ไฟล์เดียวกันบนดิสก์ และไอคอนถาดเดียวกัน — แต่พวกเขาเปิดเผยปริมาณ UI ที่แตกต่างกันมาก

การเลือกโหมด

ในการเปิดตัวครั้งแรกสะอาด SeaMeet แสดง ตัวเลือกโหมด ถามคุณว่าต้องการประสบการณ์ใด ผู้ใช้ v2.x ที่มีอยู่ที่อัปเกรดจะถูกย้ายไปยังโหมด Full อย่างเงียบ ๆ (เพื่อไม่มีอะไรเปลี่ยนแปลงอย่างเห็นได้ชัด) แต่ทุกคนสามารถสลับในภายหลังจาก ตั้งค่า

โหมดที่เลือกถูกคงไว้เป็น appMode: 'full' | 'lite' ในการตั้งค่า UI ของคุณ การสลับโหมดในขณะที่การบันทึกกำลังดำเนินอยู่จะถูกระงับจนกว่าการบันทึกจะสิ้นสุดเพื่อให้คุณไม่สูญเสียการจับภาพ; modal ตั้งค่าปิดทันทีเพื่อให้สปินเนอร์ "Saving…" มองเห็นได้ระหว่างการรอ

โหมด Full (ค่าเริ่มต้น)

นี่คือบทที่คุณอ่านมาจนถึงตอนนี้ — แถบด้านข้าง + Capture Hub + พื้นที่เนื้อหาหลัก สถานะทั้งหมด (การบันทึก การเล่น ตั้งค่า) ครอบคลุมในส่วนด้านบน โหมด Full รวมถึง:

  • Capture Hub พร้อมตัวควบคุม Flashback และภาพหน้าจอ
  • แถบด้านข้างเต็มพร้อมการ์ดการบันทึก ค้นหา เรียงลำดับและกรอง
  • โน้ตและ Wiki (ดูบท 16–17)
  • คลังสื่อ (บท 10)
  • หมวดหมู่ตั้งค่าทั้งหมด (บท 18+)
  • เวิร์กสเปซแบบ local-first (ดู "Workspaces" ด้านล่าง)

ใช้โหมด Full เมื่อ SeaMeet เป็นพื้นผิวการบันทึกหลักของคุณและคุณต้องการโน้ต wiki ตัวแทน และการจัดการคลังในหน้าต่างเดียว

โหมด Lite

โหมด Lite คือพื้นที่ผิวเล็กกว่ามากที่มีศูนย์กลางอยู่ที่ถาดระบบและรายการการประชุมที่สนับสนุนโดยคลาวด์เดียว ไม่มีแถบด้านข้าง ไม่มีมุมมองโน้ต ไม่มี wiki ไม่มี Capture Hub — การบันทึกเริ่มจากถาด (หรือ auto-detect หรือฮอตคีย์) และการบันทึกที่เสร็จสมบูรณ์ถูกแสดงเป็นการ์ดการประชุมเมื่อไปป์ไลน์สรุปหลังการประชุมได้อัปโหลดไปยังเวิร์กสเปซ SeaMeet ของคุณ

ส่วนหัวเวิร์กสเปซใน Lite:

ด้านบนสุดของหน้าต่าง Lite คือ ตัวสลับเวิร์กสเปซ (ปุ่มที่แสดงชื่อเวิร์กสเปซที่ใช้งานพร้อมอวตารและ chevron) การคลิกเปิดดรอปดาวน์ของทุกเวิร์กสเปซที่คุณมีสิทธิ์เข้าถึงบนคลาวด์ SeaMeet การเลือกเวิร์กสเปซอื่น:

  1. คงรหัสเวิร์กสเปซใหม่ไว้ในเครื่อง
  2. รีเฟรชรายการการประชุม
  3. ส่งชื่อเวิร์กสเปซใหม่ไปยังเมนูถาดเพื่อให้การบันทึกที่เริ่มจากถาดไปยังที่ที่ถูกต้องด้วย
  4. รีเซ็ตการแบ่งหน้าเป็นหน้า 1

การออกจากระบบล้างส่วนหัวเวิร์กสเปซของถาด (traySetWorkspaceDisplay(null, null)) ดังนั้นเมนูจึงไม่เคยโกหกเกี่ยวกับเวิร์กสเปซที่คุณไม่มีสิทธิ์เข้าถึงอีกต่อไป

การบันทึกใน Lite:

  • คลิกไอคอนถาดและเลือก Record audio / fullscreen / region — หรือใช้ฮอตคีย์ระดับโลก
  • Recording View ของ Lite เข้าครอบครองหน้าต่างหลักพร้อมคลื่นเสียงสด ตัวจับเวลา และตัวควบคุม Stop เดียว
  • เมื่อคุณหยุด ไฟล์ถูกบันทึกในเครื่อง และ อัปโหลดไปยังเวิร์กสเปซ SeaMeet ของคุณสำหรับการถอดความและการสรุป
  • เมื่อไปป์ไลน์คลาวด์เสร็จสิ้น การ์ดการประชุมปรากฏในรายการ

ใช้โหมด Lite เมื่อ SeaMeet เป็นตัวบันทึกพื้นหลังที่ป้อนคลาวด์ SeaMeet — คุณต้องการให้ถาดทำงานและรายการการประชุมที่สะอาดเพื่อตรวจสอบ

การสลับระหว่างโหมด

เปิด ตั้งค่า (ในโหมดใดก็ตาม) หาการกระทำ "Switch to Full / Lite mode" และยืนยัน SeaMeet หมดการบันทึกที่กำลังดำเนินอยู่ จากนั้น relaunch renderer เป็นโหมดอื่น ไฟล์ เวิร์กสเปซ การตั้งค่า และไอคอนถาดของคุณรอดชีวิตจากการสลับ

เวิร์กสเปซ

SeaMeet มี แนวคิดเวิร์กสเปซที่แตกต่างกันสองแบบ ที่แชร์ชื่อแต่อยู่ในที่ต่าง ๆ การเข้าใจว่าใครเป็นใครหลีกเลี่ยงความสับสน

Local Workspaces (โหมด Full)

ในโหมด Full เวิร์กสเปซคือ vault สไตล์ Obsidian — โฟลเดอร์บนดิสก์ที่เก็บโน้ต wiki ที่สร้างขึ้น และ (โดยค่าเริ่มต้น) การบันทึกของคุณ WorkspaceManager ในกระบวนการหลักเป็นเจ้าของ:

  • รีจิสทรี ของเวิร์กสเปซ ({ id, name, path, isDefault? }[]) คงไว้ในไฟล์ตั้งค่าของคุณ
  • รหัสเวิร์กสเปซที่ใช้งาน (เพียงหนึ่งเดียวที่ใช้งานในเวลาเดียวกัน)
  • ตัวเฝ้าดูไฟล์ chokidar บนเส้นทางของเวิร์กสเปซที่ใช้งาน พร้อม polling เปิดอัตโนมัติสำหรับโวลุมภายนอกและการเมาท์เครือข่าย (เช่น macOS /Volumes/, ~/Library/CloudStorage/GoogleDrive-<email>/… ของ Google Drive) ที่ FSEvents ทำงานไม่น่าเชื่อถือ
  • สถานะต่อเวิร์กสเปซ (โน้ตที่เปิดล่าสุด ไฟล์ล่าสุด ฯลฯ) ภายใต้ userData/workspace-state/<id>.json

ในการเปิดตัวครั้งแรก หากไม่มีเวิร์กสเปซที่ลงทะเบียน SeaMeet สร้างเวิร์กสเปซ Default อันเดียวโดยอัตโนมัติชี้ไปที่ไดเรกทอรีบันทึกของคุณ ชื่อ "Default" แปลเป็น 23 ภาษา

ทั้งมุมมองโน้ต (บท 16) และมุมมอง Wiki (บท 17) แสดง <WorkspaceSwitcher> ที่ด้านบนของแผนผังไฟล์:

│    Personal      ~/Notes/Personal│

  • คลิกแถวที่ใช้งาน เพื่อเปิดดรอปดาวน์
  • คลิกเวิร์กสเปซอื่น เพื่อสลับไปยังมัน — ตัวเฝ้าดูไฟล์ฉีกออก เส้นทางของเวิร์กสเปซใหม่ถูกเมาท์ โน้ตและ Wiki รีเฟรช และสถานะต่อเวิร์กสเปซถูกคืนสภาพ
  • เพิ่มเวิร์กสเปซ… เปิดตัวเลือกโฟลเดอร์เนทีฟเพื่อให้คุณสามารถลงทะเบียนไดเรกทอรีใดก็ได้เป็น vault (ตรวจสอบความไม่ซ้ำกัน — การลงทะเบียนเส้นทางเดียวกันสองครั้งถูกปฏิเสธ)
  • Remove (×) บนแถวลบรายการ SeaMeet เท่านั้น; ไฟล์บนดิสก์ไม่ถูกแตะ คุณไม่สามารถลบเวิร์กสเปซสุดท้ายได้
  • แต่ละแถวอาจแสดง ป้ายคลาวด์ (Dropbox, iCloud, OneDrive, Google Drive) และ ป้ายรีโมต git เมื่อการตรวจจับการซิงค์พบ

Cloud Workspaces (โหมด Lite)

ในโหมด Lite (และใน builds Full ที่เปิดใช้งานคลาวด์) เวิร์กสเปซหมายถึงสิ่งที่แตกต่าง: ทีมเวิร์กสเปซบนคลาวด์ SeaMeet ส่วนประกอบ <WorkspacePicker> ดึงเวิร์กสเปซที่คุณสามารถเข้าถึงได้ผ่าน SeaMeet API และคงไว้ที่เลือกสำหรับการกำหนดเส้นทางการอัปโหลด

เวิร์กสเปซคลาวด์ขับเคลื่อน:

  • เวิร์กสเปซใดที่การบันทึกใหม่อัปโหลดไป
  • การประชุมของเวิร์กสเปซใดปรากฏในรายการการประชุม Lite
  • แถวส่วนหัวเวิร์กสเปซ ในเมนูถาด (เพื่อให้คุณสามารถเห็นในพริบตาว่าการบันทึกที่เริ่มจากถาดถัดไปจะไปที่ใด)

ตัวเลือกคลาวด์กรองเวิร์กสเปซที่ my_status ของคุณเป็น INACTIVE ในการเข้าสู่ระบบครั้งแรก หากเวิร์กสเปซที่คุณเลือกไว้ก่อนหน้านี้ไม่อยู่ในรายการที่ส่งคืน (คุณสูญเสียสมาชิกภาพ schema drift ฯลฯ) ตัวเลือกเลือกเวิร์กสเปซแรกที่มีอยู่โดยอัตโนมัติและคงไว้ — ดังนั้นเมนูไม่สามารถถูกผูกติดอยู่กับ ID ที่เข้าถึงไม่ได้

ทั้งสองพร้อมกัน

ใน build Full ที่เปิดใช้งานคลาวด์คุณสามารถมี ทั้งสอง ประเภทของเวิร์กสเปซที่เลือกพร้อมกัน: vault ในเครื่องที่เก็บโน้ตของคุณและเวิร์กสเปซคลาวด์ SeaMeet ที่รับการอัปโหลดของคุณ พวกเขาเป็นอิสระ — การสลับหนึ่งไม่ได้สลับอีกอัน
