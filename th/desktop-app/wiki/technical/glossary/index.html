อภิธานศัพท์

บทที่ 30: อภิธานศัพท์

บทนำ

ซอฟต์แวร์บันทึก เช่นเดียวกับสาขาเทคนิคใดๆ มาพร้อมกับคำศัพท์ของตัวเอง คำเช่น "codec," "bitrate," "frame rate," และ "encoding" ถูกใช้ตลอดเวลา บทนี้เป็นพจนานุกรมที่ครอบคลุมของคุณ — อธิบายทุกคำศัพท์ทางเทคนิคที่คุณอาจพบเมื่อใช้ SeaMeet หรืออ่านเกี่ยวกับการบันทึกเสียง/วิดีโอ

ไม่ต้องกังวลหากคุณไม่ใช่ผู้เชี่ยวชาญทางเทคนิค แต่ละคำอธิบายเป็นภาษาง่ายๆ พร้อมการเปรียบเทียบเพื่อช่วยให้คุณเข้าใจ ใช้บทนี้เป็นข้อมูลอ้างอิงเมื่อใดก็ตามที่คุณพบคำที่ไม่คุ้นเคย

วัตถุประสงค์ของบท

หลังจากอ่านบทนี้ คุณจะสามารถ:

  • เข้าใจคำศัพท์ทางเทคนิคที่ใช้ใน SeaMeet
  • ทราบความแตกต่างระหว่างคำศัพท์ที่มักสับสน
  • ใช้คำศัพท์ที่ถูกต้องเมื่อแก้ไขปัญหา
  • ตัดสินใจอย่างมีข้อมูลตามแนวคิดทางเทคนิค

A

Audio Buffer (บัฟเฟอร์เสียง)

ที่จัดเก็บชั่วคราวสำหรับข้อมูลเสียงก่อนที่จะถูกประมวลผลหรือบันทึก เหมือนห้องรอที่ตัวอย่างเสียงต่อแถวก่อนถูกเข้ารหัส

Audio Interface (อินเทอร์เฟซเสียง)

ฮาร์ดแวร์ที่เชื่อมต่อไมโครโฟนและเครื่องดนตรีกับคอมพิวเตอร์ของคุณ มักให้คุณภาพเสียงที่ดีกว่าการ์ดเสียงในตัว

Action Items (รายการดำเนินการ) (AI)

งานที่ระบุโดย AI Extraction จากการบันทึก แต่ละรายการดำเนินการรวมถึงคำอธิบายงาน คนที่ได้รับมอบหมาย และวันครบกำหนด (หากกล่าวถึงในการสนทนา) ดูบทที่ 32

AI Extraction (การสกัด AI)

ฟีเจอร์การวิเคราะห์หลังการบันทึกของ SeaMeet หลังจากการบันทึกสิ้นสุด การคลิก ✨ Generate Summary ส่งเสียงไปยังเอ็นจิน AI ซึ่งจะส่งคืนผลลัพธ์ที่มีโครงสร้างห้ารายการ: Transcript, Summary, Action Items, Key Decisions, และ Chapters ดูบทที่ 32

AI Insights

แผงใน SeaMeet ที่แสดงผลลัพธ์ที่ AI สร้างขึ้นทั้งหมดสำหรับการบันทึก เข้าถึงได้จากมุมมองรายละเอียดการบันทึก ประกอบด้วยแท็บสำหรับ Transcript, Summary, Actions, Decisions และ Chapters

Audio Track (แทร็กเสียง)

สตรีมเสียงแยกต่างหากภายในไฟล์วิดีโอ วิดีโอหนึ่งอาจมีหลายแทร็ก: ไมโครโฟนของคุณ เสียงระบบ เพลงพื้นหลัง

Auto-Detection (การตรวจจับอัตโนมัติ)

ฟีเจอร์ของ SeaMeet ที่จดจำเมื่อคุณเข้าร่วมการประชุมโดยอัตโนมัติและสามารถเริ่มบันทึกได้โดยไม่ต้องแทรกแซงด้วยตนเอง

Auto-pick (การเลือกอัตโนมัติ)

ตัวจำแนกที่เลือก AI Summary Template ที่เหมาะสมที่สุดโดยอัตโนมัติตามเนื้อหาของการบันทึก เมื่อคุณสร้างสรุปใหม่ Auto-pick จะวิเคราะห์ transcript และเลือกเทมเพลตที่เหมาะสมที่สุด (เช่น standup, sales call, interview) ดังนั้นคุณจึงไม่ต้องเลือกด้วยตนเอง ดูบทที่ 33

AVI (Audio Video Interleave)

รูปแบบไฟล์วิดีโอเก่าที่พัฒนาโดย Microsoft ทำงานได้ดีบน Windows แต่เข้ากันได้น้อยกว่ากับอุปกรณ์สมัยใหม่

B

Bit

หน่วยข้อมูลดิจิทัลที่เล็กที่สุด อาจเป็น 0 หรือ 1 ทุกอย่างในคอมพิวเตอร์ของคุณประกอบด้วยบิต

BYOK (Bring Your Own Key)

รูปแบบการสมัครสมาชิกของ SeaMeet ที่ผู้ใช้จัดหา LLM API keys ของตนเอง (เช่น OpenAI, Anthropic, Google) แทนที่จะจ่ายค่าการอนุมานผ่าน SeaMeet ค่าใช้จ่ายจะถูกเรียกเก็บโดยตรงจากผู้ให้บริการ; SeaMeet เรียกเก็บเฉพาะค่าแอปเท่านั้น

Bit Depth (ความลึกบิต) (เสียง)

จำนวนบิตที่ใช้แทนตัวอย่างเสียงแต่ละตัว ความลึกบิตที่สูงกว่า = รายละเอียดมากขึ้น = ไฟล์ใหญ่ขึ้น คุณภาพ CD คือ 16-bit

Bitrate (อัตราบิต)

ปริมาณข้อมูลที่ประมวลผลต่อวินาที โดยปกติวัดเป็นกิโลบิตต่อวินาที (kbps) หรือเมกะบิตต่อวินาที (Mbps) สูงกว่า = คุณภาพดีกว่า = ไฟล์ใหญ่ขึ้น

Bluetooth Latency (ความหน่วง Bluetooth)

ความล่าช้าระหว่างเมื่อเสียงถูกสร้างขึ้นและเมื่อคุณได้ยินผ่านการเชื่อมต่อ Bluetooth โดยทั่วไป 100-300ms ซึ่งทำให้เกิดปัญหาการซิงค์

Buffer (บัฟเฟอร์)

พื้นที่จัดเก็บชั่วคราวที่เก็บข้อมูลในขณะที่ถูกถ่ายโอนหรือประมวลผล เหมือนอ่างเก็บน้ำที่เก็บน้ำก่อนจะไหลผ่านท่อ

Buffer Duration (ระยะเวลาบัฟเฟอร์) (Flashback)

SeaMeet เก็บภาพไว้กี่วินาทีใน circular buffer เมื่อคุณบันทึก Flashback คุณจะได้รับจำนวนภาพในอดีตนี้

Byte

กลุ่ม 8 bits หน่วยมาตรฐานสำหรับการวัดขนาดไฟล์ หนึ่งเมกะไบต์ (MB) เท่ากับประมาณหนึ่งล้านไบต์

C

Circular Buffer

ประเภทของบัฟเฟอร์ที่วนกลับไปยังจุดเริ่มต้นเมื่อถึงจุดสิ้นสุด SeaMeet ใช้สิ่งนี้สำหรับ Flashback — บันทึกอย่างต่อเนื่องและเขียนทับข้อมูลเก่า

Codec (Coder-Decoder)

ซอฟต์แวร์ที่บีบอัดและคลายการบีบอัดเสียงหรือวิดีโอ H.264 เป็น codec วิดีโอ MP3 เป็น codec เสียง

Codec vs. Container

Codec คือวิธีการบีบอัด (วิธีการบีบข้อมูล) Container คือรูปแบบไฟล์ (กล่องที่เก็บข้อมูล) MP4 คือ container ที่มักเก็บวิดีโอ H.264

Compression (การบีบอัด)

การลดขนาดไฟล์โดยการลบข้อมูลที่ซ้ำซ้อนหรือไม่สำคัญ อาจเป็นแบบไม่มีการสูญเสีย (ไม่มีการสูญเสียคุณภาพ) หรือสูญเสีย (สูญเสียคุณภาพบางส่วนแต่ไฟล์เล็กลง)

Chapters (บทต่างๆ) (AI)

หนึ่งในห้าผลลัพธ์ของ AI Extraction ส่วนหัวข้อที่จัดทำดัชนีตามเวลา คล้ายกับบทในหนังสือ การคลิกบทในแผง AI Insights จะข้ามเครื่องเล่นไปยังช่วงเวลานั้นในการบันทึก ดูบทที่ 32

Chunked Pipeline (ไปป์ไลน์แบบแบ่งส่วน)

กลยุทธ์การสกัด AI ที่ประมวลผลวิดีโอยาวเป็นชิ้นๆ ขนาด 10 นาทีเพื่ออยู่ใน Gemini context window ชิ้นแต่ละชิ้นจะถูก transcribed และ summarized แยกกัน จากนั้นรวมเข้าเป็นผลลัพธ์ที่สอดคล้องกันเพียงรายการเดียว ใช้โดยอัตโนมัติสำหรับการบันทึกที่เกินความจุการผ่านเดียวของโมเดล

Conflict Resolution Modal (Modal การแก้ไขความขัดแย้ง)

กล่องโต้ตอบที่ปรากฏเมื่อ GitHub Sync ตรวจพบว่า note เดียวกันถูกแก้ไขแตกต่างกันบนอุปกรณ์สองเครื่อง ให้คุณเลือกเวอร์ชันที่จะเก็บไว้ หรือผสานการเปลี่ยนแปลงด้วยตนเอง ดูบทที่ 38

CPU (Central Processing Unit)

"สมอง" ของคอมพิวเตอร์ของคุณ ทำการคำนวณและรันโปรแกรม ซอฟต์แวร์บันทึกใช้ CPU เพื่อเข้ารหัสวิดีโอ

Cursor Highlighting (การไฮไลต์เคอร์เซอร์)

เอฟเฟกต์ภาพที่ดึงความสนใจไปที่เคอร์เซอร์เมาส์ของคุณในการบันทึก มีประโยชน์สำหรับบทแนะนำเพื่อให้ผู้ดูสามารถติดตามการกระทำของคุณได้

D

Decibel (dB)

หน่วยสำหรับวัดระดับความดังของเสียง ใช้ในมิเตอร์ระดับเสียงของ SeaMeet -12 dB เป็นระดับการบันทึกที่ดี 0 dB เป็นค่าสูงสุด (บิดเบือน)

Default Device (อุปกรณ์เริ่มต้น)

อุปกรณ์เสียงหรือวิดีโอที่ Windows/macOS ใช้โดยอัตโนมัติ SeaMeet สามารถใช้ค่าเริ่มต้นหรือให้คุณเลือกอุปกรณ์เฉพาะ

Detection Method (วิธีการตรวจจับ) (Auto-Detection)

วิธีที่ SeaMeet รับรู้ว่าคุณอยู่ในการประชุม วิธีการรวมถึงการวิเคราะห์ชื่อหน้าต่าง การตรวจสอบโปรเซส และการตรวจจับเสียง

Digital Audio (เสียงดิจิทัล)

เสียงที่แสดงเป็นตัวเลข คอมพิวเตอร์ของคุณแปลงคลื่นเสียงเป็นตัวอย่างดิจิทัล (ตัวเลข) ที่สามารถจัดเก็บและประมวลผลได้

Disk Space (พื้นที่ดิสก์)

ปริมาณการจัดเก็บที่มีอยู่บนฮาร์ดไดรฟ์หรือ SSD ของคุณ การบันทึกวิดีโอต้องการพื้นที่ดิสก์จำนวนมาก

DRM (Digital Rights Management)

เทคโนโลยีที่ป้องกันการคัดลอกเนื้อหาที่ได้รับการป้องกัน Netflix, DVD และบริการสตรีมมิ่งบางตัวใช้ DRM ซึ่งป้องกันการบันทึกหน้าจอ

Decisions (การตัดสินใจ) (AI)

หนึ่งในห้าผลลัพธ์ของ AI Extraction รายการของการเลือกและข้อตกลงที่สำคัญที่ทำในระหว่างการประชุม สกัดจากการสนทนา แตกต่างจาก Action Items — decisions คือ สิ่งที่ตกลงกัน actions คือ สิ่งที่ต้องทำเป็นผล ดูบทที่ 32

Drop Frame (เฟรมที่หายไป)

เมื่อการบันทึกวิดีโอพลาดเฟรม ทำให้เกิดการกระตุก โดยปกติเกิดขึ้นเมื่อคอมพิวเตอร์ไม่สามารถตามทันความต้องการการเข้ารหัสได้

E

Echo Cancellation (การยกเลิกเสียงสะท้อน)

เทคโนโลยีที่ลบเสียงสะท้อนออกจากการบันทึก มีประโยชน์เมื่อใช้ลำโพงแทนหูฟัง — ป้องกันไมโครโฟนของคุณจากการรับเสียงลำโพง

Encode (เข้ารหัส)

กระบวนการแปลงวิดีโอ/เสียงดิบเป็นรูปแบบที่บีบอัด CPU หรือ GPU ทำสิ่งนี้แบบเรียลไทม์ในขณะที่คุณบันทึก

Encoder (ตัวเข้ารหัส)

ซอฟต์แวร์หรือฮาร์ดแวร์ที่ทำการเข้ารหัส SeaMeet ใช้ตัวเข้ารหัสซอฟต์แวร์ (CPU) หรือตัวเข้ารหัสฮาร์ดแวร์ (GPU)

External Drive (ไดรฟ์ภายนอก)

ฮาร์ดไดรฟ์หรือ SSD ที่เชื่อมต่อผ่าน USB สามารถใช้เก็บการบันทึกได้แต่อาจช้ากว่าไดรฟ์ภายใน

F

Flashback

ฟีเจอร์ time-machine ของ SeaMeet ที่บันทึกอย่างต่อเนื่องใน circular buffer ให้คุณบันทึกช่วงเวลาจากอดีต

Flashback Buffer

หน่วยความจำชั่วคราวที่ใช้โดย Flashback เก็บวิดีโอ/เสียงในช่วง X วินาทีล่าสุด

Floater (SeaMeet Floater)

วิดเจ็ตลอยที่ปรากฏบนหน้าจอของคุณสำหรับตัวควบคุมการบันทึกอย่างรวดเร็ว สามารถย่อเป็นไอคอนเล็กหรือขยายเพื่อตัวควบคุมเต็มรูปแบบ

FPS (Frames Per Second - เฟรมต่อวินาที)

จำนวนภาพนิ่ง (เฟรม) ที่ถูกจับต่อวินาทีเพื่อสร้างวิดีโอ 30fps เป็นมาตรฐาน 60fps ราบรื่นกว่า

Fullscreen Recording (การบันทึกแบบเต็มหน้าจอ)

โหมดการบันทึกที่จับหน้าจอทั้งหมดของคุณ มีประโยชน์สำหรับการประชุมและเมื่อคุณต้องการจับทุกอย่าง

Frame (เฟรม)

ภาพนิ่งเดียวในวิดีโอ วิดีโอเป็นชุดของเฟรมที่เล่นอย่างรวดเร็ว (30-60 ต่อวินาที) เพื่อสร้างการเคลื่อนไหว

Fuzzy Search (การค้นหาแบบฟัซซี่)

การค้นหาที่จัดอันดับตามความเกี่ยวข้องใน sidebar และ Media Library ที่พบการจับคู่แม้ว่าคำค้นหาจะสะกดผิดหรือทับซ้อนกับชื่อเรื่องเพียงบางส่วน แทนที่การจับคู่ substring แบบเดิม ดังนั้น "qrtly review" ยังคงพบ "Quarterly Review" ดูบทที่ 10

G

Gain (เกน)

ระดับการขยายของสัญญาณเสียง การเพิ่ม gain ทำให้เสียงดังขึ้นในการบันทึก แตกต่างจากระดับเสียง (ซึ่งมีผลต่อการเล่น)

Game Mode (โหมดเกม)

ฟีเจอร์ Windows ที่ให้ความสำคัญกับแอปเกม สามารถช่วยประสิทธิภาพการบันทึกได้แต่บางครั้งขัดแย้งกับซอฟต์แวร์บันทึก

GitHub Sync

ฟีเจอร์ซิงค์ข้ามอุปกรณ์ของ SeaMeet ที่สนับสนุนโดยที่เก็บ GitHub ส่วนตัว Notes และเมตาดาต้าจะ commit ไปยัง repo ของคุณ ดังนั้น workspace เดียวกันจะใช้ได้บนทุกเครื่องที่คุณติดตั้ง SeaMeet ดูบทที่ 38

GPU (Graphics Processing Unit)

การ์ดกราฟิกในคอมพิวเตอร์ของคุณ สามารถใช้สำหรับการเข้ารหัสวิดีโอที่เร่งด้วยฮาร์ดแวร์ (เร็วกว่า CPU มาก)

GPU Encoding (การเข้ารหัส GPU)

ใช้การ์ดกราฟิกแทน CPU เพื่อเข้ารหัสวิดีโอ เรียกอีกอย่างว่าการเร่งฮาร์ดแวร์ เร็วกว่าและมีประสิทธิภาพมากกว่า

H

H.264 (AVC)

codec วิดีโอที่พบบ่อยที่สุด ให้คุณภาพที่ดีที่ขนาดไฟล์ที่เหมาะสม ทำงานได้บนเกือบทุกอุปกรณ์

H.265 (HEVC)

codec วิดีโอที่ใหม่กว่าและมีประสิทธิภาพมากกว่า สร้างไฟล์ที่เล็กกว่า H.264 ประมาณ 50% ที่คุณภาพเดียวกัน การรองรับสากลน้อยกว่า

Hardware Acceleration (การเร่งฮาร์ดแวร์)

ใช้ฮาร์ดแวร์เฉพาะ (เช่น GPU) เพื่อทำงานแทน CPU ทั่วไป ทำให้การเข้ารหัสวิดีโอเร็วขึ้นมาก

Hardware Encoder (ตัวเข้ารหัสฮาร์ดแวร์)

ชิปเฉพาะบน GPU ที่เข้ารหัสวิดีโอ NVIDIA เรียกของเขาว่า NVENC Intel เรียกของเขาว่า Quick Sync

HD (High Definition - ความละเอียดสูง)

ความละเอียดวิดีโอ 1280×720 (720p) หรือสูงกว่า ให้วิดีโอที่ชัดเจน มีรายละเอียด

Headphones vs. Speakers (หูฟัง vs. ลำโพง)

การใช้หูฟังในขณะบันทึกป้องกันเสียงสะท้อน (เสียงจากลำโพงที่ถูกไมโครโฟนรับ) แนะนำสำหรับคุณภาพเสียงที่ดีที่สุด

I

I-Frame (Intra-frame)

เฟรมวิดีโอที่สมบูรณ์ที่ไม่พึ่งพาเฟรมอื่น ทำหน้าที่เป็นจุดอ้างอิง ขนาดไฟล์ใหญ่กว่าแต่จำเป็นสำหรับการ seeking

Import (นำเข้า)

นำไฟล์เสียงหรือวิดีโอภายนอกเข้าสู่ SeaMeet SeaMeet สามารถนำเข้ารูปแบบต่างๆ สำหรับการเล่นและการจัดการ

Input Device (อุปกรณ์อินพุต)

ฮาร์ดแวร์ที่ส่งเสียง/วิดีโอเข้าสู่คอมพิวเตอร์ของคุณ ไมโครโฟน กล้อง และการ์ด capture เป็นอุปกรณ์อินพุต

J

Jitter

การเปลี่ยนแปลงเวลาของข้อมูลเสียง/วิดีโอ ทำให้การเล่นกระตุกหรือไม่สม่ำเสมอ โดยปกติเกิดจากปัญหาประสิทธิภาพระบบ

Join a Meeting (เข้าร่วมการประชุม)

เข้าสู่การประชุมออนไลน์ผ่าน Zoom, Teams, Meet เป็นต้น SeaMeet สามารถตรวจจับเมื่อคุณเข้าร่วมและเริ่มบันทึกได้โดยอัตโนมัติ

K

Kbps (Kilobits per second - กิโลบิตต่อวินาที)

การวัดอัตราข้อมูล ใช้สำหรับ bitrate เสียง 128 kbps เป็นมาตรฐานสำหรับ MP3 192 kbps เป็นคุณภาพที่สูงกว่า

Keyframe (เฟรมหลัก)

ดู I-Frame เฟรมวิดีโอที่สมบูรณ์ใช้เป็นจุดอ้างอิง

Keyboard Shortcuts (ทางลัดคีย์บอร์ด)

ชุดคีย์ที่กระตุ้นการกระทำได้อย่างรวดเร็ว Ctrl+Alt+R เริ่มการบันทึก ทางลัดช่วยประหยัดเวลาเทียบกับการคลิกอินเทอร์เฟซ

L

Latency (ความหน่วง)

ความล่าช้าระหว่างการกระทำและเมื่อถูกประมวลผลหรือได้ยิน หูฟัง Bluetooth มีความหน่วงสูง หูฟังแบบมีสายแทบไม่มีเลย

Live Transcription (การถอดความสด)

ฟีเจอร์ของ SeaMeet ที่แปลงคำพูดเป็นข้อความแบบเรียลไทม์ในระหว่างการบันทึก คำต่างๆ ปรากฏในแผง Transcript เมื่อถูกพูด ติดด้วย timestamp และติดป้ายกำกับผู้พูด ต้องการให้เปิดใช้งานฟีเจอร์ AI และมีการเชื่อมต่ออินเทอร์เน็ต ดูบทที่ 31

Library (Recording Library - ไลบรารีการบันทึก)

คอลเลกชันของการบันทึกทั้งหมดของคุณใน SeaMeet แสดง thumbnails เมตาดาต้า และอนุญาตให้เล่น/จัดการ

Lite Mode (โหมด Lite)

พื้นผิว SeaMeet ที่เล็กกว่าและเน้นที่ tray ตัดหน้าต่างหลักลงเหลือเพียงสิ่งจำเป็น — start/stop recording, recent items, quick settings — และออกแบบมาเพื่ออาศัยอยู่ใน system tray โดยมีร่องรอยบนหน้าจอน้อยที่สุด

Lossless Compression (การบีบอัดแบบไม่สูญเสีย)

การบีบอัดที่ลดขนาดไฟล์โดยไม่สูญเสียข้อมูลใดๆ สามารถสร้างใหม่ได้อย่างสมบูรณ์แบบ เสียง FLAC ใช้การบีบอัดแบบไม่สูญเสีย

Lossy Compression (การบีบอัดแบบสูญเสีย)

การบีบอัดที่ลบข้อมูลบางส่วนออกอย่างถาวรเพื่อให้ได้ไฟล์ที่เล็กกว่า MP3 และ H.264 เป็นแบบสูญเสีย การสูญเสียคุณภาพมักไม่สามารถสังเกตได้

Low-Memory Mode (โหมดหน่วยความจำต่ำ)

ฟีเจอร์ของ SeaMeet ที่ลดคุณภาพเพื่อใช้ RAM น้อยลง มีประโยชน์สำหรับคอมพิวเตอร์เก่าหรือเมื่อรันแอปที่ใช้หน่วยความจำมาก

M

Macroblock

สี่เหลี่ยมพิกเซล 16×16 ที่ใช้ในการบีบอัดวิดีโอ H.264 แบ่งเฟรมเป็น macroblocks เพื่อบีบอัดอย่างมีประสิทธิภาพ

Mbps (Megabits per second - เมกะบิตต่อวินาที)

การวัดอัตราข้อมูลที่ใช้สำหรับวิดีโอ 8 Mbps เหมาะสำหรับวิดีโอ 1080p สูงกว่า = คุณภาพดีกว่า = ไฟล์ใหญ่ขึ้น

MCP Server

เซิร์ฟเวอร์ Model Context Protocol ที่ SeaMeet เปิดเผยเพื่อให้ AI Agent สามารถแสดงรายการเทมเพลต สร้างสรุปใหม่ ดึง transcripts และขับเคลื่อน SeaMeet จากไคลเอนต์ LLM ที่เชื่อมต่อ ทำงานเป็นโปรเซสลูกจาก dist-main/mcp-server.cjs

Media Library (ไลบรารีสื่อ)

เบราว์เซอร์หน้าต่างเต็มเฉพาะสำหรับการบันทึกและภาพหน้าจอ รองรับมุมมองตารางและรายการ ตัวกรอง (วันที่, ระยะเวลา, แท็ก) และการดำเนินการเป็นชุด (ลบ, ส่งออก, แท็ก) แตกต่างจาก Recording Library ของ sidebar ดูบทที่ 10

Metadata (เมตาดาต้า)

ข้อมูลเกี่ยวกับไฟล์ (ไม่ใช่เนื้อหาจริง) รวมถึงวันที่สร้าง ระยะเวลา ความละเอียด เป็นต้น

Microphone Array (อาร์เรย์ไมโครโฟน)

ไมโครโฟนหลายตัวทำงานร่วมกัน แล็ปท็อปบางตัวมีอาร์เรย์ไมโครโฟนสำหรับการรับเสียงที่ดีขึ้นและการยกเลิกเสียงรบกวน

Minimize to Tray (ย่อเป็น Tray)

SeaMeet สามารถทำงานในพื้นหลัง เข้าถึงได้ผ่านไอคอน system tray (ใกล้นาฬิกาของคุณ) ประหยัดพื้นที่ taskbar

MKV (Matroska)

รูปแบบ container วิดีโอที่ยืดหยุ่น รองรับหลายแทร็กเสียงและคำบรรยาย ดีสำหรับการเก็บข้อมูล

Monitor (จอภาพ)

หน้าจอคอมพิวเตอร์ของคุณ SeaMeet สามารถบันทึกหนึ่งจอภาพหรือทั้งหมดหากคุณมีหลายจอ

Mono vs. Stereo

Mono = 1 ช่องเสียง Stereo = 2 ช่อง (ซ้ายและขวา) Stereo ฟังดูดื่มด่ำกว่าแต่สร้างไฟล์ที่ใหญ่กว่า

MOV

รูปแบบ container วิดีโอของ Apple พบบ่อยบน Mac คุณภาพดีแต่เข้ากันได้น้อยกับ Windows โดยไม่ใช้ซอฟต์แวร์เพิ่มเติม

MP3

รูปแบบเสียงที่ได้รับความนิยมมากที่สุด ใช้การบีบอัดแบบสูญเสีย ไฟล์เล็ก ความเข้ากันได้สากล 128-320 kbps ทั่วไป

MP4

รูปแบบ container วิดีโอที่ได้รับความนิยมมากที่สุด ทำงานได้บนเกือบทุกอุปกรณ์ มักประกอบด้วยวิดีโอ H.264 และเสียง AAC

Multi-Monitor (หลายจอภาพ)

ใช้มากกว่าหนึ่งหน้าจอ SeaMeet สามารถบันทึกทุกจอภาพหรือเพียงหนึ่งจอ การบันทึกหลายจอภาพใช้ทรัพยากรมากกว่า

Mute (ปิดเสียง)

ปิดอินพุตหรือเอาต์พุตเสียงชั่วคราว SeaMeet สามารถปิดเสียงการบันทึกโดยไม่กระทบต่อระดับเสียงระบบ

N

Native Resolution (ความละเอียดเนทีฟ)

จำนวนพิกเซลจริงที่หน้าจอของคุณแสดง การบันทึกที่ความละเอียดเนทีฟให้ผลลัพธ์ที่คมชัดที่สุด

Noise Suppression (การระงับเสียงรบกวน)

เทคโนโลยีที่ลบเสียงรบกวนพื้นหลัง (พัดลม, เครื่องปรับอากาศ) ออกจากการบันทึกเสียง ทำให้เสียงชัดเจนขึ้น

Notification (การแจ้งเตือน)

ข้อความ popup ที่แจ้งเตือนคุณถึงเหตุการณ์ SeaMeet แสดงการแจ้งเตือนเมื่อการบันทึกเริ่ม, หยุด หรือเมื่อตรวจพบการประชุม

NVENC

ตัวเข้ารหัสวิดีโอฮาร์ดแวร์ของ NVIDIA มีอยู่ในซีรีส์ GTX 600 และใหม่กว่า การเข้ารหัสที่รวดเร็วมากด้วยการใช้ CPU น้อยที่สุด

O

OAuth Auto-Refresh (การรีเฟรช OAuth อัตโนมัติ)

กลไกการรีเฟรชโทเค็น GitHub Sync ที่ทำงาน 5 นาทีก่อนโทเค็นหมดอายุ ทำให้เซสชันการซิงค์ทำงานอยู่โดยไม่บังคับให้ผู้ใช้ต้องตรวจสอบสิทธิ์ใหม่ ทำให้ Sync State Machine กลับสู่ synced โดยไม่มีการหยุดชะงักที่มองเห็นได้ ดูบทที่ 38

Ogg

รูปแบบเสียงโอเพนซอร์ส การบีบอัดที่ดีแต่การรองรับอุปกรณ์จำกัด มักใช้ codec Vorbis

Output Device (อุปกรณ์เอาต์พุต)

ฮาร์ดแวร์ที่เล่นเสียงจากคอมพิวเตอร์ของคุณ ลำโพงและหูฟังเป็นอุปกรณ์เอาต์พุต

Overhead (CPU/หน่วยความจำ)

ทรัพยากรที่ใช้โดยซอฟต์แวร์บันทึกเอง แยกจากการบันทึกจริง SeaMeet มี overhead ต่ำ

P

P-Frame (Predicted Frame - เฟรมที่ทำนาย)

เฟรมวิดีโอที่เก็บเฉพาะการเปลี่ยนแปลงจากเฟรมก่อนหน้า เล็กกว่า I-Frames มาก สร้างการบีบอัดที่มีประสิทธิภาพ

PCM (Pulse Code Modulation)

รูปแบบเสียงดิจิทัลที่ไม่บีบอัด ใช้ภายในก่อนการเข้ารหัสเป็น MP3 หรือรูปแบบอื่นๆ คุณภาพสูง ไฟล์ใหญ่

Permissions (สิทธิ์)

การอนุญาตให้เข้าถึงทรัพยากรระบบ macOS และ Windows ต้องการให้คุณให้สิทธิ์ SeaMeet เพื่อบันทึกหน้าจอและเสียง

Pixel

จุดสีเดียวบนหน้าจอของคุณ รูปภาพประกอบด้วยพิกเซลหลายพันหรือหลายล้านพิกเซล 1920×1080 = ประมาณ 2 ล้านพิกเซล

Playback (การเล่น)

การดูหรือฟังการบันทึก SeaMeet มีเครื่องเล่นในตัวสำหรับการตรวจสอบการบันทึก

Pop Filter (ตัวกรอง Pop)

ฝาครอบโฟมหรือตาข่ายสำหรับไมโครโฟนที่ลดเสียง "p" และ "b" popping ปรับปรุงคุณภาพเสียง

Process Monitoring (การตรวจสอบโปรเซส)

วิธีการตรวจจับอัตโนมัติที่เฝ้าดูว่าโปรแกรมใดกำลังทำงาน ตรวจจับเมื่อ zoom.exe หรือ Teams.exe เริ่มต้น

Q

Quantization (การควอนไทซ์)

ลดความแม่นยำของข้อมูลเพื่อประหยัดพื้นที่ ส่วนหนึ่งของการบีบอัด ทำให้สี/เสียงที่เกือบเหมือนกันง่ายขึ้น

Quick Sync

ตัวเข้ารหัสวิดีโอฮาร์ดแวร์ของ Intel สร้างขึ้นในโปรเซสเซอร์ Intel สมัยใหม่ มีประสิทธิภาพและคุณภาพดีสำหรับการบันทึก

R

RAM (Random Access Memory)

หน่วยความจำระยะสั้นของคอมพิวเตอร์ของคุณ SeaMeet ใช้ RAM สำหรับ Flashback buffers และการประมวลผล RAM มากขึ้น = ประสิทธิภาพดีขึ้น

RAW Audio/Video (เสียง/วิดีโอ RAW)

ข้อมูลที่ไม่บีบอัด ไฟล์ใหญ่แต่คุณภาพสูงสุด SeaMeet มักเข้ารหัสเป็นรูปแบบที่บีบอัดเพื่อประหยัดพื้นที่

Real-time (เรียลไทม์)

เกิดขึ้นสด ไม่มีการล่าช้า SeaMeet เข้ารหัสวิดีโอแบบเรียลไทม์ในขณะที่คุณบันทึก ไม่ต้องรอการประมวลผลภายหลัง

Recording Mode (โหมดการบันทึก)

วิธีที่ SeaMeet จับวิดีโอ: Fullscreen (ทั้งหน้าจอ), Window (แอปเฉพาะ), หรือ Region (พื้นที่ที่เลือก)

Region Recording (การบันทึกพื้นที่)

บันทึกเฉพาะส่วนที่เลือกของหน้าจอของคุณ โหมดที่มีประสิทธิภาพที่สุด — จับเฉพาะสิ่งที่คุณต้องการ

Resolution (ความละเอียด)

จำนวนพิกเซลในรูปภาพ 1920×1080 หมายถึงกว้าง 1920 พิกเซลและสูง 1080 พิกเซล สูงกว่า = คมชัดกว่า = ไฟล์ใหญ่ขึ้น

Ring Menu (เมนูวงแหวน) (Floater)

อินเทอร์เฟซควบคุมแบบวงกลมที่ปรากฏเมื่อคุณขยายวิดเจ็ต Floater ให้การเข้าถึงตัวควบคุมการบันทึกอย่างรวดเร็ว

S

Sample Rate (อัตราตัวอย่าง) (เสียง)

จำนวนครั้งต่อวินาทีที่เสียงถูกวัด คุณภาพ CD คือ 44.1 kHz (44,100 ตัวอย่างต่อวินาที) สูงกว่า = คุณภาพดีกว่า

Sampling (การสุ่มตัวอย่าง)

แปลงคลื่นเสียงต่อเนื่องเป็นตัวเลขดิจิทัลโดยการวัดในช่วงเวลาที่สม่ำเสมอ

Save Location (ตำแหน่งบันทึก)

โฟลเดอร์ที่ SeaMeet เก็บการบันทึก สามารถเปลี่ยนได้ในการตั้งค่า ควรมีพื้นที่ว่างเพียงพอ

Screen Recording (การบันทึกหน้าจอ)

การจับวิดีโอของหน้าจอคอมพิวเตอร์ของคุณ SeaMeet เชี่ยวชาญในการบันทึกหน้าจอด้วยเสียง

Screenshot (ภาพหน้าจอ)

การจับภาพนิ่งของหน้าจอของคุณ SeaMeet สามารถถ่ายภาพหน้าจอผ่านทางลัดคีย์บอร์ดหรือ Floater

Sensitivity (ความไว) (Auto-Detection)

SeaMeet มองหาการประชุมเชิงรุกแค่ไหน ความไวสูงจับการประชุมได้มากกว่าแต่อาจมี false positives

Shortcut (ทางลัด)

ดู Keyboard Shortcuts วิธีที่รวดเร็วในการควบคุม SeaMeet โดยไม่ใช้เมาส์

Sidebar (แถบด้านข้าง)

แผงด้านซ้ายใน SeaMeet ที่แสดงส่วนต่างๆ: Recordings, Video, Flashback เป็นต้น

Slash Menu (เมนู Slash)

เมนูแทรกบล็อกในตัวแก้ไข note เรียกใช้โดยพิมพ์ / บนบรรทัดใหม่ ให้คุณแทรกหัวข้อ, รายการ, callouts, บล็อกโค้ด, embeds และประเภทบล็อกอื่นๆ โดยไม่ต้องออกจากคีย์บอร์ด ดูบทที่ 16-17

Source (แหล่งที่มา) (เสียง/วิดีโอ)

ต้นกำเนิดของสัญญาณ แหล่งเสียงรวมถึงไมโครโฟนและเสียงระบบ แหล่งวิดีโอรวมถึงหน้าจอและหน้าต่าง

Speaker Detection (การตรวจจับผู้พูด)

กระบวนการอัตโนมัติในการระบุว่าใครกำลังพูดในระหว่างการถอดความสดหรือ AI Extraction เสียงแต่ละเสียงที่แตกต่างกันจะได้รับการกำหนดป้ายกำกับ ("Speaker 1", "Speaker 2") ความแม่นยำดีขึ้นด้วยเสียงที่ชัดเจนและมีการพูดทับน้อย ดูบทที่ 31

Speaker Label (ป้ายกำกับผู้พูด)

ชื่อที่กำหนดให้กับผู้พูดใน transcript ค่าเริ่มต้นคือ "Speaker 1", "Speaker 2" เป็นต้น สามารถเปลี่ยนชื่อ (เช่น "Alice") หรือผสานกับป้ายกำกับอื่นได้หากป้ายกำกับสองอันเป็นของบุคคลเดียวกัน ดูบทที่ 34

SplitButtonMenu

ตัวควบคุม UI บนแท็บ AI Summary ที่รวมการกระทำหลักกับ dropdown สำหรับการกระทำที่เกี่ยวข้อง — เช่น ปุ่มเดียวที่รัน "Regenerate with Auto-pick" โดยค่าเริ่มต้นแต่เสนอตัวเลือก "Manual template" จาก dropdown caret ดูบทที่ 33-34

SRT (SubRip Subtitle)

รูปแบบไฟล์ข้อความสำหรับคำบรรยาย ประกอบด้วยบรรทัดข้อความที่ติด timestamp SeaMeet สามารถส่งออก transcripts เป็นไฟล์ SRT ซึ่งสามารถนำเข้าสู่ตัวแก้ไขวิดีโอ (Premiere, iMovie) หรืออัปโหลดไปยัง YouTube เป็นคำบรรยาย

SSD (Solid State Drive)

อุปกรณ์จัดเก็บข้อมูลที่รวดเร็วโดยไม่มีชิ้นส่วนเคลื่อนไหว ดีกว่าฮาร์ดไดรฟ์แบบดั้งเดิม (HDD) สำหรับการบันทึก ความเร็วในการเขียนเร็วกว่า

Stereo Mix

ฟีเจอร์เสียง Windows ที่ให้คุณบันทึกเสียงระบบ SeaMeet สามารถใช้ Stereo Mix หรือ WASAPI สำหรับการจับเสียงระบบ

Storage (การจัดเก็บ)

พื้นที่บนฮาร์ดไดรฟ์หรือ SSD ของคุณที่บันทึกการบันทึก การบันทึกวิดีโอต้องการพื้นที่จัดเก็บมาก

Stream (สตรีม)

การไหลของข้อมูลอย่างต่อเนื่อง สตรีมเสียงและวิดีโอถูกจับและเข้ารหัสในขณะบันทึก

Sync (ซิงค์) (เสียง-วิดีโอ)

เมื่อเสียงและวิดีโอจัดเรียงอย่างถูกต้อง ไม่ซิงค์หมายความว่าคุณเห็นริมฝีปากขยับก่อน/หลังได้ยินคำพูด

Sync State Machine

วงจรชีวิตของการซิงค์ GitHub: idle → pending → syncing → synced พร้อมสาขาสำหรับ error, offline, token-expired, installing-app และ creating-repo สถานะถูกแสดงในตัวบ่งชี้สถานะการซิงค์เพื่อให้คุณรู้ว่าการซิงค์อยู่ที่ใดในเวลาใดก็ตาม ดูบทที่ 38

System Audio (เสียงระบบ)

เสียงจากคอมพิวเตอร์ของคุณ — การแจ้งเตือน, วิดีโอ, เสียงการประชุม SeaMeet สามารถบันทึกเสียงระบบแยกจากไมโครโฟน

System Tray

พื้นที่ใกล้นาฬิกาของคุณที่แอปพื้นหลังแสดงไอคอน SeaMeet สามารถย่อเป็น system tray ได้

T

Template (เทมเพลต) (AI Summary Template)

prompt ที่มีโครงสร้างที่กำหนดรูปร่างผลลัพธ์การสกัด AI สำหรับประเภทการประชุมเฉพาะ — เช่น เทมเพลต standup เน้น blockers และแผนของวันพรุ่งนี้ ในขณะที่เทมเพลตการโทรขายเน้นข้อโต้แย้งและขั้นตอนต่อไป เทมเพลตสามารถเลือกด้วยตนเองหรือผ่าน Auto-pick ดูบทที่ 33

Theme (ธีม) (สว่าง/มืด)

รูปลักษณ์ของ SeaMeet ธีมสว่างมีพื้นหลังสีขาว ธีมมืดมีพื้นหลังสีเข้ม สบายตาขึ้นในตอนกลางคืน

Thumbnail (ภาพขนาดย่อ)

ภาพตัวอย่างขนาดเล็กที่แทนวิดีโอ SeaMeet แสดง thumbnails ของการบันทึกของคุณในไลบรารี

Time Machine (เครื่องเวลา) (Flashback)

คำเปรียบเทียบสำหรับฟีเจอร์ Flashback ให้คุณ "ย้อนเวลา" เพื่อจับช่วงเวลาที่เกิดขึ้นแล้ว

Timeline (เส้นเวลา)

การแสดงผลภาพของระยะเวลาของการบันทึก เครื่องเล่นของ SeaMeet แสดง timeline พร้อมตำแหน่งการเล่น

Toggle (สวิตช์)

สวิตช์ที่เปิดหรือปิดฟีเจอร์ SeaMeet ใช้ toggles ในการตั้งค่า — คลิกเพื่อสลับระหว่างสถานะ

Transcript (บทถอดความ)

บันทึกข้อความของเสียงพูด SeaMeet สร้างสองประเภท: live transcript (คำที่จับได้แบบเรียลไทม์ในระหว่างการบันทึก) และ extraction transcript (สร้างจากไฟล์เสียงหลังการบันทึก) ทั้งคู่ปรากฏในแผง AI Insights ใต้แท็บ Transcript ดูบทที่ 27 และ 28

Track (แทร็ก) (เสียง)

สตรีมเสียงแยกต่างหากภายในไฟล์ SeaMeet สามารถบันทึกหลายแทร็ก: ไมโครโฟน, เสียงระบบ เป็นต้น

Tray

เมนูไอคอน system-tray — พื้นที่แจ้งเตือน Windows, menu bar macOS, indicator Linux — ที่ SeaMeet อาศัยอยู่เมื่อย่อ ให้ start/stop recording, เปิด Lite Mode และออก แม้ว่าจะไม่มีหน้าต่างหลักที่มองเห็นได้

Trim (ตัด)

ลบส่วนต้นหรือปลายที่ไม่ต้องการของการบันทึก SeaMeet อนุญาตให้ตัดการบันทึกที่บันทึกไว้

Troubleshooting (การแก้ไขปัญหา)

กระบวนการวินิจฉัยและแก้ไขปัญหา บทที่ 25 ครอบคลุมการแก้ไขปัญหา SeaMeet ทั่วไป

U

USB Microphone (ไมโครโฟน USB)

ไมโครโฟนที่เชื่อมต่อผ่านพอร์ต USB ใช้ง่ายและมักมีคุณภาพดีกว่าไมโครโฟนแล็ปท็อปในตัว

V

VBR (Variable Bit Rate - อัตราบิตแปรผัน)

วิธีการเข้ารหัสที่ปรับคุณภาพตามความซับซ้อนของเนื้อหา ฉากที่เรียบง่ายใช้ bitrate ต่ำกว่า ฉากที่ซับซ้อนใช้สูงกว่า

Video Buffer (บัฟเฟอร์วิดีโอ)

ที่จัดเก็บชั่วคราวสำหรับเฟรมวิดีโอในระหว่างการบันทึก Flashback เก็บหน้าต่างที่กลิ้งของภาพล่าสุด

Version Badge (ตราเวอร์ชัน)

ป้ายกำกับเล็กๆ (เช่น "v3 ▾") ที่ปรากฏในแถบแท็บ AI Insights เมื่อมีการสร้างใหม่อย่างน้อยหนึ่งครั้ง การคลิกจะเปิด version picker ดูบทที่ 34

Version History (ประวัติเวอร์ชัน)

บันทึกของการรัน AI Extraction ก่อนหน้าทั้งหมดสำหรับการบันทึก ทุกครั้งที่คุณสร้างใหม่ (⟳) SeaMeet จะบันทึกผลลัพธ์ก่อนหน้าเป็น snapshot ที่มีหมายเลขก่อนที่จะเขียนทับ คุณสามารถดูเวอร์ชันใดๆ ก่อนหน้าได้ตลอดเวลา ดูบทที่ 34

Video Track (แทร็กวิดีโอ)

ส่วนประกอบภาพของไฟล์วิดีโอ แยกจากแทร็กเสียง ไฟล์วิดีโอประกอบด้วยอย่างน้อยหนึ่งแทร็กวิดีโอ

Volume (ระดับเสียง)

ความดังของเสียง แตกต่างจาก gain — ระดับเสียงมีผลต่อสิ่งที่คุณได้ยิน Gain มีผลต่อสิ่งที่บันทึก

VP8/VP9

codecs วิดีโอโอเพนซอร์สที่ใช้ในไฟล์ WebM คุณภาพดี ใช้ฟรี VP9 ใหม่กว่าและมีประสิทธิภาพมากกว่า VP8

W

WASAPI (Windows Audio Session API)

วิธี Windows สมัยใหม่สำหรับการจับเสียงระบบ น่าเชื่อถือกว่า Stereo Mix ในบางระบบ

WAV (Waveform Audio File Format)

รูปแบบเสียงที่ไม่บีบอัด ไฟล์ใหญ่แต่คุณภาพสมบูรณ์แบบ ดีสำหรับการเก็บข้อมูลหรือการแก้ไข

WebM

รูปแบบวิดีโอโอเพนซอร์สที่พัฒนาโดย Google ดีสำหรับการใช้เว็บ ใช้ codecs VP8 หรือ VP9

Wikilink

ไวยากรณ์ [[title]] ใน notes ที่สร้างลิงก์ที่นำทางได้ไปยัง note อื่น พิมพ์ [[ เปิด picker สำหรับ notes ที่มีอยู่; เลือกหนึ่งแทรกลิงก์ และคลิกที่ลิงก์ใน note ที่แสดงผลจะข้ามไปที่หน้านั้น ดูบทที่ 16-17

Window Recording (การบันทึกหน้าต่าง)

โหมดการบันทึกที่จับเฉพาะหน้าต่างแอปเฉพาะ มีประสิทธิภาพมากกว่า fullscreen

Window Title Detection (การตรวจจับชื่อหน้าต่าง)

วิธีการตรวจจับอัตโนมัติที่อ่านชื่อหน้าต่างแอป ค้นหาคำสำคัญเช่น "Zoom Meeting" หรือ "Teams"

Workspace (พื้นที่ทำงาน)

ต้นไม้ notes แยกต่างหากบวกกับชุดการบันทึกที่คุณสามารถสลับระหว่าง — เช่น workspace "Work" และ workspace "Personal" แต่ละอันมี GitHub Sync repo ของตัวเอง การสลับ workspace จะสลับ sidebar, ไลบรารี และเป้าหมายการซิงค์ในการเคลื่อนไหวครั้งเดียว ดูบทที่ 38

คำศัพท์ที่สับสนได้อธิบาย

Codec vs. Container

  • Codec: วิธี (HOW) ที่ข้อมูลถูกบีบอัด (H.264, MP3)
  • Container: ที่ (WHERE) ที่ข้อมูลถูกเก็บ (MP4, WebM, AVI)

การเปรียบเทียบ: Codec คือภาษาที่หนังสือเขียนขึ้น Container คือตัวหนังสือเอง

Bitrate vs. Resolution

  • Bitrate: ข้อมูลเท่าใด (HOW MUCH) ต่อวินาที (มีผลต่อคุณภาพและขนาดไฟล์)
  • Resolution: พิกเซลจำนวนเท่าใด (HOW MANY) (มีผลต่อความคมชัด)

คุณสามารถมีความละเอียดสูงด้วย bitrate ต่ำ (เป็นบล็อก) หรือความละเอียดต่ำด้วย bitrate สูง (ราบรื่นแต่เล็ก)

Gain vs. Volume

  • Gain: ระดับอินพุต (ความดังของการบันทึก)
  • Volume: ระดับเอาต์พุต (ความดังของการเล่น)

การเปลี่ยนระดับเสียงไม่มีผลต่อการบันทึก การเปลี่ยน gain มีผลต่อการบันทึก

Latency vs. Delay

  • Latency: คำศัพท์ทางเทคนิคสำหรับความล่าช้าในระบบดิจิทัล
  • Delay: คำศัพท์ทั่วไปสำหรับเวลารอใดๆ

โดยพื้นฐานแล้วเป็นสิ่งเดียวกัน แต่ "latency" ใช้สำหรับบริบททางเทคนิค

Frame Rate vs. Resolution

  • Frame Rate: รูปภาพจำนวนเท่าใด (HOW MANY) ต่อวินาที (ความราบรื่น)
  • Resolution: รูปภาพแต่ละรูปมีรายละเอียดเท่าใด (HOW DETAILED) (ความชัดเจน)

60fps 720p ราบรื่นกว่า 30fps 1080p แต่ 1080p คมชัดกว่า
