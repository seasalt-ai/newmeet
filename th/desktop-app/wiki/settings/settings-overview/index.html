ภาพรวมการตั้งค่า

บทที่ 18: ภาพรวมการตั้งค่า

บทนำ

ยินดีต้อนรับสู่ศูนย์ควบคุมของ SeaMeet! หากอินเทอร์เฟซหลักเหมือนห้องนักบินที่คุณบินเครื่องบิน เมนูการตั้งค่าเหมือนช่องซ่อมบำรุงที่คุณปรับเครื่องยนต์ ปรับที่นั่ง และปรับแต่งประสบการณ์การบินของคุณ บทนี้จะแสดงวิธีเข้าถึงเมนูการตั้งค่าและให้แผนที่ของหมวดหมู่ต่างๆ ที่คุณจะพบที่นั่น

เมื่อจบบทนี้ คุณจะรู้แน่นอนว่าจะหาการตั้งค่าทุกอย่างใน SeaMeet ที่ไหนและเข้าใจสิ่งที่แต่ละหมวดหมู่ควบคุม คิดว่านี่เป็นทัวร์การปฐมนิเทศก่อนที่เราจะดำดิ่งลึกในแต่ละส่วนเฉพาะ

วัตถุประสงค์ของบท

หลังจากอ่านบทนี้ คุณจะสามารถ:

  • เปิดเมนูการตั้งค่าจากหลายตำแหน่งใน SeaMeet
  • เข้าใจ 10 หมวดหมู่หลักของการตั้งค่าและสิ่งที่ควบคุม (รวมถึงกลุ่ม ฟีเจอร์ AI และ Sync ใหม่ที่เปิดตัวใน v2.1.0)
  • นำทางระหว่างส่วนการตั้งค่าต่างๆ ได้อย่างรวดเร็ว
  • จดจำตัวบ่งชี้ภาพและไอคอนที่ใช้ในอินเทอร์เฟซการตั้งค่า
  • รู้ว่าเมื่อใดควรเปลี่ยนการตั้งค่าใดตามความต้องการของคุณ

การตั้งค่าคืออะไรและทำไมจึงสำคัญ?

คิดว่าการตั้งค่า SeaMeet เหมือนการตั้งค่าบนสมาร์ทโฟนของคุณ คุณไม่จำเป็นต้องเปลี่ยนเพื่อใช้ฟีเจอร์พื้นฐาน แต่การปรับแต่งทำให้แอปทำงานตามที่คุณต้องการอย่างแน่นอน เป็นความแตกต่างระหว่างการใส่เสื้อ one-size-fits-all กับเสื้อที่ตัดเย็บตามขนาดของคุณ

การตั้งค่ามีความสำคัญเพราะช่วยให้คุณ:

ปรับแต่งประสบการณ์ของคุณ

  • เลือกภาษาที่คุณต้องการ (16 ตัวเลือก!)
  • ตั้งโหมดสว่างหรือมืดตามความสบายของดวงตา
  • เลือกที่บันทึกการบันทึกของคุณ
  • กำหนดค่าทางลัดที่ตรงกับความจำกล้ามเนื้อของคุณ

ปรับประสิทธิภาพให้เหมาะสม

  • ปรับคุณภาพเสียงตามความสามารถของไมโครโฟน
  • ตั้งความละเอียดวิดีโอให้ตรงกับหน้าจอและความต้องการการจัดเก็บ
  • เปิดหรือปิดฟีเจอร์ตามพลังของคอมพิวเตอร์
  • จัดการการใช้หน่วยความจำสำหรับการบันทึก flashback

รับรองความน่าเชื่อถือ

  • ตั้งค่าการตรวจจับอัตโนมัติเพื่อให้คุณไม่พลาดการประชุม
  • กำหนดค่าคำเตือนการจัดเก็บก่อนพื้นที่หมด
  • เลือกอุปกรณ์เสียงที่เหมาะสมสำหรับการตั้งค่าของคุณ
  • ตั้งค่าสิทธิ์อย่างถูกต้องตั้งแต่เริ่มต้น

แก้ไขปัญหาก่อนที่จะเกิดขึ้น

  • ปรับ gain ไมโครโฟนหากคนบอกว่าคุณเบาหรือดังเกินไป
  • ตั้งโหมดการบันทึกเริ่มต้นเพื่อหลีกเลี่ยงการลืมสลับ
  • กำหนดค่าตัวเลือกการเริ่มอัตโนมัติเพื่อให้การบันทึกเริ่มเมื่อคุณต้องการ
  • เปิดโหมด low-memory หากคอมพิวเตอร์ของคุณเก่ากว่าหรือช้ากว่า

วิธีการเปิดเมนูการตั้งค่า

SeaMeet ให้หลายวิธีในการเข้าถึงการตั้งค่า เช่นเดียวกับวิธีที่คุณสามารถปลดล็อกโทรศัพท์ของคุณด้วยรหัสผ่าน ลายนิ้วมือ หรือการรู้จำใบหน้า นี่คือทุกวิธีในการไปยังการตั้งค่าของคุณ:

วิธีที่ 1: จาก Sidebar ซ้าย

นี่คือวิธีที่ใช้บ่อยที่สุดในการเข้าถึงการตั้งค่า มองที่ sidebar แนวตั้งทางด้านซ้ายของหน้าต่าง SeaMeet หลัก

ขั้นตอน:

  1. ค้นหา sidebar ซ้ายพร้อมไอคอนสำหรับ Recordings, Video, Flashback เป็นต้น

  2. มองหา ไอคอนตั้งค่า — ดูเหมือนเฟืองหรือ cogwheel (⚙️)

  3. คลิกไอคอนตั้งค่า

  4. พื้นที่หลักจะสลับจากการแสดงการบันทึกของคุณเป็นการแสดงแผงการตั้งค่า

วิธีที่ 2: จาก Menu Bar (Windows)

หากคุณใช้ Windows คุณสามารถเข้าถึงการตั้งค่าผ่าน menu bar แบบดั้งเดิมที่ด้านบนของหน้าต่าง

ขั้นตอน:

  1. คลิกที่ "File" ใน menu bar ด้านบน

  2. มองหา "Settings" หรือ "Preferences" ใน dropdown menu

  3. คลิกเพื่อเปิดแผงการตั้งค่า

หมายเหตุ: วิธีนี้อาจแตกต่างเล็กน้อยขึ้นอยู่กับเวอร์ชัน Windows และเวอร์ชัน SeaMeet ของคุณ

วิธีที่ 3: ทางลัดคีย์บอร์ด (Windows)

สำหรับผู้ที่ชื่นชอบคีย์บอร์ด มีทางลัดด่วน:

บน Windows: กด Ctrl + Comma (,)

นี่เป็นทางลัดทั่วไปในแอป Windows มากมาย (รวมถึง Microsoft Office และอื่นๆ มากมาย) ดังนั้นอาจอยู่ในความจำกล้ามเนื้อของคุณแล้ว

วิธีการใช้:

  1. ตรวจสอบให้แน่ใจว่า SeaMeet เป็นหน้าต่างที่ใช้งานอยู่ (คลิกถ้าไม่แน่ใจ)
  2. กด Ctrl ค้างไว้
  3. ในขณะที่กด Ctrl ค้างไว้ กดปุ่ม comma
  4. การตั้งค่าจะเปิดทันที

วิธีที่ 4: จากเมนู Tray (Windows)

SeaMeet ทำงานใน system tray ของคุณ (พื้นที่ใกล้นาฬิกาของคุณที่มีไอคอนเล็กๆ ทั้งหมด) คุณสามารถเข้าถึงการตั้งค่าจากที่นั่นด้วย

ขั้นตอน:

  1. มองหาไอคอน SeaMeet ใน system tray ของคุณ (มุมขวาล่างของหน้าจอ)

    • คุณอาจต้องคลิกลูกศรขึ้นเล็กๆ เพื่อดูไอคอนที่ซ่อนอยู่

  2. คลิกขวาที่ไอคอน SeaMeet

  3. เมนูบริบทจะปรากฏพร้อมตัวเลือกต่างๆ

  4. คลิก "ตั้งค่า" จากเมนู

ทำไมต้องใช้วิธีนี้?

  • ดีเมื่อ SeaMeet ถูกย่อ
  • เข้าถึงได้รวดเร็วโดยไม่ต้องเปิดหน้าต่างหลัก
  • เหมาะเมื่อคุณรีบ

วิธีที่ 5: จากเมนู Floater

จำวิดเจ็ตควบคุมลอย (Floater) จากบทที่ 14 ได้หรือไม่? คุณสามารถเข้าถึงการตั้งค่าจากที่นั่นด้วย

ขั้นตอน:

  1. คลิกที่ Floater เพื่อขยาย (ถ้าอยู่ในโหมดกะทัดรัด)

  2. มองหาไอคอนเฟืองตั้งค่าหรือตัวเลือกเมนู

  3. คลิกเพื่อเปิดการตั้งค่า

หมายเหตุ: ตำแหน่งที่แน่นอนอาจแตกต่างกันไปตามการกำหนดค่า Floater ของคุณ แต่ตัวเลือกการตั้งค่าสามารถเข้าถึงได้จากมุมมอง Floater ที่ขยายเสมอ

ด้านซ้าย: รายการหมวดหมู่

  • แสดงหมวดหมู่การตั้งค่าทั้งหมดที่มี
  • คลิกที่หมวดหมู่ใดๆ เพื่อดูการตั้งค่า
  • หมวดหมู่ที่เลือกปัจจุบันถูกไฮไลต์
  • บางหมวดหมู่มีไอคอนข้างชื่อ

ด้านขวา: เนื้อหาการตั้งค่า

  • แสดงการตั้งค่าทั้งหมดสำหรับหมวดหมู่ที่เลือก
  • แต่ละการตั้งค่ามีป้ายอธิบายสิ่งที่ทำ
  • การตั้งค่าใช้ประเภทตัวควบคุมที่แตกต่างกัน:
    • Toggles (สวิตช์เปิด/ปิด) — สำหรับตัวเลือกใช่/ไม่
    • Dropdown menus — สำหรับเลือกจากตัวเลือกหลายตัว
    • ช่องข้อความ — สำหรับการป้อน file paths หรือชื่อ
    • Sliders — สำหรับปรับค่าเช่น volume
    • ปุ่ม — สำหรับการกระทำเช่น "Browse" หรือ "Reset"

ด้านล่าง: ปุ่มการกระทำ

  • ใช้ — บันทึกการเปลี่ยนแปลงของคุณ (บางครั้งอัตโนมัติ)
  • ยกเลิก — ทิ้งการเปลี่ยนแปลงและปิดการตั้งค่า
  • รีเซ็ตเป็นค่าเริ่มต้น — คืนการตั้งค่าทั้งหมดเป็นค่าโรงงาน
  • ค้นหา — ค้นหาการตั้งค่าเฉพาะอย่างรวดเร็ว (ในบางเวอร์ชัน)

หมวดหมู่ 1: การตั้งค่าทั่วไป

ไอคอน: มักจะเป็นไอคอนเฟืองหรือบ้าน สิ่งที่ควบคุม: พฤติกรรมและรูปลักษณ์แอปพื้นฐาน

การตั้งค่าทั่วไปรวมถึง:

  • พฤติกรรมการเริ่มต้น — SeaMeet ควรเปิดอัตโนมัติเมื่อคอมพิวเตอร์ของคุณเริ่ม?
  • ย่อเป็น tray — SeaMeet ควรทำงานต่อเมื่อคุณปิดหน้าต่าง?
  • การเลือกธีม — โหมดสว่าง โหมดมืด หรืออัตโนมัติ (ตามระบบ)
  • ความชอบการแจ้งเตือน — เหตุการณ์ใดควร trigger การแจ้งเตือน?
  • การตั้งค่าการอัปเดต — SeaMeet ควรตรวจสอบการอัปเดตอัตโนมัติ?

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคุณติดตั้ง SeaMeet ครั้งแรกและต้องการตั้งค่าความชอบพื้นฐาน
  • เมื่อคุณต้องการเปลี่ยนรูปลักษณ์และความรู้สึกของแอป
  • เมื่อคุณต้องการควบคุมวิธีที่ SeaMeet ทำงานในพื้นหลัง
  • เมื่อตั้งค่าการเริ่มต้นอัตโนมัติ

การเปรียบเทียบ: นี่เหมือนปรับการตั้งค่าพื้นฐานของรถยนต์ — ไฟควรเปิดอัตโนมัติ? ควรจำตำแหน่งที่นั่งของคุณ? ควร ding เมื่อคุณทิ้งกุญแจไว้ในรถ?

หมวดหมู่ 2: การตั้งค่าการจัดเก็บ

ไอคอน: มักจะเป็นไอคอนฮาร์ดไดรฟ์หรือโฟลเดอร์ สิ่งที่ควบคุม: ที่และวิธีที่บันทึกของคุณถูกบันทึก

การตั้งค่าทั่วไปรวมถึง:

  • ตำแหน่งบันทึก — โฟลเดอร์ใดที่บันทึกควรไป?
  • การจัดการการจัดเก็บ — การล้างข้อมูลอัตโนมัติของบันทึกเก่า
  • การจัดระเบียบไฟล์ — ไฟล์ควรถูกตั้งชื่อและเรียงลำดับอย่างไร?
  • คำเตือนพื้นที่ดิสก์ — แจ้งเตือนเมื่อคุณกำลังเหลือพื้นที่
  • การตั้งค่าการสำรองข้อมูล — บันทึกควรได้รับการสำรองข้อมูลไปยังที่จัดเก็บคลาวด์?

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคุณต้องการเปลี่ยนที่ที่บันทึกถูกบันทึก (เช่น ย้ายไปยังไดรฟ์ภายนอก)
  • เมื่อคุณกำลังเหลือพื้นที่ดิสก์และต้องจัดการการจัดเก็บ
  • เมื่อคุณต้องการจัดระเบียบบันทึกในวิธีเฉพาะ
  • เมื่อตั้งค่าการล้างข้อมูลอัตโนมัติเพื่อป้องกันการสะสม

การเปรียบเทียบ: นี่เหมือนการจัดระเบียบตู้เสื้อผ้าของคุณ — ตัดสินใจว่าลิ้นชักใดได้รับเสื้อผ้าใด วิธีติดป้ายกล่อง และเมื่อใดที่จะบริจาครายการเก่าเพื่อทำที่ว่างให้รายการใหม่

หมายเหตุสำคัญ: สิ่งนี้ครอบคลุมรายละเอียดในบทที่ 19 (การตั้งค่าการจัดเก็บ) ซึ่งเราจะเดินผ่านทุกตัวเลือกทีละขั้นตอน

หมวดหมู่ 3: การตั้งค่าเสียง

ไอคอน: มักจะเป็นไอคอนไมโครโฟนหรือลำโพง สิ่งที่ควบคุม: ทุกอย่างที่เกี่ยวข้องกับการบันทึกและเล่นเสียง

การตั้งค่าทั่วไปรวมถึง:

  • ไมโครโฟนเริ่มต้น — ไมโครโฟนใดที่จะใช้สำหรับการบันทึก
  • gain ไมโครโฟน — เสียงของคุณควรถูกบันทึกดังแค่ไหน
  • แหล่งเสียงระบบ — เอาต์พุตเสียงใดที่จะจับ
  • คำเตือน Bluetooth — แจ้งเตือนเมื่อใช้ไมโครโฟน Bluetooth
  • รูปแบบเสียง — รูปแบบที่ต้องการสำหรับการบันทึกเสียง (MP3, WAV เป็นต้น)
  • sample rate — ระดับคุณภาพเสียง (44.1kHz, 48kHz เป็นต้น)

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคนบอกว่าคุณเงียบหรือดังเกินไปในการบันทึก
  • เมื่อคุณมีหลายไมโครโฟนและต้องการเลือกค่าเริ่มต้น
  • เมื่อใช้หูฟัง Bluetooth และต้องการคำเตือน latency
  • เมื่อคุณต้องการเปลี่ยนคุณภาพเสียงหรือรูปแบบไฟล์
  • เมื่อแก้ไขปัญหาการบันทึกเสียง

การเปรียบเทียบ: นี่เหมือนปรับระบบเสียงในห้องคอนเสิร์ต — เลือกไมโครโฟนใดที่จะใช้ ตั้งระดับ volume ที่ถูกต้อง และตรวจสอบให้แน่ใจว่าอะคูสติกทำงานได้อย่างสมบูรณ์แบบสำหรับการแสดง

หมายเหตุสำคัญ: สิ่งนี้ครอบคลุมรายละเอียดในบทที่ 20 (การตั้งค่าเสียง) ซึ่งเราจะดำดิ่งลึกลงในการเลือกไมโครโฟน การควบคุม gain และอื่นๆ

หมวดหมู่ 4: การตั้งค่าวิดีโอ

ไอคอน: มักจะเป็นไอคอนกล้องวิดีโอหรือจอภาพ สิ่งที่ควบคุม: ทุกอย่างที่เกี่ยวข้องกับการบันทึกหน้าจอ

การตั้งค่าทั่วไปรวมถึง:

  • โหมดการบันทึกเริ่มต้น — Fullscreen, window หรือ region
  • คุณภาพวิดีโอ — ความละเอียด (1080p, 720p, 480p)
  • อัตราเฟรม — วิดีโอควรราบรื่นแค่ไหน (30fps, 60fps)
  • การเลือกจอภาพ — หน้าจอใดที่จะบันทึก (ถ้าคุณมีหลายหน้าจอ)
  • รูปแบบวิดีโอ — รูปแบบที่ต้องการสำหรับไฟล์วิดีโอ (MP4, WebM เป็นต้น)
  • การเร่งฮาร์ดแวร์ — ใช้ GPU เพื่อประสิทธิภาพที่ดีขึ้น
  • การบันทึกเคอร์เซอร์ — pointer ของเมาส์ควรมองเห็น?
  • เอฟเฟกต์เคอร์เซอร์ — ไฮไลต์การคลิก เปลี่ยนขนาดเคอร์เซอร์ เป็นต้น

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคุณต้องการตั้งโหมดการบันทึกเริ่มต้นเพื่อประหยัดคลิก
  • เมื่อคุณต้องการสร้างสมดุลคุณภาพเทียบกับขนาดไฟล์
  • เมื่อคุณมีหลายจอภาพและต้องระบุว่าจะบันทึกอันใด
  • เมื่อบันทึกการเล่นเกมและต้องการอัตราเฟรมสูง (60fps)
  • เมื่อสร้างบทเรียนและต้องการเอฟเฟกต์เคอร์เซอร์

การเปรียบเทียบ: นี่เหมือนตั้งค่ากล้องถ่ายภาพยนตร์ — เลือกคุณภาพฟิล์ม ตัดสินเลนส์ใดที่จะใช้ ตั้งอัตราเฟรมสำหรับการเคลื่อนไหวที่ราบรื่น และตัดสินว่าจะแสดงมือของช่างภาพในช็อตหรือไม่

หมายเหตุสำคัญ: สิ่งนี้ครอบคลุมรายละเอียดในบทที่ 21 (การตั้งค่าวิดีโอ) ซึ่งเราจะอธิบายคำศัพท์ทางเทคนิคทั้งหมดและช่วยให้คุณเลือกการตั้งค่าที่เหมาะสม

หมวดหมู่ 5: การตั้งค่า Flashback

ไอคอน: มักจะเป็นไอคอนลูกศรวงกลมหรือนาฬิกา (แทน "rewind") สิ่งที่ควบคุม: ฟีเจอร์การบันทึกแบบเครื่องเวลา

การตั้งค่าทั่วไปรวมถึง:

  • เริ่ม Flashback อัตโนมัติ — Flashback ควรเริ่มอัตโนมัติเมื่อ SeaMeet เปิดตัว?
  • ระยะเวลาบัฟเฟอร์ — ย้อนเวลาเก็บไว้แค่ไหน (10-120 วินาที)
  • ความยาวบัฟเฟอร์เสียง — เก็บเสียงแค่ไหน (คงที่ 30 วินาที)
  • คุณภาพวิดีโอ — ความละเอียดสำหรับวิดีโอ Flashback (มักต่ำกว่าการบันทึกปกติ)
  • โหมด low-memory — ลดการใช้หน่วยความจำสำหรับคอมพิวเตอร์เก่า
  • การคงอยู่ของบัฟเฟอร์ — เก็บบัฟเฟอร์เมื่อสลับแอป?

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคุณต้องการให้ Flashback พร้อมเสมอ (เริ่มอัตโนมัติ)
  • เมื่อคุณต้องสร้างสมดุลว่าคุณสามารถบันทึกย้อนไปได้ไกลแค่ไหนเทียบกับการใช้หน่วยความจำ
  • เมื่อคอมพิวเตอร์ของคุณเก่ากว่าและคุณต้องประหยัด RAM
  • เมื่อคุณต้องการปรับแต่งวิธีที่ Flashback ทำงาน

การเปรียบเทียบ: นี่เหมือนการกำหนดค่า DVR ของกล้องวงจรปิด — ตัดสินใจว่าจะเก็บฟุตเทจกี่วัน ตั้งคุณภาพการบันทึก และจัดการพื้นที่จัดเก็บสำหรับการบันทึกอย่างต่อเนื่อง

หมายเหตุสำคัญ: สิ่งนี้ครอบคลุมรายละเอียดในบทที่ 22 (การตั้งค่า Flashback) ซึ่งเราจะช่วยคุณค้นหาความสมดุลที่สมบูรณ์แบบระหว่างความยาวบัฟเฟอร์และประสิทธิภาพ

หมวดหมู่ 6: ฟีเจอร์ AI (ใหม่ใน v2.1.0)

ไอคอน: ไอคอน sparkle/magic-wand สีม่วง สิ่งที่ควบคุม: ทุกอย่างที่ขับเคลื่อนด้าน AI ของ SeaMeet — การถอดความสด, การสกัดหลังการประชุม, เทมเพลตสรุป และ (ตัวเลือก) AI Agent ในแอป

กลุ่มฟีเจอร์ AI มีรายการเมนูสามรายการ:

  • AI Transcription, Extraction, Summary, Wiki — ผู้ให้บริการโมเดลของคุณ การป้อนคีย์ API BYOK ภาษาสรุป และไปป์ไลน์ AI ใดที่ทำงานโดยอัตโนมัติหลังการบันทึก ครอบคลุมรายละเอียดในบทที่ 36 (Bring Your Own Key — BYOK)
  • AI Summary Templates — ไลบรารีเทมเพลตใหม่ที่ส่งใน v2.1.0 (48 เทมเพลตในตัวใน 8 หมวดหมู่: Team & Management, Project & Agile, Sales & Client, HR & Recruitment, Education & Training, Medical & Healthcare, Legal & Compliance และ Events & Media) รวมถึง toggle ตรวจจับเทมเพลตสรุปอัตโนมัติ (ค่าเริ่มต้น ON) — เมื่อเปิด SeaMeet จำแนก transcript ของการประชุมแต่ละครั้งและเลือกเทมเพลตที่เหมาะสมที่สุด; เมื่อปิด ทุกการบันทึกใช้ Meeting Minutes และไม่มีการเรียกใช้ classifier ครอบคลุมรายละเอียดในบทที่ 33 (เทมเพลตสรุป AI)
  • AI Agent & Cowork — มองเห็นได้เฉพาะเมื่อ feature flag ของ agent เปิดใช้งาน เป็นเจ้าภาพการกำหนดค่า chat-agent (Provider, ค่าเริ่มต้น Ask/Code/Plan) ครอบคลุมรายละเอียดในบทที่ 37 (Copilot & AI Agent)

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อคุณต้องการตั้งค่า BYOK ด้วยคีย์ API Gemini ของคุณเอง
  • เมื่อคุณต้องการพลิกพฤติกรรมตรวจจับเทมเพลตอัตโนมัติทั่วโลก
  • เมื่อคุณต้องการเรียกดูไลบรารีเทมเพลตที่ติดตั้งโดยไม่เปิดการบันทึก
  • เมื่อกำหนดค่าค่าเริ่มต้นของ AI Agent

การเปรียบเทียบ: นี่คือห้องควบคุม AI — แผงที่คุณเลือกว่า "สมอง" ใดที่ SeaMeet เชื่อมต่ออยู่และมันควรคิดให้คุณอย่างก้าวร้าวแค่ไหน

หมวดหมู่ 7: การตั้งค่าบันทึกอัตโนมัติ

ไอคอน: มักจะเป็นไอคอนแว่นขยายหรือ robot/automation สิ่งที่ควบคุม: การตรวจจับและการบันทึกการประชุมอัตโนมัติ

การตั้งค่าทั่วไปรวมถึง:

  • เปิดใช้งานการตรวจจับอัตโนมัติ — สวิตช์เปิด/ปิดหลักสำหรับฟีเจอร์
  • ความไวการตรวจจับ — การตรวจจับควรจะเชิงรุกแค่ไหน
  • การกระทำเริ่มต้น — เริ่มบันทึกทันทีหรือเพียงแค่แจ้งเตือน?
  • สิทธิ์ต่อแอป — แอปใดสามารถ trigger การบันทึกอัตโนมัติ
  • วิธีการตรวจจับ — สัญญาณใดที่จะเฝ้าดู (ชื่อหน้าต่าง, เสียง เป็นต้น)
  • ความล่าช้าก่อนเริ่ม — รอสักครู่หลังการตรวจจับเพื่อเริ่ม
  • การกระทำหลังประชุม — สิ่งที่จะทำเมื่อการประชุมสิ้นสุด

เมื่อใดที่จะใช้หมวดหมู่นี้:

  • เมื่อตั้งค่า SeaMeet ครั้งแรกและเปิดใช้งานการตรวจจับอัตโนมัติ
  • เมื่อคุณต้องการปรับแต่งว่าแอปใด trigger การบันทึก

  • สวิตช์จะเลื่อนและเปลี่ยนสี
  • การเปลี่ยนแปลงมักมีผลทันที

  2. รายการตัวเลือกปรากฏด้านล่าง
  3. คลิกที่ตัวเลือกที่ต้องการของคุณ
  4. dropdown ปิดด้วยการเลือกใหม่ของคุณแสดง

วิธีการใช้:

  • คลิกที่ checkbox เพื่อสลับ
  • เครื่องหมายถูกปรากฏเมื่อเปิดใช้งาน
  • คลิกอีกครั้งเพื่อยกเลิก

ความแตกต่างจาก Toggles:

  • Checkboxes โดยทั่วไปใช้เมื่อคุณสามารถเลือกหลายตัวเลือก
  • Toggles ใช้สำหรับตัวเลือกเปิด/ปิดเดียว
  • SeaMeet ใช้ toggles เป็นหลัก แต่คุณอาจเห็น checkboxes ในการตั้งค่าขั้นสูง

การเปรียบเทียบ: เหมือนรายการสิ่งที่ต้องทำ — คุณทำเครื่องหมายรายการที่คุณทำเสร็จ

พฤติกรรมการตั้งค่า: ทันทีเทียบกับใช้

ไม่ใช่ทุกการตั้งค่าทำงานในวิธีเดียวกันเมื่อคุณเปลี่ยน มีพฤติกรรมหลักสองประเภท:

การตั้งค่าทันที

สิ่งเหล่านี้มีผลทันทีที่คุณเปลี่ยน — ไม่จำเป็นต้องคลิก "ใช้" หรือ "บันทึก"

ตัวอย่าง:

  • การเปลี่ยนธีม (โหมดสว่าง/มืด)
  • การเลือกภาษา
  • Toggle switches (ส่วนใหญ่)
  • Volume/gain sliders (คุณได้ยินการเปลี่ยนแปลงในเรียลไทม์)

วิธีจดจำ:

  • การเปลี่ยนแปลงเกิดขึ้นทันที
  • ไม่จำเป็นต้องมีปุ่ม "ใช้"
  • โดยปกติเป็นการเปลี่ยนแปลงภาพหรือการสลับง่าย

การตั้งค่าที่ใช้

สิ่งเหล่านี้ต้องการให้คุณคลิก "ใช้", "ตกลง" หรือ "บันทึก" ก่อนที่จะมีผล

ตัวอย่าง:

  • พาธตำแหน่งบันทึก
  • โหมดการบันทึกเริ่มต้น
  • การกำหนดค่าเสียง/วิดีโอที่ซับซ้อน
  • การตั้งค่าสิทธิ์บางอย่าง

วิธีจดจำ:

  • มีปุ่ม "ใช้" หรือ "บันทึก" อยู่
  • คุณอาจเห็นตัวบ่งชี้ "การเปลี่ยนแปลงที่ยังไม่ได้บันทึก"
  • การเปลี่ยนแปลงไม่เกิดขึ้นจนกว่าคุณจะยืนยัน

สำคัญ: หากคุณเปลี่ยนการตั้งค่าและคลิก "ยกเลิก" การเปลี่ยนแปลงของคุณจะถูกทิ้ง! คลิก "ใช้" หรือ "ตกลง" เสมอหากคุณต้องการเก็บการเปลี่ยนแปลงของคุณ

ฟีเจอร์การค้นหา (ถ้ามี)

บางเวอร์ชันของ SeaMeet รวมกล่องค้นหาที่ด้านบนของแผงการตั้งค่า สิ่งนี้มีประโยชน์อย่างไม่น่าเชื่อ!

วิธีการใช้การค้นหา:

  1. มองหากล่องค้นหา (มักจะบอกว่า "ค้นหาการตั้งค่า..." หรือมีไอคอนแว่นขยาย)

  2. คลิกในกล่องค้นหาและพิมพ์คำสำคัญ:

    • "ไมโครโฟน" → แสดงการตั้งค่าที่เกี่ยวข้องกับไมโครโฟนทั้งหมด
    • "บันทึก" → แสดงการตั้งค่าการจัดเก็บและตำแหน่งบันทึก
    • "คุณภาพ" → แสดงการตั้งค่าคุณภาพวิดีโอและเสียง
    • "ทางลัด" → แสดงการตั้งค่าทางลัดคีย์บอร์ด

  3. ในขณะที่คุณพิมพ์ รายการการตั้งค่าจะกรองเพื่อแสดงเฉพาะรายการที่ตรงกัน

  4. คลิกที่ผลลัพธ์เพื่อกระโดดโดยตรงไปยังการตั้งค่านั้น

ทำไมการค้นหามีประโยชน์:

  • ค้นหาการตั้งค่าได้รวดเร็วโดยไม่ต้องเรียกดูหมวดหมู่
  • ค้นพบการตั้งค่าที่เกี่ยวข้องที่คุณไม่รู้ว่ามีอยู่
  • ดีเมื่อคุณไม่แน่ใจว่าการตั้งค่าอยู่ในหมวดหมู่ใด
  • ประหยัดเวลาเมื่อคุณรู้แน่นอนว่าต้องการเปลี่ยนอะไร

เวิร์กโฟลว์การตั้งค่าทั่วไป

นี่คือสถานการณ์ทั่วไปและขั้นตอนที่แน่นอนในการจัดการ:

สถานการณ์ที่ 1: การตั้งค่าครั้งแรก

คุณใหม่กับ SeaMeet และต้องการกำหนดค่าพื้นฐาน:

  1. เปิดการตั้งค่า (คลิกไอคอนเฟืองใน sidebar ซ้าย)

  2. ไปที่ทั่วไป

    • ตั้งธีมตามความชอบของคุณ
    • เปิดใช้งาน "ย่อเป็น tray" หากต้องการ
    • เปิดใช้งาน "เริ่มกับคอมพิวเตอร์" หากต้องการ

  3. ไปที่การจัดเก็บ

    • ตรวจสอบหรือเปลี่ยนตำแหน่งบันทึก
    • ตั้งค่าคำเตือนพื้นที่ดิสก์

  4. ไปที่เสียง

    • เลือกไมโครโฟนเริ่มต้นของคุณ
    • ทดสอบไมโครโฟนและปรับ gain
    • ตรวจสอบคำเตือน Bluetooth หากใช้หูฟังไร้สาย

  5. ไปที่ภาษา

    • เลือกภาษาที่แสดงที่คุณต้องการ

  6. คลิกใช้ เพื่อบันทึกการเปลี่ยนแปลงทั้งหมด

  7. ไปที่เกี่ยวกับ เพื่อบันทึกหมายเลขเวอร์ชันของคุณ (สะดวกสำหรับการสนับสนุน)

สถานการณ์ที่ 2: การเปลี่ยนที่บันทึกการบันทึก

ไดรฟ์ C: ของคุณกำลังเต็มและคุณต้องการย้ายการบันทึกไปยังไดรฟ์ภายนอก:

  1. เปิดการตั้งค่า

  2. คลิกที่การจัดเก็บ ใน sidebar ซ้าย

  3. ค้นหา "ตำแหน่งบันทึก" หรือ "ไดเรกทอรีการบันทึก"

  4. คลิกปุ่ม "Browse"

  5. นำทางไปยังไดรฟ์ภายนอก ใน file browser

    • ตัวอย่าง: D:\SeaMeet Recordings

  6. เลือกหรือสร้างโฟลเดอร์

  7. คลิกตกลง ใน file browser

  8. คลิกใช้ ในการตั้งค่า

  9. ตัวเลือก: ย้ายการบันทึกที่มีอยู่ของคุณไปยังตำแหน่งใหม่โดยใช้ File Explorer

สถานการณ์ที่ 3: การตั้งค่าการตรวจจับอัตโนมัติ

คุณต้องการให้ SeaMeet ตรวจจับการประชุม Zoom อัตโนมัติ:

  1. เปิดการตั้งค่า

  2. คลิกที่บันทึกอัตโนมัติ

  3. เปิดใช้งาน "การตรวจจับอัตโนมัติ" (toggle switch)

  4. ค้นหา Zoom ในรายการแอป

  5. เปิดใช้งานสิทธิ์สำหรับ Zoom (toggle หรือ checkbox)

  6. เลือกการกระทำเริ่มต้น: เริ่มบันทึกทันทีหรือเพียงแจ้งเตือน?

  7. ปรับความไว หากจำเป็น (slider)

  8. คลิกใช้

  9. ทดสอบ: เปิด Zoom และเริ่มการประชุมเพื่อดูว่า SeaMeet ตรวจจับหรือไม่

สถานการณ์ที่ 4: การปรับให้เหมาะสมสำหรับคอมพิวเตอร์เก่า

คอมพิวเตอร์ของคุณอายุไม่กี่ปีและทำงานช้าในระหว่างการบันทึก:

  1. เปิดการตั้งค่า

  2. ไปที่วิดีโอ

    • ลดคุณภาพวิดีโอเป็น 720p หรือ 480p
    • ตั้งอัตราเฟรมเป็น 30fps (แทน 60fps)
    • ปิดการเร่งฮาร์ดแวร์หากเป็นสาเหตุของปัญหา

  3. ไปที่ Flashback

    • เปิดใช้งาน "โหมด low-memory"
    • ลดระยะเวลาบัฟเฟอร์เป็น 30-60 วินาที (แทน 120)

  4. ไปที่เสียง

    • เลือก sample rate ที่ต่ำกว่าหากมี (44.1kHz แทน 48kHz)

  5. ไปที่การจัดเก็บ

    • เปิดใช้งานการล้างข้อมูลอัตโนมัติเพื่อป้องกันปัญหาพื้นที่ดิสก์

  6. คลิกใช้

  7. ทดสอบการบันทึก เพื่อดูว่าประสิทธิภาพดีขึ้นหรือไม่

สถานการณ์ที่ 5: การเตรียมสำหรับการนำเสนอระดับมืออาชีพ

คุณต้องบันทึกการนำเสนอคุณภาพสูงสำหรับงาน:

  1. เปิดการตั้งค่า

  2. ไปที่วิดีโอ

    • ตั้งคุณภาพเป็น 1080p (หรือสูงสุดที่มี)
    • ตั้งอัตราเฟรมเป็น 60fps สำหรับการเคลื่อนไหวที่ราบรื่น
    • เปิดใช้งาน "บันทึกเคอร์เซอร์"
    • เปิดใช้งาน "ไฮไลต์การคลิกเคอร์เซอร์" หากมี

  3. ไปที่เสียง

    • เลือกไมโครโฟนที่ดีที่สุดของคุณ
    • ตั้ง gain ในระดับที่เหมาะสม (ทดสอบก่อน!)
    • เลือกรูปแบบคุณภาพสูง (WAV สำหรับดีที่สุด หรือ MP3 bitrate สูง)

  4. ไปที่ทั่วไป

    • ปิดการแจ้งเตือนเพื่อป้องกันการรบกวน
    • ตรวจสอบให้แน่ใจว่า "ย่อเป็น tray" เปิดอยู่

  5. ไปที่การจัดเก็บ

    • ตรวจสอบว่าคุณมีพื้นที่ดิสก์เพียงพอ (วิดีโอ HD ใช้พื้นที่มาก!)

  6. คลิกใช้

  7. ทำการทดสอบบันทึก 30 วินาที เพื่อตรวจสอบว่าทุกอย่างดูและฟังดูสมบูรณ์แบบ

เคล็ดลับและทริคการตั้งค่า

เคล็ดลับที่ 1: ตาข่ายนิรภัย "รีเซ็ตเป็นค่าเริ่มต้น"

หากคุณเปลี่ยนการตั้งค่าและบางอย่างหยุดทำงาน อย่าตกใจ! ทุกหมวดหมู่มีปุ่ม "รีเซ็ตเป็นค่าเริ่มต้น" ที่คืนส่วนนั้นเป็นการตั้งค่าโรงงาน

วิธีการใช้:

  1. ไปที่หมวดหมู่ที่มีปัญหา
  2. คลิก "รีเซ็ตเป็นค่าเริ่มต้น" (มักจะอยู่ด้านล่าง)
  3. ยืนยันการรีเซ็ต
  4. ลองอีกครั้งด้วยการตั้งค่าที่สะอาด

ข้อควรระวัง: สิ่งนี้รีเซ็ตการตั้งค่าทั้งหมดในหมวดหมู่นั้น ไม่ใช่เพียงสิ่งที่คุณเปลี่ยนล่าสุด

เคล็ดลับที่ 2: ส่งออก/นำเข้าการตั้งค่า (ถ้ามี)

บางเวอร์ชันของ SeaMeet ให้คุณส่งออกการตั้งค่าของคุณไปยังไฟล์ สิ่งนี้ดีสำหรับ:

  • การสำรองข้อมูลความชอบของคุณ
  • การถ่ายโอนการตั้งค่าไปยังคอมพิวเตอร์อื่น
  • การแชร์การตั้งค่าที่ปรับให้เหมาะสมกับเพื่อนร่วมงาน

มองหา: ปุ่ม "ส่งออกการตั้งค่า" หรือ "นำเข้าการตั้งค่า" มักอยู่ในทั่วไปหรือที่ด้านล่างของแผงการตั้งค่า

เคล็ดลับที่ 3: การนำทางคีย์บอร์ด

คุณสามารถนำทางการตั้งค่าโดยไม่ใช้เมาส์:

  • Tab — ย้ายไปยังตัวควบคุมถัดไป
  • Shift + Tab — ย้ายไปยังตัวควบคุมก่อนหน้า
  • Spacebar — สลับ checkboxes หรือเปิดใช้งานปุ่ม
  • Arrow keys — นำทางตัวเลือก dropdown หรือปรับ sliders
  • Enter — ยืนยันการเลือกหรือเปิดใช้งานปุ่ม

สิ่งนี้มีประโยชน์โดยเฉพาะสำหรับการเข้าถึงหรือเมื่อเมาส์ของคุณไม่ทำงาน

เคล็ดลับที่ 4: Hover เพื่อขอความช่วยเหลือ

การตั้งค่าหลายอย่างมี tooltips ที่มีประโยชน์ Hover เมาส์ของคุณ เหนือชื่อหรือตัวควบคุมการตั้งค่าเพื่อดูข้อมูลเพิ่มเติม

ตัวอย่าง: Hover เหนือ "gain ไมโครโฟน" อาจแสดง: "ปรับสิ่งนี้หากการบันทึกของคุณเงียบเกินไปหรือดังเกินไป 50% เป็นค่าเริ่มต้น"

เคล็ดลับที่ 5: การตั้งค่าถูกบันทึกอัตโนมัติ (ปกติ)

ในกรณีส่วนใหญ่ SeaMeet จะบันทึกการตั้งค่าของคุณอัตโนมัติเมื่อคุณเปลี่ยน อย่างไรก็ตาม การเปลี่ยนแปลงที่ซับซ้อนบางอย่างต้องการการคลิก "ใช้"

สัญญาณว่าคุณต้องคลิกใช้:

  • ปุ่ม "ใช้" สามารถมองเห็นและคลิกได้
  • คุณเห็นข้อความเช่น "การเปลี่ยนแปลงที่ยังไม่ได้บันทึก"
  • การตั้งค่าเกี่ยวข้องกับ file paths หรือทรัพยากรภายนอก

เมื่อสงสัย: คลิกใช้! ไม่เคยเป็นอันตรายในการยืนยันการเปลี่ยนแปลงของคุณ

ทำความเข้าใจการคงอยู่ของการตั้งค่า

นี่คือสิ่งสำคัญที่ต้องเข้าใจ: การตั้งค่าถูกบันทึกไปยัง user profile ของคุณ และคงอยู่ระหว่างเซสชัน

สิ่งนี้หมายถึงอะไร:

  • การตั้งค่ายังคงอยู่เมื่อคุณปิดและเปิด SeaMeet ใหม่
  • การตั้งค่ายังคงเหมือนเดิมแม้ว่าคุณจะรีสตาร์ทคอมพิวเตอร์
  • การตั้งค่าผูกกับบัญชีผู้ใช้ Windows/Mac ของคุณ
  • หากคุณมีหลายบัญชีผู้ใช้ แต่ละบัญชีมีการตั้งค่าของตัวเอง

ที่ที่การตั้งค่าถูกเก็บ (ทางเทคนิค):

  • Windows: ปกติในโฟลเดอร์ user profile ของคุณ มักอยู่ใน AppData
  • macOS: ในโฟลเดอร์ user Library ของคุณ
  • คุณไม่จำเป็นต้องเข้าถึงไฟล์เหล่านี้โดยตรง — ใช้ UI การตั้งค่า

ข้อยกเว้น:

  • บางเวอร์ชันแบบพกพาอาจเก็บการตั้งค่าในโฟลเดอร์แอป
  • การปรับใช้องค์กรอาจใช้การตั้งค่าแบบรวมศูนย์
  • การติดตั้ง SeaMeet ใหม่ปกติจะรักษาการตั้งค่าผู้ใช้

ความปลอดภัยและความเป็นส่วนตัวของการตั้งค่า

การตั้งค่า SeaMeet เป็น local สำหรับคอมพิวเตอร์ของคุณและโดยทั่วไปไม่มีข้อมูลที่ละเอียดอ่อน อย่างไรก็ตาม:

สิ่งที่อยู่ในการตั้งค่า:

  • File paths (อาจเปิดเผยโครงสร้างโฟลเดอร์)
  • ความชอบแอป (ฟีเจอร์ใดที่คุณใช้)
  • การเลือกฮาร์ดแวร์ (ไมโครโฟนใดที่คุณต้องการ)
  • ไม่มีรหัสผ่านหรือข้อมูลรับรองบัญชี

ข้อพิจารณาด้านความเป็นส่วนตัว:

  • การตั้งค่าไม่รวมการบันทึกจริงของคุณ (แค่ที่ที่บันทึกถูกบันทึก)
  • การตั้งค่าการตรวจจับอัตโนมัติแสดงแอปที่คุณใช้ (แต่ไม่มีข้อมูลการใช้งาน)
  • ไม่มีการซิงค์คลาวด์ของการตั้งค่า (ทุกอย่างอยู่ในเครื่อง)

สภาพแวดล้อมองค์กร:

  • ผู้ดูแลระบบ IT อาจสามารถดูหรือจัดการการตั้งค่าได้
  • group policy อาจแทนที่การตั้งค่าบางอย่าง
  • ตรวจสอบกับแผนก IT ของคุณหากคุณมีข้อกังวล

การแก้ไขปัญหาการตั้งค่า

ปัญหาที่ 1: การตั้งค่าไม่บันทึก

อาการ: คุณเปลี่ยนการตั้งค่าแต่กลับคืนเมื่อคุณเปิดการตั้งค่าใหม่

วิธีแก้:

  1. ตรวจสอบให้แน่ใจว่าคุณคลิก "ใช้" — การตั้งค่าบางอย่างต้องการการบันทึกที่ชัดเจน
  2. ตรวจสอบพื้นที่ดิสก์ — หากไดรฟ์ของคุณเต็ม การตั้งค่าไม่สามารถบันทึกได้
  3. รันในฐานะผู้ดูแลระบบ — ลองคลิกขวา SeaMeet และ "Run as administrator"
  4. ตรวจสอบสิทธิ์ — ตรวจสอบให้แน่ใจว่าคุณมีสิทธิ์เขียนในโฟลเดอร์ user profile ของคุณ
  5. ติดตั้ง SeaMeet ใหม่ — สำรองข้อมูลการบันทึกของคุณก่อน จากนั้นติดตั้งใหม่

ปัญหาที่ 2: การตั้งค่าเป็นสีเทา

อาการ: การตั้งค่าบางอย่างมองเห็นได้แต่ไม่สามารถเปลี่ยนได้ (เป็นสีเทาหรือปิดใช้งาน)

สาเหตุทั่วไป:

  • การตั้งค่าอื่นปิดใช้งานพวกเขา — ตัวอย่างเช่น คุณไม่สามารถตั้งคุณภาพวิดีโอได้หากการบันทึกวิดีโอถูกปิดใช้งาน
  • ข้อจำกัด admin/enterprise — องค์กรของคุณอาจล็อกการตั้งค่าบางอย่าง
  • ฟีเจอร์ไม่พร้อมใช้งาน — ฟีเจอร์นั้นอาจไม่รวมอยู่ในเวอร์ชันของคุณ
  • ข้อจำกัดฮาร์ดแวร์ — การตั้งค่าบางอย่างต้องการฮาร์ดแวร์เฉพาะ

วิธีแก้:

  1. ตรวจสอบว่าคุณต้องเปิดใช้งานการตั้งค่าหลักก่อน
  2. ติดต่อแผนก IT ของคุณหากเป็นข้อจำกัดองค์กร
  3. ตรวจสอบเวอร์ชัน SeaMeet (บางฟีเจอร์เฉพาะเวอร์ชัน)
  4. ตรวจสอบว่าฮาร์ดแวร์ของคุณรองรับฟีเจอร์

ปัญหาที่ 3: UI การตั้งค่ามีปัญหา

อาการ: การตั้งค่าดูผิด ซ้อนทับ หรือไม่แสดงผลอย่างถูกต้อง

วิธีแก้:

  1. ปรับขนาดหน้าต่าง — ลองทำให้หน้าต่าง SeaMeet ใหญ่ขึ้น
  2. เริ่ม SeaMeet ใหม่ — ปิดและเปิดแอปใหม่
  3. อัปเดตไดรเวอร์กราฟิก — ไดรเวอร์ที่ล้าสมัยอาจทำให้เกิดปัญหา UI
  4. เปลี่ยนการปรับขนาดการแสดงผล — หากใช้ DPI สูง (4K) ลองปรับขนาด 100% ชั่วคราว
  5. ติดตั้ง SeaMeet ใหม่ — หากทุกอย่างล้มเหลว การติดตั้งใหม่มักแก้ปัญหา UI

ปัญหาที่ 4: ไม่สามารถค้นหาการตั้งค่า

อาการ: คุณรู้ว่าการตั้งค่ามีอยู่ แต่คุณไม่สามารถค้นหามันได้

วิธีแก้:

  1. ใช้การค้นหา — พิมพ์คำสำคัญในกล่องค้นหาการตั้งค่า
  2. ตรวจสอบหมวดหมู่ทั้งหมด — อาจอยู่ในหมวดหมู่ที่ไม่คาดคิด
  3. ตรวจสอบการตั้งค่าขั้นสูง — การตั้งค่าบางอย่างซ่อนอยู่หลังปุ่ม "ขั้นสูง"
  4. อัปเดต SeaMeet — การตั้งค่าอาจอยู่ในเวอร์ชันใหม่
  5. อ่านคู่มือ — แต่ละบทการตั้งค่าแสดงตัวเลือกที่มีทั้งหมด

ขั้นสูง: ตำแหน่งไฟล์การตั้งค่า (สำหรับผู้ใช้ขั้นสูง)

หากคุณเป็นผู้ใช้ทางเทคนิคและต้องการเข้าถึงการตั้งค่าโดยตรง นี่คือที่ที่จะหาพวกเขา:

Windows

การติดตั้งมาตรฐาน:

C:\Users\[YourUsername]\AppData\Roaming\SeaMeet\

ชื่อไฟล์อาจรวมถึง:

  • settings.json
  • config.json
  • preferences.json
  • SeaMeet.config

วิธีการเข้าถึง:

  1. กด Windows + R
  2. พิมพ์ %AppData%\SeaMeet และกด Enter
  3. มองหาไฟล์การตั้งค่า

คำเตือน: การแก้ไขไฟล์เหล่านี้ด้วยตนเองอาจทำให้ SeaMeet เสียหายได้ สำรองข้อมูลเสมอก่อน!

macOS

ตำแหน่งมาตรฐาน:

~/Library/Application Support/SeaMeet/

หรือใน preferences:

~/Library/Preferences/com.seameet.app.plist

วิธีการเข้าถึง:

  1. เปิด Finder
  2. กด Command + Shift + G
  3. พิมพ์ ~/Library/Application Support/SeaMeet
  4. คลิก Go

เมื่อใดที่จะแก้ไขไฟล์การตั้งค่าโดยตรง

โดยทั่วไป คุณไม่ควรต้องทำสิ่งนี้ แต่อาจเป็นประโยชน์สำหรับ:

  • การย้ายการตั้งค่าระหว่างคอมพิวเตอร์โดยไม่มีคลาวด์
  • การแก้ไขจำนวนมากของการตั้งค่าหลายอย่างพร้อมกัน
  • การกู้คืนการตั้งค่าจากการสำรองข้อมูล
  • การแก้ไขปัญหาเมื่อ UI ไม่เปิด

เสมอ:

  • ปิด SeaMeet อย่างสมบูรณ์ก่อนแก้ไข
  • สำรองสำเนาก่อน
  • ใช้ตัวแก้ไข JSON/ข้อความที่เหมาะสม (Notepad++, VS Code เป็นต้น)
  • ตรวจสอบรูปแบบไฟล์ถูกต้องก่อนบันทึก

รายการตรวจสอบการตั้งค่า: สิ่งที่จะกำหนดค่าก่อน

หากคุณรู้สึกท่วมท้นด้วยตัวเลือกทั้งหมด นี่คือรายการตรวจสอบที่จัดลำดับความสำคัญของการตั้งค่าที่สำคัญที่สุดที่จะกำหนดค่า:

จำเป็น (ทำสิ่งเหล่านี้ก่อน)

  • ตำแหน่งจัดเก็บ — ตรวจสอบให้แน่ใจว่าการบันทึกไปที่ที่คุณต้องการ
  • ไมโครโฟนเริ่มต้น — ตรวจสอบให้แน่ใจว่าอุปกรณ์ที่ถูกต้องถูกเลือก
  • ภาษา — ตั้งเป็นภาษาที่คุณต้องการ
  • ความชอบเริ่มต้นอัตโนมัติ — ตัดสินใจว่า SeaMeet ควรเริ่มกับคอมพิวเตอร์ของคุณหรือไม่

สำคัญ (ทำสิ่งเหล่านี้ในไม่ช้า)

  • คุณภาพวิดีโอ — ตั้งตามความต้องการและพลังคอมพิวเตอร์ของคุณ
  • รูปแบบเสียง — เลือกตามคุณภาพเทียบกับขนาดไฟล์
  • ธีม — โหมดสว่างหรือมืดเพื่อความสบาย
  • ทางลัดคีย์บอร์ด — ปรับให้ตรงกับเวิร์กโฟลว์ของคุณ

มีประโยชน์ (กำหนดค่าเมื่อจำเป็น)

  • แอปตรวจจับอัตโนมัติ — เปิดใช้งานสำหรับแอปที่คุณใช้บ่อย
  • การตั้งค่า Flashback — ปรับระยะเวลาบัฟเฟอร์ตามความชอบของคุณ
  • ความชอบการแจ้งเตือน — เลือกเหตุการณ์ใดที่แจ้งเตือนคุณ
  • ตัวเลือกการบันทึกเคอร์เซอร์ — สำหรับการบันทึกบทเรียน/การนำเสนอ

ตัวเลือก (ปรับแต่งภายหลัง)

  • การตั้งค่าเสียงขั้นสูง — sample rates, bit depths
  • ความชอบ codec วิดีโอ — การตั้งค่าการบีบอัด
  • รูปแบบการตั้งชื่อไฟล์ — รูปแบบกำหนดเองสำหรับการจัดระเบียบ
  • การปรับแต่ง hotkey — การแมปทางลัดคีย์บอร์ดขั้นสูง

อภิธานศัพท์การตั้งค่า: การอ้างอิงด่วน

นี่คืออภิธานศัพท์ด่วนของคำศัพท์ที่คุณจะเห็นทั่วการตั้งค่า:

เปิด/ปิดใช้งาน — เปิดหรือปิดฟีเจอร์ ค่าเริ่มต้น — การตั้งค่าที่ใช้เว้นแต่คุณจะระบุเป็นอย่างอื่น พาธ/ไดเรกทอรี — ตำแหน่งบนคอมพิวเตอร์ของคุณ (เช่น C:\Users\You\Documents) Browse — เปิด file browser เพื่อเลือกตำแหน่ง Bitrate — ใช้ข้อมูลต่อวินาทีเท่าใด (สูงกว่า = คุณภาพดีกว่า, ไฟล์ใหญ่กว่า) Sample Rate — เสียงถูกจับบ่อยแค่ไหนต่อวินาที (44.1kHz = 44,100 ครั้ง/วินาที) ความละเอียด — ขนาดภาพวิดีโอ (1080p = 1920×1080 พิกเซล) Frame Rate — กี่เฟรมวิดีโอต่อวินาที (fps) บัฟเฟอร์ — ที่จัดเก็บหน่วยความจำชั่วคราวสำหรับข้อมูลที่กำลังดำเนินอยู่ Gain — ระดับ volume ของอินพุต (ความไวไมโครโฟน) Codec — ซอฟต์แวร์ที่บีบอัด/คลายการบีบอัดเสียง/วิดีโอ รูปแบบ — ประเภทไฟล์ (MP3, MP4, WebM เป็นต้น) Toggle — สวิตช์ที่เปิดหรือปิดบางอย่าง ใช้ — บันทึกการเปลี่ยนแปลงที่คุณทำ รีเซ็ต — กลับไปยังค่าต้นฉบับ/ค่าเริ่มต้น
