முதன்மை இடைமுகம் - SeaMeet இன் UI முழு சுற்றுலா

அத்தியாயம் 11: முதன்மை இடைமுகம் - SeaMeet இன் UI முழு சுற்றுலா

இப்போது நீங்கள் SeaMeet ஐப் பயன்படுத்தி ஒலி மற்றும் வீடியோ பதிவு செய்துள்ளீர்கள், உங்கள் நூலகத்தை ஒழுங்குபடுத்தியுள்ளீர்கள், பதிவுகளை இயக்கியுள்ளீர்கள். இடைமுகத்தின் பல்வேறு பகுதிகளுடன் நீங்கள் தொடர்புகொண்டிருக்கிறீர்கள், ஆனால் எல்லா பகுதிகளும் எவ்வாறு ஒன்றாகப் பொருந்துகின்றன என்பதைப் பற்றிய முழுமையான படம் உங்களிடம் இல்லாமல் இருக்கலாம். இந்த அத்தியாயம் SeaMeet இன் முதன்மை இடைமுகத்தின் விரிவான சுற்றுலாவை வழங்குகிறது — ஒவ்வொரு பொத்தான், பேனல், காட்டி மற்றும் கட்டுப்பாடு — எனவே நீங்கள் நம்பிக்கையுடன் ஆப்பை வழிசெலுத்தலாம், நீங்கள் இன்னும் கண்டுபிடிக்காத அம்சங்களைக் கண்டறியலாம்.

இந்த அத்தியாயத்தை ஒரு புதிய வீட்டின் வழிகாட்டப்பட்ட சுற்றுலா என்று நினைத்துக்கொள்ளுங்கள். ஒவ்வொரு அறையிலும் நடந்து, அம்சங்களை ஆராய்ந்து, எல்லாவற்றையும் என்ன செய்கிறது என்று விளக்குவோம். முடிவில், ஒவ்வொரு செயல்பாட்டையும் எங்கே கண்டுபிடிப்பது என்பதையும், வெவ்வேறு சூழ்நிலைகளுக்கு இடைமுகம் எவ்வாறு மாறுகிறது என்பதையும் சரியாக அறிவீர்கள்.

இடது பேனல் — பதிவைத் தொடங்கு

இடது பேனல் ஒரு புதிய பதிவைத் தொடங்குவதற்கான அனைத்து கட்டுப்பாடுகளையும் கொண்டுள்ளது:

பக்கவாட்டு கட்டுப்பாடுகள் (அட்டையின் மேலே):

  • Flashback மாற்று (இடது) — Flashback முறையை மாற்ற கிளிக் செய்யுங்கள்: OFF → Audio → Screen → OFF. பஃபர் ஆயத்தமாக இருக்கும்போது ⚡ மின்னல் ஐகான் காட்டும். முழு விவரங்களுக்கு அத்தியாயம் 6 ஐப் பார்க்கவும்.
  • பெரிய சிவப்பு மைக் வட்டம் (மையம்) — வீடியோ அமைப்புகள் மாடலைத் திறந்து உங்கள் பதிவு முறையைத் தேர்ந்தெடுக்க கிளிக் செய்யுங்கள் (ஒலி மட்டும், முழுத்திரை, சாளரம், பகுதி).
  • Auto-Detect மாற்று (வலது) — ஒரு கூட்ட ஆப் கண்டறியப்படும்போது தானியங்கு பதிவை செயல்படுத்துகிறது.

சூழல் பகுதி (அட்டையின் நடுவில்):

  • Flashback OFF ஆக இருக்கும்போது: தொடங்குவது எப்படி என்ற சுருக்க விளக்கத்தைக் காட்டும்.
  • Flashback ஆயத்தமாகும்போது (சார்ஜிங்): பஃபர் நிரம்பும்போது முன்னேற்றக் குறிகாட்டியைக் காட்டும்.
  • Flashback தயாராக இருக்கும்போது: ⚡ ஐகான் மற்றும் "Flashback armed" உறுதிப்படுத்தலைக் காட்டும்.

CTA பொத்தான் (அட்டையின் கீழே):

  • லேபிள் மற்றும் செயல் Flashback நிலைக்கேற்ப மாறும்:
    • Flashback OFF → "Start Recording" (வீடியோ அமைப்புகளைத் திறக்கும்)
    • Flashback ஆயத்தமாகிறது → "Buffering…" (நிரம்பும்போது முடக்கப்பட்டது)
    • Flashback தயார் → "Record with Flashback" (பஃபரைப் பிடித்து பதிவைத் தொடங்கும்)

விரைவு-தொடக்க குறுக்குவழிகள் (கீழ் பட்டை):

  • Open Launcher — ஹாட்கீ காட்டப்பட்ட SeaMeet லாஞ்சர் பேனலைத் திறக்கிறது
  • Open Floater — ஹாட்கீ காட்டப்பட்ட Floater விட்ஜெட்டைக் காட்டுகிறது/மறைக்கிறது

வலது பேனல் — படம் பிடி

வலது பேனல் பதிவுகளிலிருந்து சுதந்திரமாக படம் பிடிப்பதைக் கையாளுகிறது:

  • கேமரா ஐகான் பொத்தான் — பெரிய ஹீரோ பொத்தான்; தற்போது தேர்ந்தெடுக்கப்பட்ட முறையைப் பயன்படுத்தி படம் பிடிக்க கிளிக் செய்யுங்கள்.
  • Full Screen / Area Capture — முழுத்திரை பிடிப்பு அல்லது ஒரு பகுதியை வரைவதற்கு இடையே தேர்வு செய்ய ரேடியோ பொத்தான்கள்.
  • Keep SeaMeet window visible checkbox — தேர்வு நீக்கப்பட்டிருக்கும்போது (இயல்புநிலை), SeaMeet படம் பிடிக்கும் முன் தன்னைச் சிறிதாக்கிக்கொள்ளும், எனவே படத்தில் தோன்றாது. தேர்வு செய்யப்பட்டிருக்கும்போது, சாளரம் காணக்கூடியதாக இருக்கும், படத்தில் தோன்றும்.
  • "Take Screenshot" பொத்தான் — பிடிப்பைத் தூண்டுகிறது (கேமரா ஐகானைக் கிளிக் செய்வதைப் போலவே).

நோக்கம்:

  • பிடிப்பைத் தொடங்குவதற்கு முன் உங்களுக்குத் தேவையான அனைத்துக்கும் ஒரே-நிறுத்தப் புள்ளி
  • அமைப்புகளைத் திறக்காமல் Flashback நிலை காணக்கூடியது மற்றும் கட்டுப்படுத்தக்கூடியது
  • படம் பிடி மற்றும் பதிவு இரண்டு அட்டைகளாக சுத்தமாகப் பிரிக்கப்பட்டுள்ளன

  • பொதுவான செயல்களுக்கு மவுஸை விட வேகமானது
  • Space இயக்கு/இடைநிறுத்தத்திற்கு
  • அம்புக்குறிகள் வழிசெலுத்தலுக்கு
  • முழு பட்டியலுக்கு அத்தியாயம் 13 ஐப் பார்க்கவும்

2. வலது-கிளிக் சூழல் மெனுக்களுக்கு

  • பதிவுகளுக்கு வலது-கிளிக் மெனுக்கள் உள்ளன
  • பொதுவான செயல்களுக்கு விரைவான அணுகல்
  • வெவ்வேறு பகுதிகளில் வெவ்வேறு விருப்பங்கள்

3. நிற்கும்போது காட்டப்படும் குறிப்புகளைப் பாருங்கள்

  • பதிவுகளைக் கண்டுபிடிக்க வேகமான வழி
  • நிகழ்நேரத்தில் வேலை செய்கிறது
  • பெயர்கள் மற்றும் மூலங்களைத் தேடுகிறது

  • நீலம்: தகவல், இணைப்புகள், தேர்வு
