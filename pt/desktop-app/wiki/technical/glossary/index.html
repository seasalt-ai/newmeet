Glossário de termos

Capítulo 30: Glossário de termos

Introdução

Software de gravação, como qualquer área técnica, vem com o seu próprio vocabulário. Palavras como "codec", "taxa de bits", "taxa de imagem" e "codificação" são constantemente atiradas para cá e para lá. Este capítulo é o seu dicionário abrangente — explicando cada termo técnico que possa encontrar ao usar o SeaMeet ou ao ler sobre gravação de áudio/vídeo.

Não se preocupe se não é técnico. Cada termo é explicado em português simples com analogias para o ajudar a compreender. Use este capítulo como referência sempre que encontrar uma palavra desconhecida.

Objetivos do capítulo

Depois de ler este capítulo, será capaz de:

  • Compreender termos técnicos usados no SeaMeet
  • Saber a diferença entre termos comummente confundidos
  • Usar terminologia correta ao resolver problemas
  • Tomar decisões informadas com base em conceitos técnicos

A

Audio Buffer (Buffer de áudio)

Armazenamento temporário de dados de áudio antes de serem processados ou guardados. Como uma sala de espera onde amostras de áudio se alinham antes de serem codificadas.

Audio Interface (Interface de áudio)

Hardware que liga microfones e instrumentos ao seu computador. Frequentemente fornece melhor qualidade de áudio do que placas de som incorporadas.

Action Items (AI) (Ações a tomar (IA))

Tarefas identificadas pela Extração por IA a partir de uma gravação. Cada ação inclui a descrição da tarefa, a pessoa atribuída e uma data limite (se mencionada na conversa). Ver Capítulo 32.

AI Extraction (Extração por IA)

A funcionalidade de análise pós-gravação do SeaMeet. Depois de uma gravação terminar, clicar em ✨ Generate Summary envia o áudio para o motor de IA, que devolve cinco saídas estruturadas: Transcrição, Resumo, Ações, Decisões-chave e Capítulos. Ver Capítulo 32.

AI Insights

O painel no SeaMeet que apresenta todos os resultados gerados por IA para uma gravação. Acessível a partir da vista de detalhe da gravação. Contém separadores para Transcrição, Resumo, Ações, Decisões e Capítulos.

Audio Track (Faixa de áudio)

Um fluxo separado de áudio dentro de um ficheiro de vídeo. Um vídeo pode ter várias faixas: o seu microfone, áudio do sistema, música de fundo.

Auto-Detection (Deteção automática)

A funcionalidade do SeaMeet que reconhece automaticamente quando se junta a uma reunião e pode iniciar a gravação sem intervenção manual.

Auto-pick

O classificador que seleciona automaticamente o modelo de resumo de IA mais apropriado com base no conteúdo da gravação. Quando regenera um resumo, o Auto-pick analisa a transcrição e escolhe o modelo que melhor se ajusta (ex.: standup, chamada de vendas, entrevista) para que não tenha de escolher manualmente. Ver Capítulo 33.

AVI (Audio Video Interleave)

Um formato mais antigo de ficheiro de vídeo desenvolvido pela Microsoft. Funciona bem em Windows mas é menos compatível com dispositivos modernos.

B

Bit

A menor unidade de informação digital. Ou um 0 ou 1. Tudo no seu computador é feito de bits.

BYOK (Bring Your Own Key)

O modelo de assinatura do SeaMeet onde os utilizadores fornecem as suas próprias chaves de API LLM (ex.: OpenAI, Anthropic, Google) em vez de pagar pela inferência através do SeaMeet. Os custos são faturados diretamente pelo fornecedor; o SeaMeet apenas cobra pela aplicação.

Bit Depth (Áudio) (Profundidade de bits)

Quantos bits são usados para representar cada amostra de áudio. Maior profundidade de bits = mais detalhe = ficheiros maiores. Qualidade CD é 16-bit.

Bitrate (Taxa de bits)

A quantidade de dados processados por segundo. Geralmente medida em kilobits por segundo (kbps) ou megabits por segundo (Mbps). Maior = melhor qualidade = ficheiros maiores.

Bluetooth Latency (Latência Bluetooth)

O atraso entre quando o som é produzido e quando o ouve numa ligação Bluetooth. Tipicamente 100-300ms, o que causa problemas de sincronização.

Buffer

Área de armazenamento temporário que retém dados enquanto estão a ser transferidos ou processados. Como um reservatório que retém água antes de fluir através de um tubo.

Buffer Duration (Flashback) (Duração do buffer)

Quantos segundos de filmagem o SeaMeet mantém no buffer circular. Quando guarda o Flashback, obtém esta quantidade de filmagem passada.

Byte

Um grupo de 8 bits. A unidade padrão para medir tamanhos de ficheiro. Um megabyte (MB) é cerca de um milhão de bytes.

C

Circular Buffer (Buffer circular)

Um tipo de buffer que volta ao início quando atinge o fim. O SeaMeet usa isto para o Flashback — gravando constantemente e sobrescrevendo dados antigos.

Codec (Coder-Decoder)

Software que comprime e descomprime áudio ou vídeo. H.264 é um codec de vídeo. MP3 é um codec de áudio.

Codec vs. Container (Codec vs. Contentor)

Codec é o método de compressão (como os dados são espremidos). Contentor é o formato do ficheiro (a caixa que contém os dados). MP4 é um contentor que frequentemente contém vídeo H.264.

Compression (Compressão)

Reduzir o tamanho do ficheiro removendo dados redundantes ou menos importantes. Pode ser sem perdas (sem perda de qualidade) ou com perdas (alguma perda de qualidade mas ficheiros mais pequenos).

Chapters (AI) (Capítulos (IA))

Uma das cinco saídas da Extração por IA. Segmentos de tópicos indexados por tempo, semelhantes a capítulos num livro. Clicar num capítulo no painel AI Insights salta o reprodutor para esse momento na gravação. Ver Capítulo 32.

Chunked Pipeline (Pipeline em partes)

A estratégia de extração por IA que processa vídeos longos em fatias de 10 minutos para se manter dentro da janela de contexto do Gemini. Cada parte é transcrita e resumida separadamente, depois unidas numa saída coerente única. Usado automaticamente para gravações que excedem a capacidade de uma única passagem do modelo.

Conflict Resolution Modal (Modal de resolução de conflitos)

O diálogo que aparece quando a sincronização com GitHub deteta a mesma nota editada de forma diferente em dois dispositivos. Permite-lhe escolher qual versão manter, ou unir alterações manualmente. Ver Capítulo 38.

CPU (Central Processing Unit) (Unidade central de processamento)

O "cérebro" do seu computador. Faz cálculos e corre programas. Software de gravação usa CPU para codificar vídeo.

Cursor Highlighting (Destaque do cursor)

Um efeito visual que chama a atenção para o seu cursor do rato nas gravações. Útil para tutoriais para que os espectadores possam seguir as suas ações.

D

Decibel (dB)

Uma unidade para medir o volume de som. Usada nos medidores de nível de áudio do SeaMeet. -12 dB é bom nível de gravação. 0 dB é o máximo (distorção).

Default Device (Dispositivo predefinido)

O dispositivo de áudio ou vídeo que o Windows/macOS usa automaticamente. O SeaMeet pode usar o predefinido ou deixá-lo escolher um dispositivo específico.

Detection Method (Auto-Detection) (Método de deteção)

Como o SeaMeet reconhece que está numa reunião. Os métodos incluem análise de título de janela, monitorização de processos e deteção de áudio.

Digital Audio (Áudio digital)

Som representado como números. O seu computador converte ondas sonoras em amostras digitais (números) que podem ser armazenadas e processadas.

Disk Space (Espaço em disco)

A quantidade de armazenamento disponível no seu disco rígido ou SSD. Gravar vídeo requer espaço em disco significativo.

DRM (Digital Rights Management) (Gestão de direitos digitais)

Tecnologia que previne a cópia de conteúdo protegido. Netflix, DVDs e alguns serviços de streaming usam DRM, o que previne a gravação de ecrã.

Decisions (AI) (Decisões (IA))

Uma das cinco saídas da Extração por IA. Uma lista de escolhas-chave e acordos feitos durante a reunião, extraídos da conversa. Distinta das Ações — decisões são o que foi acordado, ações são o que tem de ser feito como resultado. Ver Capítulo 32.

Drop Frame

Quando uma gravação de vídeo perde imagens, causando saltos. Geralmente acontece quando o computador não consegue acompanhar as exigências de codificação.

E

Echo Cancellation (Cancelamento de eco)

Tecnologia que remove o eco das gravações. Útil ao usar altifalantes em vez de auscultadores — previne que o seu microfone capte o som dos altifalantes.

Encode (Codificar)

O processo de converter vídeo/áudio em bruto num formato comprimido. CPU ou GPU fazem isto em tempo real enquanto grava.

Encoder (Codificador)

Software ou hardware que realiza codificação. O SeaMeet usa codificadores de software (CPU) ou codificadores de hardware (GPU).

External Drive (Unidade externa)

Um disco rígido ou SSD que se liga via USB. Pode ser usado para armazenar gravações mas pode ser mais lento do que unidades internas.

F

Flashback

A funcionalidade máquina do tempo do SeaMeet que grava continuamente num buffer circular, permitindo-lhe guardar momentos do passado.

Flashback Buffer

O armazenamento temporário de memória usado pelo Flashback. Retém os últimos X segundos de vídeo/áudio.

Floater (SeaMeet Floater)

O widget flutuante que aparece no seu ecrã para controlos rápidos de gravação. Pode ser minimizado para um pequeno ícone ou expandido para controlos completos.

FPS (Frames Per Second) (Imagens por segundo)

Quantas imagens estáticas (frames) são capturadas por segundo para criar vídeo. 30fps é padrão. 60fps é mais suave.

Fullscreen Recording (Gravação de ecrã inteiro)

Modo de gravação que captura todo o seu ecrã. Útil para reuniões e quando quer capturar tudo.

Frame (Imagem)

Uma única imagem estática num vídeo. O vídeo é essencialmente uma série de imagens reproduzidas rapidamente (30-60 por segundo) para criar movimento.

Fuzzy Search (Pesquisa difusa)

A pesquisa ordenada por relevância na barra lateral e Biblioteca multimédia que encontra correspondências mesmo quando a consulta tem erros ortográficos ou apenas se sobrepõe parcialmente com o título. Substitui a antiga correspondência por subcadeia exata, pelo que "rev trim" ainda encontra "Revisão Trimestral". Ver Capítulo 10.

G

Gain (Ganho)

O nível de amplificação de um sinal de áudio. Aumentar o ganho torna o áudio mais alto na gravação. Diferente do volume (que afeta a reprodução).

Game Mode (Modo de jogo)

Funcionalidade do Windows que prioriza aplicações de jogo. Pode ajudar o desempenho da gravação mas por vezes conflitua com software de gravação.

GitHub Sync

A funcionalidade de sincronização entre dispositivos do SeaMeet apoiada por um repositório GitHub privado. As notas e metadados são feitos commit para o seu repositório para que o mesmo espaço de trabalho esteja disponível em todas as máquinas onde instalou o SeaMeet. Ver Capítulo 38.

GPU (Graphics Processing Unit) (Unidade de processamento gráfico)

A placa gráfica no seu computador. Pode ser usada para codificação de vídeo acelerada por hardware (muito mais rápida que CPU).

GPU Encoding (Codificação GPU)

Usar a placa gráfica em vez do CPU para codificar vídeo. Também chamada aceleração de hardware. Mais rápida e mais eficiente.

H

H.264 (AVC)

O codec de vídeo mais comum. Fornece boa qualidade com tamanhos de ficheiro razoáveis. Funciona em virtualmente todos os dispositivos.

H.265 (HEVC)

Um codec de vídeo mais recente e mais eficiente. Produz ficheiros cerca de 50% mais pequenos do que H.264 com a mesma qualidade. Suporte universal menor.

Hardware Acceleration (Aceleração de hardware)

Usar hardware especializado (como GPU) para realizar tarefas em vez do CPU geral. Torna a codificação de vídeo muito mais rápida.

Hardware Encoder (Codificador de hardware)

Chip dedicado no GPU que codifica vídeo. NVIDIA chama ao seu NVENC. Intel chama ao seu Quick Sync.

HD (High Definition) (Alta definição)

Resolução de vídeo de 1280×720 (720p) ou superior. Fornece vídeo claro e detalhado.

Headphones vs. Speakers (Auscultadores vs. Altifalantes)

Usar auscultadores ao gravar previne eco (som dos altifalantes ser captado pelo microfone). Recomendado para melhor qualidade de áudio.

I

I-Frame (Intra-frame)

Uma imagem de vídeo completa que não depende de outras imagens. Atua como ponto de referência. Maior tamanho de ficheiro mas necessária para procura.

Import (Importar)

Trazer ficheiros externos de áudio ou vídeo para o SeaMeet. O SeaMeet pode importar vários formatos para reprodução e gestão.

Input Device (Dispositivo de entrada)

Hardware que envia áudio/vídeo para o seu computador. Microfones, câmaras e placas de captura são dispositivos de entrada.

J

Jitter

Variação no tempo dos dados de áudio/vídeo. Causa reprodução com saltos ou irregular. Geralmente devido a problemas de desempenho do sistema.

Join a Meeting (Juntar-se a uma reunião)

Entrar numa reunião online via Zoom, Teams, Meet, etc. O SeaMeet pode auto-detetar quando se junta e iniciar a gravação.

K

Kbps (Kilobits per second) (Kilobits por segundo)

Uma medida de taxa de dados. Usada para taxas de bits de áudio. 128 kbps é padrão para MP3. 192 kbps é maior qualidade.

Keyframe

Ver I-Frame. Imagens de vídeo completas usadas como pontos de referência.

Keyboard Shortcuts (Atalhos de teclado)

Combinações de teclas que acionam ações rapidamente. Ctrl+Alt+R inicia a gravação. Os atalhos poupam tempo em vez de clicar na interface.

L

Latency (Latência)

Atraso entre uma ação e quando é processada ou ouvida. Auscultadores Bluetooth têm alta latência. Auscultadores com fios quase não têm.

Live Transcription (Transcrição ao vivo)

A funcionalidade do SeaMeet que converte voz em texto em tempo real durante uma gravação. As palavras aparecem no painel de transcrição à medida que são ditas, com marca temporal e etiquetadas por orador. Requer recursos de IA ativados e uma ligação à internet. Ver Capítulo 31.

Library (Recording Library) (Biblioteca (Biblioteca de gravações))

A coleção de todas as suas gravações no SeaMeet. Mostra miniaturas, metadados e permite reprodução/gestão.

Lite Mode (Modo Lite)

A superfície mais pequena e centrada na área de notificação do SeaMeet. Retira a janela principal aos elementos essenciais — iniciar/parar gravação, itens recentes, definições rápidas — e é concebida para viver na área de notificação do sistema com mínima pegada no ecrã.

Lossless Compression (Compressão sem perdas)

Compressão que reduz o tamanho do ficheiro sem perder quaisquer dados. Pode ser reconstruída perfeitamente. O áudio FLAC usa compressão sem perdas.

Lossy Compression (Compressão com perdas)

Compressão que remove permanentemente alguns dados para obter ficheiros mais pequenos. MP3 e H.264 são com perdas. A perda de qualidade é geralmente impercetível.

Low-Memory Mode (Modo de pouca memória)

Funcionalidade do SeaMeet que reduz a qualidade para usar menos RAM. Útil para computadores mais antigos ou ao executar aplicações intensivas em memória.

M

Macroblock (Macrobloco)

Um quadrado de 16×16 píxeis usado na compressão de vídeo. H.264 divide imagens em macroblocos para comprimir eficientemente.

Mbps (Megabits per second) (Megabits por segundo)

Uma medida de taxa de dados usada para vídeo. 8 Mbps é bom para vídeo 1080p. Maior = melhor qualidade = ficheiros maiores.

MCP Server (Servidor MCP)

O servidor Model Context Protocol que o SeaMeet expõe para que o Agente IA possa listar modelos, regenerar resumos, obter transcrições e, de outra forma, conduzir o SeaMeet a partir de um cliente LLM ligado. Corre como processo filho a partir de dist-main/mcp-server.cjs.

Media Library (Biblioteca multimédia)

O navegador dedicado de janela inteira para gravações e capturas de ecrã. Suporta vistas de grelha e lista, filtros (data, duração, etiquetas) e operações em lote (eliminar, exportar, etiquetar). Distinta da Biblioteca de gravações da barra lateral. Ver Capítulo 10.

Metadata (Metadados)

Informação sobre um ficheiro (não o conteúdo real). Inclui data de criação, duração, resolução, etc.

Microphone Array (Conjunto de microfones)

Vários microfones a trabalhar em conjunto. Alguns portáteis têm conjuntos de microfones para melhor captação de som e cancelamento de ruído.

Minimize to Tray (Minimizar para área de notificação)

O SeaMeet pode correr em segundo plano, acessível via ícone da área de notificação do sistema (perto do seu relógio). Poupa espaço na barra de tarefas.

MKV (Matroska)

Um formato de contentor de vídeo flexível. Suporta várias faixas de áudio e legendas. Bom para arquivo.

Monitor

O ecrã do seu computador. O SeaMeet pode gravar um monitor ou todos os monitores se tiver várias apresentações.

Mono vs. Stereo (Mono vs. Estéreo)

Mono = 1 canal de áudio. Estéreo = 2 canais (esquerdo e direito). Estéreo soa mais imersivo mas cria ficheiros maiores.

MOV

Formato de contentor de vídeo da Apple. Comum em Macs. Boa qualidade mas menos compatível com Windows sem software adicional.

MP3

O formato de áudio mais popular. Usa compressão com perdas. Ficheiros pequenos, compatibilidade universal. 128-320 kbps típico.

MP4

O formato de contentor de vídeo mais popular. Funciona em virtualmente todos os dispositivos. Geralmente contém vídeo H.264 e áudio AAC.

Multi-Monitor (Multimonitor)

Usar mais do que um ecrã. O SeaMeet pode gravar todos os monitores ou apenas um. Gravar vários monitores usa mais recursos.

Mute (Silenciar)

Desligar temporariamente a entrada ou saída de áudio. O SeaMeet pode silenciar a gravação sem afetar o volume do sistema.

N

Native Resolution (Resolução nativa)

O número real de píxeis que o seu ecrã apresenta. Gravar em resolução nativa fornece resultados mais nítidos.

Noise Suppression (Supressão de ruído)

Tecnologia que remove ruído de fundo (ventoinhas, ar condicionado) das gravações de áudio. Torna as vozes mais claras.

Notification (Notificação)

Uma mensagem pop-up que o alerta para eventos. O SeaMeet mostra notificações quando as gravações iniciam, param, ou quando reuniões são detetadas.

NVENC

O codificador de vídeo de hardware da NVIDIA. Disponível em GTX série 600 e mais recentes. Codificação muito rápida com uso mínimo de CPU.

O

OAuth Auto-Refresh (Auto-atualização OAuth)

O mecanismo de atualização de token da sincronização com GitHub que corre 5 minutos antes da expiração do token. Mantém a sessão de sincronização viva sem forçar o utilizador a re-autenticar, transitando a máquina de estado de sincronização de volta a synced sem qualquer interrupção visível. Ver Capítulo 38.

Ogg

Um formato de áudio de código aberto. Boa compressão mas suporte limitado de dispositivos. Frequentemente usa codec Vorbis.

Output Device (Dispositivo de saída)

Hardware que reproduz áudio do seu computador. Altifalantes e auscultadores são dispositivos de saída.

Overhead (CPU/Memory) (Sobrecarga (CPU/Memória))

Recursos usados pelo próprio software de gravação, separados da gravação real. O SeaMeet tem baixa sobrecarga.

P

P-Frame (Predicted Frame)

Uma imagem de vídeo que apenas armazena alterações da imagem anterior. Muito mais pequena do que I-Frames. Cria compressão eficiente.

PCM (Pulse Code Modulation)

Formato de áudio digital não comprimido. Usado internamente antes da codificação para MP3 ou outros formatos. Alta qualidade, ficheiros grandes.

Permissions (Permissões)

Autorização para aceder a recursos do sistema. macOS e Windows requerem que conceda permissão ao SeaMeet para gravar ecrã e áudio.

Pixel (Píxel)

Um único ponto de cor no seu ecrã. As imagens são feitas de milhares ou milhões de píxeis. 1920×1080 = cerca de 2 milhões de píxeis.

Playback (Reprodução)

Ver ou ouvir uma gravação. O SeaMeet tem um reprodutor incorporado para rever gravações.

Pop Filter (Filtro de pop)

Uma cobertura de espuma ou rede para microfones que reduz sons de estouro "p" e "b". Melhora a qualidade do áudio.

Process Monitoring (Monitorização de processos)

Método de auto-deteção que observa que programas estão a correr. Deteta quando zoom.exe ou Teams.exe arranca.

Q

Quantization (Quantização)

Reduzir a precisão dos dados para poupar espaço. Parte da compressão. Simplifica cores/sons que são quase idênticos.

Quick Sync

O codificador de vídeo de hardware da Intel. Incorporado em processadores Intel modernos. Eficiente e boa qualidade para gravação.

R

RAM (Random Access Memory)

A memória de curto prazo do seu computador. O SeaMeet usa RAM para buffers do Flashback e processamento. Mais RAM = melhor desempenho.

RAW Audio/Video (Áudio/Vídeo em bruto)

Dados não comprimidos. Ficheiros grandes mas qualidade máxima. O SeaMeet geralmente codifica para formatos comprimidos para poupar espaço.

Real-time (Tempo real)

Acontecer ao vivo, sem atraso. O SeaMeet codifica vídeo em tempo real à medida que grava. Sem esperar por pós-processamento.

Recording Mode (Modo de gravação)

Como o SeaMeet captura vídeo: ecrã inteiro (todo o ecrã), janela (aplicação específica) ou região (área selecionada).

Region Recording (Gravação de região)

Gravar apenas uma porção selecionada do seu ecrã. Modo mais eficiente — captura apenas o que precisa.

Resolution (Resolução)

O número de píxeis numa imagem. 1920×1080 significa 1920 píxeis de largura por 1080 píxeis de altura. Maior = mais nítido = ficheiros maiores.

Ring Menu (Floater) (Menu em anel)

A interface de controlo circular que aparece quando expande o widget Floater. Fornece acesso rápido aos controlos de gravação.

S

Sample Rate (Audio) (Taxa de amostragem)

Quantas vezes por segundo o áudio é medido. Qualidade CD é 44,1 kHz (44.100 amostras por segundo). Maior = melhor qualidade.

Sampling (Amostragem)

Converter ondas sonoras contínuas em números digitais medindo a intervalos regulares.

Save Location (Localização para guardar)

A pasta onde o SeaMeet armazena gravações. Pode ser alterada nas definições. Deve ter bastante espaço livre.

Screen Recording (Gravação de ecrã)

Capturar vídeo do ecrã do seu computador. O SeaMeet especializa-se em gravação de ecrã com áudio.

Screenshot (Captura de ecrã)

Uma captura de imagem estática do seu ecrã. O SeaMeet pode tirar capturas via atalho de teclado ou Floater.

Sensitivity (Auto-Detection) (Sensibilidade)

Quão agressivamente o SeaMeet procura reuniões. Alta sensibilidade apanha mais reuniões mas pode ter falsos positivos.

Shortcut (Atalho)

Ver Atalhos de teclado. Forma rápida de controlar o SeaMeet sem usar o rato.

Sidebar (Barra lateral)

O painel esquerdo no SeaMeet a mostrar diferentes secções: Gravações, Vídeo, Flashback, etc.

Slash Menu (Menu de barra)

O menu de inserção de blocos no editor de notas, invocado escrevendo / numa nova linha. Permite-lhe inserir cabeçalhos, listas, callouts, blocos de código, incorporações e outros tipos de blocos sem sair do teclado. Ver Capítulos 16-17.

Source (Audio/Video) (Fonte)

A origem do sinal. As fontes de áudio incluem microfone e áudio do sistema. As fontes de vídeo incluem ecrã e janelas.

Speaker Detection (Deteção de orador)

O processo automático de identificar que pessoa está a falar durante a transcrição ao vivo ou Extração por IA. A cada voz distinta é atribuído um rótulo ("Orador 1", "Orador 2"). A precisão melhora com áudio claro e mínima conversa cruzada. Ver Capítulo 31.

Speaker Label (Rótulo de orador)

O nome atribuído a um orador numa transcrição. Predefinições para "Orador 1", "Orador 2", etc. Pode ser renomeado (ex.: "Alice") ou unido a outro rótulo se dois rótulos pertencem à mesma pessoa. Ver Capítulo 34.

SplitButtonMenu (Menu de botão dividido)

O controlo de UI no separador AI Summary que combina a ação primária com um menu para ações relacionadas — ex.: um único botão que corre "Regenerar com Auto-pick" por predefinição mas oferece escolhas de "Modelo manual" a partir do galão. Ver Capítulos 33-34.

SRT (SubRip Subtitle)

Um formato de ficheiro de texto para legendas. Contém linhas de texto com marca temporal. O SeaMeet pode exportar transcrições como ficheiros SRT, que podem ser importados para editores de vídeo (Premiere, iMovie) ou carregados para o YouTube como legendas.

SSD (Solid State Drive) (Disco de estado sólido)

Dispositivo de armazenamento rápido sem partes móveis. Melhor para gravação do que discos rígidos tradicionais (HDD). Velocidades de escrita mais rápidas.

Stereo Mix

Funcionalidade de áudio do Windows que lhe permite gravar áudio do sistema. O SeaMeet pode usar Stereo Mix ou WASAPI para captura de áudio do sistema.

Storage (Armazenamento)

Espaço no seu disco rígido ou SSD onde as gravações são guardadas. Gravações de vídeo requerem muito espaço de armazenamento.

Stream (Fluxo)

Fluxo contínuo de dados. Fluxos de áudio e vídeo são capturados e codificados durante a gravação.

Sync (Audio-Video) (Sincronização)

Quando áudio e vídeo estão devidamente alinhados. Fora de sincronização significa que vê lábios moverem-se antes/depois de ouvir as palavras.

Sync State Machine (Máquina de estado de sincronização)

O ciclo de vida da sincronização com GitHub: idle → pending → syncing → synced, com ramos para error, offline, token-expired, installing-app e creating-repo. O estado é surgido no indicador de estado de sincronização para que saiba exatamente onde a sincronização está em qualquer momento. Ver Capítulo 38.

System Audio (Áudio do sistema)

Som do seu computador — notificações, vídeos, vozes de reunião. O SeaMeet pode gravar áudio do sistema separadamente do microfone.

System Tray (Área de notificação do sistema)

A área perto do seu relógio onde aplicações em segundo plano mostram ícones. O SeaMeet pode minimizar para a área de notificação do sistema.

T

Template (AI Summary Template) (Modelo)

Um prompt estruturado que molda a saída da extração por IA para um tipo de reunião específico — ex.: um modelo de standup enfatiza bloqueios e o plano de amanhã, enquanto um modelo de chamada de vendas enfatiza objeções e próximos passos. Os modelos podem ser escolhidos manualmente ou via Auto-pick. Ver Capítulo 33.

Theme (Light/Dark) (Tema (Claro/Escuro))

Aparência visual do SeaMeet. Tema claro tem fundos brancos. Tema escuro tem fundos escuros. Mais fácil para os olhos à noite.

Thumbnail (Miniatura)

Pequena imagem de pré-visualização representando um vídeo. O SeaMeet mostra miniaturas das suas gravações na biblioteca.

Time Machine (Flashback) (Máquina do tempo)

Metáfora para a funcionalidade Flashback. Permite-lhe "voltar no tempo" para capturar momentos que já aconteceram.

Timeline (Linha do tempo)

Representação visual da duração de uma gravação. O reprodutor do SeaMeet mostra uma linha do tempo com a posição de reprodução.

Toggle (Alternador)

Um interruptor que liga ou desliga uma funcionalidade. O SeaMeet usa alternadores nas definições — clique para alternar entre estados.

Transcript (Transcrição)

Um registo de texto de áudio falado. O SeaMeet produz dois tipos: uma transcrição ao vivo (palavras capturadas em tempo real durante a gravação) e uma transcrição de extração (produzida do ficheiro de áudio após a gravação). Ambas aparecem no painel AI Insights no separador Transcrição. Ver Capítulos 27 e 28.

Track (Audio) (Faixa)

Um fluxo de áudio separado dentro de um ficheiro. O SeaMeet pode gravar várias faixas: microfone, áudio do sistema, etc.

Tray

O menu de ícones da área de notificação do sistema — área de notificação do Windows, barra de menus do macOS, indicador Linux — onde o SeaMeet vive quando minimizado. Fornece iniciar/parar gravação, abrir modo Lite e sair, mesmo quando nenhuma janela principal está visível.

Trim (Aparar)

Remover partes indesejadas do início ou fim de uma gravação. O SeaMeet permite aparar gravações guardadas.

Troubleshooting (Resolução de problemas)

O processo de diagnosticar e resolver problemas. O Capítulo 25 cobre a resolução de problemas comuns do SeaMeet.

U

USB Microphone (Microfone USB)

Um microfone que se liga via porta USB. Fácil de usar e frequentemente de melhor qualidade do que microfones incorporados de portátil.

V

VBR (Variable Bit Rate) (Taxa de bits variável)

Método de codificação que ajusta a qualidade com base na complexidade do conteúdo. Cenas simples usam taxa de bits mais baixa. Cenas complexas usam mais alta.

Video Buffer (Buffer de vídeo)

Armazenamento temporário para imagens de vídeo durante a gravação Flashback. Retém a janela rolante de filmagem recente.

Version Badge (Insígnia de versão)

Um pequeno rótulo (ex.: "v3 ▾") que aparece na barra de separadores AI Insights quando pelo menos uma regeneração foi corrida. Clicar abre o seletor de versões. Ver Capítulo 34.

Version History (Histórico de versões)

O registo de todas as execuções anteriores de Extração por IA para uma gravação. Cada vez que regenera (⟳), o SeaMeet guarda os resultados anteriores como um instantâneo numerado antes de os sobrescrever. Pode ver qualquer versão passada em qualquer momento. Ver Capítulo 34.

Video Track (Faixa de vídeo)

O componente visual de um ficheiro de vídeo. Separado das faixas de áudio. Um ficheiro de vídeo contém pelo menos uma faixa de vídeo.

Volume

Volume do áudio. Diferente do ganho — o volume afeta o que ouve. O ganho afeta o que é gravado.

VP8/VP9

Codecs de vídeo de código aberto usados em ficheiros WebM. Boa qualidade, livres para usar. VP9 é mais recente e mais eficiente do que VP8.

W

WASAPI (Windows Audio Session API)

Método moderno do Windows para capturar áudio do sistema. Mais fiável do que Stereo Mix em alguns sistemas.

WAV (Waveform Audio File Format)

Formato de áudio não comprimido. Ficheiros grandes mas qualidade perfeita. Bom para arquivo ou edição.

WebM

Formato de vídeo de código aberto desenvolvido pelo Google. Bom para uso web. Usa codecs VP8 ou VP9.

Wikilink

A sintaxe [[título]] em notas que cria uma ligação navegável para outra nota. Escrever [[ abre um seletor para notas existentes; selecionar uma insere a ligação, e clicar na ligação na nota renderizada salta para essa página. Ver Capítulos 16-17.

Window Recording (Gravação de janela)

Modo de gravação que captura apenas uma janela específica de aplicação. Mais eficiente do que ecrã inteiro.

Window Title Detection (Deteção de título de janela)

Método de auto-deteção que lê títulos de janelas de aplicações. Procura palavras-chave como "Zoom Meeting" ou "Teams".

Workspace (Espaço de trabalho)

Uma árvore de notas separada mais um conjunto de gravações entre os quais pode alternar — por exemplo, um espaço de trabalho "Trabalho" e um "Pessoal", cada um com o seu próprio repositório de sincronização com GitHub. Mudar de espaços de trabalho troca a barra lateral, biblioteca e alvo de sincronização num só movimento. Ver Capítulo 38.

X

XLR

Conector de áudio profissional usado em microfones topo de gama. Requer uma interface de áudio para ligar ao computador.

Y

YouTube

Plataforma popular de partilha de vídeo. As gravações do SeaMeet podem ser carregadas para o YouTube. O YouTube recomenda definições específicas para melhores resultados.

Z

Zero Latency (Latência zero)

Sem atraso entre ação e gravação. Impossível na prática, mas ligações com fios e bom hardware minimizam a latência.

Zoom (App) (Aplicação Zoom)

Plataforma popular de videoconferência. Uma das mais de 47 aplicações que o SeaMeet pode auto-detetar e gravar.

Zoom (Digital)

Aumentar ou ampliar uma vista. O reprodutor do SeaMeet permite zoom no vídeo para exame detalhado.

Termos confusos explicados

Codec vs. Contentor

  • Codec: COMO os dados são comprimidos (H.264, MP3)
  • Contentor: ONDE os dados são armazenados (MP4, WebM, AVI)

Analogia: codec é o idioma em que um livro está escrito. Contentor é o próprio livro.

Taxa de bits vs. Resolução

  • Taxa de bits: QUANTOS dados por segundo (afeta qualidade e tamanho do ficheiro)
  • Resolução: QUANTOS píxeis (afeta nitidez)

Pode ter alta resolução com baixa taxa de bits (com blocos) ou baixa resolução com alta taxa de bits (suave mas pequeno).

Ganho vs. Volume

  • Ganho: nível de entrada (quão alto a gravação é)
  • Volume: nível de saída (quão alto a reprodução é)

Mudar o volume não afeta a gravação. Mudar o ganho afeta a gravação.

Latência vs. Atraso

  • Latência: termo técnico para atraso em sistemas digitais
  • Atraso: termo geral para qualquer tempo de espera

São essencialmente a mesma coisa, mas "latência" é usado em contextos técnicos.

Taxa de imagens vs. Resolução

  • Taxa de imagens: QUANTAS imagens por segundo (suavidade)
  • Resolução: QUÃO DETALHADA cada imagem é (clareza)

60fps 720p é mais suave do que 30fps 1080p, mas 1080p é mais nítido.
