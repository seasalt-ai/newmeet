Glossário de Termos

Capítulo 26: Glossário de Termos

Introdução

O software de gravação, como qualquer campo técnico, vem com o seu próprio vocabulário. Palavras como "codec", "bitrate", "frame rate" e "encoding" são usadas constantemente. Este capítulo é o seu dicionário abrangente — explicando cada termo técnico que pode encontrar ao usar o SeaMeet ou ao ler sobre gravação de áudio/vídeo.

Não se preocupe se não é técnico. Cada termo é explicado em linguagem simples com analogias para ajudar na compreensão. Use este capítulo como referência sempre que encontrar uma palavra desconhecida.

Objetivos do Capítulo

Após ler este capítulo, será capaz de:

  • Compreender termos técnicos usados no SeaMeet
  • Conhecer a diferença entre termos comummente confundidos
  • Usar terminologia correta ao resolver problemas
  • Tomar decisões informadas baseadas em conceitos técnicos

A

Audio Buffer

Armazenamento temporário para dados de áudio antes de serem processados ou guardados. Como uma sala de espera onde as amostras de áudio se alinham antes de serem codificadas.

Audio Interface

Hardware que liga microfones e instrumentos ao seu computador. Frequentemente fornece melhor qualidade de áudio que as placas de som integradas.

Action Items (AI)

Tarefas identificadas pela Extração de IA a partir de uma gravação. Cada item de ação inclui a descrição da tarefa, a pessoa atribuída e uma data limite (se mencionada na conversa). Consulte o Capítulo 28.

AI Extraction

Funcionalidade de análise pós-gravação do SeaMeet. Após uma gravação terminar, clicar em ✨ "Generate Summary" envia o áudio para o motor de IA, que retorna cinco saídas estruturadas: Transcrição, Resumo, Itens de Ação, Decisões-Chave e Capítulos. Consulte o Capítulo 28.

AI Insights

O painel no SeaMeet que apresenta todos os resultados gerados por IA para uma gravação. Acessível a partir da vista de detalhe da gravação. Contém separadores para Transcrição, Resumo, Ações, Decisões e Capítulos.

Audio Track

Um fluxo separado de áudio dentro de um ficheiro de vídeo. Um vídeo pode ter múltiplas faixas: o seu microfone, áudio do sistema, música de fundo.

Auto-Detection

Funcionalidade do SeaMeet que reconhece automaticamente quando entra numa reunião e pode iniciar a gravação sem intervenção manual.

AVI (Audio Video Interleave)

Um formato de ficheiro de vídeo mais antigo desenvolvido pela Microsoft. Funciona bem no Windows mas é menos compatível com dispositivos modernos.

B

Bit

A menor unidade de informação digital. Ou um 0 ou 1. Tudo no seu computador é composto por bits.

Bit Depth (Audio)

Quantos bits são usados para representar cada amostra de áudio. Maior profundidade de bits = mais detalhe = ficheiros maiores. Qualidade de CD é 16-bit.

Bitrate

A quantidade de dados processados por segundo. Geralmente medida em kilobits por segundo (kbps) ou megabits por segundo (Mbps). Superior = melhor qualidade = ficheiros maiores.

Bluetooth Latency

O atraso entre quando o som é produzido e quando o ouve através de uma ligação Bluetooth. Tipicamente 100-300ms, o que causa problemas de sincronização.

Buffer

Área de armazenamento temporário que retém dados enquanto estão a ser transferidos ou processados. Como um reservatório que retém água antes de fluir por um tubo.

Buffer Duration (Flashback)

Quantos segundos de filmagem o SeaMeet mantém no buffer circular. Quando guarda o Flashback, obtém essa quantidade de filmagem passada.

Byte

Um grupo de 8 bits. A unidade padrão para medir tamanhos de ficheiro. Um megabyte (MB) é cerca de um milhão de bytes.

C

Circular Buffer

Um tipo de buffer que volta ao início quando chega ao fim. O SeaMeet usa isto para o Flashback — gravando constantemente e sobrescrevendo dados antigos.

Codec (Coder-Decoder)

Software que comprime e descomprime áudio ou vídeo. H.264 é um codec de vídeo. MP3 é um codec de áudio.

Codec vs. Container

Codec é o método de compressão (como os dados são comprimidos). Container é o formato de ficheiro (a caixa que contém os dados). MP4 é um contentor que frequentemente contém vídeo H.264.

Compression

Reduzir o tamanho do ficheiro removendo dados redundantes ou menos importantes. Pode ser sem perdas (sem perda de qualidade) ou com perdas (alguma perda de qualidade mas ficheiros menores).

Chapters (AI)

Uma das cinco saídas da Extração de IA. Segmentos de tópicos indexados por tempo, semelhantes a capítulos num livro. Clicar num capítulo no painel AI Insights salta o leitor para esse momento na gravação. Consulte o Capítulo 28.

CPU (Central Processing Unit)

O "cérebro" do seu computador. Faz cálculos e executa programas. O software de gravação usa o CPU para codificar vídeo.

Cursor Highlighting

Um efeito visual que chama a atenção para o cursor do rato em gravações. Útil para tutoriais para que os espectadores possam seguir as suas ações.

D

Decibel (dB)

Uma unidade para medir volume de som. Usada nos medidores de nível de áudio do SeaMeet. -12 dB é um bom nível de gravação. 0 dB é o máximo (distorção).

Default Device

O dispositivo de áudio ou vídeo que o Windows/macOS usa automaticamente. O SeaMeet pode usar o predefinido ou deixá-lo escolher um dispositivo específico.

Detection Method (Auto-Detection)

Como o SeaMeet reconhece que está numa reunião. Os métodos incluem análise de título de janela, monitorização de processos e deteção de áudio.

Digital Audio

Som representado como números. O seu computador converte ondas sonoras em amostras digitais (números) que podem ser armazenadas e processadas.

Disk Space

A quantidade de armazenamento disponível no seu disco rígido ou SSD. A gravação de vídeo requer espaço de disco significativo.

DRM (Digital Rights Management)

Tecnologia que previne a cópia de conteúdo protegido. Netflix, DVDs e alguns serviços de streaming usam DRM, que previne a gravação de ecrã.

Decisions (AI)

Uma das cinco saídas da Extração de IA. Uma lista de escolhas-chave e acordos feitos durante a reunião, extraídos da conversa. Distinto dos Itens de Ação — decisões são o que foi acordado, ações são o que deve ser feito como resultado. Consulte o Capítulo 28.

Drop Frame

Quando uma gravação de vídeo perde fotogramas, causando engasgos. Geralmente acontece quando o computador não consegue acompanhar as exigências de codificação.

E

Echo Cancellation

Tecnologia que remove eco das gravações. Útil ao usar altifalantes em vez de auscultadores — previne que o microfone capte o som do altifalante.

Encode

O processo de converter vídeo/áudio em bruto num formato comprimido. O CPU ou GPU faz isto em tempo real enquanto grava.

Encoder

Software ou hardware que realiza a codificação. O SeaMeet usa codificadores de software (CPU) ou codificadores de hardware (GPU).

External Drive

Um disco rígido ou SSD que se liga via USB. Pode ser usado para armazenar gravações mas pode ser mais lento que discos internos.

F

Flashback

Funcionalidade de máquina do tempo do SeaMeet que grava continuamente num buffer circular, permitindo guardar momentos do passado.

Flashback Buffer

O armazenamento de memória temporário usado pelo Flashback. Retém os últimos X segundos de vídeo/áudio.

Floater (SeaMeet Floater)

O widget flutuante que aparece no seu ecrã para controlos rápidos de gravação. Pode ser minimizado para um pequeno ícone ou expandido para controlos completos.

FPS (Frames Per Second)

Quantas imagens estáticas (fotogramas) são capturadas a cada segundo para criar vídeo. 30fps é padrão. 60fps é mais fluido.

Fullscreen Recording

Modo de gravação que capta o seu ecrã inteiro. Útil para reuniões e quando quer capturar tudo.

Frame

Uma única imagem estática num vídeo. O vídeo é essencialmente uma série de fotogramas reproduzidos rapidamente (30-60 por segundo) para criar movimento.

G

Gain

O nível de amplificação de um sinal de áudio. Aumentar o ganho torna o áudio mais alto na gravação. Diferente do volume (que afeta a reprodução).

Game Mode

Funcionalidade do Windows que prioriza aplicações de jogo. Pode ajudar o desempenho de gravação mas por vezes conflita com software de gravação.

GPU (Graphics Processing Unit)

A placa gráfica no seu computador. Pode ser usada para codificação de vídeo acelerada por hardware (muito mais rápida que CPU).

GPU Encoding

Usar a placa gráfica em vez do CPU para codificar vídeo. Também chamada aceleração por hardware. Mais rápida e mais eficiente.

H

H.264 (AVC)

O codec de vídeo mais comum. Fornece boa qualidade com tamanhos de ficheiro razoáveis. Funciona em praticamente todos os dispositivos.

H.265 (HEVC)

Um codec de vídeo mais recente e mais eficiente. Produz ficheiros cerca de 50% menores que H.264 com a mesma qualidade. Suporte menos universal.

Hardware Acceleration

Usar hardware especializado (como GPU) para realizar tarefas em vez do CPU genérico. Torna a codificação de vídeo muito mais rápida.

Hardware Encoder

Chip dedicado no GPU que codifica vídeo. A NVIDIA chama o seu NVENC. A Intel chama o seu Quick Sync.

HD (High Definition)

Resolução de vídeo de 1280×720 (720p) ou superior. Fornece vídeo claro e detalhado.

Headphones vs. Speakers

Usar auscultadores enquanto grava previne eco (som dos altifalantes ser captado pelo microfone). Recomendado para melhor qualidade de áudio.

I

I-Frame (Intra-frame)

Um fotograma de vídeo completo que não depende de outros fotogramas. Atua como ponto de referência. Maior tamanho de ficheiro mas necessário para navegação.

Import

Trazer ficheiros de áudio ou vídeo externos para o SeaMeet. O SeaMeet pode importar vários formatos para reprodução e gestão.

Input Device

Hardware que envia áudio/vídeo para o seu computador. Microfones, câmaras e placas de captura são dispositivos de entrada.

J

Jitter

Variação no timing de dados de áudio/vídeo. Causa reprodução irregular ou desigual. Geralmente devido a problemas de desempenho do sistema.

Join a Meeting

Entrar numa reunião online via Zoom, Teams, Meet, etc. O SeaMeet pode auto-detetar quando entra e iniciar gravação.

K

Kbps (Kilobits per second)

Uma medição de taxa de dados. Usada para bitrates de áudio. 128 kbps é padrão para MP3. 192 kbps é qualidade superior.

Keyframe

Consulte I-Frame. Fotogramas de vídeo completos usados como pontos de referência.

Keyboard Shortcuts

Combinações de teclas que acionam ações rapidamente. Ctrl+Alt+R inicia gravação. Os atalhos poupam tempo vs. clicar na interface.

L

Latency

Atraso entre uma ação e quando é processada ou ouvida. Auscultadores Bluetooth têm alta latência. Auscultadores com fio têm quase nenhuma.

Live Transcription

Funcionalidade do SeaMeet que converte fala em texto em tempo real durante uma gravação. As palavras aparecem no painel de Transcrição à medida que são ditas, com timestamp e etiqueta de orador. Requer Recursos de IA ativados e ligação à internet. Consulte o Capítulo 27.

Library (Recording Library)

A coleção de todas as suas gravações no SeaMeet. Mostra miniaturas, metadados e permite reprodução/gestão.

Lossless Compression

Compressão que reduz tamanho do ficheiro sem perder dados. Pode ser perfeitamente reconstruída. Áudio FLAC usa compressão sem perdas.

Lossy Compression

Compressão que remove permanentemente alguns dados para alcançar ficheiros menores. MP3 e H.264 são com perdas. A perda de qualidade é geralmente impercetível.

Low-Memory Mode

Funcionalidade do SeaMeet que reduz qualidade para usar menos RAM. Útil para computadores mais antigos ou ao executar aplicações intensivas em memória.

M

Macroblock

Um quadrado de 16×16 píxeis usado em compressão de vídeo. H.264 divide fotogramas em macroblocks para comprimir eficientemente.

Mbps (Megabits per second)

Uma medição de taxa de dados usada para vídeo. 8 Mbps é bom para vídeo 1080p. Superior = melhor qualidade = ficheiros maiores.

Metadata

Informação sobre um ficheiro (não o conteúdo real). Inclui data de criação, duração, resolução, etc.

Microphone Array

Múltiplos microfones a trabalhar juntos. Alguns portáteis têm conjuntos de microfones para melhor captação de som e cancelamento de ruído.

Minimize to Tray

O SeaMeet pode funcionar em segundo plano, acessível via o ícone da bandeja do sistema (perto do relógio). Poupa espaço na barra de tarefas.

MKV (Matroska)

Um formato contentor de vídeo flexível. Suporta múltiplas faixas de áudio e legendas. Bom para arquivo.

Monitor

O ecrã do seu computador. O SeaMeet pode gravar um monitor ou todos os monitores se tiver múltiplos ecrãs.

Mono vs. Stereo

Mono = 1 canal de áudio. Estéreo = 2 canais (esquerdo e direito). Estéreo soa mais imersivo mas cria ficheiros maiores.

MOV

Formato contentor de vídeo da Apple. Comum em Macs. Boa qualidade mas menos compatível com Windows sem software adicional.

MP3

O formato de áudio mais popular. Usa compressão com perdas. Ficheiros pequenos, compatibilidade universal. 128-320 kbps típico.

MP4

O formato contentor de vídeo mais popular. Funciona em praticamente todos os dispositivos. Geralmente contém vídeo H.264 e áudio AAC.

Multi-Monitor

Usar mais de um ecrã. O SeaMeet pode gravar todos os monitores ou apenas um. Gravar múltiplos monitores usa mais recursos.

Mute

Desligar temporariamente entrada ou saída de áudio. O SeaMeet pode silenciar a gravação sem afetar o volume do sistema.

N

Native Resolution

O número real de píxeis que o seu ecrã apresenta. Gravar em resolução nativa fornece resultados mais nítidos.

Noise Suppression

Tecnologia que remove ruído de fundo (ventoinhas, ar condicionado) das gravações de áudio. Torna as vozes mais claras.

Notification

Uma mensagem popup que o alerta para eventos. O SeaMeet mostra notificações quando gravações iniciam, param ou quando reuniões são detetadas.

NVENC

Codificador de vídeo por hardware da NVIDIA. Disponível na série GTX 600 e mais recentes. Codificação muito rápida com uso mínimo de CPU.

O

Ogg

Um formato de áudio de código aberto. Boa compressão mas suporte de dispositivos limitado. Frequentemente usa codec Vorbis.

Output Device

Hardware que reproduz áudio do seu computador. Altifalantes e auscultadores são dispositivos de saída.

Overhead (CPU/Memory)

Recursos usados pelo software de gravação em si, separados da gravação real. O SeaMeet tem overhead baixo.

P

P-Frame (Predicted Frame)

Um fotograma de vídeo que apenas armazena as alterações em relação ao fotograma anterior. Muito menor que I-Frames. Cria compressão eficiente.

PCM (Pulse Code Modulation)

Formato de áudio digital não comprimido. Usado internamente antes de codificar para MP3 ou outros formatos. Alta qualidade, ficheiros grandes.

Permissions

Autorização para aceder a recursos do sistema. O macOS e o Windows requerem que conceda ao SeaMeet permissão para gravar ecrã e áudio.

Pixel

Um único ponto de cor no seu ecrã. As imagens são compostas por milhares ou milhões de píxeis. 1920×1080 = cerca de 2 milhões de píxeis.

Playback

Ver ou ouvir uma gravação. O SeaMeet tem um leitor integrado para rever gravações.

Pop Filter

Uma cobertura de espuma ou rede para microfones que reduz sons explosivos de "p" e "b". Melhora a qualidade de áudio.

Process Monitoring

Método de auto-deteção que observa que programas estão em execução. Deteta quando zoom.exe ou Teams.exe inicia.

Q

Quantization

Reduzir a precisão dos dados para poupar espaço. Parte da compressão. Simplifica cores/sons que são quase idênticos.

Quick Sync

Codificador de vídeo por hardware da Intel. Integrado em processadores Intel modernos. Eficiente e boa qualidade para gravação.

R

RAM (Random Access Memory)

A memória de curto prazo do seu computador. O SeaMeet usa RAM para buffers do Flashback e processamento. Mais RAM = melhor desempenho.

RAW Audio/Video

Dados não comprimidos. Ficheiros grandes mas qualidade máxima. O SeaMeet geralmente codifica para formatos comprimidos para poupar espaço.

Real-time

A acontecer ao vivo, sem atraso. O SeaMeet codifica vídeo em tempo real enquanto grava. Sem esperar por pós-processamento.

Recording Mode

Como o SeaMeet captura vídeo: Ecrã inteiro (ecrã inteiro), Janela (aplicação específica) ou Região (área selecionada).

Region Recording

Gravar apenas uma porção selecionada do seu ecrã. Modo mais eficiente — captura apenas o que precisa.

Resolution

O número de píxeis numa imagem. 1920×1080 significa 1920 píxeis de largura por 1080 píxeis de altura. Superior = mais nítido = ficheiros maiores.

Ring Menu (Floater)

A interface de controlo circular que aparece quando expande o widget Floater. Fornece acesso rápido a controlos de gravação.

S

Sample Rate (Audio)

Quantas vezes por segundo o áudio é medido. Qualidade de CD é 44,1 kHz (44.100 amostras por segundo). Superior = melhor qualidade.

Sampling

Converter ondas sonoras contínuas em números digitais medindo em intervalos regulares.

Save Location

A pasta onde o SeaMeet armazena gravações. Pode ser alterada nas configurações. Deve ter bastante espaço livre.

Screen Recording

Capturar vídeo do ecrã do seu computador. O SeaMeet especializa-se em gravação de ecrã com áudio.

Screenshot

Uma captura de imagem estática do seu ecrã. O SeaMeet pode fazer capturas de tela via atalho de teclado ou Floater.

Sensitivity (Auto-Detection)

Quão agressivamente o SeaMeet procura reuniões. Sensibilidade alta capta mais reuniões mas pode ter falsos positivos.

Shortcut

Consulte Keyboard Shortcuts. Forma rápida de controlar o SeaMeet sem usar o rato.

Sidebar

O painel esquerdo no SeaMeet mostrando diferentes secções: Gravações, Vídeo, Flashback, etc.

Source (Audio/Video)

A origem do sinal. Fontes de áudio incluem microfone e áudio do sistema. Fontes de vídeo incluem ecrã e janelas.

Speaker Detection

O processo automático de identificar que pessoa está a falar durante transcrição ao vivo ou Extração de IA. A cada voz distinta é atribuída uma etiqueta ("Speaker 1", "Speaker 2"). A precisão melhora com áudio claro e conversa cruzada mínima. Consulte o Capítulo 27.

Speaker Label

O nome atribuído a um orador numa transcrição. Por predefinição "Speaker 1", "Speaker 2", etc. Pode ser renomeado (ex., "Alice") ou fundido com outra etiqueta se duas etiquetas pertencerem à mesma pessoa. Consulte o Capítulo 29.

SRT (SubRip Subtitle)

Um formato de ficheiro de texto para legendas. Contém linhas de texto com timestamp. O SeaMeet pode exportar transcrições como ficheiros SRT, que podem ser importados em editores de vídeo (Premiere, iMovie) ou carregados para o YouTube como legendas.

SSD (Solid State Drive)

Dispositivo de armazenamento rápido sem partes móveis. Melhor para gravação que discos rígidos tradicionais (HDD). Velocidades de escrita mais rápidas.

Stereo Mix

Funcionalidade de áudio do Windows que permite gravar áudio do sistema. O SeaMeet pode usar Stereo Mix ou WASAPI para captura de áudio do sistema.

Storage

Espaço no seu disco rígido ou SSD onde as gravações são guardadas. As gravações de vídeo requerem muito espaço de armazenamento.

Stream

Fluxo contínuo de dados. Fluxos de áudio e vídeo são capturados e codificados durante a gravação.

Sync (Audio-Video)

Quando áudio e vídeo estão devidamente alinhados. Fora de sincronia significa que vê lábios a mover antes/depois de ouvir palavras.

System Audio

Som do seu computador — notificações, vídeos, vozes de reunião. O SeaMeet pode gravar áudio do sistema separadamente do microfone.

System Tray

A área perto do relógio onde aplicações em segundo plano mostram ícones. O SeaMeet pode minimizar para a bandeja do sistema.

T

Theme (Light/Dark)

Aparência visual do SeaMeet. Tema claro tem fundos brancos. Tema escuro tem fundos escuros. Mais confortável para os olhos à noite.

Thumbnail

Pequena imagem de pré-visualização representando um vídeo. O SeaMeet mostra miniaturas das suas gravações na biblioteca.

Time Machine (Flashback)

Metáfora para a funcionalidade Flashback. Permite "voltar no tempo" para capturar momentos que já aconteceram.

Timeline

Representação visual da duração de uma gravação. O leitor do SeaMeet mostra uma linha temporal com a posição de reprodução.

Toggle

Um interruptor que liga ou desliga uma funcionalidade. O SeaMeet usa toggles nas configurações — clique para alternar entre estados.

Transcript

Um registo de texto do áudio falado. O SeaMeet produz dois tipos: uma transcrição ao vivo (palavras captadas em tempo real durante a gravação) e uma transcrição de extração (produzida a partir do ficheiro de áudio após a gravação). Ambas aparecem no painel AI Insights sob o separador Transcript. Consulte os Capítulos 27 e 28.

Track (Audio)

Um fluxo de áudio separado dentro de um ficheiro. O SeaMeet pode gravar múltiplas faixas: microfone, áudio do sistema, etc.

Trim

Remover partes desnecessárias do início ou fim de uma gravação. O SeaMeet permite cortar gravações guardadas.

Troubleshooting

O processo de diagnosticar e corrigir problemas. O Capítulo 21 cobre a resolução de problemas comuns do SeaMeet.

U

USB Microphone

Um microfone que se liga via porta USB. Fácil de usar e frequentemente com melhor qualidade que microfones integrados de portátil.

V

VBR (Variable Bit Rate)

Método de codificação que ajusta a qualidade baseada na complexidade do conteúdo. Cenas simples usam bitrate mais baixo. Cenas complexas usam bitrate mais alto.

Video Buffer

Armazenamento temporário para fotogramas de vídeo durante a gravação Flashback. Retém a janela contínua de filmagem recente.

Version Badge

Uma pequena etiqueta (ex., "v3 ▾") que aparece na barra de separadores AI Insights quando pelo menos uma regeneração foi executada. Clicar nela abre o seletor de versões. Consulte o Capítulo 29.

Version History

O registo de todas as execuções anteriores de Extração de IA para uma gravação. Cada vez que regenera (⟳), o SeaMeet guarda os resultados anteriores como um snapshot numerado antes de os sobrescrever. Pode ver qualquer versão passada a qualquer momento. Consulte o Capítulo 29.

Video Track

O componente visual de um ficheiro de vídeo. Separado das faixas de áudio. Um ficheiro de vídeo contém pelo menos uma faixa de vídeo.

Volume

Intensidade sonora do áudio. Diferente do ganho — o volume afeta o que ouve. O ganho afeta o que é gravado.

VP8/VP9

Codecs de vídeo de código aberto usados em ficheiros WebM. Boa qualidade, gratuitos para usar. VP9 é mais recente e mais eficiente que VP8.

W

WASAPI (Windows Audio Session API)

Método moderno do Windows para capturar áudio do sistema. Mais fiável que Stereo Mix em alguns sistemas.

WAV (Waveform Audio File Format)

Formato de áudio não comprimido. Ficheiros grandes mas qualidade perfeita. Bom para arquivo ou edição.

WebM

Formato de vídeo de código aberto desenvolvido pelo Google. Bom para uso web. Usa codecs VP8 ou VP9.

Window Recording

Modo de gravação que captura apenas uma janela de aplicação específica. Mais eficiente que ecrã inteiro.

Window Title Detection

Método de auto-deteção que lê títulos de janelas de aplicações. Procura palavras-chave como "Zoom Meeting" ou "Teams."

X

XLR

Conector de áudio profissional usado em microfones de alta gama. Requer uma interface de áudio para ligar ao computador.

Y

Termos Confusos Explicados

Codec vs. Container

  • Codec: COMO os dados são comprimidos (H.264, MP3)
  • Container: ONDE os dados são armazenados (MP4, WebM, AVI)

Analogia: O codec é o idioma em que um livro é escrito. O contentor é o próprio livro.

Bitrate vs. Resolution

  • Bitrate: QUANTA informação por segundo (afeta qualidade e tamanho do ficheiro)
  • Resolution: QUANTOS píxeis (afeta nitidez)

Pode ter resolução alta com bitrate baixo (imagem em blocos) ou resolução baixa com bitrate alto (fluido mas pequeno).

Gain vs. Volume

  • Gain: Nível de entrada (quão alto é gravado)
  • Volume: Nível de saída (quão alto é reproduzido)

Mudar o volume não afeta a gravação. Mudar o ganho afeta a gravação.

Latency vs. Delay

  • Latency: Termo técnico para atraso em sistemas digitais
  • Delay: Termo geral para qualquer tempo de espera

São essencialmente a mesma coisa, mas "latência" é usada para contextos técnicos.

Frame Rate vs. Resolution

  • Frame Rate: QUANTAS imagens por segundo (fluidez)
  • Resolution: Quão DETALHADA é cada imagem (clareza)

60fps 720p é mais fluido que 30fps 1080p, mas 1080p é mais nítido.
