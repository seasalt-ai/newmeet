A interface principal — Um tour completo pela UI do SeaMeet

Capítulo 13: A interface principal — Um tour completo pela UI do SeaMeet

A esta altura, já usou o SeaMeet para gravar áudio e vídeo, organizou a sua biblioteca e reproduziu gravações. Interagiu com várias partes da interface, mas pode não ter uma imagem completa de como todas as peças se encaixam. Este capítulo fornece um tour abrangente pela interface principal do SeaMeet — cada botão, painel, indicador e controlo — para que possa navegar pela aplicação com confiança e descobrir funcionalidades que pode não ter encontrado ainda.

Pense neste capítulo como um tour guiado por uma casa nova. Vamos percorrer cada divisão, examinar as funcionalidades e explicar o que tudo faz. No final, saberá exatamente onde encontrar cada função e perceberá como a interface se adapta a diferentes situações.

O esquema da janela: o panorama geral

Quando abre o SeaMeet, vê uma única janela com um esquema consistente. Este esquema permanece estável quer esteja a gravar, a reproduzir ou apenas a navegar pela sua biblioteca. Compreender este esquema é a base para usar o SeaMeet eficazmente.

Zona 1: barra de navegação superior

  • Sempre visível
  • Contém controlos globais
  • Acesso rápido a funcionalidades-chave

Zona 2: barra lateral (lista de gravações)

  • Sempre visível (na maioria das vistas)
  • Mostra as suas gravações
  • Lista de cartões de gravação com scroll

Zona 3: área de conteúdo principal

  • Muda consoante o contexto
  • Mostra o reprodutor ao reproduzir gravações
  • Mostra controlos de gravação ao preparar uma gravação
  • Mostra as definições ao configurar opções

Zona 1: a barra de navegação superior

A barra de navegação superior fornece navegação e controlos de conta. Mantém-se estreita e focada — os controlos de gravação e o Flashback mudaram-se para o Capture Hub na área de conteúdo principal (ver Estado 1 abaixo).

Esquema da barra superior

┌─────────────────────────────────────────────────────────────────────┐
│ [☰ Nav]  SeaMeet Screen & Audio Recorder              [👤 Conta]   │
│   │                                                        │        │
│  Alternador de navegação                       Menu de perfil       │
└─────────────────────────────────────────────────────────────────────┘

Alternador de navegação (☰)

O que faz: colapsa ou expande a barra lateral esquerda (lista de gravações).

Quando usar:

  • Colapsar para dar ao Capture Hub mais espaço horizontal
  • Expandir para navegar pela sua biblioteca de gravações enquanto não está a gravar

Menu de conta/utilizador (👤)

O que faz: abre o menu da conta de utilizador onde pode:

  • Iniciar ou terminar sessão
  • Abrir Definições (áudio, vídeo, Flashback, armazenamento, idioma, atalhos)
  • Abrir referência de atalhos de teclado
  • Aceder a Ajuda e Suporte

Como usar:

  1. Clique na sua imagem de perfil ou no ícone de utilizador
  2. Selecione a opção desejada no menu

Botão de gravação (🔴)

Ícone: círculo vermelho (🔴) quando pronto, quadrado (⏹️) ao gravar Rótulo: "RECORD" ou apenas o ícone Cor: vermelho brilhante (indica ação de gravação)

O que faz: Inicia ou para a gravação

Estados:

Pronto para gravar:

[🔴 RECORD]
Ícone de círculo vermelho
Clique para iniciar gravação

Gravação ativa:

[⏹️ STOP]
Ícone de quadrado
Cronómetro a mostrar tempo decorrido
Clique para parar gravação

Como usar:

Para iniciar a gravação:

  1. Configure primeiro as suas definições de gravação
  2. Clique no botão Record vermelho
  3. A gravação começa imediatamente
  4. O botão muda para Stop
  5. O cronómetro começa a contar

Para parar a gravação:

  1. Clique no botão Stop (quadrado)
  2. A gravação para
  3. O ficheiro é guardado
  4. A gravação aparece na barra lateral
  5. O botão regressa ao estado Record

O que acontece quando clica em Record:

  1. A captura de áudio/vídeo começa
  2. Aparece um cronómetro a mostrar tempo decorrido
  3. O botão muda de 🔴 para ⏹️
  4. Indicador visual mostra o estado da gravação
  5. O ficheiro está a ser escrito no armazenamento

O que acontece quando clica em Stop:

  1. A gravação para
  2. O ficheiro é finalizado e guardado
  3. A gravação aparece na lista da barra lateral
  4. O botão regressa ao estado 🔴
  5. O cronómetro desaparece ou é reiniciado

Notas importantes:

  • A gravação começa imediatamente — esteja preparado!
  • Sem contagem decrescente ou aviso
  • Certifique-se de que as suas definições estão corretas antes de clicar
  • O Flashback (se ativado) inclui o passado em buffer

Área de notificação do sistema

O SeaMeet instala um ícone na área de notificação (área de notificação do Windows, barra de menus do macOS) na primeira vez que arranca e mantém-no vivo durante toda a sessão da aplicação. A área de notificação é a superfície de controlo sempre disponível — mesmo quando fechou a janela principal, o SeaMeet continua a correr, pronto a capturar, e acessível com um único clique no seu ícone.

Porque a área de notificação se mantém ativa

Fechar a janela principal não faz sair do SeaMeet. Em vez disso, a janela esconde-se e o ícone na área de notificação fica no lugar. Isto é intencional:

  • O Auto-Detect ainda pode acordar a aplicação quando uma aplicação de reunião arranca
  • O Flashback pode manter o seu buffer rolante carregado (se armado)
  • As teclas de atalho globais (Iniciar gravação, Mostrar Launcher, Mostrar Floater) continuam a funcionar
  • Uma gravação rápida está a um clique de distância na área de notificação

A primeira vez que fechar a janela, o SeaMeet envia uma dica única de "minimizado para a área de notificação" para que perceba que a aplicação não saiu realmente. Para sair completamente, use Exit SeaMeet no menu da área de notificação (ver abaixo) ou o comando de saída de aplicações do seu SO.

O ícone da área de notificação

Ícone predefinido (inativo):

  • Windows: um pequeno .ico do logo SeaMeet na área de notificação
  • macOS: uma imagem template 22×22 na barra de menus que se adapta ao modo claro/escuro

Ícone de gravação (em curso):

  • Muda para uma variante tingida de vermelho para que veja num relance que o SeaMeet está a capturar
  • Em macOS, a barra de menus também recebe um sufixo ●; se em pausa, mostra ⏸
  • A dica muda de "SeaMeet" para "SeaMeet — Recording in progress" (ou "Paused")

Comportamento de clique:

  • Clique esquerdo no ícone — alterna a janela principal (mostrar se escondida, esconder se visível)
  • Clique direito no ícone (Windows) / clique simples (macOS) — abre o menu de contexto

Menu da área de notificação (estado inativo)

Quando não está a gravar, o menu tem aproximadamente este aspeto:

┌─────────────────────────────────────────┐
│ Workspace: Acme Sales      (desativado) │   ← apenas em builds Lite/cloud
├─────────────────────────────────────────┤
│ Gravação rápida           (desativado)  │
│   🎤  Gravar áudio                      │
│   🖥️  Gravar ecrã inteiro               │
│   ◰  Gravar região                      │
│   📷  Tirar captura      (Ctrl+Shift+S) │
│   📁  Abrir pasta de gravações          │
├─────────────────────────────────────────┤
│ 🚀 Mostrar launcher       (Ctrl+Shift+L)│
│ 🪟 Mostrar janela flutuante (Ctrl+Shift+F)│
├─────────────────────────────────────────┤
│ 🗔 Mostrar janela principal             │
├─────────────────────────────────────────┤
│ ⏻  Sair do SeaMeet                      │
└─────────────────────────────────────────┘

O que cada item faz:

  • Workspace: <nome> — cabeçalho que mostra em que espaço de trabalho na nuvem aterrará uma gravação iniciada pela área de notificação. Aparece apenas em builds Lite ou com cloud ativada onde iniciou sessão e escolheu um espaço de trabalho. Em builds sem nuvem, a linha está totalmente escondida para que a forma do menu permaneça inalterada.
  • Gravar áudio — inicia uma gravação apenas de áudio imediatamente. Sem fontes de vídeo solicitadas.
  • Gravar ecrã inteiro — inicia uma gravação do seu ecrã principal mais áudio.
  • Gravar região — abre a sobreposição de região em ecrã inteiro para poder arrastar-selecionar uma área e depois inicia uma gravação dessa região.
  • Tirar captura — abre o seletor de região para uma captura de ecrã única. Atalho mostrado se associou um em Definições → Teclado.
  • Abrir pasta de gravações — abre o navegador de ficheiros do SO no seu diretório atual de gravação.
  • Mostrar launcher — alterna o painel SeaMeet Launcher (ver Capítulo 14). O atalho é mostrado quando associado.
  • Mostrar janela flutuante — mostra/esconde o widget Floater. O atalho é mostrado quando associado.
  • Mostrar janela principal — traz a janela principal para a frente (o mesmo que clicar com o botão esquerdo no ícone quando escondida).
  • Sair do SeaMeet — o único item do menu que sai mesmo. Define a flag interna "is quitting" e pede ao Electron para terminar; tudo o resto apenas mostra/esconde superfícies.

Menu da área de notificação (durante a gravação)

Quando uma gravação está em curso, o menu remodela-se para lhe dar controlos de transporte diretos:

┌─────────────────────────────────────────┐
│ ● Gravação em curso       (desativado)  │
├─────────────────────────────────────────┤
│ ⏹  Parar gravação        (Ctrl+Shift+R) │
│ ⏸  Pausar gravação                      │
│ ⚑  Marcar evento                        │
├─────────────────────────────────────────┤
│ 🗔 Mostrar janela principal             │
├─────────────────────────────────────────┤
│ ⏻  Sair do SeaMeet                      │
└─────────────────────────────────────────┘

Notas sobre o menu de gravação:

  • A linha do cabeçalho é puramente um rótulo de estado (está intencionalmente desativada).
  • Parar gravação termina a captura e guarda o ficheiro tal como clicar no botão Stop na janela principal.
  • Pausar/Retomar só é mostrado quando o codec/fonte o suporta. Gravações apenas de vídeo escondem o item Pause.
  • Marcar evento larga um marcador de marca temporal na gravação, útil para saltar para um momento-chave durante a reprodução.
  • Quando em pausa, o menu troca para Retomar gravação no lugar de Pausa e o título do macOS muda para ⏸.

Rótulos localizados

O menu da área de notificação honra 15 localidades suportadas (inglês, espanhol, francês, alemão, japonês, coreano, hindi, polaco, português, russo, tailandês, vietnamita, dinamarquês, chinês simplificado, chinês tradicional). Idiomas fora desse conjunto recorrem ao inglês para que o menu seja sempre apresentado corretamente.

Caixa de pesquisa

Localização: topo da barra lateral Aparência: campo de texto com ícone de lupa (🔍) Texto de marcador: "Pesquisar gravações..." ou semelhante

O que faz: Filtra a lista de gravações em tempo real à medida que escreve

Como usar:

  1. Clique na caixa de pesquisa
  2. Comece a escrever
  3. A lista filtra-se automaticamente
  4. Mostra apenas gravações que correspondem à sua pesquisa
  5. Limpe a pesquisa para ver todas as gravações novamente

O que pode pesquisar:

  • Nomes de gravação
  • Rótulos de fonte ("Zoom", "Teams")
  • Datas (se escritas em formato pesquisável)
  • Correspondências parciais funcionam

Exemplos de pesquisa:

  • Pesquise "Zoom" → mostra todas as gravações do Zoom
  • Pesquise "orçamento" → mostra gravações com "orçamento" no nome
  • Pesquise "março" → mostra gravações de março
  • Pesquise "cliente" → mostra gravações relacionadas com clientes

Limpar pesquisa:

  • Clique no botão X (se presente)
  • Eliminar todo o texto
  • Premir tecla Escape

Cartões de gravação

Cada gravação na sua biblioteca é apresentada como um cartão de gravação — um resumo compacto das informações-chave da gravação.

Dois modos de vista:

  1. Vista compacta (predefinida) - info mínima, navegação eficiente
  2. Vista expandida - info detalhada, pré-visualização de forma de onda

Vista compacta

┌──────────────────────────────────────────────────────────┐
│ 🎤 Revisão orçamento Q3 - Reunião de equipa             │
│ 47:32 • Hoje, 14:30 • Zoom • Áudio                       │
└──────────────────────────────────────────────────────────┘

Elementos:

  • Ícone (🎤) - indica o tipo (áudio/vídeo)
  • Nome - título da gravação
  • Duração - quanto tempo (47:32)
  • Marca temporal - quando foi gravada (Hoje, 14:30)
  • Fonte - de onde (Zoom)
  • Tipo - Áudio/Vídeo/Flashback

Quando usar a vista compacta:

  • Navegar por muitas gravações
  • Varrimento rápido
  • Espaço limitado de ecrã
  • Visão geral da biblioteca

Quando usar a vista expandida:

  • Trabalhar com uma gravação específica
  • Precisa de ver todos os detalhes

  • Ao organizar

Ícones dos cartões de gravação explicados

Ícones de áudio:

  • 🎤 - Microfone (gravação de áudio)
  • 🔴 - Áudio (genérico)
  • 🔊 - Apenas áudio do sistema
  • 🎤+🔊 - Áudio combinado (mic + sistema)

Ícones de vídeo:

  • 🎥 - Gravação de vídeo
  • 📹 - Gravação de ecrã
  • 🖥️ - Gravação de ecrã inteiro
  • 🪟 - Gravação de janela

Ícones especiais:

  • ⏪ - Gravação Flashback
  • 📥 - Ficheiro importado
  • 🌐 - Gravação web/navegador

Controlos de ordenação e filtragem

Localização: geralmente no topo da barra lateral, perto da pesquisa

Opções de ordenação:

  • Data (mais recente primeiro) - predefinição
  • Data (mais antiga primeiro)
  • Nome (A-Z)
  • Nome (Z-A)
  • Duração (mais curta primeiro)
  • Duração (mais longa primeiro)
  • Tamanho (mais pequeno primeiro)
  • Tamanho (maior primeiro)

Como mudar a ordenação:

  1. Clique no menu "Sort"
  2. Selecione o método de ordenação
  3. Clique novamente para inverter a ordem

Opções de filtro:

  • Todos - mostrar tudo
  • Apenas áudio - gravações de áudio
  • Apenas vídeo - gravações de vídeo
  • Hoje - gravações de hoje
  • Esta semana - gravações recentes
  • Flashback - capturas Flashback
  • Por fonte - Zoom, Teams, etc.

Como filtrar:

  1. Clique no botão ou menu "Filter"
  2. Selecione critérios de filtro
  3. A lista atualiza-se para mostrar apenas correspondências
  4. Clique em "Clear" ou "All" para reiniciar

Zona 3: a área de conteúdo principal

A área de conteúdo principal é o camaleão da interface do SeaMeet — muda de aparência consoante o que está a fazer. Vamos explorar os seus diferentes estados.

Estado 1: Capture Hub (inativo / pronto para gravar)

Quando mostrado:

  • Quando abre o SeaMeet pela primeira vez
  • Quando nenhuma gravação está selecionada e não está ativamente a gravar

O que vê — o Capture Hub:

A área de conteúdo principal mostra o Capture Hub, um esquema de dois painéis que coloca os controlos de gravação e captura de ecrã em primeiro plano:

Painel esquerdo — Iniciar gravação

O painel esquerdo contém todos os controlos para iniciar uma nova gravação:

Controlos laterais (topo do cartão):

  • Alternador Flashback (esquerda) — clique para alternar o modo Flashback: OFF → Áudio → Ecrã → OFF. Mostra um ícone de raio ⚡ quando armado (o buffer está a carregar ou pronto). Ver Capítulo 7 para detalhes completos.
  • Grande círculo vermelho de mic (centro) — clique para abrir o modal de Video Settings e escolher o seu modo de gravação (apenas áudio, ecrã inteiro, janela, região).
  • Alternador Auto-Detect (direita) — ativa a gravação automática quando uma aplicação de reunião é detetada.

Área de contexto (meio do cartão):

  • Quando o Flashback está OFF: mostra uma breve descrição de como começar.
  • Quando o Flashback está a armar (a carregar): mostra um indicador de progresso enquanto o buffer enche.
  • Quando o Flashback está pronto: mostra o ícone ⚡ e confirmação "Flashback armado".

Botão CTA (fundo do cartão):

  • O rótulo e a ação adaptam-se ao estado do Flashback:
    • Flashback OFF → "Start Recording" (abre Video Settings)
    • Flashback a armar → "Buffering…" (desativado enquanto enche)
    • Flashback pronto → "Record with Flashback" (captura o buffer e inicia a gravação)

Atalhos de lançamento rápido (faixa inferior):

  • Abrir Launcher — abre o painel SeaMeet Launcher com a tecla de atalho mostrada
  • Abrir Floater — mostra/esconde o widget Floater com a tecla de atalho mostrada

Painel direito — Tirar captura

O painel direito trata das capturas de ecrã independentemente das gravações:

  • Botão de ícone de câmara — grande botão herói; clique para tirar uma captura usando o modo atualmente selecionado.
  • Ecrã inteiro / Captura de área — botões de opção para escolher entre uma captura de ecrã inteiro ou desenhar uma região.
  • Caixa Manter janela SeaMeet visível — quando desmarcada (predefinição), o SeaMeet minimiza-se antes de capturar para não aparecer na captura. Quando marcada, a janela mantém-se visível e aparecerá na captura.
  • Botão Tirar captura — aciona a captura (igual a clicar no ícone da câmara).

Propósito:

  • Centro tudo-em-um para tudo o que precisa antes de começar a capturar
  • O estado do Flashback é visível e controlável sem abrir Definições
  • Captura de ecrã e gravação estão claramente separadas em dois cartões

Modo Lite vs modo Completo

O SeaMeet vem com dois modos de interface. Partilham o mesmo motor de gravação, os mesmos ficheiros em disco e o mesmo ícone na área de notificação — mas expõem quantidades muito diferentes de UI.

Escolher um modo

Num primeiro arranque limpo, o SeaMeet mostra um seletor de modo a perguntar qual a experiência que quer. Utilizadores existentes da v2.x que atualizam são migrados silenciosamente para o modo Completo (para que nada mude visivelmente), mas todos podem mudar mais tarde nas Definições.

O modo escolhido é persistido como appMode: 'full' | 'lite' nas suas definições de UI. Mudar de modo enquanto uma gravação está em curso é adiado até a gravação esgotar para que nunca perca uma captura; o modal de Definições fecha imediatamente para que o "Saving…" spinner fique visível durante a espera.

Modo Completo (predefinido)

Este é o capítulo que tem estado a ler até agora — barra lateral + Capture Hub + área de conteúdo principal, todos os estados (Gravação, Reprodução, Definições) cobertos nas secções acima. O modo Completo inclui:

  • O Capture Hub com controlos de Flashback e captura de ecrã
  • A barra lateral completa com cartões de gravação, pesquisa, ordenação e filtro
  • Notas e Wiki (ver Cap 16–17)
  • Biblioteca multimédia (Cap 10)
  • Todas as categorias de definições (Cap 18+)
  • Espaços de trabalho locais primeiro (ver "Espaços de trabalho" abaixo)

Use o modo Completo quando o SeaMeet é a sua superfície principal de gravação e quer notas, wiki, agente e gestão de biblioteca numa janela.

Modo Lite

O modo Lite é uma superfície muito mais pequena centrada na área de notificação do sistema e numa única lista de reuniões apoiada na nuvem. Não há barra lateral, vista de notas, wiki nem Capture Hub — as gravações são iniciadas a partir da área de notificação (ou auto-detect, ou uma tecla de atalho), e as gravações terminadas surgem como cartões de reunião assim que o pipeline pós-reunião as carregou no seu espaço de trabalho SeaMeet.

Uma janela Lite típica tem este aspeto:

│  [Acme Sales ▼]                          [🔍] [⚙ Definições]│   ← cabeçalho do espaço de trabalho
├─────────────────────────────────────────────────────────────┤
│  Quinta-feira, 4 de junho                                   │
│                                                             │
│  3 reuniões, 2h 14m esta semana                             │
│                                                             │
│  ┌─────────────────────────────────────────────────────────┐│
│  │ Revisão de Pipeline Q3 — Hoje, 10:00       [Abrir]     ││
│  │ Discovery: Northwind — Ontem, 14:30        [Abrir]     ││
│  │ Sync interno — Seg, 09:00                  [Abrir]     ││
│  └─────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────┘

Cabeçalho do espaço de trabalho em Lite:

O topo da janela Lite é um comutador de espaço de trabalho (um botão a mostrar o nome do espaço de trabalho ativo com um avatar e um galão). Clicar nele abre um menu de cada espaço de trabalho a que tem acesso na nuvem SeaMeet. Escolher um espaço de trabalho diferente:

  1. Persiste o novo ID de espaço de trabalho localmente
  2. Atualiza a lista de reuniões
  3. Empurra o novo nome de espaço de trabalho para o menu da área de notificação para que uma gravação iniciada pela área de notificação também aterre no sítio certo
  4. Reinicia a paginação para a página 1

Terminar sessão limpa o cabeçalho do espaço de trabalho da área de notificação (traySetWorkspaceDisplay(null, null)) para que o menu nunca minta sobre um espaço de trabalho ao qual já não tem acesso.

Gravação em Lite:

  • Clique no ícone da área de notificação e escolha Gravar áudio / ecrã inteiro / região — ou use uma tecla de atalho global
  • A Vista de gravação do Lite assume a janela principal com uma forma de onda em tempo real, cronómetro e um único controlo Stop
  • Quando para, o ficheiro é guardado localmente e carregado para o seu espaço de trabalho SeaMeet para transcrição e sumarização
  • Assim que o pipeline na nuvem termina, o cartão da reunião aparece na lista

Use o modo Lite quando o SeaMeet é um gravador em segundo plano que alimenta a nuvem SeaMeet — quer que a área de notificação faça o trabalho e uma lista limpa de reuniões para rever.

Alternar entre modos

Abra Definições (em qualquer modo), encontre a ação "Switch to Full / Lite mode" e confirme. O SeaMeet esgota qualquer gravação em curso, depois relança o renderer para o outro modo. Os seus ficheiros, espaços de trabalho, definições e ícone da área de notificação sobrevivem à mudança.

Espaços de trabalho

O SeaMeet tem dois conceitos distintos de espaço de trabalho que partilham um nome mas vivem em sítios diferentes. Compreender qual é qual evita confusão.

Espaços de trabalho locais (modo Completo)

No modo Completo, um espaço de trabalho é um cofre estilo Obsidian — uma pasta no disco que contém as suas notas, a sua wiki gerada e (por predefinição) as suas gravações. O WorkspaceManager no processo principal possui:

  • Um registo de espaços de trabalho ({ id, name, path, isDefault? }[]) persistido no seu ficheiro de definições
  • O ID do espaço de trabalho ativo (apenas um está ativo de cada vez)
  • Um observador de ficheiros chokidar no caminho do espaço de trabalho ativo, com sondagem auto-ativada para volumes externos e montagens de rede (ex.: /Volumes/ do macOS, ~/Library/CloudStorage/GoogleDrive-<email>/… do Google Drive) onde o FSEvents não dispararia de forma fiável
  • Estado por espaço de trabalho (última nota aberta, ficheiros recentes, etc.) em userData/workspace-state/<id>.json

No primeiro arranque, se não houver espaços de trabalho registados, o SeaMeet cria automaticamente um único espaço de trabalho Predefinido apontando para o seu diretório de gravação. O nome "Predefinido" é localizado em todos os 23 idiomas.

O comutador de espaços de trabalho (cabeçalho da barra lateral):

Tanto a vista de Notas (Cap 16) como a vista de Wiki (Cap 17) renderizam um <WorkspaceSwitcher> no topo da árvore de ficheiros:

┌──────────────────────────────────┐
│ [🅰] Cofre Acme            ⌄    │   ← espaço de trabalho ativo
├──────────────────────────────────┤
│ Espaços de trabalho              │
│  ✓ Cofre Acme    ~/Notas/Acme    │
│    Pessoal       ~/Notas/Pessoal │
│    Projeto      ~/Codigo/Projeto │
├──────────────────────────────────┤
│ + Adicionar espaço de trabalho…  │
└──────────────────────────────────┘
  • Clique na linha ativa para abrir o menu
  • Clique em qualquer outro espaço de trabalho para mudar para ele — o observador de ficheiros é desmontado, o caminho do novo espaço de trabalho é montado, Notas e Wiki atualizam-se, e o estado por espaço de trabalho é restaurado
  • Adicionar espaço de trabalho… abre o seletor de pastas nativo para que possa registar qualquer diretório como cofre (a unicidade é verificada — registar o mesmo caminho duas vezes é rejeitado)
  • Remover (×) numa linha remove apenas a entrada do SeaMeet; os ficheiros em disco ficam intactos. Não pode remover o último espaço de trabalho.
  • Cada linha pode mostrar uma insígnia de nuvem (Dropbox, iCloud, OneDrive, Google Drive) e uma insígnia de remoto git quando a deteção de sincronização os encontra

Mudar de espaços de trabalho é serializado: se uma mudança já está em curso, a próxima espera que termine para que NotesManager / WikiManager nunca acabem a apontar para um caminho desatualizado.

Espaços de trabalho na nuvem (modo Lite)

No modo Lite (e em builds Completo com cloud ativada), um espaço de trabalho significa algo diferente: um espaço de trabalho de equipa na nuvem SeaMeet. O componente <WorkspacePicker> obtém os seus espaços de trabalho acessíveis através da API SeaMeet e persiste o escolhido para encaminhamento de carregamento.

Os espaços de trabalho na nuvem impulsionam:

  • Para que espaço de trabalho carrega uma nova gravação
  • Que reuniões do espaço de trabalho aparecem na lista de reuniões Lite
  • A linha de cabeçalho do espaço de trabalho no menu da área de notificação (para que veja num relance onde aterrará a próxima gravação iniciada pela área de notificação)

O seletor na nuvem filtra os espaços de trabalho onde o seu my_status é INACTIVE. Na primeira sessão, se o seu espaço de trabalho previamente escolhido não estiver na lista devolvida (perdeu adesão, desvio de esquema, etc.), o seletor escolhe automaticamente o primeiro espaço de trabalho disponível e persiste-o — para que o menu nunca fique encalhado num ID inacessível.

Ambos ao mesmo tempo

Numa build Completo com cloud ativada pode ter ambos os tipos de espaço de trabalho selecionados simultaneamente: um cofre local que contém as suas notas e um espaço de trabalho na nuvem SeaMeet que recebe os seus carregamentos. São independentes — mudar um não muda o outro.
