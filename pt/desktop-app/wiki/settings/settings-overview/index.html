Visão geral das definições

Capítulo 18: Visão geral das definições

Introdução

Bem-vindo ao centro de controlo do SeaMeet! Se a interface principal é como o cockpit onde pilota o avião, o menu de Definições é como a oficina de manutenção onde afina o motor, ajusta os bancos e personaliza a sua experiência de voo. Este capítulo vai mostrar-lhe como aceder ao menu de Definições e dar-lhe um roteiro de todas as diferentes categorias que aí encontrará.

No final deste capítulo, saberá exatamente onde encontrar cada definição no SeaMeet e perceberá o que cada categoria controla. Pense neste como o seu tour de orientação antes de mergulharmos em profundidade em cada secção específica.

Objetivos do capítulo

Depois de ler este capítulo, será capaz de:

  • Abrir o menu de Definições a partir de várias localizações no SeaMeet
  • Compreender as 10 categorias principais de definições e o que controlam (incluindo os novos grupos AI Features e Sync introduzidos na v2.1.0)
  • Navegar rapidamente entre diferentes secções de definições
  • Reconhecer os indicadores visuais e ícones usados na interface de definições
  • Saber quando alterar quais definições com base nas suas necessidades

O que são as definições, e porque importam?

Pense nas definições do SeaMeet como nas preferências do seu telemóvel. Não precisa de as alterar para usar as funcionalidades básicas, mas personalizá-las faz com que a aplicação funcione exatamente como VOCÊ quer. É a diferença entre vestir uma t-shirt de tamanho único versus uma adaptada às suas medidas.

As definições importam porque lhe permitem:

Personalizar a sua experiência

  • Escolher o seu idioma preferido (16 opções disponíveis!)
  • Definir modo claro ou escuro com base no conforto dos seus olhos
  • Escolher onde as suas gravações são guardadas
  • Configurar atalhos que correspondam à sua memória muscular

Otimizar o desempenho

  • Ajustar a qualidade do áudio com base nas capacidades do seu microfone
  • Definir a resolução de vídeo para corresponder ao seu ecrã e necessidades de armazenamento
  • Ativar ou desativar funcionalidades com base na potência do seu computador
  • Gerir o uso de memória para gravação Flashback

Garantir fiabilidade

  • Configurar a deteção automática para nunca perder uma reunião
  • Configurar avisos de armazenamento antes de ficar sem espaço
  • Escolher os dispositivos de áudio certos para a sua configuração
  • Configurar permissões corretamente desde o início

Resolver problemas antes que aconteçam

  • Ajustar o ganho do microfone se as pessoas dizem que está demasiado baixo ou alto
  • Definir modos de gravação predefinidos para evitar esquecer-se de mudar
  • Configurar opções de início automático para a gravação começar quando quer
  • Ativar o modo de pouca memória se o seu computador é mais antigo ou mais lento

Como abrir o menu de Definições

O SeaMeet dá-lhe várias formas de aceder às Definições, tal como pode desbloquear o seu telemóvel com palavra-passe, impressão digital ou reconhecimento facial. Eis todas as formas de chegar às suas definições:

Método 1: a partir da barra lateral esquerda

Esta é a forma mais comum de aceder às Definições. Olhe para a barra lateral vertical no lado esquerdo da janela principal do SeaMeet.

Passo a passo:

  1. Encontre a barra lateral esquerda com ícones para Gravações, Vídeo, Flashback, etc.

  2. Procure o ícone de Definições — parece uma engrenagem ou roda dentada (⚙️)

  3. Clique no ícone de Definições

  4. A área principal mudará de mostrar as suas gravações para mostrar o painel de Definições

Referência visual:

┌─────────────────────────────────────────────────────────────┐
│  [🎤] [🎥] [📼] [🔍] [⚙️ Definições]                       │
│   Gra   Víd  Flash  Auto    ← Ícone de Definições aqui!     │
│                                                             │
│  ┌──────────────────────────────────────────────────────┐  │
│  │                                                      │  │
│  │      PAINEL DE DEFINIÇÕES ABRE AQUI                  │  │
│  │                                                      │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘

Método 2: a partir da barra de menus (Windows)

Se estiver em Windows, também pode aceder às Definições através da barra de menus tradicional no topo da janela.

Passo a passo:

  1. Clique em "File" na barra de menus superior

  2. Procure "Settings" ou "Preferences" no menu suspenso

  3. Clique nele para abrir o painel de Definições

Nota: este método pode variar ligeiramente consoante a sua versão do Windows e versão do SeaMeet.

Método 3: atalho de teclado (Windows)

Para os entusiastas do teclado, há um atalho rápido:

Em Windows: prima Ctrl + Vírgula (,)

Este é um atalho comum em muitas aplicações Windows (incluindo Microsoft Office e muitas outras), pelo que pode já estar na sua memória muscular.

Como usar:

  1. Certifique-se de que o SeaMeet é a janela ativa (clique nela se não tem a certeza)
  2. Mantenha Ctrl premido
  3. Enquanto mantém Ctrl, prima a tecla de vírgula
  4. As Definições abrirão imediatamente

Método 4: a partir do menu da área de notificação (Windows)

O SeaMeet corre na sua área de notificação do sistema (essa é a área perto do seu relógio com todos aqueles pequenos ícones). Também pode aceder às Definições daí.

Passo a passo:

  1. Procure o ícone do SeaMeet na sua área de notificação do sistema (canto inferior direito do ecrã)

    • Pode precisar de clicar na pequena seta para cima para ver ícones escondidos

  2. Clique com o botão direito no ícone do SeaMeet

  3. Aparecerá um menu de contexto com várias opções

  4. Clique em "Settings" no menu

Porquê usar este método?

  • Ótimo quando o SeaMeet está minimizado
  • Acesso rápido sem abrir a janela principal
  • Perfeito quando está com pressa

Método 5: a partir do menu do Floater

Lembra-se do widget de controlo flutuante (o Floater) do Capítulo 14? Também pode aceder às Definições a partir daí.

Passo a passo:

  1. Clique no Floater para o expandir (se está em modo compacto)

  2. Procure um ícone de engrenagem ou opção de menu

  3. Clique nele para abrir as Definições

Nota: a localização exata pode variar com base na sua configuração do Floater, mas a opção de definições é sempre acessível a partir da vista expandida do Floater.

Assim que abre as Definições, verá um painel bem organizado dividido em secções. Vamos fazer um tour pelo que verá:

Esquema geral

Novo na v2.1.0: o grupo AI Features aloja os seus controlos de transcrição/extração/resumo, o painel AI Summary Templates (com o alternador Auto-detect summary template) e — quando ativado — as definições AI Agent & Cowork. O grupo Sync aloja GitHub Sync & Backup.

Lado esquerdo: lista de categorias

  • Mostra todas as categorias de definições disponíveis
  • Clique em qualquer categoria para ver as suas definições
  • A categoria atualmente selecionada está destacada
  • Algumas categorias têm ícones junto aos seus nomes

Lado direito: conteúdo das definições

  • Mostra todas as definições para a categoria selecionada
  • Cada definição tem um rótulo explicando o que faz
  • As definições usam diferentes tipos de controlo:
    • Alternadores (interruptores ligar/desligar) — para escolhas sim/não
    • Menus suspensos — para escolher entre várias opções
    • Campos de texto — para introduzir caminhos de ficheiro ou nomes
    • Sliders — para ajustar valores como volume
    • Botões — para ações como "Procurar" ou "Repor"

Fundo: botões de ação

  • Aplicar — guarda as suas alterações (por vezes automático)
  • Cancelar — descarta alterações e fecha as definições
  • Repor predefinições — devolve todas as definições às predefinições de fábrica
  • Pesquisar — encontre definições específicas rapidamente (em algumas versões)

As 10 categorias de definições explicadas

O SeaMeet organiza as definições em 10 categorias lógicas. Pense nestas como gavetas num arquivo — cada uma contém itens relacionados. Duas destas — AI Features e Sync — foram adicionadas na v2.1.0 para agrupar os novos controlos de modelos de resumo de IA e a sincronização entre dispositivos apoiada por GitHub:

Categoria 1: definições Gerais

Ícone: geralmente uma engrenagem ou ícone de casa O que controla: comportamento e aparência básicos da aplicação

Definições típicas incluem:

  • Comportamento de arranque — o SeaMeet deve abrir automaticamente quando o computador arranca?
  • Minimizar para a área de notificação — o SeaMeet deve continuar a correr quando fecha a janela?
  • Seleção de tema — modo claro, modo escuro ou automático (segue o sistema)
  • Preferências de notificação — que eventos devem acionar notificações?
  • Definições de atualização — o SeaMeet deve verificar atualizações automaticamente?

Quando usar esta categoria:

  • Quando instala pela primeira vez o SeaMeet e quer configurar preferências básicas
  • Quando quer alterar a aparência e sensação da aplicação
  • Quando quer controlar como o SeaMeet se comporta em segundo plano
  • Ao configurar arranque automático

Analogia: isto é como ajustar as definições básicas do seu carro — as luzes devem acender automaticamente? Deve lembrar a posição do seu banco? Deve apitar quando deixa as chaves dentro?

Categoria 2: definições de Armazenamento

Ícone: geralmente um disco rígido ou ícone de pasta O que controla: onde e como as suas gravações são guardadas

Definições típicas incluem:

  • Localização para guardar — em que pasta as gravações devem ir?
  • Gestão de armazenamento — limpeza automática de gravações antigas
  • Organização de ficheiros — como os ficheiros devem ser nomeados e ordenados?
  • Avisos de espaço em disco — alerta quando está a ficar com pouco espaço
  • Definições de cópia de segurança — as gravações devem ser copiadas para armazenamento na nuvem?

Quando usar esta categoria:

  • Quando quer alterar onde as gravações são guardadas (como mudá-las para uma unidade externa)
  • Quando está com pouco espaço em disco e precisa de gerir o armazenamento
  • Quando quer organizar as gravações de uma forma específica
  • Ao configurar limpeza automática para prevenir acumulação

Analogia: isto é como organizar o seu armário — decidir que gaveta recebe que roupa, como etiquetar caixas, e quando doar itens antigos para fazer espaço para novos.

Nota importante: isto é coberto em detalhe no Capítulo 19 (Definições de armazenamento), onde percorreremos cada opção passo a passo.

Categoria 3: definições de Áudio

Ícone: geralmente um microfone ou ícone de altifalante O que controla: tudo relacionado com gravação e reprodução de som

Definições típicas incluem:

  • Microfone predefinido — que microfone usar para gravação
  • Ganho do microfone — quão alto a sua voz deve ser gravada
  • Fonte de áudio do sistema — que saída de áudio capturar
  • Avisos Bluetooth — alertas ao usar microfones Bluetooth
  • Formato de áudio — formato preferido para gravações de áudio (MP3, WAV, etc.)
  • Taxa de amostragem — nível de qualidade de áudio (44,1kHz, 48kHz, etc.)

Quando usar esta categoria:

  • Quando as pessoas dizem que está demasiado baixo ou demasiado alto nas gravações
  • Quando tem vários microfones e quer escolher um predefinido
  • Ao usar auscultadores Bluetooth e precisa de avisos de latência
  • Quando quer mudar a qualidade do áudio ou formatos de ficheiro
  • Ao resolver problemas de gravação de áudio

Analogia: isto é como ajustar o sistema de som numa sala de concertos — escolher que microfones usar, definir os níveis de volume certos, e garantir que a acústica funciona perfeitamente para a atuação.

Nota importante: isto é coberto em detalhe no Capítulo 20 (Definições de áudio), onde mergulhamos profundamente na seleção de microfone, controlo de ganho e mais.

Categoria 4: definições de Vídeo

Ícone: geralmente uma câmara de vídeo ou ícone de monitor O que controla: tudo relacionado com gravação de ecrã

Definições típicas incluem:

  • Modo de gravação predefinido — ecrã inteiro, janela ou região
  • Qualidade do vídeo — resolução (1080p, 720p, 480p)
  • Taxa de imagens — quão suave o vídeo deve ser (30fps, 60fps)
  • Seleção de monitor — que ecrã gravar (se tem vários)
  • Formato de vídeo — formato preferido para ficheiros de vídeo (MP4, WebM, etc.)
  • Aceleração de hardware — usar GPU para melhor desempenho
  • Gravação do cursor — o ponteiro do rato deve ser visível?
  • Efeitos do cursor — destacar cliques, mudar tamanho do cursor, etc.

Quando usar esta categoria:

  • Quando quer definir um modo de gravação predefinido para poupar cliques
  • Quando precisa de equilibrar qualidade vs. tamanho do ficheiro
  • Quando tem vários monitores e precisa de especificar qual gravar
  • Ao gravar jogos e precisa de altas taxas de imagem (60fps)
  • Ao criar tutoriais e quer efeitos de cursor

Analogia: isto é como configurar uma câmara de filme — escolher a qualidade do filme, decidir que lente usar, definir a taxa de imagens para ação suave, e decidir se mostra a mão do operador na cena.

Nota importante: isto é coberto em detalhe no Capítulo 21 (Definições de vídeo), onde explicaremos todos os termos técnicos e ajudaremos a escolher as definições certas.

Categoria 5: definições do Flashback

Ícone: geralmente uma seta circular ou ícone de relógio (representando "rebobinar") O que controla: a funcionalidade de gravação máquina do tempo

Definições típicas incluem:

  • Iniciar Flashback automaticamente — o Flashback deve começar automaticamente quando o SeaMeet arranca?
  • Duração do buffer — quanto tempo no passado manter (10-120 segundos)
  • Duração do buffer de áudio — quanto áudio manter (fixo em 30 segundos)
  • Qualidade do vídeo — resolução para vídeo Flashback (frequentemente inferior à gravação normal)
  • Modo de pouca memória — reduzir uso de memória para computadores mais antigos
  • Persistência do buffer — manter o buffer ao mudar de aplicações?

Quando usar esta categoria:

  • Quando quer que o Flashback esteja sempre pronto (início automático)
  • Quando precisa de equilibrar quanto pode guardar do passado vs. uso de memória
  • Quando o seu computador é mais antigo e precisa de conservar RAM
  • Quando quer personalizar como o Flashback se comporta

Analogia: isto é como configurar o DVR de uma câmara de segurança — decidir quantos dias de filmagem manter, definir a qualidade de gravação, e gerir o espaço de armazenamento para a gravação constante.

Nota importante: isto é coberto em detalhe no Capítulo 22 (Definições do Flashback), onde o ajudaremos a encontrar o equilíbrio perfeito entre duração do buffer e desempenho.

Categoria 6: AI Features (Novo na v2.1.0)

Ícone: um ícone roxo de brilho/varinha mágica O que controla: tudo o que alimenta o lado IA do SeaMeet — transcrição ao vivo, extração pós-reunião, modelos de resumo e (opcionalmente) o Agente IA na aplicação

O grupo AI Features contém três itens de menu:

  • AI Transcription, Extraction, Summary, Wiki — o seu fornecedor de modelo, entrada de chave de API BYOK, idioma do resumo, e quais pipelines de IA correm automaticamente após uma gravação. Coberto em detalhe no Capítulo 36 (Bring Your Own Key — BYOK).
  • AI Summary Templates — a nova biblioteca de modelos lançada na v2.1.0 (48 modelos incorporados em 8 categorias: Equipa e Gestão, Projeto e Agile, Vendas e Cliente, RH e Recrutamento, Educação e Formação, Médico e Saúde, Legal e Conformidade, e Eventos e Média). Inclui o alternador Auto-detect summary template (predefinição ATIVA) — quando ativado, o SeaMeet classifica a transcrição de cada reunião e escolhe o modelo que melhor se ajusta; quando desativado, cada gravação usa Meeting Minutes e nenhuma chamada de classificador é feita. Coberto em detalhe no Capítulo 33 (Modelos de resumo de IA).
  • AI Agent & Cowork — apenas visível quando a flag do recurso de agente está ativada. Aloja a configuração de chat-agente (Provider, predefinições Ask/Code/Plan). Coberto em detalhe no Capítulo 37 (Copilot & AI Agent).

Quando usar esta categoria:

  • Quando quer configurar BYOK com a sua própria chave de API Gemini
  • Quando quer mudar o comportamento Auto-detect template globalmente
  • Quando quer navegar pela biblioteca de modelos instalados sem abrir uma gravação
  • Ao configurar as predefinições do Agente IA

Analogia: esta é a sala de controlo da IA — o painel onde escolhe a que "cérebro" o SeaMeet está ligado e quão agressivamente deve pensar por si.

Categoria 7: definições de Gravação automática

Ícone: geralmente uma lupa ou ícone robô/automação O que controla: deteção e gravação automática de reuniões

Definições típicas incluem:

  • Deteção automática ativada — interruptor principal para a funcionalidade
  • Sensibilidade da deteção — quão agressiva a deteção deve ser
  • Ação predefinida — iniciar gravação imediatamente ou apenas notificar?
  • Permissões por aplicação — que aplicações podem acionar gravação automática
  • Métodos de deteção — que sinais observar (título de janela, áudio, etc.)
  • Atraso antes de iniciar — esperar alguns segundos após deteção para começar
  • Ações pós-reunião — o que fazer quando uma reunião termina

Quando usar esta categoria:

  • Ao configurar o SeaMeet pela primeira vez e ativar deteção automática
  • Quando quer afinar que aplicações acionam gravação
  • Quando acha a deteção automática demasiado sensível (ou não sensível o suficiente)
  • Quando quer que o SeaMeet espere um momento antes de iniciar
  • Ao personalizar o que acontece depois de as reuniões terminarem

Analogia: isto é como treinar um assistente inteligente — ensiná-lo a reconhecer quando está numa reunião, decidir que reuniões importam, e dizer-lhe como responder quando deteta uma.

Nota importante: isto é coberto em detalhe no Capítulo 23 (Definições de gravação automática), onde percorreremos a configuração de permissões para todas as 47+ aplicações suportadas.

Categoria 8: Sync (Novo na v2.1.0)

Ícone: marca GitHub / ícone de nuvem O que controla: cópia de segurança opcional na nuvem privada das suas notas e wiki via o seu próprio repositório GitHub

Definições típicas incluem:

  • Set Up GitHub Sync / Authorize GitHub — fluxo OAuth de um clique que cria um repositório privado por espaço de trabalho
  • Auto-sync on changes — commit e push à medida que edita (predefinição ATIVA)
  • Sync on startup — puxar as últimas alterações quando o SeaMeet arranca (predefinição ATIVA)
  • Sync interval — quão frequentemente edições locais são agrupadas num commit (1, 5, 10 ou 30 minutos)
  • Sync Now — acionador manual de commit + push
  • Conflict resolution — edição manual ou fusão assistida por Agente quando dois dispositivos editam o mesmo ficheiro
  • Re-authorize / Disconnect — atualizar OAuth do GitHub ou desligar o espaço de trabalho

Âmbito importante: Sync cobre apenas notas e wiki (ficheiros .md). Gravações de áudio, gravações de vídeo e capturas de ecrã permanecem no seu dispositivo — nunca são empurradas para o GitHub. Isto é o que permite que um único repositório do plano gratuito do GitHub de 1 GB contenha aproximadamente 200.000–500.000 notas.

Quando usar esta categoria:

  • Ao configurar acesso entre dispositivos às suas notas e wiki pela primeira vez
  • Quando quer as suas notas copiadas para um repositório GitHub privado sem custo
  • Ao resolver um conflito de sincronização entre dois dispositivos
  • Quando precisa de re-autorizar depois do token OAuth expirar

Restrição por assinatura: Sync vem com BYOK Pro. Utilizadores gratuitos veem o item de menu Sync com uma insígnia "BYOK Pro" e um banner de incentivo que abre o paywall quando clicado.

Analogia: este é o seu cofre de segurança fora do local — uma cópia privada e controlada por versões de cada nota que o segue entre máquinas, sem nunca carregar os ficheiros multimédia pesados.

Nota importante: isto é coberto em detalhe no Capítulo 38 (GitHub Sync).

Categoria 9: definições de Idioma e Região

Ícone: geralmente um globo ou ícone de bandeira O que controla: idioma de apresentação, formatos regionais e localização

Definições típicas incluem:

  • Idioma de apresentação — idioma da interface do SeaMeet (16+ opções!)
  • Formato de data — como as datas são mostradas (MM/DD/YYYY vs DD/MM/YYYY)
  • Formato de hora — 12 horas (AM/PM) vs formato 24 horas
  • Fuso horário — para marcas temporais precisas nas gravações
  • Primeiro dia da semana — domingo vs segunda-feira (para vistas de calendário)
  • Formato numérico — separador decimal (ponto vs vírgula)

Idiomas disponíveis incluem:

  1. Inglês
  2. Espanhol (Español)
  3. Francês (Français)
  4. Alemão (Deutsch)
  5. Italiano (Italiano)
  6. Português (Português)
  7. Holandês (Nederlands)
  8. Russo (Русский)
  9. Chinês simplificado (简体中文)
  10. Chinês tradicional (繁體中文)
  11. Japonês (日本語)
  12. Coreano (한국어)
  13. Árabe (العربية)

Compreender os controlos de definições

Diferentes definições usam diferentes tipos de controlos. Eis um guia para reconhecer e usar cada tipo:

Alternadores (Ligado/Desligado)

Como parecem: Um interruptor horizontal que desliza para a esquerda (desligado) ou direita (ligado). Frequentemente colorido quando ligado (geralmente azul ou verde).

Nome da definição    [━━●──]   ← Posição desligada
                     [──●━━]   ← Posição ligada (colorida)

Como usar:

  • Clique no interruptor para o alternar
  • O interruptor deslizará e mudará de cor
  • A alteração geralmente tem efeito imediato

Exemplos no SeaMeet:

  • Iniciar Flashback automaticamente
  • Minimizar para a área de notificação do sistema
  • Ativar deteção automática
  • Mostrar cursor nas gravações

Analogia: como um interruptor de luz na sua parede — vire de um lado para ligar, do outro para desligar.

Menus suspensos

Como parecem: Um campo retangular mostrando a seleção atual com uma seta para baixo à direita.

Qualidade de gravação   [1080p HD        ▼]
                         ↑ Valor       ↑ Clique para ver
                           atual         todas as opções

Como usar:

  1. Clique no menu suspenso (ou na seta)
  2. Aparece uma lista de opções abaixo
  3. Clique na sua opção desejada
  4. O menu fecha-se com a sua nova seleção a aparecer

Exemplos no SeaMeet:

  • Qualidade de vídeo (1080p, 720p, 480p)
  • Taxa de imagens (30fps, 60fps)
  • Formato de áudio (MP3, WAV, WebM)
  • Modo de gravação predefinido (ecrã inteiro, janela, região)
  • Idioma de apresentação (16 opções)

Analogia: como um menu de restaurante — vê a seleção atual no seu prato, mas pode abrir o menu para escolher algo diferente.

Campos de entrada de texto

Como parecem: Uma caixa retangular vazia ou pré-preenchida onde pode escrever.

Localização para guardar  [C:\Users\You\Recordings    ] [Procurar...]
                            ↑ Clique aqui para     ↑ Ou clique para
                              escrever               navegar pelas pastas

Como usar:

  1. Clique dentro do campo de texto
  2. Escreva o seu texto (ou limpe primeiro o texto existente)
  3. Prima Tab ou clique noutro lado quando terminar

Funcionalidades especiais:

  • Botão Procurar — frequentemente junto a campos de caminho, abre um navegador de ficheiros
  • Texto marcador — texto cinzento a mostrar entrada de exemplo
  • Validação — pode ficar vermelho se introduzir algo inválido

Exemplos no SeaMeet:

  • Caminho do diretório de gravação
  • Padrão de nomenclatura de ficheiro
  • Atalhos de teclado personalizados
  • Nome do dispositivo de microfone (por vezes)

Analogia: como preencher um formulário no consultório do médico — escreve informação em campos em branco.

Sliders

Como parecem: Uma barra horizontal com um manípulo que pode arrastar para a esquerda ou direita.

Ganho do microfone   [━●━━━━━━━━━━━] 45%
                      ↑ Arraste este botão
                        esquerda (mais baixo)
                        ou direita (mais alto)

Como usar:

  1. Clique e mantenha o manípulo do slider (ou botão)
  2. Arraste-o para a esquerda para diminuir o valor
  3. Arraste-o para a direita para aumentar o valor
  4. Liberte quando satisfeito

Alternativa: clique em qualquer lugar na barra do slider para saltar para essa posição

Exemplos no SeaMeet:

  • Ganho/volume do microfone
  • Sensibilidade da deteção (para gravação automática)
  • Duração do buffer (para Flashback)
  • Equilíbrio qualidade/compressão

Analogia: como um botão de volume num estéreo — rode à esquerda para mais baixo, à direita para mais alto.

Botões

Como parecem: Botões retangulares ou arredondados com rótulos de texto.

[Verificar atualizações] [Repor predefinições] [Procurar...]

Como usar:

  • Simplesmente clique no botão uma vez
  • Algo acontece imediatamente (caixa de diálogo abre, ação realizada, etc.)

Tipos de botões:

  • Botões de ação — realizam uma ação (Verificar atualizações, Procurar)
  • Botões de repor — restauram predefinições (Repor predefinições)
  • Botões de navegação — vão para outros ecrãs (Definições avançadas)
  • Botões de confirmação — guardar ou cancelar alterações (Aplicar, OK, Cancelar)

Exemplos no SeaMeet:

  • Procurar (para escolher pastas)
  • Repor predefinições (para qualquer categoria)
  • Verificar atualizações (na secção Acerca)
  • Aplicar/Guardar alterações
  • Testar microfone (em definições de Áudio)

Analogia: como botões de elevador — prima uma vez e o elevador faz alguma coisa (subir, descer, abrir portas).

Caixas de verificação

Como parecem: Um pequeno quadrado que pode ser marcado (✓) ou vazio.

☐ Iniciar SeaMeet quando o computador arranca
☑ Minimizar para área de notificação ao fechar
☐ Mostrar notificações de gravação

Como usar:

  • Clique na caixa de verificação para a alternar
  • Aparece uma marca quando ativada
  • Clique novamente para desmarcar

Diferença dos alternadores:

  • As caixas de verificação são tipicamente usadas quando pode selecionar várias opções
  • Os alternadores são usados para escolhas únicas ligado/desligado
  • O SeaMeet usa principalmente alternadores, mas pode ver caixas de verificação em definições avançadas

Analogia: como uma lista de tarefas — marca itens que completou.

Comportamento das definições: imediato vs. aplicado

Nem todas as definições funcionam da mesma forma quando as altera. Há dois comportamentos principais:

Definições imediatas

Estas têm efeito assim que as altera — sem necessidade de clicar em "Aplicar" ou "Guardar".

Exemplos:

  • Mudanças de tema (modo claro/escuro)
  • Seleção de idioma
  • Interruptores alternadores (a maioria deles)
  • Sliders de volume/ganho (ouve a mudança em tempo real)

Como reconhecê-las:

  • As mudanças acontecem instantaneamente
  • Nenhum botão "Aplicar" necessário
  • Geralmente mudanças visuais ou interruptores simples

Definições aplicadas

Estas requerem que clique em "Aplicar", "OK" ou "Guardar" antes de terem efeito.

Exemplos:

  • Caminho da localização para guardar
  • Modo de gravação predefinido
  • Configurações complexas de áudio/vídeo
  • Algumas definições de permissões

Como reconhecê-las:

  • Um botão "Aplicar" ou "Guardar" está presente
  • Pode ver indicadores de "alterações por guardar"
  • As alterações não acontecem até confirmar

Importante: se alterar definições e clicar em "Cancelar", as suas alterações serão descartadas! Clique sempre em "Aplicar" ou "OK" se quer manter as suas alterações.

A funcionalidade de pesquisa (se disponível)

Algumas versões do SeaMeet incluem uma caixa de pesquisa no topo do painel de Definições. Isto é incrivelmente útil!

Como usar a pesquisa:

  1. Procure uma caixa de pesquisa (geralmente diz "Pesquisar definições..." ou tem um ícone de lupa)

  2. Clique na caixa de pesquisa e escreva palavras-chave:

    • "microfone" → mostra todas as definições relacionadas com microfone
    • "guardar" → mostra definições de armazenamento e localização para guardar
    • "qualidade" → mostra definições de qualidade de vídeo e áudio
    • "atalho" → mostra definições de atalhos de teclado

  3. À medida que escreve, a lista de definições filtra-se para mostrar apenas itens correspondentes

  4. Clique num resultado para saltar diretamente para essa definição

Porque a pesquisa é útil:

  • Encontre definições rapidamente sem navegar por categorias
  • Descubra definições relacionadas que não sabia que existiam
  • Ótimo quando não tem certeza em que categoria está uma definição
  • Poupa tempo quando sabe exatamente o que quer alterar

Fluxos de trabalho comuns de definições

Eis alguns cenários típicos e os passos exatos para lidar com eles:

Cenário 1: configuração da primeira vez

É novo no SeaMeet e quer configurar o básico:

  1. Abra Definições (clique no ícone de engrenagem na barra lateral esquerda)

  2. Vá a Geral

    • Defina o tema à sua preferência
    • Ative "Minimizar para área de notificação" se desejado
    • Ative "Iniciar com o computador" se desejado

  3. Vá a Armazenamento

    • Verifique ou altere a localização para guardar
    • Configure avisos de espaço em disco

  4. Vá a Áudio

    • Selecione o seu microfone predefinido
    • Teste o microfone e ajuste o ganho
    • Verifique avisos Bluetooth se usa auscultadores sem fios

  5. Vá a Idioma

    • Selecione o seu idioma de apresentação preferido

  6. Clique em Aplicar para guardar todas as alterações

  7. Vá a Acerca para anotar o seu número de versão (útil para suporte)

Cenário 2: mudar onde as gravações são guardadas

A sua unidade C: está a encher e quer mover as gravações para uma unidade externa:

  1. Abra Definições

  2. Clique em Armazenamento na barra lateral esquerda

  3. Encontre "Localização para guardar" ou "Diretório de gravação"

  4. Clique no botão "Procurar"

  5. Navegue para a sua unidade externa no navegador de ficheiros

    • Exemplo: D:\SeaMeet Recordings

  6. Selecione ou crie uma pasta

  7. Clique em OK no navegador de ficheiros

  8. Clique em Aplicar nas Definições

  9. Opcional: mova as suas gravações existentes para a nova localização usando o Explorador de Ficheiros

Cenário 3: configurar deteção automática

Quer que o SeaMeet detete automaticamente reuniões do Zoom:

  1. Abra Definições

  2. Clique em Gravação automática

  3. Ative "Deteção automática" (interruptor)

  4. Encontre o Zoom na lista de aplicações

  5. Ative a permissão para o Zoom (alternador ou caixa de verificação)

  6. Escolha a ação predefinida: iniciar gravação imediatamente ou apenas notificar?

  7. Ajuste a sensibilidade se necessário (slider)

  8. Clique em Aplicar

  9. Teste: abra o Zoom e inicie uma reunião para ver se o SeaMeet a deteta

Cenário 4: otimizar para um computador mais antigo

O seu computador tem alguns anos e está a correr lento durante as gravações:

  1. Abra Definições

  2. Vá a Vídeo

    • Reduza a qualidade do vídeo para 720p ou 480p
    • Defina a taxa de imagens para 30fps (em vez de 60fps)
    • Desative a aceleração de hardware se está a causar problemas

  3. Vá a Flashback

    • Ative "Modo de pouca memória"
    • Reduza a duração do buffer para 30-60 segundos (em vez de 120)

  4. Vá a Áudio

    • Escolha uma taxa de amostragem mais baixa se disponível (44,1kHz em vez de 48kHz)

  5. Vá a Armazenamento

    • Ative a limpeza automática para prevenir problemas de espaço em disco

  6. Clique em Aplicar

  7. Teste uma gravação para ver se o desempenho melhora

Cenário 5: preparar uma apresentação profissional

Precisa de gravar uma apresentação de alta qualidade para o trabalho:

  1. Abra Definições

  2. Vá a Vídeo

    • Defina a qualidade para 1080p (ou a mais alta disponível)
    • Defina a taxa de imagens para 60fps para movimento suave
    • Ative "Gravar cursor"
    • Ative "Destacar cliques do cursor" se disponível

  3. Vá a Áudio

    • Selecione o seu melhor microfone
    • Defina o ganho ao nível ideal (teste primeiro!)
    • Escolha o formato de alta qualidade (WAV para o melhor, ou MP3 de alta taxa de bits)

  4. Vá a Geral

    • Desative as notificações para prevenir interrupções
    • Garanta que "Minimizar para área de notificação" está ativado

  5. Vá a Armazenamento

    • Verifique que tem espaço em disco suficiente (vídeo HD usa muito espaço!)

  6. Clique em Aplicar

  7. Faça uma gravação de teste de 30 segundos para verificar se tudo está perfeito visual e sonoramente

Dicas e truques de definições

Dica 1: a rede de segurança "Repor predefinições"

Se altera definições e algo deixa de funcionar, não entre em pânico! Cada categoria tem um botão "Repor predefinições" que devolve essa secção às definições de fábrica.

Como usar:

  1. Vá à categoria problemática
  2. Clique em "Repor predefinições" (geralmente no fundo)
  3. Confirme a reposição
  4. Tente novamente com definições limpas

Cuidado: isto repõe TODAS as definições nessa categoria, não apenas a que alterou pela última vez.

Dica 2: exportar/importar definições (se disponível)

Algumas versões do SeaMeet permitem-lhe exportar as suas definições para um ficheiro. Isto é ótimo para:

  • Fazer cópia de segurança das suas preferências
  • Transferir definições para outro computador
  • Partilhar definições otimizadas com colegas

Procure: botões "Exportar definições" ou "Importar definições", geralmente em Geral ou no fundo do painel de Definições.

Dica 3: navegação por teclado

Pode navegar pelas definições sem rato:

  • Tab — mover para o próximo controlo
  • Shift + Tab — mover para o controlo anterior
  • Espaço — alternar caixas de verificação ou ativar botões
  • Setas — navegar opções de menu suspenso ou ajustar sliders
  • Enter — confirmar seleções ou ativar botões

Isto é especialmente útil para acessibilidade ou quando o seu rato não está a funcionar.

Dica 4: pairar para ajuda

Muitas definições têm dicas úteis. Paire o rato sobre o nome de uma definição ou controlo para ver informação adicional.

Exemplo: pairar sobre "Ganho do microfone" pode mostrar: "Ajuste isto se as suas gravações são demasiado baixas ou altas. 50% é a predefinição."

Dica 5: as definições são guardadas automaticamente (geralmente)

Na maioria dos casos, o SeaMeet guarda automaticamente as suas definições quando as altera. No entanto, algumas alterações complexas requerem clicar em "Aplicar".

Sinais de que precisa de clicar em Aplicar:

  • Um botão "Aplicar" está visível e clicável
  • Vê texto como "Alterações não guardadas"
  • A definição envolve caminhos de ficheiro ou recursos externos

Em caso de dúvida: clique em Aplicar! Nunca dói confirmar as suas alterações.

Compreender a persistência das definições

Eis algo importante para compreender: as definições são guardadas no seu perfil de utilizador e persistem entre sessões.

O que isto significa:

  • As definições sobrevivem quando fecha e reabre o SeaMeet
  • As definições mantêm-se as mesmas mesmo que reinicie o seu computador
  • As definições estão ligadas à sua conta de utilizador Windows/Mac
  • Se tem várias contas de utilizador, cada uma tem as suas próprias definições

Onde as definições são armazenadas (técnico):

  • Windows: geralmente na sua pasta de perfil de utilizador, frequentemente em AppData
  • macOS: na sua pasta Library de utilizador
  • Não precisa de aceder a estes ficheiros diretamente — use a UI de Definições

Exceções:

  • Algumas versões portáteis podem armazenar definições na pasta da aplicação
  • Implementações empresariais podem usar definições centralizadas
  • Reinstalar o SeaMeet geralmente preserva as definições do utilizador

Segurança e privacidade das definições

As definições do SeaMeet são locais ao seu computador e geralmente não contêm informação sensível. No entanto:

O que está nas definições:

  • Caminhos de ficheiros (podem revelar estrutura de pastas)
  • Preferências da aplicação (que funcionalidades usa)
  • Escolhas de hardware (que microfone prefere)
  • Sem palavras-passe ou credenciais de conta

Considerações de privacidade:

  • As definições não incluem as suas gravações reais (apenas onde são guardadas)
  • As definições de deteção automática mostram que aplicações usa (mas não dados de uso)
  • Sem sincronização na nuvem das definições (tudo fica local)

Ambientes empresariais:

  • Os administradores de TI podem conseguir ver ou gerir definições
  • A política de grupo pode anular algumas definições
  • Verifique com o seu departamento de TI se tem preocupações

Resolução de problemas das definições

Problema 1: as definições não guardam

Sintomas: altera uma definição, mas reverte quando reabre as Definições.

Soluções:

  1. Certifique-se de que clica em "Aplicar" — algumas definições requerem guardar explicitamente
  2. Verifique o espaço em disco — se a sua unidade está cheia, as definições não podem ser guardadas
  3. Execute como administrador — tente clicar com o botão direito no SeaMeet e "Executar como administrador"
  4. Verifique as permissões — garanta que tem acesso de escrita à sua pasta de perfil de utilizador
  5. Reinstale o SeaMeet — faça cópia de segurança das suas gravações primeiro, depois reinstale

Problema 2: as definições estão a cinzento

Sintomas: algumas definições são visíveis mas não podem ser alteradas (a cinzento ou desativadas).

Causas comuns:

  • Outra definição as desativa — por exemplo, não pode definir a qualidade de vídeo se a gravação de vídeo está desativada
  • Restrições de admin/empresariais — a sua organização pode bloquear certas definições
  • Funcionalidade não disponível — essa funcionalidade pode não estar incluída na sua versão
  • Limitações de hardware — algumas definições requerem hardware específico

Soluções:

  1. Verifique se precisa de ativar primeiro uma definição pai
  2. Contacte o seu departamento de TI se for restrição empresarial
  3. Verifique a versão do SeaMeet (algumas funcionalidades são específicas da versão)
  4. Verifique se o seu hardware suporta a funcionalidade

Problema 3: UI de definições está com falhas

Sintomas: as definições parecem erradas, sobrepõem-se ou não se exibem corretamente.

Soluções:

  1. Redimensione a janela — tente tornar a janela do SeaMeet maior
  2. Reinicie o SeaMeet — feche e reabra a aplicação
  3. Atualize os controladores gráficos — controladores desatualizados podem causar problemas de UI
  4. Altere a escala de visualização — se usa alta DPI (4K), tente temporariamente escala 100%
  5. Reinstale o SeaMeet — se nada mais funciona, uma instalação nova geralmente resolve problemas de UI

Problema 4: não consigo encontrar uma definição

Sintomas: sabe que uma definição existe, mas não a consegue localizar.

Soluções:

  1. Use a pesquisa — escreva palavras-chave na caixa de pesquisa de definições
  2. Verifique todas as categorias — pode estar numa categoria inesperada
  3. Verifique definições avançadas — algumas definições estão escondidas atrás de um botão "Avançado"
  4. Atualize o SeaMeet — a definição pode estar numa versão mais recente
  5. Leia o manual — cada capítulo de definições lista todas as opções disponíveis

Avançado: localização do ficheiro de definições (para utilizadores avançados)

Se é um utilizador técnico e precisa de aceder às definições diretamente, eis onde as encontrar:

Windows

C:\Users\[OSeuUtilizador]\AppData\Roaming\SeaMeet\

  • settings.json
  • config.json
  • preferences.json
  • SeaMeet.config

Como aceder:

  1. Prima Windows + R
  2. Escreva %AppData%\SeaMeet e prima Enter

  4. Clique em Ir

Quando editar ficheiros de definições diretamente

Geralmente, nunca deveria precisar de fazer isto, mas pode ser útil para:

  • Migrar definições entre computadores sem nuvem
  • Editar em massa várias definições de uma vez
  • Recuperar definições de uma cópia de segurança
  • Resolução de problemas quando a UI não abre

Sempre:

  • Feche o SeaMeet completamente antes de editar
  • Faça uma cópia de segurança primeiro
  • Use um editor JSON/texto adequado (Notepad++, VS Code, etc.)
  • Verifique que o formato do ficheiro está correto antes de guardar

Útil (configure quando necessário)

Glossário de definições: referência rápida

Eis um glossário rápido de termos que verá pelas Definições:

Ativar/Desativar — ligar ou desligar uma funcionalidade Predefinição — a definição usada a menos que especifique de outra forma Caminho/Diretório — uma localização no seu computador (como C:\Users\You\Documents) Procurar — abrir um navegador de ficheiros para selecionar uma localização Taxa de bits — quanto dados são usados por segundo (mais alto = melhor qualidade, ficheiros maiores) Taxa de amostragem — quão frequentemente o áudio é capturado por segundo (44,1kHz = 44.100 vezes/segundo) Resolução — tamanho da imagem de vídeo (1080p = 1920×1080 píxeis) Taxa de imagens — quantas imagens de vídeo por segundo (fps) Buffer — armazenamento temporário de memória para dados em curso Ganho — nível de volume de entrada (sensibilidade do microfone) Codec — software que comprime/descomprime áudio/vídeo Formato — tipo de ficheiro (MP3, MP4, WebM, etc.) Alternador — um interruptor que liga ou desliga algo Aplicar — guardar as alterações que fez Repor — voltar a valores originais/predefinidos

  • Saber a diferença entre definições imediatas e aplicadas
  • Explicar quando usar cada categoria principal
  • Navegar para qualquer definição sem se perder
  • Encontrar o alternador Auto-detect summary template em AI Features → AI Summary Templates
