您的錄音庫

第八章：您的錄音庫

使用 SeaMeet 幾週之後，您可能已經累積了數十甚至數百筆錄音。會議記錄、腦力激盪、重要通話、隨手記下的想法，還有各種五花八門的內容。如果缺乏妥善的整理，想要找到三週前主管說明新流程的那段錄音，簡直像大海撈針。

本章將教您如何整理、管理和瀏覽不斷增長的錄音收藏。您將了解 SeaMeet 如何自動整理您的檔案、如何找到您需要的內容，以及如何保持錄音庫的整潔與實用。

錄音庫：您的數位檔案櫃

將 SeaMeet 的錄音庫想像成一個專門為音訊和影片錄音設計的數位檔案櫃。就像實體檔案櫃有資料夾、標籤和歸檔系統一樣，SeaMeet 的錄音庫也有工具幫助您分類、尋找和管理錄音。

錄音庫的功能：

  • 在一個地方顯示所有錄音
  • 顯示每筆錄音的重要資訊
  • 讓您播放、重新命名、刪除和整理錄音
  • 幫助您快速找到特定錄音
  • 追蹤檔案的儲存位置

位置： 錄音庫就是 SeaMeet 視窗左側的側邊欄——顯示錄音清單的面板。

了解錄音清單

當您查看錄音清單時，會看到一組錄音卡片——每張卡片代表一筆錄音。

錄音卡片的組成

每張錄音卡片一目了然地顯示基本資訊：

┌──────────────────────────────────────────┐
│ 🔴                                       │
│ Team Meeting - Q3 Planning              │  ← 錄音名稱/標籤
│ 47:32 • Today, 2:30 PM                  │  ← 時長與時間戳記
│ Zoom • Audio + Video                    │  ← 來源與類型
│                                          │
│ [▶ 播放] [✏️ 重新命名] [🗑️ 刪除] [⋯]    │  ← 操作按鈕
└──────────────────────────────────────────┘

讓我們逐一介紹每個元素：

圖示（左側）

純音訊錄音： 🎤 或 🔴 影片錄音： 🎥 或 📹 Flashback 錄音： ⏪（可能包含此指示符）

圖示的含義：

  • 🎤 麥克風圖示： 純音訊錄音（語音備忘、電話通話）
  • 🔴 紅色圓點： 來自麥克風來源的音訊錄音
  • 🎥 攝影機： 影片錄音（螢幕、視窗或區域）
  • 🔊 喇叭： 系統音訊錄音（電腦聲音）
  • 🎤+🔊 組合： 同時包含麥克風和系統音訊的錄音

快速辨識： 只需看一眼圖示，就能分辨錄音是純音訊還是影片。

錄音名稱/標籤

內容： 錄音的名稱 來源： 根據來源和時間戳記自動產生 可以更改嗎？ 當然可以！您可以將錄音重新命名為任何您想要的名稱。

預設命名模式：

[Source]_[AppName]_[Timestamp]

預設名稱範例：

  • Microphone_seameet_20260102143045.webm
  • Zoom_seameet_20260102150022.webm
  • SystemAudio_Chrome_seameet_20260102154510.webm
  • Both_Teams_seameet_20260102160033.webm

為什麼預設名稱……不太理想： 預設名稱的設計是為了讓電腦能夠識別唯一且包含資訊，但對人來說並不太友善。Microphone_seameet_20260102143045.webm 無法告訴您那是關於新網站設計的腦力激盪會議。

解決方法： 用描述性的名稱重新命名您的錄音！

好的重新命名範例：

  • Q3 Budget Review - Team Meeting
  • Client Call - Acme Corp Website
  • Podcast Episode 47 - Interview with Dr. Smith
  • Idea - New Product Feature Brainstorm
  • Lecture - Intro to Machine Learning

時長

格式： 時:分:秒（H:MM:SS 或 M:SS）

範例：

  • 5:32 = 5 分鐘 32 秒
  • 47:32 = 47 分鐘 32 秒
  • 1:23:45 = 1 小時 23 分鐘 45 秒

重要性：

  • 幫助您了解錄音的長度
  • 有助於找到特定會議（「大約一小時長」）
  • 幫助管理儲存空間（越長 = 檔案越大）

快速參考：

5 分鐘以下    → 快速筆記、想法、提醒
5-15 分鐘     → 短對話、站立會議
15-30 分鐘    → 標準會議、通話
30-60 分鐘    → 較長會議、簡報
60 分鐘以上   → 長時間會議、線上研討會、課程

時間戳記

格式： 錄音開始的日期和時間

範例：

  • Today, 2:30 PM（如果是今天錄製的）
  • Yesterday, 10:15 AM（如果是昨天錄製的）
  • Jan 15, 9:00 AM（如果是更早之前錄製的）

精確度：

  • 近期錄音：顯示相對時間（今天、昨天）
  • 較早的錄音：顯示日期

重要性：

  • 根據特定日期找到錄音
  • 按時間順序排列
  • 提供參考依據（「上週二的會議」）

來源標籤

顯示內容： 錄音的來源

範例：

  • Microphone — 僅從麥克風錄製
  • Zoom — 偵測為 Zoom 會議
  • Chrome — 在 Google Chrome 瀏覽器中錄製
  • Teams — Microsoft Teams 會議
  • System Audio — 僅電腦聲音
  • Both - Zoom — 來自 Zoom 的麥克風 + 系統音訊組合

為什麼有用：

  • 知道哪個應用程式或來源產生了錄音
  • 幫助按會議平台分類
  • 適用於篩選（「顯示所有 Zoom 錄音」）

類型指示符

顯示： 錄音的類型

範例：

  • Audio only — 只有聲音，沒有影片
  • Audio + Video — 同時包含聲音和螢幕錄影
  • Video only — 只有螢幕畫面，沒有音訊
  • Flashback — 使用 Flashback 功能擷取

重要性：

  • 幫助您知道播放時預期的內容
  • 純音訊載入更快
  • 影片檔案較大
  • Flashback 錄音可能包含特殊內容

錄音卡片檢視模式：精簡 vs. 展開

SeaMeet 提供兩種檢視錄音卡片的方式：精簡和展開。

精簡檢視（預設）

外觀：

┌──────────────────────────────────────────┐
│ 🎤 Q3 Budget Review - Team Meeting      │
│ 47:32 • Today, 2:30 PM • Zoom           │
└──────────────────────────────────────────┘

特點：

  • 最少的資訊
  • 只顯示必要的細節
  • 佔用較少空間
  • 適合瀏覽大量錄音
  • 操作按鈕在滑鼠懸停或點擊時出現

適用時機：

  • 您有很多錄音
  • 您想快速瀏覽
  • 您正在尋找特定日期或時長

展開檢視

外觀：

┌──────────────────────────────────────────┐
│                                          │
│  🎤 Q3 Budget Review - Team Meeting     │
│                                          │
│  時長: 47:32                             │
│  錄製時間: Today, 2:30 PM               │
│  來源: Zoom                              │
│  類型: Audio + Video                     │
│  檔案: Q3_Budget_Review.webm             │
│  大小: 145 MB                            │
│                                          │
│  ┌──────────────────────────────────┐   │
│  │  [波形預覽]                      │   │
│  │                                  │   │
│  └──────────────────────────────────┘   │
│                                          │
│  [▶ 播放] [✏️ 重新命名] [📂 顯示檔案]    │
│  [🗑️ 刪除] [📤 分享] [⋯ 更多]           │
│                                          │
└──────────────────────────────────────────┘

特點：

  • 顯示所有可用資訊
  • 包含波形預覽（如果是音訊）
  • 顯示所有操作按鈕
  • 每筆錄音佔用較多空間
  • 適合檢視特定錄音

適用時機：

  • 您想查看所有詳細資訊
  • 您正準備播放或編輯
  • 您需要查看波形
  • 您想快速存取所有操作

如何切換檢視模式

方法一：針對個別錄音

  1. 點擊錄音卡片
  2. 尋找展開/收合按鈕或箭頭
  3. 點擊以在精簡和展開之間切換

方法二：全域檢視切換

  1. 在側邊欄標題中尋找檢視切換按鈕
  2. 通常以圖示形式出現（☰ 清單檢視、▦ 網格檢視等）
  3. 點擊以更改所有錄音的預設檢視

方法三：雙擊

  • 雙擊錄音以開啟展開檢視
  • 再次雙擊或按 Escape 以收合

整理您的錄音

既然您已了解畫面上的各個元素，讓我們學習如何整理您的收藏。

重新命名錄音

為什麼要重新命名？

  • 預設名稱難以記住
  • 描述性名稱有助於日後找到錄音
  • 有利於專業化的整理
  • 讓分享更容易（他人能理解內容）

如何重新命名：

方法一：快速重新命名

  1. 找到您要重新命名的錄音
  2. 尋找重新命名按鈕（✏️ 鉛筆圖示）或右鍵選單
  3. 點擊「Rename」
  4. 輸入新名稱
  5. 按 Enter 或點擊「Save」

方法二：展開檢視

  1. 展開錄音卡片
  2. 點擊名稱欄位
  3. 編輯名稱
  4. 儲存變更

方法三：右鍵選單

  1. 右鍵點擊（Mac 上為 Control-點擊）錄音
  2. 從選單中選擇「Rename」
  3. 輸入新名稱
  4. 確認

良好的命名慣例：

會議：

[類型] - [主題/客戶] - [日期]
Team Meeting - Q3 Planning - Jan 15
Client Call - Acme Corp - Jan 16
1-on-1 - Sarah - Jan 17

內容：

[類型] - [集數/主題] - [來賓/話題]
Podcast Ep47 - Interview with Dr. Smith
Tutorial - Photoshop Layers
Lecture - Intro to ML Week 3

想法/筆記：

[分類] - [簡要說明]
Idea - New Homepage Design
Notes - Competitor Analysis
Reminder - Call Insurance Company

命名小技巧：

  • ✓ 描述性但簡潔
  • ✓ 對時效性內容加上日期
  • ✓ 使用一致的格式
  • ✓ 包含關鍵人物或主題
  • ✗ 避免特殊字元（/ \ : * ? " < > |）
  • ✗ 不要讓名稱太長（不易閱讀）

刪除錄音

警告： 刪除錄音是永久性的。檔案將從您的電腦中移除。

刪除前請注意：

  • 確認您不再需要它
  • 考慮將重要錄音歸檔而非刪除
  • 請記住：SeaMeet 沒有「資源回收筒」或「垃圾桶」功能

如何刪除：

方法一：刪除按鈕

  1. 找到錄音
  2. 點擊刪除按鈕（🗑️ 垃圾桶圖示）
  3. 確認刪除
  4. 錄音被永久移除

方法二：右鍵選單

  1. 右鍵點擊錄音
  2. 選擇「Delete」
  3. 確認

方法三：鍵盤快捷鍵

  1. 選取錄音
  2. 按 Delete 鍵
  3. 確認

刪除後會發生什麼：

  • 錄音從 SeaMeet 的錄音庫中移除
  • 檔案從您的儲存資料夾中刪除
  • 無法復原（除非您有備份）
  • 釋放儲存空間

⚠️ 重要： 在 SeaMeet 中刪除會刪除實際檔案。無法復原！

在檔案系統中顯示檔案

有時您需要直接處理錄音檔案——例如：

  • 複製到其他位置
  • 上傳到雲端儲存
  • 透過電子郵件分享
  • 在其他程式中編輯

如何找到檔案：

方法一：「Show in Folder」

  1. 右鍵點擊錄音
  2. 選擇「Show in Folder」或「Reveal in Finder」
  3. 檔案總管開啟並顯示該檔案

方法二：展開檢視

  1. 展開錄音卡片
  2. 尋找「Show File」或資料夾圖示
  3. 點擊以開啟檔案位置

操作結果：

  • 檔案總管/Finder 開啟
  • 錄音檔案被醒目標示
  • 您可以複製、移動或開啟檔案
  • 檔案系統中的變更會反映在 SeaMeet 中（如果您在外部重新命名）

排序您的錄音

預設情況下，錄音按日期排序（最新的在前）。但您可以更改排序方式。

可用的排序選項：

依日期（預設）：

  • 最新的錄音在最上方
  • 最早的在最下方
  • 最適合：尋找近期的錄音

依名稱：

  • 字母順序排列（A 到 Z 或 Z 到 A）
  • 最適合：尋找特定名稱的錄音

依時長：

  • 最短到最長或反之
  • 最適合：尋找快速筆記或長會議

依大小：

  • 最小到最大的檔案
  • 最適合：管理儲存空間

依來源：

  • 按應用程式分組（所有 Zoom 在一起、所有 Teams 在一起）
  • 最適合：從特定平台尋找錄音

如何更改排序方式：

  1. 在側邊欄標題中尋找「Sort」下拉式選單
  2. 點擊並選擇您偏好的排序方式
  3. 再次點擊以切換升序/降序

篩選與搜尋

當您有很多錄音時，使用篩選和搜尋來找到您需要的內容。

搜尋框：

位於側邊欄頂部的搜尋框讓您可以依據以下條件尋找錄音：

  • 名稱
  • 來源
  • 日期（如果您輸入日期）

如何搜尋：

  1. 點擊搜尋框
  2. 輸入您要尋找的內容
  3. 結果會在您輸入時即時篩選
  4. 點擊結果以選取

搜尋範例：

  • 搜尋「Zoom」→ 顯示所有 Zoom 錄音
  • 搜尋「budget」→ 顯示名稱中包含「budget」的錄音
  • 搜尋「January」→ 顯示一月的錄音
  • 搜尋「45」→ 顯示大約 45 分鐘長的錄音

篩選器：

篩選器讓您只顯示特定類型的錄音。

常見篩選器：

依類型：

  • 只顯示音訊錄音
  • 只顯示影片錄音
  • 只顯示 Flashback 錄音

依來源：

  • 只顯示 Zoom 錄音
  • 只顯示 Teams 錄音
  • 只顯示麥克風錄音

依日期：

  • 今天
  • 昨天
  • 本週
  • 本月
  • 自訂日期範圍

依時長：

  • 短（5 分鐘以下）
  • 中等（5-30 分鐘）
  • 長（30 分鐘以上）

如何套用篩選器：

  1. 尋找「Filter」按鈕或下拉式選單
  2. 選擇您的篩選條件
  3. 清單更新為只顯示符合條件的錄音
  4. 清除篩選器以查看所有錄音

組合篩選器： 您通常可以組合多個篩選器：

  • 「顯示本週的 Zoom 錄音」
  • 「顯示 10 分鐘以下的音訊錄音」

了解檔案位置與儲存

雖然 SeaMeet 在其錄音庫中顯示您的錄音，但實際檔案儲存在您電腦的檔案系統中。

預設儲存位置

Windows：

C:\Users\[YourUsername]\Documents\SeaMeet Recordings\

Mac：

/Users/[YourUsername]/Documents/SeaMeet Recordings/

資料夾結構： SeaMeet 可能會按日期將檔案整理到子資料夾中：

SeaMeet Recordings/
├── 2026-01-15/
│   ├── Meeting_1.webm
│   └── Call_2.webm
├── 2026-01-16/
│   └── Recording_3.webm
└── 2026-01-17/
    ├── Teams_Meeting.webm
    └── Voice_Note.webm

或者所有檔案可能平放儲存：

SeaMeet Recordings/
├── Meeting_1_20260115.webm
├── Call_2_20260115.webm
├── Recording_3_20260116.webm
├── Teams_Meeting_20260117.webm
└── Voice_Note_20260117.webm

（取決於您的設定）

在檔案系統中找到特定錄音

方法一：透過 SeaMeet

  1. 在 SeaMeet 中找到該錄音
  2. 右鍵點擊 →「Show in Folder」
  3. 檔案總管開啟到確切位置

方法二：手動瀏覽

  1. 開啟「文件」資料夾
  2. 導航到「SeaMeet Recordings」
  3. 瀏覽資料夾或搜尋

方法三：系統搜尋

  • Windows：使用檔案總管搜尋
  • Mac：使用 Spotlight（Cmd+Space）
  • 依檔案名稱或日期搜尋

更改儲存位置

您可以更改 SeaMeet 儲存錄音的位置。

如何更改：

  1. 前往設定 ⚙️
  2. 導航到「Storage」或「General」
  3. 找到「Save Location」或「Storage Directory」
  4. 點擊「Browse」或「Change」
  5. 選擇新資料夾
  6. 套用變更

既有錄音會怎樣：

  • 它們留在原來的位置
  • 新錄音會存到新位置
  • SeaMeet 仍會顯示所有錄音（來自兩個位置）
  • 如有需要，您可以手動移動舊錄音

更改位置的好理由：

  • 目前磁碟空間不足
  • 想使用外接磁碟
  • 偏好不同的整理方式
  • 使用雲端同步資料夾（Dropbox、OneDrive 等）

儲存空間管理

影片和音訊檔案會佔用空間。以下是管理方式。

典型檔案大小：

錄音類型時長大約大小
純音訊30 分鐘~30-60 MB
純音訊1 小時~60-120 MB
影片（720p）30 分鐘~1 GB
影片（720p）1 小時~2 GB
影片（1080p）30 分鐘~1.8 GB
影片（1080p）1 小時~3.6 GB

儲存空間規劃：

如果您每週錄製 5 小時的會議：

  • 純音訊：每週約 300-600 MB
  • 影片（720p）：每週約 10 GB
  • 影片（1080p）：每週約 18 GB

每月估計（20 小時）：

  • 音訊：約 1.2-2.4 GB
  • 720p 影片：約 40 GB
  • 1080p 影片：約 72 GB

管理空間：

1. 定期清理：

  • 刪除不再需要的錄音
  • 只保留重要的
  • 每週或每月執行一次

2. 歸檔舊錄音：

  • 將舊錄音移至外接磁碟
  • 上傳到雲端儲存
  • 近期錄音保留在本機以便快速存取

3. 盡量使用純音訊：

  • 用於不需要影片的會議
  • 節省 90% 以上的儲存空間
  • 音訊通常已足夠

4. 降低品質設定：

  • 使用 720p 而非 1080p
  • 節省約 40% 空間
  • 品質通常仍然足夠

5. 外接儲存：

  • 使用外接 SSD 或硬碟
  • 將已完成的專案移至外接裝置
  • 將進行中的工作保留在主磁碟

錄音庫管理的最佳做法

每週檢視（5-10 分鐘）

每週花幾分鐘：

  1. 檢視新錄音

    • 查看本週錄製了什麼
    • 重新命名仍使用預設名稱的錄音
    • 刪除明顯無用的內容（測試錄音、意外觸發的錄音）

  2. 檢查儲存空間

    • 確保空間沒有不足
    • 如有需要就刪除

  3. 整理重要錄音

    • 重新命名關鍵會議
    • 記下需要後續追蹤的項目

每月歸檔（15-30 分鐘）

每個月：

  1. 辨識要保留的錄音

    • 重要會議
    • 參考資料
    • 您製作的內容

  2. 歸檔舊錄音

    • 將超過 1 個月的錄音移至外接儲存
    • 或上傳到雲端
    • 本機保留最近 2-4 週的內容

  3. 如有需要更新命名

    • 修正命名不佳的錄音
    • 如缺少日期則補上

  4. 備份重要檔案

    • 將關鍵錄音複製到多個位置
    • 不要只依賴一份副本

錄音的「清空收件匣」方法

就像電子郵件一樣，當您即時處理錄音時，錄音庫的效果最好：

工作流程：

  1. 錄音（自動或手動）
  2. 檢視（在 24-48 小時內）
  3. 重新命名（給予描述性名稱）
  4. 決定：
    • 保留（重要的，妥善命名）
    • 處理（擷取筆記後刪除）
    • 刪除（不需要的）
  5. 歸檔（每週或每月）

好處：

  • 隨時知道您有什麼
  • 能快速找到任何內容
  • 儲存空間保持可管理
  • 重要內容不會遺失

常見錄音庫問題

「我找不到我確定錄過的錄音」

可能的原因：

  1. 排序順序不對

    • 檢查是否按日期以外的方式排序
    • 切換到「By Date」檢視

  2. 篩選器已啟用

    • 檢查是否已套用篩選器
    • 清除所有篩選器

  3. 搜尋無法正常運作

    • 嘗試用不同的關鍵字搜尋
    • 檢查拼字

  4. 意外刪除

    • 檢查資源回收筒/垃圾桶
    • 直接在檔案系統中查看

  5. 儲存到了錯誤的位置

    • 檢查設定中的儲存位置
    • 可能在不同的資料夾中

解決方案：

  • 使用系統搜尋（Windows：檔案總管、Mac：Spotlight）
  • 依日期範圍搜尋
  • 如果您移動過檔案，檢查外接磁碟
  • 如果您使用自動同步，檢查雲端儲存

「我的錄音庫是空的，但我確實錄製了錄音」

可能的原因：

  1. 儲存位置不對

    • 設定被更改為不同的資料夾
    • 錄音在那裡，但錄音庫指向其他位置

  2. 檔案被外部移動/刪除

    • 您或某個程式移動了檔案
    • SeaMeet 找不到它們

  3. 需要重新整理

    • 錄音庫檢視需要重新整理
    • 關閉並重新開啟 SeaMeet

解決方案：

  • 檢查設定 → Storage 中的正確位置
  • 如果可用，使用「Refresh」或「Scan for Recordings」
  • 手動瀏覽到該資料夾進行檢查
  • 重新啟動 SeaMeet

「錄音佔用太多空間」

解決方案：

立即：

  • 刪除不需要的錄音
  • 依大小排序，刪除最大的不必要錄音
  • 清空資源回收筒

長期：

  • 會議改用純音訊
  • 降低影片品質設定
  • 使用外接儲存
  • 實施定期清理計畫

計算您的使用量：

  • 檢查 SeaMeet Recordings 資料夾的總大小
  • 估算每週/每月的累積量
  • 據此規劃儲存空間

「我在檔案總管中重新命名了檔案，現在 SeaMeet 找不到它了」

問題： SeaMeet 維護了一個錄音資料庫。如果您在 SeaMeet 外部重新命名，它可能會失去追蹤。

解決方案：

方法一：重新整理錄音庫

  1. 在 SeaMeet 中尋找「Refresh」或「Rescan」
  2. 這會更新錄音庫以符合檔案系統

方法二：重新匯入

  1. 使用 SeaMeet 的匯入功能
  2. 匯入重新命名的檔案
  3. 如果存在損壞的項目，將其刪除

方法三：改回原名

  1. 在檔案總管中將檔案改回原名
  2. 然後在 SeaMeet 中正確重新命名

最佳做法： 務必在 SeaMeet 內部重新命名錄音，而非在檔案總管中。這樣可以讓錄音庫資料庫保持同步。

進階整理：使用資料夾和分類

雖然 SeaMeet 預設按日期整理，您可以建立自己的組織結構。

方法一：外部資料夾整理

在您的檔案系統中建立資料夾：

SeaMeet Recordings/
├── Work/
│   ├── Client Calls/
│   ├── Team Meetings/
│   └── Conferences/
├── Personal/
│   ├── Ideas/
│   └── Notes/
└── Archive/
    ├── 2025/
    └── 2024/

流程：

  1. 在檔案總管/Finder 中建立資料夾
  2. 錄音完成後，將檔案移至適當的資料夾
  3. SeaMeet 通常仍能找到它們
  4. 或使用 SeaMeet 的「Import」功能將整理好的檔案匯入

方法二：命名慣例「資料夾」

使用命名來建立虛擬分類：

WORK - Client - Acme Corp - Jan 15
WORK - Meeting - Team Standup - Jan 16
WORK - Call - Vendor Discussion - Jan 17
PERSONAL - Idea - App Feature - Jan 15
PERSONAL - Notes - Book Research - Jan 16

好處：

  • 搜尋「WORK」即可找到所有工作錄音
  • 搜尋「PERSONAL」即可找到個人錄音
  • 不需要移動檔案
  • 與 SeaMeet 的搜尋功能相容

方法三：基於日期的歸檔

每月流程：

  1. 在月底建立資料夾：2026-01
  2. 將所有一月的錄音移至該資料夾
  3. SeaMeet 仍可存取它們
  4. 讓主資料夾保持整潔

或者 SeaMeet 可能會根據您的設定自動執行此操作。
