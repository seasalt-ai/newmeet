術語表

第 30 章:術語表

介紹

錄音軟體就像任何技術領域,有自己的詞彙。像「codec」、「位元率」、「影格率」與「編碼」這樣的詞不斷被丟出來。本章是您的全面字典——以淺顯易懂的語言解釋您在使用 SeaMeet 或閱讀有關音訊/視訊錄音時可能遇到的每個技術術語。

如果您不是技術人員,不要擔心。每個術語都以淺顯的英文解釋,加上類比以幫助您理解。當您遇到不熟悉的詞時,請使用本章作為參考。

章節目標

讀完本章後,您將能夠:

  • 了解 SeaMeet 中使用的技術術語
  • 知道常見混淆術語之間的差異
  • 在排除問題時使用正確術語
  • 根據技術概念做出明智決策

A

Audio Buffer(音訊緩衝)

音訊資料在處理或儲存前的暫時儲存。像個等候室,讓音訊樣本在被編碼前排隊。

Audio Interface(音訊介面)

將麥克風與樂器連接到電腦的硬體。通常提供比內建音效卡更好的音訊品質。

Action Items (AI)(行動項目)

AI 摘要從錄音中辨識的任務。每個行動項目包含任務描述、被指派的人,以及到期日(若在對話中提及)。請見第 32 章。

AI Extraction(AI 摘要)

SeaMeet 的錄音後分析功能。錄音結束後,點擊 ✨ "Generate Summary" 將音訊送到 AI 引擎,後者傳回五個結構化輸出:Transcript、Summary、Action Items、Key Decisions 和 Chapters。請見第 32 章。

AI Insights(AI 洞見)

SeaMeet 中顯示所有錄音 AI 生成結果的面板。可從錄音詳細檢視存取。包含 Transcript、Summary、Actions、Decisions 與 Chapters 的分頁。

Audio Track(音訊軌)

視訊檔案中獨立的音訊串流。視訊可能有多個音軌:您的麥克風、系統音訊、背景音樂。

Auto-Detection(自動偵測)

SeaMeet 的功能,自動辨識您加入會議的時間,且可以開始錄音而無需手動介入。

Auto-pick(自動挑選)

根據錄音內容自動選擇最合適 AI 摘要範本的分類器。當您重新生成摘要時,自動挑選分析轉錄並挑最合適的範本(例如站立會議、銷售通話、訪談),讓您不必手動選擇。請見第 33 章。

AVI (Audio Video Interleave)

由 Microsoft 開發的較舊視訊檔案格式。在 Windows 上運作良好但與現代裝置相容性較差。

B

Bit(位元)

數位資訊的最小單位。0 或 1。您電腦上的一切都是由位元構成。

BYOK (Bring Your Own Key)

SeaMeet 的訂閱模式,使用者提供自己的 LLM API 金鑰(例如 OpenAI、Anthropic、Google)而非透過 SeaMeet 付推論費用。費用由提供者直接計費;SeaMeet 只收應用程式費用。

Bit Depth (Audio)(位元深度)

用多少位元表示每個音訊樣本。較高位元深度 = 更多細節 = 較大檔案。CD 品質為 16 位元。

Bitrate(位元率)

每秒處理的資料量。通常以千位元每秒 (kbps) 或百萬位元每秒 (Mbps) 測量。較高 = 較好品質 = 較大檔案。

Bluetooth Latency(藍牙延遲)

從產生聲音到您透過藍牙連線聽到的延遲。通常 100-300ms,造成同步問題。

Buffer(緩衝)

在資料傳輸或處理時保存資料的暫時儲存區。像個水庫,在水流過管子前保存水。

Buffer Duration (Flashback)(緩衝時長)

SeaMeet 在環形緩衝區中保留多少秒的畫面。當您儲存 Flashback 時,您獲得這個量的過去畫面。

Byte(位元組)

8 個位元的群組。檔案大小的標準單位。一個 megabyte (MB) 約一百萬位元組。

C

Circular Buffer(環形緩衝區)

到達結尾時回到開頭的緩衝區。SeaMeet 為 Flashback 使用這——不斷錄製並覆蓋舊資料。

Codec (Coder-Decoder)(編解碼器)

壓縮並解壓縮音訊或視訊的軟體。H.264 是視訊編解碼器。MP3 是音訊編解碼器。

Codec vs. Container

Codec 是壓縮方法(資料如何擠壓)。Container 是檔案格式(保存資料的盒子)。MP4 是常包含 H.264 視訊的容器。

Compression(壓縮)

透過移除多餘或較不重要的資料來減少檔案大小。可以是無損(無品質損失)或有損(一些品質損失但較小檔案)。

Chapters (AI)(章節)

AI 摘要五個輸出之一。時間索引主題區段,類似書中章節。點擊 AI Insights 面板中的章節會將播放器跳到錄音中該時刻。請見第 32 章。

Chunked Pipeline(分塊管線)

處理長視訊的 AI 摘要策略,以 10 分鐘切片處理以保持在 Gemini 上下文視窗內。每塊獨立轉錄與摘要,然後合併為單一連貫輸出。自動用於超過模型單次容量的錄音。

Conflict Resolution Modal(衝突解決對話框)

當 GitHub 同步偵測到同一筆記在兩個裝置上被不同地編輯時出現的對話框。讓您選擇保留哪個版本,或手動合併變更。請見第 38 章。

CPU (Central Processing Unit)(中央處理器)

您電腦的「大腦」。執行計算並執行程式。錄音軟體使用 CPU 編碼視訊。

Cursor Highlighting(游標高亮)

在錄音中將注意力吸引到您滑鼠游標的視覺效果。對教學有用,讓觀看者可以跟隨您的動作。

D

Decibel (dB)(分貝)

測量聲音音量的單位。在 SeaMeet 的音訊等級計中使用。-12 dB 是良好錄音等級。0 dB 是最大(失真)。

Default Device(預設裝置)

Windows/macOS 自動使用的音訊或視訊裝置。SeaMeet 可以使用預設或讓您挑選特定裝置。

Detection Method (Auto-Detection)(偵測方法)

SeaMeet 如何辨識您在會議中。方法包括視窗標題分析、程序監看與音訊偵測。

Digital Audio(數位音訊)

以數字表示的聲音。您的電腦將聲波轉換為可儲存與處理的數位樣本(數字)。

Disk Space(磁碟空間)

您硬碟或 SSD 上可用的儲存量。錄製視訊需要相當的磁碟空間。

DRM (Digital Rights Management)(數位版權管理)

防止複製受保護內容的技術。Netflix、DVD 與某些串流服務使用 DRM,防止螢幕錄製。

Decisions (AI)(決議)

AI 摘要五個輸出之一。從會議中做出的關鍵選擇與協議清單,從對話擷取。與行動項目不同——決議是被同意的,行動是因此必須做的。請見第 32 章。

Drop Frame(掉幀)

視訊錄製錯過畫格,造成卡頓。通常發生在電腦無法跟上編碼需求時。

E

Echo Cancellation(回音消除)

從錄音中移除回音的技術。當使用喇叭而非耳機時有用——防止您的麥克風拾取喇叭聲音。

Encode(編碼)

將原始視訊/音訊轉換為壓縮格式的過程。您錄製時 CPU 或 GPU 即時做這件事。

Encoder(編碼器)

執行編碼的軟體或硬體。SeaMeet 使用軟體編碼器 (CPU) 或硬體編碼器 (GPU)。

External Drive(外接磁碟)

透過 USB 連接的硬碟或 SSD。可以用於儲存錄音但可能比內接磁碟慢。

F

Flashback

SeaMeet 的時光機功能,持續在環形緩衝區錄製,讓您儲存過去時刻。

Flashback Buffer(Flashback 緩衝)

Flashback 使用的暫時記憶體儲存。保留最後 X 秒的視訊/音訊。

Floater (SeaMeet Floater)

出現在您螢幕上以快速錄音控制的浮動小工具。可以最小化到小圖示或展開為完整控制。

FPS (Frames Per Second)(每秒影格數)

每秒擷取多少靜止影像(影格)以建立視訊。30fps 是標準。60fps 更流暢。

Fullscreen Recording(全螢幕錄製)

擷取整個螢幕的錄音模式。對會議與您想擷取一切時有用。

Frame(影格)

視訊中的單一靜止影像。視訊本質上是快速播放(每秒 30-60)以建立動作的一系列影格。

Fuzzy Search(模糊搜尋)

側欄與媒體庫中的相關度排名搜尋,即使查詢拼錯或只與標題部分重疊也能找到比對。取代舊的精確子字串比對,所以「qrtly review」仍能找到「Quarterly Review」。請見第 10 章。

G

Gain(增益)

音訊訊號的放大等級。增加增益讓錄音中的音訊變大聲。與音量(影響播放)不同。

Game Mode(遊戲模式)

Windows 功能,優先處理遊戲應用程式。可以幫助錄音效能但有時與錄音軟體衝突。

GitHub Sync

SeaMeet 由私人 GitHub 儲存庫支援的跨裝置同步功能。筆記與中繼資料提交到您的儲存庫,使相同工作區在您安裝 SeaMeet 的每台機器上可用。請見第 38 章。

GPU (Graphics Processing Unit)(圖形處理器)

您電腦中的顯示卡。可以用於硬體加速視訊編碼(比 CPU 快很多)。

GPU Encoding(GPU 編碼)

使用顯示卡而非 CPU 編碼視訊。也稱硬體加速。較快且較有效率。

H

H.264 (AVC)

最常見的視訊編解碼器。在合理檔案大小提供良好品質。在幾乎所有裝置上運作。

H.265 (HEVC)

較新、較有效率的視訊編解碼器。在相同品質下產生比 H.264 小約 50% 的檔案。較不普遍支援。

Hardware Acceleration(硬體加速)

使用專門硬體(如 GPU)而非一般 CPU 執行任務。讓視訊編碼快很多。

Hardware Encoder(硬體編碼器)

GPU 上專屬編碼視訊的晶片。NVIDIA 稱自己的為 NVENC。Intel 稱自己的為 Quick Sync。

HD (High Definition)(高畫質)

1280×720 (720p) 或更高的視訊解析度。提供清晰、詳細的視訊。

Headphones vs. Speakers(耳機 vs. 喇叭)

錄音時使用耳機可防止回音(被麥克風拾取的喇叭聲音)。建議用於最佳音訊品質。

I

I-Frame (Intra-frame)

不依賴其他影格的完整視訊影格。作為參考點。較大檔案但對查找必要。

Import(匯入)

將外部音訊或視訊檔案帶入 SeaMeet。SeaMeet 可以匯入各種格式以播放與管理。

Input Device(輸入裝置)

將音訊/視訊送入您電腦的硬體。麥克風、相機與擷取卡是輸入裝置。

J

Jitter(抖動)

音訊/視訊資料時序的變化。造成不平順或不均的播放。通常因系統效能問題。

Join a Meeting(加入會議)

透過 Zoom、Teams、Meet 等進入線上會議。SeaMeet 可以自動偵測您加入時並開始錄音。

K

Kbps (Kilobits per second)(每秒千位元)

資料速率的測量。用於音訊位元率。128 kbps 是 MP3 標準。192 kbps 較高品質。

Keyframe(關鍵影格)

請見 I-Frame。作為參考點的完整視訊影格。

Keyboard Shortcuts(鍵盤快捷鍵)

快速觸發動作的按鍵組合。Ctrl+Alt+R 開始錄音。快捷鍵節省時間 vs. 點擊介面。

L

Latency(延遲)

動作與被處理或聽到之間的延遲。藍牙耳機有高延遲。有線耳機幾乎沒有。

Live Transcription(即時轉錄)

SeaMeet 的功能,錄音期間即時將語音轉為文字。字詞在被說出時出現在 Transcript 面板中,加上時間戳記並由講者標記。需要 AI 功能啟用與網路連線。請見第 31 章。

Library (Recording Library)(錄音庫)

您在 SeaMeet 中所有錄音的集合。顯示縮圖、中繼資料,並允許播放/管理。

Lite Mode

較小、以系統匣為中心的 SeaMeet 介面。將主視窗剝離至基本——開始/停止錄音、近期項目、快速設定——並設計為居住在系統匣中,螢幕佔用最小。

Lossless Compression(無損壓縮)

在不丟失任何資料的情況下減少檔案大小的壓縮。可以完美重建。FLAC 音訊使用無損壓縮。

Lossy Compression(有損壓縮)

永久移除一些資料以達成較小檔案的壓縮。MP3 與 H.264 是有損的。品質損失通常不易察覺。

Low-Memory Mode(低記憶體模式)

SeaMeet 功能,降低品質以使用較少 RAM。對較舊電腦或執行記憶體密集應用程式時有用。

M

Macroblock(巨集區塊)

視訊壓縮中使用的 16×16 像素方形。H.264 將影格分為巨集區塊以有效壓縮。

Mbps (Megabits per second)(每秒百萬位元)

用於視訊的資料速率測量。8 Mbps 對 1080p 視訊良好。較高 = 較好品質 = 較大檔案。

MCP Server

SeaMeet 暴露的 Model Context Protocol 伺服器,讓 AI 助手可以列出範本、重新生成摘要、抓取轉錄,並從連接的 LLM 客戶端驅動 SeaMeet。從 dist-main/mcp-server.cjs 作為子程序執行。

Media Library(媒體庫)

用於錄音與截圖的專屬全視窗瀏覽器。支援格狀與清單檢視、篩選(日期、時長、標籤)與批次操作(刪除、匯出、標記)。與側欄的錄音庫不同。請見第 10 章。

Metadata(中繼資料)

關於檔案的資訊(不是實際內容)。包括建立日期、時長、解析度等。

Microphone Array(麥克風陣列)

一起運作的多個麥克風。某些筆電有麥克風陣列以獲得較好的聲音拾取與噪音消除。

Minimize to Tray(最小化到系統匣)

SeaMeet 可以在背景執行,透過系統匣圖示(時鐘旁)存取。節省工作列空間。

MKV (Matroska)

彈性的視訊容器格式。支援多個音訊軌與字幕。對封存好。

Monitor(顯示器)

您的電腦螢幕。SeaMeet 可以錄一個顯示器或所有顯示器(若您有多個顯示器)。

Mono vs. Stereo(單聲道 vs. 立體聲)

單聲道 = 1 個音訊通道。立體聲 = 2 個通道(左與右)。立體聲聽起來更沉浸但建立較大檔案。

MOV

Apple 的視訊容器格式。在 Mac 上常見。好品質但沒有額外軟體在 Windows 上相容性較差。

MP3

最受歡迎的音訊格式。使用有損壓縮。小檔案、通用相容性。通常 128-320 kbps。

MP4

最受歡迎的視訊容器格式。在幾乎所有裝置上運作。通常包含 H.264 視訊與 AAC 音訊。

Multi-Monitor(多顯示器)

使用多於一個螢幕。SeaMeet 可以錄所有顯示器或只一個。錄製多顯示器使用較多資源。

Mute(靜音)

暫時關閉音訊輸入或輸出。SeaMeet 可以靜音錄音而不影響系統音量。

N

Native Resolution(原生解析度)

您螢幕顯示的實際像素數。以原生解析度錄製提供最清晰結果。

Noise Suppression(噪音抑制)

從音訊錄音中移除背景噪音(風扇、冷氣)的技術。讓聲音更清晰。

Notification(通知)

警示您事件的彈出訊息。SeaMeet 在錄音開始、停止或偵測到會議時顯示通知。

NVENC

NVIDIA 的硬體視訊編碼器。在 GTX 600 系列及更新上可用。使用最少 CPU 的非常快速編碼。

O

OAuth Auto-Refresh

GitHub 同步權杖重新整理機制,在權杖到期前 5 分鐘執行。讓同步工作階段保持運作而不強迫使用者重新驗證,將同步狀態機悄悄轉回 synced。請見第 38 章。

Ogg

開源音訊格式。良好壓縮但裝置支援有限。通常使用 Vorbis 編解碼器。

Output Device(輸出裝置)

從您電腦播放音訊的硬體。喇叭與耳機是輸出裝置。

Overhead (CPU/Memory)(額外負擔)

錄音軟體本身使用的資源,與實際錄音分開。SeaMeet 有低額外負擔。

P

P-Frame (Predicted Frame)

只儲存與前一影格變化的視訊影格。比 I-Frame 小很多。建立有效壓縮。

PCM (Pulse Code Modulation)

未壓縮數位音訊格式。在編碼為 MP3 或其他格式之前內部使用。高品質、大檔案。

Permissions(權限)

存取系統資源的授權。macOS 與 Windows 要求您授予 SeaMeet 錄製螢幕與音訊的權限。

Pixel(像素)

您螢幕上單一顏色點。影像由數千或數百萬像素組成。1920×1080 = 約 2 百萬像素。

Playback(播放)

觀看或聆聽錄音。SeaMeet 有內建播放器用於審閱錄音。

Pop Filter(防噴罩)

麥克風的泡棉或網狀蓋,減少「p」與「b」爆裂聲。改善音訊品質。

Process Monitoring(程序監看)

監看哪些程式執行的自動偵測方法。偵測 zoom.exe 或 Teams.exe 啟動時。

Q

Quantization(量化)

降低資料精度以節省空間。壓縮的一部分。簡化幾乎相同的顏色/聲音。

Quick Sync

Intel 的硬體視訊編碼器。內建於現代 Intel 處理器。有效率且品質好用於錄音。

R

RAM (Random Access Memory)(隨機存取記憶體)

您電腦的短期記憶。SeaMeet 為 Flashback 緩衝與處理使用 RAM。較多 RAM = 較好效能。

RAW Audio/Video(原始音訊/視訊)

未壓縮資料。大檔案但最大品質。SeaMeet 通常編碼為壓縮格式以節省空間。

Real-time(即時)

即時發生,沒有延遲。SeaMeet 在您錄製時即時編碼視訊。沒有後處理等候。

Recording Mode(錄音模式)

SeaMeet 如何擷取視訊:全螢幕(整個螢幕)、視窗(特定應用程式)或區域(選取區域)。

Region Recording(區域錄製)

只錄製您螢幕選取部分。最有效率的模式——只擷取您需要的。

Resolution(解析度)

影像中像素數。1920×1080 表示寬 1920 像素、高 1080 像素。較高 = 較清晰 = 較大檔案。

Ring Menu (Floater)(環形選單)

您展開 Floater 小工具時出現的圓形控制介面。提供錄音控制的快速存取。

S

Sample Rate (Audio)(取樣率)

音訊每秒測量多少次。CD 品質為 44.1 kHz(每秒 44,100 樣本)。較高 = 較好品質。

Sampling(取樣)

透過以規則間隔測量將連續聲波轉換為數位數字。

Save Location(儲存位置)

SeaMeet 儲存錄音的資料夾。可以在設定中變更。應有大量可用空間。

Screen Recording(螢幕錄製)

擷取您電腦螢幕的視訊。SeaMeet 專精於含音訊的螢幕錄製。

Screenshot(截圖)

您螢幕的靜止影像擷取。SeaMeet 可以透過鍵盤快捷鍵或 Floater 拍截圖。

Sensitivity (Auto-Detection)(靈敏度)

SeaMeet 多激進地尋找會議。高靈敏度抓住較多會議但可能有錯誤的正向。

Shortcut(快捷鍵)

請見鍵盤快捷鍵。不使用滑鼠控制 SeaMeet 的快速方式。

Sidebar(側欄)

SeaMeet 中左側面板,顯示不同區段:Recordings、Video、Flashback 等。

Slash Menu(斜線選單)

筆記編輯器中的區塊插入選單,在新行輸入 / 喚起。讓您插入標題、清單、提示、程式碼區塊、內嵌與其他區塊類型而不離開鍵盤。請見第 16-17 章。

Source (Audio/Video)(來源)

訊號的源頭。音訊來源包括麥克風與系統音訊。視訊來源包括螢幕與視窗。

Speaker Detection(講者偵測)

在即時轉錄或 AI 摘要中辨識哪個人在說話的自動過程。每個獨特聲音被指派標籤(「Speaker 1」、「Speaker 2」)。準確度隨清晰音訊與最小交叉談話而改善。請見第 31 章。

Speaker Label(講者標籤)

在轉錄中指派給講者的名稱。預設為「Speaker 1」、「Speaker 2」等。可以重新命名(例如「Alice」)或與另一標籤合併(若兩個標籤屬於同一人)。請見第 34 章。

SplitButtonMenu(分割按鈕選單)

AI 摘要分頁上的 UI 控制,結合主要動作與相關動作的下拉——例如,預設執行「Regenerate with Auto-pick」但從下拉雪佛龍提供「Manual template」選擇的單一按鈕。請見第 33-34 章。

SRT (SubRip Subtitle)

用於字幕的文字檔案格式。包含有時間戳記的文字行。SeaMeet 可以匯出轉錄為 SRT 檔案,可以匯入到視訊編輯器(Premiere、iMovie)或上傳到 YouTube 作為字幕。

SSD (Solid State Drive)(固態硬碟)

沒有移動部件的快速儲存裝置。比傳統硬碟 (HDD) 更適合錄製。較快的寫入速度。

Stereo Mix

Windows 音訊功能,讓您錄製系統音訊。SeaMeet 可以使用 Stereo Mix 或 WASAPI 做系統音訊擷取。

Storage(儲存)

您硬碟或 SSD 上錄音儲存的空間。視訊錄音需要大量儲存空間。

Stream(串流)

持續的資料流。音訊與視訊串流在錄音時被擷取與編碼。

Sync (Audio-Video)(同步)

當音訊與視訊正確對齊時。不同步表示您看到嘴唇移動前/後才聽到話。

Sync State Machine(同步狀態機)

GitHub 同步的生命週期:idle → pending → syncing → synced,並有 error、offline、token-expired、installing-app 與 creating-repo 的分支。狀態在同步狀態指示器中浮現,讓您隨時確切知道同步在哪。請見第 38 章。

System Audio(系統音訊)

來自您電腦的聲音——通知、視訊、會議聲音。SeaMeet 可以將系統音訊與麥克風分開錄製。

System Tray(系統匣)

您時鐘旁顯示背景應用程式圖示的區域。SeaMeet 可以最小化到系統匣。

T

Template (AI Summary Template)(範本)

為特定會議類型塑造 AI 摘要輸出的結構化提示——例如,站立會議範本強調阻礙與明天的計畫,而銷售通話範本強調反對與下一步。範本可手動挑選或透過自動挑選。請見第 33 章。

Theme (Light/Dark)(主題)

SeaMeet 的視覺外觀。淺色主題有白色背景。深色主題有深色背景。在晚上對眼睛較舒適。

Thumbnail(縮圖)

代表視訊的小預覽影像。SeaMeet 在錄音庫中顯示錄音縮圖。

Time Machine (Flashback)(時光機)

Flashback 功能的比喻。讓您「回到過去」擷取已發生的時刻。

Timeline(時間軸)

錄音時長的視覺呈現。SeaMeet 的播放器顯示帶播放位置的時間軸。

Toggle(切換)

開啟或關閉功能的開關。SeaMeet 在設定中使用切換——點擊以在狀態間切換。

Transcript(轉錄)

口說音訊的文字紀錄。SeaMeet 產生兩種:即時轉錄(錄音期間即時擷取的字詞)與摘要轉錄(錄音後從音訊檔案產生)。兩者出現在 AI Insights 面板的 Transcript 分頁下。請見第 27 與 28 章。

Track (Audio)(音軌)

檔案中獨立的音訊串流。SeaMeet 可以錄製多個軌道:麥克風、系統音訊等。

Tray(系統匣)

系統匣圖示選單——Windows 通知區、macOS 選單列、Linux 指示器——當 SeaMeet 最小化時居住的地方。即使沒有主視窗可見,也提供開始/停止錄音、開啟 Lite Mode 與結束。

Trim(修剪)

移除錄音不要的開頭或結尾部分。SeaMeet 允許修剪儲存的錄音。

Troubleshooting(疑難排解)

診斷並修復問題的過程。第 25 章涵蓋排除常見 SeaMeet 問題。

U

USB Microphone(USB 麥克風)

透過 USB 連接的麥克風。容易使用,品質通常比內建筆電麥克風好。

V

VBR (Variable Bit Rate)(可變位元率)

根據內容複雜度調整品質的編碼方法。簡單場景使用較低位元率。複雜場景使用較高。

Video Buffer(視訊緩衝)

Flashback 錄音期間視訊影格的暫時儲存。保留最近畫面的滾動視窗。

Version Badge(版本徽章)

在執行至少一次重新生成後出現在 AI Insights 分頁列中的小標籤(例如「v3 ▾」)。點擊它開啟版本挑選器。請見第 34 章。

Version History(版本歷史)

錄音所有先前 AI 摘要執行的紀錄。每次您重新生成 (⟳),SeaMeet 在覆蓋前將先前結果儲存為編號快照。您隨時可以檢視任何過去版本。請見第 34 章。

Video Track(視訊軌)

視訊檔案的視覺成分。與音訊軌分開。視訊檔案包含至少一個視訊軌。

Volume(音量)

音訊的響度。與增益不同——音量影響您聽到的。增益影響被錄的。

VP8/VP9

在 WebM 檔案中使用的開源視訊編解碼器。良好品質,免費使用。VP9 比 VP8 更新更有效率。

W

WASAPI (Windows Audio Session API)

擷取系統音訊的現代 Windows 方法。在某些系統上比 Stereo Mix 更可靠。

WAV (Waveform Audio File Format)

未壓縮音訊格式。大檔案但完美品質。對封存或編輯好。

WebM

由 Google 開發的開源視訊格式。對網頁使用好。使用 VP8 或 VP9 編解碼器。

Wikilink

筆記中的 [[title]] 語法,建立可導覽到另一筆記的連結。輸入 [[ 開啟現有筆記的挑選器;選擇一個插入連結,點擊渲染筆記中的連結會跳到該頁。請見第 16-17 章。

Window Recording(視窗錄製)

只擷取特定應用程式視窗的錄音模式。比全螢幕更有效率。

Window Title Detection(視窗標題偵測)

讀取應用程式視窗標題的自動偵測方法。尋找像「Zoom Meeting」或「Teams」這樣的關鍵字。

Workspace(工作區)

您可以切換的獨立筆記樹與錄音集——例如「Work」工作區與「Personal」工作區,每個有自己的 GitHub 同步儲存庫。切換工作區一次交換側欄、錄音庫與同步目標。請見第 38 章。

X

XLR

用於高階麥克風的專業音訊接頭。需要音訊介面才能連接到電腦。

Y

YouTube

受歡迎的影片分享平台。SeaMeet 錄音可上傳到 YouTube。YouTube 建議最佳結果的特定設定。

Z

Zero Latency(零延遲)

動作與錄音之間沒有延遲。實務上不可能,但有線連接與良好硬體將延遲降至最低。

Zoom (App)

受歡迎的視訊會議平台。SeaMeet 可以自動偵測與錄製的 47+ 應用程式之一。

Zoom (Digital)(縮放)

放大或擴大檢視。SeaMeet 的播放器允許放大視訊以檢視細節。

容易混淆的術語解說

Codec vs. Container

  • Codec: 資料如何壓縮(H.264、MP3)
  • Container: 資料在哪儲存(MP4、WebM、AVI)

類比:Codec 是書用什麼語言寫的。Container 是書本身。

Bitrate vs. Resolution

  • Bitrate: 每秒多少資料(影響品質與檔案大小)
  • Resolution: 多少像素(影響清晰度)

您可以有高解析度與低位元率(塊狀)或低解析度與高位元率(平順但小)。

Gain vs. Volume

  • Gain: 輸入等級(錄音多大聲)
  • Volume: 輸出等級(播放多大聲)

變更音量不影響錄音。變更增益影響錄音。

Latency vs. Delay

  • Latency: 數位系統中延遲的技術術語
  • Delay: 任何等候時間的一般術語

它們基本上相同,但「latency」用於技術上下文。

Frame Rate vs. Resolution

  • Frame Rate: 每秒多少圖片(流暢度)
  • Resolution: 每張圖片多詳細(清晰度)

60fps 720p 比 30fps 1080p 更流暢,但 1080p 更清晰。
