主介面 - 完整導覽 SeaMeet 的 UI

第 13 章:主介面 - 完整導覽 SeaMeet 的 UI

到目前為止,您已用 SeaMeet 錄製音訊與視訊、整理過錄音庫,並播放過錄音。您已經操作過介面的各個部分,但可能還沒有完整的全景視角來理解所有元件如何拼湊在一起。本章將提供 SeaMeet 主介面的全面導覽——每個按鈕、面板、指示器與控制——讓您能自信地在應用程式中操作,並找到尚未發現的功能。

把本章想成一場新家的導覽。我們會走過每個房間、檢視特色,並說明每樣東西的功能。讀完之後,您將確切知道每個功能在哪裡,以及介面如何適應不同情境。

視窗版面:大局

當您開啟 SeaMeet 時,會看到一個版面一致的單一視窗。無論您正在錄音、播放,或只是瀏覽錄音庫,版面都保持穩定。了解這個版面是有效運用 SeaMeet 的基礎。

三個主要區域

區域 1:頂部導覽列

  • 始終可見
  • 包含全域控制
  • 快速存取重要功能

區域 2:側欄(錄音清單)

  • 始終可見(在大多數檢視中)
  • 顯示您的錄音
  • 可捲動的錄音卡片清單

區域 3:主內容區

  • 依情境變化
  • 播放錄音時顯示播放器
  • 準備錄音時顯示錄音控制
  • 設定選項時顯示設定

區域 1:頂部導覽列

頂部導覽列提供導覽與帳戶控制。它保持精簡且專注——錄音控制與 Flashback 已移至主內容區的 Capture Hub(請見下方狀態 1)。

導覽切換 (☰)

功能: 折疊或展開左側欄(錄音清單)。

何時使用:

  • 折疊以給 Capture Hub 更多水平空間
  • 展開以在非錄音時瀏覽您的錄音庫

帳戶 / 使用者選單 (👤)

功能: 開啟使用者帳戶選單,您可以在此:

  • 登入或登出
  • 開啟設定(音訊、視訊、Flashback、儲存、語言、快捷鍵)
  • 開啟鍵盤快捷鍵參考
  • 存取「Help & Support」

如何使用:

  1. 點擊您的個人頭像或使用者圖示
  2. 從下拉中選擇所需選項

錄音按鈕 (🔴)

圖示: 準備就緒時為紅色圓圈 (🔴),錄音中為正方形 (⏹️) 標籤: "RECORD" 或僅圖示 顏色: 鮮紅(代表錄音動作)

功能: 開始或停止錄音

狀態:

準備錄音:

[🔴 RECORD]
紅色圓圈圖示
點擊以開始錄音

錄音中:

[⏹️ STOP]
正方形圖示
顯示經過時間的計時器
點擊以停止錄音

如何使用:

要開始錄音:

  1. 先配置您的錄音設定
  2. 點擊紅色的「Record」按鈕
  3. 錄音立即開始
  4. 按鈕變為「Stop」
  5. 計時器開始計算

要停止錄音:

  1. 點擊「Stop」按鈕(正方形)
  2. 錄音停止
  3. 檔案儲存
  4. 錄音出現在側欄
  5. 按鈕回到「Record」狀態

點擊 Record 時會發生什麼:

  1. 音訊/視訊擷取開始
  2. 計時器出現,顯示經過時間
  3. 按鈕從 🔴 變為 ⏹️
  4. 視覺指示顯示錄音狀態
  5. 檔案正在寫入儲存

點擊 Stop 時會發生什麼:

  1. 錄音停止
  2. 檔案完成並儲存
  3. 錄音出現在側欄清單
  4. 按鈕回到 🔴 狀態
  5. 計時器消失或重設

重要備註:

  • 錄音會立即開始——請做好準備!
  • 沒有倒數或警告
  • 點擊前確認您的設定正確
  • Flashback(如果已啟用)會包含緩衝的過去

系統匣

SeaMeet 在首次啟動時會安裝系統匣圖示(Windows 通知區、macOS 選單列),並在整個應用程式作業階段保持運作。系統匣是隨時可用的控制介面——即使您關閉了主視窗,SeaMeet 仍在執行、隨時可擷取,並可從圖示一鍵點擊到達。

為什麼系統匣保持運作

關閉主視窗並不會結束 SeaMeet。視窗會隱藏,而系統匣圖示留在原處。這是刻意設計:

  • 自動偵測仍能在會議應用程式啟動時喚醒應用程式
  • Flashback 可繼續維持其滾動緩衝(若已啟用)
  • 全域快捷鍵(開始錄音、顯示啟動器、顯示 Floater)仍能運作
  • 快速錄音只需一次系統匣點擊

第一次關閉視窗時,SeaMeet 會送出一次性「已最小化到系統匣」提示,讓您理解應用程式並未真正結束。要完全結束,從系統匣選單使用 Exit SeaMeet(請見下方),或您作業系統的應用程式結束指令。

系統匣圖示

預設圖示(閒置):

  • Windows:通知區內的小型 SeaMeet 標誌 .ico
  • macOS:選單列中的 22×22 範本圖像,會適應淺/深色模式

錄音中圖示(進行中):

  • 切換到紅色變體,讓您一眼看出 SeaMeet 正在擷取
  • 在 macOS 上,選單列也會獲得 ● 後綴;若暫停則顯示 ⏸
  • 工具提示從「SeaMeet」變為「SeaMeet — Recording in progress」(或「Paused」)

點擊行為:

  • 左鍵點擊圖示 — 切換主視窗(隱藏時顯示、可見時隱藏)
  • 右鍵點擊圖示(Windows)/ 單擊(macOS)— 開啟上下文選單

系統匣選單(閒置狀態)

當您未在錄音時,選單大致長這樣:

│ Workspace: Acme Sales      (已停用)     │   ← 僅 Lite / 雲端組建
├─────────────────────────────────────────┤

每個項目的功能:

  • Workspace: <name> — 標題,顯示由系統匣啟動的錄音會落在哪個雲端工作區。僅在您已登入並挑選工作區的 Lite 或雲端啟用組建中出現。在非雲端組建中,該列完全隱藏,以保持選單形狀不變。
  • Record audio — 立即開始僅音訊的錄音。不請求視訊來源。
  • Record fullscreen — 開始主顯示器加音訊的錄製。
  • Record region — 開啟全螢幕區域重疊,讓您拖曳選取一個區域,然後開始該區域的錄製。
  • Take screenshot — 開啟區域選擇器以拍一張一次性截圖。若您已在 Settings → Keyboard 中綁定快捷鍵則會顯示。
  • Open recordings folder — 在您目前的儲存目錄開啟 OS 檔案瀏覽器。
  • Show launcher — 切換 SeaMeet 啟動器面板(請見第 14 章)。若已綁定,會顯示快捷鍵。
  • Show floating window — 顯示/隱藏 Floater 小工具。若已綁定,會顯示快捷鍵。
  • Show main window — 把主視窗帶到前面(與圖示隱藏時左鍵點擊圖示相同)。
  • Exit SeaMeet — 唯一會真正結束的選單項目。它設定內部「結束中」標誌,並要求 Electron 終止;其他項目只是顯示/隱藏介面。

系統匣選單(錄音中)

當錄音正在進行時,選單重新形塑,提供您直接的傳輸控制:

┌─────────────────────────────────────────┐
│ ● 錄音進行中             (已停用)        │
├─────────────────────────────────────────┤
│ ⏹  停止錄音              (Ctrl+Shift+R)  │
│ ⏸  暫停錄音                              │
│ ⚑  標記事件                              │
├─────────────────────────────────────────┤
│ 🗔 顯示主視窗                            │
├─────────────────────────────────────────┤
│ ⏻  結束 SeaMeet                          │
└─────────────────────────────────────────┘

錄音選單的注意事項:

  • 標題行僅作為狀態標籤(刻意停用)。
  • Stop recording 結束擷取並儲存檔案,與在主視窗點擊「Stop」按鈕相同。
  • Pause/Resume 僅在編解碼器/來源支援時顯示。僅視訊錄影會隱藏「Pause」項目。
  • Mark event 在錄音中放下一個時間戳記標記,在播放時方便跳回關鍵時刻。
  • 暫停時,選單會把 Pause 換成 Resume recording,macOS 標題會翻成 ⏸。

在地化標籤

系統匣選單支援 15 種區域(English、Spanish、French、German、Japanese、Korean、Hindi、Polish、Portuguese、Russian、Thai、Vietnamese、Danish、Simplified Chinese、Traditional Chinese)。超出該集合的語言會回退到 English,讓選單始終正確呈現。

搜尋框

位置: 側欄頂部 外觀: 帶放大鏡圖示 (🔍) 的文字欄位 佔位文字: 「搜尋錄音...」或類似

功能: 在您輸入時即時篩選錄音清單

如何使用:

  1. 在搜尋框中點擊
  2. 開始輸入
  3. 清單自動篩選
  4. 只顯示符合您搜尋的錄音
  5. 清除搜尋以再次看到所有錄音

您可以搜尋什麼:

  • 錄音名稱
  • 來源標籤(「Zoom」、「Teams」)
  • 日期(若以可搜尋格式輸入)
  • 部分比對可用

搜尋範例:

  • 搜尋「Zoom」→ 顯示所有 Zoom 錄音
  • 搜尋「budget」→ 顯示名稱含「budget」的錄音
  • 搜尋「March」→ 顯示三月的錄音
  • 搜尋「client」→ 顯示客戶相關的錄音

清除搜尋:

  • 點擊 X 按鈕(若存在)
  • 刪除所有文字
  • 按 Escape 鍵

錄音卡片

您錄音庫中的每一筆錄音都會顯示為錄音卡片——錄音重要資訊的精簡摘要。

兩種檢視模式:

  1. 精簡檢視(預設)- 極少資訊、有效率瀏覽
  2. 展開檢視 - 詳細資訊、波形預覽

精簡檢視

元素:

  • 圖示 (🎤) - 指示類型(音訊/視訊)

排序與篩選控制

位置: 通常在側欄頂部,接近搜尋

排序選項:

Lite 與 Full 模式

SeaMeet 提供兩種介面模式。它們共用相同的錄音引擎、相同的磁碟檔案,以及相同的系統匣圖示——但暴露出非常不同的 UI 量。

挑選模式

在乾淨的首次啟動時,SeaMeet 會顯示模式挑選器詢問您要哪種體驗。現有的 v2.x 使用者升級時會默默遷移到 Full 模式(讓視覺上無變化),但每個人都可以稍後從 Settings 切換。

選擇的模式以 appMode: 'full' | 'lite' 持久化於您的 UI 設定中。如果在錄音進行時切換模式,會等到錄音排空後再切換,所以您永遠不會丟失擷取;Settings 對話框會立即關閉,使「Saving…」轉圈在等候期間可見。

Full 模式(預設)

這是您一直在讀的章節——側欄 + Capture Hub + 主內容區,所有狀態(錄音、播放、設定)都在上方章節涵蓋。Full 模式包含:

  • 含 Flashback 與截圖控制的 Capture Hub
  • 含錄音卡片、搜尋、排序與篩選的完整側欄
  • 筆記與 Wiki(請見第 16–17 章)
  • 媒體庫(第 10 章)
  • 所有設定類別(第 18 章以後)
  • 本機優先工作區(請見下方「工作區」)

當 SeaMeet 是您的主要錄音介面,且您想在單一視窗中擁有筆記、wiki、agent 與錄音庫管理時,使用 Full 模式。

Lite 模式

Lite 模式是更小的介面,以系統匣與單一雲端會議清單為中心。沒有側欄、沒有筆記檢視、沒有 wiki、沒有 Capture Hub——錄音從系統匣開始(或自動偵測、或快捷鍵),完成的錄音在會議後摘要管線上傳至您的 SeaMeet 工作區後,作為會議卡片呈現。

與 Full 模式的差異:

介面FullLite
含錄音卡片的側欄有無 — 替換為雲端會議清單
Capture Hub(雙面板)有無 — 錄音從系統匣 / 快捷鍵開始
筆記與 Wiki 檢視有無
媒體庫有無
頂部的工作區標題僅在專用檢視始終可見

自動偵測 toast有有
權限引導有有
設定面板完整類別清單範圍縮小的「Lite Settings」對話框

Lite 中的工作區標題:

Lite 視窗的最頂部是工作區切換器(顯示啟用工作區名稱、頭像與下拉箭頭的按鈕)。點擊它會開啟您在 SeaMeet 雲端上可存取的每個工作區的下拉。挑選不同工作區會:

  1. 在本機持久化新工作區 ID
  2. 重新整理會議清單
  3. 將新工作區名稱推送至系統匣選單,讓由系統匣啟動的錄音也落在正確的地方
  4. 將分頁重設為第 1 頁

登出會清除系統匣的工作區標題(traySetWorkspaceDisplay(null, null)),這樣選單就永遠不會謊稱您不再有權存取的工作區。

Lite 中的錄音:

  • 點擊系統匣圖示並選擇 Record audio / fullscreen / region — 或使用全域快捷鍵
  • Lite 錄音檢視接管主視窗,提供即時波形、計時器與單一停止控制
  • 當您停止時,檔案會儲存到本機並上傳到您的 SeaMeet 工作區進行轉錄與摘要
  • 一旦雲端管線完成,會議卡片會出現在清單中

當 SeaMeet 是背景錄音機並提供 SeaMeet 雲端時,使用 Lite 模式——您希望系統匣完成工作,並有一個整潔的會議清單可審查。

在模式之間切換

開啟 Settings(任一模式),找到「Switch to Full / Lite mode」動作並確認。SeaMeet 會將任何進行中的錄音排空,然後重新啟動 renderer 進入另一模式。您的檔案、工作區、設定與系統匣圖示會在切換中保留。

工作區

SeaMeet 有兩種獨立的工作區概念,它們共用名稱但住在不同位置。瞭解誰是誰可避免混淆。

本機工作區(Full 模式)

在 Full 模式中,工作區是 Obsidian 風格的儲存區——磁碟上的資料夾,存放您的筆記、產生的 wiki,以及(預設)您的錄音。主程序中的 WorkspaceManager 擁有:

  • 工作區的註冊表({ id, name, path, isDefault? }[]),持久化於您的設定檔
  • 啟用工作區 ID(一次只有一個啟用)
  • 啟用工作區路徑上的 chokidar 檔案監視器,在外接磁碟區與網路掛載(例如 macOS /Volumes/、Google Drive 的 ~/Library/CloudStorage/GoogleDrive-<email>/…)上自動啟用輪詢,因為 FSEvents 無法可靠觸發
  • 每工作區狀態(上次開啟的筆記、最近檔案等)位於 userData/workspace-state/<id>.json

在首次啟動時,如果沒有註冊任何工作區,SeaMeet 會自動建立指向您儲存目錄的單一 Default 工作區。「Default」名稱已在所有 23 種語言中本地化。

工作區切換器(側欄標題):

筆記檢視(第 16 章)與 Wiki 檢視(第 17 章)都會在檔案樹頂部渲染 <WorkspaceSwitcher>:

┌──────────────────────────────────┐
│ [🅰] Acme Vault            ⌄    │   ← 啟用工作區
├──────────────────────────────────┤
│ 工作區                            │
│  ✓ Acme Vault     ~/Notes/Acme  │
│    Personal      ~/Notes/Personal│
│    Side Project  ~/Code/Side    │
├──────────────────────────────────┤
│ + 新增工作區…                     │
└──────────────────────────────────┘
  • 點擊啟用列以開啟下拉
  • 點擊任何其他工作區以切換到它——檔案監視器拆除、新工作區路徑掛載、筆記與 Wiki 重新整理,並還原每工作區狀態
  • **新增工作區…**開啟原生資料夾挑選器,讓您將任何目錄註冊為儲存區(會檢查唯一性——拒絕兩次註冊同一路徑)
  • 列上的 移除(×)只移除SeaMeet 項目;磁碟上的檔案不受影響。您不能移除最後一個工作區。
  • 每列可能顯示雲端徽章(Dropbox、iCloud、OneDrive、Google Drive)以及在同步偵測找到時的 git 遠端徽章

切換工作區會序列化:如果切換已在進行中,下一次切換會等候它完成,讓 NotesManager / WikiManager 永遠不會指向陳舊路徑。

雲端工作區(Lite 模式)

在 Lite 模式(以及雲端啟用的 Full 組建)中,工作區意味著不同的東西:SeaMeet 雲端上的團隊工作區。<WorkspacePicker> 元件透過 SeaMeet API 抓取您可存取的工作區,並將選擇的持久化以供上傳路由使用。

雲端工作區驅動:

  • 新錄音上傳到哪個工作區
  • 哪個工作區的會議出現在 Lite 會議清單中
  • 系統匣選單中的工作區標題列(讓您一眼看出由系統匣啟動的下一個錄音會落在哪)

雲端挑選器會過濾掉您的 my_status 為 INACTIVE 的工作區。首次登入時,如果您先前選擇的工作區不在傳回的清單中(您失去成員身分、結構漂移等),挑選器會自動挑第一個可用的工作區並持久化——這樣選單就永遠不會卡在無法存取的 ID 上。

兩者皆有

在雲端啟用的 Full 組建中,您可以同時選取兩種工作區:存放筆記的本機儲存區,以及接收您上傳的 SeaMeet 雲端工作區。它們是獨立的——切換其中一個不會切換另一個。
