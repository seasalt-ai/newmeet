音訊錄音詳解

第 3 章：音訊錄音詳解

既然你已經完成了第一次錄音，讓我們更深入地了解音訊錄音。本章將解釋 SeaMeet 捕捉音訊的三種方式：透過你的麥克風、透過你的電腦，或兩者同時進行。讀完後，你就會知道在任何情況下應該選擇哪個選項。

什麼是音訊錄音？（基礎知識）

在我們進入技術細節之前，讓我們先了解音訊錄音到底是什麼。

簡單解釋： 音訊錄音就像拍照一樣，但對象是聲音。就像相機捕捉光線並將其儲存為圖片一樣，錄音機捕捉聲波並將其儲存為數位檔案。

可以這樣理解：

  • 你的聲音在空氣中產生聲波
  • 麥克風偵測到這些聲波並將其轉換為電子訊號
  • SeaMeet 將這些訊號轉換為數位檔案
  • 該檔案可以稍後播放、分享或編輯

SeaMeet 有什麼特別之處？ 不同於手機上的簡單錄音應用程式，SeaMeet 可以捕捉：

  1. 你的聲音（透過你的麥克風）
  2. 你電腦的聲音（影片、音樂、會議音訊）
  3. 兩者混合在一起（你的說話聲 + 會議音訊）

這種靈活性使 SeaMeet 非常適合錄製會議、建立教學、捕捉串流內容等等。

三種音訊錄音模式

SeaMeet 提供三種不同的音訊錄製方式。了解何時使用每一種是獲得最佳效果的關鍵。

模式 1：僅麥克風 🎤

錄製內容： 只有你的聲音（或麥克風拾取的任何聲音）

可以想像成： 把錄音機放在嘴邊

最適合：

  • 語音備忘錄和個人筆記
  • 播客錄製
  • 影片配音
  • 聽寫
  • 練習演講或簡報時的自我錄音
  • 訪談（如果你只需要你這邊的聲音）

運作方式： SeaMeet 啟動你電腦的麥克風並錄製它聽到的一切。這可能包括：

  • 你的聲音
  • 房間裡的聲音
  • 背景噪音（電視、交通等）

範例情境：

你正在為一個專案進行腦力激盪。你打開 SeaMeet，選擇「Microphone」模式，然後開始大聲說出你的想法。稍後，你可以播放錄音來回顧你的思路。

模式 2：僅系統音訊 🔊

錄製內容： 你電腦發出的所有聲音（但不包括你的聲音）

可以想像成： 錄製廣播——捕捉從喇叭發出的一切

最適合：

  • 錄製線上會議（當你不需要你的聲音時）
  • 儲存串流音樂或播客
  • 捕捉影片音訊
  • 錄製遊戲聲音
  • 儲存線上課程

運作方式： SeaMeet 建立一個「虛擬迴路」，在音訊到達你的喇叭之前捕捉你電腦的音訊輸出。就像在你的電腦和喇叭之間放了一個錄音裝置。

範例情境：

你正在參加 Zoom 會議，想要錄製其他人說的話，但不需要錄製你自己的聲音。你選擇「System Audio」模式並開始錄音。檔案將包含其他人的音訊，但不包含你的。

關於系統音訊的重要說明：

  • Windows： 適用於所有版本的 Windows 10 和 11
  • Mac： 需要 macOS 13.2（Ventura）或更新版本。較舊的 Mac 仍然可以錄製麥克風音訊和影片，但無法單獨錄製系統音訊。

模式 3：兩者混合 🎤+🔊

錄製內容： 你的聲音和你電腦的聲音，混合在一起

可以想像成： 錄製電話通話，你可以聽到對話的雙方

最適合：

  • 線上會議（你 + 其他參與者）
  • 視訊通話（對話的雙方）
  • 教學課程（你的說明 + 螢幕上的聲音）
  • 遊戲實況（你的評論 + 遊戲音訊）
  • 反應影片（你的反應 + 你正在觀看的影片）

運作方式： SeaMeet 同時啟動你的麥克風和系統音訊捕捉，然後將它們混合成一個音訊檔案。你不會得到兩個單獨的檔案——一切都會自動混合在一起。

範例情境：

你正在 Zoom 上主持一個網路研討會。你想錄製你所說的（你的麥克風）和參加者所說的（系統音訊）。你選擇「Both」模式並開始錄音。最終檔案包含整個對話。

為什麼這非常有用： 想像錄製一個會議，你可以聽到：

  • 你提出問題 ✓
  • 你的同事回答 ✓
  • 接下來的討論 ✓

全部在一個無縫的錄音中。無需稍後合併檔案！

如何選擇你的錄音模式

現在讓我們逐步說明如何在 SeaMeet 中選擇每種模式。

開啟錄音選項

  1. 確保 SeaMeet 已開啟
  2. 在視窗右側找到錄音控制（或你的錄音面板所在的位置）
  3. 找到標示為「Audio Source」或「Recording Mode」的區段

你應該會看到類似這樣的畫面：

Audio Source
○ Microphone only
○ System audio only
● Both (Mixed)    ← [目前選取]

選擇僅麥克風

  1. 點擊「Microphone」或「Microphone only」的單選按鈕或下拉選單
  2. 你可能會看到額外的選項：
    • 麥克風選擇下拉選單： 選擇要使用哪個麥克風（如果你有多個）
    • 麥克風測試按鈕： 點擊以查看你的麥克風是否正常運作
    • 音量／增益滑桿： 調整麥克風的錄音音量
  3. 錄音將在你的錄音清單中標示為「Microphone」

視覺指示器： 尋找 🎤 麥克風圖示

選擇僅系統音訊

  1. 點擊「System Audio」或「System audio only」的單選按鈕或下拉選單
  2. 在 Mac 上（如果你看到警告）：你可能需要在系統偏好設定中授予額外的權限
  3. 錄音將根據偵測到的應用程式來標示（例如「Zoom」、「Chrome」或「System Audio」）

視覺指示器： 尋找 🔊 喇叭圖示或應用程式名稱

選擇兩者混合

  1. 點擊「Both」或「Microphone + System」的單選按鈕或下拉選單
  2. 你會看到麥克風和系統音訊的選項
  3. 從下拉選單中選擇你偏好的麥克風
  4. 錄音將標示為「Both」或偵測到的應用程式名稱

視覺指示器： 尋找 🎤+🔊 圖示或「Mixed」標籤

了解麥克風

由於麥克風品質會顯著影響你的錄音，讓我們了解基礎知識。

什麼是麥克風？

麥克風是一種將聲波轉換為電子訊號的裝置。可以把它想像成一個小耳朵，它傾聽並將聽到的內容翻譯成你的電腦可以理解的格式。

類比： 想像聯合國的翻譯員。有人用法語說話，翻譯員傾聽，然後將其翻譯成英語供耳機使用。麥克風做的事情一樣——它「傾聽」聲音並將其轉換為數位訊號。

你可能擁有的麥克風類型

1. 內建麥克風（筆記型電腦）

  • 是什麼： 內建在筆記型電腦機體中的小型麥克風
  • 品質： 基本使用尚可，但不太好
  • 最適合： 快速筆記、隨意錄音
  • 限制： 會收到鍵盤噪音、風扇噪音、房間迴音

2. 耳機麥克風

  • 是什麼： 附在頭戴式耳機或耳塞上的麥克風
  • 品質： 通常比內建的好
  • 最適合： 通話、會議、遊戲
  • 優點： 靠近你的嘴巴，背景噪音更少

3. USB 麥克風

  • 是什麼： 透過 USB 插入的獨立麥克風
  • 品質： 可以從非常好到極佳
  • 最適合： 播客、專業錄音、配音
  • 例如： Blue Yeti、Audio-Technica AT2020、Rode NT-USB

4. 無線／藍牙麥克風

  • 是什麼： 無線連接（藍牙或 USB 接收器）
  • 品質： 差異很大
  • 最適合： 需要四處走動的演講
  • 注意： 可能有延遲問題（請參見下方藍牙章節）

在 SeaMeet 中選擇正確的麥克風

如果你連接了多個麥克風，SeaMeet 讓你選擇要使用哪一個：

逐步操作：

  1. 尋找標示為「Microphone」或「Input Device」的下拉選單
  2. 點擊下拉選單查看可用的麥克風
  3. 選擇你想使用的那個
  4. 說話並觀察音訊電平指示器（如果可見）來測試它

專業提示： 在重要的錄音之前一定要測試你的麥克風！

調整麥克風音量（增益）

有時你的錄音太安靜或太大聲。SeaMeet 讓你調整這個設定。

什麼是「增益」？

增益就像麥克風的音量控制，但它的運作方式與喇叭音量不同：

  • 喇叭音量： 控制播放的音量
  • 麥克風增益： 控制錄音的音量

類比： 把增益想像成相機的感光度設定。較高的感光度（增益）捕捉更多的光線（聲音），但可能引入噪音。較低的感光度捕捉較少但更乾淨。

在 SeaMeet 中調整增益

  1. 前往設定 ⚙️
  2. 尋找「Audio」或「Microphone」設定
  3. 找到「Gain」或「Microphone Volume」滑桿
  4. 調整滑桿：
    • 向左（較低）： 較安靜的錄音，較不敏感
    • 向右（較高）： 較大聲的錄音，較敏感

預設值通常是 1.0x（100%）

如何設定正確的電平

方法 1：視覺指示器

  • 說話時觀察音訊電平計
  • 目標是達到最大值的約 70-80%
  • 避免持續達到 100%（會造成失真）
  • 避免保持在 20% 以下（太安靜）

方法 2：測試錄音

  1. 做一個 10 秒的測試錄音
  2. 播放回來
  3. 如果太安靜：增加增益
  4. 如果失真／太大聲：降低增益
  5. 再次測試

常見的增益問題

「我的錄音太安靜」

  • 將增益提高到 1.5x 或 2.0x
  • 靠近麥克風
  • 檢查麥克風是否在系統設定中被靜音
  • 嘗試不同的麥克風

「我的錄音聽起來失真或有『雜音』」

  • 將增益降低到 0.7x 或 0.5x
  • 稍微遠離麥克風
  • 檢查鬆動的線材
  • 減少背景噪音

「我可以聽到背景噪音」

  • 降低增益並靠近麥克風
  • 使用降噪功能（如果你的麥克風設定中有的話）
  • 在更安靜的環境中錄音
  • 考慮使用具有更好噪音抑制功能的麥克風

藍牙音訊注意事項

藍牙耳機和麥克風很方便，但在錄音方面有一些特殊的考量。

藍牙音訊如何運作

藍牙在裝置之間無線傳送音訊。但是，它有一些限制：

  • 延遲： 說話和錄音之間有小的延遲（通常 100-300 毫秒）
  • 品質： 壓縮音訊（不如有線的品質高）
  • 依賴電池： 電池耗盡時就不能用
  • 干擾： 可能受到其他無線裝置的影響

SeaMeet 的藍牙警告

SeaMeet 會在偵測到你使用藍牙裝置時顯示警告，因為：

  1. 延遲可能導致同步問題 - 你的聲音在錄音中可能會稍微延遲
  2. 品質會降低 - 藍牙會壓縮音訊
  3. 連線可能中斷 - 如果電池耗盡或連線變弱

當你看到警告時：

  • 點擊「Dismiss」如果你想繼續使用藍牙
  • 切換到有線耳機／麥克風以獲得最佳品質
  • 警告只是建議，不是必須遵守的

藍牙錄音的最佳實踐

如果你必須使用藍牙：

  • 使用高品質的藍牙裝置（尋找「aptX」或「AAC」支援）
  • 保持裝置充電
  • 靠近你的電腦
  • 先用短錄音測試
  • 注意輕微的延遲

更好的替代方案：

  • 有線 USB 麥克風（最佳品質）
  • 帶麥克風的有線耳機
  • 內建筆記型電腦麥克風（如果沒有其他選擇）

常見使用案例和建議設定

以下是實際場景及每種場景的最佳音訊設定：

使用案例 1：錄製線上會議

你的目標： 捕捉包括你的貢獻在內的整個會議

建議設定：

  • 模式： 兩者混合（麥克風 + 系統）
  • 麥克風： 你最好的可用麥克風
  • 增益： 1.0x（根據測試調整）
  • 原因： 在一個檔案中捕捉對話的雙方

專業提示： 在正式會議之前與同事一起測試！

使用案例 2：建立語音備忘錄

你的目標： 快速記錄一個想法或點子

建議設定：

  • 模式： 僅麥克風
  • 麥克風： 內建或最近的可用麥克風
  • 增益： 1.0x
  • 原因： 快速、簡單，只有你的聲音

專業提示： 使用 Floater（浮動小工具）快速存取，無需開啟完整的應用程式

使用案例 3：錄製串流音樂

你的目標： 從串流服務儲存一首歌或播客

建議設定：

  • 模式： 僅系統音訊
  • 原因： 你不想要房間噪音或你的聲音，只要音樂

法律說明： 只錄製你有權錄製的內容。尊重版權法。

使用案例 4：錄製教學課程

你的目標： 建立一個解說軟體的教學影片

建議設定：

  • 模式： 兩者混合（麥克風 + 系統）
  • 麥克風： 如果有的話，使用 USB 麥克風
  • 增益： 麥克風 1.0x，系統音訊正常音量
  • 原因： 你的聲音 + 軟體聲音 = 完整教學

專業提示： 做一個 30 秒的測試錄音來檢查兩個來源的音訊電平

使用案例 5：錄製遊戲實況

你的目標： 帶著你的評論捕捉遊戲過程

建議設定：

  • 模式： 兩者混合（麥克風 + 系統）
  • 麥克風： 耳機麥克風
  • 增益： 1.0x，可能需要調整以使你的聲音在遊戲音訊中清晰可聞
  • 原因： 遊戲聲音 + 你的反應／評論

專業提示： 注意你的電平——遊戲音訊可能很大聲，會蓋過你的聲音

使用案例 6：錄製講座

你的目標： 儲存一堂課或演講以便稍後複習

建議設定：

  • 模式： 僅系統音訊（如果是線上觀看）或僅麥克風（如果是現場）
  • 原因： 在這個場景中你通常不需要錄製你自己

替代方案： 使用 Flashback 模式（第 6 章）來捕捉最後幾分鐘，如果你錯過了開頭！

常見音訊問題疑難排解

「我在錄音中聽不到任何聲音！」

檢查以下事項：

  1. 是否選擇了正確的模式？

    • 僅麥克風：你有說話嗎？
    • 僅系統音訊：你的電腦上有在播放聲音嗎？
    • 兩者混合：你有在說話且有音訊在播放嗎？

  2. 檢查麥克風權限

    • Windows：設定 → 隱私權 → 麥克風
    • Mac：系統偏好設定 → 安全性與隱私 → 麥克風
    • 確保 SeaMeet 被允許

  3. 你的麥克風是否被靜音？

    • 檢查麥克風上的實體靜音按鈕
    • 檢查系統音量混合器
    • 檢查是否有其他應用程式正在獨占使用麥克風

  4. 增益是否太低？

    • 在 SeaMeet 設定中增加麥克風增益

「有一種奇怪的迴音或重複聲音」

這通常意味著： 你同時錄製麥克風和系統音訊，但你的喇叭正在透過系統播放麥克風的聲音。

解決方案：

  1. 使用耳機 - 防止麥克風拾取喇叭輸出
  2. 啟用回音消除 - 某些麥克風具有此功能
  3. 降低喇叭音量 - 降低回饋的機會
  4. 切換到僅麥克風模式 - 如果你不需要系統音訊

「我的聲音聽起來像機器人或金屬聲」

可能的原因：

  1. 藍牙問題 - 切換到有線連接
  2. 低位元率錄音 - 檢查品質設定
  3. 麥克風損壞 - 用另一個麥克風測試
  4. 音訊處理衝突 - 關閉其他音訊應用程式

「有很多背景噪音」

解決方案：

  1. 靠近麥克風 - 允許較低的增益設定
  2. 使用指向性麥克風 - 較少拾取側面噪音
  3. 在較安靜的空間錄音 - 關閉窗戶、關閉風扇
  4. 添加柔軟材料 - 毯子、枕頭可以吸收迴音
  5. 使用降噪 - 某些麥克風具有此功能，或稍後編輯

「錄音音量自動上下變動」

這可能是： 自動增益控制（AGC） - 某些麥克風會自動調整音量

修正方法：

  1. 在系統設定中檢查麥克風屬性
  2. 停用「AGC」或「Automatic Gain Control」
  3. 改為在 SeaMeet 中設定固定的增益電平

你的音訊始終受到保護

SeaMeet 在你錄音時持續不斷地將音訊寫入磁碟——而不是只在你按下停止時才寫入。

這意味著如果在錄音過程中出了任何問題（當機、斷電、強制退出），到那個時刻為止捕捉的所有內容都已經安全地儲存在你的磁碟上了。你永遠不會因為技術故障而失去數小時的會議音訊。

這適用於所有三種音訊模式：僅麥克風、僅系統音訊和兩者混合。

請參閱第 4 章了解 SeaMeet 的持續磁碟寫入如何保護你所有錄音的完整說明。

出色音訊的最佳實踐

錄音前

✅ 測試你的設定

  • 做一個 10 秒的測試錄音
  • 用耳機回放聆聽
  • 在正式錄音前檢查是否有問題

✅ 選擇正確的環境

  • 安靜、沒有迴音的房間
  • 關閉窗戶和門
  • 關閉電腦上的通知

✅ 正確放置你的麥克風

  • 距離你的嘴巴 15-30 公分
  • 稍微偏到一邊（不要正對著）
  • 與嘴巴同高，不要太高或太低

✅ 檢查你的電平

  • 目標是一致的音量
  • 避免削波（達到最大電平）
  • 根據需要調整增益

錄音中

✅ 用耳機監聽（如果可能）

  • 聽到你實際錄製的內容
  • 立即發現問題
  • 防止迴音問題

✅ 保持一致

  • 不要靠近／遠離麥克風
  • 保持相同的說話音量
  • 避免突然的大聲噪音

✅ 使用正確的模式

  • 僅麥克風用於獨自錄音
  • 僅系統用於捕捉電腦音訊
  • 兩者混合用於會議和教學

錄音後

✅ 批判性地回聽

  • 音量是否一致？
  • 有不想要的噪音嗎？
  • 一切都清晰嗎？

✅ 用描述性名稱重新命名檔案

  • "Meeting_Zoom_March15.webm"
  • "Tutorial_Photoshop_Basics.webm"
  • "VoiceMemo_Idea_ForProject.webm"

✅ 定期整理

  • 按專案或日期建立資料夾
  • 刪除測試錄音
  • 備份重要檔案
