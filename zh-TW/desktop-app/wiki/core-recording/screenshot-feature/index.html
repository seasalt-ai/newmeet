截圖功能

第 6 章:截圖功能

除了音訊與視訊錄製之外,SeaMeet 還包含強大的截圖功能,讓您能夠擷取螢幕的靜態影像。無論您需要儲存影片中的某個時刻、擷取錯誤訊息,或視覺化記錄某些事物,截圖都是極為實用的工具。本章將教您關於在 SeaMeet 中拍攝、檢視及管理截圖的所有事項。

什麼是截圖?(基礎概念)

在深入細節前,讓我們先了解截圖實際上是什麼。

簡單解釋: 截圖就像是替您的電腦螢幕拍張照。不是用相機拍攝真實世界,而是用軟體把您在特定時刻看到的畫面原原本本擷取下來。

這樣想:

  • 您的螢幕顯示影像、文字與圖像
  • 截圖會精準地把這些像素捕捉下來
  • 影像會儲存成可以檢視、編輯或分享的檔案
  • 不同於影片,它是時間中的單一凝固時刻

SeaMeet 的截圖有什麼特別之處? 與只是儲存影像的基本截圖工具不同,SeaMeet:

  1. 擷取選取的區域(不只是整個螢幕)
  2. 擷取中繼資料(自動擷取尺寸、檔案大小)
  3. 使用 AI 自動擷取文字 (OCR) 並複製到剪貼簿
  4. 與您的錄音一同管理截圖
  5. 提供專屬檢視器,包含分享與複製選項

為何使用截圖?

截圖與音訊或視訊錄製的用途不同。了解何時使用各種工具,有助於您挑選正確的工具。

截圖 vs. 音訊/視訊錄製

您需要什麼使用截圖使用音訊錄音使用視訊錄影
儲存錯誤訊息✅ 完美❌ 無法擷取文字⚠️ 過度使用
記錄某項設定✅ 完美❌ 沒有視覺資訊⚠️ 過度使用
從影片擷取一格✅ 完美❌ 沒有視覺✅ 但檔案大
記錄對話❌ 沒有音訊✅ 完美✅ 完美
逐步展示流程⚠️ 需要多張❌ 沒有視覺✅ 完美
儲存收據或確認單✅ 完美❌ 無法讀取文字⚠️ 過度使用

截圖大顯身手的場合

1. 文件記錄

  • 儲存錯誤訊息以供技術支援
  • 在變更設定前擷取目前的設定
  • 記錄網站設計或版面配置
  • 儲存收據與確認單

2. 溝通

  • 完整呈現您所看到的內容給同事
  • 在簡報中加入視覺資料
  • 用圖片建立逐步指南
  • 分享影片中特定的時刻

3. 存檔

  • 儲存可能稍後會用到的資訊
  • 擷取時效性內容(票券、序號)
  • 保留可能變動的網頁
  • 建立視覺參考材料

4. 品質

  • 無損 PNG 格式保留每個像素
  • 比影片畫格的品質更高
  • 對文字與 UI 元素來說很完美
  • 沒有壓縮失真

截圖在 SeaMeet 中如何運作

SeaMeet 讓拍攝截圖既簡單又強大。以下是基本流程:

1. 觸發       →  2. 選取        →  3. 擷取        →  4. 儲存       →  5. 檢視
鍵盤           在螢幕上          SeaMeet 抓取        PNG 儲存到        在截圖
快捷鍵或       畫一個方框        像素,完全保        儲存資料夾        檢視器
按鈕點擊                         留原樣            並擷取中繼        中開啟
                                                 資料

流程:

  1. 您觸發截圖(鍵盤快捷鍵或 Capture Hub 按鈕)
  2. 對於區域擷取:畫出您想要的範圍;對於全螢幕:擷取會立即發生
  3. SeaMeet 擷取那確切的內容(SeaMeet 本身預設會從擷取中隱藏)
  4. 影像會儲存為高品質的 PNG 檔案
  5. 您可以在 SeaMeet 的專屬截圖檢視器中檢視

拍攝您的第一張截圖

讓我們逐步進行您的第一次截圖。

方法 1:使用鍵盤快捷鍵

最快的截圖方式:

在 Windows 上:

  1. 同時按 Ctrl + Alt + S
  2. 您的螢幕會稍微變暗
  3. 透過點擊並拖曳畫出一個矩形
  4. 放開以擷取

在 macOS 上:

  1. 同時按 Cmd + Shift + S
  2. 您的螢幕會稍微變暗
  3. 透過點擊並拖曳畫出一個矩形
  4. 放開以擷取

發生什麼事:

  • SeaMeet 立刻擷取所選區域
  • 截圖會自動儲存
  • 您會聽到微弱的相機快門音(如果已啟用)
  • 檔案會出現在您的「Recent Snapshots」側欄

方法 2:使用 Capture Hub

當您位於 SeaMeet 主視窗時:

  1. 在 Capture Hub 的右側面板中選擇您的模式:
    • Full Screen — 立即擷取整個顯示器
    • Area Capture — 開啟區域選擇器,讓您畫出一個方框
  2. 選擇性地勾選 "Keep SeaMeet window visible when taking screenshot"(請見下方說明)
  3. 點擊 Take Screenshot 按鈕或大型相機圖示
  4. 對於區域擷取:畫出擷取矩形,然後放開

視窗可見性選項: 預設情況下,SeaMeet 會在拍截圖前自行最小化,讓應用程式不會出現在擷取畫面中。如果您希望 SeaMeet 視窗保持可見(例如,想故意拍下它),請勾選 "Keep SeaMeet window visible when taking screenshot" 核取方塊。

OCR 自動複製選項: 勾選 "Extract text (OCR) and copy to clipboard",SeaMeet 就會使用 AI 自動讀取截圖中所有可見的文字,並複製到您的剪貼簿。截圖擷取完成後,AI 管線會在背景執行(約 15–30 秒)。完成時,擷取的文字會取代剪貼簿上的截圖影像,並有通知確認複製成功。這在不想重打字的情況下,快速從影像、錯誤對話框或網頁取得文字非常有用。

  • 同樣的核取方塊也會出現在 Region Selector 重疊介面中(靠近 "Capture Screen or Press Enter" 按鈕),讓您可以針對每次擷取進行切換。
  • 預設值可在 Settings → AI Extraction & Summary → Auto-extract text (OCR) on screenshot 中變更。
  • 需要 API 金鑰。 如果未設定 Gemini API 金鑰,核取方塊會變灰,並帶有指向帳單入口的「subscribe here」連結。

方法 3:使用浮動啟動器

當您已開啟 SeaMeet:

  1. 找到浮動啟動器小工具(通常在螢幕的某個角落)
  2. 找到相機圖示 📷(截圖按鈕)
  3. 點擊它
  4. 在螢幕上畫出一個矩形
  5. 放開以擷取

到哪找啟動器:

  • 通常在 SeaMeet 執行時出現
  • 可透過拖曳移動
  • 不使用時會最小化
  • 提供錄音與截圖功能的快速存取

如何選取完美的區域

逐步說明:

  1. 將游標定位在您想擷取的內容的一角
  2. 點擊並按住滑鼠左鍵
  3. 拖曳到對角
  4. 當方框正好涵蓋您所需的內容時放開
  5. 按 Enter 確認,或直接放開以自動擷取

精確選取的提示:

  • 從您要的內容稍微外側開始
  • 您可以在放開之前調整選取範圍
  • 按住 Shift 可限制為正方形(在某些模式下)
  • 隨時按 Escape 可取消並重試

會擷取到什麼:

  • 完全是您所畫矩形內的內容
  • 完整解析度(沒有品質損失)
  • 包含所有文字、影像與圖形
  • 但不包含變暗的覆蓋層或選取框

截圖儲存於何處

瞭解截圖儲存位置有助於您尋找並管理它們。

預設儲存位置

截圖儲存在:

Documents/SeaMeet/Screenshots/

範例路徑:

  • Windows: C:\Users\YourName\Documents\SeaMeet\Screenshots\
  • macOS: /Users/YourName/Documents/SeaMeet/Screenshots/

檔案命名慣例

SeaMeet 會自動以時間戳記命名您的截圖:

Screenshot_YYYYMMDD_HHMMSS.png

範例: Screenshot_20260209_143052.png

  • 拍攝時間:2026 年 2 月 9 日
  • 時間:下午 2:30:52
  • 格式:PNG(高品質)

為什麼這種命名方式有用:

  • ✅ 您能確切知道每張截圖的拍攝時間
  • ✅ 在檔案總管中按時間排序
  • ✅ 沒有重複檔名的衝突
  • ✅ 易於尋找特定截圖

截圖中繼資料

每張截圖都包含自動擷取的資訊:

{
  "filename": "Screenshot_20260209_143052.png",
  "type": "screenshot",
  "isScreenshot": true,
  "imageMetadata": {
    "width": 1920,
    "height": 1080,
    "format": "png",
    "fileSize": 2540000
  },
  "timestamp": "2026-02-09T14:30:52.000Z"
}

這代表:

  • 尺寸: 1920×1080 像素(Full HD)
  • 格式: PNG(無損、高品質)
  • 檔案大小: 約 2.5 MB
  • 擷取時間: 自動記錄

在 SeaMeet 中檢視截圖

SeaMeet 提供專屬的截圖檢視器,用以檢視您的擷取。

開啟截圖檢視器

方法 1:從側欄

  1. 查看您的「Recent Snapshots」側欄
  2. 找到您的截圖(有 📷 相機圖示)
  3. 點擊它
  4. 截圖檢視器會自動開啟

方法 2:從檔案匯入

  1. 點擊「Import」或將檔案拖入 SeaMeet
  2. 選擇影像檔案(PNG、JPG 等)
  3. 它們會出現在您的側欄
  4. 點擊以檢視

瞭解中繼資料顯示

尺寸:

  • 顯示為 寬 × 高(像素)
  • 範例:1920 × 1080
  • 這告訴您擷取影像的解析度

檔案大小:

  • 以人類可讀的單位呈現
  • 範例:2.5 MB 或 850 KB
  • PNG 檔案較大,但品質比 JPG 高

格式:

  • SeaMeet 截圖一律是「PNG」
  • 其他匯入的影像可能顯示「JPG」、「WebP」等

使用截圖:動作

截圖檢視器提供多種您可以對擷取進行的動作。

複製到剪貼簿

功能: 將截圖影像複製到您的系統剪貼簿,方便您貼到其他地方。

如何使用:

  1. 開啟截圖檢視器
  2. 點擊 📋 複製 按鈕
  3. 或按 Ctrl+C(Windows)/ Cmd+C(macOS)
  4. 貼到任何接受影像的應用程式(電子郵件、聊天、文件等)

何時使用:

  • ✅ 貼到 Slack、Teams 或 Discord
  • ✅ 加入 Word 文件或電子郵件
  • ✅ 上傳到網站或表單
  • ✅ 在聊天訊息中分享
  • ✅ 建立快速視覺參考

進階提示: 這是不必先儲存就能分享截圖的最快方式!

在系統檢視器中開啟

功能: 在您系統的檔案總管中開啟包含截圖的資料夾,並選取該檔案。

如何使用:

  1. 開啟截圖檢視器
  2. 點擊 📂 開啟 按鈕
  3. 您的檔案總管會開啟,顯示 Screenshots 資料夾
  4. 該檔案會被標示/選取

何時使用:

  • ✅ 您想重新命名檔案
  • ✅ 您需要將它移動到其他位置
  • ✅ 您想從檔案附加到電子郵件
  • ✅ 您需要在其他程式中編輯它

分享(僅限 macOS)

功能: 開啟 macOS 分享選單,透過各種方法傳送截圖。

如何使用:

  1. 開啟截圖檢視器(在 macOS 上)
  2. 點擊 🔗 分享 按鈕
  3. 從分享選項中選擇:
    • AirDrop(到附近的裝置)
    • 訊息
    • 郵件
    • 備忘錄
    • 社群媒體
    • 還有更多…

何時使用:

  • ✅ 快速分享到 Apple 裝置
  • ✅ 透過訊息傳送
  • ✅ 加入備忘錄或提醒
  • ✅ 發布到社群媒體

為什麼 Windows 沒有這個: Windows 沒有像 macOS 那樣的標準化分享 API。在 Windows 上,請改用複製,然後貼到您目的地的應用程式中。

在側欄管理截圖

截圖會出現在「Recent Snapshots」區段中,與錄音並列。

截圖如何顯示

視覺指示:

  • 📷 相機圖示(取代 🎥 視訊或 🎵 音訊圖示)
  • 圖示背景為紫色
  • 在中繼資料行顯示尺寸(例如「1920×1080」)
  • 顯示 "Screenshot" 標籤

側欄項目範例:

┌─────────────────────────────────────────┐
│ 📷  Screenshot                          │
│     Screenshot_20260209_143052.png      │
│     1920×1080 • 今天 下午 2:30          │
└─────────────────────────────────────────┘

搜尋截圖

搜尋列也適用於截圖:

  1. 在側欄頂部的搜尋方塊中輸入
  2. 截圖會在符合您搜尋條件時顯示
  3. 依檔名與中繼資料搜尋

您可以搜尋:

  • 部分檔名(例如 "Screenshot_20260209")
  • 時間關鍵字(例如「今天」、「昨天」)
  • 副檔名(例如 ".png")

排序與整理

截圖如何排序:

  • 依時間戳記(最新優先)
  • 與錄音按時間先後混合排列
  • 最新擷取出現在頂端

自動重新整理:

  • 截圖在擷取後立即出現
  • 不需手動重新整理(但如果需要也可以)
  • 側欄即時更新

匯入外部截圖

您可以將其他來源的截圖帶入 SeaMeet。

支援的影像格式

SeaMeet 可匯入下列影像類型:

格式副檔名最適用於
PNG.png截圖、含透明度的圖形
JPEG.jpg, .jpeg相片、含漸層的影像
WebP.webp現代網頁影像
GIF.gif簡單動畫、圖形
BMP.bmp未壓縮影像(大檔案)
TIFF.tiff專業列印
HEIC/HEIF.heiciPhone 相片(macOS/iOS)

如何匯入影像

方法 1:使用匯入按鈕

  1. 在 SeaMeet 中,點擊「Open Files」或「Import」
  2. 在檔案對話框中,將篩選器變更為顯示影像
  3. 選擇您的影像檔案
  4. 點擊「Open」
  5. 影像會出現在您的側欄

方法 2:拖放

  1. 在檔案總管中找到影像檔
  2. 將它拖到 SeaMeet 視窗中
  3. 將它放到側欄區域
  4. 影像會被匯入並出現在清單中

匯入時會發生什麼:

  • SeaMeet 擷取中繼資料(尺寸、檔案大小)
  • 影像會被參考(而不複製)
  • 它會出現在您的側欄,帶有截圖圖示
  • 您可以在截圖檢視器中檢視它

注意: 匯入的影像會留在原本的位置。SeaMeet 建立一個參考指向它們。

實際截圖情境

讓我們看看截圖是完美工具的真實場景。

情境 1:儲存錯誤訊息

狀況: 應用程式顯示您看不懂的錯誤。您想就此向技術支援詢問。

為何截圖完美:

  • 擷取確切的錯誤文字
  • 包含任何錯誤代碼
  • 顯示脈絡(您當時在做什麼)
  • 容易附加到支援工單

怎麼做:

  1. 出現錯誤時,按 Ctrl+Alt+S(Windows)或 Cmd+Shift+S(macOS)
  2. 在錯誤對話框周圍畫一個方框
  3. 截圖會自動儲存
  4. 開啟它,使用「複製」貼到您的支援聊天/電子郵件中

情境 2:記錄設定

狀況: 您正在變更一些重要設定,並希望記得它們原本的值。

為何截圖完美:

  • 精確設定的視覺紀錄
  • 比把所有內容寫下來更快
  • 沒有抄寫錯誤的可能
  • 容易比對「之前」與「之後」

怎麼做:

  1. 前往設定頁面
  2. 為目前設定拍張截圖
  3. 進行您的變更
  4. 再拍另一張截圖
  5. 現在您擁有兩種狀態的視覺紀錄

情境 3:建立逐步說明

狀況: 您正在向同事說明如何使用軟體,需要視覺輔助。

為何截圖完美:

  • 顯示要點擊哪些按鈕
  • 擷取選單位置
  • 您所說的內容沒有模糊空間
  • 專業文件

怎麼做:

  1. 自己走過一遍流程
  2. 在每個重要步驟拍截圖
  3. 之後將它們按順序排列並加上說明
  4. 分享完整的指南

情境 4:從影片擷取特定畫格

狀況: 您在看影片時,想把某個特定時刻儲存為影像。

為何截圖比影片畫格更好:

  • 比影片畫格擷取的品質更高
  • 立即擷取(無需影片處理)
  • 確切是您想要的時刻
  • 比影片片段檔案更小

怎麼做:

  1. 將影片暫停在確切的畫格
  2. 在影片播放器區域拍截圖
  3. 影像會以完整品質儲存
  4. 您只需分享那個時刻

情境 5:儲存網頁內容

狀況: 您在網站上找到可能會變動或消失的重要資訊。

為何截圖完美:

  • 確切保留您看到的頁面
  • 即使網站當機也能用
  • 擷取視覺設計與版面配置
  • 比儲存整個頁面更快

怎麼做:

  1. 前往該頁面
  2. 拍下相關區段的截圖
  3. 影像永久儲存
  4. 您永遠擁有這份視覺紀錄

將截圖與其他功能相比

瞭解何時使用截圖,何時使用其他 SeaMeet 功能,有助於您更有效率地工作。

截圖 vs. 視訊錄影

面向截圖視訊錄影
擷取什麼一個時刻持續動作
檔案大小小(約 2-5 MB)大(約 60 MB/分鐘)
最適用於靜態內容、文字、UI動態、流程、示範
擷取時間立即需要持續時間
品質完美像素精度經壓縮,可能模糊
聲音無可包含音訊

決策指引:

  • 使用截圖的時機: 您需要特定時刻、文字很重要,或檔案大小有關鍵作用
  • 使用視訊的時機: 您需要展示流程、動態很重要,或您需要音訊

截圖 vs. Flashback 錄音

面向截圖Flashback 錄音
時機當下時刻過去(已發生)
持續時間立即可變(過去 X 分鐘)
檔案大小非常小(約 2-5 MB)中等(可變)
最適用於擷取目前狀態找回錯過的時刻
品質完整解析度影片品質(經壓縮)

決策指引:

  • 使用截圖的時機: 您現在看到某樣想儲存的東西
  • 使用 Flashback 的時機: 您剛剛錯過某事,想找回過去幾分鐘

截圖最佳實務

遵循這些指引,以最大化截圖的效益。

拍截圖之前

✅ 準備您的螢幕

  • 關閉無關的視窗
  • 隱藏敏感資訊
  • 將您要擷取的內容最大化
  • 確保良好的對比與可見度

✅ 考量目的

  • 誰會看到這張截圖?
  • 哪些資訊需要可見?
  • 文字在擷取的尺寸下是否清晰可讀?
  • 是否有任何敏感資料外露?

✅ 整理您的桌面

  • 移除視野中的個人檔案
  • 關閉聊天應用程式
  • 視需要隱藏通知區域
  • 呈現專業的外觀

拍截圖時

✅ 精確選取

  • 只擷取您所需的部分(不多不少)
  • 若有助於理解,可加入脈絡
  • 避免切掉重要的 UI 元素
  • 在內容周圍留下小幅邊距

✅ 留意解析度

  • 較高解析度 = 更多細節
  • 但檔案較大
  • 想想截圖用於什麼目的
  • 1080p 通常足以應付大多數用途

✅ 完成前檢查

  • 您是否擷取到正確的區域?
  • 內容是否清楚可見?
  • 是否不小心包含了敏感資訊?
  • 文字是否可讀?

拍完截圖後

✅ 以描述性方式重新命名 與其用:Screenshot_20260209_143052.png 試試:Photoshop_Layers_Error.png 或 Website_Homepage_Design.png

✅ 定期整理

  • 依專案或主題建立資料夾
  • 刪除暫時/測試用截圖
  • 備份重要擷取
  • 封存不再需要的舊截圖

✅ 分享前先檢視

  • 開啟截圖並驗證品質
  • 檢查是否有任何敏感資訊
  • 確認它清楚展示您預期的內容
  • 視需要裁剪或加註

截圖問題的疑難排解

「截圖沒有出現在側欄中」

可能的原因與解決方案:

  1. 檢查掃描是否完成

    • 點擊側欄中的重新整理按鈕
    • 等候幾秒讓掃描完成
    • 新截圖應會出現

  2. 驗證檔案位置

    • 截圖應該在 Documents/SeaMeet/Screenshots/
    • 檢查資料夾是否存在
    • 確認 PNG 檔案在該位置

  3. 檢查檔案權限

    • SeaMeet 需要讀取該資料夾的權限
    • 在 macOS 上:檢查 System Preferences → Security & Privacy → Files and Folders
    • 在 Windows 上:確保沒有防毒軟體阻擋存取

  4. 重新啟動 SeaMeet

    • 有時需要全新掃描
    • 關閉並重新開啟應用程式
    • 檢查截圖是否出現

「截圖品質看起來很差」

解決方案:

  1. 截圖一律是完整品質

    • SeaMeet 以 100% 品質儲存 PNG
    • 檢視器顯示原始檔案
    • 如果看起來品質差,可能是來源內容解析度低

  2. 檢查您的螢幕縮放

    • 某些筆電使用 125% 或 150% 縮放
    • 這可能影響清晰度
    • 截圖擷取您所看到的(縮放後)

  3. 驗證原始內容

    • 如果擷取影片,影片本身可能解析度低
    • 截圖無法加入原本不存在的細節
    • 它們精確擷取螢幕上的內容

「我在磁碟上找不到我的截圖」

解決方案:

  1. 檢查預設位置

    • Windows:C:\Users\[YourName]\Documents\SeaMeet\Screenshots\
    • macOS:/Users/[YourName]/Documents/SeaMeet/Screenshots/

  2. 依檔名搜尋

    • 尋找以 "Screenshot_" 開頭的檔案
    • 使用您系統的檔案搜尋
    • 篩選 PNG 檔案

  3. 檢查 SeaMeet 設定

    • 您可以在 Settings → Storage 中變更儲存位置
    • 驗證該處顯示的截圖資料夾路徑

「複製到剪貼簿沒有作用」

解決方案:

  1. 嘗試按鈕而非鍵盤

    • 點擊檢視器中的「Copy」按鈕
    • 有時鍵盤快捷鍵失效

  2. 檢查剪貼簿權限

    • 某些安全軟體會阻擋剪貼簿存取
    • 嘗試重新啟動 SeaMeet
    • 用其他應用程式測試

  3. 驗證檔案是否存在

    • 如果截圖被移動或刪除,複製就無法運作
    • 開啟檔案位置以確認它存在
    • 視需要重新匯入

「分享按鈕沒有出現」

這在 Windows 與 Linux 上是正常的:

  • 分享按鈕僅出現在 macOS 上
  • macOS 有內建的 SharingService API
  • Windows 與 Linux 沒有標準化的分享系統
  • 在這些平台上,改用「複製」並貼上
