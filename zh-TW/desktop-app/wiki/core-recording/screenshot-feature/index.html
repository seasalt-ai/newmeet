截圖功能

第六章：截圖功能

除了音訊和視訊錄製之外，SeaMeet 還包含強大的截圖功能，讓您可以擷取螢幕上的靜態影像。無論您需要儲存影片中的特定時刻、擷取錯誤訊息，還是以視覺方式記錄某些內容，截圖都非常實用。本章將教您在 SeaMeet 中拍攝、檢視和管理截圖的所有知識。

什麼是截圖？（基礎知識）

在我們深入了解細節之前，先來理解截圖到底是什麼。

簡單說明： 截圖就像是為您的電腦螢幕拍照。您不是使用相機拍攝現實世界，而是使用軟體精確擷取您在特定時刻看到的螢幕畫面。

這樣想：

  • 您的螢幕顯示影像、文字和圖形
  • 截圖會精確擷取這些像素的顯示狀態
  • 影像會儲存為可以檢視、編輯或分享的檔案
  • 與影片不同，它是一個單一的凍結瞬間

SeaMeet 的截圖有什麼特別之處？ 與只能儲存影像的基本截圖工具不同，SeaMeet：

  1. 擷取選定區域（不只是整個螢幕）
  2. 擷取中繼資料（自動記錄尺寸、檔案大小）
  3. 自動擷取文字（OCR），並使用 AI 將文字複製到您的剪貼簿
  4. 管理截圖，與您的錄音一起整理
  5. 提供專用檢視器，具備分享和複製選項

為什麼要使用截圖？

截圖與音訊或影片錄製有不同的用途。了解何時使用哪種工具，有助於您選擇正確的方式。

截圖 vs. 音訊/影片錄製

您的需求使用截圖使用錄音使用影片錄製
儲存錯誤訊息✅ 完美❌ 無法擷取文字⚠️ 大材小用
記錄設定✅ 完美❌ 沒有視覺資訊⚠️ 大材小用
從影片中擷取畫面✅ 完美❌ 沒有視覺✅ 但檔案較大
錄製對話❌ 沒有音訊✅ 完美✅ 完美
逐步展示流程⚠️ 需要多張❌ 沒有視覺✅ 完美
儲存收據或確認✅ 完美❌ 無法讀取文字⚠️ 大材小用

截圖的最佳使用時機

1. 文件記錄

  • 儲存錯誤訊息以供技術支援
  • 在變更設定前擷取當前設定
  • 記錄網站設計或版面配置
  • 儲存收據和確認資訊

2. 溝通交流

  • 向同事展示您看到的確切畫面
  • 在簡報中加入視覺素材
  • 使用影像建立逐步指南
  • 分享影片中的特定時刻

3. 存檔備份

  • 儲存日後可能需要的資訊
  • 擷取有時效性的內容（票券、代碼）
  • 保存可能會變更的網頁
  • 建立視覺參考資料

4. 品質優勢

  • 無損 PNG 格式保留每一個像素
  • 比影片畫面品質更高
  • 非常適合文字和 UI 元素
  • 無壓縮失真

截圖在 SeaMeet 中如何運作

SeaMeet 讓截圖變得簡單又強大。以下是基本流程：

1. 觸發       →  2. 選取       →  3. 擷取       →  4. 儲存       →  5. 檢視
鍵盤快捷鍵      在螢幕上          SeaMeet 精確     PNG 儲存到       在截圖
或按鈕點擊      畫出方框          擷取這些像素     儲存資料夾       檢視器中
                                                並擷取中繼資料   開啟

流程說明：

  1. 您觸發截圖（鍵盤快捷鍵或 Capture Hub 按鈕）
  2. 區域擷取：畫出您想要的區域；全螢幕：立即擷取
  3. SeaMeet 擷取該確切內容（預設情況下 SeaMeet 本身會被隱藏）
  4. 影像儲存為高品質 PNG 檔案
  5. 您可以在 SeaMeet 的專用截圖檢視器中查看

拍攝您的第一張截圖

讓我們一步步完成第一張截圖的擷取。

方法一：使用鍵盤快捷鍵

拍攝截圖最快的方式：

在 Windows 上：

  1. 同時按下 Ctrl + Alt + S
  2. 您的螢幕會稍微變暗
  3. 按住滑鼠左鍵並拖曳來畫出矩形
  4. 放開滑鼠即完成擷取

在 macOS 上：

  1. 同時按下 Cmd + Shift + S
  2. 您的螢幕會稍微變暗
  3. 按住滑鼠左鍵並拖曳來畫出矩形
  4. 放開滑鼠即完成擷取

擷取後會發生什麼：

  • SeaMeet 立即擷取選定區域
  • 截圖自動儲存
  • 您會聽到輕微的快門聲（如果已啟用）
  • 檔案會出現在您的「最近快照」側邊欄中

方法二：使用 Capture Hub

當您在 SeaMeet 主視窗中時：

  1. 在 Capture Hub 的右側面板中選擇模式：
    • "Full Screen" — 立即擷取整個螢幕
    • "Area Capture" — 開啟區域選取器讓您畫出方框
  2. 可選擇勾選 "Keep SeaMeet window visible when taking screenshot"（見下方說明）
  3. 點擊 "Take Screenshot" 按鈕或大型相機圖示
  4. 區域擷取模式：畫出擷取矩形，然後放開滑鼠

視窗可見性選項： 預設情況下，SeaMeet 會在截圖前自動最小化，以避免應用程式出現在截圖中。如果您希望 SeaMeet 視窗保持可見（例如刻意要擷取它），請勾選 "Keep SeaMeet window visible when taking screenshot" 核取方塊。

OCR 自動複製選項： 勾選 "Extract text (OCR) and copy to clipboard" 可讓 SeaMeet 使用 AI 自動讀取截圖中所有可見文字，並將其複製到您的剪貼簿。截圖擷取後，AI 處理流程會在背景執行（約 15–30 秒）。完成後，擷取的文字會取代剪貼簿中的截圖影像，並有通知確認已複製。這對於快速從圖片、錯誤對話方塊或網頁中擷取文字而無需重新輸入非常有用。

  • 相同的核取方塊也會出現在區域選取器覆蓋層中（靠近「Capture Screen or Press Enter」按鈕），讓您可以逐次切換。
  • 預設值可在設定 → AI Extraction & Summary → Auto-extract text (OCR) on screenshot 中更改。
  • **需要 API 金鑰。**如果未配置 Gemini API 金鑰，該核取方塊會顯示為灰色，並附有「subscribe here」連結前往訂閱入口。

方法三：使用浮動啟動器

當您開啟 SeaMeet 時：

  1. 尋找浮動啟動器小工具（通常在螢幕角落）
  2. 找到相機圖示 📷（截圖按鈕）
  3. 點擊它
  4. 在螢幕上畫出矩形
  5. 放開滑鼠即完成擷取

在哪裡找到啟動器：

  • 通常在 SeaMeet 運行時出現
  • 可以拖曳移動位置
  • 不使用時會最小化
  • 提供錄音和截圖功能的快速存取

如何選取完美的區域

逐步操作：

  1. 將游標定位到您想擷取內容的一個角落
  2. 按住滑鼠左鍵
  3. 拖曳到對角位置
  4. 當方框正好覆蓋您需要的內容時放開
  5. 按 Enter 確認，或直接放開滑鼠自動擷取

精確選取的技巧：

  • 從您想要的內容稍微外側開始
  • 放開前可以調整選取範圍
  • 在某些模式下按住 Shift 可以限制為正方形
  • 隨時按 Escape 取消並重新開始

擷取的內容：

  • 完全是您畫出的矩形內部的內容
  • 以完整解析度擷取（無品質損失）
  • 包含所有文字、影像和圖形
  • 但不包含變暗的覆蓋層或選取框

截圖儲存位置

了解截圖儲存的位置有助於您尋找和管理截圖。

預設儲存位置

截圖儲存在：

Documents/SeaMeet/Screenshots/

路徑範例：

  • Windows：C:\Users\YourName\Documents\SeaMeet\Screenshots\
  • macOS：/Users/YourName/Documents/SeaMeet/Screenshots/

檔案命名規則

SeaMeet 會自動以時間戳記為截圖命名：

Screenshot_YYYYMMDD_HHMMSS.png

範例： Screenshot_20260209_143052.png

  • 拍攝日期：2026 年 2 月 9 日
  • 拍攝時間：下午 2:30:52
  • 格式：PNG（高品質）

為什麼這種命名方式很有用：

  • ✅ 您可以確切知道每張截圖的拍攝時間
  • ✅ 在檔案總管中按時間排序
  • ✅ 不會有重複檔名的衝突
  • ✅ 容易找到特定的截圖

截圖中繼資料

每張截圖都包含自動擷取的資訊：

{
  "filename": "Screenshot_20260209_143052.png",
  "type": "screenshot",
  "isScreenshot": true,
  "imageMetadata": {
    "width": 1920,
    "height": 1080,
    "format": "png",
    "fileSize": 2540000
  },
  "timestamp": "2026-02-09T14:30:52.000Z"
}

這些資訊的含義：

  • 尺寸： 1920×1080 像素（Full HD）
  • 格式： PNG（無損、高品質）
  • 檔案大小： 約 2.5 MB
  • 擷取時間： 自動記錄

在 SeaMeet 中檢視截圖

SeaMeet 提供專用的截圖檢視器，讓您可以檢視擷取的影像。

開啟截圖檢視器

方法一：從側邊欄

  1. 查看您的「最近快照」側邊欄
  2. 找到您的截圖（有 📷 相機圖示）
  3. 點擊它
  4. 截圖檢視器會自動開啟

方法二：從檔案匯入

  1. 點擊「匯入」或將檔案拖曳到 SeaMeet 中
  2. 選擇影像檔案（PNG、JPG 等）
  3. 它們會出現在您的側邊欄中
  4. 點擊即可檢視

了解中繼資料顯示

尺寸：

  • 以 寬度 × 高度 像素顯示
  • 範例：1920 × 1080
  • 這告訴您擷取影像的解析度

檔案大小：

  • 以易讀的單位格式化
  • 範例：2.5 MB 或 850 KB
  • PNG 檔案比 JPG 更大但品質更高

格式：

  • SeaMeet 截圖一律為「PNG」
  • 其他匯入的影像可能顯示「JPG」、「WebP」等

處理截圖：操作功能

截圖檢視器提供多種操作，讓您可以處理擷取的影像。

複製到剪貼簿

功能說明： 將截圖影像複製到系統剪貼簿，以便您可以貼到其他地方。

使用方式：

  1. 開啟截圖檢視器
  2. 點擊 📋 複製 按鈕
  3. 或按 Ctrl+C（Windows）/ Cmd+C（macOS）
  4. 貼到任何接受影像的應用程式中（電子郵件、聊天、文件等）

適用時機：

  • ✅ 貼到 Slack、Teams 或 Discord
  • ✅ 加入 Word 文件或電子郵件
  • ✅ 上傳到網站或表單
  • ✅ 在聊天訊息中分享
  • ✅ 建立快速視覺參考

專業提示： 這是分享截圖最快的方式，不需要先另存到其他地方！

在系統檢視器中開啟

功能說明： 在系統的檔案總管中開啟包含您截圖的資料夾，並選取該檔案。

使用方式：

  1. 開啟截圖檢視器
  2. 點擊 📂 開啟 按鈕
  3. 您的檔案總管會開啟並顯示截圖資料夾
  4. 該檔案會被醒目標示/選取

適用時機：

  • ✅ 您想重新命名檔案
  • ✅ 您需要將它移動到其他位置
  • ✅ 您想從檔案附加到電子郵件
  • ✅ 您需要在其他程式中編輯它

分享（僅限 macOS）

功能說明： 開啟 macOS 的分享選單，透過各種方式傳送截圖。

使用方式：

  1. 開啟截圖檢視器（在 macOS 上）
  2. 點擊 🔗 分享 按鈕
  3. 從分享選項中選擇：
    • AirDrop（傳送到附近的裝置）
    • 訊息
    • 郵件
    • 備忘錄
    • 社群媒體
    • 更多…

適用時機：

  • ✅ 快速分享到 Apple 裝置
  • ✅ 透過「訊息」傳送
  • ✅ 加入「備忘錄」或「提醒事項」
  • ✅ 發布到社群媒體

為什麼 Windows 沒有此功能： Windows 沒有像 macOS 一樣的標準化分享 API。在 Windows 上，請改用「複製」然後貼到您的目標應用程式中。

在側邊欄中管理截圖

截圖會與錄音一起出現在您的「最近快照」區段中。

截圖的顯示方式

視覺指標：

  • 📷 相機圖示（而非 🎥 影片或 🎵 音訊圖示）
  • 圖示背景為紫色
  • 在中繼資料行中顯示尺寸（例如「1920×1080」）
  • 顯示 "Screenshot" 標籤

側邊欄項目範例：

┌─────────────────────────────────────────┐
│ 📷  Screenshot                          │
│     Screenshot_20260209_143052.png      │
│     1920×1080 • 今天 下午 2:30          │
└─────────────────────────────────────────┘

搜尋截圖

搜尋列也適用於截圖：

  1. 在側邊欄頂部的搜尋方塊中輸入
  2. 如果截圖符合搜尋條件就會顯示
  3. 可依檔名和中繼資料搜尋

可以搜尋的內容：

  • 部分檔名（例如「Screenshot_20260209」）
  • 時間關鍵字（例如「今天」、「昨天」）
  • 副檔名（例如「.png」）

排序與整理

截圖的排序方式：

  • 依時間戳記排序（最新在前）
  • 與錄音按時間順序混合排列
  • 最近的擷取會出現在頂部

自動重新整理：

  • 新截圖在擷取後會立即顯示
  • 無需手動重新整理（但需要時可以手動操作）
  • 側邊欄即時更新

匯入外部截圖

您可以將其他來源的截圖匯入 SeaMeet。

支援的影像格式

SeaMeet 可以匯入以下影像類型：

格式副檔名最適合用於
PNG.png截圖、具有透明度的圖形
JPEG.jpg, .jpeg照片、具有漸層的影像
WebP.webp現代網頁影像
GIF.gif簡單動畫、圖形
BMP.bmp未壓縮影像（檔案較大）
TIFF.tiff專業印刷
HEIC/HEIF.heiciPhone 照片（macOS/iOS）

如何匯入影像

方法一：使用匯入按鈕

  1. 在 SeaMeet 中，點擊「開啟檔案」或「匯入」
  2. 在檔案對話框中，變更篩選條件以顯示影像
  3. 選擇您的影像檔案
  4. 點擊「開啟」
  5. 影像會出現在您的側邊欄中

方法二：拖放

  1. 在檔案總管中找到影像檔案
  2. 將它拖曳到 SeaMeet 視窗中
  3. 放在側邊欄區域
  4. 影像會被匯入並出現在列表中

匯入後會發生什麼：

  • SeaMeet 擷取中繼資料（尺寸、檔案大小）
  • 影像會被參照（不會複製）
  • 在側邊欄中以截圖圖示顯示
  • 您可以在截圖檢視器中查看

注意： 匯入的影像會保留在原始位置。SeaMeet 會建立對它們的參照。

實用截圖情境

讓我們看看在現實場景中，截圖在哪些情況下是完美的工具。

情境一：儲存錯誤訊息

情境： 某個應用程式顯示了一個您不理解的錯誤。您想要向技術支援詢問。

為什麼截圖最適合：

  • 擷取確切的錯誤文字
  • 包含所有錯誤代碼
  • 顯示當時的上下文（您正在做什麼）
  • 容易附加到支援工單

操作方式：

  1. 當錯誤出現時，按 Ctrl+Alt+S（Windows）或 Cmd+Shift+S（macOS）
  2. 在錯誤對話框周圍畫出方框
  3. 截圖會自動儲存
  4. 開啟截圖並使用「複製」貼到您的支援聊天/電子郵件中

情境二：記錄設定

情境： 您正在變更一些重要的設定，想要記住變更前的狀態。

為什麼截圖最適合：

  • 精確配置的視覺記錄
  • 比手動記錄更快
  • 不會有抄寫錯誤
  • 容易比較「變更前」和「變更後」

操作方式：

  1. 導覽到設定頁面
  2. 對當前設定拍攝截圖
  3. 進行變更
  4. 再拍攝一張截圖
  5. 現在您有兩種狀態的視覺記錄

情境三：建立逐步說明

情境： 您正在向同事說明如何使用軟體，需要視覺輔助。

為什麼截圖最適合：

  • 精確顯示要點擊哪些按鈕
  • 擷取選單位置
  • 沒有歧義
  • 專業的文件記錄

操作方式：

  1. 自己先執行一遍流程
  2. 在每個重要步驟拍攝截圖
  3. 之後按順序排列並加上說明
  4. 分享完整的指南

情境四：從影片中擷取特定畫面

情境： 您正在觀看影片，想要將特定時刻儲存為影像。

為什麼截圖比影片畫面更好：

  • 比影片畫面擷取的品質更高
  • 即時擷取（無需影片處理）
  • 精確到您想要的時刻
  • 檔案比影片片段小

操作方式：

  1. 在確切的畫面暫停影片
  2. 對影片播放器區域拍攝截圖
  3. 影像以完整品質儲存
  4. 您可以只分享那個時刻

情境五：儲存網頁內容

情境： 您發現網站上有重要資訊，但該資訊可能會變更或消失。

為什麼截圖最適合：

  • 精確保存您看到的頁面
  • 即使網站關閉也能查看
  • 擷取視覺設計和版面配置
  • 比儲存整個頁面更快

操作方式：

  1. 導覽到該頁面
  2. 對相關區段拍攝截圖
  3. 影像會永久儲存
  4. 您擁有永久的視覺記錄

將截圖與其他功能比較

了解何時使用截圖與其他 SeaMeet 功能的差異，有助於您更有效率地工作。

截圖 vs. 影片錄製

面向截圖影片錄製
擷取內容一個瞬間連續動作
檔案大小小（約 2-5 MB）大（約 60 MB/分鐘）
最適合靜態內容、文字、UI動態、流程、示範
擷取時間瞬間完成需要持續時間
品質完美的像素精確度壓縮後可能模糊
聲音無可包含音訊

決策指南：

  • 使用截圖的時機： 您需要特定時刻、文字很重要、或檔案大小很重要
  • 使用影片的時機： 您需要展示流程、動態很重要、或您需要音訊

截圖 vs. Flashback 錄製

面向截圖Flashback 錄製
時間點當下時刻過去（已經發生的）
持續時間瞬間可變（過去 X 分鐘）
檔案大小非常小（約 2-5 MB）中等（可變）
最適合擷取當前狀態恢復錯過的時刻
品質完整解析度影片品質（壓縮）

決策指南：

  • 使用截圖的時機： 您現在看到想要儲存的內容
  • 使用 Flashback 的時機： 您剛錯過某些內容，想要恢復過去幾分鐘的錄製

截圖最佳實務

遵循這些指南以充分利用截圖功能。

拍攝截圖之前

✅ 準備您的螢幕

  • 關閉不相關的視窗
  • 隱藏敏感資訊
  • 最大化您想要擷取的內容
  • 確保良好的對比度和可見度

✅ 考慮用途

  • 誰會看到這張截圖？
  • 哪些資訊需要可見？
  • 在擷取的大小下文字是否可讀？
  • 是否有敏感資料正在顯示？

✅ 整理您的桌面

  • 從視線中移除個人檔案
  • 關閉聊天應用程式
  • 如有需要，隱藏通知區域
  • 呈現專業的外觀

拍攝截圖時

✅ 精確選取

  • 確切擷取您需要的內容（不多不少）
  • 如果有助於理解，包含上下文
  • 避免切掉重要的 UI 元素
  • 在內容周圍保留小邊距

✅ 注意解析度

  • 解析度越高 = 細節越多
  • 但檔案大小也越大
  • 考慮截圖的用途
  • 1080p 通常足以應對大多數情況

✅ 完成前檢查

  • 您擷取了正確的區域嗎？
  • 內容清楚可見嗎？
  • 是否不小心包含了敏感資訊？
  • 文字是否可讀？

拍攝截圖之後

✅ 描述性地重新命名 不要使用：Screenshot_20260209_143052.png 試試：Photoshop_圖層_錯誤.png 或 網站_首頁_設計.png

✅ 定期整理

  • 依專案或主題建立資料夾
  • 刪除臨時/測試截圖
  • 備份重要的擷取
  • 封存不再需要的舊截圖

✅ 分享前檢查

  • 開啟截圖並驗證品質
  • 檢查是否有敏感資訊
  • 確保清楚顯示您想要表達的內容
  • 如有需要，裁切或加註

截圖問題疑難排解

「截圖沒有出現在側邊欄中」

可能的原因和解決方案：

  1. 確認掃描已完成

    • 點擊側邊欄中的重新整理按鈕
    • 等待幾秒鐘讓掃描完成
    • 新截圖應該會出現

  2. 驗證檔案位置

    • 截圖應該在 Documents/SeaMeet/Screenshots/
    • 確認該資料夾存在
    • 確保 PNG 檔案位於該位置

  3. 檢查檔案權限

    • SeaMeet 需要讀取資料夾的權限
    • macOS：檢查「系統偏好設定」→「安全性與隱私」→「檔案與資料夾」
    • Windows：確保沒有防毒軟體阻擋存取

  4. 重新啟動 SeaMeet

    • 有時需要重新掃描
    • 關閉並重新開啟應用程式
    • 檢查截圖是否出現

「截圖品質看起來很差」

解決方案：

  1. 截圖一律為完整品質

    • SeaMeet 以 100% 品質儲存 PNG
    • 檢視器顯示原始檔案
    • 如果看起來品質差，可能是來源內容解析度低

  2. 檢查您的螢幕縮放比例

    • 某些筆記型電腦使用 125% 或 150% 的縮放比例
    • 這可能影響表觀銳利度
    • 截圖會擷取您看到的畫面（已縮放）

  3. 驗證原始內容

    • 如果擷取的是影片，影片本身可能是低解析度
    • 截圖無法增加不存在的細節
    • 截圖精確擷取螢幕上的畫面

「我找不到磁碟上的截圖」

解決方案：

  1. 檢查預設位置

    • Windows：C:\Users\[YourName]\Documents\SeaMeet\Screenshots\
    • macOS：/Users/[YourName]/Documents/SeaMeet/Screenshots/

  2. 搜尋檔案名稱

    • 尋找以「Screenshot_」開頭的檔案
    • 使用系統的檔案搜尋功能
    • 依 PNG 檔案篩選

  3. 檢查 SeaMeet 設定

    • 您可以在「設定」→「儲存」中變更儲存位置
    • 確認其中顯示的截圖資料夾路徑

「複製到剪貼簿無法運作」

解決方案：

  1. 試試按鈕而非鍵盤

    • 點擊檢視器中的「複製」按鈕
    • 有時鍵盤快捷鍵無法運作

  2. 檢查剪貼簿權限

    • 某些安全軟體會阻擋剪貼簿存取
    • 嘗試重新啟動 SeaMeet
    • 用其他應用程式測試

  3. 驗證檔案是否存在

    • 如果截圖已被移動或刪除，複製功能將無法運作
    • 開啟檔案位置確認它存在
    • 如有需要，重新匯入

「分享按鈕沒有出現」

在 Windows 和 Linux 上這是正常的：

  • 分享按鈕只在 macOS 上出現
  • macOS 有內建的 SharingService API
  • Windows 和 Linux 沒有標準化的分享系統
  • 在這些平台上請改用「複製」再貼上
