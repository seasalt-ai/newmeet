歡迎使用 SeaMeet

第一章：歡迎使用 SeaMeet

SeaMeet 是什麼？

想像一下，能夠捕捉電腦上的任何時刻——無論是重要的會議、有趣的視訊通話片段、想保存的教學影片，還是需要錄製的簡報。SeaMeet 是您的個人錄音助手，讓這一切變得無比簡單。

把 SeaMeet 想像成電腦專用的智慧錄音機與攝影機。就像您用手機錄製語音備忘錄或拍攝影片一樣，SeaMeet 讓您錄製電腦螢幕上發生的一切，以及來自麥克風的聲音或電腦發出的聲音。

SeaMeet 能做什麼？

SeaMeet 可以擷取：

🔴 錄音

  • 透過麥克風錄製您的聲音
  • 錄製電腦發出的聲音（影片、音樂、會議音訊）
  • 同時錄製兩者（非常適合線上會議）

🎥 錄影

  • 錄製整個螢幕（簡報、教學影片）
  • 錄製特定應用程式視窗（Zoom 通話、瀏覽器分頁）
  • 錄製螢幕的自訂區域（僅需要的部分）

⏪ Flashback 錄製（您的時光機）

  • 在背景持續錄製
  • 擷取已發生的時刻（最多回溯 2 分鐘）
  • 再也不錯過任何重要時刻

🤖 自動偵測

  • 自動偵測您加入會議的時機
  • 無需您動手即可開始錄製
  • 支援 Zoom、Teams、Google Meet 及 40 多款其他應用程式

為什麼選擇 SeaMeet？

🎯 簡單易用 無需複雜設定。只需開啟應用程式、點擊錄製，即可完成。如果您會使用智慧型手機相機，就能使用 SeaMeet。

💾 本地儲存所有內容 您的錄音保存在電腦上，而非雲端。這意味著：

  • 完全隱私
  • 無需網路
  • 您擁有自己的資料
  • 更快速存取檔案

🛡️ 零資料損失——您的錄音始終安全 SeaMeet 在您錄製時持續且增量地將影片和音訊寫入磁碟，而非僅在停止時才寫入。這意味著：

  • 即使電腦在錄製途中崩潰，您已擷取的內容都會保留
  • 不存在可能在最後失敗的「處理」步驟
  • 長時間錄製（多小時會議、全天工作）永遠不會有風險
  • 即使應用程式被強制關閉，您的影像已安全保存在磁碟上

這與許多錄製工具有根本區別——那些工具將整段錄製緩衝在記憶體中，僅在結束時才寫入檔案，意味著一次崩潰就可能清除數小時的工作成果。使用 SeaMeet，一旦錄製了一秒鐘的影片或音訊，它就已儲存完畢。

⚡ 極速快捷 與需要先「加入」會議的雲端錄製服務不同，SeaMeet 即時啟動。再加上 Flashback，您甚至可以擷取過去的時刻！

🌍 適用於所有場景 SeaMeet 適用於任何應用程式——Zoom、Teams、Google Meet、Discord、Skype、網頁瀏覽器、遊戲等等。只要能發出聲音或出現在螢幕上，SeaMeet 就能錄製。

🎨 精美現代 簡潔直觀的設計，支援淺色和深色模式。提供 16 種語言版本。

👨‍🏫 教育工作者與學生

🎮 內容創作者

系統需求

安裝 SeaMeet 前，請確認您的電腦符合以下需求：

Windows

  • 作業系統： Windows 10 或 Windows 11（64 位元）
  • 處理器： Intel Core i3 或同等 AMD 處理器（或更高規格）
  • 記憶體： 最低 4 GB RAM（錄影建議 8 GB）
  • 儲存空間： 200 MB 供應用程式使用 + 錄音所需空間
  • 音訊： 可正常使用的麥克風（內建或外接）
  • 顯示卡： 任何現代顯示卡（整合顯示卡亦可）

注意： 若您計劃大量使用錄影或 Flashback 功能，SeaMeet 在至少 8 GB RAM 的系統上效能最佳。

macOS

  • 作業系統： macOS 14.2（Sonoma）或更新版本
  • 處理器： Intel 或 Apple Silicon（M1/M2/M3/M4）
  • 記憶體： 最低 4 GB RAM（建議 8 GB）
  • 儲存空間： 200 MB 供應用程式使用 + 錄音所需空間
  • 音訊： 可正常使用的麥克風

如果我的電腦較舊怎麼辦？

別擔心！SeaMeet 仍可運作，但您可能需要：

  • 僅使用純音訊錄製（不含影片）
  • 選擇較低的品質設定
  • 縮短 Flashback 緩衝時間
  • 錄製時關閉其他應用程式

安裝指南

步驟 1：下載 SeaMeet

  1. 前往 SeaMeet 下載頁面（由您的管理員或組織提供）
  2. 點擊適合您作業系統的下載按鈕：
    • Windows： 尋找 SeaMeet-Setup.exe 或 SeaMeet-Installer.exe
    • Mac： 尋找 SeaMeet.dmg 或 SeaMeet.pkg
  3. 等待下載完成

步驟 2：在 Windows 上安裝

  1. 找到下載的檔案

    • 通常位於 Downloads（下載）資料夾
    • 檔案名稱：SeaMeet-Setup.exe 或類似名稱

  2. 執行安裝程式

    • 雙擊下載的檔案
    • 若 Windows 顯示安全警告，點擊「更多資訊」，然後點擊「仍要執行」
    • 此警告出現是因為 SeaMeet 是新應用程式

  3. 按照安裝精靈操作

    • 點擊「下一步」開始
    • 選擇安裝位置（或接受預設位置）
    • 點擊「安裝」
    • 等待安裝完成
    • 點擊「完成」

  4. 啟動 SeaMeet

    • 在點擊「完成」前勾選「啟動 SeaMeet」，或
    • 在「開始」功能表中找到 SeaMeet
    • 雙擊桌面上的 SeaMeet 圖示（若已建立）

步驟 3：在 Mac 上安裝

  1. 找到下載的檔案

    • 通常位於 Downloads（下載）資料夾
    • 檔案名稱：SeaMeet.dmg

  2. 開啟 DMG 檔案

    • 雙擊 .dmg 檔案
    • 視窗將開啟並顯示 SeaMeet 應用程式

  3. 安裝應用程式

    • 方法 A（建議）： 將 SeaMeet 圖示拖曳到您的「應用程式」資料夾
    • 方法 B： 雙擊 SeaMeet 圖示直接執行（不會永久安裝）

  4. 首次啟動（重要！）

    • 開啟您的「應用程式」資料夾
    • 雙擊 SeaMeet
    • 若看到安全警告：
      • 點擊「取消」
      • 前往「系統偏好設定」→「安全性與隱私權」→「一般」
      • 點擊 SeaMeet 相關訊息旁的「仍要開啟」
      • 在確認對話框中點擊「開啟」
    • 此狀況僅在首次啟動時出現

  5. 授予權限（macOS） SeaMeet 首次啟動時，將要求以下幾項權限：

    • 麥克風存取： 點擊「好」以允許
    • 螢幕錄製： 前往「系統偏好設定」→「安全性與隱私權」→「隱私權」→「螢幕錄製」，勾選 SeaMeet
    • 輔助使用功能（選用）： 某些功能可能要求輔助使用功能權限

步驟 4：首次啟動設定

首次開啟 SeaMeet 時：

  1. 歡迎畫面

    • 您將看到歡迎訊息
    • 應用程式的簡短概覽

  2. 選擇儲存位置

    • SeaMeet 將詢問錄音的儲存位置
    • 預設位置：Documents/SeaMeet Recordings
    • 您可以稍後在「設定」中更改

  3. 快速導覽（選用）

    • 部分版本包含介面的簡短導覽
    • 若您想略過可以跳過

  4. 準備就緒！

    • SeaMeet 主視窗出現
    • 前往第二章開始您的第一次錄音

安裝問題排除

問題：「安裝失敗」或出現錯誤訊息

解決方案：

  1. 確認您在電腦上擁有系統管理員權限
  2. 安裝期間暫時停用防毒軟體
  3. 重新下載安裝程式（可能已損毀）
  4. 重新啟動電腦後再試

問題：「此應用程式無法在您的電腦上執行」（Windows）

解決方案：

  • 確認您下載的是 64 位元版本（而非 32 位元）
  • 確認您的 Windows 已更新至最新版本
  • 若使用工作電腦，請聯絡您的 IT 部門

問題：「SeaMeet 已損毀且無法開啟」（Mac）

解決方案：

  1. 這是 macOS 的安全功能
  2. 前往「系統偏好設定」→「安全性與隱私權」→「一般」
  3. 尋找有關 SeaMeet 被封鎖的訊息
  4. 點擊「仍要開啟」
  5. 再次嘗試啟動 SeaMeet

問題：SeaMeet 已開啟但無法錄製

解決方案：

  1. 確認麥克風已插入並正常運作
  2. Mac 上：檢查「系統偏好設定」→「安全性與隱私權」→「麥克風」（確認 SeaMeet 已勾選）
  3. Windows 上：檢查「隱私權設定」→「麥克風」
  4. 授予權限後重新啟動 SeaMeet

仍然遇到問題？

  • 確認您的電腦符合系統需求
  • 確認您有足夠的可用磁碟空間（至少 1 GB）
  • 關閉其他可能正在使用麥克風的應用程式
  • 提供具體的錯誤訊息聯絡支援
