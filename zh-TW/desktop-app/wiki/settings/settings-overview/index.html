設定總覽

第 14 章：設定總覽

簡介

歡迎來到 SeaMeet 的控制中心！如果說主介面是駕駛艙，讓你駕駛飛機，那麼設定選單就是維修站，讓你微調引擎、調整座椅、自訂飛行體驗。本章將向你介紹如何開啟設定選單，並帶你了解其中各個分類的功能。

讀完本章後，你將清楚知道每個設定的位置，以及各個分類所控制的內容。把這一章視為深入探索各個特定章節前的導覽之旅。

本章目標

閱讀本章後，你將能夠：

  • 從 SeaMeet 的多個位置開啟設定選單
  • 了解 8 大設定分類及其功能
  • 快速切換不同的設定區段
  • 辨識設定介面中的視覺指示器與圖示
  • 根據需求判斷應調整哪些設定

設定是什麼，為什麼重要？

把 SeaMeet 的設定想成智慧型手機上的偏好設定。你不需要更改設定就能使用基本功能，但自訂設定能讓應用程式完全按照「你的方式」運作。就像穿一件量身訂製的衣服，而不是一件萬能尺碼的衣服。

設定之所以重要，在於它讓你能夠：

個人化你的體驗

  • 選擇偏好的語言（多達 16 種語言！）
  • 根據眼睛的舒適度設定淺色或深色模式
  • 選擇錄音的儲存位置
  • 設定符合你習慣的快捷鍵

最佳化效能

  • 根據麥克風的能力調整音訊品質
  • 設定視訊解析度以符合螢幕和儲存需求
  • 根據電腦效能啟用或停用功能
  • 管理 Flashback 錄音的記憶體使用量

確保可靠性

  • 設定自動偵測，確保不錯過任何會議
  • 在儲存空間不足前設定警告
  • 為你的裝置選擇合適的音訊設備
  • 從一開始就正確設定權限

預先解決問題

  • 若別人反映你的聲音太小或太大，調整麥克風增益
  • 設定預設錄音模式，避免忘記切換
  • 設定自動開始選項，讓錄音在你需要時自動啟動
  • 若電腦較舊或較慢，啟用低記憶體模式

如何開啟設定選單

SeaMeet 提供多種方式開啟設定，就像你可以用密碼、指紋或臉部辨識解鎖手機一樣。以下是所有開啟設定的方法：

方法 1：從左側邊欄

這是存取設定最常用的方式。請看 SeaMeet 主視窗左側的垂直側邊欄。

步驟說明：

  1. 找到含有「錄音」、「視訊」、「Flashback」等圖示的左側邊欄。

  2. 找到設定圖示 — 它看起來像齒輪（⚙️）。

  3. 點擊設定圖示。

  4. 主要區域會從顯示錄音內容切換為顯示設定面板。

方法 2：從選單列（Windows）

如果你使用 Windows，也可以透過視窗頂端的傳統選單列存取設定。

步驟說明：

  1. 點擊頂端選單列中的 「File」（檔案）。

  2. 在下拉選單中找到 「Settings」（設定） 或 「Preferences」（偏好設定）。

  3. 點擊以開啟設定面板。

注意： 此方法可能因你的 Windows 版本和 SeaMeet 版本而略有不同。

方法 3：鍵盤快捷鍵（Windows）

對於鍵盤愛好者，有一個快速的快捷鍵：

Windows 系統： 按下 Ctrl + 逗號（,）

這是許多 Windows 應用程式（包括 Microsoft Office 等）中常用的快捷鍵，你可能早已熟悉。

使用方式：

  1. 確保 SeaMeet 是作用中的視窗（如果不確定，請點擊一下）。
  2. 按住 Ctrl 鍵。
  3. 在按住 Ctrl 的同時，按下逗號鍵。
  4. 設定會立即開啟。

方法 4：從系統匣選單（Windows）

SeaMeet 會在系統匣中執行（即靠近時鐘的那個區域，有許多小圖示）。你也可以從那裡存取設定。

步驟說明：

  1. 在系統匣中找到 SeaMeet 圖示（螢幕右下角）。

    • 你可能需要點擊向上的小箭頭來查看隱藏圖示。

  2. 在 SeaMeet 圖示上按右鍵。

  3. 會出現一個包含各種選項的快顯選單。

  4. 從選單中點擊 「Settings」（設定）。

為何使用此方法？

  • SeaMeet 最小化時非常方便。
  • 無需開啟主視窗即可快速存取。
  • 在趕時間時非常實用。

方法 5：從 Floater 選單

還記得第 12 章的浮動控制小工具（Floater）嗎？你也可以從那裡存取設定。

步驟說明：

  1. 點擊 Floater 以展開它（如果它處於緊湊模式）。

  2. 找到設定齒輪圖示或選單選項。

  3. 點擊以開啟設定。

注意： 確切位置可能因你的 Floater 設定而有所不同，但設定選項始終可從展開的 Floater 視圖中存取。

左側：分類清單

  • 顯示所有可用的設定分類。
  • 點擊任意分類即可查看其設定。
  • 目前選取的分類會以高亮顯示。
  • 某些分類名稱旁有圖示。

右側：設定內容

  • 顯示所選分類的所有設定。
  • 每個設定都有說明標籤。
  • 設定使用不同類型的控制項：
    • 切換開關（開/關）— 用於是/否的選擇
    • 下拉選單 — 用於從多個選項中選擇
    • 文字欄位 — 用於輸入檔案路徑或名稱
    • 滑桿 — 用於調整音量等數值
    • 按鈕 — 用於執行「瀏覽」或「重設」等操作

底部：操作按鈕

  • 套用 — 儲存你的變更（有時自動儲存）
  • 取消 — 放棄變更並關閉設定
  • 重設為預設值 — 將所有設定恢復為出廠預設值
  • 搜尋 — 快速找到特定設定（某些版本提供）

8 大設定分類說明

SeaMeet 將設定整理為 8 個邏輯分類。把這些分類想像成檔案櫃的抽屜 — 每個抽屜裝著相關的東西：

分類 1：一般設定

圖示： 通常是齒輪或房屋圖示 控制內容： 應用程式的基本行為和外觀

典型設定包括：

  • 啟動行為 — SeaMeet 是否應在電腦開機時自動開啟？
  • 最小化至系統匣 — 關閉視窗時 SeaMeet 是否繼續在背景執行？
  • 主題選擇 — 淺色模式、深色模式或自動（隨系統設定）
  • 通知偏好 — 哪些事件應觸發通知？
  • 更新設定 — SeaMeet 是否應自動檢查更新？

何時使用此分類：

  • 首次安裝 SeaMeet 並想設定基本偏好時
  • 想改變應用程式的外觀和風格時
  • 想控制 SeaMeet 在背景的行為時
  • 設定自動啟動時

比喻： 這就像調整汽車的基本設定 — 燈光是否自動開啟？是否記住你的座椅位置？鑰匙留在車內時是否發出警示聲？

分類 2：儲存設定

圖示： 通常是硬碟或資料夾圖示 控制內容： 錄音的儲存位置和方式

典型設定包括：

  • 儲存位置 — 錄音應存入哪個資料夾？
  • 儲存管理 — 自動清理舊錄音
  • 檔案整理 — 檔案的命名和排序方式
  • 磁碟空間警告 — 在空間不足時發出警示
  • 備份設定 — 錄音是否應備份至雲端儲存？

何時使用此分類：

  • 想更改錄音的儲存位置（例如移至外接硬碟）時
  • 磁碟空間不足，需要管理儲存空間時
  • 想以特定方式整理錄音時
  • 設定自動清理以防止累積時

比喻： 這就像整理衣櫃 — 決定哪個抽屜放哪件衣服、如何標記箱子，以及何時捐出舊物為新物騰出空間。

重要提示： 第 15 章（儲存設定）會詳細介紹此內容，逐步帶你了解每個選項。

分類 3：音訊設定

圖示： 通常是麥克風或喇叭圖示 控制內容： 與錄音和播放相關的所有音訊設定

典型設定包括：

  • 預設麥克風 — 錄音時使用哪支麥克風
  • 麥克風增益 — 你的聲音應以多大的音量錄製
  • 系統音訊來源 — 要擷取哪個音訊輸出
  • 藍牙警告 — 使用藍牙麥克風時的提示
  • 音訊格式 — 音訊錄音的偏好格式（MP3、WAV 等）
  • 取樣率 — 音訊品質等級（44.1kHz、48kHz 等）

何時使用此分類：

  • 別人反映你在錄音中聲音太小或太大時
  • 擁有多支麥克風並想設定預設麥克風時
  • 使用藍牙耳機並需要延遲警告時
  • 想更改音訊品質或檔案格式時
  • 排除音訊錄音問題時

比喻： 這就像調整音樂廳的音響系統 — 選擇使用哪些麥克風、設定正確的音量，並確保聲學效果完美。

重要提示： 第 16 章（音訊設定）會詳細介紹此內容，深入說明麥克風選擇、增益控制等。

分類 4：視訊設定

圖示： 通常是攝影機或螢幕圖示 控制內容： 與螢幕錄製相關的所有設定

典型設定包括：

  • 預設錄製模式 — 全螢幕、視窗或區域
  • 視訊品質 — 解析度（1080p、720p、480p）
  • 影格速率 — 影片的流暢度（30fps、60fps）
  • 螢幕選擇 — 錄製哪個螢幕（如有多個螢幕）
  • 視訊格式 — 視訊檔案的偏好格式（MP4、WebM 等）
  • 硬體加速 — 使用 GPU 提升效能
  • 游標錄製 — 滑鼠游標是否應顯示？
  • 游標效果 — 高亮顯示點擊、更改游標大小等

何時使用此分類：

  • 想設定預設錄製模式以減少操作步驟時
  • 需要在品質與檔案大小之間取得平衡時
  • 擁有多個螢幕並需要指定錄製哪個時
  • 錄製遊戲需要高影格速率（60fps）時
  • 製作教學影片並需要游標效果時

比喻： 這就像設置電影攝影機 — 選擇底片品質、決定使用哪個鏡頭、設定流暢動作的影格速率，以及決定是否在畫面中顯示攝影師的手。

重要提示： 第 17 章（視訊設定）會詳細介紹此內容，說明所有技術術語並協助你選擇正確的設定。

分類 5：Flashback 設定

圖示： 通常是循環箭頭或時鐘圖示（代表「倒轉」） 控制內容： 時光機錄音功能

典型設定包括：

  • 自動開始 Flashback — Flashback 是否應在 SeaMeet 啟動時自動開始？
  • 緩衝時長 — 保留多長時間的內容（10-120 秒）
  • 音訊緩衝長度 — 保留多少音訊（固定為 30 秒）
  • 視訊品質 — Flashback 視訊的解析度（通常低於一般錄製）
  • 低記憶體模式 — 為較舊的電腦減少記憶體使用量
  • 緩衝持久性 — 切換應用程式時保留緩衝？

何時使用此分類：

  • 想讓 Flashback 隨時待命（自動開始）時
  • 需要在可回溯的時間長度與記憶體使用量之間取得平衡時
  • 電腦較舊需要節省 RAM 時
  • 想自訂 Flashback 的行為時

比喻： 這就像設定保全攝影機的數位錄影機 — 決定保留多少天的影像、設定錄製品質，以及管理持續錄製的儲存空間。

重要提示： 第 18 章（Flashback 設定）會詳細介紹此內容，協助你找到緩衝時長與效能之間的完美平衡。

分類 6：自動錄音設定

圖示： 通常是放大鏡或機器人/自動化圖示 控制內容： 自動會議偵測與錄製

典型設定包括：

  • 啟用自動偵測 — 功能的主開關
  • 偵測靈敏度 — 偵測的積極程度
  • 預設動作 — 立即開始錄製或僅通知？
  • 各應用程式權限 — 哪些應用程式可觸發自動錄製
  • 偵測方式 — 監控哪些訊號（視窗標題、音訊等）
  • 開始前的延遲 — 偵測後等待幾秒再開始
  • 會議結束後的動作 — 會議結束時要做什麼

何時使用此分類：

  • 首次設定 SeaMeet 並啟用自動偵測時
  • 想微調哪些應用程式觸發錄製時
  • 發現自動偵測過於靈敏或不夠靈敏時
  • 想讓 SeaMeet 在開始前稍作等待時
  • 自訂會議結束後的動作時

比喻： 這就像訓練一個智慧助理 — 教它辨識你是否在開會、決定哪些會議重要，以及告訴它偵測到會議時如何回應。

重要提示： 第 19 章（自動錄音設定）會詳細介紹此內容，逐步帶你設定 47 種以上支援應用程式的權限。

分類 7：語言與地區設定

圖示： 通常是地球或旗幟圖示 控制內容： 顯示語言、地區格式和在地化

典型設定包括：

  • 顯示語言 — SeaMeet 的介面語言（16 種以上！）
  • 日期格式 — 日期的顯示方式（MM/DD/YYYY 或 DD/MM/YYYY）
  • 時間格式 — 12 小時制（AM/PM）或 24 小時制
  • 時區 — 確保錄音時間戳記準確
  • 一週的第一天 — 星期日或星期一（用於日曆視圖）
  • 數字格式 — 小數點分隔符號（句號或逗號）

支援的語言包括：

  1. 英文
  2. 西班牙文（Español）
  3. 法文（Français）
  4. 德文（Deutsch）
  5. 義大利文（Italiano）
  6. 葡萄牙文（Português）
  7. 荷蘭文（Nederlands）
  8. 俄文（Русский）
  9. 簡體中文（简体中文）
  10. 繁體中文（繁體中文）
  11. 日文（日本語）
  12. 韓文（한국어）
  13. 阿拉伯文（العربية）
  14. 印地文（हिन्दी）
  15. 土耳其文（Türkçe）
  16. 波蘭文（Polski）

何時使用此分類：

  • 想以母語使用 SeaMeet 時
  • 日期/時間格式不符合你所在地區的慣例時
  • 跨時區工作並需要準確的時間戳記時
  • 預設語言不是你偏好的語言時

比喻： 這就像設定 GPS 導航系統 — 為語音指引選擇偏好語言、選擇英里或公里，以及設定你的所在時區。

重要提示： 此內容與主題設定和視覺自訂一同在第 20 章（語言與外觀）中詳細介紹。

分類 8：關於 SeaMeet

圖示： 通常是資訊（i）圖示或 SeaMeet 標誌 控制內容： 應用程式資訊，並非真正的「設定」

你將在此找到：

  • 版本號碼 — 你正在使用哪個版本的 SeaMeet
  • 建置日期 — 此版本的編譯時間
  • 授權資訊 — 你的授權類型和到期日
  • 開發者致謝 — 製作 SeaMeet 的人員
  • 第三方授權 — 所使用的開源元件
  • 檢查更新 — 手動檢查更新的按鈕
  • 支援連結 — 說明、意見回饋和聯絡資訊

何時使用此分類：

  • 需要知道你的版本（用於支援請求）時
  • 檢查是否有可用更新時
  • 尋找說明資源或聯絡資訊時
  • 想了解更多關於 SeaMeet 開發資訊時

比喻： 這就像餐廳菜單上的「關於我們」頁面 — 它述說餐廳的歷史、介紹主廚，並展示他們的獎項和認證。

了解設定控制項

不同的設定使用不同類型的控制項。以下是辨識和使用每種類型的指南：

切換開關（開/關）

外觀： 一個可向左（關）或向右（開）滑動的水平開關。開啟時通常有顏色（通常是藍色或綠色）。

設定名稱          [━━●──]   ← 關閉位置
                  [──●━━]   ← 開啟位置（有顏色）

使用方式：

  • 點擊開關以切換。
  • 開關會滑動並改變顏色。
  • 更改通常立即生效。

SeaMeet 中的範例：

  • 自動開始 Flashback
  • 最小化至系統匣
  • 啟用自動偵測
  • 在錄音中顯示游標

比喻： 就像牆上的電燈開關 — 往一邊撥是開，另一邊是關。

下拉選單

外觀： 一個顯示目前選擇的矩形欄位，右側有向下箭頭。

錄製品質          [1080p HD        ▼]
                   ↑ 目前值       ↑ 點擊查看
                                    所有選項

使用方式：

  1. 點擊下拉選單（或箭頭）。
  2. 選項清單出現在下方。
  3. 點擊你想要的選項。
  4. 下拉選單關閉，顯示你的新選擇。

SeaMeet 中的範例：

  • 視訊品質（1080p、720p、480p）
  • 影格速率（30fps、60fps）
  • 音訊格式（MP3、WAV、WebM）
  • 預設錄製模式（全螢幕、視窗、區域）
  • 顯示語言（16 種選項）

比喻： 就像餐廳菜單 — 你看到目前餐盤上的選擇，但可以打開菜單選擇不同的食物。

文字輸入欄位

外觀： 一個空白或預先填寫的矩形框，供你輸入文字。

儲存位置         [C:\Users\你\錄音              ] [瀏覽...]
                   ↑ 點此輸入                    ↑ 或點擊
                                                  瀏覽資料夾

使用方式：

  1. 點擊文字欄位內部。
  2. 輸入文字（或先清除現有文字）。
  3. 完成後按 Tab 鍵或點擊其他地方。

特殊功能：

  • 瀏覽按鈕 — 通常在路徑欄位旁，開啟檔案瀏覽器
  • 預留位置文字 — 灰色文字顯示範例輸入
  • 驗證 — 如果你輸入無效內容，可能變成紅色

SeaMeet 中的範例：

  • 儲存目錄路徑
  • 檔案命名模式
  • 自訂鍵盤快捷鍵
  • 麥克風裝置名稱（有時）

比喻： 就像填寫醫生辦公室的表格 — 你在空白欄位中填寫資訊。

滑桿

外觀： 一個水平條，帶有可向左或向右拖曳的控點。

麥克風增益        [━●━━━━━━━━━━━] 45%
                   ↑ 拖曳此旋鈕
                     向左（較小聲）
                     或向右（較大聲）

使用方式：

  1. 點擊並按住滑桿控點（或旋鈕）。
  2. 向左拖曳以減少數值。
  3. 向右拖曳以增加數值。
  4. 滿意時放開。

替代方式： 點擊滑桿條上的任意位置以跳至該位置。

SeaMeet 中的範例：

  • 麥克風增益/音量
  • 偵測靈敏度（用於自動錄製）
  • 緩衝時長（用於 Flashback）
  • 品質/壓縮平衡

比喻： 就像音響上的音量旋鈕 — 向左轉是較小聲，向右轉是較大聲。

按鈕

外觀： 帶有文字標籤的矩形或圓角按鈕。

[檢查更新] [重設為預設值] [瀏覽...]

使用方式：

  • 只需點擊一次按鈕。
  • 立即發生某事（開啟對話框、執行動作等）。

按鈕類型：

  • 操作按鈕 — 執行動作（檢查更新、瀏覽）
  • 重設按鈕 — 恢復預設值（重設為預設值）
  • 導覽按鈕 — 前往其他畫面（進階設定）
  • 確認按鈕 — 儲存或取消變更（套用、確定、取消）

SeaMeet 中的範例：

  • 瀏覽（用於選擇資料夾）
  • 重設為預設值（適用於任何分類）
  • 檢查更新（在關於區段）
  • 套用/儲存變更
  • 測試麥克風（在音訊設定中）

比喻： 就像電梯按鈕 — 按一次，電梯就會做某事（上樓、下樓、開門）。

核取方塊

外觀： 一個可勾選（✓）或空白的小方格。

☐ 電腦開機時啟動 SeaMeet
☑ 關閉時最小化至系統匣
☐ 顯示錄音通知

使用方式：

  • 點擊核取方塊以切換。
  • 啟用時出現勾號。
  • 再次點擊以取消勾選。

與切換開關的差異：

  • 核取方塊通常用於可選擇多個選項的情況
  • 切換開關用於單一的開/關選擇
  • SeaMeet 主要使用切換開關，但在進階設定中可能看到核取方塊

比喻： 就像待辦清單 — 勾選已完成的項目。

設定行為：立即生效與套用後生效

並非所有設定在更改後都以相同方式生效。有兩種主要行為：

立即生效的設定

這些設定在你更改後立即生效 — 不需要點擊「套用」或「儲存」。

範例：

  • 主題變更（淺色/深色模式）
  • 語言選擇
  • 切換開關（大部分）
  • 音量/增益滑桿（你可以即時聽到變化）

如何辨識：

  • 變更立即發生
  • 不需要「套用」按鈕
  • 通常是視覺變更或簡單的切換

套用後生效的設定

這些設定需要你點擊「套用」、「確定」或「儲存」後才能生效。

範例：

  • 儲存位置路徑
  • 預設錄製模式
  • 複雜的音訊/視訊設定
  • 某些權限設定

如何辨識：

  • 出現「套用」或「儲存」按鈕
  • 你可能看到「未儲存的變更」指示
  • 確認前不會發生變更

重要： 如果你更改設定後點擊「取消」，你的變更將被捨棄！如果想保留變更，請務必點擊「套用」或「確定」。

搜尋功能（如果可用）

某些版本的 SeaMeet 在設定面板頂端提供搜尋框，這非常實用！

如何使用搜尋：

  1. 找到搜尋框（通常顯示「搜尋設定...」或有放大鏡圖示）。

  2. 點擊搜尋框並輸入關鍵字：

    • 「麥克風」→ 顯示所有與麥克風相關的設定
    • 「儲存」→ 顯示儲存和保存位置的設定
    • 「品質」→ 顯示視訊和音訊品質設定
    • 「快捷鍵」→ 顯示鍵盤快捷鍵設定

  3. 隨著你的輸入，設定清單會篩選為僅顯示相符的項目。

  4. 點擊結果以直接跳至該設定。

為何搜尋有用：

  • 無需瀏覽分類即可快速找到設定
  • 發現你不知道存在的相關設定
  • 不確定設定在哪個分類時非常方便
  • 當你確切知道想更改什麼時節省時間

常見的設定工作流程

以下是一些典型的情境和精確的處理步驟：

情境 1：首次設定

你是 SeaMeet 的新用戶，想設定基本偏好：

  1. 開啟設定（點擊左側邊欄的齒輪圖示）

  2. 前往「一般」

    • 設定你偏好的主題
    • 視需要啟用「最小化至系統匣」
    • 視需要啟用「隨電腦開機啟動」

  3. 前往「儲存」

    • 確認或更改儲存位置
    • 設定磁碟空間警告

  4. 前往「音訊」

    • 選擇預設麥克風
    • 測試麥克風並調整增益
    • 如使用無線耳機，檢查藍牙警告

  5. 前往「語言」

    • 選擇你偏好的顯示語言

  6. 點擊「套用」 儲存所有變更

  7. 前往「關於」 記下你的版本號碼（支援時很有用）

情境 2：更改錄音的儲存位置

你的 C: 磁碟快滿了，想將錄音移至外接硬碟：

  1. 開啟設定

  2. 在左側邊欄點擊**「儲存」**

  3. 找到**「儲存位置」** 或**「錄音目錄」**

  4. 點擊**「瀏覽」** 按鈕

  5. 在檔案瀏覽器中導覽至你的外接硬碟

    • 範例：D:\SeaMeet 錄音

  6. 選擇或建立資料夾

  7. 在檔案瀏覽器中點擊**「確定」**

  8. 在設定中點擊**「套用」**

  9. 選用： 使用檔案總管將現有錄音移至新位置

情境 3：設定自動偵測

你想讓 SeaMeet 自動偵測 Zoom 會議：

  1. 開啟設定

  2. 點擊**「自動錄音」**

  3. 啟用「自動偵測」（切換開關）

  4. 在應用程式清單中找到 Zoom

  5. 啟用 Zoom 的權限（切換或核取方塊）

  6. 選擇預設動作： 立即開始錄製或僅通知？

  7. 視需要調整靈敏度（滑桿）

  8. 點擊**「套用」**

  9. 測試： 開啟 Zoom 並開始會議，看 SeaMeet 是否偵測到

情境 4：為較舊的電腦最佳化

你的電腦有幾年歷史，錄音時運行緩慢：

  1. 開啟設定

  2. 前往「視訊」

    • 將視訊品質降低至 720p 或 480p
    • 將影格速率設為 30fps（而非 60fps）
    • 如果造成問題，停用硬體加速

  3. 前往「Flashback」

    • 啟用「低記憶體模式」
    • 將緩衝時長縮短至 30-60 秒（而非 120 秒）

  4. 前往「音訊」

    • 如果可用，選擇較低的取樣率（44.1kHz 而非 48kHz）

  5. 前往「儲存」

    • 啟用自動清理以防止磁碟空間問題

  6. 點擊**「套用」**

  7. 測試錄音，看效能是否改善

情境 5：準備專業簡報

你需要為工作錄製一段高品質的簡報：

  1. 開啟設定

  2. 前往「視訊」

    • 將品質設為 1080p（或最高可用設定）
    • 將影格速率設為 60fps 以獲得流暢動作
    • 啟用「錄製游標」
    • 如果可用，啟用「高亮顯示游標點擊」

  3. 前往「音訊」

    • 選擇你最好的麥克風
    • 將增益設為最佳水準（先測試！）
    • 選擇高品質格式（最佳選 WAV，或選高位元率 MP3）

  4. 前往「一般」

    • 停用通知以防止干擾
    • 確保「最小化至系統匣」已啟用

  5. 前往「儲存」

    • 確認磁碟空間足夠（HD 視訊佔用大量空間！）

  6. 點擊**「套用」**

  7. 進行 30 秒的測試錄製，確認一切看起來和聽起來都完美

設定技巧

技巧 1：「重設為預設值」安全網

如果你更改了設定後某些功能停止運作，不要慌張！每個分類都有「重設為預設值」按鈕，可將該區段恢復為出廠設定。

使用方式：

  1. 前往有問題的分類。
  2. 點擊「重設為預設值」（通常在底部）。
  3. 確認重設。
  4. 以乾淨的設定重試。

注意： 這會重設該分類中的所有設定，而不只是你最後更改的那個。

技巧 2：匯出/匯入設定（如果可用）

某些版本的 SeaMeet 允許你將設定匯出至檔案。這非常適合：

  • 備份你的偏好設定
  • 將設定轉移至另一台電腦
  • 與同事分享最佳化的設定

尋找： 「匯出設定」或「匯入設定」按鈕，通常在「一般」分類或設定面板底部。

技巧 3：鍵盤導覽

你可以在不使用滑鼠的情況下導覽設定：

  • Tab — 移至下一個控制項
  • Shift + Tab — 移至上一個控制項
  • 空白鍵 — 切換核取方塊或啟動按鈕
  • 方向鍵 — 導覽下拉選項或調整滑桿
  • Enter — 確認選擇或啟動按鈕

這對於無障礙需求或滑鼠無法使用時特別有用。

技巧 4：懸停以取得說明

許多設定都有實用的工具提示。將滑鼠懸停在設定名稱或控制項上，可查看額外資訊。

範例： 懸停在「麥克風增益」上可能顯示：「如果錄音太小聲或太大聲，請調整此項目。預設值為 50%。」

技巧 5：設定通常自動儲存

在大多數情況下，SeaMeet 在你更改設定時會自動儲存。但某些複雜的更改需要你點擊「套用」。

需要點擊「套用」的跡象：

  • 「套用」按鈕可見且可點擊
  • 你看到「未儲存的變更」等文字
  • 設定涉及檔案路徑或外部資源

有疑問時： 點擊「套用」！確認變更不會有任何損失。

了解設定的持久性

這是一個重要的概念：設定儲存在你的使用者設定檔中，在各個使用工作階段之間持續存在。

這代表：

  • 關閉並重新開啟 SeaMeet 後設定仍然存在
  • 重新啟動電腦後設定保持不變
  • 設定與你的 Windows/Mac 使用者帳戶綁定
  • 如果你有多個使用者帳戶，每個帳戶有各自的設定

設定的儲存位置（技術資訊）：

  • Windows： 通常在你的使用者設定檔資料夾中，通常在 AppData 內
  • macOS： 在你的使用者 Library 資料夾中
  • 你不需要直接存取這些檔案 — 使用設定 UI 即可

例外情況：

  • 某些可攜式版本可能將設定儲存在應用程式資料夾中
  • 企業部署可能使用集中式設定
  • 重新安裝 SeaMeet 通常會保留使用者設定

設定安全性與隱私

SeaMeet 的設定存在於你的本機電腦，通常不包含敏感資訊。但是：

設定中包含的內容：

  • 檔案路徑（可能洩露資料夾結構）
  • 應用程式偏好設定（你使用哪些功能）
  • 硬體選擇（你偏好哪支麥克風）
  • 無密碼或帳戶憑證

隱私考量：

  • 設定不包括你的實際錄音（只有儲存位置）
  • 自動偵測設定顯示你使用哪些應用程式（但不包含使用資料）
  • 設定不會同步至雲端（所有內容保留在本機）

企業環境：

  • IT 管理員可能可以查看或管理設定
  • 群組原則可能覆蓋某些設定
  • 如有疑慮，請向 IT 部門諮詢

設定問題排除

問題 1：設定無法儲存

症狀： 你更改了設定，但重新開啟設定後它恢復原狀。

解決方法：

  1. 確保你點擊了「套用」 — 某些設定需要明確儲存
  2. 檢查磁碟空間 — 如果磁碟已滿，設定無法儲存
  3. 以管理員身分執行 — 嘗試右鍵點擊 SeaMeet 並選擇「以管理員身分執行」
  4. 檢查權限 — 確保你有寫入使用者設定檔資料夾的存取權
  5. 重新安裝 SeaMeet — 先備份錄音，再重新安裝

問題 2：設定呈灰色（無法更改）

症狀： 某些設定可見但無法更改（呈灰色或停用狀態）。

常見原因：

  • 另一個設定停用了它 — 例如，如果視訊錄製被停用，就無法設定視訊品質
  • 管理員/企業限制 — 你的組織可能鎖定某些設定
  • 功能不可用 — 該功能可能不包含在你的版本中
  • 硬體限制 — 某些設定需要特定硬體

解決方法：

  1. 檢查是否需要先啟用父設定
  2. 如果是企業限制，請聯絡 IT 部門
  3. 檢查 SeaMeet 版本（某些功能特定於某些版本）
  4. 確認你的硬體支援該功能

問題 3：設定 UI 顯示異常

症狀： 設定看起來不對勁、重疊或無法正確顯示。

解決方法：

  1. 調整視窗大小 — 嘗試將 SeaMeet 視窗放大
  2. 重新啟動 SeaMeet — 關閉並重新開啟應用程式
  3. 更新繪圖驅動程式 — 過時的驅動程式可能導致 UI 問題
  4. 更改顯示縮放 — 如果使用高 DPI（4K），暫時嘗試 100% 縮放
  5. 重新安裝 SeaMeet — 如果一切都失敗，全新安裝通常可修復 UI 問題

問題 4：找不到設定

症狀： 你知道某個設定存在，但找不到它。

解決方法：

  1. 使用搜尋 — 在設定搜尋框中輸入關鍵字
  2. 檢查所有分類 — 它可能在出乎意料的分類中
  3. 查看進階設定 — 某些設定隱藏在「進階」按鈕後面
  4. 更新 SeaMeet — 該設定可能在更新版本中
  5. 閱讀說明文件 — 每個設定章節都列出所有可用選項

進階：設定檔案位置（適合進階使用者）

如果你是技術型使用者，需要直接存取設定，以下是找到它們的位置：

Windows

標準安裝：

C:\Users\[你的使用者名稱]\AppData\Roaming\SeaMeet\

檔案名稱可能包括：

  • settings.json
  • config.json
  • preferences.json
  • SeaMeet.config

存取方式：

  1. 按下 Windows + R
  2. 輸入 %AppData%\SeaMeet 並按 Enter
  3. 尋找設定檔案

警告： 手動編輯這些檔案可能損壞 SeaMeet。請務必先備份！

macOS

標準位置：

~/Library/Application Support/SeaMeet/

或在偏好設定中：

~/Library/Preferences/com.seameet.app.plist

存取方式：

  1. 開啟 Finder
  2. 按下 Command + Shift + G
  3. 輸入 ~/Library/Application Support/SeaMeet
  4. 點擊「前往」

何時直接編輯設定檔案

一般來說，你永遠不需要這樣做，但以下情況可能有幫助：

  • 在電腦之間遷移設定而無需使用雲端
  • 一次批次編輯多個設定
  • 從備份中恢復設定
  • UI 無法開啟時進行排除

務必：

  • 在編輯前完全關閉 SeaMeet
  • 先備份一份
  • 使用適當的 JSON/文字編輯器（Notepad++、VS Code 等）
  • 儲存前確認檔案格式正確

設定檢查清單：應優先設定的項目

如果你對這麼多選項感到不知所措，以下是最重要設定的優先清單：

必要（先做這些）

  • 儲存位置 — 確保錄音存到你想要的地方
  • 預設麥克風 — 確保選擇正確的裝置
  • 語言 — 設定為你偏好的語言
  • 自動啟動偏好 — 決定 SeaMeet 是否應隨電腦開機啟動

重要（盡快完成）

  • 視訊品質 — 根據需求和電腦效能設定
  • 音訊格式 — 根據品質與檔案大小偏好選擇
  • 主題 — 淺色或深色模式以確保舒適
  • 鍵盤快捷鍵 — 自訂以符合你的工作流程

實用（需要時設定）

  • 自動偵測應用程式 — 為你常用的應用程式啟用
  • Flashback 設定 — 根據偏好調整緩衝時長
  • 通知偏好 — 選擇哪些事件通知你
  • 游標錄製選項 — 用於教學/簡報錄製

選用（之後微調）

  • 進階音訊設定 — 取樣率、位元深度
  • 視訊編解碼器偏好 — 壓縮設定
  • 檔案命名模式 — 用於整理的自訂格式
  • 熱鍵自訂 — 進階鍵盤快捷鍵對應

設定詞彙表：快速參考

以下是你在設定中會看到的術語快速詞彙表：

啟用/停用 — 開啟或關閉功能 預設 — 除非另有指定，否則使用的設定 路徑/目錄 — 電腦上的位置（如 C:\Users\你\文件） 瀏覽 — 開啟檔案瀏覽器以選擇位置 位元率 — 每秒使用的資料量（越高 = 品質越好，檔案越大） 取樣率 — 每秒擷取音訊的次數（44.1kHz = 每秒 44,100 次） 解析度 — 視訊影像大小（1080p = 1920×1080 像素） 影格速率 — 每秒的視訊影格數（fps） 緩衝區 — 持續資料的暫時記憶體儲存 增益 — 輸入的音量水準（麥克風靈敏度） 編解碼器 — 壓縮/解壓縮音訊/視訊的軟體 格式 — 檔案類型（MP3、MP4、WebM 等） 切換 — 開啟或關閉某功能的開關 套用 — 儲存你所做的變更 重設 — 恢復為原始/預設值
