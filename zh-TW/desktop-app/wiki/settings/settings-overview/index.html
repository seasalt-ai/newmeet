設定概覽

第 18 章:設定概覽

介紹

歡迎來到 SeaMeet 的控制中心!如果主介面像駕駛艙,讓您駕駛飛機,那麼設定選單就像維修車庫,讓您微調引擎、調整座椅,並客製化您的飛行體驗。本章將向您展示如何從 SeaMeet 中的多個位置存取設定選單,並提供您將在那裡找到的所有不同類別的路線圖。

讀完本章之後,您將確切知道每個 SeaMeet 設定的位置,並了解每個類別控制什麼。把這想成在我們深入每個特定區段前的方向導覽。

章節目標

讀完本章後,您將能夠:

  • 從 SeaMeet 中多個位置開啟設定選單
  • 了解 10 個主要設定類別及它們控制什麼(包括 v2.1.0 推出的新 AI Features 與 Sync 群組)
  • 在不同設定區段間快速導覽
  • 識別設定介面中使用的視覺指示器與圖示
  • 根據需求知道何時變更哪個設定

什麼是設定,為什麼它們重要?

把 SeaMeet 設定想成您智慧型手機上的偏好設定。您不需要變更它們就能使用基本功能,但客製化它們會讓應用程式照您要的方式運作。這就是穿一件「均一尺寸」襯衫與穿一件量身訂做襯衫的差別。

設定重要,因為它們讓您可以:

個人化您的體驗

  • 選擇您偏好的語言(有 16 個選項可用!)
  • 依您眼睛的舒適度設定淺色或深色模式
  • 挑選錄音儲存位置
  • 配置符合您肌肉記憶的快捷鍵

最佳化效能

  • 依您麥克風的能力調整音訊品質
  • 設定符合您螢幕與儲存需求的視訊解析度
  • 依您電腦的能力啟用或停用功能
  • 管理 Flashback 錄音的記憶體用量

確保可靠性

  • 設定自動偵測,讓您不會錯過會議
  • 在用盡空間前設定儲存警告
  • 為您的設定選擇正確的音訊裝置
  • 從一開始正確設定權限

在問題發生前解決它們

  • 如果人們說您太安靜或太大聲,調整麥克風增益
  • 設定預設錄音模式以避免忘記切換
  • 配置自動啟動選項,讓錄音在您要時開始
  • 如果您的電腦較舊或較慢,啟用低記憶體模式

如何開啟設定選單

SeaMeet 給您多種存取設定的方式,就像您可以用密碼、指紋或臉部辨識解鎖手機。以下是所有抵達您設定的方式:

方法 1:從左側欄

這是存取設定最常見的方式。看 SeaMeet 主視窗左側的垂直側欄。

逐步說明:

  1. 找到左側欄,有 Recordings、Video、Flashback 等圖示

  2. 尋找設定圖示——它看起來像齒輪 (⚙️)

  3. 點擊設定圖示

  4. 主區會從顯示您的錄音切換到顯示設定面板

方法 2:從選單列(Windows)

如果您在 Windows 上,您也可以透過視窗頂部的傳統選單列存取設定。

逐步說明:

  1. 點擊頂部選單列中的 "File"

  2. 在下拉選單中尋找 "Settings" 或 "Preferences"

  3. 點擊它以開啟設定面板

注意: 此方法可能因您的 Windows 版本與 SeaMeet 版本略有不同。

方法 3:鍵盤快捷鍵(Windows)

對於熱愛鍵盤的人來說,有個快速捷徑:

在 Windows: 按 Ctrl + 逗號 (,)

這是許多 Windows 應用程式(包括 Microsoft Office 與許多其他)中常見的快捷鍵,所以它可能已在您的肌肉記憶中。

如何使用:

  1. 確認 SeaMeet 是啟用視窗(如果不確定,點擊它)
  2. 按住 Ctrl
  3. 按住 Ctrl 同時按逗號鍵
  4. 設定立即開啟

方法 4:從系統匣選單(Windows)

SeaMeet 在您的系統匣中執行(那是時鐘旁的區域,有許多小圖示)。您也可以從那裡存取設定。

逐步說明:

  1. 在系統匣中尋找 SeaMeet 圖示(螢幕右下角)

    • 您可能需要點擊小向上箭頭以看到隱藏的圖示

  2. 右鍵點擊 SeaMeet 圖示

  3. 上下文選單會出現,有各種選項

  4. 從選單點擊 "Settings"

為什麼使用此方法?

  • SeaMeet 最小化時很棒
  • 不開啟主視窗即快速存取
  • 您急時很完美

方法 5:從 Floater 選單

還記得第 14 章中的浮動控制小工具(Floater)嗎?您也可以從那裡存取設定。

逐步說明:

  1. 點擊 Floater 展開它(如果在精簡模式中)

  2. 尋找設定齒輪圖示或選單選項

  3. 點擊它以開啟設定

注意: 確切位置可能因您的 Floater 配置而異,但從展開的 Floater 檢視中總是可存取設定選項。

10 種設定類別解說

SeaMeet 將設定組織為 10 個邏輯類別。把這些想成檔案櫃中的抽屜——每個都包含相關項目。其中兩個——AI Features 與 Sync——在 v2.1.0 加入,以將新的 AI 摘要範本控制與 GitHub 支援的跨裝置同步分組在一起:

類別 1:一般設定

圖示: 通常是齒輪或房屋圖示 控制什麼: 基本應用程式行為與外觀

典型設定包括:

  • 啟動行為 — SeaMeet 應在電腦啟動時自動開啟嗎?
  • 最小化到系統匣 — 當您關閉視窗時 SeaMeet 應繼續執行嗎?
  • 主題選擇 — 淺色模式、深色模式或自動(跟隨系統)
  • 通知偏好 — 哪些事件應觸發通知?
  • 更新設定 — SeaMeet 應自動檢查更新嗎?

何時使用此類別:

  • 您首次安裝 SeaMeet 並想設定基本偏好時
  • 您想變更應用程式的外觀與風格時
  • 您想控制 SeaMeet 在背景的行為時
  • 設定自動啟動時

比喻: 這就像調整汽車的基本設定——燈應自動亮嗎?它應記住您的座位位置嗎?當您把鑰匙留在車內時應發出警示嗎?

類別 2:儲存設定

圖示: 通常是硬碟或資料夾圖示 控制什麼: 您錄音儲存的位置與方式

典型設定包括:

  • 儲存位置 — 錄音應到哪個資料夾?
  • 儲存管理 — 自動清理舊錄音
  • 檔案組織 — 檔案應如何命名與排序?
  • 磁碟空間警告 — 在空間不足時警示
  • 備份設定 — 錄音應備份到雲端儲存嗎?

何時使用此類別:

  • 您想變更錄音儲存位置(例如將它們移到外接磁碟)
  • 您磁碟空間不足且需要管理儲存
  • 您想以特定方式組織錄音
  • 設定自動清理以防止累積

比喻: 這就像整理您的衣櫃——決定哪個抽屜放哪些衣服、如何標記盒子,以及何時捐贈舊物品以騰出空間給新的。

重要備註: 這在第 19 章(儲存設定)中詳述,我們將逐步走過每個選項。

類別 3:音訊設定

圖示: 通常是麥克風或喇叭圖示 控制什麼: 與聲音錄製和播放相關的所有事項

典型設定包括:

  • 預設麥克風 — 用於錄音的麥克風
  • 麥克風增益 — 您的聲音應被多大聲地錄製
  • 系統音訊來源 — 要擷取的音訊輸出
  • 藍牙警告 — 使用藍牙麥克風時的警示
  • 音訊格式 — 音訊錄音的偏好格式(MP3、WAV 等)
  • 取樣率 — 音訊品質等級(44.1kHz、48kHz 等)

何時使用此類別:

  • 當人們說您在錄音中太安靜或太大聲時
  • 當您有多支麥克風並想選擇預設時
  • 當使用藍牙耳機並需要延遲警告時
  • 當您想變更音訊品質或檔案格式時
  • 排除音訊錄音問題時

比喻: 這就像調整演唱會廳的音響系統——選擇要使用哪些麥克風、設定正確音量,並確保音響為演出完美運作。

重要備註: 這在第 20 章(音訊設定)中詳述,我們將深入麥克風選擇、增益控制等。

類別 4:視訊設定

圖示: 通常是攝影機或顯示器圖示 控制什麼: 與螢幕錄製相關的所有事項

典型設定包括:

  • 預設錄音模式 — 全螢幕、視窗或區域
  • 視訊品質 — 解析度(1080p、720p、480p)
  • 影格率 — 視訊應多流暢(30fps、60fps)
  • 顯示器選擇 — 要錄哪個螢幕(如果有多個)
  • 視訊格式 — 視訊檔案的偏好格式(MP4、WebM 等)
  • 硬體加速 — 使用 GPU 以獲得更好效能
  • 滑鼠錄製 — 滑鼠指標應可見嗎?
  • 滑鼠效果 — 高亮點擊、變更游標大小等

何時使用此類別:

  • 您想設定預設錄音模式以節省點擊時
  • 您需要在品質與檔案大小之間取得平衡時
  • 您有多顯示器並需要指定要錄哪個時
  • 錄製遊戲且需要高影格率(60fps)時
  • 建立教學並想要游標效果時

比喻: 這就像設定電影攝影機——選擇底片品質、決定使用哪個鏡頭、設定影格率以獲得流暢動作,以及決定是否在鏡頭中顯示攝影師的手。

重要備註: 這在第 21 章(視訊設定)中詳述,我們將說明所有技術術語,並協助您選擇正確的設定。

類別 5:Flashback 設定

圖示: 通常是循環箭頭或時鐘圖示(代表「倒帶」) 控制什麼: 時光機錄音功能

典型設定包括:

  • 自動啟動 Flashback — Flashback 應在 SeaMeet 啟動時自動開始嗎?
  • 緩衝時長 — 要保留多久之前(10-120 秒)
  • 音訊緩衝長度 — 要保留多少音訊(固定 30 秒)
  • 視訊品質 — Flashback 視訊的解析度(通常低於一般錄音)
  • 低記憶體模式 — 為較舊電腦減少記憶體用量
  • 緩衝持久化 — 切換應用程式時保留緩衝?

何時使用此類別:

  • 您想讓 Flashback 隨時準備好(自動啟動)時
  • 您需要在多久能儲存以前 vs. 記憶體用量之間取得平衡時
  • 您的電腦較舊且需要節省 RAM 時
  • 您想客製化 Flashback 的行為時

比喻: 這就像配置監視器的 DVR——決定保留多少天的錄影、設定錄製品質,以及為持續錄製管理儲存空間。

重要備註: 這在第 22 章(Flashback 設定)中詳述,我們將協助您在緩衝長度與效能之間找到完美平衡。

類別 6:AI Features(v2.1.0 新增)

圖示: 紫色光點/魔杖圖示 控制什麼: 驅動 SeaMeet AI 端的所有事項——即時轉錄、會議後摘要、摘要範本,以及(選擇性)應用程式內 AI 助手

AI Features 群組包含三個選單項目:

  • AI Transcription, Extraction, Summary, Wiki — 您的模型提供者、BYOK API 金鑰輸入、摘要語言,以及錄音後哪些 AI 管線自動執行。在第 36 章(Bring Your Own Key — BYOK)中詳述。
  • AI Summary Templates — v2.1.0 推出的新範本庫(48 個內建範本,跨 8 個類別:Team & Management、Project & Agile、Sales & Client、HR & Recruitment、Education & Training、Medical & Healthcare、Legal & Compliance 以及 Events & Media)。包括 Auto-detect summary template 切換(預設開)——開啟時,SeaMeet 分類每個會議的轉錄並挑最合適的範本;關閉時,每個錄音使用 Meeting Minutes,且不會進行分類器呼叫。在第 33 章(AI 摘要範本)中詳述。
  • AI Agent & Cowork — 只在 agent 功能旗標啟用時可見。承載聊天助手配置(Provider、Ask/Code/Plan 預設)。在第 37 章(Copilot & AI Agent)中詳述。

何時使用此類別:

  • 您想使用自己的 Gemini API 金鑰設定 BYOK 時
  • 您想全域翻轉自動偵測範本行為時
  • 您想瀏覽已安裝範本庫而不開啟錄音時
  • 配置 AI Agent 的預設時

比喻: 這是 AI 控制室——您選擇 SeaMeet 連接到哪個「大腦」以及它應為您思考得多激進的面板。

類別 7:自動錄音設定

圖示: 通常是放大鏡或機器人/自動化圖示 控制什麼: 自動會議偵測與錄製

典型設定包括:

  • 自動偵測啟用 — 此功能的總開關
  • 偵測靈敏度 — 偵測應多激進
  • 預設動作 — 立即開始錄音或只是通知?
  • 每應用程式權限 — 哪些應用程式可觸發自動錄音
  • 偵測方法 — 要監看的訊號(視窗標題、音訊等)
  • 開始前延遲 — 偵測後等幾秒再開始
  • 會議後動作 — 會議結束時要做什麼

何時使用此類別:

  • 第一次設定 SeaMeet 並啟用自動偵測時
  • 您想微調哪些應用程式觸發錄音時
  • 您發現自動偵測太敏感(或不夠敏感)時
  • 您想讓 SeaMeet 在開始前等一下時
  • 客製化會議結束後發生什麼時

比喻: 這就像訓練智慧助手——教它認出您何時在會議中、決定哪些會議重要,以及告訴它在偵測時如何回應。

重要備註: 這在第 23 章(自動錄音設定)中詳述,我們將走過為所有 47+ 支援的應用程式設定權限。

類別 8:Sync(v2.1.0 新增)

圖示: GitHub 標誌 / 雲端圖示 控制什麼: 透過您自己的 GitHub 儲存庫,對您筆記與 wiki 進行選擇性的私人雲端備份

典型設定包括:

  • Set Up GitHub Sync / Authorize GitHub — 為每個工作區建立私人儲存庫的一鍵 OAuth 流程
  • Auto-sync on changes — 在您編輯時提交並推送(預設開)
  • Sync on startup — SeaMeet 啟動時拉取最新變更(預設開)
  • Sync interval — 本機編輯多久批次成一次提交(1、5、10 或 30 分鐘)
  • Sync Now — 手動提交 + 推送觸發
  • Conflict resolution — 當兩個裝置編輯同一檔案時的手動編輯或 Agent 輔助合併
  • Re-authorize / Disconnect — 重新整理 GitHub OAuth 或解除工作區的連結

重要範圍: Sync 只涵蓋筆記與 wiki(.md 檔案)。音訊錄音、視訊錄影與截圖留在您的裝置上——它們從不推送到 GitHub。這就是讓單一 1 GB GitHub 免費方案儲存庫能容納大約 200,000–500,000 個筆記的原因。

何時使用此類別:

  • 首次設定跨裝置存取您的筆記與 wiki 時
  • 您想將筆記免費備份到私人 GitHub 儲存庫時
  • 解決兩個裝置間的同步衝突時
  • 在 OAuth 權杖過期後您需要重新授權時

訂閱限制: Sync 隨 BYOK Pro 推出。免費使用者會看到帶有「BYOK Pro」徽章的 Sync 選單項目,以及點擊時開啟付費牆的提示橫幅。

比喻: 這是您的場外保險箱——每個筆記的私人、版本控制副本,在電腦間追隨您,而不上傳大量媒體檔案。

重要備註: 這在第 38 章(GitHub Sync)中詳述。

了解設定控制

不同的設定使用不同的控制類型。以下是辨識和使用每種類型的指南:

切換開關(開/關)

它們長什麼樣: 水平開關,向左滑(關)或向右滑(開)。開啟時通常有顏色(通常藍或綠)。

設定名稱              [━━●──]   ← 關閉位置
                      [──●━━]   ← 開啟位置(有顏色)

如何使用:

  • 點擊開關以切換它
  • 開關會滑動並變色
  • 變更通常立即生效

SeaMeet 中的範例:

  • 自動啟動 Flashback
  • 最小化到系統匣
  • 啟用自動偵測
  • 在錄音中顯示游標

比喻: 像牆上的電燈開關——一邊開、另一邊關。

下拉選單

它們長什麼樣: 顯示目前選擇的矩形欄位,右側有向下箭頭。

錄音品質              [1080p HD        ▼]
                       ↑ 目前         ↑ 點擊查看
                         值             所有選項

如何使用:

  1. 點擊下拉(或箭頭)
  2. 選項清單在下方出現
  3. 點擊您要的選項
  4. 下拉關閉,顯示您的新選擇

SeaMeet 中的範例:

  • 視訊品質(1080p、720p、480p)
  • 影格率(30fps、60fps)
  • 音訊格式(MP3、WAV、WebM)
  • 預設錄音模式(全螢幕、視窗、區域)
  • 顯示語言(16 個選項)

比喻: 像餐廳菜單——您看到目前的選擇在您盤子上,但您可以開菜單選別的。

文字輸入欄位

它們長什麼樣: 空白或預填的矩形框,您可以在裡面打字。

儲存位置             [C:\Users\You\Recordings    ] [瀏覽...]
                       ↑ 在這裡點擊輸入        ↑ 或點擊
                                                  瀏覽資料夾

如何使用:

  1. 點擊文字欄位內
  2. 輸入您的文字(或先清除現有文字)
  3. 完成後按 Tab 或點擊別處

特殊功能:

  • 瀏覽按鈕 — 通常在路徑欄位旁,開啟檔案瀏覽器
  • 預留文字 — 顯示範例輸入的灰色文字
  • 驗證 — 若您輸入無效內容可能變紅

SeaMeet 中的範例:

  • 儲存目錄路徑
  • 檔案命名模式
  • 自訂鍵盤快捷鍵
  • 麥克風裝置名稱(有時)

比喻: 像在醫生診所填表——您在空白欄位寫資訊。

滑桿

它們長什麼樣: 水平條,有您可以向左或向右拖曳的握把。

麥克風增益            [━●━━━━━━━━━━━] 45%
                       ↑ 拖此旋鈕
                         左(較安靜)
                         或右(較大聲)

如何使用:

  1. 點擊並按住滑桿握把(或旋鈕)
  2. 向左拖以降低值
  3. 向右拖以增加值
  4. 滿意時放開

替代: 在滑桿條上任何位置點擊,以跳到該位置

SeaMeet 中的範例:

  • 麥克風增益/音量
  • 偵測靈敏度(用於自動錄音)
  • 緩衝時長(用於 Flashback)
  • 品質/壓縮平衡

比喻: 像音響上的音量旋鈕——向左轉降低、向右轉提高。

按鈕

它們長什麼樣: 含文字標籤的矩形或圓角按鈕。

[檢查更新] [重設為預設] [瀏覽...]

如何使用:

  • 只需點擊按鈕一次
  • 某件事立即發生(對話框開啟、執行動作等)

按鈕類型:

  • 動作按鈕 — 執行動作(檢查更新、瀏覽)
  • 重設按鈕 — 還原預設(重設為預設)
  • 導覽按鈕 — 前往其他畫面(進階設定)
  • 確認按鈕 — 儲存或取消變更(套用、確定、取消)

SeaMeet 中的範例:

  • 瀏覽(用於選擇資料夾)
  • 重設為預設(任何類別)
  • 檢查更新(在「關於」區段)
  • 套用/儲存變更
  • 測試麥克風(在音訊設定)

比喻: 像電梯按鈕——按一次,電梯做某事(上、下、開門)。

核取方塊

它們長什麼樣: 可勾選 (✓) 或為空的小方形。

☐ 電腦啟動時啟動 SeaMeet
☑ 關閉時最小化到系統匣
☐ 顯示錄音通知

如何使用:

  • 點擊核取方塊以切換
  • 啟用時出現勾號
  • 再次點擊取消勾選

與切換的差異:

  • 核取方塊通常用於您可選取多個選項
  • 切換用於單一開/關選擇
  • SeaMeet 主要使用切換,但您可能在進階設定中看到核取方塊

比喻: 像代辦清單——您勾選已完成的項目。

設定行為:立即 vs. 套用

並非所有設定在您變更時都以相同方式運作。有兩種主要行為:

立即設定

這些在您變更時立即生效——無需點擊「Apply」或「Save」。

範例:

  • 主題變更(淺色/深色模式)
  • 語言選擇
  • 切換開關(大多數)
  • 音量/增益滑桿(您即時聽到變化)

如何識別:

  • 變更立即發生
  • 不需要「Apply」按鈕
  • 通常是視覺變更或簡單切換

套用設定

這些要求您在生效前點擊「Apply」、「OK」或「Save」。

範例:

  • 儲存位置路徑
  • 預設錄音模式
  • 複雜音訊/視訊配置
  • 某些權限設定

如何識別:

  • 有「Apply」或「Save」按鈕存在
  • 您可能看到「unsaved changes」指示
  • 變更直到您確認才發生

重要: 如果您變更設定並點擊「Cancel」,您的變更會被丟棄!如果您想保留變更,請務必點擊「Apply」或「OK」。

搜尋功能(如可用)

某些版本的 SeaMeet 在設定面板頂部包含搜尋框。這非常有用!

如何使用搜尋:

  1. 尋找搜尋框(通常顯示「Search settings...」或有放大鏡圖示)

  2. 點擊搜尋框並輸入關鍵字:

    • 「microphone」→ 顯示所有麥克風相關設定
    • 「save」→ 顯示儲存與儲存位置設定
    • 「quality」→ 顯示視訊與音訊品質設定
    • 「shortcut」→ 顯示鍵盤快捷鍵設定

  3. 在您輸入時,設定清單篩選為只顯示符合項目

  4. 點擊結果以直接跳到該設定

為什麼搜尋有幫助:

  • 快速找設定,不必瀏覽類別
  • 發現您不知道存在的相關設定
  • 當您不確定設定屬於哪個類別時很棒
  • 當您確切知道想變更什麼時節省時間

常見設定工作流程

以下是一些典型情境與處理它們的確切步驟:

情境 1:首次設定

您是 SeaMeet 新手,想配置基本內容:

  1. 開啟設定(點擊左側欄的齒輪圖示)

  2. 前往「一般」

    • 將主題設為您的偏好
    • 若需要,啟用「最小化到系統匣」
    • 若需要,啟用「電腦啟動時啟動」

  3. 前往「儲存」

    • 驗證或變更儲存位置
    • 設定磁碟空間警告

  4. 前往「音訊」

    • 選擇您的預設麥克風
    • 測試麥克風並調整增益
    • 若使用無線耳機,檢查藍牙警告

  5. 前往「語言」

    • 選擇您偏好的顯示語言

  6. **點擊「Apply」**以儲存所有變更

  7. **前往「關於」**以記下您的版本號(對支援很方便)

情境 2:變更錄音儲存位置

您的 C: 磁碟空間不足,想將錄音移到外接磁碟:

  1. 開啟設定

  2. 點擊左側欄的「儲存」

  3. 找到「儲存位置」或「錄音目錄」

  4. 點擊「Browse」按鈕

  5. 在檔案瀏覽器中導覽到您的外接磁碟

    • 範例:D:\SeaMeet Recordings

  6. 選擇或建立資料夾

  7. 在檔案瀏覽器中點擊「OK」

  8. 在設定中點擊「Apply」

  9. 選擇性: 使用檔案總管手動將現有錄音移到新位置

情境 3:設定自動偵測

您希望 SeaMeet 自動偵測 Zoom 會議:

  1. 開啟設定

  2. 點擊「自動錄音」

  3. 啟用「自動偵測」(切換開關)

  4. 在應用程式清單中找到 Zoom

  5. 啟用 Zoom 的權限(切換或核取方塊)

  6. 選擇預設動作: 立即開始錄音或只通知?

  7. 若需要調整靈敏度(滑桿)

  8. 點擊「Apply」

  9. 測試: 開啟 Zoom 並開始會議,看 SeaMeet 是否偵測

情境 4:為較舊電腦最佳化

您的電腦有幾年了,錄音時執行緩慢:

  1. 開啟設定

  2. 前往「視訊」

    • 將視訊品質降至 720p 或 480p
    • 將影格率設為 30fps(而非 60fps)
    • 若硬體加速造成問題則停用

  3. 前往「Flashback」

    • 啟用「低記憶體模式」
    • 將緩衝時長降至 30-60 秒(而非 120)

  4. 前往「音訊」

    • 若可用,選擇較低的取樣率(44.1kHz 而非 48kHz)

  5. 前往「儲存」

    • 啟用自動清理以防止磁碟空間問題

  6. 點擊「Apply」

  7. 測試錄音,看效能是否改善

情境 5:為專業簡報做準備

您需要為工作錄製高品質簡報:

  1. 開啟設定

  2. 前往「視訊」

    • 將品質設為 1080p(或最高可用)
    • 將影格率設為 60fps 以獲得流暢動作
    • 啟用「錄製游標」
    • 若可用,啟用「高亮游標點擊」

  3. 前往「音訊」

    • 選擇您最好的麥克風
    • 將增益設為最佳等級(先測試!)
    • 選擇高品質格式(WAV 為最佳,或高位元率 MP3)

  4. 前往「一般」

    • 停用通知以防止中斷
    • 確保「最小化到系統匣」已啟用

  5. 前往「儲存」

    • 確認您有足夠磁碟空間(HD 視訊使用很多空間!)

  6. 點擊「Apply」

  7. 做 30 秒測試錄音以驗證一切看起來與聽起來都完美

設定提示與技巧

提示 1:「重設為預設」安全網

如果您變更設定且某事停止運作,別慌張!每個類別都有「Reset to Defaults」按鈕,將該區段回到出廠設定。

如何使用:

  1. 前往有問題的類別
  2. 點擊「Reset to Defaults」(通常在底部)
  3. 確認重設
  4. 用乾淨的設定再試

注意: 這會重設該類別中的所有設定,不只是您最後變更的那個。

提示 2:匯出/匯入設定(如可用)

某些版本的 SeaMeet 讓您將設定匯出到檔案。這對以下很棒:

  • 備份您的偏好
  • 將設定轉移到另一台電腦
  • 與同事分享最佳化的設定

尋找: 「Export Settings」或「Import Settings」按鈕,通常在「一般」或設定面板底部。

提示 3:鍵盤導覽

您可以不使用滑鼠導覽設定:

  • Tab — 移到下一個控制
  • Shift + Tab — 移到上一個控制
  • 空格鍵 — 切換核取方塊或啟動按鈕
  • 方向鍵 — 導覽下拉選項或調整滑桿
  • Enter — 確認選擇或啟動按鈕

這對於無障礙或當您的滑鼠不能用時特別有用。

提示 4:懸停以獲得協助

許多設定有有用的工具提示。將滑鼠懸停在設定名稱或控制上以看額外資訊。

範例: 懸停在「Microphone Gain」上可能顯示:「Adjust this if your recordings are too quiet or too loud. 50% is the default.」

提示 5:設定自動儲存(通常)

在大多數情況下,SeaMeet 在您變更時自動儲存您的設定。然而,某些複雜變更要求點擊「Apply」。

需要點擊 Apply 的跡象:

  • 「Apply」按鈕可見且可點擊
  • 您看到「Unsaved changes」之類的文字
  • 設定涉及檔案路徑或外部資源

有疑問時: 點擊 Apply!確認您的變更從不會傷害。

了解設定持久化

這裡有個重要的事情要了解:設定儲存到您的使用者個人檔案,並在作業階段間持久化。

這代表:

  • 您關閉並重新開啟 SeaMeet 時設定存活
  • 即使您重新啟動電腦,設定仍相同
  • 設定與您的 Windows/Mac 使用者帳戶綁定
  • 如果您有多個使用者帳戶,每個都有自己的設定

設定儲存在哪裡(技術):

  • Windows: 通常在您的使用者個人檔案資料夾,通常在 AppData
  • macOS: 在您的使用者 Library 資料夾
  • 您不需要直接存取這些檔案 — 使用設定 UI

例外:

  • 某些可攜版本可能將設定儲存在應用程式資料夾
  • 企業部署可能使用集中設定
  • 重新安裝 SeaMeet 通常保留使用者設定

設定安全性與隱私

SeaMeet 設定是您電腦本機的,通常不包含敏感資訊。然而:

設定中有什麼:

  • 檔案路徑(可能透露資料夾結構)
  • 應用程式偏好(您使用哪些功能)
  • 硬體選擇(您偏好哪個麥克風)
  • 沒有密碼或帳戶憑證

隱私考量:

  • 設定不包括您實際的錄音(只是它們儲存位置)
  • 自動偵測設定顯示您使用哪些應用程式(但不是用量資料)
  • 沒有設定的雲端同步(所有都留在本機)

企業環境:

  • IT 管理員可能能檢視或管理設定
  • 群組政策可能覆蓋某些設定
  • 若您有疑慮,請洽 IT 部門

設定問題的疑難排解

問題 1:設定不儲存

症狀: 您變更設定,但重新開啟設定時它回到原樣。

解決方案:

  1. 確認您點擊「Apply」 — 某些設定要求明確儲存
  2. 檢查磁碟空間 — 若磁碟滿,設定無法儲存
  3. 以系統管理員執行 — 嘗試右鍵 SeaMeet 並「以系統管理員身分執行」(Windows)
  4. 檢查權限 — 確保您有使用者個人檔案資料夾的寫入存取
  5. 重新安裝 SeaMeet — 先備份您的錄音,然後重新安裝

問題 2:設定變灰

症狀: 某些設定可見但無法變更(變灰或停用)。

常見原因:

  • 另一個設定停用它們 — 例如,若視訊錄影停用,您無法設定視訊品質
  • 管理員/企業限制 — 您的組織可能鎖定某些設定
  • 功能不可用 — 該功能可能未包含在您的版本中
  • 硬體限制 — 某些設定要求特定硬體

解決方案:

  1. 檢查您是否需要先啟用父設定
  2. 若是企業限制,洽您的 IT 部門
  3. 檢查 SeaMeet 版本(某些功能是版本特定的)
  4. 驗證您的硬體支援該功能

問題 3:設定 UI 故障

症狀: 設定看起來不對、重疊或不正確顯示。

解決方案:

  1. 調整視窗大小 — 嘗試讓 SeaMeet 視窗更大
  2. 重啟 SeaMeet — 關閉並重新開啟應用程式
  3. 更新顯示卡驅動程式 — 過時的驅動程式可能造成 UI 問題
  4. 變更顯示縮放 — 若使用高 DPI (4K),暫時試 100% 縮放
  5. 重新安裝 SeaMeet — 若都失敗,全新安裝通常修復 UI 問題

問題 4:找不到設定

症狀: 您知道有個設定存在,但找不到它。

解決方案:

  1. 使用搜尋 — 在設定搜尋框輸入關鍵字
  2. 檢查所有類別 — 它可能在意外類別中
  3. 檢查進階設定 — 某些設定隱藏在「Advanced」按鈕後
  4. 更新 SeaMeet — 該設定可能在較新版本中
  5. 讀手冊 — 每個設定章節列出所有可用選項

進階:設定檔位置(給進階使用者)

如果您是技術使用者並需要直接存取設定,這裡是找到它們的地方:

Windows

標準安裝:

C:\Users\[YourUsername]\AppData\Roaming\SeaMeet\

檔名可能包括:

  • settings.json
  • config.json
  • preferences.json
  • SeaMeet.config

如何存取:

  1. 按 Windows + R
  2. 輸入 %AppData%\SeaMeet 並按 Enter
  3. 尋找設定檔

警告: 手動編輯這些檔案可能損壞 SeaMeet。永遠先備份!

macOS

標準位置:

~/Library/Application Support/SeaMeet/

或在偏好設定中:

~/Library/Preferences/com.seameet.app.plist

如何存取:

  1. 開啟 Finder
  2. 按 Command + Shift + G
  3. 輸入 ~/Library/Application Support/SeaMeet
  4. 點擊「Go」

何時直接編輯設定檔

通常,您不應需要這樣做,但這可能對以下有幫助:

  • 不使用雲端在電腦間遷移設定
  • 一次大量編輯多個設定
  • 從備份還原設定
  • 當 UI 無法開啟時排除問題

永遠:

  • 編輯前完全關閉 SeaMeet
  • 先做備份副本
  • 使用適當的 JSON/文字編輯器(Notepad++、VS Code 等)
  • 儲存前驗證檔案格式正確

設定檢查清單:先配置什麼

如果您被所有選項淹沒,以下是最重要先配置的設定優先檢查清單:

必要(先做這些)

  • 儲存位置 — 確保錄音去您要的地方
  • 預設麥克風 — 確保選擇正確裝置
  • 語言 — 設為您偏好的語言
  • 自動啟動偏好 — 決定 SeaMeet 是否應隨電腦啟動

重要(很快做這些)

  • 視訊品質 — 根據您的需求與電腦能力設定
  • 音訊格式 — 根據品質 vs. 檔案大小偏好選擇
  • 主題 — 淺色或深色模式以求舒適
  • 鍵盤快捷鍵 — 客製化以符合您的工作流程

有用(視需要配置)

  • 自動偵測應用程式 — 為您常用的應用程式啟用
  • Flashback 設定 — 將緩衝時長調整為您的偏好
  • 通知偏好 — 選擇哪些事件通知您
  • 游標錄製選項 — 用於教學/簡報錄音

選擇性(稍後微調)

  • 進階音訊設定 — 取樣率、位元深度
  • 視訊編解碼器偏好 — 壓縮設定
  • 檔案命名模式 — 整理的自訂格式
  • 熱鍵客製化 — 進階鍵盤快捷鍵對應

設定詞彙表:快速參考

以下是您在設定中會看到的詞彙的快速詞彙表:
