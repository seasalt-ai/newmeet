音訊設定

第 20 章：音訊設定

簡介

聲音是錄音的靈魂。無論你是在錄製重要的商業會議、錄製播客，還是儲存家人的視訊通話，音訊品質決定了結果是否專業，還是令人沮喪又難以使用。音訊設定是你的工具組，確保每個聲音都能清晰傳達 — 沒有喃喃自語、沒有回音、不再有「你聽得到我嗎？」的困擾。

讀完本章後，你將成為音訊專家。你將知道如何選擇正確的麥克風、完美地調整音量、避免藍牙延遲等常見音訊問題，並根據需求選擇最佳的音訊格式。

本章目標

閱讀本章後，你將能夠：

  • 選擇並設定你的預設麥克風
  • 調整麥克風增益以達到最佳音量
  • 了解並防止藍牙音訊延遲問題
  • 根據需求選擇正確的音訊格式（MP3、WAV、WebM）
  • 設定系統音訊擷取設定
  • 排除常見的音訊錄製問題
  • 為不同的錄製情境設定音訊

為何音訊設定重要

想像這個情境：你剛結束了一場 2 小時的策略規劃會議。你錄製了整個會議，讓你的團隊之後可以回顧決策內容。但當你播放時，你發現：

  • 你的聲音幾乎聽不見（麥克風距離太遠）
  • 視訊通話中客戶的聲音好像在水裡（壓縮太強）
  • 有令人分心的回音（房間聲學 + 增益太高）
  • 每次打字都像打雷一樣（靈敏的麥克風拾取鍵盤聲）

影片看起來很好，但音訊品質太差，錄音幾乎沒用。這就是為何花時間設定音訊是值得的 — 良好的音訊比良好的視訊更難在後製中修復。

掌握音訊設定的主要原因：

1. 專業品質

  • 清晰的音訊讓你聽起來有能力且有準備
  • 糟糕的音訊會削弱最好的內容
  • 客戶和同事以聲音來判斷品質

2. 理解力和無障礙性

  • 清晰的音訊更容易理解
  • 對轉錄準確性很重要
  • 對無障礙需求（聽力障礙）至關重要

3. 檔案大小管理

  • 音訊格式在檔案大小上差異很大
  • 選擇品質與大小之間的正確平衡
  • 在不犧牲清晰度的情況下節省儲存空間

4. 避免重錄

  • 第一次就做好比較好
  • 重新錄製會議通常是不可能的
  • 適當的設定可防止災難

了解音訊基礎知識

在深入設定之前，讓我們先了解數位音訊錄製的基礎知識。

數位音訊的運作方式（簡單說明）

把音訊錄製想成為聲音拍照：

取樣率 = 每秒拍多少張「照片」

  • 就像相機快門速度
  • 44.1kHz = 每秒 44,100 個取樣
  • 48kHz = 每秒 48,000 個取樣
  • 越高 = 更多細節、更大的檔案

位元深度 = 每個取樣中有多少細節

  • 就像相機的色彩深度
  • 16 位元 = 65,536 個可能值
  • 24 位元 = 1,670 萬個可能值
  • 越高 = 更大的動態範圍、更大的檔案

位元率 = 每秒的總資料量

  • 取樣率 × 位元深度 × 聲道數
  • 越高 = 更好的品質、更大的檔案
  • MP3 使用「有損」壓縮來降低位元率

比喻： 錄製音訊就像用點（像素）繪畫。每英寸更多的點（取樣率）和更多可用的顏色（位元深度）= 更好的圖片。但需要更多的油漆（儲存空間）。

音訊聲道

單聲道（1 個聲道）：

  • 單一音訊串流
  • 所有聲音混合在一起
  • 較小的檔案
  • 適合：語音錄音、口述

立體聲（2 個聲道）：

  • 左右音訊串流
  • 創造空間感
  • 較大的檔案（2 倍單聲道大小）
  • 適合：音樂、沉浸式錄音

SeaMeet 通常錄製：

  • 麥克風音訊為單聲道
  • 系統音訊為立體聲（如果來源是立體聲）

現在讓我們逐一詳細說明每個區段。

區段 1：麥克風選擇

麥克風是你的音訊輸入裝置 — 它擷取你的聲音並將其轉換為數位資料。選擇正確的麥克風會帶來很大的差異。

麥克風類型

1. 內建麥克風（筆記型電腦/網路攝影機）

  • 優點： 隨時可用，無需設定
  • 缺點： 品質差、拾取電腦噪音、對位置敏感
  • 最適合： 緊急時使用

2. USB 麥克風（獨立式）

  • 範例： Blue Yeti、Audio-Technica AT2020USB+、Rode NT-USB
  • 優點： 音質優秀、設定容易、價格實惠（50-200 美元）
  • 缺點： 佔用桌面空間、在鏡頭前可見
  • 最適合： 居家辦公、播客製作、日常錄音

3. 耳機麥克風

  • 範例： Jabra、Plantronics、遊戲耳機
  • 優點： 與嘴巴距離一致、解放雙手
  • 缺點： 品質不一、長時間使用可能不舒服
  • 最適合： 長時間通話、遊戲、免持工作

4. 無線/藍牙麥克風

  • 範例： AirPods、藍牙耳機
  • 優點： 行動自由、無需線纜
  • 缺點： 延遲問題、依賴電池、壓縮失真
  • 最適合： 短暫通話、行動錄音（有注意事項）

5. 專業 XLR 麥克風

  • 範例： Shure SM7B、Electro-Voice RE20
  • 優點： 錄音室品質、極為耐用
  • 缺點： 需要音訊介面（$$）、設定複雜
  • 最適合： 專業錄音室、廣播品質

在 SeaMeet 中選擇預設麥克風

步驟說明：

  1. 開啟音訊設定

    • 點擊設定齒輪圖示
    • 點擊左側邊欄中的「Audio」（音訊）

  2. 找到「Default microphone」（預設麥克風）下拉選單

    • 顯示目前選取的裝置

  3. 點擊下拉選單

    • 列出所有可用的麥克風

  4. 選擇你偏好的麥克風

    • 選擇你最常使用的那一個
    • 通常最好選擇有線 USB 麥克風

  5. 點擊「Apply」（套用）

清單中你會看到：

Microphone (Blue Yeti)
Microphone (Realtek Audio) ← 內建
Headset Microphone (Jabra)
Microphone (USB Audio Device)
Stereo Mix ← 系統音訊（通常不要選這個）

提示：

  • 選擇名稱中含有「Microphone」的麥克風，而非「Stereo Mix」
  • 「Default」通常代表 Windows 的預設（可能會意外更改）
  • 選擇特定裝置可確保一致性

測試你的麥克風

在錄製任何重要內容之前，請務必先測試你的麥克風！

使用 SeaMeet 的測試功能：

  1. 在音訊設定中找到輸入電平測試區段

  2. 正常地對著麥克風說話

  3. 觀察電平表：

    • 應在「良好」區域（中間）跳動
    • 偶爾達到「大聲」是可以的
    • 不應一直觸碰最大值（紅色）
    • 不應保持在「小聲」（太低）

  4. 讀取目前電平顯示：

    • 顯示分貝（dB）
    • -12 dB 至 -6 dB 是理想的
    • 0 dB 是最大值（會失真）
    • 低於 -30 dB 表示太安靜

顏色的含義：

  • 🟢 綠色（-30 至 -12 dB）：良好電平
  • 🟡 黃色（-12 至 -6 dB）：逐漸大聲，偶爾沒問題
  • 🔴 紅色（-6 至 0 dB）：太大聲了！會失真！

測試用語句：

「測試，一、二、三。這是麥克風測試。」
「今天天氣真的很好，陽光普照。」
「快速的棕色狐狸跳過懶惰的狗。」

應注意的事項：

  • ☐ 清晰，不悶
  • ☐ 沒有回音或殘響
  • ☐ 沒有背景噪音（風扇、空調）
  • ☐ 在「P」和「B」音上沒有爆音
  • ☐ 音量一致
  • ☐ 沒有噼啪聲或靜電

區段 2：麥克風增益（音量控制）

增益是麥克風訊號放大程度的技術術語。把它想像成音響上的音量旋鈕 — 但是用於輸入而非輸出。

了解增益與音量的差異

增益（輸入）：

  • 控制麥克風訊號的音量
  • 在錄製前調整
  • 影響訊噪比
  • 太高 = 失真（削波）
  • 太低 = 安靜、嘈雜的錄音

音量（輸出）：

  • 控制播放時的音量
  • 在錄製後調整
  • 不影響錄音品質
  • 以後可以隨時調高

比喻：

  • 增益就像設定相機感光元件的靈敏度
  • 音量就像調整螢幕亮度以查看照片
  • 如果照片模糊（增益太低），讓螢幕更亮並不能解決問題

調整麥克風增益

步驟說明：

  1. 開啟音訊設定

  2. 找到「Microphone Gain」（麥克風增益）區段

  3. 調整增益滑桿：

    • 正常地對著麥克風說話
    • 觀察電平表
    • 調整滑桿直到你一致地達到 -12 至 -6 dB

  4. 用特定情境微調：

    • 輕聲說話（耳語）：應仍能偵測到
    • 大聲說話（興奮時）：應在 -6 dB 達到峰值，而非 0 dB
    • 正常對話：應維持在 -18 至 -12 dB 左右

「增強」設定

某些麥克風（尤其是內建筆記型電腦麥克風）需要一個稱為「增強」的額外放大階段。

何時使用增強：

  • 麥克風本身很安靜
  • 即使增益調至 100%，電平仍然太低
  • 使用距離嘴巴較遠的麥克風
  • 內建麥克風通常需要 +10-20dB 的增強

何時不使用增強：

  • 麥克風已經夠大聲
  • 啟用時聽到嘶嘶聲或噪音
  • 使用高品質 USB 麥克風（通常不需要）

設定方式：

  1. 先嘗試調整主增益滑桿
  2. 如果仍然太安靜，啟用增強
  3. 從 10-20% 增強開始
  4. 測試並調整
  5. 更多增強 = 更多噪音，所以使用最少需要的量

自動增益：朋友還是敵人？

什麼是自動增益？ 自動即時調整麥克風音量以保持電平一致。

優點：

  • ☐ 適合說話聲音不一致的情況（有些人大聲，有些人小聲）
  • ☐ 在整個錄音過程中保持一致的音量
  • ☐ 免持，不需要手動調整

缺點：

  • ☐ 可能導致「泵浦」效果（音量明顯波動）
  • ☐ 當你停止說話時可能放大背景噪音
  • ☐ 可能產生不自然的音訊
  • ☐ 不適合專業錄音

建議：

  • ✅ 啟用自動增益：

    • 非正式的團隊會議
    • 品質不是關鍵的快速通話
    • 你走動很多時

  • ❌ 停用自動增益：

    • 專業簡報
    • 播客錄製
    • 客戶會議
    • 任何品質重要的錄音

如何切換：

☑ 自動調整麥克風增益  ← 勾選以啟用
☐ 自動調整麥克風增益  ← 取消勾選以停用

區段 3：系統音訊擷取

系統音訊是來自你電腦的聲音 — 視訊通話聲音、通知聲音、你播放的影片等。擷取這些聲音對於完整的會議錄音至關重要。

會擷取什麼？

系統音訊中包含的內容：

  • Zoom、Teams、Meet 通話中的聲音
  • YouTube、訓練影片的影片音訊
  • 遊戲聲音
  • 電腦上播放的音樂
  • 通知聲音

不包含的內容：

  • 來自其他實體裝置的聲音
  • 你的麥克風（那是獨立的）
  • 來自手機的音訊
  • 外接喇叭播放的實體媒體

系統音訊來源選擇

通常可用的選項：

  1. Default Output Device（預設輸出裝置）

    • 擷取電腦正在播放的任何內容
    • 自動跟隨你的聲音設定
    • 建議大多數使用者使用

  2. 特定輸出裝置

    • 喇叭（Realtek Audio）
    • 耳機（USB Audio）
    • 螢幕音訊（HDMI）
    • 如果你有多個輸出，請使用此選項

  3. Stereo Mix / What U Hear

    • 擷取電腦上播放的所有內容
    • 可能無法在所有系統上使用
    • 可能需要在 Windows 音效設定中啟用

如何設定：

預設系統音訊來源：[Default Output Device ▼]

建議： 除非有特定原因需要從特定輸出擷取，否則使用「Default Output Device」（預設輸出裝置）。

系統音訊與麥克風：混音

當你錄製「兩者」（麥克風 + 系統音訊）時，SeaMeet 會建立混音：

你的聲音 ───────┐
                ├──→ 混合在一起 ──→ 錄音
他們的聲音 ─────┘

為何重要：

  • 錄製後你無法將它們分開
  • 如果其中一個太大聲/太安靜，之後無法修復
  • 錄製前確認兩個電平都正確

測試混音：

  1. 選擇「兩者」後開始測試錄製
  2. 加入測試通話或播放影片
  3. 同時說話並播放影片/通話
  4. 停止並播放
  5. 確認：
    • 你的聲音清晰且明顯
    • 對方的聲音可聽清楚
    • 兩者都不壓過對方

區段 4：藍牙音訊設定

藍牙麥克風和耳機很方便，但在錄音方面有嚴重的注意事項。如果你使用無線音訊裝置，這一節非常重要。

了解藍牙延遲

什麼是延遲？ 聲音產生與被擷取或播放之間的延遲。

藍牙延遲問題：

你說：「你好」
         ↓
藍牙傳輸（50-200ms 延遲）
         ↓
SeaMeet 接收：「你好」（半秒後）
         ↓
錄音有同步問題

藍牙有延遲的原因：

  1. 音訊壓縮（藍牙使用有損編解碼器）
  2. 無線傳輸時間
  3. 裝置處理時間
  4. 不同的藍牙版本有不同的延遲

典型藍牙延遲：

  • 藍牙 4.2：200-300ms（非常明顯）
  • 藍牙 5.0：100-200ms（明顯）
  • 藍牙 5.2 搭配 LE Audio：40-80ms（較好）
  • 有線連線：<10ms（幾乎感知不到）

藍牙警告功能

功能說明： 當 SeaMeet 偵測到你使用藍牙麥克風時，會顯示關於潛在延遲問題的警告。

警告範例：

⚠️ 偵測到藍牙音訊

你正在使用 AirPods 作為麥克風。
藍牙音訊可能導致：
• 你的說話與錄音之間的延遲（100-300ms）
• 與視訊的音訊同步問題
• 由於壓縮造成的音訊品質降低

建議：
• 使用有線 USB 麥克風以獲得最佳效果
• 如果必須使用藍牙，讓裝置靠近電腦
• 在重要會議前進行測試錄製

[仍然使用] [切換至有線麥克風] [取消]

如何啟用/設定：

☑ 使用藍牙麥克風時顯示延遲警告
☑ 如果有線麥克風可用，自動切換

藍牙錄製的最佳做法

何時可以使用藍牙：

  • ✅ 非正式的內部會議
  • ✅ 音訊品質不重要時
  • ✅ 短暫的錄製（<15 分鐘）
  • ✅ 沒有有線選項時

何時應避免藍牙：

  • ❌ 客戶簡報
  • ❌ 公開分享的錄音
  • ❌ 播客或專業內容
  • ❌ 長時間錄製（電池耗盡）
  • ❌ 精確的唇型同步很重要時

如果必須使用藍牙：

  1. 讓裝置靠近：

    • 距離電腦 3 英尺（1 公尺）以內
    • 減少斷線並改善延遲

  2. 確保電量充足：

    • 電量低 = 效能更差
    • 長時間錄製前確認電量

  3. 關閉其他藍牙裝置：

    • 減少干擾
    • 斷開未使用的藍牙周邊裝置

  4. 使用最佳可用的編解碼器：

    • aptX Low Latency（如果支援）：約 40ms
    • AAC（Apple 裝置）：約 120-150ms
    • SBC（標準）：約 200-300ms

  5. 先測試：

    • 總是先進行 30 秒的測試錄製
    • 確認同步問題
    • 確認音訊品質

  6. 考慮替代方案：

    • 有線 USB 耳機：更好的品質，無延遲
    • USB 麥克風 + 有線耳機：專業設置
    • 在手機上單獨錄製音訊，在編輯中同步

區段 5：音訊格式設定

音訊格式決定你的錄音如何被壓縮和儲存。這影響檔案大小、相容性和品質。

SeaMeet 中可用的音訊格式

1. MP3（MPEG-1 Audio Layer III）

  • 最適合： 分享、網路播放、儲存效率
  • 優點： 小型檔案、通用相容性、處理快速
  • 缺點： 有損壓縮（有些品質損失）
  • 典型大小： 每分鐘 1MB（128 kbps）

2. WAV（Waveform Audio File Format）

  • 最適合： 專業編輯、歸檔、最大品質
  • 優點： 未壓縮、無品質損失、業界標準
  • 缺點： 大型檔案、上傳較慢
  • 典型大小： 每分鐘 10MB（CD 品質）

3. WebM（僅音訊子集）

  • 最適合： 網路應用程式、HTML5 播放
  • 優點： 開放格式、良好壓縮、現代化
  • 缺點： 相容性不如 MP3 普遍
  • 典型大小： 每分鐘 0.5-1MB（使用 Opus 編解碼器）

4. OGG（Ogg Vorbis）

  • 最適合： 開源專案、技術應用程式
  • 優點： 免費格式、良好壓縮
  • 缺點： 裝置支援有限
  • 典型大小： 每分鐘 1-2MB

5. M4A（MPEG-4 Audio）

  • 最適合： Apple 生態系統、播客
  • 優點： 低位元率下品質良好、iTunes 相容
  • 缺點： 在 Apple 以外的相容性不一
  • 典型大小： 每分鐘 1MB

品質設定

MP3/M4A（位元率選項）：

品質：[中（128 kbps）▼]

選項：
• 低（96 kbps）      — 小型檔案，可接受的品質
• 中（128 kbps）     — 良好平衡，建議
• 高（192 kbps）     — 更好的品質，較大的檔案
• 非常高（256 kbps） — 出色的品質
• 極高（320 kbps）   — 近乎透明，大型檔案

建議：

  • 語音錄音：128-192 kbps
  • 音樂/內容：192-320 kbps
  • 歸檔：WAV 或 320 kbps MP3

WAV（位元深度選項）：

位元深度：[16 位元 ▼]

選項：
• 16 位元  — CD 品質，標準
• 24 位元  — 專業，更大的動態範圍
• 32 位元浮點 — 最大品質，非常大的檔案

建議：

  • 大多數錄音：16 位元就夠了
  • 專業工作：24 位元
  • 32 位元浮點只有在進行大量音訊處理時才需要

取樣率設定

取樣率：[48 kHz ▼]

選項：
• 44.1 kHz — CD 品質，音樂的標準
• 48 kHz   — 專業視訊標準，建議
• 96 kHz   — 高解析度，對大多數用途來說過度

建議：

  • 視訊錄製使用 48 kHz（與視訊標準相符）
  • 純音訊可以使用 44.1 kHz
  • 較高的取樣率 = 較大的檔案，音訊效益極小

格式選擇指南

情境 1：快速的團隊會議備忘

格式：MP3
品質：中（128 kbps）
取樣率：48 kHz
原因：小型檔案、容易分享、品質足以滿足語音需求

情境 2：客戶簡報錄製

格式：WAV
位元深度：16 位元
取樣率：48 kHz
原因：最大品質、專業歸檔

情境 3：播客錄製

格式：MP3
品質：高（192 kbps）
取樣率：44.1 kHz
原因：良好品質、可管理的大小、播客的標準

情境 4：網路上傳/串流

格式：WebM（Opus 編解碼器）
品質：中
取樣率：48 kHz
原因：針對網路最佳化、小型檔案、良好品質

區段 6：進階音訊設定

噪音抑制

功能說明： 使用軟體演算法去除背景噪音（風扇、空調、鍵盤打字聲）。

設定通常包括：

☑ 啟用噪音抑制
等級：[中 ▼]

等級：
• 輕度 — 只去除明顯的噪音
• 中度 — 平衡的噪音去除（建議）
• 積極 — 去除更多噪音，但可能影響聲音

何時使用：

  • ✅ 嘈雜的環境
  • ✅ 筆記型電腦風扇運轉中
  • ✅ 機械鍵盤打字聲
  • ✅ 空調嗡嗡聲

注意：

  • 積極的抑制可能使聲音聽起來像機器人
  • 可能去除想要的環境聲音
  • 在重要錄製前進行測試

回音消除

功能說明： 防止麥克風拾取喇叭的聲音造成回音。

運作方式：

  1. 電腦播放通話中的聲音
  2. 麥克風可能從喇叭拾取那個聲音
  3. 沒有消除：對方聽到自己的回音
  4. 有消除：軟體去除回聲的聲音

設定：

☑ 啟用回音消除
強度：[正常 ▼]

何時使用：

  • ✅ 使用喇叭而非耳機時
  • ✅ 在有喇叭的會議室中
  • ❌ 使用耳機/耳機時不需要

注意： 回音消除可能略微降低音訊品質。盡可能使用耳機替代。

自動增益控制（AGC）

在區段 2 中已提及，但值得注意進階選項：

☑ 啟用 AGC
起始時間：[快速 ▼]  — 對大聲聲音反應的速度
釋放時間：[緩慢 ▼]  — 恢復正常的速度
最大增益：[+20 dB ▼] — 允許的最大放大量

微調：

  • 起始時間： 快速 = 對突然的大聲聲音迅速反應
  • 釋放時間： 緩慢 = 平滑過渡，避免泵浦效果
  • 最大增益： 限制安靜聲音被增強的程度（防止噪音放大）

區段 7：音訊問題排除

問題 1：未偵測到麥克風

症狀：

  • 麥克風未出現在下拉清單中
  • 「找不到麥克風」錯誤
  • 測試顯示沒有輸入

解決方法：

  1. 確認實體連線：

    • 確認 USB 線已牢固插入
    • 嘗試不同的 USB 連接埠
    • 確認麥克風是否有電源指示燈

  2. Windows 音效設定：

    • 右鍵點擊工作列中的喇叭圖示 → 開啟音效設定
    • 點擊「音效控制台」（右側）
    • 前往「錄音」標籤
    • 確認麥克風是否出現
    • 如果出現但已停用：右鍵點擊 → 啟用
    • 如果出現但非預設：右鍵點擊 → 設為預設裝置

  3. 更新驅動程式：

    • 裝置管理員 → 音訊輸入和輸出
    • 找到你的麥克風
    • 右鍵點擊 → 更新驅動程式
    • 或解除安裝並重新啟動（Windows 會重新安裝）

  4. macOS 權限：

    • 系統偏好設定 → 安全性與隱私 → 隱私
    • 點擊左側的「麥克風」
    • 確認 SeaMeet 已勾選

  5. 重新啟動 SeaMeet：

    • 完全關閉並重新開啟
    • 有時需要完整重新啟動電腦

問題 2：錄音太安靜

症狀：

  • 電平表幾乎不動
  • 播放需要最大音量才能聽到
  • 轉錄失敗或不準確

解決方法：

  1. 提高增益：

    • 音訊設定 → 麥克風增益滑桿
    • 增加至 70-80%

  2. 啟用增強：

    • 開啟「Boost」（增強）選項
    • 設為 10-20%

  3. 靠近麥克風：

    • 理想距離：6-12 英寸（15-30 公分）
    • 太遠 = 安靜且拾取房間噪音
    • 太近 = 爆音和失真

  4. 確認 Windows 電平：

    • 音效控制台 → 錄音
    • 雙擊你的麥克風
    • 電平標籤 → 增加至 80-100%

  5. 確認靜音按鈕：

    • 許多麥克風都有實體靜音按鈕
    • 某些在其控制面板中有軟體靜音

問題 3：錄音太大聲/失真

症狀：

  • 電平表一直在紅色區域
  • 音訊聽起來有雜音或爆裂
  • 達到最大電平的峰值

解決方法：

  1. 降低增益：

    • 音訊設定 → 將增益降低至 40-60%

  2. 停用增強：

    • 如果已啟用，關閉增強

  3. 遠離麥克風：

    • 增加距離至 12-18 英寸
    • 使用防噴嘴以減少爆音

  4. 說話輕柔一點：

    • 調整你的說話音量
    • 正常對話的音量最好

  5. 確認 Windows 中是否有削波：

    • 音效控制台 → 錄音 → 內容
    • 電平標籤 → 確認沒有在帶增強的情況下達到 100%

問題 4：背景噪音/嘶嘶聲

症狀：

  • 持續的嗡嗡聲或嘶嘶聲
  • 風扇噪音、鍵盤聲
  • 房間回音

解決方法：

對於機械噪音：

  1. 啟用噪音抑制（音訊設定）
  2. 設為中度或積極
  3. 將麥克風遠離電腦風扇
  4. 使用指向性麥克風

對於鍵盤聲：

  1. 使用按下說話功能（如果可用）
  2. 將鍵盤遠離麥克風
  3. 使用機械鍵盤靜音貼片
  4. 將麥克風放在鍵盤上方的懸臂支架上

對於房間回音：

  1. 添加軟質陳設品（窗簾、地毯、靠墊）
  2. 在較小的房間錄製
  3. 使用聲學泡棉板
  4. 靠近麥克風（減少房間聲音）

對於電子嘶嘶聲：

  1. 降低麥克風增益（降低噪音底限）
  2. 靠近麥克風（改善訊噪比）
  3. 使用更高品質的麥克風
  4. 確認線纜連線

問題 5：系統音訊未錄製

症狀：

  • 其他人的聲音不在錄音中
  • 通話中可以聽到他們，但播放中聽不到
  • 只錄製了你的聲音

解決方法：

  1. 確認錄製模式：

    • 確認你正在錄製「系統音訊」或「兩者」
    • 而非只是「麥克風」

  2. 確認系統音訊來源：

    • 音訊設定 → 預設系統音訊來源
    • 確認設定為正確的輸出

  3. Windows Stereo Mix：

    • 某些系統需要啟用「Stereo Mix」
    • 音效控制台 → 錄音
    • 在空白區域右鍵點擊 → 顯示已停用的裝置
    • 右鍵點擊 Stereo Mix → 啟用
    • 設為 SeaMeet 的預設

  4. macOS 螢幕錄製權限：

    • 系統偏好設定 → 安全性與隱私 → 隱私
    • 螢幕錄製
    • 確認 SeaMeet 已勾選
    • 啟用後重新啟動 SeaMeet

  5. 確認通話音訊：

    • 確認通話音訊是從電腦播放
    • 而非從手機或不同裝置播放
    • 在錄製時播放 YouTube 影片進行測試

問題 6：音訊/視訊同步問題

症狀：

  • 嘴唇在動，但聲音之後才出現
  • 音訊聽起來有延遲
  • 使用藍牙時特別嚴重

解決方法：

  1. 使用有線麥克風：

    • 從藍牙切換至 USB 或有線耳機
    • 消除無線延遲

  2. 重新啟動電腦：

    • 清除音訊緩衝問題
    • 重設音效驅動程式

  3. 確認藍牙延遲：

    • 如果使用藍牙，那可能是原因
    • 遵循區段 4 中的藍牙最佳做法

  4. 調整緩衝區大小（進階）：

    • 某些版本允許調整緩衝區
    • 較大的緩衝區 = 更多延遲但較少卡頓
    • 較小的緩衝區 = 較少延遲但可能卡頓

  5. 後製修復：

    • 如果已錄製了有同步問題的內容：
    • 匯入影片編輯器（DaVinci Resolve、Premiere）
    • 手動調整音訊軌時間

區段 8：錄製情境設定

情境 1：專業播客錄製

目標： 最大品質、歸檔標準

設定：

麥克風：USB 電容麥克風（Blue Yeti、AT2020）
增益：65%（峰值在 -6 dB）
增強：關閉
自動增益：關閉
格式：WAV（24 位元，48 kHz）
噪音抑制：輕度或關閉
回音消除：關閉
系統音訊：關閉（除非進行訪談）
藍牙：絕不使用

實體設置：

  • 麥克風距離嘴巴 6-8 英寸
  • 麥克風前方的防噴嘴
  • 有軟質陳設品的安靜房間
  • 使用耳機監聽（不用喇叭）

情境 2：每日團隊站立會議

目標： 良好品質、高效儲存、快速分享

設定：

麥克風：耳機或內建麥克風（方便勝於品質）
增益：70%
增強：10%（如果使用筆記型電腦麥克風）
自動增益：開啟（說話聲音不一致）
格式：MP3（192 kbps）
取樣率：48 kHz
噪音抑制：中度
回音消除：開啟（使用喇叭）
系統音訊：開啟（擷取團隊聲音）
藍牙：只在必要時使用，先測試

實體設置：

  • 筆記型電腦放在桌上，正常距離
  • 建議使用耳機，有回音消除的喇叭也可以
  • 不用擔心輕微的背景噪音

情境 3：客戶簡報錄製

目標： 專業品質、可靠的擷取、備份安全

設定：

麥克風：高品質 USB 麥克風或耳機
增益：測試並設定為 -12 dB 峰值
增強：關閉
自動增益：關閉
格式：WAV（16 位元）作為主要，MP3 作為備份
取樣率：48 kHz
噪音抑制：輕度
回音消除：關閉（使用耳機）
系統音訊：開啟（擷取客戶音訊）
藍牙：絕不使用（風險太高）

實體設置：

  • 專用的安靜空間
  • USB 麥克風放在桌上
  • 使用耳機清楚聽到客戶
  • 通話前 5 分鐘進行測試錄製
  • 讓備用音訊錄音機持續執行（手機、第二個應用程式）

情境 4：遊戲/教學錄製

目標： 聲音清晰度與遊戲音訊的平衡

設定：

麥克風：耳機麥克風或專用 USB
增益：60-70%
增強：關閉
自動增益：關閉（防止安靜遊戲時段的音量泵浦）
格式：MP3（192 kbps）或 M4A
取樣率：48 kHz
噪音抑制：中度（鍵盤聲）
回音消除：關閉（佩戴耳機）
系統音訊：開啟（遊戲音訊）
藍牙：絕不使用（延遲會破壞遊戲體驗）

實體設置：

  • 有良好隔音的耳機
  • 機械鍵盤靜音貼片或安靜的鍵盤
  • 麥克風放在遠離鍵盤的位置
