儲存設定

第 19 章：儲存設定

簡介

你用 SeaMeet 製作的每一個錄音都需要一個家 — 一個存放在電腦上的地方，直到你決定移動、刪除或永久保留它。儲存設定是管理這些數位資產的控制面板。把自己想像成錄音的物業管理人：你決定它們住在哪個「社區」（資料夾）、房子能有多大（檔案大小限制），以及何時進行大掃除（自動刪除）。

讀完本章後，你將清楚知道如何控制錄音的儲存位置、如何防止硬碟爆滿，以及如何整理不斷增加的會議、簡報和創意內容錄音庫。

本章目標

閱讀本章後，你將能夠：

  • 更改所有錄音的預設儲存位置
  • 在磁碟空間不足前設定儲存警告
  • 設定舊錄音的自動清理
  • 了解檔案命名慣例和整理方式
  • 將現有錄音移至新位置
  • 排除儲存相關問題
  • 計算所需的儲存空間

為何儲存設定重要

讓我說一個故事。Sarah 是一位專案管理師，她使用 SeaMeet 錄製所有團隊的每日站立會議。三個月來，一切運作順暢 — 錄音自動儲存，播放流暢，她可以輕鬆參考過去的討論。然後有一天，她的電腦開始運作緩慢。程式崩潰了。她無法儲存新檔案。經過調查，她發現 C: 磁碟完全滿了 — 47GB 的 SeaMeet 錄音在她不知情的情況下累積了！

這個故事說明了為何儲存管理不只是「有更好」的選項 — 對於以下情況來說，它至關重要：

防止系統問題

  • 硬碟滿時，整台電腦會變慢
  • Windows 和 macOS 需要可用空間才能正常運作
  • 磁碟已滿會阻止軟體更新並導致崩潰

維持效能

  • SeaMeet 在錄製過程中需要空間來建立暫存檔案
  • 視訊錄製尤其需要大量可用空間才能順暢運作
  • Flashback 錄製使用 RAM 和磁碟空間作為緩衝

保持整齊

  • 沒有管理，錄音就會堆成一大堆
  • 找到特定錄音變成惡夢
  • 一切混亂時，備份也變得困難

控制成本

  • 雲端備份的費用取決於使用的儲存空間
  • 需要根據用量選擇適合大小的外接硬碟
  • 了解你的用量有助於規劃儲存採購

了解儲存基礎知識

在深入設定之前，讓我們先了解一些儲存基礎知識：

錄音佔用多少空間？

純音訊錄音：

  • MP3 格式（標準品質）：每分鐘約 1MB
  • WAV 格式（高品質）：每分鐘約 10MB
  • 1 小時的 MP3 會議：約 60MB
  • 1 小時的 WAV 會議：約 600MB

視訊錄音：

  • 1080p 30fps（高品質）：每分鐘約 150-300MB
  • 720p 30fps（標準品質）：每分鐘約 75-150MB
  • 480p 30fps（基本品質）：每分鐘約 25-50MB
  • 1 小時的 1080p 錄音：約 9-18GB
  • 1 小時的 720p 錄音：約 4.5-9GB

Flashback 錄製（連續緩衝）：

  • 音訊緩衝（30 秒）：使用 RAM，不使用磁碟
  • 視訊緩衝（不定）：根據時長和品質使用約 30-600MB 的 RAM

實際範例： 如果你每天錄製一場 1080p 的一小時視訊會議：

  • 每天：約 15GB
  • 每週（5 場會議）：約 75GB
  • 每月（20 場會議）：約 300GB
  • 每年：約 3.6TB

這佔用大量空間！這就是為何儲存管理至關重要。

儲存位置：可以儲存在哪裡？

內建硬碟（Windows 上的 C: 磁碟，Mac 上的 Macintosh HD）

  • 優點：速度快、隨時可用、不需額外硬體
  • 缺點：空間有限、容易填滿、滿了會影響系統效能

外接硬碟（USB 連線）

  • 優點：容量大（1TB-5TB+）、不影響系統磁碟、可攜帶
  • 缺點：錄製時必須連接、比內建硬碟慢、可能意外斷線

網路磁碟機（NAS、共用資料夾）

  • 優點：集中儲存、可從多台電腦存取、自動備份
  • 缺點：需要網路連線、錄製效能較慢、設定複雜

雲端儲存（OneDrive、Google Drive、Dropbox 資料夾）

  • 優點：自動備份、任何地方皆可存取、跨裝置同步
  • 缺點：需要網路、上傳時間延遲、持續訂閱費用

最佳做法： 許多使用者將錄音暫時儲存至內建磁碟，然後將較舊的錄音移至外接儲存或雲端備份。

現在讓我們逐一詳細說明每個區段。

區段 1：儲存位置

這是最重要的儲存設定 — 它決定你所有錄音存放的位置。

如何更改儲存位置

步驟說明：

  1. 開啟儲存設定

    • 點擊 SeaMeet 左側邊欄中的設定齒輪圖示
    • 點擊分類清單中的「Storage」（儲存）

  2. 找到「Save Location」（儲存位置）

    • 找到顯示目前路徑的文字欄位
    • 可能如下所示：C:\Users\你的名字\SeaMeet 錄音

  3. 點擊「Browse...」（瀏覽...）

    • 檔案瀏覽器視窗將開啟

  4. 導覽至你想要的位置

    • 內建磁碟機：點擊「此電腦」然後選擇 C: 或 D: 磁碟
    • 外接磁碟機：在「此電腦」下尋找你的 USB 磁碟機
    • 網路位置：使用位址列輸入路徑

  5. 選擇或建立資料夾

    • 你可以選擇現有資料夾
    • 或建立新資料夾：右鍵點擊 → 新增資料夾 → 命名（例如「SeaMeet 錄音」）

  6. 點擊「Select Folder」（選取資料夾）或「OK」（確定）

    • 檔案瀏覽器關閉
    • 新路徑顯示在文字欄位中

  7. 點擊「Apply」（套用）

    • 你的變更已儲存
    • 未來的錄音將存至新位置

路徑範例：

Windows：
- 內建：C:\Users\Sarah\Documents\SeaMeet 錄音
- 外接：D:\SeaMeet 錄音
- 網路：\\server\shared\recordings

macOS：
- 內建：/Users/sarah/Documents/SeaMeet Recordings
- 外接：/Volumes/ExternalDrive/SeaMeet Recordings
- 網路：/Volumes/Server/recordings

選擇正確的位置

情境 1：你有充裕的內建空間

  • 目前狀況：C: 磁碟有 500GB+ 的可用空間
  • 建議：保持預設位置
  • 原因：效能最快、設定最簡單

情境 2：你的 C: 磁碟快滿了

  • 目前狀況：可用空間不足 100GB
  • 建議：移至 D: 磁碟或外接儲存
  • 步驟：
    1. 將現有錄音複製至新位置
    2. 在設定中更改儲存位置
    3. 確認新錄音正常運作
    4. 刪除舊副本（先備份！）

情境 3：你有大容量外接硬碟

  • 目前狀況：2TB 外接 USB 磁碟機
  • 建議：直接儲存至外接磁碟機
  • 步驟：
    1. 確保錄製時磁碟機始終連接
    2. 在設定中將儲存位置設為外接磁碟機
    3. 考慮將該磁碟機專用於錄音

情境 4：你使用雲端儲存

  • 目前狀況：已同步的 OneDrive 或 Google Drive 資料夾
  • 建議：儲存至雲端磁碟中的子資料夾
  • 步驟：
    1. 在雲端磁碟中建立「SeaMeet 錄音」資料夾
    2. 將其設為儲存位置
    3. 錄音自動同步至雲端
    4. 注意：大型視訊檔案可能需要較長時間上傳

將現有錄音移至新位置

當你更改儲存位置時，SeaMeet 不會自動移動現有錄音。以下是正確的操作方式：

重要： 移動檔案前請務必先備份！

步驟說明：

  1. 開啟兩個資料夾

    • 開啟你目前的錄音資料夾（舊位置）
    • 開啟你的新錄音資料夾（新位置）
    • 將視窗並排排列

  2. 選取所有現有錄音

    • 在舊資料夾中，按 Ctrl+A（Windows）或 Cmd+A（Mac）選取全部
    • 或手動選取要移動的特定錄音

  3. 複製（先不要移動！）

    • 按 Ctrl+C（Windows）或 Cmd+C（Mac）複製
    • 點擊新資料夾位置
    • 按 Ctrl+V（Windows）或 Cmd+V（Mac）貼上
    • 等待複製完成（大型檔案可能需要一段時間）

  4. 確認複製結果

    • 確認所有檔案都出現在新位置
    • 播放一兩個錄音以確認可以正常使用
    • 確認檔案大小相符

  5. 更新 SeaMeet 設定

    • 開啟 SeaMeet 設定 → 儲存
    • 將儲存位置更改為新資料夾
    • 點擊「套用」

  6. 測試新錄音

    • 進行短暫的測試錄製
    • 確認它出現在新位置
    • 播放以確認運作正常

  7. 刪除舊副本（選用）

    • 只有在確認一切正常後才這樣做！
    • 在舊位置選取檔案
    • 按 Delete 鍵
    • 確認刪除
    • 或移至資源回收筒/垃圾桶以策安全

替代方式：移動而非複製 如果你有信心且空間有限：

  • 跳過步驟 3-4
  • 在步驟 3 中使用 Ctrl+X（剪下）而非 Ctrl+C（複製）
  • 然後 Ctrl+V 貼至新位置
  • 檔案移動而非複製（更快，但沒有備份）

常見的儲存位置問題

問題 1：更改位置時出現「存取被拒絕」

原因： 你沒有寫入所選資料夾的權限。

解決方法：

  1. 選擇不同位置（例如你的「文件」資料夾）
  2. 以管理員身分執行 SeaMeet（右鍵點擊 → 以管理員身分執行）
  3. 檢查資料夾權限（右鍵點擊資料夾 → 內容 → 安全性）

問題 2：瀏覽時外接磁碟機未顯示

原因： 磁碟機未連接、格式化不正確或驅動程式問題。

解決方法：

  1. 確認磁碟機已插入並已開機
  2. 在檔案總管（Windows）或 Finder（Mac）中確認磁碟機是否出現
  3. 嘗試不同的 USB 連接埠
  4. 重新啟動電腦
  5. 在磁碟管理（Windows）或磁碟工具程式（Mac）中檢查磁碟機狀態

問題 3：網路磁碟機無法使用

原因： 網路連線問題、磁碟機離線或權限不足。

解決方法：

  1. 確認你已連線至網路
  2. 先嘗試透過檔案總管/Finder 存取磁碟機
  3. 確認是否需要輸入憑證
  4. 如果是工作網路磁碟機，請聯絡 IT 部門

問題 4：錄音未出現在新位置

原因： 設定未儲存，或 SeaMeet 使用了快取的位置。

解決方法：

  1. 完全重新啟動 SeaMeet
  2. 確認設定已套用
  3. 確認沒有多個 SeaMeet 執行個體在執行
  4. 嘗試重新設定位置並立即點擊「套用」

區段 2：儲存使用量監控

儲存使用量區段提供你錄音儲存狀況的視覺儀表板。把它想像成數位儲存的油量計。

了解儲存顯示

你通常會看到：

目前儲存使用量
┌──────────────────────────────────────────────────────┐
│ 錄音資料夾：已使用 47.3 GB                             │
│ 可用空間：剩餘 12.7 GB                                │
│ 總容量：500 GB                                        │
│                                                      │
│ █████████████████████████████████░░░░░░░░░░░░░░░░░   │
│ 79% 已滿 — 警告閾值：85%                              │
└──────────────────────────────────────────────────────┘

數字說明：

  • 錄音資料夾： 你的實際錄音佔用多少空間
  • 可用空間： 該磁碟機剩餘多少空間
  • 總容量： 磁碟機/分割區的總大小
  • 視覺長條： 使用量的圖形呈現
  • 百分比： 你的儲存空間有多滿
  • 警告閾值： 何時開始收到警告

顏色標示（大多數版本）：

  • 🟢 綠色：低於 50% — 狀況很好！
  • 🟡 黃色：50-80% — 留意一下
  • 🟠 橘色：80-90% — 警告區域，考慮清理
  • 🔴 紅色：90%+ — 危急！立即清理！

為何這些數字重要

新錄音的可用空間：

  • 需要錄製一場 2 小時的視訊會議？
  • 以 1080p 計算，大約需要 20-30GB
  • 如果你只有 15GB 可用，你將無法錄製！

系統效能：

  • Windows 需要至少 10-15% 的可用空間才能正常運作
  • macOS 也需要大量可用空間用於虛擬記憶體
  • 磁碟已滿會導致速度變慢、崩潰和問題

Flashback 錄製需求：

  • Flashback 需要 RAM 和一些磁碟空間作為緩衝
  • 如果儲存嚴重不足，Flashback 可能無法正常運作

不同儲存水準應採取的措施

綠色區域（0-50% 已滿）：

  • 你狀況良好！
  • 繼續正常錄製
  • 也許設定自動清理作為預防措施
  • 目前不需要立即行動

黃色區域（50-80% 已滿）：

  • 監控情況
  • 考慮設定儲存警告
  • 為未來規劃清理策略
  • 仍可安全地正常錄製

橘色區域（80-90% 已滿）：

  • ⚠️ 警告區域！
  • 如果尚未啟用，設定儲存警告
  • 考慮將舊錄音移至外接儲存
  • 啟用自動清理
  • 確認是否有可以刪除的錄音
  • 功能仍正常，但要主動應對

紅色區域（90%+ 已滿）：

  • 🚨 危急！需要立即行動！
  • 在釋放空間前停止錄製
  • 立即將錄音移至外接磁碟機
  • 刪除不必要的檔案
  • 清空資源回收筒/垃圾桶
  • 執行磁碟清理工具
  • 確認是否有重複的錄音

區段 3：儲存警告

儲存警告就像汽車的油量警示燈 — 在你空間耗盡前提醒你。這讓你有時間採取行動，而不是在錄製中途被「磁碟已滿」錯誤嚇到。

儲存警告的運作方式

警告閾值設定： 你可以設定 SeaMeet 何時應警告你儲存空間不足：

儲存空間不足時顯示警告：[80% ▼]

選項通常包括：

  • 70% 已滿
  • 75% 已滿
  • 80% 已滿（建議）
  • 85% 已滿
  • 90% 已滿
  • 自訂百分比

達到閾值時的情況：

  1. 視覺警告：

    • 出現通知彈出視窗
    • 儲存長條變為橘色/紅色
    • 介面中出現警告圖示

  2. 錄製前警告：

    • 如果啟用，在開始錄製前警告你
    • 顯示估計所需空間與可用空間
    • 讓你選擇取消或繼續

  3. 系統匣圖示指示器：

    • SeaMeet 系統匣圖示可能會改變
    • 顯示警告徽章或顏色變化

警告訊息範例：

⚠️ 儲存警告

你的錄音資料夾已達 87% 滿（已使用 43.5 GB，共 50 GB）。
僅剩 6.5 GB。

1 小時的視訊錄製約需要 15 GB。
你可能沒有足夠空間完成錄製。

[管理儲存] [仍然繼續] [取消]

設定儲存警告

步驟說明：

  1. 開啟儲存設定

  2. 找到「Storage Warnings」（儲存警告）區段

  3. 啟用「Show warning when storage is low」（儲存空間不足時顯示警告）

    • 勾選核取方塊或切換開關

  4. 設定你的閾值

    • 點擊下拉選單（目前顯示百分比）
    • 選擇你偏好的閾值
    • 建議：
      • 重度使用者：70-75%
      • 一般使用者：80%
      • 輕度使用者：85-90%

  5. 啟用「Show warning before recording if low space」（空間不足時在錄製前顯示警告）

    • 這可防止你開始一個無法完成的錄製
    • 強烈建議！

  6. 點擊「Apply」（套用）

測試你的警告： 確認警告正常運作：

  1. 暫時將閾值設得很低（例如 10%）
  2. 確認警告是否出現
  3. 將閾值重設為你偏好的值
  4. 點擊「套用」

錄製前空間檢查

這是最實用的功能之一 — 它在你開始錄製前計算你是否有足夠空間。

運作方式：

  1. 你點擊「開始錄製」
  2. SeaMeet 根據以下條件估算所需空間：
    • 錄製類型（純音訊或視訊）
    • 選取的品質設定
    • 時長（如果已知，否則假設為 1 小時）
  3. 比較所需空間與可用空間
  4. 如果空間不足，警告你

估算範例：

此錄製估計所需空間：
• 純音訊（MP3）：每小時 60 MB
• 純音訊（WAV）：每小時 600 MB
• 視訊（1080p）：每小時 18 GB
• 視訊（720p）：每小時 9 GB
• 視訊（480p）：每小時 3 GB

你有 12 GB 可用。
建議的最長錄製時間：1080p 下約 40 分鐘

為何重要： 沒有什麼比錄製了重要的 2 小時會議，卻因為磁碟已滿而在 45 分鐘後中斷，更讓人沮喪的了。這個警告可以防止這種情況發生。

區段 4：自動清理

自動清理就像有一個機器人助手，定期整理你的錄音並刪除你可能不再需要的舊錄音。這是一種設定好就不用管的儲存管理方式。

自動清理的運作方式

基本概念： SeaMeet 自動刪除符合特定時間條件的錄音，同時保護你可能仍需要的最近錄音。

兩個主要控制項：

  1. 時間閾值： 刪除超過 X 天的錄音
  2. 最小保留量： 始終至少保留最近的 Y 個錄音

設定範例：

☑ 自動刪除舊錄音
刪除超過此天數的錄音：[90 天 ▼]
至少保留：[最近的 10 個 ▼]
☑ 移至資源回收筒而非永久刪除

實際運作方式：

  • 你有過去 6 個月的 50 個錄音
  • 30 個錄音超過 90 天
  • SeaMeet 將刪除最舊的 20 個
  • 但它保留最近的 10 個（即使某些超過 90 天）
  • 結果：你保留 30 個錄音（最近的 10 個 + 20 個足夠新的）

設定自動清理

步驟說明：

  1. 開啟儲存設定

  2. 找到「Automatic Cleanup」（自動清理）區段

  3. 啟用「Automatically delete old recordings」（自動刪除舊錄音）

    • 切換開關至開啟

  4. 設定時間閾值

    • 點擊下拉選單
    • 選擇保留錄音的時間長度
    • 選項通常為：7、14、30、60、90、180、365 天
    • 大多數使用者的建議：90 天（3 個月）

  5. 設定最小保留數量

    • 選擇始終要保留多少個最近的錄音
    • 選項通常為：5、10、20、50 或全部
    • 建議：10-20 個錄音

  6. 選擇刪除方式

    • ☑ 移至資源回收筒（更安全，需要時可恢復）
    • ☐ 永久刪除（立即釋放空間，無法恢復）
    • 建議：使用資源回收筒！

  7. 點擊「Apply」（套用）

清理何時發生？

  • 每天：通常每天檢查一次
  • 啟動時：可能在 SeaMeet 啟動時檢查
  • 手動觸發：某些版本有「立即清理」按鈕
  • 錄製後：可能在你完成錄製後檢查

選擇正確的清理設定

輕度使用者（每週 1-2 個錄音）：

時間閾值：180 天（6 個月）
最小保留量：20 個錄音
原因：你不常建立錄音，所以保留較長時間

一般使用者（每週 3-5 個錄音）：

時間閾值：90 天（3 個月）
最小保留量：10 個錄音
原因：適合中度使用的平衡方式

重度使用者（每日錄音）：

時間閾值：30 天（1 個月）
最小保留量：10 個錄音
原因：頻繁錄音很快就會填滿空間，需要積極清理

商業/合規使用者：

時間閾值：365 天（1 年）或更長
最小保留量：50 個以上錄音
☐ 停用自動清理
原因：法律或合規要求可能規定需保留錄音
注意：手動管理儲存或使用外部歸檔

重要的安全功能

資源回收筒保護：

  • 始終啟用「移至資源回收筒」
  • 已刪除的錄音在資源回收筒中保留 30 天（Windows）或直到清空垃圾桶（Mac）
  • 你可以恢復意外刪除的錄音
  • 若要永久釋放空間，需要單獨清空資源回收筒

已標記/最愛保護：

  • 某些版本不刪除已標記或加入最愛的錄音
  • 標記重要錄音以防止被清理刪除
  • 在清理設定中確認你的版本是否有此功能

手動覆寫：

  • 你隨時可以手動刪除錄音
  • 手動刪除立即發生
  • 自動清理只刪除舊的、未受保護的錄音

監控自動清理

查看清理記錄： 某些版本顯示清理記錄：

清理記錄（過去 30 天）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1 月 15 日 — 刪除 3 個錄音（最舊：95 天）
1 月 14 日 — 刪除 2 個錄音（最舊：92 天）
1 月 12 日 — 刪除 5 個錄音（最舊：98 天）
1 月 8 日 — 無需清理

取得清理通知： 你可以選擇在清理發生時收到通知：

☑ 刪除舊錄音時通知我
☑ 顯示清理摘要
☑ 超過 10 個檔案時在刪除前警告

暫時停用： 如果你需要暫停清理：

  1. 前往儲存設定
  2. 取消勾選「自動刪除舊錄音」
  3. 點擊「套用」
  4. 準備好時重新啟用（清理將恢復）

區段 5：檔案整理

錄音的命名和整理方式對之後找到它們有很大影響。良好的整理可以將混亂的一堆變成可搜尋的資料庫。

檔案命名模式

是什麼： 命名模式決定你儲存錄音時的預設檔案名稱。

可用模式（典型選項）：

  1. 日期_時間（簡單）

    2024-01-15_14-30-22.mp4
    • 優點：簡單、按時間順序排列
    • 缺點：無法了解錄製內容

  2. 日期_時間_應用程式（建議）

    2024-01-15_14-30-22_Zoom.mp4
2024-01-15_14-30-22_Teams.mp4
    • 優點：知道使用哪個應用程式，按時間順序排列
    • 缺點：仍然無法說明會議主題

  3. 應用程式_日期_時間

    Zoom_2024-01-15_14-30-22.mp4
Teams_2024-01-15_14-30-22.mp4
    • 優點：按應用程式分組，容易找到特定平台
    • 缺點：在每個應用程式內，按日期排序

  4. 自訂模式

    {YYYY}-{MM}-{DD}_{HH}-{mm}-{ss}_{App}_{Custom}
    • 某些版本允許建立自訂模式
    • 使用如日期、時間、應用程式名稱等變數

如何更改：

  1. 開啟儲存設定
  2. 找到「File Organization」（檔案整理）區段
  3. 點擊「Naming pattern」（命名模式）下拉選單
  4. 選擇你偏好的模式
  5. 點擊「套用」

建立子資料夾

是什麼： 根據時間段或其他條件自動將錄音整理至資料夾。

整理選項：

  1. 無子資料夾（扁平結構）

    /SeaMeet 錄音/
  ├── 2024-01-15_14-30-22_Zoom.mp4
  ├── 2024-01-15_16-00-00_Teams.mp4
  └── 2024-01-16_09-00-00_Zoom.mp4
    • 所有錄音在同一個資料夾
    • 簡單但可能變得擁擠

  2. 按年

    /SeaMeet 錄音/
  ├── 2023/
  │   └── [2023 年的錄音...]
  └── 2024/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      └── [2024 年的錄音...]
    • 按年份分隔
    • 適合長期歸檔

  3. 按月（建議）

    /SeaMeet 錄音/
  └── 2024-01/
      ├── 2024-01-15_14-30-22_Zoom.mp4
      ├── 2024-01-15_16-00-00_Teams.mp4
      └── 2024-01-16_09-00-00_Zoom.mp4
    • 按月份分隔
    • 平衡的整理方式
    • 容易找到最近的錄音
    • 適合每月清理/審查

  4. 按週

    /SeaMeet 錄音/
  └── 2024-W03/
      ├── [第 3 週的錄音...]
    • 按週數分隔
    • 適合專案型工作
    • 可與衝刺週期對齊

  5. 按天

    /SeaMeet 錄音/
  └── 2024-01-15/
      ├── 14-30-22_Zoom.mp4
      └── 16-00-00_Teams.mp4
    • 按天分隔
    • 最細緻的分類
    • 如果你經常錄製，會有很多資料夾

如何設定：

  1. 開啟儲存設定
  2. 找到「Create subfolders by」（建立子資料夾）
  3. 選擇你偏好的整理方式
  4. 點擊「套用」
  5. 新錄音將遵循此結構

注意： 現有錄音保留在目前位置；這只影響新的錄音。

整理的最佳做法

「按月 + 應用程式」策略（強烈建議）：

命名：日期_時間_應用程式
子資料夾：按月

結果：

/SeaMeet 錄音/
  ├── 2024-01/
  │   ├── 2024-01-15_14-30-22_Zoom.mp4
  │   ├── 2024-01-15_16-00-00_Teams.mp4
  │   └── 2024-01-16_09-00-00_Zoom.mp4
  └── 2024-02/
      ├── 2024-02-01_10-00-00_Meet.mp4
      └── 2024-02-05_14-00-00_Zoom.mp4

為何有效：

  1. 時間順序： 容易按日期找到錄音
  2. 不會令人不知所措： 每個月的檔案數量可管理
  3. 應用程式識別： 知道使用哪個平台
  4. 容易清理： 舊了就刪除整個月份的資料夾
  5. 簡單備份： 將月份資料夾複製至外接儲存

區段 6：儲存最佳做法

3-2-1 備份規則

對於重要的錄音，請遵循業界標準的 3-2-1 備份策略：

3： 保留 3 份重要資料的副本

  • 原始錄音
  • 本機備份（外接硬碟）
  • 雲端備份（OneDrive、Google Drive 等）

2： 使用 2 種不同的儲存類型

  • 內建硬碟（原始）
  • 外接硬碟或雲端（備份）

1： 在異地保留 1 份備份

  • 雲端儲存符合異地要求
  • 或將外接硬碟保存在不同的物理位置

如何應用於 SeaMeet：

  1. 錄製至內建硬碟（快速、立即存取）
  2. 設定自動同步至雲端資料夾（OneDrive、Dropbox）
  3. 每月：將重要錄音複製至外接硬碟
  4. 每季：將較舊的錄音移至外接歸檔

計算你的儲存需求

使用此公式估算你的需求：

所需儲存空間 = （每日用量 × 天數）+ 安全緩衝 + 增長空間

計算範例：

情境：你每天在工作日錄製 2 小時的 1080p 視訊

每日：2 小時 × 15 GB/小時 = 每天 30 GB
每週：30 GB × 5 天 = 每週 150 GB
每月：150 GB × 4 週 = 每月 600 GB
每年：600 GB × 12 個月 = 每年 7.2 TB

安全緩衝：20% = 1.44 TB
增長係數：1.5× (50% 增長) = 3.6 TB

建議總量：7.2 + 1.44 + 3.6 = 12.24 TB

實際建議：

  • 輕度使用者（每週 1 小時純音訊）：每年 100 GB
  • 一般使用者（每週 5 小時混合）：每年 1-2 TB
  • 重度使用者（每天 2 小時視訊）：每年 5-10 TB

管理儲存成本

如果使用雲端儲存：

  • 純音訊：非常實惠（100GB 約每月 2-5 美元）
  • 視訊錄音：可能很快就變貴
  • 1TB 視訊在雲端：約每月 10-20 美元
  • 10TB 視訊在雲端：約每月 100-200 美元

節省成本策略：

  1. 日常會議使用較低視訊品質（720p 而非 1080p）
  2. 大多數會議只保留音訊，只在需要時錄視訊
  3. 將舊錄音歸檔至較便宜的冷儲存
  4. 轉錄/摘要後刪除錄音
  5. 使用壓縮格式（MP3、壓縮 MP4）

如果使用外接硬碟：

  • 1TB 外接硬碟：約 50-70 美元（一次性費用）
  • 4TB 外接硬碟：約 100-120 美元（一次性費用）
  • 8TB 外接硬碟：約 150-200 美元（一次性費用）
  • 對於大型視訊資料庫來說更具成本效益

每月儲存維護例行程序

每月撥出 15 分鐘進行儲存維護：

每月第 1 週：

  1. 查看儲存儀表板

    • 開啟 SeaMeet → 設定 → 儲存
    • 記錄目前使用百分比
    • 確認可用空間

  2. 審查自動清理

    • 如果可用，確認清理記錄
    • 確認設定正常運作
    • 視需要調整

  3. 移動舊錄音

    • 在外接硬碟上為上個月建立資料夾
    • 複製超過 30 天的錄音
    • 確認副本正常運作
    • 從內建硬碟刪除

  4. 清空資源回收筒

    • 右鍵點擊資源回收筒 → 清空
    • 永久釋放空間

  5. 更新備份

    • 同步雲端資料夾
    • 確認外接硬碟備份

所需時間： 10-15 分鐘 效益： 防止儲存危機，保持系統順暢運作

儲存問題排除

問題 1：錄製時出現「空間不足」錯誤

症狀：

  • 錯誤訊息：「磁碟空間不足，無法開始錄製」
  • 錄製無法開始
  • 警告出現但你繼續了

立即解決方法：

  1. 快速釋放空間：

    • 清空資源回收筒（可立即釋放 1-10GB）
    • 執行磁碟清理（Windows）或最佳化儲存（Mac）
    • 刪除舊下載、暫存檔案
    • 解除安裝未使用的程式

  2. 更改儲存位置：

    • 切換至空間較多的磁碟機
    • 外接磁碟機是最快的解決方案

  3. 降低錄製品質：

    • 設定 → 視訊 → 將品質降低至 720p 或 480p
    • 減少 50-75% 的空間使用

  4. 切換至純音訊：

    • 如果視訊不是必要的，只錄製音訊
    • 使用空間比視訊少 99%

長期解決方法：

  • 設定自動清理
  • 提高儲存警告閾值
  • 移至較大的磁碟機
  • 建立定期維護例行程序

問題 2：錄音消失了

症狀：

  • 昨天還在的錄音今天不見了
  • 在預期的資料夾中找不到檔案
  • SeaMeet 資料庫中顯示錄音但檔案遺失

可能的原因和解決方法：

原因 1：自動清理執行了

  • 確認清理是否刪除了舊錄音
  • 在資源回收筒中尋找恢復
  • 解決方法：調整清理設定或停用

原因 2：移至不同位置

  • 確認你最近是否更改了儲存位置
  • 舊錄音在前一個資料夾中
  • 解決方法：更新資料庫或將檔案移至新位置

原因 3：意外刪除

  • 確認資源回收筒
  • 確認你（或其他人）是否刪除了檔案
  • 解決方法：從資源回收筒或備份恢復

原因 4：磁碟機代號已變更（Windows）

  • 外接磁碟機取得不同的代號（D: 變成 E:）
  • SeaMeet 在錯誤的位置尋找
  • 解決方法：重新指定磁碟機代號或更新儲存位置

恢復步驟：

  1. 先確認資源回收筒
  2. 在整台電腦中搜尋錄音檔名
  3. 確認備份位置（雲端、外接硬碟）
  4. 如果最近刪除，使用檔案恢復軟體
  5. 確認 SeaMeet 的內部資料庫（可能顯示路徑）

問題 3：SeaMeet 無法存取儲存位置

症狀：

  • 錯誤：「無法寫入儲存位置」
  • 錄音無法儲存
  • 設定在儲存位置顯示紅色警告

解決方法：

  1. 確認資料夾權限：

    • 右鍵點擊資料夾 → 內容 → 安全性（Windows）
    • 確認你的使用者有「寫入」權限
    • 如果缺少，新增權限

  2. 確認磁碟機健康狀況：

    • 執行磁碟機錯誤檢查
    • Windows：右鍵點擊磁碟機 → 內容 → 工具 → 檢查
    • Mac：磁碟工具程式 → 急救

  3. 確認磁碟機連線：

    • 如果是外接/網路磁碟機，確認已連接
    • 確認磁碟機出現在檔案總管/Finder 中
    • 如有必要，重新連接

  4. 選擇不同位置：

    • 切換至「文件」資料夾（通常始終可存取）
    • 使用內建磁碟機而非外接磁碟機

  5. 以管理員身分執行：

    • 右鍵點擊 SeaMeet → 以管理員身分執行
    • 可能繞過某些權限問題

問題 4：儲存使用量顯示不正確的數字

症狀：

  • SeaMeet 顯示 50GB 已使用，但資料夾顯示 20GB
  • 可用空間與檔案總管不符
  • 數字看起來非常不對勁

可能的原因：

  1. 隱藏檔案：

    • SeaMeet 可能計入隱藏的暫存檔案
    • 在檔案總管中啟用「顯示隱藏檔案」以確認

  2. 快取資料：

    • 舊的儲存計算已被快取
    • 重新啟動 SeaMeet 以重新整理

  3. 多個位置：

    • SeaMeet 可能正在追蹤多個資料夾
    • 確認儲存位置最近是否已更改

  4. 資料庫與檔案系統：

    • SeaMeet 的資料庫可能有過時資訊
    • 重新掃描或重新整理資料庫

修復方式：

  1. 完全關閉 SeaMeet
  2. 在檔案總管中手動確認資料夾大小
  3. 重新啟動 SeaMeet
  4. 前往儲存設定，尋找「重新整理」或「重新掃描」
  5. 等待重新計算

進階儲存主題

網路儲存（NAS）設定

什麼是 NAS？ Network Attached Storage（網路附接儲存）— 連接至你的網路的硬碟，可從任何電腦存取。

使用 NAS 設定 SeaMeet：

  1. 對應網路磁碟機（Windows）：

    • 開啟檔案總管
    • 點擊「此電腦」→「連線網路磁碟機」
    • 輸入 NAS 路徑：\\NAS-名稱\共用資料夾
    • 勾選「登入時重新連線」
    • 指定磁碟機代號（例如 Z:）

  2. 設定 SeaMeet 儲存位置：

    • 設定 → 儲存
    • 瀏覽至 Z:\SeaMeet 錄音（或你對應的磁碟機）
    • 點擊「套用」

  3. 注意事項：

    • 網路速度影響錄製效能
    • 1080p 錄製需要約 25MB/s 的持續寫入速度
    • WiFi 可能太慢；如果可能，使用乙太網路
    • 如果網路中斷，錄製可能失敗

最佳做法： 先錄製至本機磁碟，然後在之後自動同步至 NAS。

雲端儲存整合

運作方式： SeaMeet 儲存至一個與雲端儲存（OneDrive、Google Drive、Dropbox 等）同步的資料夾。

設定步驟：

  1. 建立雲端資料夾：

    • 開啟 OneDrive/Google Drive 資料夾
    • 建立「SeaMeet 錄音」子資料夾

  2. 設為儲存位置：

    • 設定 → 儲存 → 瀏覽
    • 選擇雲端資料夾
    • 套用

  3. 設定同步：

    • OneDrive：右鍵點擊資料夾 → 一律保留在此裝置（如果想要本機副本）
    • 或「釋放空間」以只儲存在雲端

  4. 監控上傳：

    • 大型視訊需要時間上傳
    • 確認雲端應用程式的上傳進度
    • 上傳完成前不要關機

優點：

  • 自動備份
  • 可從任何地方存取
  • 跨裝置同步

缺點：

  • 上傳頻寬用量
  • 大型資料庫的儲存成本
  • 在其他地方可用前的上傳延遲

技巧：

  • 使用「依需求取得檔案」（OneDrive）或「Smart Sync」（Dropbox）節省本機空間
  • 在離峰時間排程上傳
  • 在雲端儲存前壓縮視訊以節省費用

儲存警告：70% 閾值

命名模式：日期_時間_應用程式
子資料夾：按月
備份：雲端同步 + 外接每月歸檔
