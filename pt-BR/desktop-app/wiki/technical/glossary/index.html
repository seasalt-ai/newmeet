Glossário de Termos

Capítulo 26: Glossário de Termos

Introdução

O software de gravação, como qualquer campo técnico, vem com seu próprio vocabulário. Palavras como "codec", "bitrate", "taxa de quadros" e "codificação" são usadas constantemente. Este capítulo é o seu dicionário abrangente — explicando cada termo técnico que você pode encontrar ao usar o SeaMeet ou ao ler sobre gravação de áudio/vídeo.

Não se preocupe se você não for técnico. Cada termo é explicado em linguagem simples com analogias para ajudar você a entender. Use este capítulo como referência sempre que encontrar uma palavra desconhecida.

Objetivos do Capítulo

Após ler este capítulo, você será capaz de:

  • Entender os termos técnicos usados no SeaMeet
  • Conhecer a diferença entre termos frequentemente confundidos
  • Usar a terminologia correta ao solucionar problemas
  • Tomar decisões informadas com base em conceitos técnicos

A

Audio Buffer — Armazenamento temporário para dados de áudio antes de serem processados ou salvos. Como uma sala de espera onde as amostras de áudio fazem fila antes de serem codificadas.

Audio Interface — Hardware que conecta microfones e instrumentos ao seu computador. Frequentemente oferece melhor qualidade de áudio do que placas de som integradas.

Action Items (AI) — Tarefas identificadas pela Extração de IA a partir de uma gravação. Cada item de ação inclui a descrição da tarefa, a pessoa responsável e um prazo (se mencionado na conversa). Consulte o Capítulo 28.

AI Extraction — Recurso de análise pós-gravação do SeaMeet. Após uma gravação terminar, clicar em ✨ Gerar Resumo envia o áudio para o motor de IA, que retorna cinco saídas estruturadas: Transcrição, Resumo, Itens de Ação, Decisões Principais e Capítulos. Consulte o Capítulo 28.

AI Insights — O painel no SeaMeet que exibe todos os resultados gerados por IA para uma gravação. Acessível a partir da visualização de detalhes da gravação. Contém abas para Transcrição, Resumo, Ações, Decisões e Capítulos.

Audio Track — Um fluxo de áudio separado dentro de um arquivo de vídeo. Um vídeo pode ter múltiplas faixas: seu microfone, áudio do sistema, música de fundo.

Auto-Detection — Recurso do SeaMeet que reconhece automaticamente quando você entra em uma reunião e pode iniciar a gravação sem intervenção manual.

AVI (Audio Video Interleave) — Um formato de arquivo de vídeo mais antigo desenvolvido pela Microsoft. Funciona bem no Windows, mas é menos compatível com dispositivos modernos.

B

Bit — A menor unidade de informação digital. Pode ser 0 ou 1. Tudo no seu computador é feito de bits.

Bit Depth (Audio) — Quantos bits são usados para representar cada amostra de áudio. Maior profundidade de bits = mais detalhes = arquivos maiores. A qualidade CD é de 16 bits.

Bitrate — A quantidade de dados processados por segundo. Geralmente medida em kilobits por segundo (kbps) ou megabits por segundo (Mbps). Maior = melhor qualidade = arquivos maiores.

Bluetooth Latency — O atraso entre quando o som é produzido e quando você o ouve por uma conexão Bluetooth. Tipicamente 100-300ms, o que causa problemas de sincronização.

Buffer — Área de armazenamento temporário que retém dados enquanto estão sendo transferidos ou processados. Como um reservatório que retém água antes de fluir por um cano.

Buffer Duration (Flashback) — Quantos segundos de imagens o SeaMeet mantém no buffer circular. Quando você salva o Flashback, você obtém essa quantidade de imagens passadas.

Byte — Um grupo de 8 bits. A unidade padrão para medir tamanhos de arquivos. Um megabyte (MB) é aproximadamente um milhão de bytes.

C

Circular Buffer — Um tipo de buffer que volta ao início quando chega ao final. O SeaMeet usa isso para o Flashback — gravando continuamente e sobrescrevendo dados antigos.

Codec (Coder-Decoder) — Software que comprime e descomprime áudio ou vídeo. H.264 é um codec de vídeo. MP3 é um codec de áudio.

Codec vs. Container — Codec é o método de compressão (como os dados são comprimidos). Container é o formato de arquivo (a caixa que contém os dados). MP4 é um contêiner que frequentemente contém vídeo H.264.

Compression — Reduzir o tamanho do arquivo removendo dados redundantes ou menos importantes. Pode ser sem perdas (sem perda de qualidade) ou com perdas (alguma perda de qualidade, mas arquivos menores).

Chapters (AI) — Uma das cinco saídas da Extração de IA. Segmentos de tópicos indexados por tempo, semelhantes a capítulos em um livro. Clicar em um capítulo no painel de AI Insights leva o player para aquele momento na gravação. Consulte o Capítulo 28.

CPU (Central Processing Unit) — O "cérebro" do seu computador. Faz cálculos e executa programas. O software de gravação usa a CPU para codificar vídeo.

Cursor Highlighting — Um efeito visual que chama atenção para o cursor do mouse nas gravações. Útil para tutoriais, para que os espectadores possam acompanhar suas ações.

D

Decibel (dB) — Uma unidade para medir o volume do som. Usado nos medidores de nível de áudio do SeaMeet. -12 dB é um bom nível de gravação. 0 dB é o máximo (distorção).

Default Device — O dispositivo de áudio ou vídeo que o Windows/macOS usa automaticamente. O SeaMeet pode usar o padrão ou deixar você escolher um dispositivo específico.

Detection Method (Auto-Detection) — Como o SeaMeet reconhece que você está em uma reunião. Os métodos incluem análise de título de janela, monitoramento de processos e detecção de áudio.

Digital Audio — Som representado como números. Seu computador converte ondas sonoras em amostras digitais (números) que podem ser armazenadas e processadas.

Disk Space — A quantidade de armazenamento disponível no seu disco rígido ou SSD. A gravação de vídeo requer espaço significativo em disco.

DRM (Digital Rights Management) — Tecnologia que impede a cópia de conteúdo protegido. Netflix, DVDs e alguns serviços de streaming usam DRM, o que impede a gravação de tela.

Decisions (AI) — Uma das cinco saídas da Extração de IA. Uma lista de escolhas e acordos principais feitos durante a reunião, extraídos da conversa. Distinto dos Itens de Ação — decisões são o que foi acordado, ações são o que deve ser feito como resultado. Consulte o Capítulo 28.

Drop Frame — Quando uma gravação de vídeo perde quadros, causando travamentos. Geralmente acontece quando o computador não consegue acompanhar as demandas de codificação.

E

Echo Cancellation — Tecnologia que remove eco das gravações. Útil ao usar alto-falantes em vez de fones de ouvido — impede que o microfone capte o som dos alto-falantes.

Encode — O processo de converter vídeo/áudio bruto em um formato comprimido. A CPU ou GPU faz isso em tempo real enquanto você grava.

Encoder — Software ou hardware que realiza a codificação. O SeaMeet usa codificadores de software (CPU) ou codificadores de hardware (GPU).

External Drive — Um disco rígido ou SSD que conecta via USB. Pode ser usado para armazenar gravações, mas pode ser mais lento que drives internos.

F

Flashback — O recurso de máquina do tempo do SeaMeet que grava continuamente em um buffer circular, permitindo salvar momentos do passado.

Flashback Buffer — O armazenamento temporário de memória usado pelo Flashback. Mantém os últimos X segundos de vídeo/áudio.

Floater (SeaMeet Floater) — O widget flutuante que aparece na sua tela para controles rápidos de gravação. Pode ser minimizado para um pequeno ícone ou expandido para controles completos.

FPS (Frames Per Second) — Quantas imagens estáticas (quadros) são capturadas por segundo para criar vídeo. 30fps é padrão. 60fps é mais suave.

Fullscreen Recording — Modo de gravação que captura sua tela inteira. Útil para reuniões e quando você quer capturar tudo.

Frame — Uma única imagem estática em um vídeo. O vídeo é essencialmente uma série de quadros exibidos rapidamente (30-60 por segundo) para criar movimento.

G

Gain — O nível de amplificação de um sinal de áudio. Aumentar o ganho torna o áudio mais alto na gravação. Diferente do volume (que afeta a reprodução).

Game Mode — Recurso do Windows que prioriza aplicativos de jogos. Pode ajudar no desempenho de gravação, mas às vezes conflita com o software de gravação.

GPU (Graphics Processing Unit) — A placa de vídeo no seu computador. Pode ser usada para codificação de vídeo com aceleração de hardware (muito mais rápida que a CPU).

GPU Encoding — Usar a placa de vídeo em vez da CPU para codificar vídeo. Também chamado de aceleração de hardware. Mais rápido e mais eficiente.

H

H.264 (AVC) — O codec de vídeo mais comum. Oferece boa qualidade com tamanhos de arquivo razoáveis. Funciona em praticamente todos os dispositivos.

H.265 (HEVC) — Um codec de vídeo mais novo e mais eficiente. Produz arquivos cerca de 50% menores que H.264 com a mesma qualidade. Suporte menos universal.

Hardware Acceleration — Usar hardware especializado (como GPU) para realizar tarefas em vez da CPU geral. Torna a codificação de vídeo muito mais rápida.

Hardware Encoder — Chip dedicado na GPU que codifica vídeo. NVIDIA chama o deles de NVENC. Intel chama o deles de Quick Sync.

HD (High Definition) — Resolução de vídeo de 1280×720 (720p) ou superior. Fornece vídeo claro e detalhado.

Headphones vs. Speakers — Usar fones de ouvido durante a gravação evita eco (som dos alto-falantes sendo captado pelo microfone). Recomendado para melhor qualidade de áudio.

I

I-Frame (Intra-frame) — Um quadro de vídeo completo que não depende de outros quadros. Funciona como ponto de referência. Tamanho de arquivo maior, mas necessário para busca.

Import — Trazer arquivos de áudio ou vídeo externos para o SeaMeet. O SeaMeet pode importar vários formatos para reprodução e gerenciamento.

Input Device — Hardware que envia áudio/vídeo para o seu computador. Microfones, câmeras e placas de captura são dispositivos de entrada.

J

Jitter — Variação no tempo dos dados de áudio/vídeo. Causa reprodução irregular ou desigual. Geralmente devido a problemas de desempenho do sistema.

Join a Meeting — Entrar em uma reunião online via Zoom, Teams, Meet, etc. O SeaMeet pode detectar automaticamente quando você entra e iniciar a gravação.

K

Kbps (Kilobits per second) — Uma medida de taxa de dados. Usada para bitrates de áudio. 128 kbps é padrão para MP3. 192 kbps é de qualidade superior.

Keyframe — Consulte I-Frame. Quadros de vídeo completos usados como pontos de referência.

Keyboard Shortcuts — Combinações de teclas que acionam ações rapidamente. Ctrl+Alt+R inicia a gravação. Atalhos economizam tempo em comparação a clicar na interface.

L

Latency — Atraso entre uma ação e quando é processada ou ouvida. Fones de ouvido Bluetooth têm alta latência. Fones com fio têm quase nenhuma.

Live Transcription — Recurso do SeaMeet que converte fala em texto em tempo real durante uma gravação. As palavras aparecem no painel de Transcrição conforme são faladas, com carimbo de hora e identificação de locutor. Requer Recursos de IA habilitados e conexão com a internet. Consulte o Capítulo 27.

Library (Recording Library) — A coleção de todas as suas gravações no SeaMeet. Mostra miniaturas, metadados e permite reprodução/gerenciamento.

Lossless Compression — Compressão que reduz o tamanho do arquivo sem perder nenhum dado. Pode ser perfeitamente reconstruído. O áudio FLAC usa compressão sem perdas.

Lossy Compression — Compressão que remove permanentemente alguns dados para obter arquivos menores. MP3 e H.264 são com perdas. A perda de qualidade geralmente é imperceptível.

Low-Memory Mode — Recurso do SeaMeet que reduz a qualidade para usar menos RAM. Útil para computadores mais antigos ou ao executar apps que consomem muita memória.

M

Macroblock — Um quadrado de 16×16 pixels usado na compressão de vídeo. H.264 divide quadros em macroblocks para comprimir eficientemente.

Mbps (Megabits per second) — Uma medida de taxa de dados usada para vídeo. 8 Mbps é bom para vídeo 1080p. Maior = melhor qualidade = arquivos maiores.

Metadata — Informações sobre um arquivo (não o conteúdo real). Inclui data de criação, duração, resolução, etc.

Microphone Array — Múltiplos microfones trabalhando juntos. Alguns laptops têm arrays de microfone para melhor captação de som e cancelamento de ruído.

Minimize to Tray — O SeaMeet pode executar em segundo plano, acessível pelo ícone na bandeja do sistema (próximo ao relógio). Economiza espaço na barra de tarefas.

MKV (Matroska) — Um formato de contêiner de vídeo flexível. Suporta múltiplas faixas de áudio e legendas. Bom para arquivamento.

Monitor — A tela do seu computador. O SeaMeet pode gravar um monitor ou todos os monitores, se você tiver múltiplos displays.

Mono vs. Stereo — Mono = 1 canal de áudio. Estéreo = 2 canais (esquerdo e direito). O estéreo parece mais imersivo, mas cria arquivos maiores.

MOV — Formato de contêiner de vídeo da Apple. Comum em Macs. Boa qualidade, mas menos compatível com o Windows sem software adicional.

MP3 — O formato de áudio mais popular. Usa compressão com perdas. Arquivos pequenos, compatibilidade universal. Típico de 128-320 kbps.

MP4 — O formato de contêiner de vídeo mais popular. Funciona em praticamente todos os dispositivos. Geralmente contém vídeo H.264 e áudio AAC.

Multi-Monitor — Usar mais de uma tela. O SeaMeet pode gravar todos os monitores ou apenas um. Gravar múltiplos monitores usa mais recursos.

Mute — Desligar temporariamente a entrada ou saída de áudio. O SeaMeet pode silenciar a gravação sem afetar o volume do sistema.

N

Native Resolution — O número real de pixels que sua tela exibe. Gravar na resolução nativa fornece os resultados mais nítidos.

Noise Suppression — Tecnologia que remove ruído de fundo (ventiladores, ar condicionado) das gravações de áudio. Torna as vozes mais claras.

Notification — Uma mensagem popup que alerta você sobre eventos. O SeaMeet mostra notificações quando as gravações iniciam, param ou quando reuniões são detectadas.

NVENC — Codificador de vídeo por hardware da NVIDIA. Disponível na série GTX 600 e mais novas. Codificação muito rápida com uso mínimo de CPU.

O

Ogg — Um formato de áudio de código aberto. Boa compressão, mas suporte limitado a dispositivos. Frequentemente usa o codec Vorbis.

Output Device — Hardware que reproduz áudio do seu computador. Alto-falantes e fones de ouvido são dispositivos de saída.

Overhead (CPU/Memory) — Recursos usados pelo próprio software de gravação, separados da gravação real. O SeaMeet tem baixa sobrecarga.

P

P-Frame (Predicted Frame) — Um quadro de vídeo que armazena apenas as mudanças em relação ao quadro anterior. Muito menor que os I-Frames. Cria compressão eficiente.

PCM (Pulse Code Modulation) — Formato de áudio digital não comprimido. Usado internamente antes da codificação para MP3 ou outros formatos. Alta qualidade, arquivos grandes.

Permissions — Autorização para acessar recursos do sistema. macOS e Windows exigem que você conceda ao SeaMeet permissão para gravar tela e áudio.

Pixel — Um único ponto de cor na sua tela. As imagens são feitas de milhares ou milhões de pixels. 1920×1080 = aproximadamente 2 milhões de pixels.

Playback — Assistir ou ouvir uma gravação. O SeaMeet tem um player integrado para revisar gravações.

Pop Filter — Uma cobertura de espuma ou malha para microfones que reduz os sons de "p" e "b". Melhora a qualidade do áudio.

Process Monitoring — Método de detecção automática que observa quais programas estão em execução. Detecta quando zoom.exe ou Teams.exe inicia.

Q

Quantization — Reduzir a precisão dos dados para economizar espaço. Parte da compressão. Simplifica cores/sons que são quase idênticos.

Quick Sync — Codificador de vídeo por hardware da Intel. Integrado em processadores Intel modernos. Eficiente e de boa qualidade para gravação.

R

RAM (Random Access Memory) — A memória de curto prazo do seu computador. O SeaMeet usa RAM para buffers Flashback e processamento. Mais RAM = melhor desempenho.

RAW Audio/Video — Dados não comprimidos. Arquivos grandes, mas de qualidade máxima. O SeaMeet geralmente codifica para formatos comprimidos para economizar espaço.

Real-time — Acontecendo ao vivo, sem atraso. O SeaMeet codifica vídeo em tempo real enquanto você grava. Sem espera por pós-processamento.

Recording Mode — Como o SeaMeet captura vídeo: Tela Cheia (tela inteira), Janela (app específico) ou Região (área selecionada).

Region Recording — Gravar apenas uma parte selecionada da sua tela. Modo mais eficiente — captura apenas o que você precisa.

Resolution — O número de pixels em uma imagem. 1920×1080 significa 1920 pixels de largura por 1080 pixels de altura. Maior = mais nítido = arquivos maiores.

Ring Menu (Floater) — A interface de controle circular que aparece quando você expande o widget Floater. Fornece acesso rápido aos controles de gravação.

S

Sample Rate (Audio) — Quantas vezes por segundo o áudio é medido. A qualidade CD é 44,1 kHz (44.100 amostras por segundo). Maior = melhor qualidade.

Sampling — Converter ondas sonoras contínuas em números digitais medindo em intervalos regulares.

Save Location — A pasta onde o SeaMeet armazena gravações. Pode ser alterada nas configurações. Deve ter bastante espaço livre.

Screen Recording — Capturar vídeo da tela do seu computador. O SeaMeet é especializado em gravação de tela com áudio.

Screenshot — Uma captura de imagem estática da sua tela. O SeaMeet pode tirar capturas de tela via atalho de teclado ou Floater.

Sensitivity (Auto-Detection) — Com que agressividade o SeaMeet procura por reuniões. Alta sensibilidade detecta mais reuniões, mas pode ter falsos positivos.

Shortcut — Consulte Atalhos de Teclado. Forma rápida de controlar o SeaMeet sem usar o mouse.

Sidebar — O painel esquerdo no SeaMeet mostrando diferentes seções: Gravações, Vídeo, Flashback, etc.

Source (Audio/Video) — A origem do sinal. As fontes de áudio incluem microfone e áudio do sistema. As fontes de vídeo incluem tela e janelas.

Speaker Detection — O processo automático de identificar qual pessoa está falando durante a transcrição ao vivo ou Extração de IA. Cada voz distinta recebe um rótulo ("Locutor 1", "Locutor 2"). A precisão melhora com áudio claro e mínima sobreposição de vozes. Consulte o Capítulo 27.

Speaker Label — O nome atribuído a um locutor em uma transcrição. Padrão para "Locutor 1", "Locutor 2", etc. Pode ser renomeado (por exemplo, "Alice") ou mesclado com outro rótulo se dois rótulos pertencem à mesma pessoa. Consulte o Capítulo 29.

SRT (SubRip Subtitle) — Um formato de arquivo de texto para legendas. Contém linhas de texto com carimbo de hora. O SeaMeet pode exportar transcrições como arquivos SRT, que podem ser importados para editores de vídeo (Premiere, iMovie) ou carregados no YouTube como legendas.

SSD (Solid State Drive) — Dispositivo de armazenamento rápido sem partes móveis. Melhor para gravação do que discos rígidos tradicionais (HDD). Velocidades de escrita mais rápidas.

Stereo Mix — Recurso de áudio do Windows que permite gravar o áudio do sistema. O SeaMeet pode usar Stereo Mix ou WASAPI para captura de áudio do sistema.

Storage — Espaço no seu disco rígido ou SSD onde as gravações são salvas. As gravações de vídeo requerem muito espaço de armazenamento.

Stream — Fluxo contínuo de dados. Fluxos de áudio e vídeo são capturados e codificados durante a gravação.

Sync (Audio-Video) — Quando o áudio e o vídeo estão devidamente alinhados. Fora de sincronia significa que você vê os lábios se moverem antes/depois de ouvir as palavras.

System Audio — Som do seu computador — notificações, vídeos, vozes de reunião. O SeaMeet pode gravar o áudio do sistema separadamente do microfone.

System Tray — A área próxima ao relógio onde os apps em segundo plano mostram ícones. O SeaMeet pode minimizar para a bandeja do sistema.

T

Theme (Light/Dark) — Aparência visual do SeaMeet. O tema claro tem fundos brancos. O tema escuro tem fundos escuros. Mais fácil para os olhos à noite.

Thumbnail — Imagem de prévia pequena representando um vídeo. O SeaMeet mostra miniaturas das suas gravações na biblioteca.

Time Machine (Flashback) — Metáfora para o recurso Flashback. Permite "voltar no tempo" para capturar momentos que já aconteceram.

Timeline — Representação visual da duração de uma gravação. O player do SeaMeet mostra uma linha do tempo com a posição de reprodução.

Toggle — Um interruptor que liga ou desliga um recurso. O SeaMeet usa interruptores nas configurações — clique para alternar entre estados.

Transcript — Um registro de texto do áudio falado. O SeaMeet produz dois tipos: uma transcrição ao vivo (palavras capturadas em tempo real durante a gravação) e uma transcrição de extração (produzida a partir do arquivo de áudio após a gravação). Ambas aparecem no painel de AI Insights na aba Transcrição. Consulte os Capítulos 27 e 28.

Track (Audio) — Um fluxo de áudio separado dentro de um arquivo. O SeaMeet pode gravar múltiplas faixas: microfone, áudio do sistema, etc.

Trim — Remover as partes indesejadas do início ou fim de uma gravação. O SeaMeet permite cortar gravações salvas.

Troubleshooting — O processo de diagnosticar e corrigir problemas. O Capítulo 21 aborda a solução de problemas comuns do SeaMeet.

U

USB Microphone — Um microfone que conecta via porta USB. Fácil de usar e frequentemente de melhor qualidade do que os microfones integrados de laptops.

V

VBR (Variable Bit Rate) — Método de codificação que ajusta a qualidade com base na complexidade do conteúdo. Cenas simples usam bitrate menor. Cenas complexas usam bitrate maior.

Video Buffer — Armazenamento temporário para quadros de vídeo durante a gravação Flashback. Mantém a janela rotativa de imagens recentes.

Version Badge — Um pequeno rótulo (por exemplo, "v3 ▾") que aparece na barra de abas de AI Insights quando pelo menos uma regeneração foi executada. Clicar nele abre o seletor de versão. Consulte o Capítulo 29.

Version History — O registro de todas as execuções anteriores de Extração de IA para uma gravação. Cada vez que você regenera (⟳), o SeaMeet salva os resultados anteriores como um snapshot numerado antes de sobrescrevê-los. Você pode visualizar qualquer versão anterior a qualquer momento. Consulte o Capítulo 29.

Video Track — O componente visual de um arquivo de vídeo. Separado das faixas de áudio. Um arquivo de vídeo contém pelo menos uma faixa de vídeo.

Volume — Intensidade do áudio. Diferente do ganho — o volume afeta o que você ouve. O ganho afeta o que é gravado.

VP8/VP9 — Codecs de vídeo de código aberto usados em arquivos WebM. Boa qualidade, gratuitos para usar. VP9 é mais novo e mais eficiente que VP8.

W

WASAPI (Windows Audio Session API) — Método moderno do Windows para capturar áudio do sistema. Mais confiável que o Stereo Mix em alguns sistemas.

WAV (Waveform Audio File Format) — Formato de áudio não comprimido. Arquivos grandes, mas qualidade perfeita. Bom para arquivamento ou edição.

WebM — Formato de vídeo de código aberto desenvolvido pelo Google. Bom para uso na web. Usa codecs VP8 ou VP9.

Window Recording — Modo de gravação que captura apenas uma janela de aplicativo específica. Mais eficiente que a tela cheia.

Window Title Detection — Método de detecção automática que lê os títulos das janelas dos aplicativos. Procura palavras-chave como "Zoom Meeting" ou "Teams."

X

XLR — Conector de áudio profissional usado em microfones de alta qualidade. Requer uma interface de áudio para conectar ao computador.

Y

YouTube — Plataforma popular de compartilhamento de vídeo. As gravações do SeaMeet podem ser carregadas no YouTube. O YouTube recomenda configurações específicas para melhores resultados.

Z

Zero Latency — Nenhum atraso entre ação e gravação. Impossível na prática, mas conexões com fio e bom hardware minimizam a latência.

Termos Confusos Explicados

Codec vs. Contêiner

  • Codec: COMO os dados são comprimidos (H.264, MP3)
  • Contêiner: ONDE os dados são armazenados (MP4, WebM, AVI)

Analogia: O codec é o idioma em que um livro é escrito. O contêiner é o próprio livro.

Bitrate vs. Resolução

  • Bitrate: QUANTA quantidade de dados por segundo (afeta qualidade e tamanho do arquivo)
  • Resolução: QUANTOS pixels (afeta nitidez)

Você pode ter alta resolução com baixo bitrate (pixelado) ou baixa resolução com alto bitrate (suave, mas pequeno).

Ganho vs. Volume

  • Ganho: Nível de entrada (quão alto a gravação é)
  • Volume: Nível de saída (quão alto a reprodução é)

Mudar o volume não afeta a gravação. Mudar o ganho afeta a gravação.

Latência vs. Atraso

  • Latência: Termo técnico para atraso em sistemas digitais
  • Atraso: Termo geral para qualquer tempo de espera

São essencialmente a mesma coisa, mas "latência" é usada em contextos técnicos.

Taxa de Quadros vs. Resolução

  • Taxa de Quadros: QUANTAS imagens por segundo (fluidez)
  • Resolução: QUÃO DETALHADA é cada imagem (clareza)

60fps 720p é mais fluido que 30fps 1080p, mas 1080p é mais nítido.
