प्लेटफ़ॉर्म अंतर

अध्याय 29: प्लेटफ़ॉर्म अंतर

परिचय

SeaMeet कई प्लेटफ़ॉर्मों पर काम करता है—Windows, macOS और Linux—लेकिन प्रत्येक ऑपरेटिंग सिस्टम की अपनी विशेषताएँ, क्षमताएँ और सीमाएँ हैं। जो Windows पर पूरी तरह से काम करता है, वह Mac पर अलग व्यवहार कर सकता है। कुछ सुविधाएँ एक प्लेटफ़ॉर्म पर उपलब्ध हैं लेकिन दूसरे पर नहीं। इन अंतरों को समझने से आपको SeaMeet का अधिकतम लाभ उठाने में मदद मिलती है, चाहे आप किसी भी कंप्यूटर का उपयोग कर रहे हों।

यह अध्याय बताता है कि SeaMeet प्रत्येक प्लेटफ़ॉर्म पर कैसे अनुकूलित होता है, कौन सी सुविधाएँ प्लेटफ़ॉर्म-विशिष्ट हैं, और आपको किन सीमाओं के बारे में पता होना चाहिए।

अध्याय के उद्देश्य

इस अध्याय को पढ़ने के बाद, आप यह करने में सक्षम होंगे:

  • Windows, macOS और Linux संस्करणों के बीच अंतर समझें
  • जानें कि कौन सी सुविधाएँ प्लेटफ़ॉर्म-विशिष्ट हैं
  • अपने ऑपरेटिंग सिस्टम के लिए SeaMeet को सही तरीके से कॉन्फ़िगर करें
  • प्लेटफ़ॉर्म-विशिष्ट सीमाओं के आसपास काम करें
  • अपनी रिकॉर्डिंग आवश्यकताओं के लिए सही प्लेटफ़ॉर्म चुनें

भाग 1: प्लेटफ़ॉर्म द्वारा अवलोकन

Windows पर SeaMeet

किसके लिए सर्वश्रेष्ठ:

  • अधिकतम संगतता
  • गेमिंग रिकॉर्डिंग
  • व्यावसायिक वातावरण
  • सबसे सुविधा-संपूर्ण संस्करण

मुख्य विशेषताएँ:

  • अधिकांश सुविधाएँ उपलब्ध
  • सर्वश्रेष्ठ हार्डवेयर त्वरण समर्थन (NVIDIA/AMD/Intel)
  • आसान सिस्टम ऑडियो कैप्चर
  • व्यापक ऐप संगतता
  • सबसे अधिक परीक्षित और स्थिर

समर्थित Windows संस्करण:

  • Windows 10 (संस्करण 1809 और बाद का)
  • Windows 11
  • Windows Server 2019/2022 (सीमित समर्थन)

समर्थित Windows आर्किटेक्चर:

  • x64 (Intel/AMD 64-बिट): पूर्ण समर्थन, सभी सुविधाएँ उपलब्ध
  • ARM64 (Windows on ARM): समर्थित, कुछ ऑडियो सुविधाएँ अनुपलब्ध
    • Surface Pro X और समान डिवाइस
    • स्क्रीन रिकॉर्डिंग, वीडियो रिकॉर्डिंग, माइक्रोफ़ोन रिकॉर्डिंग पूरी तरह से समर्थित
    • सिस्टम ऑडियो कैप्चर और ऑडियो डिवाइस गणना उपलब्ध नहीं (विनम्र क्षरण)
    • विवरण के लिए नीचे Windows ARM64 अनुभाग देखें

समर्थित नहीं:

  • Windows 7, 8, 8.1 (जीवन के अंत में)
  • Windows XP/Vista (प्राचीन)
  • 32-बिट Windows (x86)

macOS पर SeaMeet

किसके लिए सर्वश्रेष्ठ:

  • क्रिएटिव पेशेवर
  • Apple इकोसिस्टम उपयोगकर्ता
  • साफ़, सुसंगत इंटरफ़ेस
  • Mac वर्कफ़्लो के साथ एकीकरण

मुख्य विशेषताएँ:

  • पॉलिश किया हुआ, मूल Mac इंटरफ़ेस
  • Apple Silicon (M1/M2/M3) पर उत्कृष्ट प्रदर्शन
  • Intel Mac पर उत्कृष्ट प्रदर्शन
  • कसा हुआ सिस्टम एकीकरण
  • अलग अनुमति मॉडल
  • प्रति-ऐप माइक्रोफ़ोन मॉनिटरिंग
  • ब्राउज़र मीटिंग पहचान और ऑटो-स्टार्ट रोकथाम

समर्थित macOS संस्करण:

  • macOS 14.2 Sonoma (न्यूनतम - native-audio-node सुविधाओं के लिए आवश्यक)
  • macOS 15 Sequoia
  • भविष्य के संस्करण

समर्थित macOS आर्किटेक्चर:

  • Apple Silicon (arm64): पूर्ण समर्थन, प्रति-ऐप ऑडियो डिटेक्शन सहित सभी सुविधाएँ
  • Intel (x64): अलग इंस्टॉलर के साथ पूर्ण समर्थन

Apple Silicon और Intel समर्थन:

  • दो अलग DMG इंस्टॉलर: एक Intel के लिए, एक Apple Silicon के लिए
  • अपने Mac के प्रोसेसर से मेल खाने वाला संस्करण डाउनलोड करें
  • M1/M2/M3 Mac → arm64 संस्करण डाउनलोड करें
  • Intel Mac → x64 संस्करण डाउनलोड करें
  • दोनों संस्करणों में समान सुविधाएँ हैं
  • VideoToolbox (Apple Silicon) या Quick Sync (Intel) के माध्यम से हार्डवेयर त्वरण
  • प्रति-ऐप माइक्रोफ़ोन डिटेक्शन (native-audio-node)
  • मीटिंग एप्लिकेशन के लिए स्मार्ट विंडो प्री-सिलेक्शन

Linux पर SeaMeet

किसके लिए सर्वश्रेष्ठ:

  • स्रोत से SeaMeet चलाने वाले तकनीकी उपयोगकर्ता
  • परियोजना में योगदान देने वाले डेवलपर्स
  • गोपनीयता-संवेदनशील उपयोगकर्ता
  • ओपन-सोर्स के समर्थक

मुख्य विशेषताएँ:

  • समुदाय-समर्थित, केवल-स्रोत (कोई आधिकारिक प्रीबिल्ट इंस्टॉलर नहीं)
  • वितरण के अनुसार चर सुविधा सेट
  • अधिक मैनुअल कॉन्फ़िगरेशन आवश्यक
  • कमांड-लाइन अनुकूल
  • कम "यह बस काम करता है" सुविधाएँ

समर्थित वितरण:

  • Ubuntu 20.04+ (सर्वश्रेष्ठ समर्थन)
  • Fedora 34+
  • Debian 11+
  • अन्य Debian/Ubuntu-आधारित डिस्ट्रो

Linux इंस्टॉल नोट्स (v2.1.4+):

✅ npm install अब Linux पर सफाई से सफल होता है

v2.1.4 तक, `npm install` Linux पर EBADPLATFORM के साथ विफल हो जाता था
क्योंकि native-audio-node — एक macOS/Windows-केवल मूल मॉड्यूल —
`dependencies` में सूचीबद्ध था। v2.1.4 के अनुसार यह अन्य प्लेटफ़ॉर्म-विशिष्ट
ऑडियो पैकेजों (macos-audio-devices, native-sound-mixer, win-audio) के साथ
`optionalDependencies` में रहता है, इसलिए npm उन्हें Linux पर रोकने के बजाय
छोड़ देता है।

यदि आपने पहले `npm ERR! EBADPLATFORM` का सामना किया था:
1. v2.1.4 या बाद का संस्करण खींचें
2. node_modules और package-lock.json हटाएँ
3. npm install फिर से चलाएँ — यह बिना त्रुटि के पूरा होना चाहिए

सीमाएँ:

  • कोई आधिकारिक प्रीबिल्ट इंस्टॉलर नहीं — npm start के माध्यम से स्रोत से चलाएँ
  • प्रति-ऐप माइक्रोफ़ोन मॉनिटरिंग और मीटिंग ऑटो-डिटेक्शन अनुपलब्ध हैं (native-audio-node की आवश्यकता है, जिसमें कोई Linux बाइनरी नहीं है)
  • System Tray उपलब्धता डेस्कटॉप परिवेश पर निर्भर करती है (नीचे Tray अनुभाग देखें)
  • हार्डवेयर त्वरण GPU/ड्राइवर संयोजन के अनुसार भिन्न होता है
  • सिस्टम-ऑडियो कैप्चर के लिए अधिक सेटअप आवश्यक (PulseAudio / PipeWire लूपबैक)

Lite Mode:

Lite Mode (v2.x में पेश किया गया) एक रेंडरर-साइड कॉम्पैक्ट लेआउट है — पूर्ण ऐप विंडो के बजाय रिकॉर्डिंग नियंत्रण, तरंगरूप और त्वरित क्रियाओं के साथ एक 560×80 floater बार। यह ui.appMode सेटिंग ('full' या 'lite') द्वारा नियंत्रित होता है और रनटाइम पर सेटिंग्स के माध्यम से स्विच करता है। Lite Mode तीनों प्लेटफ़ॉर्म पर समान रूप से काम करता है क्योंकि इसमें कोई प्लेटफ़ॉर्म-विशिष्ट कोड पथ नहीं है।

भाग 3: Windows-विशिष्ट सुविधाएँ और सेटअप

Windows के फायदे

1. सिस्टम ऑडियो आसान है

Windows पर, सिस्टम ऑडियो कैप्चर करना सीधा है:

विधि: Stereo Mix (सबसे विश्वसनीय)

सेटअप:
1. स्पीकर आइकन पर दायाँ-क्लिक करें → Open Sound settings
2. Sound Control Panel → Recording
3. खाली क्षेत्र पर दायाँ-क्लिक करें → Show Disabled Devices
4. "Stereo Mix" पर दायाँ-क्लिक करें → Enable
5. Default के रूप में सेट करें

SeaMeet अब सिस्टम ऑडियो को सीधे कैप्चर कर सकता है

वैकल्पिक विधियाँ:

  • WASAPI लूपबैक (आधुनिक विधि)
  • DirectSound कैप्चर
  • वर्चुअल ऑडियो केबल

2. हार्डवेयर त्वरण की भरमार

Windows में सर्वश्रेष्ठ GPU एनकोडर समर्थन है:

NVIDIA GPU:

GTX 600 श्रृंखला और नया:
• NVENC एनकोडर समर्पित चिप
• उत्कृष्ट गुणवत्ता
• बहुत कुशल
• SeaMeet स्वचालित रूप से समर्थन करता है

AMD GPU:

Radeon HD 7000 श्रृंखला और नया:
• VCE (Video Coding Engine)
• अच्छी गुणवत्ता
• कुशल एनकोडिंग
• स्वचालित समर्थन

Intel एकीकृत:

4th gen Core और नया:
• Quick Sync Video
• आश्चर्यजनक रूप से अच्छी गुणवत्ता
• बहुत बिजली कुशल
• लैपटॉप के लिए उत्कृष्ट

3. गेमिंग सुविधाएँ

Windows-विशिष्ट गेमिंग एकीकरण:

गेम मोड समर्थन:
• Windows Game Mode API
• गेम में होने पर ऑटो-डिटेक्ट
• संसाधन अनुकूलित करें
• केवल Windows पर उपलब्ध

Game Bar एकीकरण:
• Xbox Game Bar के साथ काम कर सकता है
• कोई संघर्ष नहीं
• अलग शॉर्टकट

Windows सेटअप गाइड

इष्टतम कॉन्फ़िगरेशन:

1. सिस्टम ऑडियो के लिए Stereo Mix सक्षम करें
2. GPU ड्राइवर अपडेट करें:
   - NVIDIA: GeForce Experience
   - AMD: Radeon Software
   - Intel: Intel Driver Assistant

3. SeaMeet में हार्डवेयर त्वरण सक्षम करें:
   सेटिंग्स → वीडियो → हार्डवेयर त्वरण का उपयोग करें

4. रिकॉर्डिंग के लिए पावर प्लान "High Performance" पर सेट करें

5. यदि समस्या हो रही है तो Windows Game Mode अक्षम करें:
   सेटिंग्स → गेमिंग → गेम मोड → Off

Windows-विशिष्ट शॉर्टकट

ग्लोबल शॉर्टकट (हर जगह काम करते हैं):
• Ctrl + Alt + R — रिकॉर्डिंग शुरू/बंद करें
• Ctrl + Alt + F — Flashback सहेजें

• Win + Alt + R — Xbox Game Bar रिकॉर्ड
   (SeaMeet के साथ काम करता है)

Windows ARM64-विशिष्ट जानकारी

Windows ARM64 क्या है?

ARM64 एक अलग प्रोसेसर आर्किटेक्चर है:
• Windows on ARM डिवाइस (Surface Pro X, आदि) में उपयोग किया जाता है
• ARM-आधारित प्रोसेसर के लिए मूल समर्थन
• x64 ऐप्स को एमुलेट कर सकता है (धीमा)
• मूल ARM64 ऐप्स के लिए बढ़ता समर्थन

ARM64 पर SeaMeet

SeaMeet में v1.0.2+ से शुरू होकर मूल ARM64 समर्थन है:

✅ ARM64 पर पूरी तरह से समर्थित:
• स्क्रीन रिकॉर्डिंग (उच्च प्रदर्शन)
• वीडियो रिकॉर्डिंग (उच्च प्रदर्शन)
• माइक्रोफ़ोन रिकॉर्डिंग (प्रत्यक्ष Windows API)
• विंडो डिटेक्शन और प्रबंधन
• Floater विजेट और कीबोर्ड शॉर्टकट
• सेटिंग्स और रिकॉर्डिंग लाइब्रेरी
• सभी UI सुविधाएँ

❌ ARM64 पर उपलब्ध नहीं:
• सिस्टम ऑडियो कैप्चर (ऐप्स/स्पीकर से ऑडियो)
• ऑडियो डिवाइस गणना (माइक्रोफ़ोन/स्पीकर डिटेक्शन)
• ऑडियो मिक्सर नियंत्रण
• इनके लिए ARM64 के लिए संकलित नहीं किए गए मूल मॉड्यूल की आवश्यकता होती है

Linux पर Intel:
• एनकोडिंग के लिए VA-API
• आमतौर पर अच्छी तरह से काम करता है
• Mesa ड्राइवरों का हिस्सा

# .deb पैकेज डाउनलोड करें

# या dnf के माध्यम से यदि रेपो में हो

• MP4 सभी प्लेटफ़ॉर्म पर काम करता है
• WebM सभी प्लेटफ़ॉर्म पर काम करता है
• MOV सभी प्लेटफ़ॉर्म पर काम करता है (कोडेक्स के साथ)

कंप्यूटर बदलते समय कोई रूपांतरण आवश्यक नहीं

Windows/Linux: Ctrl + Alt + [key]
Mac: Cmd + Shift + [key]

गेमिंग के लिए:

  • Windows (सर्वश्रेष्ठ हार्डवेयर समर्थन, अधिकांश गेम)

क्रिएटिव कार्य के लिए:

  • macOS (क्रिएटिव ऐप्स के साथ एकीकरण)

प्रोग्रामिंग/विकास के लिए:

  • कोई भी (व्यक्तिगत पसंद)
  • Linux यदि आप ओपन सोर्स पसंद करते हैं

व्यवसाय/उद्यम के लिए:

  • Windows (सबसे आम, आसान IT समर्थन)
  • macOS (व्यवसाय में बढ़ रहा है)

गोपनीयता के लिए:

  • Linux (सबसे अधिक नियंत्रण)

सारांश

SeaMeet सभी प्रमुख प्लेटफ़ॉर्म पर काम करता है लेकिन प्रत्येक की अपनी ताकत है:

✅ Windows: अधिकांश सुविधाएँ, आसान सेटअप, सर्वश्रेष्ठ गेमिंग, व्यापक ऑडियो नियंत्रण

✅ macOS: पॉलिश, स्मार्ट मीटिंग डिटेक्शन, अलग अनुकूलित DMG के माध्यम से Intel और Apple Silicon दोनों पर काम करता है (सार्वभौमिक बाइनरी नहीं — अपने चिप से मेल खाने वाला चुनें), उत्कृष्ट प्रदर्शन

✅ Linux: लचीला, गोपनीयता-केंद्रित, समुदाय-समर्थित, केवल-स्रोत इंस्टॉल (कोई प्रीबिल्ट इंस्टॉलर नहीं — v2.1.4 के बाद से साफ़ npm install)

प्लेटफ़ॉर्म अनुशंसाएँ:

Windows चुनें यदि:

  • आप अधिकतम संगतता चाहते हैं
  • आप गेम रिकॉर्ड करते हैं
  • आपको आसान सिस्टम ऑडियो कैप्चर की आवश्यकता है
  • आप NVIDIA/AMD GPU का उपयोग करते हैं
  • आपको अधिकतम सुविधा नियंत्रण की आवश्यकता है

macOS चुनें यदि:

  • आप Apple इकोसिस्टम में हैं
  • आपके पास Intel या Apple Silicon Mac है (दोनों समर्थित)
  • आप पॉलिश मूल अनुभव चाहते हैं
  • आप क्रिएटिव कार्य करते हैं
  • आप स्वचालित मीटिंग डिटेक्शन और स्मार्ट विंडो चयन चाहते हैं
  • आप एकीकृत प्रति-ऐप ऑडियो मॉनिटरिंग को महत्व देते हैं

Linux चुनें यदि:

  • आप तकनीकी रूप से इच्छुक हैं
  • आप ओपन सोर्स को महत्व देते हैं
  • आप अधिकतम नियंत्रण चाहते हैं
  • आपको कॉन्फ़िगरेशन से कोई आपत्ति नहीं है
  • आप समुदाय-समर्थित विकल्प पसंद करते हैं

v1.0.5+ में macOS फायदे:

✨ नई सुविधाएँ (macOS 14.2+):
• प्रति-ऐप माइक्रोफ़ोन मॉनिटरिंग (native-audio-node)
• स्वचालित मीटिंग डिटेक्शन
• स्मार्ट विंडो प्री-सिलेक्शन
• ब्राउज़र मीटिंग डिटेक्शन
• ऑटो-स्टार्ट रोकथाम
• अलग अनुकूलित इंस्टॉलर (Intel + Apple Silicon)
• छोटे डाउनलोड आकार (~100 MB प्रति आर्किटेक्चर)
