AI 결과 편집 - 세부 사항을 정확하게 다듬기

제29장: AI 결과 편집 — 세부 사항을 정확하게 다듬기

전사 서비스가 초안을 납품한 후 교정하는 것과 같습니다——힘든 작업은 이미 완료되었으며, 마지막 몇 가지 거친 부분만 다듬으면 됩니다. AI가 모든 것을 캡처하고 구조화하는 작업을 완료했습니다. 이제 "화자 2"가 실제로는 "Alice"가 되어야 하는지, 그리고 오늘의 추출이 지난주 버전보다 나은지를 결정하는 것은 여러분의 몫입니다.

이 장에서는 두 가지 유형의 편집을 다룹니다:

  • A절: 화자 레이블 — 실시간 전사에서 화자 레이블 이름 변경, 병합, 재할당
  • B절: 버전 기록 — 이전 AI 추출 실행 결과 탐색, 비교, 탐색

이 장의 목표

이 장을 읽고 나면 다음을 할 수 있게 됩니다:

  • 화자 레이블을 이름 변경하여 모든 곳에서 즉시 업데이트되는 것 확인
  • 같은 사람에게 속한 두 개의 화자 레이블 병합
  • 개별 전사 세그먼트를 올바른 화자로 재할당
  • 버전 배지가 나타나는 위치와 사용 방법 이해
  • 최신 버전을 잃지 않고 이전 추출 실행 결과 탐색
  • 오래된 버전 배너를 통해 역사적 버전을 보고 있음을 확인

A절: 화자 레이블

레이블이 중요한 이유

자동 화자 감지는 "화자 1", "화자 2"와 같은 임시 이름을 할당합니다. 이것들은 기능적으로는 괜찮지만 읽기 쉽지 않습니다. "화자 1이 금요일까지 배송해야 한다고 했다"는 "Alice가 금요일까지 배송해야 한다고 했다"보다 훨씬 덜 유용하고 공유하기도 어렵습니다.

이름 변경에는 30초가 걸리며 전사를 기술적 출력에서 전문적인 문서로 변환합니다.

화자 레이블 편집은 실시간 전사 (제27장에 설명된 것처럼 녹음 중 실시간 전사가 활성화된 녹음)에 사용할 수 있습니다. AI 추출로 생성된 전사도 동일한 레이블을 사용하며 Transcript 탭에서 이름을 변경할 수 있습니다.

화자 이름 변경

화자 레이블을 이름 변경하면 녹음 전체에 걸쳐 해당 화자의 모든 언급이 변경됩니다——전사, 요약, 실행 항목, 결정 사항, 챕터가 모두 동시에 업데이트됩니다. AI가 "화자 1이 예산을 15% 삭감할 것을 제안했다"고 썼다면, "화자 1"을 "Alice"로 이름 변경하면 그 줄은 모든 곳에서 "Alice가 예산을 15% 삭감할 것을 제안했다"로 표시됩니다.

단계별 절차:

  1. 녹음 라이브러리에서 녹음 열기

  2. 세부 정보 패널에서 "AI Insights" 클릭 후 Transcript 탭 선택

    • 보이는 내용: 모든 세그먼트와 화자 레이블이 있는 전사. 왼쪽 가장자리 (또는 레이아웃에 따라 오른쪽)에 감지된 모든 화자 레이블을 나열하는 화자 패널이 있습니다.

  3. 화자 패널에서 이름 변경하려는 화자 옆의 연필 아이콘 ✏️ 클릭

    • 보이는 내용: 레이블이 현재 이름 ("화자 1")으로 미리 채워진 편집 가능한 텍스트 필드로 바뀝니다.

  4. 새 이름 입력 (예: "Alice")

    • 보이는 내용: 입력한 문자가 자리 표시자를 대체합니다.

  5. Enter 키 누르기 (또는 필드 밖 클릭)

    • 보이는 내용: 모든 전사 세그먼트에서 "화자 1"의 모든 출현이 동시에 "Alice"로 업데이트됩니다. 화자 패널에는 "화자 1" 대신 "Alice"가 표시됩니다.

팁: 누가 말했는지 기억하고 있는 동안 녹음 직후에 화자 이름을 변경하세요. 문맥 기억은 빠르게 희미해집니다.

두 화자 병합

때로는 AI가 한 사람에 대해 두 개의 레이블을 생성합니다——녹음의 다른 지점에서 목소리가 다르게 들릴 때 발생합니다 (예: 누군가가 마이크에서 더 멀리 이동했거나, 웃고 나서 일반적인 톤으로 돌아온 경우). 병합은 두 레이블을 하나로 합칩니다.

단계별 절차:

  1. 화자 패널에서, 다른 화자로 흡수하려는 화자 ("소스" 화자)를 찾습니다

  2. 병합 아이콘 클릭 (또는 화자 레이블을 마우스 오른쪽 버튼으로 클릭하고 Merge into… 선택)

    • 보이는 내용: 드롭다운 또는 서브 패널이 나타나 다른 모든 감지된 화자를 나열합니다.

  3. 타겟 화자 선택 — 소스를 병합하려는 화자

    • 예시: "화자 3"을 "Alice"로 만들려면 "Alice"를 타겟으로 선택합니다.

  4. Apply 클릭 (또는 팝업에서 확인)

    • 보이는 내용: 이전에 "화자 3"에 귀속된 모든 세그먼트가 이제 "Alice"에 귀속됩니다. "화자 3"이 화자 패널에서 사라집니다. 전사가 모든 곳에서 즉시 업데이트됩니다.

참고: 병합은 되돌릴 수 없습니다. 잘못 병합한 경우 개별 세그먼트를 수동으로 이름 변경해야 합니다 (다음 섹션 참조). 적용 전에 두 번 확인하세요.

단일 세그먼트 재할당

대부분의 세그먼트가 올바르게 귀속되어 있지만 특정 세그먼트가 잘못 식별된 경우, 다른 세그먼트에 영향을 주지 않고 해당 개별 세그먼트를 수정할 수 있습니다.

단계별 절차:

  1. Transcript 탭에서, 잘못된 화자에게 귀속된 세그먼트 찾기

  2. 해당 세그먼트에 표시된 화자 이름 클릭 (예: "화자 2")

    • 보이는 내용: 작은 팝업 또는 인라인 드롭다운이 나타나 감지된 모든 화자를 나열합니다.

  3. 목록에서 올바른 화자 선택

    • 보이는 내용: 해당 세그먼트의 화자 레이블이 선택된 화자로 업데이트됩니다. 다른 세그먼트는 영향을 받지 않습니다.

이것은 고립된 잘못된 귀속에 유용합니다——예를 들어, 다른 누군가가 잠깐 질문에 답했을 때 AI가 잘못된 사람에게 귀속시킨 경우입니다.

화자 편집의 제한 사항

제한 사항세부 내용
실시간 전사만 가능화자 편집은 녹음 중 또는 AI 추출로 생성된 전사에 사용할 수 있습니다. 가져온 전사 파일에는 사용할 수 없습니다.
기존 이름으로 이름 변경 불가"Alice"가 이미 레이블로 존재하는 경우 "화자 2"를 "Alice"로 이름 변경할 수 없습니다——대신 병합을 사용하세요.
실행 취소 없음화자 변경은 즉시 저장되며 실행 취소할 수 없습니다. 병합은 신중하게 사용하세요.
이름은 로컬 설정화자 이름은 이 녹음에만 저장됩니다. 다른 녹음에는 영향을 미치지 않습니다.

B절: 버전 기록

버전이 존재하는 이유

⟳을 클릭하여 AI 추출을 재생성할 때마다 SeaMeet은 덮어쓰기 전에 이전 결과를 번호가 매겨진 버전 스냅샷으로 조용히 저장합니다. 아무것도 삭제되지 않습니다.

이는 다음을 의미합니다:

  • 좋은 결과를 잃을 걱정 없이 자유롭게 재생성
  • 현재 추출을 이전 것과 비교
  • 재생성이 더 나쁜 결과를 생성한 경우 이전 버전으로 돌아가기

버전 배지

버전 배지는 콘텐츠 탭과 내보내기 버튼 사이의 AI Insights 탭 바에 표시됩니다:

[Transcript] [Summary] [Actions] [Decisions] [Chapters]  ·  v3 ▾  [MD] [SRT] [JSON] [⟳]
  • "v3 ▾" — 버전 3 (최신)을 보고 있으며, ▾는 드롭다운을 나타냄
  • 배지는 적어도 한 번의 재생성 후에만 나타납니다——처음 사용하는 사용자에게는 인터페이스에 변화가 없습니다

AI 추출을 한 번만 실행한 경우 (재생성한 적 없음), 배지가 나타나지 않습니다. 이것은 설계에 의한 것입니다——아직 비교할 것이 없습니다.

버전 탐색

버전 배지를 클릭하여 버전 선택기 열기:

┌─────────────────────────────────────────┐
│  ✓  v3 — 최신                           │
│      2026년 3월 1일, 오전 9:15          │
├─────────────────────────────────────────┤
│     v2                                  │
│      2026년 3월 1일, 오전 9:00          │
├─────────────────────────────────────────┤
│     v1                                  │
│      2026년 2월 27일, 오전 10:30        │
└─────────────────────────────────────────┘
  • 체크 표시 (✓)는 현재 보고 있는 버전을 나타냄
  • 버전은 최신순으로 나열됨
  • 각 항목에는 추출이 완료된 날짜와 시간이 표시됨
  • 최신은 항상 가장 최근 실행

이전 버전 보기:

  1. 버전 배지 ("v3 ▾") 클릭
  2. 원하는 버전 클릭 (예: "v1")
  3. 보이는 내용: 다섯 개의 탭이 모두 해당 실행의 과거 데이터로 다시 로드됩니다. 상단에 오래된 버전 배너가 나타납니다.

오래된 버전 배너

최신 버전 이외의 버전을 볼 때마다 콘텐츠 영역 상단에 얇은 황갈색 배너가 나타납니다:

┌──────────────────────────────────────────────────────────────┐
│  ⚠  3개 중 v2 보기 · 생성됨 3월 1일, 오전 9:00  [View latest →]│
└──────────────────────────────────────────────────────────────┘
  • "3개 중 v2 보기" — 어떤 역사적 버전인지, 총 몇 개의 버전이 있는지
  • "생성됨 3월 1일, 오전 9:00" — 이 버전이 생성된 시간
  • "View latest →" — 한 번 클릭으로 최신 추출로 돌아가기

오래된 버전 배너는 안전 신호입니다. 콘텐츠를 공유하거나 그에 따라 행동할 때 혼란을 방지하기 위해 최신 결과를 보고 있지 않을 때를 항상 알 수 있도록 합니다.

역사적 버전을 보면서 내보내기하면 최신 버전이 아닌 해당 버전의 데이터가 내보내집니다. 내보내기 버튼은 정상적으로 작동합니다——현재 표시된 내용에 대해 작동할 뿐입니다.

실시간 기준선

녹음 중에 실시간 전사가 활성화되어 있었다면 (제27장), 재생성을 몇 번 했는지에 관계없이 원래의 실시간 전사는 버전 선택기 하단에 특별 항목으로 항상 사용 가능합니다:

┌─────────────────────────────────────────────┐
│  ✓  v3 — 최신                               │
│      2026년 3월 1일, 오전 9:15              │
├─────────────────────────────────────────────┤
│     v2                                      │
│      2026년 3월 1일, 오전 9:00              │
├─────────────────────────────────────────────┤
│     v1                                      │
│      2026년 2월 27일, 오전 10:30            │
├─────────────────────────────────────────────┤
│     Live (original)                         │
│      AI 기반 · 2월 27일 녹음                │
└─────────────────────────────────────────────┘

"Live (original)"를 선택하면:

  • Transcript 탭만 콘텐츠로 채워집니다——이것은 녹음 중 실시간으로 캡처된 대화 텍스트입니다
  • Summary, Actions, Decisions, Chapters 탭에는 "이 버전에서는 사용할 수 없습니다"가 표시됩니다——실시간 AI 엔진은 전사만 생성했으며 전체 추출 출력은 생성하지 않았습니다
  • 이것은 최신 추출이 아니므로 오래된 버전 배너가 나타납니다

실시간 기준선은 다음을 비교하는 데 유용합니다:

  • 실시간 AI가 들은 것 (Live) 대 후처리 AI가 전사한 것 (어떤 vN)
  • 실시간 처리와 후속 추출 사이에서 화자 감지가 개선되었거나 변경되었는지 여부

버전 기록의 제한 사항

제한 사항세부 내용
읽기 전용역사적 버전은 스냅샷입니다. 직접 편집할 수 없습니다. 편집하려면 최신 버전으로 전환하고 거기서 변경하세요.
삭제 없음개별 버전은 삭제할 수 없습니다 (전체 녹음은 삭제할 수 있으며 모든 것이 제거됩니다).
이름 변경 없음버전에 이름이나 레이블을 붙일 수 없습니다 (예: "좋은 버전"). 번호와 타임스탬프로만 식별됩니다.
차이 보기 없음버전은 한 번에 하나씩만 볼 수 있습니다. 이 릴리스에서는 나란히 비교할 수 없습니다.
배지는 1회 이상 재생성 필요배지는 적어도 한 번의 재생성 후에만 나타납니다. 단일 추출 실행만 있는 녹음에는 배지가 표시되지 않습니다.

문제 해결

"버전 배지가 나타나지 않음"

증상: AI 추출을 실행했지만 탭 바에 버전 배지가 나타나지 않습니다.

무슨 일이 일어나고 있는지: 배지는 적어도 한 번의 재생성 (⟳ 클릭) 후에만 나타납니다. 단일 초기 추출 실행은 버전을 만들지 않습니다——아직 비교할 것이 없습니다.

할 일: ⟳를 클릭하여 재생성합니다. 새 추출이 완료된 후 "v2 ▾"를 표시하는 배지가 나타납니다.

"화자 변경이 저장되지 않음"

증상: 화자 이름을 변경하고 클릭했지만, 다음 로드 시 이전 이름이 다시 나타납니다.

순서대로 시도해보세요:

  1. 인터넷 연결 확인 — 일부 화자 편집은 동기화 단계가 필요합니다
  2. 녹음을 닫기 전에 5초 기다리기 — 변경 사항은 약간의 지연 후에 저장됩니다
  3. 라이브러리에서 녹음을 다시 로드하고 다시 확인

문제가 지속되면 SeaMeet을 다시 시작하고 이름 변경을 다시 적용해보세요.

"병합 옵션이 회색으로 표시됨"

증상: 화자 레이블을 마우스 오른쪽 버튼으로 클릭하거나 병합 아이콘을 클릭해도 응답이 없거나 옵션이 회색으로 표시됩니다.

무슨 일이 일어나고 있는지: 병합은 적어도 두 개의 서로 다른 화자 레이블이 필요합니다. 화자가 한 명만 감지된 경우 병합할 대상이 없습니다.

할 일: 전사가 화자 한 명만 식별했을 수 있습니다——솔로 녹음이나 한 사람이 주도하는 인터뷰에서는 정상입니다.

모범 사례

녹음 직후 화자 이름 변경 누가 무엇을 말했는지에 대한 기억은 빠르게 희미해집니다. 녹음 후 한 시간 이내에 AI Insights를 열고 문맥이 사라지기 전에 이름 변경을 완료하세요.

최신 버전을 작업 버전으로 유지 역사적 버전은 참조 및 비교용입니다. 이전 버전을 기본 보기로 유지하지 마세요——최신 버전이 항상 가장 완전하고 가장 최근에 처리된 버전입니다.

선택적으로 재생성 전에 내보내기 버전 기록이 과거 결과를 자동으로 보존하므로 ⟳ 전에 내보내기는 엄격히 필요하지 않습니다. 하지만 독립적인 파일 (이메일 또는 첨부 파일용)을 원한다면 먼저 내보내기하세요.

중복에는 이름 변경 전에 병합 사용 같은 사람이 두 개의 화자로 나타나는 경우 (예: "화자 1"과 "화자 3"), 두 개를 수동으로 이름 변경하는 것보다 병합을 사용하세요. 병합이 더 빠르고 모든 미래 참조가 통합되는 것이 보장됩니다.

정확성을 위해 실시간 기준선 검토 실시간 전사를 실행했다면 "Live (original)" 보기를 최신 추출과 비교하세요. 실시간 전사는 때로 후처리가 놓치는 뉘앙스를 포착하며, 그 반대도 마찬가지입니다.
