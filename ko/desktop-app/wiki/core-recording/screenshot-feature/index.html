스크린샷 기능

제 6 장: 스크린샷 기능

오디오 및 비디오 녹화 외에도 SeaMeet에는 화면의 정지 이미지를 캡처할 수 있는 강력한 스크린샷 기능이 포함되어 있습니다. 비디오의 특정 순간을 저장하거나, 오류 메시지를 캡처하거나, 시각적으로 무언가를 문서화해야 할 때 스크린샷은 매우 유용합니다. 이 챕터에서는 SeaMeet에서 스크린샷을 촬영, 보기, 관리하는 모든 것에 대해 가르쳐 드립니다.

스크린샷이란 무엇인가요? (기본)

자세한 내용에 들어가기 전에 스크린샷이 실제로 무엇인지 이해해 봅시다.

간단한 설명: 스크린샷은 컴퓨터 화면의 사진을 찍는 것과 같습니다. 카메라를 사용하여 실제 세계를 캡처하는 대신, 소프트웨어를 사용하여 특정 순간에 모니터에 표시된 것을 정확히 캡처합니다.

이렇게 생각해 보세요:

  • 화면은 이미지, 텍스트, 그래픽을 표시합니다
  • 스크린샷은 그 픽셀을 보이는 그대로 정확히 캡처합니다
  • 이미지는 보거나, 편집하거나, 공유할 수 있는 파일로 저장됩니다
  • 비디오와 달리 시간 속에서 정지된 단일 순간입니다

SeaMeet의 스크린샷이 특별한 이유는 무엇인가요? 단순히 이미지를 저장하는 기본 스크린샷 도구와 달리, SeaMeet은:

  1. 선택된 영역을 캡처합니다 (전체 화면뿐만 아니라)
  2. 메타데이터를 추출합니다 (크기, 파일 크기 자동)
  3. AI를 사용해 텍스트(OCR)를 자동 추출하여 클립보드에 복사합니다
  4. 녹음과 함께 스크린샷을 관리합니다
  5. 공유 및 복사 옵션이 있는 전용 뷰어를 제공합니다

스크린샷을 사용하는 이유는?

스크린샷은 오디오 또는 비디오 녹음과는 다른 목적을 제공합니다. 각각을 언제 사용해야 하는지 이해하면 올바른 도구를 선택하는 데 도움이 됩니다.

스크린샷 vs. 오디오/비디오 녹화

필요한 것스크린샷 사용오디오 녹음 사용비디오 녹화 사용
오류 메시지 저장✅ 완벽❌ 텍스트를 캡처할 수 없음⚠️ 과함
설정 문서화✅ 완벽❌ 시각 정보 없음⚠️ 과함
비디오에서 한 프레임 캡처✅ 완벽❌ 시각 없음✅ 그러나 큰 파일
대화 녹음❌ 오디오 없음✅ 완벽✅ 완벽
단계별 프로세스 표시⚠️ 여러 개 필요❌ 시각 없음✅ 완벽
영수증이나 확인 저장✅ 완벽❌ 텍스트 읽기 불가⚠️ 과함

스크린샷이 빛날 때

1. 문서화

  • 기술 지원을 위한 오류 메시지 저장
  • 변경 전 설정 캡처
  • 웹사이트 디자인이나 레이아웃 문서화
  • 영수증 및 확인 저장

2. 커뮤니케이션

  • 동료에게 자신이 보는 것을 정확히 보여주기
  • 프레젠테이션에 시각 자료 포함
  • 이미지로 단계별 가이드 작성
  • 비디오의 특정 순간 공유

3. 보관

  • 나중에 필요할 수 있는 정보 저장
  • 시간에 민감한 콘텐츠 캡처(티켓, 코드)
  • 변경될 수 있는 웹페이지 보존
  • 시각 참조 자료 작성

4. 품질

  • 무손실 PNG 형식이 모든 픽셀을 보존
  • 비디오 프레임보다 높은 품질
  • 텍스트와 UI 요소에 완벽
  • 압축 아티팩트 없음

SeaMeet에서 스크린샷이 작동하는 방식

SeaMeet은 스크린샷 촬영을 간단하고 강력하게 만듭니다. 기본 흐름은 다음과 같습니다:

1. TRIGGER     →  2. SELECT      →  3. CAPTURE     →  4. SAVE       →  5. VIEW
Keyboard       Draw a box         SeaMeet grabs      PNG saved to      Open in
shortcut or    on your screen     the pixels         storage folder    screenshot
button click                      exactly as         with metadata     viewer
                                  they appear        extracted

프로세스:

  1. 스크린샷을 트리거합니다 (키보드 단축키 또는 Capture Hub 버튼)
  2. 영역 캡처의 경우: 원하는 영역을 그립니다; 전체 화면의 경우: 캡처가 즉시 이루어집니다
  3. SeaMeet이 그 정확한 내용을 캡처합니다 (SeaMeet 자체는 기본적으로 캡처에서 숨겨집니다)
  4. 이미지는 고품질 PNG 파일로 저장됩니다
  5. SeaMeet의 전용 스크린샷 뷰어에서 볼 수 있습니다

첫 스크린샷 촬영하기

첫 스크린샷을 캡처하는 과정을 안내해 드리겠습니다.

방법 1: 키보드 단축키 사용

스크린샷을 촬영하는 가장 빠른 방법:

Windows에서:

  1. Ctrl + Alt + S를 함께 누릅니다
  2. 화면이 약간 어두워집니다
  3. 클릭 후 드래그하여 사각형을 그립니다
  4. 놓으면 캡처됩니다

macOS에서:

  1. Cmd + Shift + S를 함께 누릅니다
  2. 화면이 약간 어두워집니다
  3. 클릭 후 드래그하여 사각형을 그립니다
  4. 놓으면 캡처됩니다

무슨 일이 일어나나요:

  • SeaMeet이 선택한 영역을 즉시 캡처합니다
  • 스크린샷이 자동으로 저장됩니다
  • 미묘한 카메라 셔터 소리가 들립니다 (활성화된 경우)
  • 파일이 최근 스냅샷 사이드바에 나타납니다

방법 2: Capture Hub 사용

메인 SeaMeet 창에 있을 때:

  1. Capture Hub의 오른쪽 패널에서 모드를 선택합니다:
    • Full Screen — 전체 디스플레이를 즉시 캡처합니다
    • Area Capture — 영역 선택기를 열어 상자를 그릴 수 있도록 합니다
  2. 선택적으로 **"Keep SeaMeet window visible when taking screenshot"**을 체크합니다 (아래 참조)
  3. Take Screenshot 버튼 또는 큰 카메라 아이콘을 클릭합니다
  4. 영역 캡처의 경우: 캡처 사각형을 그린 후 놓습니다

창 가시성 옵션: 기본적으로 SeaMeet은 스크린샷을 촬영하기 전에 자체를 최소화하여 앱이 캡처에 나타나지 않도록 합니다. SeaMeet 창이 계속 보이도록 하려면 (예: 의도적으로 캡처하려는 경우) "Keep SeaMeet window visible when taking screenshot" 체크박스를 선택합니다.

OCR 자동 복사 옵션: **"Extract text (OCR) and copy to clipboard"**를 체크하면 SeaMeet이 AI를 사용해 스크린샷에서 보이는 모든 텍스트를 자동으로 읽고 클립보드에 복사합니다. 스크린샷이 캡처된 후 AI 파이프라인이 백그라운드에서 실행됩니다 (~15–30초). 완료되면 추출된 텍스트가 클립보드의 스크린샷 이미지를 대체하고 알림이 복사를 확인합니다. 이는 이미지, 오류 대화상자 또는 웹페이지에서 텍스트를 다시 입력하지 않고 빠르게 가져오는 데 유용합니다.

  • Region Selector 오버레이에도 동일한 체크박스가 나타나므로 ("Capture Screen or Press Enter" 버튼 근처) 캡처별로 전환할 수 있습니다.
  • 기본값은 설정 → AI Extraction & Summary → Auto-extract text (OCR) on screenshot에서 변경할 수 있습니다.
  • API 키가 필요합니다. Gemini API 키가 구성되지 않은 경우 체크박스가 회색으로 표시되고 결제 포털로 가는 "subscribe here" 링크가 표시됩니다.

방법 3: 플로팅 런처 사용

SeaMeet이 열려 있을 때:

  1. 플로팅 런처 위젯을 찾습니다 (보통 화면 모서리에 있음)
  2. 카메라 아이콘 📷 (스크린샷 버튼)을 찾습니다
  3. 클릭합니다
  4. 화면에 사각형을 그립니다
  5. 놓으면 캡처됩니다

런처를 찾을 수 있는 곳:

  • 보통 SeaMeet이 실행 중일 때 나타납니다
  • 드래그하여 이동할 수 있습니다
  • 사용하지 않을 때 최소화됩니다
  • 녹음 및 스크린샷 기능에 빠르게 접근할 수 있습니다

영역 선택기 이해하기

스크린샷을 트리거하면 SeaMeet이 영역 선택기를 표시합니다. 보이는 것을 이해해 봅시다.

영역 선택기가 표시하는 것

┌─────────────────────────────────────────────────────────────┐
│  화면 (약간 어두워짐)                                       │
│                                                             │
│     ┌─────────────────────────┐                            │
│     │  ┌───────────────────┐  │ ← 이 상자를 클릭하고      │
│     │  │                   │  │   드래그하여 그립니다     │
│     │  │  선택된 영역      │  │                            │
│     │  │                   │  │                            │
│     │  │  이 영역은        │  │                            │
│     │  │  스크린샷으로     │  │                            │
│     │  │  캡처됩니다       │  │                            │
│     │  │                   │  │                            │
│     │  └───────────────────┘  │                            │
│     │                         │                            │
│     └─────────────────────────┘                            │
│                                                             │
│  [✓] Extract text (OCR) and copy to clipboard               │
│  Enter를 눌러 캡처  │  Escape를 눌러 취소                  │
└─────────────────────────────────────────────────────────────┘

완벽한 영역을 선택하는 방법

단계별:

  1. 캡처하려는 한 모서리에 커서를 위치시킵니다
  2. 왼쪽 마우스 버튼을 클릭한 채로 유지합니다
  3. 반대쪽 모서리로 드래그합니다
  4. 상자가 필요한 부분을 정확히 덮을 때 놓습니다
  5. Enter를 눌러 확인하거나 그냥 놓아 자동 캡처합니다

정확한 선택을 위한 팁:

  • 원하는 콘텐츠 약간 바깥에서 시작합니다
  • 놓기 전에 선택을 조정할 수 있습니다
  • Shift를 누르고 있으면 정사각형으로 제한됩니다 (일부 모드에서)
  • 언제든지 Escape를 눌러 취소하고 다시 시도할 수 있습니다

캡처되는 것:

  • 그린 사각형 내부에 있는 것 정확히
  • 전체 해상도로 (품질 손실 없음)
  • 모든 텍스트, 이미지, 그래픽을 포함
  • 그러나 어두워진 오버레이나 선택 상자는 포함되지 않음

스크린샷이 저장되는 위치

스크린샷이 어디에 저장되는지 이해하면 찾고 관리하는 데 도움이 됩니다.

기본 저장 위치

스크린샷은 다음에 저장됩니다:

Documents/SeaMeet/Screenshots/

예시 경로:

  • Windows: C:\Users\YourName\Documents\SeaMeet\Screenshots\
  • macOS: /Users/YourName/Documents/SeaMeet/Screenshots/

파일 명명 규칙

SeaMeet은 자동으로 타임스탬프를 포함해 스크린샷의 이름을 지정합니다:

Screenshot_YYYYMMDD_HHMMSS.png

예시: Screenshot_20260209_143052.png

  • 촬영일: 2026년 2월 9일
  • 시간: 오후 2:30:52
  • 형식: PNG (고품질)

이 명명이 유용한 이유:

  • ✅ 각 스크린샷이 언제 촬영되었는지 정확히 알 수 있습니다
  • ✅ 파일 탐색기에서 시간순으로 정렬됩니다
  • ✅ 중복 파일명 충돌이 없습니다
  • ✅ 특정 스크린샷을 찾기 쉽습니다

스크린샷 메타데이터

모든 스크린샷에는 자동으로 추출된 정보가 포함됩니다:

{
  "filename": "Screenshot_20260209_143052.png",
  "type": "screenshot",
  "isScreenshot": true,
  "imageMetadata": {
    "width": 1920,
    "height": 1080,
    "format": "png",
    "fileSize": 2540000
  },
  "timestamp": "2026-02-09T14:30:52.000Z"
}

이것이 의미하는 것:

  • 크기: 1920×1080 픽셀 (Full HD)
  • 형식: PNG (무손실, 고품질)
  • 파일 크기: ~2.5 MB
  • 캡처 시간: 자동으로 기록됨

SeaMeet에서 스크린샷 보기

SeaMeet은 캡처를 보기 위한 전용 스크린샷 뷰어를 제공합니다.

스크린샷 뷰어 열기

방법 1: 사이드바에서

  1. "Recent Snapshots" 사이드바를 봅니다
  2. 스크린샷을 찾습니다 (📷 카메라 아이콘이 있음)
  3. 클릭합니다
  4. 스크린샷 뷰어가 자동으로 열립니다

방법 2: 파일 가져오기에서

  1. "Import"를 클릭하거나 파일을 SeaMeet으로 드래그합니다
  2. 이미지 파일 (PNG, JPG 등)을 선택합니다
  3. 사이드바에 나타납니다
  4. 클릭하여 봅니다

  • 가져온 다른 이미지는 "JPG", "WebP" 등을 표시할 수 있습니다

  2. 📋 복사 버튼을 클릭합니다
  3. 또는 Ctrl+C (Windows) / Cmd+C (macOS)를 누릅니다
  4. 이미지를 받아들이는 모든 앱(이메일, 채팅, 문서 등)에 붙여넣습니다

언제 사용하나요:

  • ✅ 웹사이트나 양식에 업로드
  • ✅ 채팅 메시지에서 공유
  • ✅ 빠른 시각 참조 만들기

프로 팁: 이는 다른 곳에 먼저 저장하지 않고 스크린샷을 공유하는 가장 빠른 방법입니다!

언제 사용하나요:

  • ✅ 다른 위치로 이동해야 할 때
  • ✅ 파일에서 이메일에 첨부하고 싶을 때
  • ✅ 다른 프로그램에서 편집해야 할 때

사이드바에서 스크린샷 관리하기

스크린샷은 녹음과 함께 "Recent Snapshots" 섹션에 나타납니다.

스크린샷이 표시되는 방식

시각적 표시기:

  • 📷 카메라 아이콘 (🎥 비디오 또는 🎵 오디오 아이콘 대신)
  • 아이콘 배경은 보라색
  • 메타데이터 라인에 크기를 표시 (예: "1920×1080")
  • "Screenshot" 라벨을 표시

사이드바 항목 예시:

┌─────────────────────────────────────────┐
│ 📷  Screenshot                          │
│     Screenshot_20260209_143052.png      │
│     1920×1080 • 오늘 오후 2:30          │
└─────────────────────────────────────────┘

스크린샷 검색

검색 바는 스크린샷에도 작동합니다:

  1. 사이드바 상단의 검색 상자에 입력합니다
  2. 검색과 일치하는 스크린샷이 나타납니다
  3. 파일명과 메타데이터로 검색합니다

검색할 수 있는 것:

  • 부분 파일명 (예: "Screenshot_20260209")
  • 시간 키워드 (예: "Today", "Yesterday")
  • 파일 확장자 (예: ".png")

정렬 및 정리

스크린샷이 정렬되는 방식:

  • 타임스탬프별 (최신순)
  • 녹음과 시간순으로 혼합됨
  • 가장 최근 캡처가 상단에 표시됨

자동 새로 고침:

  • 캡처 즉시 새 스크린샷이 나타납니다
  • 수동으로 새로 고칠 필요 없음 (필요한 경우 가능)
  • 사이드바가 실시간으로 업데이트됩니다

외부 스크린샷 가져오기

다른 소스의 스크린샷을 SeaMeet으로 가져올 수 있습니다.

지원되는 이미지 형식

SeaMeet은 이러한 이미지 유형을 가져올 수 있습니다:

형식확장자최적 용도
PNG.png스크린샷, 투명도가 있는 그래픽
JPEG.jpg, .jpeg사진, 그라데이션이 있는 이미지
WebP.webp현대 웹 이미지
GIF.gif간단한 애니메이션, 그래픽
BMP.bmp비압축 이미지 (큰 파일)
TIFF.tiff전문 인쇄
HEIC/HEIF.heiciPhone 사진 (macOS/iOS)

이미지를 가져오는 방법

방법 1: 가져오기 버튼 사용

  1. SeaMeet에서 "Open Files" 또는 "Import"를 클릭합니다
  2. 파일 대화상자에서 필터를 이미지로 변경합니다
  3. 이미지 파일을 선택합니다
  4. "Open"을 클릭합니다
  5. 이미지가 사이드바에 나타납니다

방법 2: 드래그 앤 드롭

  1. 파일 탐색기에서 이미지 파일을 찾습니다
  2. SeaMeet 창으로 드래그합니다
  3. 사이드바 영역에 놓습니다
  4. 이미지가 가져와져 목록에 나타납니다

가져올 때 무슨 일이 일어나나요:

  • SeaMeet이 메타데이터 (크기, 파일 크기)를 추출합니다
  • 이미지는 참조됩니다 (복제되지 않음)
  • 스크린샷 아이콘과 함께 사이드바에 나타납니다
  • 스크린샷 뷰어에서 볼 수 있습니다

참고: 가져온 이미지는 원래 위치에 그대로 있습니다. SeaMeet은 그것에 대한 참조를 만듭니다.

실용적인 스크린샷 시나리오

스크린샷이 완벽한 도구인 실세계 상황을 살펴봅시다.

시나리오 1: 오류 메시지 저장

상황: 애플리케이션에서 이해할 수 없는 오류가 표시됩니다. 기술 지원팀에 문의하고 싶습니다.

스크린샷이 완벽한 이유:

  • 정확한 오류 텍스트를 캡처합니다
  • 모든 오류 코드를 포함합니다
  • 컨텍스트(무엇을 하고 있었는지)를 표시합니다
  • 지원 티켓에 쉽게 첨부할 수 있습니다

수행 방법:

  1. 오류가 나타나면 Ctrl+Alt+S (Windows) 또는 Cmd+Shift+S (macOS)를 누릅니다
  2. 오류 대화상자 주위에 상자를 그립니다
  3. 스크린샷이 자동으로 저장됩니다
  4. 열고 복사를 사용해 지원 채팅/이메일에 붙여넣습니다

시나리오 2: 설정 문서화

상황: 중요한 설정을 변경하고 이전이 어땠는지 기억하고 싶습니다.

스크린샷이 완벽한 이유:

  • 정확한 구성의 시각적 기록
  • 모든 것을 적는 것보다 빠름
  • 전사 오류의 가능성 없음
  • "이전"과 "이후"를 쉽게 비교

수행 방법:

  1. 설정 페이지로 이동합니다
  2. 현재 설정의 스크린샷을 찍습니다
  3. 변경 사항을 적용합니다
  4. 다른 스크린샷을 찍습니다
  5. 이제 두 상태의 시각적 기록이 있습니다

시나리오 3: 단계별 지침 작성

상황: 동료에게 소프트웨어 사용 방법을 설명하고 시각 자료가 필요합니다.

스크린샷이 완벽한 이유:

  • 클릭할 버튼을 정확히 표시
  • 메뉴 위치 캡처
  • 의미에 대한 모호함 없음
  • 전문적인 문서화

수행 방법:

  1. 직접 프로세스를 진행합니다
  2. 각 중요한 단계에서 스크린샷을 찍습니다
  3. 나중에 설명과 함께 순서대로 배열합니다
  4. 완전한 가이드를 공유합니다

시나리오 4: 비디오에서 특정 프레임 캡처

상황: 비디오를 보고 있고 특정 순간을 이미지로 저장하고 싶습니다.

비디오 프레임보다 스크린샷이 나은 이유:

  • 비디오 프레임 추출보다 높은 품질
  • 즉각적인 캡처 (비디오 처리 없음)
  • 원하는 정확한 순간
  • 비디오 클립보다 작은 파일

수행 방법:

  1. 정확한 프레임에서 비디오를 일시정지합니다
  2. 비디오 플레이어 영역의 스크린샷을 찍습니다
  3. 이미지가 전체 품질로 저장됩니다
  4. 그 순간만 공유할 수 있습니다

시나리오 5: 웹 콘텐츠 저장

상황: 웹사이트에서 변경되거나 사라질 수 있는 중요한 정보를 발견합니다.

스크린샷이 완벽한 이유:

  • 보이는 그대로 페이지를 보존
  • 사이트가 다운되어도 작동
  • 시각 디자인과 레이아웃을 캡처
  • 전체 페이지를 저장하는 것보다 빠름

수행 방법:

  1. 페이지로 이동합니다
  2. 관련 섹션의 스크린샷을 찍습니다
  3. 이미지가 영구적으로 저장됩니다
  4. 영원히 시각적 기록을 가지게 됩니다

스크린샷을 다른 기능과 비교

스크린샷과 다른 SeaMeet 기능을 언제 사용해야 하는지 이해하면 더 효율적으로 작업할 수 있습니다.

스크린샷 vs. 비디오 녹화

측면스크린샷비디오 녹화
캡처하는 것한 순간연속 동작
파일 크기작음 (~2-5 MB)큼 (~60 MB/분)
최적 용도정적 콘텐츠, 텍스트, UI동작, 프로세스, 데모
캡처 시간즉시지속 시간 필요
품질완벽한 픽셀 정확도압축, 흐릴 수 있음
사운드없음오디오 포함 가능

결정 가이드:

  • 스크린샷을 사용할 때: 특정 순간이 필요하거나, 텍스트가 중요하거나, 파일 크기가 중요할 때
  • 비디오를 사용할 때: 프로세스를 표시해야 하거나, 동작이 중요하거나, 오디오가 필요할 때

스크린샷 vs. Flashback 녹음

측면스크린샷Flashback 녹음
타이밍현재 순간과거 (이미 일어남)
지속 시간즉시가변 (지난 X분)
파일 크기매우 작음 (~2-5 MB)중간 (~가변)
최적 용도현재 상태 캡처놓친 순간 복구
품질전체 해상도비디오 품질 (압축)

결정 가이드:

  • 스크린샷을 사용할 때: 지금 보고 있는 것을 저장하고 싶을 때
  • Flashback을 사용할 때: 방금 놓친 것이 있고 지난 몇 분을 복구하고 싶을 때

스크린샷 모범 사례

스크린샷을 최대한 활용하려면 다음 지침을 따르세요.

스크린샷을 찍기 전에

✅ 화면 준비

  • 관련 없는 창 닫기
  • 민감한 정보 숨기기
  • 캡처하려는 콘텐츠 최대화
  • 좋은 대비와 가시성 확보

✅ 목적 고려

  • 이 스크린샷을 누가 볼 것인가?
  • 어떤 정보가 보여야 하는가?
  • 캡처 크기에서 텍스트가 읽힐까?
  • 민감한 데이터가 표시되고 있는가?

✅ 데스크톱 정리

  • 보이는 곳에서 개인 파일 제거
  • 채팅 애플리케이션 닫기
  • 필요한 경우 알림 영역 숨기기
  • 전문적인 모습 제시

스크린샷을 찍을 때

✅ 선택 정확히

  • 필요한 것을 정확히 캡처 (더도 덜도 말고)
  • 이해에 도움이 된다면 컨텍스트 포함
  • 중요한 UI 요소를 자르지 않기
  • 콘텐츠 주위에 작은 여백 남기기

✅ 해상도 주의

  • 더 높은 해상도 = 더 많은 디테일
  • 그러나 더 큰 파일 크기
  • 스크린샷이 어디에 사용될지 고려
  • 1080p는 대부분의 목적에 충분합니다

✅ 완료 전 확인

  • 올바른 영역을 캡처했는가?
  • 콘텐츠가 명확하게 보이는가?
  • 민감한 정보가 실수로 포함되었는가?
  • 텍스트가 읽히는가?

스크린샷을 찍은 후

✅ 설명적으로 이름 바꾸기 다음 대신: Screenshot_20260209_143052.png 시도: Photoshop_Layers_Error.png 또는 Website_Homepage_Design.png

✅ 정기적으로 정리

  • 프로젝트나 주제별 폴더 만들기
  • 임시/테스트 스크린샷 삭제
  • 중요한 캡처 백업
  • 더 이상 필요 없는 오래된 스크린샷 보관

✅ 공유 전 검토

  • 스크린샷을 열고 품질 확인
  • 민감한 정보 확인
  • 의도한 것을 명확히 보여주는지 확인
  • 필요한 경우 자르거나 주석 달기

스크린샷 문제 해결

"스크린샷이 사이드바에 나타나지 않음"

가능한 원인 및 해결책:

  1. 스캔이 완료되었는지 확인

    • 사이드바에서 새로 고침 버튼을 클릭하세요
    • 스캔이 끝날 때까지 몇 초 기다리세요
    • 새 스크린샷이 나타나야 합니다

  2. 파일 위치 확인

    • 스크린샷은 Documents/SeaMeet/Screenshots/에 있어야 합니다
    • 폴더가 존재하는지 확인하세요
    • PNG 파일이 해당 위치에 있는지 확인하세요

  3. 파일 권한 확인

    • SeaMeet에는 폴더를 읽을 권한이 필요합니다
    • macOS에서: 시스템 환경설정 → 보안 및 개인정보 보호 → 파일 및 폴더 확인
    • Windows에서: 안티바이러스가 액세스를 차단하지 않는지 확인

  4. SeaMeet 재시작

    • 때로는 새 스캔이 필요합니다
    • 애플리케이션을 닫고 다시 엽니다
    • 스크린샷이 나타나는지 확인합니다

"스크린샷 품질이 좋지 않아 보임"

해결책:

  1. 스크린샷은 항상 전체 품질입니다

    • SeaMeet은 100% 품질로 PNG를 저장합니다
    • 뷰어는 원본 파일을 표시합니다
    • 좋지 않아 보이면 원본 콘텐츠가 저해상도일 수 있습니다

  2. 화면 스케일링 확인

    • 일부 노트북은 125% 또는 150% 스케일링을 사용합니다
    • 이는 외관상 선명도에 영향을 줄 수 있습니다
    • 스크린샷은 보이는 그대로 (스케일링된) 캡처합니다

  3. 원본 콘텐츠 확인

    • 비디오를 캡처하는 경우 비디오가 저해상도일 수 있습니다
    • 스크린샷은 존재하지 않는 디테일을 추가할 수 없습니다
    • 화면에 있는 것을 정확히 캡처합니다

"디스크에서 스크린샷을 찾을 수 없음"

해결책:

  1. 기본 위치 확인

    • Windows: C:\Users\[YourName]\Documents\SeaMeet\Screenshots\
    • macOS: /Users/[YourName]/Documents/SeaMeet/Screenshots/

  2. 파일명으로 검색

    • "Screenshot_"으로 시작하는 파일을 찾습니다
    • 시스템의 파일 검색을 사용합니다
    • PNG 파일로 필터링합니다

  3. SeaMeet 설정 확인

    • 설정 → 저장소에서 저장 위치를 변경할 수 있습니다
    • 거기에 표시된 스크린샷 폴더 경로를 확인합니다

"클립보드에 복사가 작동하지 않음"

해결책:

  1. 키보드 대신 버튼 시도

    • 뷰어에서 "Copy" 버튼을 클릭합니다
    • 때로는 키보드 단축키가 작동하지 않습니다

  2. 클립보드 권한 확인

    • 일부 보안 소프트웨어는 클립보드 액세스를 차단합니다
    • SeaMeet을 재시작해 보세요
    • 다른 애플리케이션으로 테스트하세요

  3. 파일이 존재하는지 확인

    • 스크린샷이 이동되거나 삭제되면 복사가 작동하지 않습니다
    • 파일 위치를 열어 존재하는지 확인합니다
    • 필요한 경우 다시 가져오기

"공유 버튼이 나타나지 않음"

이는 Windows와 Linux에서 정상입니다:

  • 공유 버튼은 macOS에서만 나타납니다
  • macOS에는 내장 SharingService API가 있습니다
  • Windows와 Linux에는 표준화된 공유 시스템이 없습니다
  • 이러한 플랫폼에서는 대신 복사하여 붙여넣기를 사용하세요
