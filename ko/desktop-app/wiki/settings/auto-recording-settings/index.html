자동 녹음 설정

제23장: 자동 녹음 설정

소개

녹음 시작을 기억할 필요가 없다고 상상해 보세요. 이런 상황을 그려보세요: Zoom 회의에 참가하기 위해 클릭하면, SeaMeet이 자동으로 이를 감지하고, 백그라운드에서 녹음을 시작하여, "Record"를 한 번도 클릭하지 않고도 전체 세션을 캡처합니다. 회의가 끝나면 자동으로 중지되고 파일이 저장됩니다. 이것은 공상 과학이 아닙니다—SeaMeet의 자동 녹음 기능이며, 47개 이상의 커뮤니케이션 및 회의 애플리케이션을 지원합니다.

이 장은 자동 녹음 감지를 설정하고, 구성하고, 마스터하기 위한 완벽한 가이드입니다. SeaMeet에 회의 앱을 감시할 수 있는 권한을 부여하고, 감지 감도를 미세 조정하고, 회의가 감지되었을 때 어떤 일이 일어나는지 구성하는 방법을 배울 것입니다—이 모든 것을 개인정보와 통제를 유지하면서 할 수 있습니다.

장 목표

이 장을 읽은 후, 다음을 할 수 있게 됩니다:

  • 자동 회의 감지 활성화 및 구성
  • SeaMeet이 사용하는 다섯 가지 감지 방법 이해
  • 특정 애플리케이션에 대한 권한 부여 (47개 이상의 지원 앱)
  • 워크플로우에 맞게 감지 감도 조정
  • 자동 작업 구성 (녹음, 알림 또는 확인)
  • 감지 문제 해결
  • 편의성과 개인정보 및 시스템 리소스 간의 균형 유지

자동 녹음이란?

자동 녹음은 온라인 회의에 참가할 때를 감시하여 자동으로 녹음을 시작할 수 있는 SeaMeet의 지능형 모니터링 시스템입니다. 녹음 버튼을 절대 잊지 않는 도우미라고 생각하세요.

작동 방식 (간단 버전)

자동 녹음 없이:

Zoom 회의 참가 → 녹음 깜빡함 → 회의 종료 → 아무것도 캡처 안 됨 ❌

자동 녹음 사용 시:

Zoom 회의 참가 → SeaMeet이 감지 → 자동 녹음 시작 → 
회의 종료 → 녹음이 자동으로 중지 및 저장 ✅

다섯 가지 감지 방법

SeaMeet은 탐정이 다양한 단서를 사용하는 것처럼 여러 기술을 사용하여 회의를 감지합니다:

방법 1: 창 제목 분석

  • 애플리케이션의 제목 표시줄을 감시합니다
  • "Zoom Meeting," "Microsoft Teams," "Google Meet"와 같은 키워드를 감지합니다
  • 대상: 대부분의 전통적인 회의 앱

방법 2: 프로세스 모니터링

  • 어떤 애플리케이션이 실행 중인지 모니터링합니다
  • 회의 프로세스 시작을 감지합니다 (예: zoom.exe, Teams.exe)
  • 대상: 식별 가능한 프로세스가 있는 앱

방법 3: 오디오 스트림 감지

  • 회의에 전형적인 오디오 활동 패턴을 수신합니다
  • 마이크와 스피커가 함께 활성화될 때 감지합니다
  • 대상: 오디오를 사용하는 모든 앱 (웹 기반 회의도 캐치)

방법 4: 창 형상 분석

  • 회의 앱의 특징적인 창 모양과 크기를 인식합니다
  • 전체 화면 또는 특정 창 레이아웃을 감지합니다
  • 대상: 독특한 UI 레이아웃을 가진 앱

방법 5: URL/프로토콜 모니터링

  • 브라우저 URL에서 회의 링크를 모니터링합니다
  • meet.google.com, zoom.us/join 등으로 이동할 때 감지합니다
  • 대상: 브라우저의 웹 기반 회의

섹션 1: 자동 감지 활성화

마스터 스위치

☑ 자동 회의 감지 활성화

이 기능의 역할:

  • 감지 엔진을 활성화합니다
  • SeaMeet이 회의 애플리케이션을 모니터링하기 시작합니다
  • 다섯 가지 감지 신호를 감시하기 시작합니다
  • 자동 녹음 기능을 활성화합니다

개인정보 참고: SeaMeet은 회의 애플리케이션만 감지합니다—명시적으로 녹음을 시작하거나 자동 녹음을 구성하지 않는 한 화면이나 오디오를 녹음하지 않습니다.

리소스 사용:

  • CPU: 최소 (유휴 시 <1%)
  • RAM: 감지 엔진에 약 20-50MB
  • 영향: 현대 컴퓨터에서 거의 느끼지 못할 수준

섹션 2: 감지 감도

감도 이해

감지 감도는 SeaMeet이 회의를 식별하는 데 얼마나 적극적인지를 제어합니다. 연기 감지기처럼 생각하세요—너무 민감하면 오경보가 발생하고, 충분히 민감하지 않으면 실제 화재를 놓칩니다.

감도 수준:

낮은 감도:

감지 감도: [낮음 ▼]

동작:
• 트리거하려면 매우 강한 신호가 필요
• 여러 감지 방법이 일치해야 함
• 오탐지 감소
• 일부 회의를 놓칠 수 있음

적합한 용도:
• 매우 예측 가능한 회의 패턴을 가진 사용자
• 오탐지에 불편함을 느끼는 사용자
• 기능을 처음 테스트하는 경우

중간 감도 (권장):

감지 감도: [중간 ▼]

동작:
• 균형 잡힌 감지
• 대부분의 회의가 안정적으로 감지됨
• 가끔 오탐지 (드물게)
• 좋은 정확도

적합한 용도:
• 대부분의 사용자 (권장 설정)
• 다양한 회의 앱 혼용
• 일반적인 워크플로우

높은 감도:

감지 감도: [높음 ▼]

동작:
• 단일 강한 신호로 감지
• 거의 모든 회의를 캐치
• 더 많은 오탐지 가능
• 비회의 앱을 간혹 감지할 수 있음

적합한 용도:
• 회의를 절대 놓치고 싶지 않은 사용자
• 예측할 수 없는 회의 패턴
• 다양한 회의 플랫폼 사용

사용자 정의 감도:

일부 버전에서는 개별 감지 방법의 미세 조정이 가능합니다:
• 창 제목 감지: [높음/중간/낮음]
• 프로세스 모니터링: [높음/중간/낮음]
• 오디오 감지: [높음/중간/낮음]
• 형상 감지: [높음/중간/낮음]
• URL 감지: [높음/중간/낮음]

감도를 조정해야 할 때

감도를 높여야 하는 경우:

  • SeaMeet이 녹음하려는 회의를 놓치는 경우
  • 덜 일반적인 회의 앱을 사용하는 경우
  • 회의가 일관되지 않게 감지되는 경우

감도를 낮춰야 하는 경우:

  • 너무 많은 오탐지가 발생하는 경우
  • SeaMeet이 일반 영상 통화를 회의로 인식하는 경우
  • 비회의 앱이 감지를 트리거하는 경우

감도 테스트:

1. 감도를 중간으로 설정
2. 가장 자주 사용하는 앱에서 테스트 회의 시작
3. SeaMeet이 감지하는지 확인
4. 놓치는 경우 → 감도 높이기
5. 오탐지가 있는 경우 → 감도 낮추기

섹션 3: 감지 모드

스마트 감지 (권장)

감지 모드: [스마트 (권장) ▼]

작동 방식: SeaMeet은 다섯 가지 감지 방법을 모두 조합하여 증거의 가중치를 평가합니다:

  • 창 제목 + 프로세스 + 오디오 = 높은 확신 → 트리거
  • 창 제목만 = 중간 확신 → 감도에 따라 트리거될 수 있음
  • 오디오만 = 낮은 확신 → 보통 먼저 확인

장점:

  • 가장 정확한 감지
  • 오탐지 감소
  • 다양한 회의 유형에 적응

창 제목만

감지 모드: [창 제목만 ▼]

작동 방식: 애플리케이션 창 제목만을 기반으로 감지합니다.

장점:

  • 간단하고 예측 가능
  • 낮은 리소스 사용
  • 프라이버시 친화적 (프로세스를 모니터링하지 않음)

단점:

  • 웹 기반 회의를 놓칠 수 있음
  • 창 제목이 일반적인 경우 감지 불가
  • 앱이 제목을 변경하면 감지가 중단될 수 있음

적합한 용도:

  • 프로세스 모니터링에 대해 우려하는 사용자
  • 표준 회의 앱을 사용하는 간단한 설정

프로세스 모니터링

감지 모드: [프로세스 모니터링 ▼]

작동 방식: 어떤 애플리케이션이 실행 중인지를 기반으로 감지합니다.

장점:

  • 창이 최소화되어 있어도 회의를 캐치
  • 창 제목이 숨겨져 있어도 작동
  • 데스크톱 앱에 안정적

단점:

  • 앱이 적극적으로 실행 중이어야 함 (단순히 열려 있는 것이 아님)
  • 브라우저 기반 회의를 잘 캐치하지 못함
  • 리소스를 더 많이 사용

적합한 용도:

  • 데스크톱 앱을 많이 사용하는 사용자
  • 표준 앱이 있는 기업 환경

오디오 기반 감지

감지 모드: [오디오 기반 ▼]

작동 방식: 오디오 활동 패턴을 기반으로 감지합니다.

장점:

  • 오디오를 사용하는 모든 앱을 캐치
  • 브라우저 기반 회의에도 작동
  • 범용적인 감지 방법

단점:

  • 비회의 오디오를 감지할 수 있음 (통화, 동영상)
  • 마이크/스피커 접근이 필요
  • 오탐지가 발생할 수 있음

적합한 용도:

  • 웹 기반 회의 사용자
  • 특이하거나 사용자 정의 회의 플랫폼
  • 다른 방법이 실패할 때

섹션 4: 기본 작업

회의가 감지되면 어떻게 되나요?

SeaMeet이 반응하는 방식에 대해 세 가지 옵션이 있습니다:

옵션 1: 먼저 확인 (권장)

회의 감지 시: [먼저 확인 ▼]

동작:
• 알림 표시: "Zoom에서 회의가 감지되었습니다. 녹음을 시작하시겠습니까?"
• 예 또는 아니요를 클릭
• 승인한 경우에만 녹음 시작
• 사용자에게 통제권 부여

적합한 용도:
• 대부분의 사용자
• 프라이버시에 민감한 사용자
• 모든 회의를 녹음하고 싶지 않은 경우

옵션 2: 자동으로 녹음 시작

회의 감지 시: [자동으로 녹음 시작 ▼]

동작:
• 프롬프트 없이 녹음 즉시 시작
• 모든 것을 자동으로 캡처
• 회의 종료 시 중지 (구성된 경우)
• "설정하고 잊어버리기" 모드

적합한 용도:
• 규정 준수 요구 사항 (모든 회의를 녹음해야 하는 경우)
• 항상 녹음을 원하는 사용자
• 중요한 작업 아카이빙

옵션 3: 알림만

회의 감지 시: [알림만 ▼]

동작:
• 알림 표시: "회의가 감지되었습니다"
• 녹음 시작 안 함
• 원하면 수동으로 녹음 시작 가능
• 자동화 없이 인지만

적합한 용도:
• 감지 정확도 테스트
• 회의 패턴 학습
• 알고 싶지만 녹음은 원하지 않을 때

시작 전 지연

시작 전 지연: [5초 ▼]

옵션:
• 0초 — 즉시
• 3초 — 빠르게
• 5초 — 표준
• 10초 — 여유 있게
• 30초 — 참가 버퍼

지연을 사용하는 이유는?

0-3초:

  • 처음부터 캡처
  • 회의 전 대화를 캐치할 수 있음
  • 규정 준수 녹음에 적합

5초 (권장):

  • 초기 "참가 중" 화면 건너뛰기
  • 실제 회의 시작을 캡처
  • "먼저 확인" 모드에서 거부할 시간 확보

10-30초:

  • 잡담과 인사 건너뛰기
  • 주요 콘텐츠 캡처
  • 긴 회의에 적합

예시:

Zoom 회의에 참가합니다:
0:00 — 참가 클릭
0:03 — "호스트가 입장을 허용하기를 기다리는 중"
0:08 — 회의 입장
0:10 — 잡담 시작

5초 지연 설정 시:
• 녹음이 0:05에 시작
• 입장 시점부터 캡처
• 대기 화면은 놓침

섹션 5: 애플리케이션 권한

녹음을 트리거할 수 있는 앱 관리

애플리케이션 권한 섹션에는 47개 이상의 지원 앱과 체크박스가 나열되어 있습니다:

☑ Zoom — 활성화됨, 감지됨
☑ Microsoft Teams — 활성화됨, 감지됨
☑ Google Meet — 활성화됨, 감지됨
☐ Discord — 비활성화됨, 무시됨
☑ Webex — 활성화됨, 감지됨
☐ Skype — 비활성화됨, 무시됨

선택적 권한이 중요한 이유:

프라이버시:

  • 사용하지 않는 앱은 활성화하지 마세요
  • 불필요한 모니터링 방지
  • SeaMeet이 "감시"하는 범위를 제한

성능:

  • 모니터링할 앱이 적을수록 = 리소스 사용량 감소
  • 활성화된 앱에 대한 더 빠른 감지
  • 백그라운드 활동 감소

정확도:

  • 앱을 비활성화하면 오탐지 방지
  • 실제 도구에 감지를 집중

활성화 권장 앱

필수 (이것들을 활성화하세요):

  • ✅ Zoom
  • ✅ Microsoft Teams
  • ✅ Google Meet
  • ✅ Webex
  • ✅ Slack (허들/통화를 사용하는 경우)

일반 (사용하는 경우 활성화):

  • ✅ Skype / Skype for Business
  • ✅ GoTo Meeting
  • ✅ RingCentral
  • ✅ 8x8
  • ✅ BlueJeans

선택 (필요에 따라 활성화):

  • ☐ Discord (업무 통화에 사용하는 경우)
  • ☐ WhatsApp Desktop (업무에 사용하는 경우)
  • ☐ 게임 플랫폼 (Steam 등)
  • ☐ 소셜 앱 (Facebook 등)

업무에 따라 활성화:

  • 기업 사용자? 기업 앱 활성화 (Avaya, Mitel 등)
  • 교육? Blackboard, Adobe Connect 활성화
  • 크리에이티브? 필요 없을 수도 있음
  • 소셜 미디어 관리자? 메시징 앱 활성화

앱 활성화/비활성화 방법

단계별 안내:

  1. 자동 녹음 설정 열기

    • 설정 → Auto-Recording

  2. 애플리케이션 권한으로 스크롤

  3. 사용하는 앱 체크:

    • 모니터링하려는 각 앱 옆의 체크박스를 클릭
    • 또는 "Enable All" 버튼 사용 (권장하지 않음)

  4. 사용하지 않는 앱 체크 해제:

    • 사용하지 않는 앱은 체크 해제 상태로 둠
    • 불필요한 모니터링 감소

  5. "Apply" 클릭

  6. 감지 테스트:

    • 활성화된 앱 중 하나를 열기
    • 회의 시작
    • 감지가 작동하는지 확인

사용자 정의 앱 추가

일부 버전에서는 사용자 정의 애플리케이션 추가가 가능합니다:

[+ 사용자 정의 애플리케이션 추가]

세부 정보 입력:
• 애플리케이션 이름: "MyCustomApp"
• 창 제목 키워드: "Meeting,Call,Conference"
• 프로세스 이름: "mycustomapp.exe"
• [저장]

사용 시기:

  • 회사 전용 회의 플랫폼
  • 틈새 또는 산업별 도구
  • 베타 또는 미출시 애플리케이션

섹션 6: 회의 후 작업

자동 중지

☑ 회의 종료 시 자동으로 녹음 중지

이 기능의 역할: 회의가 종료되면 (앱이 닫히거나 퇴장하면), SeaMeet이 자동으로 녹음을 중지합니다.

유용한 이유:

  • "녹음 중지를 깜빡했어요" 방지
  • 저장 공간 절약 (회의 후 녹음 안 함)
  • 깨끗한 파일 (회의 콘텐츠만)

회의 종료 감지 방식:

  • 창 닫힘
  • 프로세스 종료
  • 30초 이상 오디오 중단
  • 명시적으로 회의에서 퇴장

참고: 이 기능을 비활성화하면 수동으로 중지할 때까지 녹음이 계속됩니다.

저장 알림

☑ 녹음 저장 시 알림 표시

이 기능의 역할: 녹음이 완료되고 저장되면 팝업을 표시합니다.

알림 예시:

✅ 녹음 저장됨
"Zoom Meeting - 2024-01-15"가 저장되었습니다.
길이: 45분
위치: SeaMeet Recordings

[녹음 보기] [닫기]

활성화하는 이유:

  • 녹음이 잘 되었는지 확인
  • 검토/이름 변경 알림
  • 안심감 제공

비활성화하는 이유:

  • 많은 회의를 녹음하는 경우 산만할 수 있음
  • 이미 작동하는 것을 알고 있는 경우
  • 나중에 녹음을 확인하는 것을 선호

스마트 이름 변경

☑ 회의 이름으로 녹음 파일 이름 변경 (가능한 경우)

이 기능의 역할: 일반적인 타임스탬프 이름 대신, SeaMeet이 실제 회의 이름을 사용하려고 합니다.

예시:

스마트 이름 변경 없이:
2024-01-15_14-30-22_Zoom.mp4

스마트 이름 변경 사용 시:
"Q1 Planning Meeting - Acme Corp" 2024-01-15.mp4
"Weekly Team Standup" 2024-01-15.mp4

작동 방식: SeaMeet은 다음에서 회의 제목을 읽습니다:

  • Zoom 회의 주제
  • Teams 회의 제목
  • 캘린더 이벤트 제목 (연결된 경우)
  • 창 제목 정보

제한 사항:

  • 모든 앱이 회의 이름을 노출하지는 않음
  • 즉석 회의에는 제목이 없을 수 있음
  • 사용 불가 시 타임스탬프로 대체

섹션 7: 고급 옵션

내부 회의 제외

☑ 내부 회사 회의 제외

이 기능의 역할: 회의가 내부 (같은 조직) vs. 외부 (고객, 벤더)인지 감지하려고 합니다.

작동 방식:

  • 회의 참가자를 읽음
  • 이메일 도메인 확인
  • 모든 참가자가 @yourcompany.com = 내부
  • 외부 도메인의 참가자가 있는 경우 = 외부

사용 사례: 고객 회의는 자동으로 녹음하지만 내부 팀 회의는 녹음하지 않음.

참고: 참가자 목록을 읽으려면 캘린더 통합 또는 회의 앱 권한이 필요합니다.

그룹 vs. 1:1

☑ 1:1 통화 녹음 안 함 (그룹 회의만)

이 기능의 역할: 회의에 3명 이상이 있는 경우에만 자동 녹음합니다.

사용 사례: 팀 회의는 녹음하고 싶지만 일상적인 1:1 확인은 녹음하고 싶지 않은 경우.

감지 방식:

  • 회의 앱에서 참가자 수를 읽음
  • 30초 동안 대기하여 참석자 수 카운트
  • 3명 이상 감지된 경우에만 녹음

주의: 사람들이 점진적으로 참가하는 경우 대규모 회의의 시작 부분을 놓칠 수 있습니다.

앱 설정 존중

☑ 앱 "녹음 금지" 설정 존중

이 기능의 역할: 일부 회의 앱에는 "이 회의는 녹음하지 않아야 합니다"라는 개인정보 설정이 있습니다. SeaMeet은 이를 존중합니다.

활성화하는 이유:

  • 법적 준수
  • 프라이버시 존중
  • 직업적 예의
  • 회사 정책에 의해 요구될 수 있음

작동 방식:

  • 회의 메타데이터에서 녹음 플래그를 확인
  • "녹음 금지" 플래그가 있으면 SeaMeet이 자동 녹음하지 않음
  • 필요한 경우 수동으로 재정의 가능

섹션 8: 테스트 및 문제 해결

감지 테스트 방법

단계별 테스트:

  1. 자동 감지 활성화

    • 설정 → Auto-Recording → 활성화
    • 감도를 중간으로 설정
    • 테스트 앱 활성화 (예: Zoom)
    • "Apply" 클릭

  2. 테스트 회의 열기

    • 활성화된 애플리케이션 열기
    • 테스트 회의 참가 또는 시작
    • 수동으로 녹음을 시작하지 않음

  3. 감지 확인

    • 5-10초 이내에 다음이 표시되어야 합니다:
      • 알림: "Zoom에서 회의가 감지되었습니다"
      • 또는 녹음이 자동으로 시작 (자동으로 설정된 경우)
      • 또는 시스템 트레이 표시기 변경

  4. 응답 확인

    • "먼저 확인" 모드: "예"를 클릭하여 녹음 시작
    • "자동" 모드: 녹음이 시작되었는지 확인
    • "알림만" 모드: 알림을 받았는지 확인

  5. 테스트 종료

    • 회의 퇴장
    • 자동 중지가 활성화된 경우 녹음이 중지되었는지 확인
    • 파일이 저장되었는지 확인

감지가 작동하지 않으면?

감지 문제 해결

문제 1: 전혀 감지되지 않음

확인:

  1. 자동 녹음이 활성화되어 있나요? (설정 → 체크박스)
  2. 특정 앱이 권한에서 활성화되어 있나요?
  3. 감도를 높음으로 높여보세요
  4. 감지 모드를 변경해 보세요 (예: 오디오 기반으로)
  5. SeaMeet을 완전히 다시 시작하세요

문제 2: 오탐지

증상:

  • 회의 중이 아닌데 SeaMeet이 회의를 감지
  • YouTube 시청 중 녹음 시작
  • 일반 영상 통화에서 트리거

해결 방법:

  1. 감도를 낮음으로 낮추기
  2. "창 제목만" 감지로 전환
  3. 잘못 트리거하는 앱 비활성화
  4. 특정 창 제목 제외
  5. 자동 시작 대신 "먼저 확인" 모드 사용

문제 3: 일관되지 않은 감지

증상:

  • 때때로 감지하고 때때로 못함
  • Zoom에서는 작동하지만 Teams에서는 안 됨
  • SeaMeet을 연 후 첫 번째 회의를 놓침

해결 방법:

  1. 감도 높이기
  2. "스마트" 감지 모드 사용
  3. 여러 감지 방법 활성화
  4. 앱 업데이트로 창 제목이 변경되었는지 확인
  5. 회의 앱을 열기 전에 SeaMeet이 실행 중인지 확인

문제 4: 감지는 되지만 녹음 안 됨

증상:

  • "회의가 감지되었습니다" 알림을 받음
  • 하지만 녹음이 시작되지 않음
  • 또는 확인을 요청하지만 "예"를 클릭해도 아무 일도 일어나지 않음

해결 방법:

  1. 저장 공간 확인 (설정 → Storage)
  2. SeaMeet에 녹음 권한이 있는지 확인
  3. SeaMeet을 관리자로 실행
  4. 다른 녹음이 이미 진행 중인지 확인
  5. SeaMeet 다시 시작

섹션 9: 프라이버시 및 보안

SeaMeet이 모니터링하는 것

자동 감지가 활성화된 경우:

  • SeaMeet은 애플리케이션 창 제목을 모니터링합니다
  • SeaMeet은 어떤 프로세스가 실행 중인지 확인합니다
  • SeaMeet은 오디오 패턴을 수신할 수 있습니다 (활성화된 경우)
  • SeaMeet은 화면을 지속적으로 녹화하지 않습니다
  • SeaMeet은 이 모니터링 데이터를 저장하지 않습니다
  • SeaMeet은 모니터링 정보를 서버로 전송하지 않습니다

모든 감지는 컴퓨터에서 로컬로 이루어집니다.

SeaMeet이 녹음하는 것

명시적으로 녹음할 때만:

  • SeaMeet은 마이크 및/또는 시스템에서 오디오를 녹음합니다
  • SeaMeet은 화면에서 영상을 녹음합니다 (비디오 모드의 경우)
  • 녹음은 선택한 위치에 로컬로 저장됩니다
  • SeaMeet은 녹음을 어디에도 업로드하지 않습니다
  • 데이터에 대한 완전한 통제권이 있습니다

프라이버시를 위한 모범 사례

  1. 실제로 사용하는 앱만 활성화

    • 사용하지 않는 앱에 대한 모니터링을 활성화하지 마세요
    • 불필요한 모니터링 범위 감소

  2. "먼저 확인" 모드 사용

    • 녹음 시점을 직접 통제
    • 예기치 않은 녹음 없음

  3. 녹음을 정기적으로 검토

    • 필요 없는 녹음 삭제
    • 민감한 데이터를 보관하지 마세요

  4. 회의 참가자에게 알림

    • 많은 관할권에서 법적 요구 사항
    • 직업적 예의
    • 많은 회의 앱이 "녹음 중" 표시기를 보여줌

  5. 녹음 폴더 보안

    • 강력한 컴퓨터 비밀번호 사용
    • 민감한 녹음에 대한 암호화 고려
    • 녹음을 불필요하게 공유하지 마세요
