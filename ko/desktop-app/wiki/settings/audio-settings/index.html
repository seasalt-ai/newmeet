오디오 설정

20장: 오디오 설정

소개

소리는 녹음의 영혼입니다. 중요한 비즈니스 회의를 캡처하든, 팟캐스트를 녹음하든, 가족 화상 통화를 저장하든, 오디오 품질은 전문적인 결과물과 답답하고 사용할 수 없는 결과물의 차이를 만들어냅니다. 오디오 설정은 모든 목소리가 명확하게 전달되도록 보장하는 도구 모음입니다.

이 장을 마치면 오디오 전문가가 됩니다. 올바른 마이크를 선택하고, 볼륨 레벨을 완벽하게 조정하고, Bluetooth 레이턴시와 같은 일반적인 오디오 함정을 피하고, 필요에 맞는 최적의 오디오 형식을 선택하는 방법을 알게 됩니다.

장 목표

이 장을 읽고 나면 다음을 할 수 있습니다:

  • 기본 마이크 선택 및 구성
  • 최적의 볼륨 레벨을 위한 마이크 게인 조정
  • Bluetooth 오디오 레이턴시 문제 이해 및 방지
  • 필요에 맞는 올바른 오디오 형식 선택 (MP3, WAV, WebM)
  • 시스템 오디오 캡처 설정 구성
  • 일반적인 오디오 녹음 문제 해결
  • 다양한 녹음 시나리오에 맞는 오디오 설정

오디오 설정이 중요한 이유

이 시나리오를 상상해보세요: 2시간짜리 전략 기획 회의를 방금 끝냈습니다. 팀이 나중에 결정 사항을 검토할 수 있도록 전체 세션을 녹화했습니다. 하지만 재생하면 다음을 발견합니다:

  • 목소리가 거의 들리지 않음 (마이크가 너무 멀리 있음)
  • 화상 통화의 고객 목소리가 수중에서 말하는 것처럼 들림 (너무 강한 압축)
  • 산만한 에코가 있음 (실내 음향 + 너무 높은 게인)
  • 타이핑할 때마다 천둥 소리처럼 들림 (키보드를 감지하는 민감한 마이크)

영상은 훌륭하지만 오디오가 너무 나빠서 녹음이 거의 쓸모없습니다. 이것이 오디오 설정에 시간을 투자하는 것이 배당금을 내는 이유입니다.

오디오 설정을 마스터해야 하는 주요 이유:

1. 전문적인 품질

  • 명확한 오디오는 유능하고 준비된 사람처럼 들리게 함
  • 나쁜 오디오는 최고의 콘텐츠조차 약화시킴

2. 이해력 및 접근성

  • 명확한 오디오는 이해하기 더 쉬움
  • 전사 정확도에 중요

3. 파일 크기 관리

  • 오디오 형식은 파일 크기에서 크게 차이남
  • 선명도를 희생하지 않고 저장 공간 절약

4. 재녹음 방지

  • 처음부터 올바르게 하는 것이 더 좋음
  • 회의 재녹음은 보통 불가능

오디오 기본 이해

디지털 오디오 작동 원리 (간단한 설명)

샘플링 레이트 = 초당 "사진" 수

  • 44.1kHz = 초당 44,100개의 샘플
  • 48kHz = 초당 48,000개의 샘플
  • 높을수록 = 더 많은 디테일, 더 큰 파일

비트 깊이 = 각 샘플의 디테일 양

  • 16비트 = 65,536개의 가능한 값
  • 24비트 = 16.7백만개의 가능한 값
  • 높을수록 = 더 넓은 다이나믹 레인지, 더 큰 파일

비트레이트 = 초당 총 데이터

  • 샘플 레이트 × 비트 깊이 × 채널 수
  • 높을수록 = 더 좋은 품질, 더 큰 파일

오디오 채널

모노 (1 채널): 단일 오디오 스트림, 작은 파일, 음성 녹음에 적합

스테레오 (2 채널): 왼쪽 및 오른쪽 오디오 스트림, 더 큰 파일, 음악에 적합

SeaMeet 일반적으로 녹음:

  • 마이크 오디오는 모노로
  • 시스템 오디오는 스테레오로 (소스가 스테레오인 경우)

섹션 1: 마이크 선택

마이크 유형

1. 내장 마이크 (노트북/웹캠)

  • 장점: 항상 사용 가능, 설정 불필요
  • 단점: 낮은 품질, 컴퓨터 소음 감지, 위치에 민감
  • 적합: 긴급 사용에만

2. USB 마이크 (독립형)

  • 예: Blue Yeti, Audio-Technica AT2020USB+, Rode NT-USB
  • 장점: 우수한 품질, 쉬운 설정, 합리적인 가격
  • 적합: 홈 오피스, 팟캐스팅, 정기 녹음

3. 헤드셋 마이크

  • 예: Jabra, Plantronics, 게이밍 헤드셋
  • 장점: 입까지 일정한 거리, 핸즈프리
  • 적합: 긴 통화, 게이밍

4. 무선/Bluetooth 마이크

  • 예: AirPods, Bluetooth 헤드셋
  • 장점: 이동의 자유, 케이블 없음
  • 단점: 레이턴시 문제, 배터리 의존성
  • 적합: 짧은 통화, 모바일 녹음 (주의 필요)

5. 전문가용 XLR 마이크

  • 예: Shure SM7B, Electro-Voice RE20
  • 장점: 스튜디오 품질
  • 단점: 오디오 인터페이스 필요, 복잡한 설정
  • 적합: 전문 스튜디오, 방송 품질

SeaMeet에서 기본 마이크 선택

  1. 오디오 설정 열기 (설정 기어 아이콘 → "Audio")
  2. "Default microphone" 드롭다운 찾기
  3. 드롭다운 클릭 → 사용 가능한 모든 마이크 나열
  4. 선호하는 마이크 선택
  5. "Apply" 클릭

팁:

  • 이름에 "Microphone"이 있는 마이크 선택, "Stereo Mix"는 선택 안 함
  • "Default"는 Windows 기본값 (예기치 않게 변경될 수 있음)
  • 특정 장치를 선택하면 일관성이 보장됨

마이크 테스트

중요한 것을 녹음하기 전에 항상 마이크를 테스트하세요!

레벨 미터 해석:

  • 🟢 초록색 (-30 ~ -12 dB): 좋은 레벨
  • 🟡 노란색 (-12 ~ -6 dB): 점점 커짐, 가끔은 괜찮음
  • 🔴 빨간색 (-6 ~ 0 dB): 너무 큼! 왜곡 발생!

체크할 사항:

  • ☐ 명확함, 먹먹하지 않음
  • ☐ 에코나 잔향 없음
  • ☐ 배경 소음 없음 (팬, 에어컨)
  • ☐ 일정한 볼륨
  • ☐ 지직거림이나 정전기 없음

섹션 2: 마이크 게인 (볼륨 컨트롤)

게인은 마이크 신호가 증폭되는 정도를 나타내는 기술적 용어입니다.

게인 대 볼륨 이해

게인 (입력): 마이크 신호가 얼마나 큰지 제어 (녹음 전에 조정)

  • 너무 높으면 = 왜곡 (클리핑)
  • 너무 낮으면 = 조용하고 잡음 많은 녹음

볼륨 (출력): 재생 소리가 얼마나 큰지 제어 (녹음 품질에 영향 없음)

마이크 게인 조정

슬라이더를 조정하여 일반 음성이 일관되게 -12 ~ -6 dB에 도달하도록 합니다.

시각적 안내:

너무 낮음:   [●░░░░░░░░░░░░░░░░░░░░] 15%  -- 미터가 거의 움직이지 않음
좋음:        [━━━━━━━━━●━━━━━━━━━━━] 65%  -- 미터가 녹색 구역에서 튀어오름
너무 높음:   [██████████████████●░] 95%  -- 미터가 항상 빨간색, 왜곡 발생

"Boost" 설정

일부 마이크(특히 내장 노트북 마이크)는 추가 증폭인 "부스트"가 필요합니다.

부스트 사용 시기: 게인 100%에서도 레벨이 너무 낮을 때, 내장 마이크 사용 시

부스트를 사용하지 말아야 할 때: 마이크가 이미 충분히 큰 경우, 쉬익 소리가 들릴 때

자동 게인: 친구인가 적인가?

장점: 일관성 없는 화자에게 좋음, 일정한 볼륨 유지

단점: "펌핑" 효과 야기 가능, 배경 소음 증폭 가능, 전문 녹음에 부적합

권장:

  • ✅ 활성화: 일반 팀 회의, 편의 우선
  • ❌ 비활성화: 전문 프레젠테이션, 팟캐스트, 고객 회의

섹션 3: 시스템 오디오 캡처

시스템 오디오는 컴퓨터에서 나오는 소리입니다—화상 통화 목소리, 알림 소리, 재생하는 영상 등.

시스템 오디오 소스 선택

권장 옵션:

  1. Default Output Device — 대부분의 사용자에게 권장
  2. 특정 출력 장치 — 여러 출력이 있는 경우
  3. Stereo Mix / What U Hear — Windows 사운드 설정에서 활성화 필요

시스템 오디오 대 마이크: 믹스

"Both" (마이크 + 시스템 오디오)로 녹음하면 SeaMeet가 믹스를 만듭니다:

내 목소리 ─────┐
               ├──→ 함께 믹스 ──→ 녹음
상대방 목소리 ─┘

참고: 녹음 후에 분리할 수 없으므로, 녹음 전에 두 레벨을 올바르게 설정하세요.

섹션 4: Bluetooth 오디오 설정

Bluetooth 마이크와 헤드폰은 편리하지만 심각한 녹음 주의 사항이 따릅니다.

Bluetooth 레이턴시 이해

일반적인 Bluetooth 레이턴시:

  • Bluetooth 4.2: 200-300ms (매우 눈에 띔)
  • Bluetooth 5.0: 100-200ms (눈에 띔)
  • Bluetooth 5.2 with LE Audio: 40-80ms (더 나음)
  • 유선 연결: 10ms 미만 (감지 불가)

Bluetooth 경고 기능

SeaMeet가 Bluetooth 마이크를 감지하면 잠재적 레이턴시 문제에 대한 경고를 표시합니다.

☑ Show latency warning when using Bluetooth mics
☑ Automatically switch to wired mic if available

Bluetooth 녹음 모범 사례

Bluetooth 사용이 괜찮은 경우:

  • ✅ 일반 내부 회의
  • ✅ 오디오 품질이 중요하지 않을 때
  • ✅ 짧은 녹음 (15분 미만)

Bluetooth를 피해야 할 경우:

  • ❌ 고객 프레젠테이션
  • ❌ 팟캐스트 또는 전문 콘텐츠
  • ❌ 긴 녹음 (배터리 소모)
  • ❌ 정확한 립싱크가 중요할 때

섹션 5: 오디오 형식 설정

SeaMeet에서 사용 가능한 오디오 형식

1. MP3 (MPEG-1 Audio Layer III)

  • 적합: 공유, 웹 재생, 저장 효율성
  • 장점: 작은 파일, 범용 호환성
  • 단점: 손실 압축 (일부 품질 손실)
  • 일반적인 크기: 분당 1MB (128 kbps에서)

2. WAV (Waveform Audio File Format)

  • 적합: 전문 편집, 보관, 최대 품질
  • 장점: 비압축, 품질 손실 없음
  • 단점: 큰 파일, 느린 업로드
  • 일반적인 크기: 분당 10MB (CD 품질)

3. WebM (오디오 전용 하위 집합)

  • 적합: 웹 애플리케이션, HTML5 재생
  • 장점: 오픈 형식, 좋은 압축
  • 일반적인 크기: 분당 0.5-1MB (Opus 코덱)

4. OGG (Ogg Vorbis) — 오픈 소스 프로젝트에 적합, 제한된 장치 지원

5. M4A (MPEG-4 Audio) — Apple 에코시스템 및 팟캐스트에 적합

품질 설정

MP3/M4A 비트레이트 권장:

Quality: [Medium (128 kbps) ▼]

옵션:
• Low (96 kbps)        -- 작은 파일, 허용 가능한 품질
• Medium (128 kbps)    -- 좋은 균형, 권장
• High (192 kbps)      -- 더 좋은 품질, 더 큰 파일
• Very High (256 kbps) -- 우수한 품질
• Extreme (320 kbps)   -- 거의 투명, 큰 파일

WAV 비트 깊이:

  • 대부분의 녹음: 16비트면 충분
  • 전문 작업: 24비트

샘플 레이트 권장:

  • 영상 녹음에는 48 kHz 사용
  • 오디오 전용에는 44.1 kHz면 충분

형식 선택 가이드

시나리오 1: 빠른 팀 회의 메모 — MP3, Medium (128 kbps), 48 kHz

시나리오 2: 고객 프레젠테이션 녹음 — WAV, 16-bit, 48 kHz

시나리오 3: 팟캐스트 녹음 — MP3, High (192 kbps), 44.1 kHz

시나리오 4: 웹 업로드/스트리밍 — WebM (Opus 코덱), Medium, 48 kHz

섹션 6: 고급 오디오 설정

노이즈 서프레션

소프트웨어 알고리즘을 사용하여 배경 소음 (팬, 에어컨, 키보드 타이핑)을 제거합니다.

☑ Enable noise suppression
Level: [Medium ▼]

주의: 공격적인 서프레션은 목소리를 로봇처럼 들리게 만들 수 있습니다.

에코 캔슬레이션

마이크가 스피커의 소리를 감지할 때 에코를 방지합니다.

사용 시기:

  • ✅ 헤드폰 대신 스피커를 사용할 때
  • ✅ 스피커가 있는 회의실에서
  • ❌ 헤드폰/헤드셋으로는 필요 없음

자동 게인 컨트롤 (AGC)

☑ Enable AGC
Attack time: [Fast ▼]  -- 큰 소리에 얼마나 빨리 반응하는지
Release time: [Slow ▼] -- 정상으로 돌아오는 속도
Max gain: [+20 dB ▼]   -- 허용되는 최대 증폭

섹션 7: 오디오 문제 해결

문제 1: 마이크가 감지되지 않음

해결책:

  1. 물리적 연결 확인 (USB 케이블 단단히 꽂기, 다른 포트 시도)
  2. Windows 사운드 설정에서 마이크 활성화 확인
  3. 드라이버 업데이트
  4. macOS: 시스템 환경설정 → 보안 및 개인 정보 보호 → 마이크에서 SeaMeet 확인
  5. SeaMeet 완전히 닫고 다시 열기

문제 2: 녹음이 너무 조용함

해결책:

  1. 게인을 70-80%로 증가
  2. "Boost" 옵션 켜기 (10-20%)
  3. 마이크에 15-30cm로 더 가까이
  4. Windows 사운드 컨트롤 패널에서 레벨 80-100%로 설정
  5. 마이크의 물리적 음소거 버튼 확인

문제 3: 녹음이 너무 크거나 왜곡됨

해결책:

  1. 게인을 40-60%로 줄이기
  2. 부스트가 활성화된 경우 끄기
  3. 마이크에서 더 멀리 (30-45cm)
  4. 더 조용하게 말하기

문제 4: 배경 소음/쉬익 소리

기계적 소음: 노이즈 서프레션 활성화 (Medium 또는 Aggressive), 마이크를 팬에서 멀리

키보드 클릭: 키보드 댐퍼 사용, 마이크를 키보드 위 붐 암에 설치

실내 에코: 부드러운 가구 추가, 작은 방에서 녹음

전자 쉬익 소리: 게인 낮추기, 마이크에 더 가까이, 더 좋은 마이크 사용

문제 5: 시스템 오디오가 녹음되지 않음

해결책:

  1. "System Audio" 또는 "Both"로 녹음 모드 확인
  2. Default system audio source 설정 확인
  3. Windows: Stereo Mix 활성화 (사운드 컨트롤 패널 → 녹음 → 비활성화된 장치 표시)
  4. macOS: 시스템 환경설정 → 보안 및 개인 정보 보호 → 화면 녹화 권한 확인 후 SeaMeet 재시작

문제 6: 오디오/영상 싱크 문제

해결책:

  1. 유선 마이크로 전환 (Bluetooth 레이턴시 제거)
  2. 컴퓨터 재시작
  3. 이미 녹음한 경우 영상 편집기 (DaVinci Resolve, Premiere)에서 오디오 트랙 타이밍 수동 조정

섹션 8: 녹음 시나리오 구성

시나리오 1: 전문 팟캐스트 녹음

목표: 최대 품질, 보관 표준

마이크: USB 콘덴서 마이크 (Blue Yeti, AT2020)
게인: 65% (피크는 -6 dB)
부스트: Off
자동 게인: Off
형식: WAV (24-bit, 48 kHz)
노이즈 서프레션: Light 또는 Off
에코 캔슬레이션: Off
시스템 오디오: Off (인터뷰하는 경우 제외)
Bluetooth: 절대 사용 안 함

시나리오 2: 일일 팀 스탠드업 회의

목표: 좋은 품질, 효율적인 저장, 빠른 공유

마이크: 헤드셋 또는 내장
게인: 70%
부스트: 10% (노트북 마이크 사용 시)
자동 게인: On
형식: MP3 (192 kbps)
샘플 레이트: 48 kHz
노이즈 서프레션: Medium
에코 캔슬레이션: On (스피커 사용 시)
시스템 오디오: On
Bluetooth: 필요한 경우에만, 먼저 테스트

시나리오 3: 고객 프레젠테이션 녹음

목표: 전문적 품질, 안정적인 캡처

마이크: 고품질 USB 마이크 또는 헤드셋
게인: -12 dB 피크로 설정
부스트: Off
자동 게인: Off
형식: WAV (16-bit), MP3 백업
샘플 레이트: 48 kHz
노이즈 서프레션: Light
에코 캔슬레이션: Off (헤드폰 사용)
시스템 오디오: On
Bluetooth: 절대 사용 안 함

시나리오 4: 게이밍/튜토리얼 녹음

목표: 음성 선명도와 게임 오디오의 균형

마이크: 헤드셋 마이크 또는 전용 USB
게인: 60-70%
부스트: Off
자동 게인: Off
형식: MP3 (192 kbps) 또는 M4A
샘플 레이트: 48 kHz
노이즈 서프레션: Medium
에코 캔슬레이션: Off (헤드폰 착용 시)
시스템 오디오: On
Bluetooth: 절대 사용 안 함
