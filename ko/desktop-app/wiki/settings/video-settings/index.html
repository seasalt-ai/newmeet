비디오 설정

21장: 비디오 설정

소개

비디오 녹음은 SeaMeet를 단순한 오디오 캡처 도구에서 강력한 시각적 문서화 시스템으로 변환합니다. 소프트웨어 시연을 보존하든, 화상 통화를 캡처하든, 게임플레이를 녹화하든, 튜토리얼을 만들든, 비디오 설정은 녹음의 품질, 파일 크기, 호환성을 결정합니다. 이 장은 SeaMeet의 모든 비디오 측면을 마스터하기 위한 종합 가이드입니다.

이 장을 마치면 해상도, 프레임 레이트, 코덱 및 아마추어 녹음과 전문적인 결과물을 구분하는 모든 기술적 세부 사항을 이해하게 됩니다.

장 목표

이 장을 읽고 나면 다음을 할 수 있습니다:

  • 필요에 맞는 최적의 비디오 해상도 선택
  • 프레임 레이트 이해 및 30fps 대 60fps 사용 시기
  • 최적의 녹음 모드 선택 (전체 화면, 창, 영역)
  • 비디오 형식 및 코덱 효과적으로 구성
  • 더 나은 성능을 위한 하드웨어 가속 설정
  • 커서 녹음 및 효과 사용자 지정
  • 일반적인 비디오 녹음 문제 해결
  • 저장 상황에 맞게 품질 대 파일 크기 균형 맞추기

비디오 기본 이해

해상도: 화질은 얼마나 선명한가?

해상도는 비디오 이미지를 구성하는 픽셀(작은 점) 수입니다. 픽셀이 많을수록 = 더 많은 디테일 = 더 큰 파일 크기.

일반적인 해상도:

480p (SD - 표준 해상도)

  • 해상도: 854 × 480 픽셀
  • 파일 크기: 분당 ~25-50MB
  • 용도: 빠른 데모, 낮은 대역폭 상황

720p (HD - 고화질)

  • 해상도: 1280 × 720 픽셀
  • 파일 크기: 분당 ~75-150MB
  • 용도: 표준 품질, 웹 영상, 일반 녹음

1080p (FHD - 풀 HD)

  • 해상도: 1920 × 1080 픽셀
  • 파일 크기: 분당 ~150-300MB
  • 용도: 전문 작업, 상세 시연, 보관

1440p (2K - 쿼드 HD)

  • 해상도: 2560 × 1440 픽셀
  • 파일 크기: 분당 ~300-600MB
  • 용도: 고세밀 작업, 대형 모니터

4K (UHD - 울트라 HD)

  • 해상도: 3840 × 2160 픽셀
  • 파일 크기: 분당 ~600MB-1GB
  • 용도: 전문 프로덕션, 미래 대비

프레임 레이트: 모션이 얼마나 부드러운가?

프레임 레이트 (fps = 초당 프레임 수)는 각 초당 캡처되는 개별 이미지 수를 결정합니다.

일반적인 프레임 레이트:

24 fps (영화 표준) — 예술적 콘텐츠, 프레젠테이션에 사용

30 fps (표준 영상) — 대부분의 콘텐츠에 좋은 균형

60 fps (부드러운 모션) — 게임플레이, 소프트웨어 시연, 스포츠

120+ fps (고프레임 레이트) — 전문 게이밍, 슬로우 모션 효과

코덱: 비디오가 어떻게 압축되나?

코덱(코더-디코더)은 비디오를 압축하는 소프트웨어입니다.

H.264 (AVC) — 범용 호환성, 좋은 품질, 적절한 파일 크기. 일반적으로 MP4

H.265 (HEVC) — H.264보다 파일이 50% 작음, 지원 낮음. MP4

VP8/VP9 — 오픈 소스, 좋은 웹 지원. WebM

AV1 — 최첨단 효율성, 매우 느린 인코딩. MP4, WebM

대부분 사용자 권장: H.264 MP4 형식 사용. 모든 장치에서 작동합니다.

섹션 1: 녹음 모드

SeaMeet는 비디오를 캡처하는 세 가지 방법을 제공합니다.

모드 1: 전체 화면 녹음

캡처 대상: 모니터에 표시되는 모든 것

사용 시기:

  • ✅ 화상 통화 녹음 (전체 통화 창 캡처)
  • ✅ 프레젠테이션이나 웨비나 캡처
  • ✅ 게임플레이 녹음
  • ✅ 경계에 대해 생각하지 않고 모든 것을 캡처하고 싶을 때

장점: 단순함, 모든 것을 캡처, 콘텐츠 놓칠 위험 없음

단점: 개인 알림 포함, 큰 파일 크기

모드 2: 창 녹음

캡처 대상: 특정 애플리케이션 창만

사용 시기:

  • ✅ 특정 앱 녹음 (Zoom, 브라우저 등)
  • ✅ 바탕화면/개인 콘텐츠 숨기기
  • ✅ 더 작은 파일 크기
  • ✅ 하나의 앱에 집중된 튜토리얼 녹음

장점: 프라이버시, 작은 파일, 전문적인 모양

단점: 녹음 전에 창 선택 필요, 창이 최소화되면 녹음이 일시 정지

모드 3: 영역 녹음

캡처 대상: 사용자가 정의하는 화면의 사용자 지정 직사각형 영역

사용 시기:

  • ✅ 화면의 특정 부분 녹음
  • ✅ 집중된 튜토리얼 만들기
  • ✅ 인터페이스 없이 화상 통화 참가자 캡처
  • ✅ 불필요한 인터페이스 요소 제거

장점: 최소 파일 크기, 콘텐츠에 대한 최대 제어

단점: 녹음 영역을 수동으로 그려야 함, 콘텐츠가 영역 밖으로 이동하면 캡처 안 됨

기본 모드 선택

화상 통화 및 회의용:
→ 기본값: Fullscreen
→ 이유: 전체 통화 인터페이스를 안정적으로 캡처

튜토리얼 및 데모용:
→ 기본값: Window 또는 Region
→ 이유: 더 깔끔하고 집중된 콘텐츠

예측 불가능한 콘텐츠용:
→ 기본값: Fullscreen
→ 이유: 아무것도 놓치지 않음

섹션 2: 비디오 품질 설정

해상도 선택 가이드

480p 선택 시기:

  • 품질이 중요하지 않은 긴 회의 녹음
  • 저장 공간이 심각하게 제한될 때

720p 선택 시기:

  • 표준 비즈니스 사용
  • 이메일이나 Slack으로 공유
  • 균형 잡힌 품질과 파일 크기

1080p 선택 시기:

  • 전문적 프레젠테이션
  • 고객 납품물
  • 상세 소프트웨어 시연
  • 파일 크기보다 품질이 더 중요할 때

1440p 또는 4K 선택 시기:

  • 전문 비디오 프로덕션
  • 매우 큰 모니터 (32인치 이상)
  • 저장이 문제가 아닐 때

프레임 레이트 선택 가이드

30fps 선택 시기:

  • 대담 영상 녹음 (회의, 프레젠테이션)
  • 표준 튜토리얼
  • 파일 크기가 중요할 때

60fps 선택 시기:

  • 게임플레이 녹음
  • 빠른 마우스 이동이 있는 소프트웨어 시연
  • 웹사이트/문서 스크롤

섹션 3: 성능 설정

하드웨어 가속

그래픽 카드(GPU)를 사용하여 프로세서(CPU) 대신 비디오를 인코딩합니다. 이렇게 하면 녹음의 성능 영향이 크게 줄어듭니다.

사용 가능한 인코더 (하드웨어에 따라 다름):

  • NVIDIA NVENC (NVIDIA 그래픽 카드용)
  • AMD VCE (AMD 그래픽 카드용)
  • Intel Quick Sync (Intel 내장 그래픽용)
  • Apple VideoToolbox (Mac용)

활성화 권장 시기:

  • ✅ 전용 그래픽 카드가 있을 때 (NVIDIA/AMD)
  • ✅ 녹음이 컴퓨터를 느리게 만들 때
  • ✅ 1080p 이상 해상도에서
  • ❌ 하드웨어 인코딩으로 품질 문제가 발생하는 경우

품질 프리셋

Ultra Fast — 가장 빠른 인코딩, 가장 큰 파일 크기

Fast — 빠른 인코딩, 적절한 파일

Balanced (권장) — 좋은 품질, 합리적인 파일 크기

High Quality — 더 나은 압축, 더 작은 파일, 느린 인코딩

Maximum Quality — 최고 압축, 가장 작은 파일, 가장 느린 인코딩

Lossless — 압축 없음, 완벽한 품질, 매우 큰 파일

권장: 대부분의 녹음에는 "Balanced" 사용.

섹션 4: 비디오 형식 및 코덱

형식 선택

MP4 (H.264) ⭐ 권장

  • 범용 호환성, 좋은 품질 및 압축
  • 모든 장치에서 작동
  • 적합: 모든 용도

MP4 (H.265/HEVC)

  • H.264보다 파일이 50% 작음
  • 적합: 모바일 장치, 제한된 저장 공간

WebM (VP8/VP9)

  • 오픈 소스 형식
  • 웹 임베딩에 적합
  • 적합: 웹 업로드, HTML5 플레이어

MOV (QuickTime)

  • Apple 기본 형식
  • 적합: Mac 중심 워크플로우, 전문 영상 편집

AVI — 구형 Windows 형식, 큰 파일, 범용 호환성

MKV (Matroska) — 유연한 컨테이너, 여러 오디오 트랙 지원, 보관에 적합

비트레이트 설정

Auto (권장) — SeaMeet가 최적의 비트레이트를 자동으로 계산

사용자 지정 비트레이트 예시:

  • 5 Mbps — 720p 표준 품질
  • 10 Mbps — 1080p 표준 품질
  • 20 Mbps — 1080p 고품질
  • 50+ Mbps — 4K 또는 전문 품질

섹션 5: 커서 녹음 옵션

커서를 녹음하는 이유

커서 녹음의 장점:

  • 시청자에게 어디를 봐야 할지 표시
  • 튜토리얼 및 시연에 필수
  • 소프트웨어 녹음을 이해 가능하게 함

커서 녹음의 단점:

  • 지속적으로 움직이면 산만함
  • 커서가 개인 정보를 드러낼 수 있음

커서 설정

기본 커서 녹음:

☑ Record cursor

커서 강조 표시:

☑ Highlight cursor clicks

사용자 지정:
• Click effect: [Ripple / Circle / Flash ▼]
• Effect color: [Yellow ▼]
• Effect size: [Normal ▼]

커서 크기:

Cursor size: [Normal ▼]
옵션: Small, Normal, Large, Extra Large

활성화/비활성화 시기:

커서 켜기:

  • 튜토리얼 및 시연
  • 소프트웨어 안내
  • 탐색을 보여줘야 할 때

커서 끄기:

  • 화상 통화 녹음 (커서가 산만함)
  • 슬라이드만 있는 프레젠테이션
  • 커서가 개인 정보 드러낼 때

섹션 6: 다중 모니터 구성

다중 모니터 녹음

단일 모니터 녹음:

Default monitor: [Primary (Display 1) ▼]
☑ Show monitor selection on each recording
  • 하나의 화면만 캡처
  • 더 작은 파일 크기
  • 대부분의 사용자에게 권장

모든 모니터 녹음:

  • 연결된 모든 화면 캡처
  • 매우 큰 파일 크기
  • 콘텐츠가 여러 화면에 걸칠 때만 사용

다중 모니터 모범 사례:

  1. 녹음 콘텐츠를 기본 모니터에 배치
  2. 개인 항목은 보조 모니터에 유지
  3. 창 녹음 모드 사용 — 어느 모니터에 있든 특정 창 선택
  4. 필요한 모니터만 녹음

섹션 7: 비디오 문제 해결

문제 1: 녹음이 끊기거나 프레임 드롭이 있음

해결책:

  1. 하드웨어 가속 활성화
  2. 해상도 낮추기 (1080p → 720p)
  3. 프레임 레이트 줄이기 (60fps → 30fps)
  4. 품질 프리셋 낮추기 (High Quality → Fast)
  5. 다른 프로그램 닫기
  6. 디스크 속도 확인 (내부 SSD에 녹음)

문제 2: 비디오 품질이 나쁘거나 흐릿함

해결책:

  1. 해상도 높이기
  2. 비트레이트 높이기 (1080p에서 15-20 Mbps 시도)
  3. 품질 프리셋을 "High Quality" 또는 "Maximum Quality"로 변경
  4. 원본 소스 확인 (저품질 화상 통화는 개선 불가)

문제 3: 녹음 파일이 너무 큼

해결책:

  1. 해상도 줄이기 (720p는 1080p의 공간 50% 절약)
  2. 프레임 레이트 낮추기 (30fps는 60fps의 50%)
  3. H.265 코덱 사용 (H.264보다 50% 작음)
  4. 비트레이트 줄이기

1시간 1080p 녹음 파일 크기 목표:

  • 고품질: 8-12 GB
  • 표준 품질: 4-6 GB

문제 4: 다른 장치에서 비디오가 재생되지 않음

해결책:

  1. MP4 H.264 형식 사용 (가장 범용적)
  2. 코덱 확인 (H.265/HEVC는 구형 장치에서 작동 안 할 수 있음)
  3. 해상도 낮추기 (일부 장치는 4K에 어려움)
  4. Handbrake를 사용하여 H.264 MP4로 재인코딩

문제 5: 검은 화면 또는 빈 녹음

해결책:

  1. 녹음 모드 확인 (올바른 창/모니터 선택 여부)
  2. DRM 보호 콘텐츠 — Netflix, DVD 등은 녹음을 차단함
  3. 관리자 권한 — SeaMeet를 관리자로 실행
  4. 그래픽 드라이버 업데이트
  5. 다른 모드 시도 (창 → 전체 화면 또는 영역)

섹션 8: 녹음 시나리오 구성

시나리오 1: 전문 튜토리얼 영상

모드: Region (화면의 특정 영역)
해상도: 1080p
프레임 레이트: 30fps (빠른 상호작용이 있으면 60fps)
하드웨어 가속: ON
품질 프리셋: High Quality
형식: MP4 (H.264)
비트레이트: 12-15 Mbps
커서: ON (클릭 강조 표시 포함)
커서 크기: Large

시나리오 2: 일일 화상 통화 녹음

모드: Fullscreen
해상도: 720p (프레젠테이션 시 1080p)
프레임 레이트: 30fps
하드웨어 가속: ON
품질 프리셋: Balanced
형식: MP4 (H.264)
비트레이트: Auto
커서: OFF (회의에서 산만함)

시나리오 3: 게임플레이 녹음

모드: Fullscreen 또는 Window (게임)
해상도: 1080p
프레임 레이트: 60fps (부드러운 게임플레이에 필수)
하드웨어 가속: ON (성능에 매우 중요)
품질 프리셋: Balanced 또는 Fast
형식: MP4 (H.264)
비트레이트: 15-20 Mbps
커서: ON

시나리오 4: 웨비나/컨퍼런스 녹음

모드: Fullscreen 또는 Window (슬라이드만)
해상도: 1080p
프레임 레이트: 30fps
하드웨어 가속: ON
품질 프리셋: High Quality
형식: MP4 (H.264)
비트레이트: 10 Mbps
커서: ON

요약

이제 비디오 녹음 전문가가 되었습니다!

✅ 녹음 모드 — 전체 화면, 창, 영역 녹음 중 언제 무엇을 사용할지

✅ 해상도 마스터 — 필요와 저장에 맞게 480p/720p/1080p/4K 균형

✅ 프레임 레이트 선택 — 30fps 대 60fps (부드러운 모션 대 파일 크기)

✅ 코덱 및 형식 — 범용 호환성을 위해 H.264 MP4 사용

✅ 하드웨어 가속 — GPU에 인코딩을 오프로드하여 더 나은 성능

✅ 품질 프리셋 — 인코딩 속도 대 압축 효율성 균형

✅ 커서 옵션 — 튜토리얼을 위해 클릭 강조 표시 및 크기 조정

✅ 다중 모니터 설정 — 올바른 화면 녹음 및 다른 화면에서 개인 정보 유지

✅ 문제 해결 — 끊김, 낮은 품질, 큰 파일, 재생 문제 해결

빠른 참조: 사용 사례별 권장 설정
